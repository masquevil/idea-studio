# 桌游-宝藏猎人

## 游戏概述

名为《宝藏猎人》，是一个**非对称竞技类**桌游。玩家收集传闻，获得宝藏的线索，最终获得宝藏总价值最高的国家获胜。

游戏**支持 2-7 人**游玩。阵营可以根据游戏人数**任意组合**，有着极高的灵活性，比如：

| 游戏人数 | 2 | 3 | 4 | 5 |
| - | - | - | - | - |
| 双阵营 | 1v1 | 1v2 | 1v3 | 2v3 |

| 游戏人数 | 4 | 5 | 6 |
| - | - | - | - |
| 三阵营 | 1v1v2 | 1v1v3 | 1v2v3 |

| 游戏人数 | 7 |
| - | - |
| 四阵营 | 1v1v2v3 |

## 玩法概述

游戏具有以下核心道具：

1. 传闻（卡牌）：产能
2. 货币（硬币）：资源
3. 线索（方块）：资源
4. 宝藏 —— VP（卡牌）：VP

玩家每回合可进行的基本操作是：

1. 打听传闻：摸传闻牌（每回合）
2. 封锁传闻：获得指定传闻牌（消耗货币）
3. 二选一：
   1. 验证传闻：消耗传闻牌，用少量资源换更多资源
   2. 深入调查：直接获得指定资源（亏）
4. 线索交易：线索与货币互换
5. 探寻宝藏：消耗线索，获得宝藏（VP）
6. 散布传闻：用不要的传闻牌换货币
