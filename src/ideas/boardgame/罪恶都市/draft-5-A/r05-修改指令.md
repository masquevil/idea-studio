# 评审⑤ · 修改指令（第十轮）

> 面向 ③-C 修改阶段的精简修改清单。仅写"改什么 + 为什么"，细节见 r01~r04。

---

## 🔴 必须修改

1. [02-角色设计 §3.1]【老鼠】等级 1 得分与等级 2 持平（核心区匹配 +1 → 同为 3 分/次），等级梯度"低等级低回报"失效；人群掩护使核心区调查免防御代价。
   → 原因：等级 1 综合强度 ≥ 等级 2（r03 §3.1 / r04 §1.1）。修改方向二选一，需与用户确认：
   - 方向 A：等级 1 匹配加分仅限影响值 1（核心区 3 分 → 2 分）；
   - 方向 B：人群掩护加限制（如每轮限 1 次/仅调查 1 次免代价）。

2. [02-角色设计 §3.4]【疯子】连环作案（每相邻有证地点 +1）使单次作案达 5-6 分，2.5-3 次 KSA 即终局（4-6 轮），显著突破 8 轮下限；制造恐慌铺证成本低 + 隐藏回复 2 使警长反制失效。
   → 原因：超模确认（r03 §3.4 / r04 §1.2）。建议改为"每有 1 个相邻有证地点 +1，最多 +2"或"连环加成上限 2"，需与用户确认。

3. [01-规则书 §4.2 / FAQ] 混乱 Token 仅 2 枚，追偿/爆料共用且放置期间未定义冲突。
   → 原因：规则漏洞（r01 §1.1）。FAQ：放置期间不能执行另一动作；黎明收回后方可用。

4. [02-角色设计 §2.3]【智囊·战术分析】⚡️ 缺"你的回合"限制，回合外出牌与行动体系冲突。
   → 原因：回合外触发歧义（r01 §2.1）。改为"⚡️ **你的回合限一次**"。

5. [01-规则书 §6.5 追偿] 未限定 2 名角色必须不同、未明确是否可包含自己。
   → 原因：边界未定义（r01 §1.8）。FAQ：2 名角色必须不同；可包含受害者自己。

## 🟡 建议修改

1. [02-角色设计 §2.2]【猎犬·天罗地网】⚡️ 无次数限制，一轮可多放警员。
   → 原因：情报充裕时一轮多控压制面过广（r01 §2.5 / r03 §2.2）。建议加"你的回合限一次"。

2. [03-地点牌 §4-15 黑市] 触发口径歧义（单次支付 >1 vs 累计 ≥2）。
   → 原因：表述歧义（r01 §1.3）。FAQ 明确"本回合累计花费 ≥2 触发一次"。

3. [02-角色设计 §3.4]【疯子·连环作案】计数口径需统一（相邻地点 vs 相邻证据）。
   → 原因：卡面与执行记录不一致（r01 §1.6）。确认按"相邻地点，每个最多 +1"。

4. [01-规则书 §5.5 / FAQ] 延时牌黎明结算（新秀登榜/名动黑白）与终局检查先后未定。
   → 原因：影响终局判定（r01 §1.7）。FAQ：延时效果先于第 ⑦ 项终局检查结算。

5. [01-规则书 §5.4/§5.5] 先机标记更新时机未列入黎明清单。
    → 原因：执行找不到时机（r01 §1.2）。

6. [01-规则书 §7.2] 越狱减费技能（硬汉体质 -1/亡命之徒 -2）缺"最低为 0"下限。
    → 原因：屠夫可免费越狱一格（r01 §1.5）。

7. [02-角色设计 §4 裁决者] 从重判决"在看守所期间"时间段需定义；裁决者 combo 过强风险。
    → 原因：时间段歧义 + combo 压制过强（r01 §2.2/§2.6）。FAQ 定义期间；评估加"每轮限 1 次登场看守所"。

8. [04-策略牌 §2.5]【名动黑白】分数 ≥12 才 +1，未达标玩家拿此牌全程无效，违反 P1。
    → 原因：P1 全角色可用性存疑（r01 §3.1 / r03 §5.1）。建议改为"若你分数最高，黎明 +1"或降低门槛。

9. [04-策略牌 §2.3]【留有后手】"本牌不占手牌上限"表述歧义。
    → 原因：指代不明（r01 §3.2）。改为"摸 1 张牌（此牌不计入手牌上限）"。

10. [04-策略牌 §1.3 vs §3.1] 卡牌构成表完全重复。
    → 原因：文档冗余（r01 §3.3）。删除 §1.3 保留 §3.1。

11. [01-规则书 §4.1/§6] 地点牌 ➡️ 能力的使用者未明确（谁可触发走私通道/捷径等）。
    → 原因：规则缺口（r01 §1.4）。正文明确"任何玩家可在自己回合花 1 行动触发"。

## 🟢 可延后 / 观察

 1. [02-角色设计 §3.2] 幽灵（华丽骗术占重大）、毒蛇（地下网络触发难）、艾米莉（依赖外部触发）偏弱。
    → 原因：角色内部失衡，非全局问题；测试阶段观察后再调。

 2. [01-规则书 §9] 2-3 人局和平奖励几乎不可达（迷雾 Token 常驻）。
    → 原因：跨人数平衡问题；可考虑迷雾不计入和平判定。

 3. [01-规则书 §2] 配件种类偏多，上手负载高。
    → 原因：轻中策定位信息负载偏高；以"快速参考卡"缓解，不改机制。
