# r05 · 修改指令（第七轮）

> 汇总 r01~r04，给 ③-C 修改阶段用的精简修改清单。
> 🔴 = 必须修改 | 🟡 = 建议修改 | 🟢 = 可延后
> 格式：[文档 · 位置] 改什么 → 原因。

---

## 🔴 必须修改

1. **[01-规则书 §4.2 / §6.2 抓捕]** 统一抓捕效果文字为："将你持有该罪犯的'证据 Token'全部移入看守所对应数字区域；该罪犯留在版图上的'证据 Token'全部返回其角色供应堆"
   → 原因：当前两处"所有移入看守所"与"版图返回供应堆"并存，规则矛盾
   → 同步在 §4.5"证据 Token 循环"补充分支：作案→版图→抓捕时直接返回角色供应堆（不经看守所）

2. **[02-角色设计 §4 英雄 C·越权执法]** "移入看守所的 1 区域"改为"移入看守所，放置于其所属犯罪等级区域，并置于数字格 1（距出狱 1 格）"
   → 原因："1 区域"存在犯罪等级区/数字格歧义

3. **[01-规则书 §6.5 受害者·爆料]** 触发条件"该地点被其它角色选择为目标时"改为"该地点被其它角色以行动或效果指定时（含'调查/侦查/作案'等针对该地点的行动）"，并在 FAQ Q12 补充此判定
   → 原因：按现行 Q12 口径，地点永远不会"被选为目标"，爆料能力形同虚设

4. **[04-策略牌 §4 #17 大计划]** 效果改为："当你执行'作案/抓捕/制裁/登场/追偿/爆料'行动获得分数时，或结算你的角色能力获得分数时，本次额外 +1 分"（如需控强度，可改为"该牌全局限用 1 次"）
   → 原因：现行仅覆盖罪犯/警长，违反 P1 全角色可用性

5. **[02-角色设计 §3 罪犯 4·疯子]** "制造恐慌"增加花费："花费 2 个'情报 Token'，选择 1 个地点，在该地点放置 1 个你的'证据 Token'"（或加"重大"标签）
   → 原因：0 情报布证 + 连环作案 = 6-7 分/次速攻，8 轮终局，超模且形成必胜策略

6. **[01-规则书 §2 配件说明]** 明确"迷雾 Token"数量（建议 4 枚）+ 补充"迷雾 Token 不足时少放"兜底
   → 原因：数量未定义导致版图迷雾累积失控、机制失效

7. **[01-规则书 §2 配件说明 + §3.1]** 明确"情报 Token"总量（建议 60~70 枚）
   → 原因：供应堆"剩余"依赖总量定义，多个效果从供应堆取用

## 🟡 建议修改

1. **[02-角色设计 §2 警长 B·猎犬·追踪直觉]** 改为"当你进行'侦查动作'时，从该地点额外获得 1 个'情报 Token'"，或限制与"市政厅监控"不可叠加
   → 原因：追踪直觉 + 市政厅监控使侦查净 -1 倒赚，取证链无限循环

2. **[02-角色设计 §3 罪犯 2C·铁拳·暴力催收]** 增加"每回合限 1 次"
   → 原因：无频次限制时每回合可查看+弃 2 张手牌，干扰过强

3. **[03-地点牌设计 §4 #15 黑市]** 明确"地下经济"："每回合限 1 次"= 每个玩家各自每回合限 1 次；触发 = 在该地点进行行动并花费"情报 Token"时
    → 原因：触发归属未定义，多人共享结算不清

4. **[03-地点牌设计 §3 #06 港口区 / §4 #14 地下通道]** 明确"移动证据"适用者："任何角色皆可使用，可移动该地点任意 1 个'证据 Token'（不改变归属）"，频次定义同 #10
    → 原因：适用者未定义

5. **[01-规则书 §7.2 越狱]** FAQ 补充："每推进 1 格 = 该罪犯在看守所的全部证据整体左移 1 格，花费 2'情报 Token' + 弃 1 张手牌 + 1 分（不论证据数量）"
    → 原因：多证据场景语义未定义

6. **[01-规则书 §5.3 迷雾阶段]** 补充"迷雾 Token"清除相关：警长对已获得的"迷雾 Token"执行"抓捕动作"时，该清除占用当回合"重大"名额（如已在 §6.2 写明则确认一致）
    → 原因：迷雾清除与抓捕同为"重大"位，需确认口径

7. **[03-地点牌设计 §6 影响值分布]** "核心区 5 张"改为"核心区 6 张"
    → 原因：数据笔误（实际列出 6 个地点）

8. **[02-角色设计 §5 受害者 C·掮客·信息垄断]** FAQ："目标地点在调查后情报值为 0 时，信息垄断改为从供应堆获得 1 个'情报 Token'"
    → 原因：调查 -1 后地点可能归零，边界未定义

9. **[01-规则书 §3.3 / §5.4]** 明确起始玩家：无受害者局（2-4 人）警长起始；有受害者局（5-7 人）受害者起始（或统一为警长→受害者→罪犯→超级英雄）
    → 原因：现行两处矛盾

10. **[01-规则书 §4.2 / §6.1 读报]** "额外花费 1 个行动"改为"花费 1 个行动"
    → 原因：读报非重大行动，"额外"易误解为占 2 行动

## 🟢 可延后

 1. **[01-规则书 §4.2 布控]** "属于角色的'证据 Token'"统一为"属于其它角色的'证据 Token'"
    → 原因：措辞与 §6.2 一致（已可理解，仅统一）

 2. **[01-规则书 §4.2 / §6.2 高效抓捕]** 统一"移动的'证据 Token'数量"口径为"你持有并移入看守所的该罪犯'证据 Token'数量"
    → 原因：口径统一（当前可理解为持有数，无实际冲突）

 3. **[01-规则书 §3.1 / §5.3]** 统一网格表述为"4×3 网格"（4 行 3 列）
    → 原因：与图示方向一致

 4. **[01-规则书 §11 FAQ]** 补充："智囊·战术分析借出的策略牌进入弃牌堆"
    → 原因：边界确认

 5. **[04-策略牌 §5.2 效果分类统计]** 得分加成牌待大计划修复后复查占比（建议保持 2 张 + 覆盖全阵营）
    → 原因：随 #4 联动

> 备注：r01 发现但已在 r02-r04 量化中确认不影响主基准的项（如幽灵·华丽骗术偏弱），暂不列入修改指令，留待用户反馈决定是否处理。
