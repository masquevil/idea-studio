# r05 · 修改指令（第六轮）

> 汇总第六轮 r01~r04 的评审结果，给 AI 自身（③-C 修改阶段）使用的修改清单。
> 格式：仅"改什么 + 为什么改"，无背景分析。
> 优先级：🔴 必须修改 / 🟡 建议修改 / 🟢 可延后。
>
> 依据文档：r01（非量化）、r02（量化基准）、r03（设计审查）、r04（综合计算）。

---

## 🔴 必须修改

### 1. [01-规则书 §4.5 / §6.4] 补充英雄持有"证据 Token"的归还规则

   → 英雄「制裁」获得的证据无循环出口，永久脱离循环会导致罪犯资源被饿死、影响无证据奖励判定。
   → **改为**：黎明阶段，英雄将持有的全部"证据 Token"归还对应罪犯的**角色供应堆**（r01 §1.1 / r04 §2.3）。

### 2. [01-规则书 §5.4 ②] 补给阶段补上"罪犯隐藏值 +1（不超过上限）"

   → §4.6 写了补给阶段自动回复 1，但 §5.4 补给阶段漏写，实体游玩易漏执行（r01 §1.2）。

### 3. [01-规则书 §5.5 ②] 补上爆料"混乱 Token"的黎明收回步骤

   → 爆料写"黎明收回（见 §5.5②）"但 §5.5② 未列，规则缺失（r01 §1.3）。

### 4. [01-规则书 §6.5 爆料] 限定 +1 情报修正的影响范围

   → 未限定导致影响侦查/制裁/登场等一切参考情报值的行动，受害者获得超预期跨方压制。
   → **改为**：爆料的情报值 +1 修正仅影响**罪犯计算作案花费**（与布控同口径），不影响其他行动（r01 §1.4）。

### 5. [01-规则书 §6.5 追偿] 补 FAQ：混乱 Token 必须放 2 名**不同**角色、且不能是自己

   → 未限定会出现"放自己面前 -1/ +1 净 0"的逻辑冲突（r01 §3.1）。

### 6. [01-规则书 §6.5 追偿] 补 FAQ：目标分数扣减最低为 0，目标扣不足 1 分时受害者仍 +1

   → 避免受害者因目标低分而收益落空（r01 §3.2）。

### 7. [04-策略牌设计 #18 不在场证明] 重做或改为通用防御

   → 只有罪犯会被抓捕，警长/英雄/受害者拿到完全无正面作用，违反 P1 全角色可用性原则（r01 §5.2）。
   → **候选方向**：改为"抵消针对你的任意负面效果/行动"或"抵消一次被抓"与资源补偿并存的通用机制。

### 8. [02-角色设计 · 屠夫] 「致命打击」下修

   → 上城作案单次 5 分（4/3+超额+1），效率 1.67 分/资源，被抓净赚 1 分/次（r03 §2.2 / r04 C1）。
   → **候选**：改为"上城作案时若该地点相邻有你的证据，额外 +1"，或直接去掉（用灭迹+亡命之徒定位）。

### 9. [02-角色设计 · 疯子] 「连环作案」上限收紧 + 隐藏狩猎防御问题

   → 连环作案 + 博物馆 = 单次 7 分极端暴发（r03 §2.2 / r04 C2）；同时调查 −2 隐藏使疯子长期隐藏 0 → 成为警长"提款机"。
   → **候选**：连环作案上限从 +2 降为 +1 或仅在核心区生效；隐藏狩猎的"调查额外 −1"改为"−1 而非 −2"或删除额外减益，避免防御性崩溃（r03 疯子行）。

### 10. [02-角色设计 · 鬼手] 「后巷密道」加"每回合限 1 次"

   → ⚡️ 无次数限制 → 情报充足可无限移动全部证据，完全规避布控/侦查（r03 §2.2 / r04 C3）。

### 11. [02-角色设计 · 裁决者] 「越权执法」加成本限制

   → 隐藏 0 时 0 情报 + ⚡️ 免行动 → 每回合白拿 1 分 + 场控，12 轮白拿 12 分（r03 §2.3 / r04 C4）。
   → **候选**：加最小成本（如"花费 2 情报"下限）、或改为 ➡️ 行动触发、或移除"每回合限 1 次"取消免行动性。

### 12. [02-角色设计 · 艾登] 「连本带利」下调

   → 追偿门槛 ≥1 + 双目标 + 额外 +1 = 单次 4 分、1.33 分/资源，超基准 3 倍（r03 §2.4 / r04 C5）。
   → **候选**：连本带利改为"仅 1 名目标触发时 +1"（上限 +1 而非 +2），或门槛回到 ≥2 并保留 +1。

### 13. [02-角色设计 · 毒蛇] 「地下网络」重做或放宽

   → "手牌与情报均 0"触发条件近乎不可达，近似死技能（r01 §4.2 / r03 §2.2）。

### 14. [01-规则书 §8.2 / §5.5] 调整警长「无证据奖励」与抓捕链的互斥结构

   → 无证据奖励（+2/轮）与抓捕链互斥，警长实际只能走单一路线（r02 B2-4 / r04 §四/§五）。
   → **候选**：改为"本轮**无新的证据 Token 被放置到版图**时 +2"（松耦合），或新增警长第二条得分路线。

### 15. [08-数值修正 / 01-规则书 §4.7、03-地点牌] 下修罪犯 0 能力超模（影响值/超额/压0）

   → 罪犯无干预 18 分 vs 基准 14-15（偏高 20-28%），核心驱动 = 压 0 低成本 + 超额 +1 + 区域高影响值（r02 §2.5 / r04 §五）。
   → 若无更优方案，先执行第 8/9 项技能下修 + 本项区域数值微调（如超额改为"影响值 > 犯罪等级"才触发，或上城/核心影响值各 −1），保留压 0 × 布控的健康博弈。

### 16. [01-规则书 §11 FAQ] 补"目标"判定清单（金库保险/紧急躲避）

   → 两牌依赖"被选为目标"但范围未定义，玩家无法预判防御范围（r01 §2.5 / F9）。
