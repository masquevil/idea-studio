# r05 · 修改指令（第五轮）

> 汇总 r01~r04 的评审结果，给 AI 自身（③-C 修改阶段）使用的修改清单。
> 格式：仅"改什么 + 为什么改"，无背景分析。
> 优先级：🔴 必须修改 / 🟡 建议修改 / 🟢 可延后。

---

## 🔴 必须修改

1. **[01-规则书 §5.5 黎明①、§7.1「入狱」] 看守所"证据 Token"移动方向统一**
   - 改为与隐藏值轨道一致（0 在最左），黎明移动改为"向左移动 1 格（数字减少 1）"；出狱 = 移动到 0 格。
   - → 原因：当前"向右移动（数字减少）"与"0 在左"的轨道排布、裁决者"越权执法数字 +1 = 延长"语义冲突（R1-1）。

2. **[01-规则书 §4.2 行动表、§6.3 作案详解] 作案补标"**重大**"**
   - → 原因：§4.4/§10.2 已列作案为重大，两处缺失造成读者误解（R1-3）。

3. **[02-角色设计 §4 英雄 B「暗影」莲 — 战术干扰] 删除死分支**
   - 改为："选择 1 名角色，弃置其 1 张手牌；你获得 2 分（每局限 1 次）"。
   - → 原因："弃置证据/情报 Token"分支永不可触发（手牌只有策略牌）（R1-2）。

4. **[02-角色设计 §4 英雄 C「裁决者」赫尔曼 — 越权执法] 移动方向修正**
   - 改为"将其向左移动 1 格的相反方向，即数字 +1（延长刑期）"的明确表述。
   - → 原因：与 R1-1 方向统一（R1-1 延伸）。

5. **[02-角色设计 §4 英雄 C「裁决者」赫尔曼 — 法律漏洞] "原本可以得分"改为可执行判定**
   - 改为："使其本回合不获得任何分数；若其因本效果失去 ≥1 分，你获得 1 分"。
   - → 原因：原判定无法客观执行（R1-12）。

6. **[02-角色设计 §3 罪犯 4「疯子」莱利 — 连环作案] 卡面精简**
   - 改为："你进行'作案动作'时，若该地点相邻地点有你的'证据 Token'，额外 +1 分（上限 +2）"。删除"（四方向，不含斜角）""黎明阶段重置"等边界说明，归口规则书正文/FAQ。
   - → 原因：卡面过长 + "黎明阶段重置"冗余（R1-11）。

7. **[03-地点牌设计 §3 医院 — 康复中心] 处理"调查恢复隐藏 → 压 0 免费"交叉风险**
   - 二选一：① 改为"在本地点进行'调查动作'时，你的隐藏值不降低（每回合限 1 次）"；② 保留恢复但限制"每回合限 1 次"且仅于调查后隐藏值 -1 时恢复 1 点（净 0）。
   - → 原因：医院 × 压 0 使罪犯"调查-隐藏"双代价坍缩为单资源，放大罪犯超模（D3-3/C4-10 🔴）。

8. **[04-策略牌 §3 #18「不在场证明」] 扩展适用范围以合规 P1**
   - 改为"**⏳ 延时**。当你成为'抓捕'动作的目标或角色技能的目标时：抵消本次效应对你的影响"。
   - → 原因：当前仅罪犯受益，英雄/受害者/警长拿到为废牌（R1-8）。

9. **[04-策略牌 §4 #17「大计划」] 扩展适用范围以合规 P1**
   - 改为"**⏳ 延时**。当你执行'作案'或'抓捕'行动，或结算你的角色能力获得分数时：本次额外 +1 分"。
   - → 原因：扩展阵营无作案/抓捕，当前对英雄/受害者不可兑现（R1-7）。

10. **[04-策略牌 §3 #11「证据误导」] 消除对警长的负收益**
    - 改为"**快速**。当警长执行'侦查动作'获得'证据 Token'时，可弃置此牌，改为获得该地点上另一个'证据 Token'（若该地点只有 1 个'证据 Token'则不能使用；打出者自行决定是否改选）"——将"强制改选"改为"可选改选"，由打出者（罪犯常用）掌控；若需保持攻防性，标注其为偏斜牌并在 §7.1 显式声明。
    - → 原因：原效果强制改选，对警长是帮倒忙（R1-9）。

11. **[罪犯基础得分（规则书 §6.3 / 策略收敛）] 缓解"压 0 作案"最强收敛**
    - 建议方向（择一或组合，注意不改全局规则冲突）：
      - 核心区/上城影响值 -1（核心 2→基准不变？上城 3→3；博物馆 4→4）→ 优先方案：**将"超额作案"触发条件从"影响值 ≥ 犯罪等级"调整为"影响值 ＞ 犯罪等级"，或取消超额 +1 改为固定 +1**，消除"压 0 + 超额"叠加出的 1.5-2.0 分/资源极端值。
      - 或：作案得分改为"影响值 - 1（最低 0）+ 超额修正"。
    - → 原因：罪犯 0 能力效率 1.0-2.0 vs 基准 0.39-0.42，超模 2.4-2.6 倍；且压 0 是唯一高效路径（C4-11 收敛）。r02 核心结论。
    - ⚠️ 数值调整属设计决策，需在③-B 与用户确认方向后再动。

12. **[警长被动收敛（无证据奖励 × 抓捕互斥）] 修复 B2-4 结构矛盾**
    - 建议方向（③-B 确认）：
      - 方案 A：**无证据奖励改为"仅当版图上没有*属于*罪犯的'证据 Token'（迷雾 Token 不影响）时触发"**——但迷雾只在 2-3 人局，4 人局无迷雾，此改动对 4 人局无区别。
      - 方案 B：**抓捕本身不再与无证据奖励互斥**——将无证据奖励改为"每个黎明，若本轮内警长执行过'抓捕动作'，额外 +1 分"（奖励主动抓捕而非被动等待）。
      - 方案 C：降低无证据奖励分值（2→1）并加强抓捕收益（高效抓捕 +1→+2），引导主动。
    - → 原因：警长理性收敛于"被动等无证据奖励"，猫鼠互动退化（C4-12/13）。

13. **[02-角色设计 扩展阵营] 强化"记者·艾米莉"得分能力**
    - 建议：独家头条 2 分 → 3 分，或新增每轮稳定的信息-得分联动（如"深度调查后，若目标本回合执行'作案'或'抓捕'行动，你获得 1 分"）。
    - → 原因：记者综合 5-7 分，严重不足（C4-5/D3-7）。

14. **[02-角色设计 扩展阵营] 强化"裁决者·赫尔曼"得分能力**
    - 建议：法律漏洞改为"若其因本效果失去 ≥1 分，你获得 1 分"之外，增加稳定得分源（如越权执法改为"每轮限 1 次"或 +1 分/格）。
    - → 原因：裁决者综合 6-9 分，严重不足（C4-5/D3-6）。

## 🟡 建议修改

1. **[01-规则书 §6.1 读报] 补"总消耗 2 点行动力"**
   - → 原因：消除"1 行动或 2 行动"歧义（R1-4）。

2. **[01-规则书 §4.5 资源] 补地点"情报 Token"上限规则**
   - 建议"每个地点的'情报 Token'不得超过其初始情报值，'情报干扰'超出部分不放置"。
   - → 原因：无上限允许堆叠，打破区域梯度（R1-13）。

3. **[01-规则书 §7.2 越狱] 明确多 Token 处理**
   - 改为"每次执行'越狱'，选择自己的 1 个'证据 Token'，向 0 格方向推进任意格（每推进 1 格结算费用与得分）"。
   - → 原因：多"证据 Token"同时推进的规则模糊（R1-6）。

4. **[01-规则书 FAQ] 补充 4 条边界确认**
   - Q：出狱当轮是否可被立即抓捕？（建议：可）
   - Q：金库是否限制角色技能/地点效果？（建议：仅限策略牌选取）
   - Q：看守所中的"证据 Token"是否计入"无证据奖励"的版图判定？（建议：不计入）
   - Q：通风报信若警长情报不足 2 个，选"弃置其 2 个"怎么处理？（建议：不足则全部弃置）
   - → 原因：边界情况需明确（C4-8/R1-14/R1-15/R1-10）。

5. **[02-角色设计 §4 英雄 B「暗影」莲 — 情报截获] 措辞重写**
   - 改为"每当其他角色花费 1 个'情报 Token'执行行动时，你从公共供应堆获得 1 个'情报 Token'（每回合限 1 次）"。
   - → 原因："若花费方为供应堆"分支无对应情形（R1-5）。

6. **[02-角色设计 §4 英雄 A「夜枭」/§3 罪犯] 清场防守频率约束**
   - 毒蛇·暗度陈仓、双面人·金蝉脱壳、屠夫·消灭痕迹（及夜枭·暗影追踪销毁）——建议统一约束为"每轮限 1 次"或增加 1 情报成本。
   - → 原因：多玩家清场技能叠加可瘫痪警长抓捕链（C4-2 集体滥用风险）。

7. **[01-规则书 §4.2 / §6.2 高效抓捕] 评估"高效抓捕 + 补差"叠加**
   - 若采纳 12 的"主动抓捕奖励"方案 C（高效 +1→+2），需同时复核"1 证据补差抓高等级"的 0.8 分/资源是否过高（建议补差触发时高效 +1 无效）。
   - → 原因：B2-2 提示"最少证据"成为抓捕最优，自相矛盾。

8. **[03-地点牌设计 §3 下城] 下城收益过低（D3-1）**
   - 建议：下城任一地点的影响值 1 → 2（如码头仓库），或为下城增加"作案 0 情报"特例以提升 0.33 分/资源。
   - → 原因：下城沦为情报砖，区域梯度断裂（D3-1）。

9. **[02-角色设计 §3 罪犯 4「疯子」] 等级 4 综合劣势（D3-2/C4-9）**
   - 建议：隐藏狩猎的"调查额外 -1"改为"调查额外 -0（即标准 -1）"，降低压 0 自损；或博物馆影响值 4 的超额条件放宽至等级 4 专属（保持 4）。
   - → 原因：等级 4 极易被抓 × 回报不足，结构性劣势（D3-2/C4-9）。

10. **[03-地点牌设计 §3 黑市] 观察黑市是否成等级 2 新最优**
    - 标记为测试阶段重点观察项；若黑市过强，黑市影响值 2 → 1 或情报 3 → 2。
    - → 原因：下城高性价比点打破梯度（D3-4）。

11. **[04-策略牌 §3 信息牌 05/06] 增强或标记观察**
    - 建议将 05/06 各加 1 个次级收益（如"尾随跟踪：再获得 1 个'情报 Token'"）。
    - → 原因：信息牌价值偏低，策略收敛于强牌（D3-5）。

## 🟢 可延后

1. **[02-角色设计 §4-5] 扩展阵营"每局限 1 次"计数器负担**
   - 评估铁拳制裁/战术干扰/越权执法/黑料曝光是否可改"每轮限 1 次"并调强度。
   - → 原因：组件负担增加（R1-16）。

2. **[02-角色设计 §3 罪犯 3「双面人」— 金融犯罪] 低效印章（0.4 分/资源）**
   - 建议 3 情报 → 2 情报 或 获得 3 分。
   - → 原因：当前低于罪犯基础效率，性价比差（r03）。

3. **[02-角色设计 §3 罪犯 2「毒蛇」— 地下网络] 双 0 条件几乎不可触发**
   - 建议条件放宽为"手牌为 0 时"或"情报为 0 时"。
   - → 原因：双 0 太苛刻（r03）。

4. **[01-规则书 §5.3 迷雾] 2 人局节奏风险标记观察**
   - 2 人局迷雾操作 2 次/轮 → 警长行动负担重，测试阶段重点观察。
   - → 原因：2 人局节奏可能拖沓（r01/C4 延伸）。

5. **[02-角色设计 §4 超级英雄卡面] 5-7 人局上手门槛**
   - 修正逻辑问题后统一做卡面精简（优先 R1-2/R1-5/R1-12）。
   - → 原因：技能文字偏长（r01 §4.3）。
