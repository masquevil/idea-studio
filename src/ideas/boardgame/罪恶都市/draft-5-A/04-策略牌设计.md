# 策略牌设计

---

## 1. 策略牌概述

策略牌是玩家在行动阶段可打出的战术卡牌。每张策略牌的效果描述中标注其标签（如有），各类型的打出规则详见规则书 §5.4 行动阶段。

### 1.1 卡牌格式

```
┌──────────────────────┐
│    情报报告            │  ← 策略牌名称
│                      │
│  ┌────────────────┐   │
│  │   卡牌插画区域    │   │
│  └────────────────┘   │
│                      │
│  ── 效果 ──          │
│  获得 2 个情报        │  ← 效果文本（不再标注 ➡️ 图标）
│  Token               │
│                      │
│  "引用或背景文案"      │  ← 风味文本（可选）
└──────────────────────┘
```

### 1.2 卡牌构成

| 类型 | 数量 | 说明 |
| ------ | ------ | ------ |
| 普通策略牌 | 19 张 | 打出消耗 1 个行动，立即生效 |
| **快速** 策略牌 | 9 张 | 打出时不消耗行动，符合条件时即可打出 |
| ⏳ **延迟** 标签牌 | 5 张 | 在上述类型基础上附加 ⏳ 延迟 标签，打出时正面向上放置，延迟生效（说明：不在场证明由 2 张减为 1 张） |
| **合计** | **34 张** | |

> ⏳ 延迟 标签可附加在任何策略牌上，打出时仍消耗对应的行动力（或无消耗），但效果延迟触发。
> 策略牌本身不再标注 ➡️、↩️ 等图标——这些是能力的图标，非策略牌的类型标识。

## 2. 普通策略牌（19 张）

> 以下策略牌打出时消耗 1 个行动，立即生效。

### 2.1 情报类（6 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 01 | **情报报告** | 3 张 | 从供应堆获得 2 个情报 Token |
| 02 | **情报截获** | 2 张 | 从任意地点获得 1 个情报 Token |
| 03 | **情报共享** | 1 张 | 选择 1 名角色，双方各从供应堆获得 1 个情报 Token |

### 2.2 干扰类（6 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 04 | **情报干扰** | 2 张 | 在指定地点放置 2 个情报 Token（从供应堆获得） |
| 05 | **尾随跟踪** | 2 张 | 选择 1 名罪犯，查看其当前隐藏值和手牌数量（不查看手牌内容） |
| 06 | **暗中观察** | 2 张 | 选择 1 个地点，查看该地点上所有证据 Token 的归属 |

### 2.3 防御/反击类（4 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 07 | **暗中行动** | 2 张 | 选择 1 名罪犯，将其隐藏值提高或降低 1 点（不超过角色卡上限，不低于 0） |
| 08 | **金库保险** | 2 张 | 选择 1 名角色，该角色本回合内不能被选为任何技能或卡牌效果的目标 |

### 2.4 资源转换类（4 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 09 | **证据交易** | 2 张 | 弃置 1 个版图上的**其他罪犯**的证据 Token（选择 1 个地点上的该罪犯证据 Token 移回其拥有者手中；不能弃置自己的证据 Token），获得 2 个情报 Token |
| 10 | **线人报酬** | 2 张 | 消耗 1 情报 Token，从牌堆顶查看 3 张牌，选择 1 张加入手牌，其余 2 张以任意顺序放回牌堆底 |

## 3. 快速策略牌（9 张）

### 3.1 快速牌（7 张）

| # | 名称 | 数量 | 类型 | 效果 |
| --- | ------ | ------ | ------ | ------ |
| 11 | **证据误导** | 2 张 | **快速** | 当警长执行侦查并选择一个地点上的证据 Token 时，改为选择该地点上另一名罪犯的证据 Token（若该地点只有 1 个证据 Token，此牌不能使用）。你持有此牌时对警长无效（该牌为罪犯阵营偏好牌，警长抽到后可在修整阶段弃置并获得 1 情报 Token 作为补偿） |
| 13 | **留一手** | 1 张 | **快速** | 此牌不占用手牌上限。 |
| 14 | **通风报信** | 2 张 | **快速** | 当警长执行抓捕时，你查看警长消耗的证据 Token 数量，可弃置 1 张手牌使该次抓捕消耗的证据 Token 数量视为 +1 |
| 15 | **恰到好处** | 2 张 | **快速** | 当一名角色得分时，你从供应堆获得 1 个情报 Token（该效果每回合合计限 1 次，持有 2 张也不叠加） |

### 3.2 ↩️ 效果的快速牌（2 张）

> ↩️ 不再作为策略牌的独立类型。紧急躲避保留原有效果，其触发条件在效果描述中标注（效果上仍表现为 ↩️ 反应触发能力）。

| # | 名称 | 数量 | 类型 | 效果 |
| --- | ------ | ------ | ------ | ------ |
| 12 | **紧急躲避** | 2 张 | **快速** | （↩️ 效果）当你被其他角色指定为目标时，使其效果对你失效。 |

## 4. ⏳ 延迟 策略牌（5 张）

> 以下牌在普通策略牌基础上附加 ⏳ 延迟 标签。打出时消耗 1 个行动，并正面向上放在你的角色区域，在符合条件时结算其效果（结算时不消耗行动）。

| # | 名称 | 数量 | 类型 | 打出条件 | 结算时机 | 效果 |
| --- | ------ | ------ | ------ | --------- | --------- | ------ |
| 16 | **设伏** | 2 张 | 普通 ⏳ 延迟 | 行动阶段打出，正面向上放置 | 下一轮傍晚阶段结算 | 选择 1 个地点，该地点本轮罪犯作案花费 +2（不计入"情报 Token"，也不消耗警员 Token） |
| 17 | **大计划** | 2 张 | 普通 ⏳ 延迟 | 行动阶段打出，正面向上放置 | 当你执行作案或抓捕行动时结算 | 本次行动额外获得 1 分 |
| 18 | **不在场证明** | 1 张 | 普通 ⏳ 延迟 | 行动阶段打出，正面向上放置 | 当警长对你执行抓捕时结算 | 抵消本次抓捕（警长消耗的证据 Token 不退回） |

## 6. 各阵营的策略牌使用策略

### 6.1 警长优先关注的牌

| 牌名 | 理由 |
| ------ | ------ |
| 情报截获 #02 | 快速获得情报，支撑侦查/布控消耗 |
| 尾随跟踪 #05 | 掌握罪犯的隐藏值状态，决定抓捕时机 |
| 设伏 #16 | 压制罪犯活动区域的优秀手段，提高目标地点作案成本 |
| 大计划 #17 | 抓捕时额外 +1 分，提高得分效率 |

### 6.2 罪犯优先关注的牌

| 牌名 | 理由 |
| ------ | ------ |
| 情报报告 #01 | 快速积累情报，为作案准备资源 |
| 暗中行动 #07 | 提高自己的隐藏值，增加抓捕成本 |
| 紧急躲避 #12 | 防止被针对（包括警长抓捕和超级英雄技能） |
| 不在场证明 #18 | 抵消抓捕，关键时刻保命 |
| 证据交易 #09 | 弃置其他罪犯版图上的证据 Token，获得情报（跨罪犯干扰） |

### 6.3 通用策略

| 牌名 | 适用场景 |
| ------ | --------- |
| 情报共享 #03 | 可与其他角色建立临时合作关系 |
| 情报干扰 #04 | 警长用来提高作案难度，罪犯用来延缓警长侦查 |
| 证据误导 #11 | 罪犯用来混淆警长侦查目标（警长持有可弃置获 1 情报补偿） |
| 恰到好处 #15 | 任何阵营都适用，积少成多 |

## 7. 平衡性说明

### 7.1 策略牌的全局限制

快速牌不消耗行动，打出时也不占用行动上限。

### 7.2 与角色能力的兼容性

策略牌的设计原则是所有牌对所有阵营都有正面潜力。部分角色有与特定牌联动的能力（如"鬼手"阿列克谢的精妙手法与调查联动）。

### 7.3 后续调整方向

| 调整方向 | 触发条件 | 建议调整 |
| --------- | --------- | --------- |
| 资源过剩 | 玩家普遍在修整阶段弃置大量情报 Token | 减少情报类卡牌数量，或提高情报消耗型行动的性价比 |
| 信息不足 | 玩家觉得"看不到对方的状态" | 增加信息类卡牌（如查看隐藏值、查看手牌） |
| 防御过强 | 防御类卡牌使用率过高 | 增加"无视防御"效果，或限制防御类卡牌的出牌时机 |
| 延迟牌节奏慢 | 玩家不愿意使用延迟牌 | 增强延迟牌效果，或减少延迟牌的消耗 |
