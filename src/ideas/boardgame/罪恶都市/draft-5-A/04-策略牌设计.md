**第一部分 · 卡牌清单（设计结果）**

## 1. 策略牌概述

策略牌是玩家在行动阶段可打出的战术卡牌。各类型的打出规则详见规则书 §5.4 行动阶段。

### 1.1 卡牌格式

```
┌──────────────────────┐
│    情报报告            │  ← 策略牌名称
│                      │
│  ┌────────────────┐   │
│  │   卡牌插画区域    │   │
│  └────────────────┘   │
│                      │
│  ── 效果 ──          │
│  从供应堆获得          │  ← 标签 + 效果文本
│  2 个"情报 Token"     │
│                      │
│  "引用或背景文案"      │  ← 风味文本（可选）
└──────────────────────┘
```

### 1.2 标签

效果文本以标签开头（如有）。标签含义见规则书 §10.2：

| 标签 | 说明 |
| ------ | ------ |
| **快速** | 可在任意玩家回合中、满足牌面条件时打出；打出该策略牌时无需花费行动 |
| **⏳ 延时** | 打出时正面向上放在你的角色区域。结算其打出效果。满足条件时结算其延时效果 |

### 1.3 卡牌构成

| 类型 | 数量 |
| ------ | ------ |
| 普通策略牌 | 20 张 |
| **快速** 策略牌 | 9 张 |
| **⏳ 延时** 策略牌 | 5 张 |
| **合计** | **34 张** |

## 2. 普通策略牌（20 张）

> 以下策略牌打出时消耗 1 个行动，立即生效。

### 2.1 情报类（6 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 01 | **情报报告** | 3 | 从供应堆获得 2 个"情报 Token" |
| 02 | **情报截获** | 2 | 从任意地点获得 1 个"情报 Token" |
| 03 | **情报共享** | 1 | 选择 1 名角色，双方各从供应堆获得 1 个"情报 Token" |

### 2.2 干扰类（8 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 04 | **情报干扰** | 2 | 在指定地点放置 2 个"情报 Token"（从供应堆获得） |
| 05 | **尾随跟踪** | 2 | 选择 1 名罪犯，查看其当前隐藏值和手牌数量（不查看手牌内容） |
| 06 | **暗中观察** | 2 | 选择 1 个地点，查看该地点上所有"证据 Token"的归属 |
| 07 | **栽赃陷害** | 2 | 选择 1 个地点上的 1 个"证据 Token"，将其移至 1 个相邻地点 |

### 2.3 防御/反击类（4 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 08 | **暗中行动** | 2 | 选择 1 名罪犯，将其隐藏值提高或降低 1 点（不超过角色卡上限，不低于 0） |
| 09 | **金库保险** | 2 | 选择 1 名角色，该角色本回合内不能被选为任何技能或卡牌效果的目标 |

### 2.4 资源转换类（2 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 10 | **线人报酬** | 2 | 消耗 1 个"情报 Token"，从牌堆顶查看 3 张牌，选择 1 张加入手牌，其余 2 张以任意顺序放回牌堆底 |

## 3. 快速策略牌（9 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 11 | **证据误导** | 2 | **快速**。当警长执行"侦查动作"获得"证据 Token"时，改为获得该地点上另一个"证据 Token"（若该地点只有 1 个"证据 Token"，此牌不能使用） |
| 12 | **紧急躲避** | 2 | **快速**。当你被其他角色的策略牌指定为目标时，使其效果对你失效 |

| 15 | **恰到好处** | 2 | **快速**。当一名角色得分时，从供应堆获得 1 个"情报 Token" |

## 4. ⏳ 延时 策略牌（5 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 16 | **设伏** | 2 | **⏳ 延时**。下一轮傍晚阶段：选择 1 个地点，该地点本轮罪犯作案花费 +2（不计入"情报 Token"，也不消耗"警员 Token"） |

**第二部分 · 策略设计说明（设计思路）**

## 6. 各阵营的策略牌使用策略

### 6.1 警长优先关注的牌

| 牌名 | 理由 |
| ------ | ------ |
| 情报截获 #02 | 快速获得情报，支撑侦查/布控消耗 |
| 尾随跟踪 #05 | 掌握罪犯的隐藏值状态，决定抓捕时机 |
| 设伏 #16 | 压制罪犯活动区域的优秀手段，提高目标地点作案成本 |
| 大计划 #17 | 抓捕时额外 +1 分，提高得分效率 |

### 6.2 罪犯优先关注的牌

| 牌名 | 理由 |
| ------ | ------ |
| 情报报告 #01 | 快速积累情报，为作案准备资源 |
| 栽赃陷害 #07 | 移动其他罪犯版图上的"证据 Token"至相邻地点（跨罪犯干扰） |
| 暗中行动 #08 | 提高自己的隐藏值，增加抓捕成本 |
| 紧急躲避 #12 | 防止被针对 |
| 不在场证明 #18 | 抵消抓捕，关键时刻保命 |

### 6.3 通用策略

| 牌名 | 适用场景 |
| ------ | --------- |
| 情报共享 #03 | 可与其他角色建立临时合作关系 |
| 情报干扰 #04 | 警长用来提高作案难度，罪犯用来延缓警长侦查 |
| 证据误导 #11 | 罪犯用来混淆警长侦查目标 |
| 恰到好处 #15 | 任何阵营都适用，积少成多 |

## 7. 平衡性说明

### 7.1 策略牌全角色可用性

见 `refs/user-initial-5.md`（用户原始想法库，核心想法依据）。

### 7.2 与角色能力的兼容性

策略牌的设计原则是所有牌对所有阵营都有正面潜力。部分角色有与特定牌联动的能力（如"鬼手"阿列克谢的精妙手法与调查联动）。

### 7.3 后续调整方向

| 调整方向 | 触发条件 | 建议调整 |
| --------- | --------- | --------- |
| 资源过剩 | 玩家普遍在修整阶段弃置大量"情报 Token" | 减少情报类卡牌数量，或提高情报消耗型行动的性价比 |
| 信息不足 | 玩家觉得"看不到对方的状态" | 增加信息类卡牌（如查看隐藏值、查看手牌） |
| 防御过强 | 防御类卡牌使用率过高 | 增加"无视防御"效果，或限制防御类卡牌的出牌时机 |
| 延时牌节奏慢 | 玩家不愿意使用延时牌 | 增强延时牌效果，或减少延时牌的消耗 |
