## 第一部分 · 卡牌清单（设计结果）

### 1. 策略牌概述

策略牌是玩家在行动阶段可打出的战术卡牌。各类型的打出规则详见规则书 §5.4 行动阶段。

#### 1.1 卡牌格式

```
┌──────────────────────┐
│    情报报告            │  ← 策略牌名称
│                      │
│  ┌────────────────┐   │
│  │   卡牌插画区域    │   │
│  └────────────────┘   │
│                      │
│  ── 效果 ──          │
│  获得 2 个             │  ← 标签 + 效果文本
│  "情报 Token"         │
│                      │
│  "引用或背景文案"      │  ← 风味文本（可选）
└──────────────────────┘
```

#### 1.2 标签

效果文本以标签开头（如有）。标签含义见规则书 §10.2：

| 标签 | 说明 |
| - | - |
| **快速** | 可在任意玩家回合中、满足牌面条件时打出；打出该策略牌时无需花费行动 |
| **延时** | 打出时正面向上放在你的角色区域。结算其打出效果。满足条件时结算其延时效果 |

> 「以身入局 #11」同时标注**快速**与**延时**：以快速方式打出（无需花费行动），正面放置在你的角色区域并持续存在，黎明阶段弃置。

## 第二部分 · 策略设计说明（设计思路）

### 4. 平衡性说明

#### 4.1 P1 全角色可用性自检

> P1 原则（`refs/user-initial-5.md`）：所有策略牌对任意角色拿到时，都应能产生正面作用。

| # | 名称 | 自检结果 | 说明 |
| - | - | - | - |
| 01 | 情报报告 | ✅ | 四阵营均需情报，纯增益 |
| 02 | 现场勘查 | ✅ | 任何角色花费行动后均可触发，行动补贴 |
| 03 | 情报共享 | ✅ | 净 +2 情报，可社交可独享 |
| 04 | 情报干扰 | ✅ | 抬高点成本，警长压罪犯 / 罪犯互压均可用 |
| 05 | 情报泄露 | ✅ | 双刃方向由打出者自选，攻防皆可 |
| 06 | 混淆视听 | ✅ | 类似 #04，延时压制单点 |
| 07 | 盛会开幕 | ✅ | 集中 + 清空双重效果，战术多样 |
| 08 | 心理侧写 | ✅ | 信息 + 弃牌干扰，对任意角色有价值 |
| 09 | 留有后手 | ✅ | 通用过牌，无阵营偏向 |
| 10 | 情报网络 | ✅ | 通用检索 |
| 11 | 以身入局 | ✅ | 反应式过牌，任何角色的重大动作都可触发 |
| 12 | 社会工程 | ✅ | 降（利警）/ 升（利罪）双方向，英雄与受害者按自身政治立场取舍 |
| 13 | 替罪羔羊 | ✅ | 移动"证据 Token"影响侦查焦点，人人可用 |
| 14 | 证据误导 | ✅ | 干扰侦查结果，罪犯保证 / 英雄控证 / 警长借证均可 |
| 15 | 金蝉脱壳 | ✅ | 纯防御，任何被针对的角色可用 |
| 16 | 通风报信 | ✅ | 重大动作结算后给予 / 剥夺情报，角度中立 |
| 17 | 一夜成名 | ✅ | 直接得分，无阵营偏向 |
| 18 | 新秀登榜 | ✅ | 低分段托底，落后方与低节奏阵营受益 |
| 19 | 名动黑白 | ✅ | 高分段提速，领先方冲刺终局 |

#### 4.2 与角色能力的兼容性

- 「社会工程 #12」与警长「铁腕」的雷霆行动（-1 隐藏值）方向叠加；与罪犯自身的隐藏值回复 / 隐藏动作配合可快速拉高防御。
- 「心理侧写 #08」与警长「智囊」的战术分析（查看手牌后可立即打出其中 1 张）共享信息获取窗口，但二者独立结算，不冲突；心理侧写"弃置其区域的一张牌"含延时牌，可拆解对手的「混淆视听」「以身入局」「新秀登榜」「名动黑白」等角色区域牌。
- 「替罪羔羊 #13」「证据误导 #14」与地点「金融中心·金库」的强制效果（此处"证据 Token"不能被策略牌选择为目标）冲突时，以金库限制为准。
- 「金蝉脱壳 #15」与罪犯「双面人」的技能「打点关系」效果不同：策略牌是"被策略牌指定为目标时使效果失效"，角色技能是"警长通过'侦查动作'获得你的'证据 Token'时花费 4 情报使其返回角色供应堆"。命名已区分，不混淆。

#### 4.3 与地点效果的联动

- 「混淆视听 #06」与「布控」均为"计算地点情报值时"的修正，可叠加且无上限（规则书 §11 Q10）。
- 「情报泄露 #05」的移除方向与"作案回填 1 情报"相互拉扯：压 0 地点作案回填 1 后，可再用 #05 移除归 0，形成低成本作案窗口（受手牌数量约束）。
- 「盛会开幕 #07」与「火车站·流动人口」的黎明回填共同影响版图情报分布，是少数能快速重塑版图情报格局的牌。
