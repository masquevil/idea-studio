## 一、4 人局综合节奏

### 1.1 罪犯方综合节奏（3 罪犯）

**前提**：3 罪犯各自独立作战，但共享版图情报。等级组合按推荐（1 个等级 1 + 2 个等级 2，或 2+2+3 等）。

**综合推演（无警长干预的理想态）**：

| 等级组合 | 每人单次 IV | 每人达标次数 | 合计周期（理想） | 说明 |
| - | - | - | - | - |
| 1+2+2 | 3 / 3 / 3 | 5 / 5 / 5 | ~10 轮 | 三人独立达标，任何一人 5 次作案即触发终局 |
| 2+2+3 | 3 / 3 / 4 | 5 / 5 / 4 | 9~10 轮 | 等级 3 更快达标 |
| 2+3+4（含疯子） | 3 / 4 / 爆发 | 5 / 4 / 2-3 | **7~9 轮** | 疯子爆发可大幅提前终局 |

**疯子（当前规则）综合推演**：R1-R2 制造恐慌×2 布 4 证 → R3 连环作案 = 影响 2 + 匹配 1 + 相邻 3-4 = **6-7 分** → R5-R6 再爆一次 → **约 8 轮内 15 分**。若 3 罪犯含疯子，全局终局被疯子的爆发强行拉快 → **其他罪犯的节奏被迫跟随，游戏提前结束**。判定：**综合影响超标，疯子需 nerf（r03 已提）**。

### 1.2 警长综合节奏（含技能）

**猎犬（当前最强）**：

- 追踪直觉：侦查净花费 = 地点情报 - 1（回 1 情报）；配合核心区压 1 地点 → 侦查净 0
- 抓捕循环：侦查（0 情报）→ 抓捕（2 行动 + 补差 1）→ 3 分/次
- 抓捕频率：每 2 轮 1 次（0 情报侦查 + 1 补差）→ 4-5 次抓捕 ≈ 8-10 轮 + 前期和平 1-2 = **9-11 轮**
- 判定：与基准相当（0 能力警长也 9-11 轮），猎犬的收益被"侦查免费"兑现为**情报结余**（警长攒下的情报可转布控/更激进），实际略强于基准但未超模

**铁腕**：

- 雷霆行动：抓捕轮"侦查 + 抓捕"同轮 → 抓捕周期 2 轮→1 轮 → 4-5 次抓捕 ≈ 4-5 执行轮 + 攒情报 = **7-9 轮**
- 铁腕执法：抓隐藏 ≤1 目标 +1 分 → 单次 4 分（等级 2 高效 3 + 1）→ 4 次即 16 分 → **更快触发**
- 判定：**铁腕是全技能警长中最快**（7-9 轮），但需"隐藏 ≤1"条件（依赖罪犯调查掉隐藏或等级 1 目标）→ 条件型爆发，合理

**智囊**：

- 战术分析：借罪犯手牌打出（如借到"大计划"→ 抓捕额外 +1）= 单次抓捕 4 分 + 信息收益
- 借牌依赖对方手牌质量，强度波动大 → 判定：**上限高、下限低**，合理

**警长综合结论**：猎犬/铁腕/智囊各有节奏优势，整体使警长在 8-11 轮区间波动，**与罪犯基准（9-12 轮）基本对等**（加权口径下警长剥夺含金量更高，净平衡成立）。

### 1.3 净平衡判定（§3.5 跨方抑制）

| 维度 | 罪犯（无干预） | 罪犯（被抑制后） | 警长 |
| - | - | - | - |
| 理想节奏 | 10 轮 | 12-14 轮（布控 +2 情报费/次 → 需额外调查轮；抓捕 → -1 执行轮/次） | 9-11 轮 |
| 判定 | 自然触发 ✓ | **被抑制后接近/出界** | 同时执法+压制下仍能达标 ✓ |

**关键结论**：

- 警长单次布控使目标地点罪犯作案情报费 +2（1→3）→ 罪犯需额外 1 个调查轮/次 → **3 罪犯集中于同一地点时，警长一次布控压制 3 人**，抑制效率极高
- 但布控每回合限 1 次（行动占用）→ 警长在"布控"与"侦查/抓捕"之间取舍 → 抑制与得分不可兼得的张力成立
- **净平衡判定：通过**。罪犯理想 10 轮、被抑制 12-14 轮（出界边缘）、警长 9-11 轮——差在 1-3 轮内，属可接受范围；但**若警长 2 次以上连续的布控+抓捕叠加，罪犯被压制过重**（<8 轮？不，是罪犯周期 >12 轮被过度反制）。标记：布控对"集中作案"的惩罚偏重，测试时关注 3 罪犯是否被逼分散（分散则布控失效 → 平衡自然恢复）。

## 二、深度漏洞检查（§3.8/§3.9 维度）

### 2.1 资源消耗趋势（情报 Token）

**版图情报总量**：4 人局 12 张地点，初始情报 ≈ 3×4 + 3×3~4 + 3×3 + 1×5 ≈ 40 左右（随抽牌浮动）。

**消耗与回补**：

| 来源 | 类型 | 速率 |
| - | - | - |
| 调查（每次 -1 版图） | 消耗 | 4 人每轮 3-4 次调查（罪犯为主）→ 每轮 -3~-4 |
| 复苏（情报 0 地点 +1） | 回补 | 每轮最多 +12（所有 0 值地点），实际随耗竭推进 +3~+6/轮 |
| 火车站回填 | 回补 | 每轮 +1（≤初始值） |
| 作案/侦查花费 | 回流 | 情报花费 → 公共供应堆（**不消耗版图**）→ 供应堆再被读报/报告等取出 |

**趋势判断**：

- 前 3-4 轮：版图情报被调查快速压降，核心区压点地点进入 0↔1 震荡（复苏托底）
- 中期（R5-R9）：多数主动作案点稳定在 1 情报；每轮作案情报费稳定 1
- 后期（R10-R12）：版图情报普遍低位，侦查/作案花费便宜 → **后期节奏加速**（符合"后期冲刺"预期）
- **判定：耗竭曲线平滑**；复苏 + 回流机制保证了"成本不跳跃"（原则 11/12 通过）

**风险点**：若 3 罪犯同时压点多个地点，版图情报快速归零 → 各地点长期 0↔1 震荡 → 作案费稳定 1（不是 0，复苏兜底）→ **不会出现"作案费突变 0"的跳跃** ✓；但供应堆情报富集（花费回流 + 读报/报告取出次数少）→ 警长侦查补差成本下降 → 默认利警。标记：供应堆富集是长期趋势，符合"犯罪成本不随通胀降低"的设计（§3.8 敏感性已知）。

### 2.2 成本突变检查

| 场景 | 成本变化 | 是否突变 |
| - | - | - |
| 地点情报 1→0（调查后再作战） | 作案费 1→0 | 复苏兜底回 1，实际稳定在 1，无突变 ✓ |
| 布控生效 | 作案费 1→3 | **+2 跳跃**。对单次作战影响大，但布控每回合限 1 次/警长 1 人，且玩家可换地点规避 → 属可预期的战术性跳跃，可接受 |
| 抓捕入狱 | 作战能力中断 | 罪犯失去 1 个执行轮（只能读报），成本体现为轮次损失而非资源跳跃 ✓ 平滑 |
| 迷雾 Token（2-3 人局） | 侦查成本推高 | 迷雾累积（r01 1.4 需修复数量）——修复后每轮 1-2 枚，侦查成本渐进增加，无突变 |

**判定：成本结构平滑**，唯一显著跳跃是"布控 +2"，属设计内战术变化。

### 2.3 循环完整性检查（Token 全链路）

| Token | 产生 | 消耗/回收 | 闭环判定 |
| - | - | - | - |
| 情报 Token | 调查/复苏/回流/效果 | 花费 → 公共供应堆 → 可再获 | ✓ 闭环（供应堆总量需定义，r01 1.5） |
| 证据 Token（罪犯） | 角色供应堆（5 枚） | 作案 → 版图 → 侦查（警长持）→ 抓捕（看守所）→ 出狱（返回供应堆）；或抓捕时版图证直接返回供应堆 | ✓ 闭环（需修复 r01 1.1 文字，但机制闭环成立） |
| 警员 Token | 角色供应堆（5 枚） | 布控 → 地点 → 黎明收回 | ✓ 闭环 |
| 英雄 Token | 角色供应堆（1 枚） | 登场 → 地点 → 黎明收回 | ✓ 闭环 |
| 混乱 Token | 受害者（2 枚） | 追偿/爆料 → 角色/地点 → 黎明收回 | ✓ 闭环 |
| 迷雾 Token | 公共（数量待定义） | 放置 → 侦查（警长持）→ 清除（公共） | ⚠️ **数量未定义会导致累积失控**（r01 1.4） |

**判定**：全链路闭环，唯一缺口是迷雾 Token 数量定义。

### 2.4 交叉组合风险（原则 14）

| 组合 | 效果 | 风险判定 |
| - | - | - |
| 猎犬追踪直觉 + 市政厅监控 | 侦查净 X-2，压 1 地点侦查净 -1（倒赚） | ⚠️ **偏高**：警长侦查不仅能免费取证，还能倒赚情报。叠加后警长取证链无限循环（侦查倒赚 → 补差 → 抓捕）。**建议限制**：追踪直觉与监控不可叠加（或监控改为"侦查时从该地点额外获得 1 情报"——改变收益来源） |
| 鬼手精妙手法 + 地下酒吧 | 调查 1 行动 → 3 情报（1 地点 +1 黑市 +1 精妙） | ⚠️ **偏高**：资源产出 3 倍于基础调查。但依赖"地下酒吧在版图"（6 张核心抽 6，必中？——4 人局核心区 6 张全展出，地下酒吧必在版图！）→ **必中的强资源点**。幽灵+鬼手双罪犯可轮流吃。建议关注：地下酒吧"每回合限 1 次"是全局还是个人（r01 3.1 同款问题）；若全局 1 次则多人竞争稀释 ✓ 偏低风险 |
| 疯子制造恐慌 + 连环作案 | 无情报布证 + 相邻加成无上限 | 🔴 **超模**（r03 已判） |
| 设伏 + 布控叠加 | 目标地点情报 +4 | 两次压制叠加，作案情报费 1→5 → **单点作战完全冻结**。但设伏需延时准备 + 布控占行动，双前置条件 → 高风险高收益，属战术组合。**可接受**（但若叠加爆料 +1 → +5，几乎不可作案 → 测试关注） |
| 恰到好处 + 高频得分局 | 每轮 +1~3 情报（多人得分） | 被动滚资源，长期收益可观但不直接得分 → 可接受 |
| 铁腕雷霆行动 + 大计划（借牌） | 同轮侦查+抓捕+额外 1 分 | 高爆发但手牌+条件依赖 → 合理上限 |

**判定**：主要风险为 ① 猎犬+监控（侦查倒赚，🔴 达标）② 疯子组合（🔴）③ 地下酒吧多人叠加（🟡 取决于"每回合限 1 次"口径）。

### 2.5 策略收敛检查（原则 15）

**收敛风险分析**：

1. **罪犯策略收敛**：核心区影响 2 是等级 1-2 的明确最优（效率 1.00 分/IC）→ 3 罪犯可能全部涌向核心区同点 → **布控一压三、共享压点成果** → 出现"扎堆核心区"的收敛风险。
   - 缓解：核心区 6 个地点、影响 2 的有 5 个（老城/红灯/工厂/酒吧/医院/学校，实际 6 张中 5 张影响 2）→ 罪犯可分散；且分散后警长布控只能覆盖 1 点 → **收敛被布控惩罚自然破除**。
   - 判定：**中等收敛风险，机制上有破除途径**（布控分化 + 地点多样性）✓

2. **警长策略收敛**：抓等级 3+ 目标 + 布控压制是明显最优。无收敛问题（跨方天然多样性）。

3. **策略牌收敛**：资源牌（情报报告）与防御牌价值普适 → 可能人人抢 → 但牌库随机摸取，无法定向 → 收敛风险低 ✓

4. **终极检查（有无"必胜策略"）**：0 能力无（双方基准对等）；叠加技能后，**疯子抢先爆发的"速攻流"** 有必胜策略苗头（8 轮内 15 分，警长来不及反制）→ **根因是制造恐慌无情报费**，nerf 后收敛风险解除。

**判定：收敛风险主要为疯子速攻流（根因同超模）与罪犯扎堆核心区（有天然破除机制）**。

### 2.6 非对称阵营综合对比（含扩展）

**4 人局（核心对称轴）**：

| 阵营 | 理想周期 | 被抑制周期 | 加权口径 | 综合对比 |
| - | - | - | - | - |
| 罪犯 | 10 轮 | 12-14 轮 | 1.0 | 基准通过，被抑制后偏出界 |
| 警长 | 9-11 轮（含技能） | — | ~1.33（抓捕） | 与罪犯理想对齐，略优但依赖罪犯行动 |

**判定：4 人局净平衡成立**（警长加权后与罪犯基本对等，且警长需承担"抑制成本"——布控/侦查占用本可抓捕的行动位）。

**5-7 人局（扩展阵营推演）**：

| 阵营 | 得分手段 | 综合评估 |
| - | - | - |
| 超级英雄 | 制裁（等差数列 1+2+3…）/ 登场（地点证据数 X） | 制裁滚雪球依赖多次取证（每次增加持有数）→ 需 5 次制裁达 15 分（1+2+3+4+5）；夜枭"一网打尽"加速取证。**依赖罪犯产生证据** → 若罪犯少（5 人局 3 罪犯）证据供给足；制裁的公安差（隐藏值花费）随警长抓捕竞争。**综合约 9-12 轮**，与基准可比。⚠️ 英雄取走证据 → 减少警长目标 → 三方拉扯，机制健康 |
| 受害者 | 追偿（夺 1）/ 爆料（翻面 1） | 依赖他人得分/地点被选 → **触发率低**（r01 1.2 爆料几乎不触发；追偿每轮 1 次重大，需目标得分 ≥2 才生效）→ 综合约 **11-14 轮**，**偏弱**。需依赖角色技能（艾登 ≥1 门槛）补强。判定：受害者是扩展局中最弱阵营，爆料修复（r01）与技能补偿（r03）double 必要 |

**非对称补偿检查（原则 16）**：受害者无"基础得分手段"（追偿/爆料都是条件型）→ 其技能（艾米莉 +1/+1、艾登降门槛/+1、掮客信息+保底）是补偿核心。当前补偿不足以弥补触发率缺陷 → **建议至少修复爆料触发 + 保留技能补偿**，并在测试阶段重点验证受害者可达性。

## 四、r04 结论摘要

**🔴 必须处理（综合失衡）**：

1. **疯子速攻流**（制造恐慌 0 情报布证 → 连环作案 6-7 分/次 → 8 轮终局）：综合影响 = 全局终局被拉快 + 必胜策略苗头。**修改：制造恐慌加情报费或限制频率**。
2. **猎犬追踪直觉 + 市政厅监控**（侦查净 -1 倒赚）：取证链无限循环风险。**修改：限制叠加或调整追踪直觉收益**。

**🟡 需明确**：
3. 地下酒吧"每回合限 1 次"的全局/个人口径（影响资源产出强度）。
4. 受害者（扩展）触发率缺陷 → 依赖 r01 爆料修复 + 技能补偿。

**✓ 通过项**：资源耗竭平滑、成本无突变、Token 链闭环（除迷雾数量）、4 人局非对称净平衡、策略收敛有天然破除机制。
