## 2. 交叉组合风险（§4.2 原则 14）

### 2.1 🔴 疯子 × 黑市 × 连作案（三重叠加）

**组合**：疯子（等级 4，连环作案）+ 黑市（地下经济，花费回 1 情报）+ 相邻上城地点批量布证。

**推演**：

1. 疯子在黑市压 0（3 情报 1.5 轮）→ 2 次作案（每次 4 分 = 影响 2 + 匹配 +1 + 连环 +1，相邻 1 证据），黑市回填被地下经济抵消 → 净花费 0
2. 再用 2-3 轮在商业街/金融中心相邻堆积自身证据（每次作案 3-4 分）
3. 第 4-5 次作案时相邻证据达 3-4 个 → 单次 6-8 分
4. **总节奏：6-8 轮 15 分**，远快于 8-12 基准

**风险等级**：🔴 严重。即使单独修复黑市或疯子其一，另一项仍使罪犯阵营整体快于警长反制（警长 12 轮才 13-14 分）。**两项都需修复**。

### 2.2 🔴 裁决者 × 越权执法 × 重大叠加（每回合双得分）

**组合**：裁决者越权执法（1 行动，非重大）+ 制裁/登场（重大，2 行动）。

**推演**：

- 回合行动：制裁（2 行动 + 情报）→ 剩余 0 行动？——**需 3 行动才能同回合执行越权执法（1）+ 制裁（2）**。回合基准 2 行动 + 夜行 1 = 3 行动（弃 2 手牌）。
- 夜行条件下：制裁（2 行动）+ 越权执法（1 行动）= 每回合可得 `等差数列分 + 1 分 + 剥夺`
- 若放弃夜行：第 2 天回合交替执行"制裁轮 / 越权轮"，越权执法作为轻量得分补充（1 行动，每回合限 1 次）仍显著加速。

**风险等级**：🔴 高。即使无夜行，越权执法"1 行动 + 1-3 情报 → 1 分 + 剥夺"的效率约为警长抓捕的 1.7 倍（§r03 2.5），且 5-7 人局中无对应反制手段（谁能阻止英雄移证据入狱？）。

### 2.3 🟡 黑市 × 警长侦查（对称风险）

**组合**：黑市地下经济对**所有玩家**生效（"每个玩家自己的回合内限 1 次"）。警长在黑市侦查（花费 X）→ 回 1 情报 → 侦查净成本 -1；警长在黑市抓捕补差花费 → 回 1。

**影响**：黑市是全阵营通用资源循环点，警长也受益（侦查/抓捕成本降低）。**修复黑市时需注意不误伤警长侧**——若直接移除回 1，警长失去廉价侦查点；若保留但限制"仅花费作案相关行动触发"，则只斩断罪犯的净 0 成本链。

**建议**：黑市效果改为"**在本地点进行'作案动作'时**，花费减少 1（最低 0）"——与码头仓库同型，既保留"下城便宜"定位，又不产生全局资源回环。

### 2.4 🟡 暗影 × 登场 × 证据集中（偏强但可控）

**组合**：暗影影随（登场回 1 情报 + 相邻证据 +1 分）+ 登场（X = 该地点证据数）。

**推演**：在证据集中地点（X=3）登场 = 3 分 + 影随 1 分 + 回 1 情报 = **4 分 + 净 1 情报回本/次**。每 2-3 轮可登场 1 次（英雄 Token 黎明收回）。

**判定**：🟡 偏强但受"英雄 Token 黎明收回 + 重大每回合 1 次"频率约束，且登场后证据被清 → 制裁复利中断（登场/制裁互斥的取舍）。**可控，标记测试重点**。

### 2.5 其余组合检查

| - | - | - |

| 老鼠 × 核心区调查 | 隐藏不降的压点免代价 | 🟢 限核心区，范围可控 |

| 设伏 + 布控 + 爆料叠加 | 目标地点花费 +5 | 🟡 极端压制单点（Q11 无上限）；受"单点集中"策略约束，玩家可绕行 |
| 不在场证明 × 重大动作 | 打断抓捕/作案/制裁 | 🟢 快速 + 弃 1 牌 + 仅 1 张，成本合理 |
| 通风报信 × 重大动作 | 每次重大后 ±2 情报 | 🟡 战略影响力大，观察收敛 |

## 3. 策略收敛检查（§4.2 原则 15）

### 3.1 🔴 收敛风险 1：黑市 + 等级 2 双甜点

**现象**：等级 2 罪犯单次 3 分（效率 0.60-0.67 分/行动）是最优效率；黑市（若保留回 1）提供唯一"0 成本连作案"地点。**理性罪犯必然：选等级 2 角色 + 黑市压点连作案**。

**推演**：玩家 A（等级 2）在黑市压 0 后：每次作案花费 0 情报（地下经济抵消回填）、得 3 分（影响 2 + 匹配 1）。5 次作案 = 5 执行轮 + 1.5 准备轮 = **6.5-7 轮 15 分**。其他罪犯若选等级 3-4（需上城 4-5 初始压点）或等级 1（单次 2 分），效率全面落后。

**结论**：黑市回 1 + 等级 2 甜点 → 单一最优策略。**黑市修复（§2.3）+ 等级 2 效率回调**（如核心区影响值 2 地点与等级 2 的匹配加分是否过慷慨）双管齐下。

### 3.2 🟡 收敛风险 2：所有罪犯涌入同一最优地点

**现象**：若某地点（如黑市/老城区）效率最优，3 罪犯可能集中压同一地点。此时：

- 该地点情报被快速压 0 → 作案成本趋 0（但回填竞争）
- 警长侦查成本也低（该地情报 0）→ **警长清证成本同步降低**，抓捕威胁集中
- 多罪犯同地点 → 互相竞争证据空间 + 被"栽赃陷害"干扰

**结论**：集中压点有自我制衡（警长反制 + 内部竞争），**收敛风险中等**。但若配合黑市净 0 成本，内部竞争被资源无限性抵消 → 仍是问题。黑市修复后此风险可接受。

### 3.3 🟡 收敛风险 3：受害者无脑追偿

**现象**：受害者主 KSA 追偿（轻量型，每轮 1 次）单次 +1 分，但 15 次触发才达标。理性受害者每轮追偿 + 调查，**无脑追偿**是否最优？

**推演**：追偿需要情报（每次 1 情报）= 每轮 1 次调查供情报 + 1 次追偿 = 每轮 1 追偿。但追偿目标"期间得分 ≥ 2"依赖他人得分 → 若全场低分（互相压制），追偿空转。

**结论**：追偿的最优性依赖场况，收敛风险低；但**受害者主动性不足**（完全依赖他人得分节奏）是体验设计问题，非平衡问题。标记测试观察。

### 3.4 ✅ 无收敛项目

- 警长 3 路线（铁腕抓低隐/猎犬清证/智囊借牌）各异，无单一最优
- 策略牌受手牌上限 3 约束，无"囤牌必胜"
- 地点梯度提供多目标选择（下城安全 / 核心效率 / 上城爆发）

### 4.2 跨阵营抑制分析（§3.5，警长 → 罪犯）

**警长侧两部分**：

| 部分 | 内容 | 量化 |
| - | - | - |
| ① 自身双效率 | 抓捕 3-4 分/次 × 1.33 加权 | 12 轮 4-5 次 ≈ 16-20 当量 |
| ② 对罪犯抑制 | 布控 +2 情报（拉断连作案链）、侦查取证（限连作案）、抓捕入狱（损失 1 执行轮） | 每次有效抓捕使目标罪犯损失约 1 轮（3 分当量） |

**净平衡判定**：

- 罪犯无干预：9-11 轮 15 分（等级 2）/ 6-8 轮（疯子）→ 警长须通过抑制把疯子拉到 8-12 轮区间
- 警长 12 轮内完成 4-5 次抓捕时：可造成目标罪犯共损失 4-5 个执行轮。**若集中打击疯子（3 罪犯中 1 人），疯子 6-8 轮被拉长至 9-11 轮** → 警长抑制有效 ✅
- **但**：警长自身 12 轮 13-14 分、需 15 分，**抑制罪犯与自身得分无法兼顾**（抓捕轮占满回合，无法同时调查/侦查攒下一案）——这正是 r02 已发现的警长纯分缺口。**猎犬/智囊的补分缺口不解决，警长即使有效抑制罪犯，自己也到不了 15 分**。
- **结论**：4 人局中"警长有效压制 + 自身达标"无法同时满足（除非铁腕的 +1 分条件全触发）。**结构性矛盾：警长阵营整体偏弱 + 罪犯（疯子）超快**。

### 4.3 受害者 → 领先者抑制（5-7 人局）

- 追偿（艾登）对高分角色每轮 -1 → 压制领先者 ✅
- 但受害者自身 15 分达标困难（艾米莉/掮客）→ 抑制别人自己也赢不了，**抑制无收益闭环** → 受害者边缘化风险。

## 5. 资源循环深度检查

### 5.1 资源消耗趋势（情报 Token 耗竭曲线）

**情报 Token 产生**：调查（地点→玩家）+ 策略牌（供应堆→玩家）+ 火车站回填 + 作案回填 + 黑市回 1。

**情报 Token 消耗**：侦查花费、作案花费、抓捕补差、布控/技能花费、追偿爆料花费——**所有花费返回公共供应堆**（§4.5）。

**循环闭合判定**：

| 资源 | 产生 → 消耗 → 回收 | 闭环 |
| - | - | - |
| 情报 Token | 调查（地点→玩家）→ 花费 → 回公共供应堆 → （下次调查）再取 | ✅ 闭环 |
| 证据 Token | 角色供应堆 → 作案放置 → 侦查持有 → 抓捕入狱 → 黎明左移 → 0 格返回角色供应堆 | ✅ 闭环 |
| 警员 Token | 角色供应堆 → 布控放置 → 黎明收回 | ✅ 闭环 |
| 英雄 Token | 角色供应堆 → 登场放置 → 黎明收回 | ✅ 闭环 |
| 混乱 Token | 受害者 → 追偿/爆料放置 → 黎明收回 | ✅ 闭环（若修复 r01 §1.1 互斥问题） |
| 迷雾 Token | 供应堆 → 迷雾行动放置 → 侦查取得 → 抓捕返回供应堆 | ✅ 闭环 |

**结论**：所有 Token 链闭环 ✅，无永久流失。

### 5.2 情报耗竭 / 成本突变成分

- **地点情报耗竭**：核心区地点初始 3，4 人局中 3 罪犯 + 警长共用。每个被压 0 后回填 1（作案），火车站额外 +1 → **地点情报不会永久为 0**（作案回填 + 火车站）✅
- **成本突变检查**：作案成本随回填 0→1→2 平滑递增（黑市回归避免后）；布控/设伏 +2/+5 提供短期跳跃但受"本轮有效"约束，非永久 ✅
- **供应堆情报富集**：若多人调查多过花费，供应堆情报富集 80 枚（若玩家少）。4 人局 12 轮 × 人均消耗 10+ 情报 = 约 40-50 枚消耗，供应堆 80 枚**充足** ✅ 无明显枯竭风险

### 5.3 证据 Token 循环量检查（罪犯侧）

- 每个罪犯 5 枚证据。连续作案 5 次后证据全在版图 → 第 6 次作案改为**移动已有证据**（§4.5 溢出）
- 移动证据**不增加版图证据总数** → 罪犯的"证据蓄积"有上限 5 枚/人
- 警长侦查取走 1 枚 → 罪犯证据回角色供应堆 → 可再次作案放置
- **循环完整** ✅；**溢出规则为连作案提供了自然刹车**（5 次后无法新增证据，只能移动——配合匹配加分判定仍可得分但无法堆叠新证据）

## 7. 结论与移交

**r04 主判定**：
