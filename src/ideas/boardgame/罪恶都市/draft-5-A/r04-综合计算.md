# r04 · 综合计算（第五轮）

> 评审范围：加入所有特殊能力、环境效果、卡牌效果后的综合结果——各阵营/路线综合得分/进度预期、资源循环深度检查（资源消耗趋势、成本突变、循环完整性）、交叉组合风险、策略收敛检查、非对称阵营综合对比。
>
> 依据：r02 基准（罪犯 0 能力 1.0 分/资源、警长抓捕链 0.6 分/IR）、r03 审查（超模/偏弱清单）。
>
> 设计基准：0.39-0.42 分/资源、1.17-1.25 分/IR（14-15 分 / 12 轮）。

## 一、各阵营综合得分预期

### 1.1 罪犯（核心区压 0 作案 + 超模技能）

以等级 2 「毒蛇」理查德 + 核心区为例，加入技能后的完整循环：

| 技能项 | 对循环的影响 |
| - | - |
| 暗度陈仓（2 情报+1 行动，重大） | 每轮最多 1 次回收版图证据 → 阻断警长侦查目标；消耗 1 个"重大"槽（与作案冲突？） |

> ⚠️ **重大槽冲突检测（C4-1）**：暗度陈仓与作案均为"重大"（每回合仅 1 次）。若毒蛇本回合用暗度陈仓回收证据，则**不能同时作案**。这意味着"自我清场"是以**牺牲当轮 3 分作案**为代价的。量化修正：毒蛇"暗度陈仓"的实际机会成本 = 当轮作案 3 分 + 2 行动 + 2 情报。**该技能并非零成本防守，而是防守-得分二选一**，超模评级应下调为 ⭐⭐（合理偏强），清场防守滥用风险大幅降低。

**修正后的清场防守链评估**：

- 毒蛇每"清场"一次，代价 = 放弃当轮作案（-3 分），但换来"警长对该目标无证据可抓"（剥夺警长 3 分/次抓捕 + 0.6 分/IR 的枪口）。
- **净平衡判断**：只有当警长确实在下一轮会抓到毒蛇时，"清场"才是正收益；若警长并未瞄准毒蛇，清场 = 净亏 3 分。→ 清场是**时机性防守**而非无脑超模，符合策略多样性。
- 但三罪犯中若有 2+ 人拥有清场技能（毒蛇暗度陈仓 / 双面人金蝉脱壳 / 屠夫消灭痕迹），警长目标池持续清空 → **抓捕链被结构性压制**。此类技能的**冷却**（重大槽）与**成本**（2-4 情报）使其不能每轮使用，但**每局 4-6 次**的可用频率仍足以在关键节点瓦解警长攻势。

**综合结论 C4-2（清场防守）**：清场防守各技能因"重大槽冲突 + 机会成本"而**非超模**，但**存在集体滥用风险**（多玩家清场技能叠加时警长抓捕链效率坍缩）。建议在 r05 给出频率限制强化（如暗度陈仓改为"每轮限 1 次但不可与作案同轮"→ 或加 1 任务条件约束）。

### 1.2 罪犯综合进度（最优路线）

结合 r02 推演 + 技能微调，等级 2 罪犯核心区路线综合：

| 项 | 值 |
| - | - |
| 基础（0 能力） | 12 轮 18 分 |
| 技能加成（幽灵·华丽骗术净 +1 情报 → 约多 0.5 次作案 +1.5 分） | +1.5 |
| 技能加成（毒蛇·见机清场 → 时机性，均值不计分） | ±0 |
| **综合预期** | **约 18-20 分 / 12 轮** |

- **进度**：第 9-10 轮即达 15 分 → **显著提前于 12 轮上限**。
- **与基准对照**：罪犯综合效率 ≈ 1.1-1.2 分/资源，仍大约为设计基准的 2.7 倍。
- **判定 C4-3**：罪犯整体进度过快，15 分终点在无强抑制下"轻易可达"，**游戏的胜负手完全落在警长能否有效抑制罪犯**；若抑制失败，罪犯碾压性获胜。见 §四 净平衡。

### 1.3 警长综合进度

| 项 | 值 |
| - | - |
| 抓捕链（0 能力） | 0.6 分/IR × 12 ≈ 7.2 分 |

- **进度**：警长在罪犯配合（持续留证据）下可达 12-14 分，勉强贴 15 分线；若罪犯全员清场防守，则**坍缩至 8-10 分**。
- **判定 C4-4**：警长综合进度依赖罪犯"留证据"，结构上与无证据奖励冲突（B2-4）→ 警长实际得分高度受制于罪犯行为，**自由度不足**。

## 二、资源循环深度检查

### 2.1 资源消耗趋势（版图情报总量）

4 人局 12 张地点初始情报总量：参考上 3 + 核心 6 + 下 3 各张情报值之和。

| 区域 | 组合 | 情报总量 |
| - | - | - |
| 上城 3 张 | 商业街 4 + 金融 4 + 市政 4 / 或 博物馆 5 替换 | 12-13 |
| 核心 6 张 | 基准 3×6 + 港口 4 + 火车站 4 + 红灯 4（-3 ×3 基准） | 21 |
| 下城 3 张 | 贫民 2 + 通道 2 + 码头 2 / 或黑市 3 替换 | 6-7 |
| **总初始情报** | — | **约 39-41** |

- **消耗速度**：4 名玩家每轮共 8 行动 + 4 手牌。按罪犯压 0 的节奏，每名罪犯约每 2 轮抽干 1 个地点（3 次调查）。
- **12 轮累计调查次数**：罪犯 3 人 × 每 2 轮 1 次调查 ≈ 18 次调查；警长常态调查 ≈ 4-6 次/轮（侦查/布控补给）。合计 ≈ 35-45 次调查。
- **调查总消耗 vs 情报总量**：**约 35-45 次调查 ≈ 版图总情报 39-41** → **12 轮结束时版图情报接近枯竭**（全部地点压至 0 附近）。
- **判定 C4-6（资源耗竭可预测性）**：资源按可预测节奏耗竭（每 2 轮 1 地点），**符合原则 #11**。但枯竭时间点（第 10-11 轮）与 15 分终局（第 9-10 轮）接近 → 最后 2 轮"无情报可调查"的真空期较短，影响可控。

### 2.2 成本突变检查

- **作案情报花费**：随地点情报值 3→2→1→0 平滑下降，**无跳跃变化**（原则 #12 ✅）。
- **证据耗竭（5 枚满版）**：第 5 次作案后（约 R9-R10）触发"移动"转型，移动与正常作案**成本曲线相同**（花目标地情报值）→ **平滑过渡**（✅）。
- **警长侦查依赖情报值**：地点压至 0 时，侦查花费 0 → 警长可低成本取证，为罪犯压 0 的**风险面**（对向抑制依然存在）。
- **成本突变结论 C4-7**：无跳跃式成本突变；压 0 的"双向低成本"已由 r02 B2-1 记录，此处确认其仍在平滑区间内。

### 2.3 循环完整性检查（Token 链）

| 资源链 | 产生 | 消耗 | 回收 | 闭环 |
| - | - | - | - | - |
| 情报 Token | 调查/复苏/火车站 | 作案/侦查/布控等 | 返回公共供应堆 | ✅ |
| 证据 Token（罪犯） | 作案放置 | 侦查（警长持有）→ 抓捕（入看守所）→ 出狱（返回角色供应堆） | ✅ 全链闭环 | ✅ |
| 证据 Token（越狱） | — | 越狱推进至 0 → 返回角色供应堆 | 若在越狱前被警长抓捕 → 入看守所 → 出狱 | ✅ |
| 警员 Token | 角色供应堆 | 布控放置 | 黎明收回 | ✅ |
| 迷雾 Token（2-3 人） | 迷雾阶段放置 | 警长侦查获得 → 抓捕清除 → 返回公共供应堆 | ✅ | ✅ |
| 英雄 Token | 角色供应堆 | 铁拳制裁放置 | 黎明收回 | ✅ |

**循环异常 C4-8（出狱-越狱-抓捕三向冲突）**：

- 场景：罪犯证据在看守所，罪犯执行"越狱"推进；此时警长也持有同罪犯的其他证据 → 抓捕需"该罪犯不在看守所"（§6.2 条件）。
- 冲突：**守卫所内证据推进与看守所出狱判定**——若罪犯通过越狱先到 0 格释放，警长手中证据如何结算（Q4 已有表述：移入看守所），但"出狱后立即被抓回"的循环是否合理？（读报保底 + 无行动）→ **需要 FAQ 明确"出狱当轮是否可被立即抓捕"**（建议：可，因抓捕条件仅"不在看守所"，无冷却）。
- 判据：此边界不破坏闭环，但需显式化。

**循环异常 C4-9（精神病例）**：疯子莱利"隐藏狩猎"隐藏值上限 2、自动回复 2、调查额外 -1。其**调查 1 次 = -2 隐藏**，而回合补给 +1、总上限 2 → 疯子连续调查 2 次即从满隐藏跌至 0，**警长零补差抓捕**（隐藏 0 时移动 1 证据即可，补差为 0）。**疯子的"高风险"兑现为"极易被抓"**，与 D3-2 的等级 4 回报不足叠加 → 等级 4 综合劣势显著。

## 三、交叉组合风险

### 3.1 技能 × 环境 × 卡牌交叉检查

| 组合 | 机制 | 风险 |
| - | - | - |
| 医院·康复中心 × 压 0 循环 | 调查恢复 1 隐藏 → 压 0 调查无隐藏代价 | 🔴 放大 r02 罪犯超模；见 D3-3 |
| 老鼠·人群掩护 × 核心区压 0 | 核心调查不降隐藏 → 零代价压 0 | 🟡 强化超模（但仅限老鼠） |
| 疯子·隐藏狩猎 × 压 0（调查 -2 隐藏） | 压 0 需多次调查 → 隐藏掉光 → 极易被抓 | 🟡 等级 4 结构劣势（D3-2） |
| 屠夫·致命打击 × 上城压 0 | 上城 4 分/次 + 消除痕迹清场 | 🟡 高爆发但被重大槽约束 |
| 毒蛇·暗度陈仓 × 自身无版图证据 | 警长对其抓捕条件不满足 | 🟡 集体滥用风险（C4-2） |
| 铁拳·暴力催收 × 他罪犯手牌 | 可弃警长关键手牌（如延时牌） | 🟢 可控 |
| 掮客·黑料曝光 × 对手手牌堆满 | 3 张全弃 → 1.4 分/资源 | 🟡 方差过大（D3-8→已记 r03） |
| 策略牌#09 金库保险 × 关键回合保护 | 目标本回合不可被指定为目标 | 🟢 防御牌，可控 |
| 警长·天罗地网 × 免费布控 | 免费布控 1 次 + 天罗地网 1 次 → 每轮 2 布控 | 🟡 布控叠放强度（每地最多 2 警员限制存在） |
| 夜枭·铁拳制裁 × 罪犯集中一城 | 清空一处证据 + 禁作案 → 罪犯被迫转移 | 🟡 对罪犯打击大，但每局 1 次有限 |

**判定 C4-10**：**最高优先级交叉风险 = 医院 × 压 0**（D3-3 升级为综合风险）——医院让罪犯的"调查-隐藏"双代价坍缩为单代价，直接放大 0 能力超模。r05 必须处理。

### 3.2 无敌/僵局检查

- **罪犯全员清场 → 警长彻底无证据可抓**：警长失去抓捕得分 + 无证据奖励（版图无证据反而触发 +2/轮）→ 警长转走"无证据奖励路线"（每轮 +2），反而形成**结构替代**。判定：清场防守不会造成警长零得分，而是把警长推向无证据奖励路线 → **警长策略被迫收敛**（只能走奖励路线），**策略多样性受损**但非僵局。
- **罪犯被捕 → 读报保底**：读报 2 行动→1 情报，**永远是亏的**（比调查差），但提供最低运转 → 非僵局，符合原则 #5。
- **迷雾 Token 堆积（2-3 人）**：2 人局每轮 2 迷雾 → 警长侦查资源持续被迷雾消耗，版图证据被迷雾分流 → **2 人局节奏风险**（r01 已列），此处量化确认：2 人局 12 轮 = 24 次迷雾操作，警长需至少 12-16 次侦查+抓捕清除迷雾（每次 ~2 情报），**占用警长大量行动** → 2 人局警长效率进一步下降。

### 3.3 策略收敛检查

**收敛路径 1（罪犯）**：压 0 + 上城/核心高影响作案为**普遍最优**；所有罪犯（除下城避险）都会走向"调查压 0 → 作案"循环。差异仅在目标地点选择（受等级/技能影响）。

- **收敛判定 C4-11**：罪犯侧**存在强收敛**——压 0 作案是唯一高效得分路径，玩法多样性被压缩。尤其"下城 0.33 分/资源"与"核心 1.0 分/资源"的 3 倍差，几乎消灭下城作为主动选项。

**收敛路径 2（警长）**：抓捕链 vs 无证据奖励二选一；因抓捕依赖罪犯主动留证据，**理性警长会被动转向无证据奖励路线**（更稳定）→ 警长策略同样收敛。

- **收敛判定 C4-12**：警长侧**收敛于被动防守**——主动抓捕的收益不稳定（依赖罪犯行为），不如每轮白嫖 +2 无证据奖励。这削弱了游戏的**猫鼠互动**（警长不再主动追捕）。

**收敛路径 3（策略牌）**：高价值牌集中（07/09/13/14）→ 玩家普遍抓保留强牌，信息牌打入弃牌堆概率高（D3-5）。

**综合判定 C4-13（双收敛 → 互动退化）**：罪犯收敛于"压 0 作案"、警长收敛于"被动无证据奖励"——**两条最优路径都无需与对方交互**。这是本轮评审最严重的策略性问题：游戏标题的"猫鼠博弈"在实际最优策略下退化为"各自刷分"。

## 四、非对称阵营综合对比（净平衡）

### 4.1 净平衡计算

依据 §3.5 跨方抑制分析：**净平衡 = 罪犯无干预效率 − 警长抑制量**。

| 项 | 数值 | 依据 |
| - | - | - |
| 罪犯无干预综合效率 | ≈ 18-20 分 / 12 轮 | §1.2 |
| 警长抑制量（抓捕打断 1 罪犯 2-3 轮） | -2~-4 分/次 × 3 次 ≈ -6~-12 分 | 每抓捕 1 罪犯损失其 2-3 轮作案（~1.5-2 分/轮） |
| 警长抑制量（布控 +2 情报 → 作案 +2 情报成本） | 每轮 1-2 次布控 → 罪犯成本 +2~4 情报 ≈ 削减 1-2 作案/轮 | — |
| **罪犯净综合（扣除抑制）** | **≈ 8-14 分 / 12 轮** | — |

### 4.2 对照基准

| 对象 | 综合预期分数 | 与基准（14-15）对比 |
| - | - | - |
| 罪犯（无抑制） | 18-20 | 🔴 偏高 |
| 罪犯（扣除警长抑制） | 8-14 | ✅ 落入合理带（中值 ~11 略低） |
| 警长（主动抓捕路线） | 13-17 | ✅ 达标 |
| 警长（被动无证据奖励路线） | 10-14 | ✅ 达标 |

**判定 C4-14**：在**理想抑制**（警长成功抓捕 2-3 次 + 布控）下，罪犯净效率落回基准带 → **设计在"抑制有效"时平衡**。但前提苛刻：

- 警长能否成功抓捕依赖 3 名罪犯中的**至少 1 人留下证据**（若全员清场防守则抑制失败）；
- 抑制的**不确定性**（抓错目标/目标转移）使警长抑制量波动大（-6~-12 的区间宽）。

**核心矛盾 C4-15（平衡依赖抑制成功率）**：本游戏平衡**完全系于警长抓捕的成功率**。若警长发挥失误/罪犯清场成功 → 罪犯单侧 18-20 分碾压；若警长发挥出色 → 双方都贴 15 分线。**中间态（警长部分成功）的博弈结果方差极大**，属于"高方差平衡"——与"轻中策"定位（应偏稳）存在张力。

## 六、综合结论

1. **资源循环体系健康**：情报/证据/Token 全链闭环、成本平滑、耗竭可预测（C4-6/7/8）。
2. **平衡系于"警长抑制成功率"**：抑制有效则双方贴线；抑制失效则罪犯碾压（C4-14/15）。高方差平衡与轻中策定位存在张力。
3. **策略性核心问题**：**双收敛**——罪犯收敛压 0 作案、警长收敛被动防守，猫鼠博弈在最优策略下退化（C4-13）。
4. **交叉风险最高**：医院 × 压 0 放大罪犯超模（C4-10）；清场防守集体滥用压制警长（C4-2）。
5. **扩展阵营就业率**：裁决者、记者严重不足；夜枭/暗影/掮客达标（C4-5）。
6. **等级梯度**：等级 4 综合劣势（回报不足 + 极易被抓）；等级 1 舒适（唯一白嫖调查）。
