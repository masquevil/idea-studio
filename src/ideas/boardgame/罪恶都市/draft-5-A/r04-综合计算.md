## 二、资源循环深度检查

### 2.1 资源消耗趋势（版图情报）

- 初始版图总情报：上城 3×4 + 核心 6×3（含火车站/港口 4）+ 下城 3×2 ≈ 36（视抽取浮动）。
- 每轮消耗：3 罪犯 + 1 警长各调查 0-2 次。稳态下罪犯每 2 轮压 1 次调查（r02 推演），警长取证调查 1-2 次/轮。
- **复苏回填**：情报 0 地点傍晚 +1；火车站黎明额外 +1。
- **估**：12 轮内版图情报在中后期趋紧但**不会枯竭**——因复苏机制对 0 情报地点保底回填，压 0 打法可持续（r02 已推演"压 0 → 傍晚回 1 → 每 2 轮压 1 次"闭合循环）。
- **极端情况**：若 4 名玩家同时主攻同一区域（如都压核心），该区 6 地点可能多轮被压 0，复苏回 1 后被再次压走 → 该区情报长期低位 → 作案成本长期 0-1（对罪犯有利）。
- **结论**：版图情报**不会自然枯竭**（复苏兜底），但**压 0 会形成局部情报低位区**，罪犯在该区获得系统性低成本优势（B2-1 的确认）。

### 2.2 成本突变检查

| 检查项 | 结果 |
| - | - |
| 作案成本（地点情报值） | 0-1（压0区）↔ 2-5（未压区）。在同一地点内部平滑（0→1→0→1）；跨地点切换会出现跳变（如从压0核心 1 → 上城 4），但这是玩家主动选择，非机制突变 ✅ |
| 逮捕后的出狱成本 | 出狱隐藏值重置为上限；越狱成本按格数线性（2 情报/格 + 1 手牌/格 + 1 分/格），无跳跃 ✅ |
| 证据 5 枚满后 | 从"放置"转为"移动"，成本结构相同（花当前情报值），无突变 ✅ |
| 供应堆情报枯竭 | 无上限、回流快（花费返回公共供应堆），无双端枯竭风险 ✅ |
| **压 0 + 布控叠加** | 压 0 后作案 0 情报；布控 +2 → 突然变 2 IC。**单地点作案成本从 0 跳变到 2**——布控是"本轮"效果，罪犯可延后或转移，非系统性突变，但**布控对压 0 打法的反制有效** ⚠️ |

### 2.3 循环完整性检查（Token/资源全链路）

| 循环 | 产生 → 消耗 → 回收 | 完整性 |
| - | - | - |
| 情报 Token | 地点/供应堆 → 全行动花费 → 花费后返回公共供应堆 | ✅ 闭环 |
| 证据 Token（罪犯/警长） | 角色供应堆 → 作案（版图）→ 侦查（警长持有）→ 抓捕（看守所）→ 出狱 → 角色供应堆 | ✅ 闭环 |
| 证据 Token（英雄制裁） | 作案（版图）→ 制裁（英雄持有）→ **？** | 🔴 **缺口**（r01 §1.1）：无归还规则 → 英雄持证永久脱离循环 |
| 警员 Token | 角色供应堆 → 布控（版图）→ 黎明收回 | ✅ 闭环 |
| 英雄 Token | 角色供应堆 → 登场（版图）→ 黎明收回 | ✅ 闭环 |
| 迷雾 Token（2-3人局） | 版图 → 警长侦查 → 抓捕清除 → 返回公共供应堆 | ✅ 闭环 |
| 混乱 Token（受害者） | 角色供应堆 → 追偿/爆料（版面/地点）→ 黎明收回 | ✅ 闭环 |
| 策略牌 | 牌堆 → 手牌 → 打出 → 弃牌堆 → 重洗 | ✅ 闭环 |

- **关键缺口确认**：英雄制裁证据循环（🔴）——若不修复，5-7 人局长局中：
  1. 罪犯证据被英雄永久扣留 → 罪犯角色供应堆证据减少 → 多次作案后无证据可放（需移动 5 枚内的），作案能力受迫下降；
  2. 英雄手上的证据**不计入版图** → 会让警长"无证据奖励"条件更容易满足（英雄扣着证据＝版图净空），但英雄无法主动清除自己的持有 → 若英雄不配合，警长无法判断何时触发（状态怪异性）。
- **修复建议**（呼应 r01 F1）：黎明阶段英雄将持有的全部证据 Token 归还对应罪犯的**角色供应堆**，或置于版图原位。推荐归还角色供应堆——英雄制裁效果＝"破坏一次作案 + 赚分"，罪犯可重新积累，循环关闭。

### 2.4 供应堆情报通胀（新增检查）

- 供应堆情报来源：策略牌（情报报告 3×2、截获 2×1、共享 1）、地下酒吧（+1/回合）、黑市（+1/回合）、市政厅（侦查 +1）——**均从供应堆新增，不经版图**。
- 12 轮 × 4 玩家摸牌 → 情报类策略牌被摸到概率不低；地下酒吧/黑市若在版图则每轮提供 +1-2 情报。
- **通胀影响**：
  - 利好"情报消耗型"行动：警长侦查/抓捕（补差）、英雄制裁/越权执法、受害者追偿——成本变相降低；
  - 对罪犯不利：罪犯作案成本取决于**版图**情报值，不因供应堆富集而降低 → 罪犯要么压 0（成本 0-1），要么在高情报地点花大成本；
  - **结论**：情报通胀放大"抓人侧（警长/英雄）"对"罪犯"的压制力，同时强化罪犯"压 0 作案"的动机 → 双向都指向同一策略（压 0）→ 策略收敛加剧（见 §四）。

## 三、交叉组合风险（重点检查）

### 3.1 屠夫·致命打击 × 上城（等级 3）

- **组合**：上城压 0 后作案，影响 3 + 超额 1 + 致命打击 1 = **5 分/次**。
- **成本**：2 行动 + 1 情报（压 0 后）= 3 IC；准备期 4 次调查（上城初始 4）。
- **效率**：5/3 ≈ 1.67 分/资源；单次 5 分超过设计基准（0.39-0.42）约 4 倍。
- **风险对冲**：隐藏 0（调查链必然归 0）→ 警长"1 证据高效抓"（3 分 + 高效 1 = 4 分）→ **屠夫每次作案净领先 5−4 = 1 分**，即使被抓也有 1 分净利 → **超模确证**（被抓成本无法抵消）。
- **结论**：🔴 必须下修（r05 建议：致命打击改为相邻证据条件触发，或上城影响值/超额结构调整，或提高被抓损失）。

### 3.2 疯子·连环作案 × 博物馆（等级 4）

- **组合**：博物馆影响 4 + 超额 1 + 连环相邻证据 2 = **7 分/次**（极端）。
- **成本**：压 5 情报（5 次调查 × −2 隐藏 = 隐藏归 0）+ 布证（制造恐慌 2 情报/张或正常作案布证）。
- **效率**：7/3 ≈ 2.33 分/资源（稳态），但准备期需 4-6 轮，期间隐藏 0 完全暴露。
- **风险对冲**：警长抓 4 + 高效 1 = 5 分 → **疯子每次作案净领先 7−5 = 2 分**；即使被捕损失 1 轮（≈1 轮作案机会 7 分，但从最终净分看，7分/次 × 3-4 次成功作案已远超被抓损失）。
- **结论**：🔴 严重超模。疯子的"高风险"（隐藏 0）因警长抓捕收益（5 分）低于疯子作案收益（7 分）而**失去威慑力**——"高风险高回报"的平衡被打破，回报溢出。

### 3.3 鬼手·后巷密道 × 布控/侦查规避

- **组合**：⚡️ 1 情报无限移动证据 → 警长布控（+2）被完全规避（移到无布控地点）、侦查目标转移、制造恐慌布点更灵活。
- **效率影响**：把警长最核心的压制工具（布控）对鬼手失效 → 鬼手作案成本长期 0-1 → 效率 1.2-1.5 分/资源。
- **结论**：🔴 交叉破坏警长工具，需加限制（每回合限 1 次，r05）。

### 3.4 裁决者·越权执法 + 从重判决（英雄）

- **组合**：
  - 越权执法：⚡️ 花目标隐藏值（隐藏 0 时 0 情报）→ 1 证据入狱 1 区域 + 1 分，每回合 1 次 → **12 轮白拿 12 分 + 场控**；
  - 从重判决：登场选看守所，花 1+X 情报得 X 分 → 看守所堆积 4-5 证据时一次 4-5 分；
  - **合计**：12（越权）+ 5（从重）+ 登场 1 分/次 ≈ **18-20 分**，远超基准。
- **前提依赖**：证据入狱供应来自警长抓捕（若警长不抓则无）→ 但越权执法自身也在制造入狱（移证据入 1 区域）→ **自给自足**，警长不抓也能刷。
- **结论**：🔴 超模确证（扩展局）。越权执法的"0 成本白拿 1 分"是主因。

### 3.5 艾登·有备而来 + 连本带利（受害者）

- **组合**：追偿门槛 ≥1（有备而来）+ 每达标 +1（连本带利）。
- **触发**：4 人局罪犯作案 3 分/次、警长抓捕 2-4 分 → "本轮得分 ≥1"几乎必然满足 → 2 目标均达标常见。
- **收益**：夺 2 分 + 连本带利 2 = **4 分/次**，成本 3 IC（1 行动 + 2 情报）→ 1.33 分/资源。
- **节奏**：12 轮若追偿 5-6 次 → 20-24 分 → 严重超模。
- **结论**：🔴 超模确证（扩展局）。"有条件"的设计意图被"门槛 ≥1"几乎破除（条件形同虚设）。

### 3.6 猎犬·天罗地网 + 免费布控（警长）

- **组合**：免费布控（有证据 0 行动，1 次/回合）+ 天罗地网（⚡️ 1 情报布控，1 次/回合）→ **每回合最多 2 次布控**。
- **效果**：双布控覆盖 2 地点 → 罪犯主要活动区被加 2 成本；若配合智囊布局预判（相邻 +1 情报）→ 区域封锁。
- **效率**：布控让 1 罪犯单次作案 +2 IC ≈ 2 分当量（按罪犯 1 分/资源折算）→ 双布控 12 轮若 50% 命中作案 → **抑制 12-24 分当量**。
- **结论**：🟡 警长侧交叉强化有效但不过分（布控仅本轮、罪犯可转移/延迟）→ 属合理压制工具，但需注意与智囊组合的"区域封锁"是否过强（列入阶段④测试观察）。

### 3.7 压 0 × 布控（跨方关键博弈）

- 罪犯压 0（情报 0）→ 布控 +2 → 作案成本 0 → 2（跳变）。
- **博弈**：布控把压 0 地区的"低成本优势"抵消 → 警长的正确反制是"压罪犯主攻区布控"；罪犯的反制是"多区并行压 0"（3 罪犯各压一区 → 警长 1-2 布控不够）。
- **结论**：🟢 这是健康的猫鼠博弈核心，但**布控数量（1-2/回合）不足以覆盖 3 罪犯多区压 0** → 实际抑制效率低于名义（r05 观察项）。

## 四、策略收敛检查

### 4.1 罪犯侧收敛

- r02/r03 已指出：核心区 1.0、上城 1.33-2.0 → **所有罪犯理性涌向上城/核心**；压 0 打法成为唯一主流（0-1 情报成本）。
- **收敛结果**：3 罪犯挤同一高价值区 → 互相竞争情报（先调查者得资源、压 0 者让全区受益 → 搭便车问题）→ 警长布控/抓捕集中在单区 → **罪犯互相"抢压 0 公共品"，警长坐收渔利**——这反而给警长抑制提供便利（单区集中 = 低成本压制）。
- **非收敛缓解**：火车站双回填（无法压 0）、红灯区冷区（无人去）、黑市反哺（特定策略）→ 提供局部多样性，但整体收敛压力仍强。
- **判定**：策略收敛问题**持续存在**（上城/核心军备竞赛），但部分被"公共品竞争 + 警长集中压制"自然缓解；下城依然缺乏等级 2+ 价值（0.33 分/资源 vs 核心 1.0）。

### 4.2 警长侧收敛

- 警长最优收敛到"布控 + 1 证据高效抓捕"单一套路（r03 §5.2）。
- 无证据奖励（+2/轮）因互斥被放弃 → **警长几乎只有一条得分路线**。
- 判定：警长侧策略多样性不足——建议 r05 考虑让无证据奖励与抓捕链部分兼容（如"本轮无新证据放置"而非"版图净空"），或增加警长第二条得分路线。

### 4.3 扩展阵营收敛

- 裁决者收敛到"越权执法刷分"、艾登收敛到"追偿 4 分"、掮客"信息垄断白嫖"——扩展阵营各自收敛到单一最优技能组合。
- 且扩展阵营收益高度绑定警长/罪犯行为（互动依赖），警长不作为时骤降。

### 4.4 收敛结论

策略收敛在 4 人局核心对抗（警长 vs 罪犯）与扩展局（英雄/受害者）均存在，但性质不同：

- 罪犯收敛 → 由"公共品竞争 + 警长集中压制"部分自平衡；
- 警长收敛 → 因互斥结构**缺乏自平衡**（单一路线）；
- 扩展阵营收敛 → 由超模技能驱动（裁决者/艾登），下修技能即可缓解。

## 五、非对称阵营综合对比（净平衡）

### 5.1 净平衡模型（4 人局，12 轮）

**模型假设**：

- 3 罪犯各自运作（无强互斗），警长全力压制。
- 警长 12 轮行动预算：约 4-5 次抓捕 + 5-6 次布控 + 相应调查/侦查前置。
- 抓捕抑制：每次让目标罪犯损失 ≈ 1 轮得分（1.5 分/IR 当量）+ 证据重积累成本（约 0.5 分当量）= **2 分**。
- 布控抑制：每次有效命中让目标罪犯单次作案 +2 IC ≈ **1 分当量**（罪犯可转移/延迟，取 50% 有效）。

**分项计算**：

| 对象 | 计算 | 12 轮预期 |
| - | - | - |
| 罪犯甲（被重点压） | 18（无干预）− 2 次抓×2 − 3 次布控×1 | 18 − 4 − 3 = **11 分** |
| 罪犯乙、丙（均摊压） | 18 − 1.5 次抓×2 − 2 次布控×1 | 18 − 3 − 2 = **13 分/人** |
| 警长 | 抓捕链 0.6 分/IR × 12 + 高效 +1×4 + 偶发无证据 1 次×2 | 7.2 + 4 + 2 ≈ **13.2 分** |

**审计行（折算依据）**：

- 抓捕抑制折算：罪犯 1.5 分/IR（r02）→ 被捕损失 1 轮 = 1.5 分 + 重积累 0.5 分 = 2 分/次；
- 布控抑制折算：+2 IC（作案成本）→ 按罪犯 1.0 分/资源（r02）＝2 分/次，实际 50% 有效 → 1 分/次；
- 警长高效 +1：5 次抓捕中 4 次移动数 < 犯罪等级 → +4 分。

### 5.2 净平衡判定

| 对比 | 数值 | 判定 |
| - | - | - |
| 罪犯被抑制后 vs 设计基准 | 11-13 分 vs 14-15 分 | 🟡 略偏低（被过度抑制） |
| 警长 vs 设计基准 | 13.2 分 vs 14-15 分 | 🟡 略偏低 |
| 罪犯被抑制后 vs 警长 | 11-13 vs 13.2 | 🟡 警长略优（可控） |
| **罪犯无干预 vs 基准** | **18 分 vs 14-15 分** | 🔴 **偏高 20-28%** |
| **罪犯无干预 vs 警长** | **18 vs 13.2** | 🔴 **4.8 分差距** |

**核心结论**：

1. **罪犯 0 能力无干预效率（18 分）系统性偏高**（超基准 20-28%）。警长需"全程完美压制"（约 4-5 次抓捕 + 5-6 次布控且 50% 有效、自身 13 分）才能把罪犯拉回 11-13 分——**容错率极低**：任何警长失误（选错目标、手牌差、罪犯多区压 0 分散布控）都会让罪犯逼近/触发 15 分。
2. **警长 13 分与罪犯被压后的 11-13 分接近**——若警长成功执行压制，双方在 12 轮都能达到接近线，游戏具备"最后一轮白热化"的竞技性；但**这个平衡建立在警长近乎完美发挥上**，不是稳定平衡。
3. **无证据奖励（+2/轮）与抓捕互斥**是警长结构缺陷——警长抓人时拿不到该奖励，不抓人时靠罪犯自觉（无人作案才触发）→ 该奖励实际是"空头支票"。
4. **罪犯技能进一步放大差距**：屠夫/疯子/鬼手综合效率 1.2-2.3 分/资源 → 即使被抓 2 次仍可 14-20 分 → **技能层把超模推向失控**。

### 5.3 扩展局净平衡（5-7 人）

| 阵营 | 预期 | vs 基准 | 判定 |
| - | - | - | - |
| 罪犯（3-4人，无警长集中压制） | 18-25（技能强化） | 🔴 严重超模 | 🔴 |
| 警长（分心压 4-5 人） | ~8-10 | 🟡 偏低 | 🟡 |
| 受害者（艾登） | 14-18 | 🔴 超模 | 🔴 |
| 英雄（裁决者） | 15-18 | 🔴 超模 | 🔴 |
| 英雄（夜枭/暗影） | 5-10 | 🟡 偏低 | 🟡 |

- **扩展局失衡加剧**：4 人局的核心超模（罪犯）在扩展局因警长注意力分散而更严重；同时受害者/英雄的超模技能（艾登、裁决者）成熟，扩展局呈现"人人超模、比谁更超模"的局面。**英雄阵营内部（裁决者 vs 夜枭/暗影）失衡最刺眼**。

## 七、综合结论

1. **罪犯侧超模是 4 人局首要问题**：0 能力 18 分 vs 基准 14-15（偏高 20-28%）；技能层（屠夫 5 分/次、疯子 7 分/次、鬼手无限移证）放大到 20-25 分。
2. **警长结构缺陷**：无证据奖励与抓捕互斥 → 单一路线 + 被动依赖罪犯行为；13.2 分需完美发挥。
3. **循环断链**：英雄制裁证据循环无出口（🔴，必须修复）。
4. **扩展局全面失衡**：艾登追偿流、裁决者越权执法/从重判决超模；夜枭/暗影补偿不足；英雄内部失衡。
5. **策略收敛**：压 0 成为绝对主流（罪犯）；警长单一"布控+1证据抓"；扩展阵营靠超模技能，非健康设计。
6. **r05 修改方向**（给 ③-C 使用）：
   - 罪犯超模 → 下修影响值/超额收益，或削弱压 0 收益（如复苏加量 3-4/轮——见 05-待评估想法.md 待评估项），或提高被抓损失；
   - 警长结构 → 无证据奖励与抓捕链松耦合（或新增警长第二得分路线）；
   - 超模技能 → 屠夫致命打击、疯子连环作案上限、鬼手后巷密道加次数限制、裁决者越权执法加成本、艾登连本带利下调；
   - 循环 → 修复英雄制裁证据归还规则；
   - 收敛 → 为下城/红灯区注入价值，缓解区域冷区。
