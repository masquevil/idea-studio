## 1. 各阵营综合得分/进度预期

### 1.1 综合效率修正矩阵（r03 超模技能并入后）

| 阵营 | 基准效率（r02） | 超模技能增益 | 修正后效率 | 12 轮预期得分 |
| - | - | - | - | - |
| 罪犯·一般角色 | 0.33~0.5 | 无 | 0.33~0.5 | 12~18 分 |
| 罪犯·幽灵（华丽骗术） | 0.33~0.5 | 每回合净 +1 情报 ≈ 资源 +33% | 0.44~0.67 | 16~24 分 |
| 罪犯·鬼手（精妙手法） | 0.33~0.5 | 调查翻倍 ≈ 压点成本减半 | 0.5~0.67 | 18~24 分 |
| 罪犯·双面人（金融犯罪） | 0.33~0.5 | 每局限 1 次 +2 分（无风险） | 0.44~0.5 | 16~18 分（+2 保底） |
| 警长·铁腕（雷霆行动） | 0.5 | 资源 +33% | 0.67 | 24 分 |
| 警长·猎犬（天罗地网） | 0.5 | 布控免行动 | 0.5~0.67 | 18~24 分 |
| 警长·智囊 | 0.5 | 无正增益 | 0.5 | 18 分 |

> **综合结论**：含超模技能后，幽灵/鬼手/铁腕预期得分 16-24 分，远超目标 14-15 分与终局线 15 分。**超模技能不仅破坏阵营平衡，还压缩游戏时长**——若 8-9 轮就有人到 15 分，后半程内容（复苏、后期策略）被跳过。

### 1.2 跨方抑制后的净平衡（§3.5 方法论）

**罪犯无干预效率**（打空作案稳态）：0.5 分/资源、1.5 分/轮

**警长对罪犯的抑制量**（4 人局，3 罪犯）：

| 手段 | 机制 | 对罪犯的量化影响 | 频率（12 轮） | 抑制总量 |
| - | - | - | - | - |
| 抓捕 | 中断作案：罪犯 ≥1 轮无得分（仅读报 1 情报） | 损失 1.5 分/轮 × 被关轮数 | 3~4 次 | 1.5 × 3~4 轮 = 4.5~6 分 |
| 布控 | 目标点作案花费 +2 | 动态成本 +2 | 每回合可用（警员 5 枚） | 视罪犯选点而定，约 1~2 情报/次 |
| 侦查 | 取走证据 | 限制连续作案（证据 5 枚封顶） | 1~2 次/轮 | 迫使转移/中断 |

**净平衡估算**：

- 罪犯 12 轮无干预得分（打空稳态）≈ 0.5 × 36 = 18 分
- 警长抑制量 ≈ 抓捕 4.5~6 分 + 布控/侦查拖延 ≈ 5~8 分
- **罪犯净得分 ≈ 18 − (5~8) ≈ 10~13 分**——**低于基准 14-15 分**！

> **关键发现 4**：含抑制后，罪犯净效率反而**过低**（10~13 vs 目标 14-15）。原因：警长单侧超模（铁腕/猎犬）+ 抓捕的中断效应（1 次抓捕 = 罪犯损失 1.5 分/轮 × 关押 2-4 轮）。**超模警长把罪犯压到目标线以下**——双方超模不是"抵消"，而是"双输"（游戏时长被压缩 + 罪犯体验差）。

**警长自身双效率**（铁腕）：0.67 分/资源 × 36 ≈ 24 分（名义），但受 3 点约束：

1. 侦查目标分散（3 罪犯证据分散在不同点）
2. 情报供给上限（侦查花费随版图情报值波动）
3. 罪犯被捕后的"无证据奖励"窗口竞争

实际可达 15-18 分——**警长明显压过罪犯**。

### 1.3 阵营综合强度对比（净平衡后）

| 阵营 | 无干预效率 | 受抑制后 | 相对平衡（±基准） |
| - | - | - | - |
| 罪犯（一般） | 0.33~0.5 | 10~13 分 | 略低于目标（被压制） |
| 罪犯（幽灵/鬼手） | 0.44~0.67 | 14~17 分 | 接近目标（超模被抑制抵消） |
| 警长（铁腕/猎犬） | 0.5~0.67 | 15~18 分 | **超目标，压制罪犯** |
| 警长（智囊） | 0.5 | 13~15 分 | 目标线上 |

> **结论**：当前版本**警长侧整体超模**（铁腕/猎犬的确定性高），而**罪犯侧依赖抽中幽灵/鬼手才能持平**。抽 2 选 1 下：警长 2/3 概率抽到超模角；罪犯 3 人每人 4/8 概率取到 2 个超模角之一——**阵营强度方差过大**。

## 2. 资源循环深度检查

### 2.1 资源消耗趋势（情报 Token 全链路）

**产生**：调查（地点→玩家）、复苏（供应堆→地点）、火车站黎明（供应堆→地点）、策略牌（供应堆→玩家）、读报（供应堆→玩家）

**消耗**：作案（玩家→?）、侦查（玩家→?）、布控（警员 Token 无情报消耗，但布控本身 1 行动）、技能/策略牌花费

**去向裁定**（r02 采用：返回供应堆闭环）：

- 若花费的小 Token 返回供应堆 → 全链路闭环 ✓
- 若移除 → 12 轮总量：初始版图情报（上 3×4 + 核 6×3~4 + 下 3×2~3）≈ 39~45 + 复苏（3 区域×12 轮=36）≈ **75~81 总供给；供给 vs 消耗**：若 1 罪犯每 2 轮作案花费 2-3 情报 → 12 轮 × 3 罪犯 ≈ 36-54 消耗，加上侦查 ≈ 24-36，总消耗 60-90 ≥ 供给 75-81——**边界紧绷，可能枯竭**

**结论**：

- ✅ **推荐口径**：花费的"情报 Token"返回公共供应堆（闭环），避免后期枯竭
- 🟡 但需**在规则书明确**（r01 4.1），否则规则缺口

### 2.2 成本突变检查（原则 12）

| 场景 | 成本变化 | 是否突变 |
| - | - | - |
| 地点打空（I→0） | 作案花费 I→0 | 平滑（1 点 1 点降）✓ |
| 复苏回填 | 作案花费 +1/轮 | 平滑 ✓ |
| 布控/设伏 | +2 作案花费 | **跳跃**（0→2 或 1→3）⚠️ 但此为本轮性压制设计，符合意图 |
| 证据 5 枚封顶 | 被迫转移 | 平滑（转移 1 行动+原效不变）✓ |

**核心结论**：

- 常态路径成本平滑 ✓
- **布控/设伏的 +2 跳跃**是警长主动压制手段，属设计意图，但叠加铁腕/猎犬/设伏三联时，罪犯单次作案成本可 +2×2（布控+设伏）+ 补差——**成本跳跃上限达 4-6 情报**，超出罪犯单回合供给（3 资源），需评估

### 2.3 循环完整性检查（原则 13）

| 循环 | 链路 | 状态 |
| - | - | - |
| 情报 Token | 调查/复苏/火车站/牌 → 花费 → （返回供应堆待定） | ⚠️ 需规则书明确返回 |
| 证据 Token | 角色供应堆 → 作案（版图）→ 侦查（警长）→ 抓捕（看守所）→ 黎明右移 → 出狱（角色供应堆） | ✅ 闭环完整 |
| 警员 Token | 警长供应堆 → 布控（版图）→ 黎明收回 | ✅ 闭环完整 |
| 迷雾 Token | 迷雾行动放版图 → 侦查移除 | ✅ 闭环完整（2-3 人局） |
| 手牌 | 牌堆 → 摸牌 → 出牌/弃置 → 弃牌堆 → 洗回 | ✅ 闭环完整 |

### 2.4 IP 枯竭检查（深层维度）

| 指标 | 状态 |
| - | - |
| 版图情报总值 | 39~45（12 张）→ 随调查速降，复苏 +3/轮 → 净下降 1~2/轮（3 罪犯 + 警长均调查）→ **8-10 轮版图接近干涸** |
| IP 枯竭时间点 | 约第 8~10 轮 |
| 枯竭后状态 | 作案/侦查成本趋 0 → **双方效率同步跃升**（r02 关键发现 3）→ 后期加速 |
| 异常点 | 火车站（黎明 +1 永不枯竭）→ 枯竭后唯一"有情报可取"的点，**成为后期焦点**（侦查源/作案陷阱双属性） |

> **关键发现 5**：版图 IP 在第 8-10 轮耗尽后，火车站成为唯一情报高地。此时：罪犯想作案低影响点（0 成本）就放弃超额；想拿超额就得打火车站（高成本）——**后期策略退化为"火车站攻防战"**，多样性下降。

## 5. 非对称阵营综合对比（净结论）

### 5.1 4 人局平衡全景

| 阵营 | 强度上限 | 强度下限 | 方差 | 结论 |
| - | - | - | - | - |
| 警长 | 24（铁腕） | 18（智囊） | 6 分 | 整体偏高，铁腕/猎犬超模 |
| 罪犯（3 人） | 24（鬼手+幽灵同局） | 12（全抽普通角） | 12 分 | **方差巨大**，且普通角被压制 |

### 5.2 净平衡判定

- **警长 vs 罪犯**：警长强于罪犯（铁腕/猎犬超模 + 抓捕中断效应）
- **罪犯内**：幽灵/鬼手 >> 其他罪犯（资源效率 2 倍）
- **罪犯 vs 目标**：抽到超模角的罪犯 ≈ 目标线；抽不到的 ≈ 低于目标 30%

> **整体结论**：当前版本平衡偏斜——**警长过强、罪犯方差过大、超模技能破坏策略多样性**。与第三轮评审发现的"罪犯超模"问题已发生根本转化（上一轮修改压了罪犯，本轮看来压过头且警长侧未同步收敛）。

## 6. 深层漏洞检查（综合）

### 6.1 后期加速与终局锁定（原则 12 关联）

- r02 已验证：打空作案稳态 1.5 分/轮 vs 首轮 1.0 分/轮 → **后期加速 50%**
- 叠加版图 IP 枯竭（§2.4）→ 第 9 轮起作案/侦查成本趋 0 → 双方每轮得分跳跃
- **风险**：领先者在第 9-11 轮锁定胜局（15 分滚动到达），第 12 轮终局条款形同虚设，胜负提前决定
- **判断**：1.5 分/轮 × 5 轮（R8-12）= 7.5 分，若前期积累 7.5+ 即达 15。**后期加速 + 前期劣势累积**可能导致"完成 8 轮即胜负判定"的局面。🟡 建议测试观察，若频繁出现则需下调稳态效率（如复苏 +1/轮 或作案费用保底 1）

### 6.2 看守所/越狱深度检查（原则 10）

| 场景 | 机制 | 检查 |
| - | - | - |
| 被捕（证据入看守所） | 仅读报行动 | 罪犯损失 1.5 分/轮 ✓ 符合抓捕价值 |
| 越狱（推进 1 格：2 情报+1 手牌+1 分） | 主动消耗 | 从格 3 越狱 = 6 情报+3 手牌+3 分 |
| 越狱 vs 等出狱 | 出狱 = 黎明右移 1 格/轮，等 3 轮 | 3 轮损失 4.5 分 vs 越狱花 6 情报+3 手牌换 3 分+提前 2 轮行动 |
| 判定 | 越狱价值 | **越狱效率约等于等出狱**（花资源换时间），但若回场 3 轮可作案 2 次（6 分）→ 越狱赚。**越狱是强策略** 🟡；配合双面人金蝉脱壳（防侦查）过于强大——铁链：越狱保底 3 分 + 金蝉脱壳防侦查 |

### 6.3 双面人「金融犯罪」的破局能力（🔴）

- 2 情报收益：1 行动 + 3 情报 → 2 分（每局限 1 次）
- 问题：**无抓捕风险、无证据暴露、无视版图状态**（任何地点都能用）
- 与"证据"生态完全隔离：3A 白领罪犯可以 12 轮完全不参与猫鼠博弈，纯靠金融犯罪 + 下城种证据赚分
- **判断**：这是"绕开核心循环"的得分类技能，破坏核心循环参与度（原则 1/15）。🔴 必须修：改为依赖版图状态（如"在影响值 ≥ 自己的地点"或"需要先进行调查积累"）

### 6.4 证据 Token 封顶与连续作案（原则 6 关联）

- 5 枚封顶 → 最多同时 5 个地点有证据 → 连续作案至第 6 次强制转移
- 3 罪犯 × 5 = 15 证据可同时存在 → 警长手中最多 5（无上限声明）
- **问题**：警长一次性侦查/抓捕可移走 1 罪犯的全部在场证据（抓捕 X 枚）→ 抓捕后该罪犯版图清零 → 无证据奖励窗口出现
- **动态**：警长"攒证"（侦查多次不移走）→ 攒到 X ≥ 隐藏值 → 高效抓捕 + 版图清空双重收益 —— 这是警长的**最优节奏**，但依赖罪犯持续在同一地点作案（侦查需同点）。罪犯可通过分散作案反制 ✓ 博弈存在

### 6.5 迷雾阶段（2-3 人局）检查

- 迷雾：3-罪犯人数 次操作，每次移除最高情报点情报并放迷雾
- 迷雾侦查规则：先花当前情报值移除迷雾（不获证据）→ 该点回复常
- **问题**：移除迷雾花费 = 当前情报值，而迷雾放在"情报值最高"的地点 → 移除成本高（4-5 情报）→ **2 人局 2 迷雾 × 高成本 = 警长每轮需 8-10 情报清雾**，超出供给（3/轮）
- **判断**：🔴 2 人局警长清雾成本严重超预算，迷雾机制在 2 人局可能让警长完全无法侦查。需降迷雾成本（"移除迷雾 = 固定 1-2 情报"或"移除后获等值情报"）。3 人局 1 次迷雾可接受

> 注：2-3 人局非标准配置，但迷雾成本突变属设计缺陷，r05 应纳入修改。

## 7. 综合结论与优先级

### 7.1 全局平衡全景（第四轮核心结论）

| 维度 | 状态 | 严重度 |
| - | - | - |
| 阵营平衡（警长 vs 罪犯） | 警长过强，罪犯被压 | 🔴 |
| 罪犯内部方差 | 幽灵/鬼手/双面人 3 超模导致 12 分方差 | 🔴 |
| 策略多样性 | 5 个超模技能 = 5 条收敛最优 | 🔴 |
| 资源循环 | 情报去向未定义（缺口） | 🟡 |
| 交叉组合 | 黑市负成本 1 项硬伤 | 🔴 |
| 后期节奏 | 后期加速 + 提前锁定 | 🟡 |
| 扩展阵营 | 掮客信息垄断白板 | 🟡 |
| 迷雾（2-3 人） | 清雾成本超预算 | 🔴 |

### 7.2 相对第三轮的转化

- **第三轮**发现：罪犯侧超模（压区作案效率过高、掮客得分过高等）
- **本轮**发现：上一轮修改（影响值 1-4、策略牌重做）使罪犯基准回落，但**警长侧 3 个超模技能（铁腕/猎犬 + 智囊布局）未被同步收敛**，且罪犯 3 个超模角色（幽灵/鬼手/双面人）遗留
- **净结果**：当前平衡不是"双方都略高"，而是**警长压过罪犯、罪犯内部两极分化**
