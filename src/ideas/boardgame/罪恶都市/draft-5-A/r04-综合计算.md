## 1. 各阵营综合得分预期

### 1.1 计算方法

结合 r02 的 0 特殊能力基准 + r03 的角色能力修正，计算 4 人局（1 警长 + 3 罪犯）在 12 轮中的预期得分。

### 1.2 警长综合得分预期

| 角色 | 基础得分(12轮) | 能力加成 | 预期总分 | 评语 |
| - | - | - | - | - |
| 铁腕·鲍默尔 | ~24 分(基准) | +12 行动(约 4~6 分) | **28~30 分** | 超模。基准已超 15 分，能力加成更多 |
| 猎犬·莫里斯 | ~24 分(基准) | 侦查回血 + 快速布控 | **26~28 分** | 效率提升但不如铁腕直接 |
| 智囊·温斯洛 | ~24 分(基准) | 情报 + 查看手牌 | **24~26 分** | 信息优势不直接改分 |

**关键发现**：铁腕的雷霆行动使得警长在 12 轮中额外获得 12 次行动。基准下警长典型节奏是"每 2 轮抓捕 1 次"，每轮平均 2 分。多了 12 行动后，原本不够行动做的"额外侦查 + 布控"可以更多执行，导致警长的整体节奏加快约 20~30%。

**问题**：铁腕的过强不是"够不够用"的问题，而是"与其他角色差距太大"的问题。12 轮满打满算铁腕约 30 分，已经是胜利条件的 2 倍。这意味着玩铁腕的警长在 4 人局中大概率赢，除非罪犯运气极好。

## 2. 资源循环深度检查

### 2.1 情报 Token 消耗趋势

#### 情报总供给量

标准 4 人局版图初始情报 Token 总数：

- 上城 3 张 × 4.25（平均）= 12.75
- 核心 6 张 × 3.38（平均）= 20.28
- 下城 3 张 × 2.25（平均）= 6.75
- **初始总计**：约 39~42 个情报 Token

另外，以下机制产生新情报 Token：

- 火车站·流动人口：每轮 1 个（最多补充到 4）
- 策略牌 #01 情报报告(3 张)：每张 2 情报 = 6 情报
- 策略牌 #02 情报截获(2 张)：每张 1 情报 = 2 情报
- 策略牌 #04 情报干扰(2 张)：每张放置 2 情报在地点 = 4 情报

**潜在的 Token 数量**：初始 39~42 + 游戏过程中产生的 ~12~20 = 总计 50~60 情报 Token。

#### 情报消耗量

- 侦查：每次 3.32（平均）× 12 轮 × 约 1~2 次 = 40~80 情报
- 作案：每次 3.38（平均）× 6 次 = 20~25 情报
- 布控：0（不消耗，仅消耗行动）
- 抓捕补差：每次约 2~4 情报 × 6~8 次 = 12~32 情报
- 卡牌消耗：线人报酬 2 情报，金库保险等

**问题**：如果公共供应堆初始只有约 40 个情报 Token，而侦查一项就可能消耗 40~80，那么**情报 Token 会不会不够用**？

**分析**：侦查消耗的情报 Token 会自动流回供应堆（§4.3 花费与效果分离原则）。情报 Token 是全局资源，被消耗后回到供应堆，不会消失。所以 Token 总量不减少——只是在不同区域（版图地点、玩家手中、供应堆）之间流转。

实际上只有以下情况导致**情报 Token 从游戏中移除**：

- 规则书中没有"消耗情报 Token 并移除"的机制
- 所有花费的情报 Token 都回到供应堆（或玩家手中）
- 唯一可能减少的是黎明阶段并未回收的 Token？

**结论**：情报 Token 是**守恒的**，不存在枯竭问题。但特定地点的情报值可能降至 0（如果被大量调查）。而 FAQ Q2 提到情报值 0 的地点作案无需花费情报——这反而可能降低消耗。

### 2.2 证据 Token 循环深度

**循环路径**：
角色供应堆 → 作案(放置到地点) → 侦查(警长持有) → 抓捕(移入看守所) → 黎明阶段移动 → 移动到 0 → 返回角色供应堆

**关键点**：证据 Token 永远不会离开游戏系统，只是在各位置间转移。不会消耗或消失。

**潜在问题**：如果罪犯的 5 个证据 Token 全部在地点上（角色供应堆为空），且都不被侦查不被捕：

- 罪犯无法放置"新"证据——每次作案只能移动现有证据
- 这意味着最多维持 5 个作案位置，无法扩展
- 如果被铁拳制裁(夜枭)销毁，销毁的证据是返回"所有者面前"而不是返回角色供应堆？描述写的是"放回其所有者面前"，这不同于返回供应堆——所有者面前就是警长手中吗？

**再看铁拳制裁的描述**："销毁该地点上所有'证据 Token'（放回所有者面前）"——指的是放回罪犯面前（而非警长面前）。所以销毁的证据返回罪犯的角色供应堆。这与规则书 §4.5 中"证据 Token"的循环一致。

**证据 Token 的完整循环确认**：
角色供应堆 → 作案(地点) → 侦查(警长) → 抓捕(看守所) → 出狱(角色供应堆) ✅ 闭环

### 2.3 成本突变检查

**情景**：当版图上的情报 Token 因大量调查而减少（各地点情报值降低时）：

| 地点情报值 | 调查收益 | 作案成本 | 作案得分 | 侦查成本 |
| - | - | - | - | - |
| 5(初始) | 1 情报 | 5 情报 | 4 分 | 5 情报 |
| 3(消耗后) | 1 情报 | 3 情报 | 4 分(不变) | 3 情报 |
| 1(消耗后) | 1 情报 | 1 情报 | 4 分(不变) | 1 情报 |
| 0(耗尽) | 不能调查 | 0 情报 | 4 分(不变) | 0 情报(但也要查吗？) |

**关键发现**：作案得分**不随情报值变化**，只取决于影响值。这意味着当某一地点的情报 Token 被大量消耗后：

- 作案成本下降（情报值消耗变少）
- 得分不变（影响值不变）
- **作案性价比大幅提升**

这可能导致玩家集中消耗某个地点的情报，然后每次在那里作案都能用极低成本获得高得分。**这违反了审查原则 §15"操作成本不应跳跃式变化"**——成本从 5 降到 0，同一地点的作案效率从 0.57 分/行动提升到无穷大（0 成本）。

**结论**：作案成本与情报值绑定，但得分与影响值绑定，导致情报被消耗后作案性价比暴增。这是一个设计漏洞。

**修复建议**：作案成本不应取决于当前情报值，而应基于初始情报值或使用固定值。

## 3. 交叉组合风险检查

### 3.1 技能 × 地点交叉风险

#### 组合 A：港口区走私通道(移动证据到上城) + 屠夫·汉斯致命打击

屠夫在上城作案有 +1 分优势。港口区是核心区（初始情报值 4，影响值 3），可以移动证据到上城。

**但是**：作案的得分基于作案地点的影响值，证据位置不影响得分。证据位置影响的是"警长是否能侦查到该证据"。

所以此组合不会直接产生分数加成，而是：

1. 在港口区作案（影响值 3，得 3+1+1=5 分？）
2. 用走私通道将证据移到上城
3. 上城情报值高（4.25），警长侦查成本更高

**实际收益**：间接增加警长抓捕成本，不直接影响得分。

**结论**：🟢 交叉组合风险较低。

#### 组合 B：码头仓库(作案情报-1) + 地下通道(移动证据到上城)

1. 在下城区作案（情报值 2.25，影响值 1.25）
2. 码头仓库减耗：情报花费 2.25 - 1 = 1.25
3. 作案得分：1.25（影响值）+ 超额 1（等级 1-2 可触发）= 2.25 分
4. 用地下通道将证据移到上城区

**效率**：（1.25 情报获取成本 = 1.25 行动）+ 2 行动（作案）= 3.25 行动 → 2.25 分 = 0.69 分/行动

这个效率甚至高于上城作案的 0.52~0.68，且情报获取成本更低。但下城的得分上限低（1.25），所以整体收益仍然有限。

**结论**：🟡 下城区组合具有一定性价比，但受限于下城影响值低，不会成为主流。

#### 组合 C：鬼手(调查效率翻倍) + 医院(调查回隐藏值)

鬼手调查效率已是 2 倍。医院的效果是"罪犯在此调查时额外恢复 1 隐藏值"。

这意味着：鬼手在医院调查 1 次 = 2 情报(精妙手法) + 1 隐藏值恢复(医院)。效率极高。

**结论**：🟡 这个组合让鬼手的资源获取更加恐怖。原本鬼手调查已超模，配合医院后更是近乎无限续航。

### 3.2 技能 × 策略牌交叉风险

#### 组合 D：铁拳暴力催收 + 线人报酬 #10

1. 暴力催收：从警长处抽取 2 张手牌（花费 1 情报 + 1 行动）
2. 线人报酬 #10：消耗 2 情报从牌库看 3 选 1（花费 1 行动 + 2 情报）

铁拳可以用暴力催收剥夺警长手牌，同时用线人报酬补充自己的手牌。此组合使铁拳的资源控制力和手牌质量都极强。

**结论**：🟡 交叉组合产生较强的信息/资源不对称优势。

#### 组合 E：屠夫(上城+1分) + 大计划 #17(延迟,下次作案+1分) + 消灭痕迹(移除证据)

屠夫在上城作案可叠加：

- 影响值 3.25 分（平均上城）
- 超额 +1 分（等级 3 在上城触发）
- 致命打击 +1 分
- 大计划 +1 分（如果提前一轮打出）
- **单次作案总分**：6.25 分

加上消灭痕迹移除证据，警长无法侦查。屠夫的这一套组合极其致命。

**结论**：🔴 单个组合强度过高。6.25 分/次的效率（仅 1 回合行动），等于约 1/3 的胜利条件。

### 3.3 卡牌交互中的漏洞

#### 金库保险 #08 + 不在场证明 #18

金库保险：选择 1 名角色，本回合不能被指定为目标。
不在场证明（延迟）：抵消抓捕。

**冲突**：如果金库保险和不在场证明同时作用，当警长指定目标时——金库保险使目标不能被指定，因此在场证明的条件"当警长对你执行抓捕时"可能不会被触发（因为指定目标已被阻止）。

**结论**：🟡 需要明确"不能被指定为目标"和"抵消抓捕"的优先级。但从保护机制看，两者重叠时有冗余保护。

## 4. 策略收敛检查

### 4.1 是否有对所有玩家都最优的同一策略？

**问题定义**：是否存在一种"必胜策略"，使得所有玩家理性的选择都趋同？

#### 警长方面

| 警长角色 | 最优策略 |
| - | - |
| 铁腕 | 优先收集 1 证据 + 情报补差抓捕等级 3 罪犯。每 2 轮 4 分 |
| 猎犬 | 侦查得情报 + 快速布控。先布控再侦查降低成本 |
| 智囊 | 查看手牌后针对性布控/抓捕。信息优势型 |

**结论**：⚡ 警长最优策略集中在"1 证据补差法"，效率约 0.48 分/行动向。不同角色执行路径有差异，但核心逻辑相似。**策略收敛风险存在**——警长都不愿意收集足额证据。

#### 罪犯方面

| 罪犯等级 | 最优策略 |
| - | - |
| 等级 1 | 核心区作案（超额可触发）+ 大量调查积累情报 |
| 等级 2(鬼手) | 调查→调查→作案。极速情报积累 |
| 等级 2(幽灵) | 偷情报 + 作案 |
| 等级 3(屠夫) | 只在上城作案，用消灭痕迹防被捕 |
| 等级 4(疯子) | 逐步部署证据链，触发连环作案 |

**结论**：⚡ 各等级的最优策略有差异（作案区域、资源积累方式不同）。但**所有罪犯的核心框架都是"积累情报→作案得分"**。差别只在于积累速度和效率。

#### 收敛风险评估

| 维度 | 风险 | 说明 |
| - | - | - |
| 警长策略收敛 | 🟡 中等 | 情报补差法效率远高于足额收集，警长最优策略趋同 |
| 罪犯策略收敛 | 🟢 较低 | 不同等级的最优区域和节奏不同 |
| 跨阵营收敛 | 🟢 低 | 警长和罪犯的核心玩法完全不同，不会收敛 |
| 全局最优策略 | 🟢 不存在 | 没有一套策略同时适用于所有阵营 |

### 4.2 证据 Token 有限性导致的策略收敛

当 5 个证据 Token 全在版图上时，罪犯只能移动现有证据而不能新增。

**这意味着**：第 5 次作案后，所有罪犯的策略焦点从"在多个新地点作案"转向"在最佳地点反复作案"。

这可能导致：

1. 所有罪犯都聚集到最高影响值的地点（如博物馆、上城区）作案
2. 所有证据 Token 集中在 1~2 个地点，警长一次性侦查可获得多个证据
3. 抓捕收益巨大的"连锅端"

**结论**：🟡 证据 Token 有限性可能导致后期策略收敛（全部聚集到高影响值地点）。

## 6. 深层漏洞检查

### 6.1 IP 枯竭（已检查，无此问题）

情报 Token 守恒→无枯竭 ✅

### 6.2 犯罪成本坍塌（发现重大问题）

**问题**：案成本与当前情报值挂钩，得分与影响值挂钩。当同一地点的情报被多次调查后，犯罪成本降至极低（甚至 0），但得分不变。

**结果**：在游戏后期，罪犯会倾向于涌入一个低情报值但高影响值的地点"洗分"。一旦该地点情报被调查至 0，作案无需任何情报消耗，但得分不受影响。

**量化**：

- 博物馆(初始情报值 5，影响值 4)
- 经过 5 次调查后情报值为 0
- 此时作案成本：0 情报（FAQ Q2）
- 得分：4 分 + 超额 1 分(等级 ≤4) = 5 分
- **效率**：2 行动 → 5 分 = **2.5 分/行动**
- 这是基准效率（0.71 分/行动）的 3.5 倍

**🔴 严重漏洞**。

### 6.3 技能 × 地点交叉风险（多处发现）

- 鬼手(调查效率翻倍) + 任何地点 → 资源积累失控
- 铁拳(暴力催收) + 警长 → 警长手牌几乎永久真空
- 疯子(连环作案) + 博物馆(高影响值) → 单次 8 分上限

### 6.4 策略收敛（已检查，中等风险）

证据 Token 有限的后期收敛问题。

### 6.5 证据循环停滞

如果罪犯一直不作案（不出证据），警长就没有可以侦查和抓捕的目标。理论上：

- 警长永远无法得分（除非无证据奖励）
- 但罪犯也不得分

理论上这是"双方的纳什均衡"——都不动。但实际上游戏中一定有玩家主动得分（因为这需要得分且抢跑），所以此情况不构成实际问题。
