## 0. 综合模拟设定

### 0.1 模拟对阵与假设

- **4 人局**：警长「猎犬」莫里斯 + 罪犯「老鼠」「鬼手」「双面人」（覆盖等级 1/2/3 的代表性技能组合，官方推荐"战术型"变体）。
- **版图**（固定 12 张）：上城{商业街 4/3、市政厅 4/3、博物馆 5/4}；核心{老城区 3/2、废弃工厂 3/2、地下酒吧 3/2、港口区 4/3、火车站 4/3、红灯区 4/2}；下城{贫民窟 2/1、黑市 3/2、码头仓库 2/1}。
- **复苏/无证据奖励**：生效。
- **布控口径**：r02/r03 遗留裁定项。综合计算按**双口径分别报告结果**，并标注对结论的影响方向。
- **策略牌**：初始 1 张，补给每轮 1 张 → 12 轮共 13 张。按期望收益抽样处理牌库构成（资源/信息/防御/干扰/得分加成的比例），不逐张展开；关键强牌（证据交易/恰到好处/不在场证明）单独做交叉组合。

### 0.2 模拟决策规则（理性玩家）

- 罪犯：优先压区自己独占的低复苏地点 → 作案 → 被警长盯上后转移/隐藏/越狱。
- 警长：优先在"证据堆叠 2+"且隐藏已压低的罪犯处做抓捕链（收割压制）。
- 三罪犯共享版图：同一地点被多人压区时，调查的双效（情报 + 地点变低）被多人共享 → 竞争地点压区更快、谁先作案谁受益。

### 1.4 与 r02 单机基准的对比修正

| 情景 | r02 单机（无对抗） | r04 综合（有对抗） | 修正幅度 |
| - | - | - | - |
| 罪犯·压区流 | 18-20 分 | 12-17 分 | **-15%~-30%** |
| 警长·抓捕链 | 9-13 分 | 9-11 分 | 基本持平（警长仍低于基准） |
| 设计基准 | 14-15 分 | — | — |

**核心结论 A（修正 r02 的单侧结论）**：

1. 罪犯在真实 4 人局中的得分被"罪犯间竞争 + 警长抑制"从 18-20 拉回 12-17，**与基准 14-15 的偏差收敛到 -14%~+13%**（差异主要由技能组合导致）。
2. **警长仍显著低于基准**（9-11 vs 14-15，-20%~-35%）：尽管抑制量全部实现，但"1 警长 vs 3 罪犯"的固定配置下，警长的得分时间被 3 罪犯分摊，轮次效率无法达标。
3. **结论修正提示**：r02 的"三大抑制源"机制成立（罪犯竞争、警长抑制、隐藏暴露都在真实 4 人局中实际生效），**但平衡点在"罪犯勉强压回基准 / 警长明显偏弱"的位置**。若目标是"各阵营发挥一般时得分相差不大"（设计基准 §4.1），则警长需要加强。

## 2. 资源循环深度检查（原则 6、11、12、13）

### 2.1 资源消耗趋势（原则 11：资源耗竭可预测）

| 资源 | 产生 | 消耗 | 趋势评估 |
| - | - | - | - |
| 版图情报值 | 调查 -1/次；作案/侦查不变；复苏 +1/区域/轮；火车站 +1/轮；黑市 +1（花费时）；港/车站等效果 | 调查是唯一消耗方 | **可预测**：核心区 6 地点共享"每轮复苏回填 1 个最低点"，3 罪犯 + 警长 4 方持续调查 → 核心区情报下行速度 ≈ (每次调查 -1) - (回填 +1/轮)。4 方若集中在核心，核心区情报在 R5-R8 大面积到 0 是常态 → **动态成本进入"0-1 情报的低位区间"的时间点可预期** ✓ |
| 情报 Token（个人） | 调查 +1/次；补给 1 牌（可换情报）；读报 +1 | 作案 X；侦查 Y；抓捕 Z；技能 | 个人累计：12 轮调查 ≈ 12 情报；作案 4-5 次 × 1-2 情报 ≈ 4-10 → **盈余 2-8**，无耗竭风险（下城/核心压区后动态成本 0-1 情报，几乎不耗个人情报） |
| 手牌 | 补给 1/轮；摸牌行动 | 弃牌（修整）；出牌；读报 | 每轮补给 1 张 → 12 轮 12 张；若玩家出牌/读报少于补给，手牌严重溢出 → **大量手牌被弃置（12 张中约 8-10 张被弃）**。手牌是"被浪费"的最大资源池（原则 6 半违反） |
| 证据 Token | 作案放置；技能回收（暗度陈仓/后巷密道/消灭痕迹/证据交易） | 警长侦查取走；抓捕入狱；出狱回收；英雄销毁 | 循环完整（§4.5 已定义全链路）✓ 但**往返周期长**：放置→侦查→入狱→出狱 需 3-6 轮。警长持证不抓时证据暂存警长手中 → 罪犯 5 枚封顶更快触发"移动模式"，反而让蓄意留证的警长收益更高（r01 5.5 的叠加效应在综合局成立） |
| 警员 Token | 5 枚常驻 | 布控后黎明回收 | 无耗竭 ✓ |

### 2.2 成本突变检查（原则 12：操作成本平滑过渡）

| 场景 | 突变源 | 检查结果 |
| - | - | - |
| 地点情报从高位被压到 0 的过渡 | 作案动态成本 X 从 4→0 线性下降 | **平滑** ✓（成本与情报值绑定，随调查逐点下降） |
| **被捕瞬间** | 罪犯从"正常作案流"切换到"读报流" | **突变** ⚠️：入狱后轮次效率从 1.0-1.5 骤降至 0.25（读报不产分；仅越狱产 1 分/轮行）。这是"有意的惩罚性突变"，但结合看守所 3-4 轮刑期，对高等级罪犯是沉重打击 |
| **隐藏值归零瞬间** | 抓捕补差 Z 从 4→0 | 罪犯压区行为自身导致隐藏下行，随时间自然发生 → **平滑** ✓（但触发条件连续，最终体现为"被抓成本骤降的时间点可预测"） |
| 布控口径②（提情报值） | 作案成本从 1→3（被布控） | **跳跃上升** ⚠️：罪犯正在压区的地点被布控，作案花费 +2 即时生效，无预警。对罪犯节奏是"打回原形"式打击（这正是警长想要的），但与原则 12 的平滑性冲突。若维持口径②，建议布控在傍晚阶段结算（有 1 轮预警） |
| 证据 5 枚封顶 → 移动模式 | 第 6 次作案从"放置"变"移动" | **平滑** ✓（同为"2 行动 + X 情报 → 得分"，仅证据位变化；若目标为 0 情报地点则成本近似 2 行动） |

| 循环 | 状态 |
| - | - |
| 情报 Token：调查产生 → 作案/侦查/抓捕消耗 →（供应堆）→ 复苏回填版图 | **闭环无泄漏** ✓（唯一边界：供应堆总量未定义 r01 5.8） |

## 3. 交叉组合风险（原则 14：不超预期；重点验证 r03 交接）

### 3.1 压区快攻 × 证据交易（罪犯资源循环突破）

- 组合：罪犯「鬼手」（调查 +1 情报）持有「证据交易」（弃 1 证据 → +3 情报）+「情报报告」（+2 情报）。
- 单轮极限：M（摸牌）→ 出情报报告（+2 情报）→ 出证据交易（回收自身证据 +3 情报）→ 用作案（X=0-1 的低压区地点）→ 1 行动换 1-3 情报 × 2 + 回收 1 证据 → **一个行动轮可净增 4-6 情报且保留 1 证据循环**。
- 若鬼手 12 轮中 2 次打出证据交易（出牌 2 次 + 摸牌补齐），相对 0 能力基准再 +4~6 分 → **罪犯峰值突破 20 分**。警长若布控口径①无法压制其作案成本，此组合会把压区快攻推向 22+ 分。
- **判定**：⚠️ 高交叉风险。`证据交易`是罪魁（r03 已标 🔴），建议将其"弃己方证据得 3 情报"改为"弃**其他罪犯**证据得 3 情报"或直接降为 2 情报。

### 3.2 双面人金融犯罪 × 大计划（行动换分直购）

- 金融犯罪：3 情报 + 2 行动 + 3 分；大计划：1 行动（延时）+ 1 分。
- 双面人一局可打出：金融犯罪 3 分 + 大计划附着作案 +1 分（相当于 4 情报/行动组合换 4 分）。
- **判定**：分/资源 ≈ 1.0（超过基准 0.39-0.42 的 2.4 倍）。即使计 2 行动，仍是"无需版图配合的直接得分"→ **确定超模**（r03 已标 🔴），r05 需下调。

### 3.3 抵消抓捕手段总量（原则：警长体验）

- 全局"抵消/破解抓捕"手段：老鼠见风使舵（2 情报，限 1）、双面人金蝉脱壳（2 情报，限 1）、策略牌不在场证明（2 张）、紧急躲避（2 张，免疫指定）、金库保险（2 张，免疫指定）。
- 一张警长抓捕（4-6 IC）被以下任一抵消：见风使舵（2 情报）、不在场证明（已付 1 行动）、紧急躲避（0 行动）。
- **判定**：单局 3 罪犯中若 1-2 名持有抵消手段，警长 12 轮的 3-4 次抓捕将被抵消 1-2 次 → **警长有效抓捕下降到 1-2 次 → 警长得分 6-8 分，远低于基准**。需降低"抵消抓捕"的密度（玩家持有概率），或给警长"抓捕被抵消时返还部分投入"（如已花费情报退回一半）作为补偿。

### 3.4 布控双口径 × 猎犬天罗地网（叠加压制）

- 若口径②：莫里斯天罗地网（⚡️ 花 1 情报布控）→ 每轮可免费布控 1 次 + 常规布控 1 次 = 2 处地点 +2 情报。
- 若同时叠加市政厅侦查 +1 情报，侦查成本进一步降低。猎犬的"侦查→抓捕"链在口径②下异常流畅。
- **判定**：口径②会让猎犬的布控流综合效率接近基准上限（1.2-1.3 分/轮），但仅限猎犬；其他警长（铁腕/智囊）仍偏弱。**裁定建议（交 r05）**：采用口径②（布控提升地点情报值，影响所有行动），但把布控的基础效果从 +2 降为 +1，避免"布控+天罗地网"叠加过度压制罪犯。

### 3.5 疯子连环作案 × 上城链（空间流派峰值）

- 疯子（等级 4）在上城三连点（商业街-市政厅-博物馆）做链：相邻有自己证据时 +X（X=场上其他己证数，上限 +3）。
- 理论峰值：3 点各 1 证据 → 第 4 次作案放新点 +3 分 → 单次 4+3=7 分。
- **判定**：⚠️ 峰值过高（单次 7 分，分/资源 1.75）。考虑疯子的隐藏上限 2 + 上城复苏回填高成本，实际触发频率受限（需 3 点同时持有己证，警长侦查一收就断链）。**标记为 🟡 潜在超模，需实测**；建议降低上限（+2 替代 +3）或增加"断链后重新蓄力"成本。

### 3.6 交叉组合总表

| 组合 | 风险 | 判定 | 建议 |
| - | - | - | - |
| 压区快攻 × 证据交易×鬼手 | 高 | ⚠️ 突破 20+ 分 | 证据交易改限制/降数值 |
| 金融犯罪 × 大计划 | 高 | ⚠️ 1.0 分/资源直购 | 下调金融犯罪 |
| 抵消抓捕总量 | 中高 | ⚠️ 警长抓捕被稀释 | 降密度或补偿返还 |
| 布控 × 天罗地网（口径②） | 中 | 🟡 仅猎犬超模 | 布控 +2→+1 |
| 连环作案 × 上城链 | 中 | 🟡 峰值 7 分 | 上限 +3→+2 |

## 4. 策略收敛检查（原则 15）

### 4.1 候选策略集合（0-1 技能）

| 策略 | 核心操作 | 12 轮预期 | 收敛风险 |
| - | - | - | - |
| A. 压区快攻（调查×2→作案） | D×2 + C | 14-18 分（有对抗） | ⚠️ **最高**：所有罪犯共享同一最优节奏 |
| B. 多线分散作战 | 走低复苏点轮换 | 12-16 分 | 🟡 较低（被警长盯上代价大，收益也低） |
| C. 证据流/移动流 | 靠 5 枚封顶移动刷 0 情报点 | 8-12 分 | 🟢 条件苛刻（需 5 证全铺开） |
| D. 越狱流 | 入狱后快速越狱得分 | 仅限被捕后 | 🟢 被动型 |
| E. 防守流 | 高隐藏 + 布控规避 | 10-13 分 | 🟢 低 |

### 4.2 收敛判定

- **策略 A 在所有罪犯角色下都是最优或接近最优**（无论等级、技能如何组合，压区→作案的资源循环都是得分主流）。差异化技能（连环作案/致命打击）只是给压区流加"风味修饰"，未改变收敛到 A 的事实。
- **布控口径②若不生效**（口径①），警长对策略 A 的核心压制手段失效 → 策略 A 成为"必胜策略"，收敛风险**极高**。
- **布控口径②若生效但强度 +2**，策略 A 被有效打断但过度（罪犯被布控后只能转点，节奏损失大）→ 收敛风险中（被"布控-转点"循环代替，转向另一个收敛）。
- **判定**：当前设计下**策略收敛为"压区快攻"（策略 A），并通过"布控-转点"形成轻微博弈**。改进方向：给罪犯 1-2 个不依赖压区的次要得分路径（如提升越狱流的收益、或证据移动流的奖励），扩大策略多样性空间。

### 5.2 判平衡结论（净平衡公式：罪犯无干预效率 − 警长抑制量）

## 7. 对 r05 的交接（综合计算的必改项）

1. **警长基础效率补强**：综合数据显示警长 12 轮 9-11 分，距基准 -3~-5 分。候选修正：①抓捕得分 = 犯罪等级 +1（等级 2→3 分）；②高效抓捕条件放宽为"证据数 ≤ 犯罪等级"；③无证据奖励 +1→+2/次；④给警长"黎明若 2 名以上罪犯有证据在版图则 +1 分"的新奖励。**建议组合 ①+③，预计 +3~4 分**，回测仍不超基准。
2. **证据交易重做**：改为"弃 1 个版图上的**其他罪犯**证据 → 获得 2 情报"，堵住"自弃自证刷资源"的漏洞，且保持跨罪犯干扰价值。
3. **金融犯罪下调**：3 情报 → 3 分 改为 **3 情报 → 2 分**（或 4 情报 3 分），降至 ≤ 基准 0.5 分/资源附近。
4. **抵消抓捕密度**：不在场证明由 2 张减为 1 张；或给警长"抓捕被抵消时，已花费的情报 Token 返还一半"。
5. **布控统一**：§4.2 与 §6.2 统一为"布控使该地点情报值 +1（本轮有效，影响所有参考该地点的行动）"；同地点仍限 1 警员；上限不受复苏约束但不超过初始值 +1（需规则补充）。
6. **疯子连环上限 +3→+2**（🟡 实测后备选）。
7. **策略收敛缓解**（ 备选）：给移动流/越狱流加 0.5 分轻微奖励（如"移动证据到新地点时额外 +1 分"，或越狱 1 分/格 → 1.5 分/格），成本可控地扩开策略空间。
