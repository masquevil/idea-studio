## 1. 各阵营/路线综合得分预期（含技能）

### 1.1 警长（含技能）

| 路径 | 推演 | 总轮次 | 评价 |
| - | - | - | - |
| 铁腕·雷霆行动流 | 弃牌 +1 行动 → 一回合"侦查+抓捕"，取证/抓捕同轮 | 5 次抓捕 ≈ 8-9 轮 | ✅ 强提速 |
| 猎犬流 | 侦查回扣 1 情报（取证成本 -1） | ≈ 9-10 轮 | ✅ |
| 智囊流 | 借牌压缩蓄力轮 | ≈ 9-10 轮 | ✅ |

**警长综合**：技能将警长从 0 技能 10-11 轮拉到 **8-10 轮**，与罪犯（10-11 含被干扰）基本对齐 ✅。铁腕显著强于另两张（阵营内差异，测试观察）。

### 1.2 罪犯（含技能，等级梯度）

| 等级/角色 | 核心节奏 | 单次作案 | 达标轮次 | 评价 |
| - | - | - | - | - |
| 等级1·老鼠 | 人群掩护免核心压点隐藏代价 | 3 分（影响2+匹配1） | 5 次 ≈ 10-11 轮 | ✅ |
| 等级2（基准） | 压0 后 0→1→2 递增，周期重压 | 3 分 | 5 次 ≈ 10-11 轮 | ✅ |

| 等级4·疯子 | 制造恐慌布证 → 连环作案 | 单次 4-7 分（§2.1） | **3-4 次 ≈ 8-10 轮** | 🔴 超模边缘（回填抑制后较上轮回落） |

**罪犯综合**：除疯子外梯度合理；疯子爆发被作案回填抑制，但仍是唯一威胁主基准的角色（§2.1 详算）。

### 1.3 超级英雄（扩展）

**制裁流水线（夜枭 + 一网打尽）**：

- 制裁花费 = 目标隐藏值 + 当前持证数；得分 = 持证数（1+2+3+4+5=15）。
- 回填时代**制裁情报需求上升**（取证本身需情报）。

| 制裁次数 | 持证 | 得分 | 动态花费（隐藏2+持证） |
| - | - | - | - |
| 1 | 1 | 1 | 2+0 = 2 |
| 2（一网打尽） | 3 | 3 | 4 |
| 3 | 4 | 4 | 5 |
| 4 | 5 | 5 | 6 |
| 累计 | — | **13** | ≈17 情报 |

- 蓄力 8-9 轮（侦察 2 情报/轮）+ 执行 4 轮 ≈ **12-13 轮** → 临界。
- 一网打尽省 4-6 情报 → ≈11-12 轮 ✅。暗影情报截获（双倍蓄力）可再压缩 → ≈10-11 轮。
- **评价**：英雄制裁流 ≈11-12 轮，略慢但技能可补，✅ 合理偏慢。

**登场流**：登场得 X 分（该地点证据数），依赖他人布证 → 3-5 分/次，约 4-5 次 ≈12 轮 ✅。

**越权执法（裁决者）**：

- ⚡️ 每回合限 1 次，花 2-3 情报（目标隐藏值）→ 1 证入狱格 1 + 自己 +1 分。
- 12 轮极限 12 次（需蓄力 24-36 情报）→ 实际 5-8 次 → **5-8 分 + 剥夺 5-8 证据**，几乎不占执行轮。
- 🟡 偏强（免费动作高频刷分），r05 建议限制（改为 ➡️ 行动等）。

### 1.4 受害者（扩展，触发率独立推演）

| 场景 | 基础（≥2）触发率 | 有备而来（≥1）触发率 |
| - | - | - |
| 他人作案/抓捕轮（3 分） | 100% | 100% |
| 他人蓄力轮（0-1 分） | 0% | 0-100% |
| 混合 | ~50-70% | ~70-90% |

- 追偿轻量型（1 行动 + 2 情报），每 2 轮 1 次 → 12 轮 ~5-6 次 × 0.7 × 1 分 ≈ **3.5-4.5 分**（表面），加权 5-8 分当量；爆料 ≈2-3 分。
- **受害者基础得分 ≈6-8 分/局，加权后仍与 15 分有缺口，依赖技能补足**。5-7 人局中易成"酱油阵营"。🔴 需用户确认补强方案（r05 D2：追偿 +1 分 / 爆料可控翻面 / 暂不处理）。

## 2. 深层漏洞检查

### 2.1 🔴 交叉组合：疯子（等级4）连环作案（回填时代重算）

**组合**：制造恐慌（布证）+ 连环作案（相邻证据 +1，无上限）+ 压点 + 隐藏上限 2。

**推演（老城压 0，疯子证据 3 枚于相邻地点）**：

| 步骤 | 行动 | 地点情报(前→后) | 动态花费 | 收益 |
| - | - | - | - | - |
| R1 | 制造恐慌（X=2 → 花 2 情报布第 3 证） | — | 2 | 0 |
| R2 | 连环作案（老城） | 0→1 | 0 | 影响2+匹配1+相邻3×1 = **6 分** |
| R3 | 连环作案（老城） | 1→2 | 1 | 相邻4×1 → **7 分** |
| R4 | 连环作案（老城） | 2→3 | 2 | **7 分** |
| R5 | 重压（D、D）+ 后续 | 3→1 | 0 | 0 |
| R6 | 连环作案 | 1→2 | 1 | **7 分** |
| 累计 | | | | **27 分（6 轮）** |

**关键变化（对比上轮）**：作案回填使成本递增，疯子第 3-4 次作案需支付 1-2 情报并重压，不再能无成本连击。但**相邻加成（4-5 枚证据 × +1 = +4~5）使单次 6-7 分**，仍只需 **3-4 次作案 ≈ 8-10 轮**即达 15 分（含重压轮）。

**判定**：🔴 **仍超模**，但超模程度较上轮（4-6 轮爆 15 分）**显著缓解**——触发"交叉组合超预期"（原则 14）的边际从"碾压"降为"越过主基准下限"。

**修改方向（供 r05）**：

1. 连环作案加成**加帽**（"相邻每 1 枚 +1，最多 +3"）→ 单次 5 分，4-5 次 ≈10 轮；
2. 或限制**相邻证据来源**（仅"非制造恐慌放置"的证据计相邻）→ 直接砍组合核心；
3. 或制造恐慌与作案互斥（布证轮不能作案）。

> 推荐方向 1 + 3 组合；方向 2 单独亦可。

### 2.2 🟡 交叉组合：越权执法 + 从重判决

- 越权执法（⚡️ 免费）不断移证入狱 → 看守所堆证 → 从重判决登场爆分。
- 依赖罪犯多次被捕，触发条件强；越权执法单行强度（§1.3）才是主问题。组合非🔴。

### 2.3 🟡 交叉组合：布控 + 设伏 + 爆料（+5 封点）

- 同一地点 +2+2+1 = +5 情报值修正 → 作案/侦查成本暴涨。
- 罪犯可转移证据规避，非致命；3 罪犯各自为政难合力。✅ 合理。

### 2.4 资源循环深度检查

**① 证据 Token 循环**（角色供应堆 → 作案 → 版图 → 侦查 → 警长 → 抓捕 → 看守所 → 出狱）：

```
闭环 ✅：出狱返回角色供应堆。
溢出机制 ✅：5 枚全版图 → 作案改移动。
英雄制裁拿证保留在英雄手中 → 脱离罪犯循环（有意设计，剥夺当量）。
异常点：看守所内证据黎明左移 1 格（数字 -1），到 0 出狱；不入狱的（英雄/迷雾）不占看守所。✅
```

**② 情报 Token 循环（回填时代更新）**：

```
闭环 ✅：花费回公共堆；调查从地点取走（消耗版图存量）；作案/火车站/情报干扰回填（抬升版图）。
动态平衡：作案回填（+1/次）+ 火车站（+1/黎明）+ 情报干扰（+2/放置） vs 调查取走（-1/次）。
平衡分析：4 人局 12 地点、初始总量 ~38 情报。3 罪犯每轮 ~2 次调查（-2）+ 警长/英雄取证 -1~3；回填 ~2-4/轮。整体缓慢消耗，不再快速枯竭 ✅。
潜在通胀：若罪犯长期不压点（少调查）+ 频繁作案 → 回填 > 消耗 → 版图情报回升 → 侦查/制裁成本回升（利好警长/英雄）。平滑 ✅。
```

**③ 成本突变检查**：

| 场景 | 突变点 | 评估 |
| - | - | - |
| 地点情报耗竭（压 0） | 作案 0 成本（首击） | 因回填，压 0 后第二次 1、第三次 2 → **成本平滑递增，无跳跃** ✅ |
| 证据 Token 耗尽 | 作案改移动 | 成本不变 ✅ |
| 手牌上限 3 | 弃牌 | 平滑 ✅ |
| 看守所证据清零 | 证据返回 → 可再作案 | 平滑 ✅ |
| 版图情报通胀 | 回填 > 消耗 | 持续回升，平滑（无突变）；对压点罪犯是隐性成本抬升 |

**结论**：三大 Token 循环闭环；**作案回填将旧口径的"压 0 后 0 成本平台"改为"成本平滑递增"**，满足原则 12（无跳跃）✅。

### 2.5 策略收敛检查

- **罪犯**：压 0 是最高效路线，但**多罪犯同挤一点 = 各自回填互相抬价** → 分散动机自增强 → 收敛被机制自然打破 ✅（r03 注意点）。
- **警长**：抓压点罪犯（0 取证）是唯一高效路线 → 与罪犯压点形成猫鼠循环 ✅。
- **疯子**：爆发流仍是最优（§2.1）→ 收敛点 🔴 需修复。
- **英雄/受害者**：依赖外部条件，非全局最优。

**结论**：除疯子外，作案回填时代策略收敛被自然抑制，猫鼠博弈更健康。

### 2.6 非对称阵营综合对比（加权分）

| 阵营 | 表面分 | 加权系数 | 加权当量 | 达标轮次 | 判定 |
| - | - | - | - | - | - |
| 罪犯（除疯子） | 15 | 1.0 | 15 | 10-11 | ✅ |
| 警长 | 12-15 | ≈1.33 | 16-20 | 8-10 | ✅（少数压制多数补偿） |
| 超级英雄 | 14-15 | 1.0 | 15-17 | 11-12 | ⚠️ 偏慢临界 |
| 受害者 | 6-8 | 1.5-2.0 | 10-15 | 12+ | 🔴 偏弱 |
| 疯子 | 20+ | 1.0 | 20+ | 8-10 | 🔴 超模边缘 |

**综合判定**：

- **🔴 疯子**：唯一威胁主基准（虽回填已抑制）。
- **🔴 受害者**：基础得分弱，12 轮难达 15 分。
- **🟡 超英**：11-12 轮临界偏慢（技能可补）。
- **✅ 警长/普通罪犯**：平衡良好（回填时代双端对齐）。
