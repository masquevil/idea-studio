# 评审④ · 综合计算（第十轮）

> 加入所有特殊能力、环境效果、卡牌效果后的综合结果。
> 重点验证 r03 提出的平衡风险（等级 1 超模、疯子提速、警长偏慢、扩展阵营分化）+ 资源循环深度检查 + 交叉组合 + 策略收敛。
> 仍以 4 人局（1 警长 + 3 罪犯）为主；扩展阵营（5-7 人局）附注。

## 1. 各阵营综合得分/进度预期（含技能 + 策略牌）

### 1.1 罪犯 · 等级 1（老鼠）综合节奏

> r02 已示等级 1 与等级 2 同样 3 分/次；人群掩护在核心区免调查隐藏代价。

| 组分 | 轮数 | 说明 |
| - | - | - |
| 首压 | 2 轮 | 核心区 3→0 |
| 执行轮 | 5 轮 | 5 次作案 × 1 轮（3 分/次） |
| 重压轮 | 2 轮 | 4×0.5 |
| 干扰轮 | 0-2 轮 | 隐藏常驻 1 → 警长抓捕补差 1，被捕风险低于高等级 |
| **总轮次** | **9-11 轮** | 与等级 2 持平，但防御更优 → **等级梯度失效确认** |

**结论**：老鼠综合节奏与等级 2 基准一致（9-11 轮），且：

- 隐藏常驻 1（人群掩护）→ 抓捕补差恒定 1 情报；
- 入狱格 1 → 出狱最快；
- 见风使舵（4 情报）每局 1 次保底打断抓捕。
**判定**：等级 1 综合强度 ≥ 等级 2 平均，与"低等级低回报"原则冲突。🔴 需修正（方向见 r05）。

### 1.2 罪犯 · 等级 4（疯子）综合节奏

> 场景：核心区建立相邻网络（2-3 个相邻有证地点）→ 连环作案爆发。

| 阶段 | 行动 | 得分 |
| - | - | - |
| 铺证（R1-2） | 制造恐慌/作案散布证据至相邻地点 | 0-3 分 |
| 爆发（R3） | 影响值 3 地点作案（压制后） | 3（影响）+1（匹配）+2~3（连环）= **6-7 分** |
| 再爆发（R4-5） | 转移/补证再作案 | 4-7 分/次 |

**节奏推演**：2-3 次 KSA 即达 15 分（约 4-6 轮 + 准备），**显著低于 8 轮主基准下限**。🔴 超模确认。
**风险缓冲不足**：制造恐慌（➡️ 1 行动，成本=版图证据数）铺证成本低；隐藏狩猎回复 2 点使警长压低隐藏失效。警长唯一有效反制是抓捕（打断 1 轮），但疯子版图 5 证据时每次抓捕仅移 1 证入狱，剩余证据仍支撑连环。

### 1.3 警长综合节奏（含技能 + 策略牌）

> 0 能力 10-13 轮临界（r02）。加入技能与策略牌：

| 角色 | 补强 | 预估总轮次 |
| - | - | - |
| 铁腕 | 雷霆行动压隐藏 + 铁腕执法 +1 分 | 8-11 轮（4 分/次 × 4 次 + 和平/高效） |
| 猎犬 | 追踪直觉回扣 + 天罗地网布控 | 9-12 轮（侦查成本降低） |
| 智囊 | 战术分析借牌 + 布局预判 | 9-12 轮（借牌补手牌资源） |

**结论**：技能将警长拉回 8-12 区间，但**依赖角色技能**——0 能力警长仍偏慢。策略牌（情报报告/现场勘查/一夜成名）可进一步加速，但随机性大。**判定**：警长综合节奏落在 8-12 内，偏慢但可接受；铁腕是最强警长（4 分/次抓低隐藏），猎犬/智囊需要更多准备。

### 1.4 扩展阵营综合节奏（5-7 人局附注）

- **超级英雄**：登场 2-4 分/次（高证据密度），5-6 次达标 → 综合 10-12 轮，**合理偏快**；夜枭制裁滚雪球（1+3+6+10+15）在 6 次内可达 15 分，但需持续取证。裁决者越权执法（1 行动 +1 分 + 剥夺）叠加从重判决 → **过强风险**（r01 §2.2）。
- **受害者**：艾登追偿（目标 -1 你 +2）= 净 2 分当量/次，6-8 次达标 → 综合 10-12 轮，**合理**；艾米莉依赖爆料外部触发，触发率不可控 → **偏弱**。

## 2. 资源循环深度检查

### 2.1 版图情报消耗趋势（4 人局）

| 时段 | 版图情报状态 | 分析 |
| - | - | - |
| 前期（R1-4） | 12 地点初始 2-5 情报，罪犯压 0 + 调查抽走 | 情报快速消耗，核心区出现压 0 地点 |
| 中期（R5-8） | 作案回填 + 火车站回填 + 情报牌回补 | 供给与消耗平衡，压 0 地点作案回填 1，需重压 |
| 后期（R9-12） | 情报牌（干扰/泄露）加剧波动 | 波动上升，策略牌影响放大 |

**归零时间点**：若 3 罪犯集中压同一核心点（初始 3），2-3 轮即归 0 → 此后作案免费 + 回填 1 的循环稳定。**未出现全局情报枯竭**（火车站回填 + 情报牌 + 80 枚存量供给充足）。

### 2.2 犯罪成本突变检查

- **压 0 → 作案（0 花费）** 与 **布控/混淆 +2 → 作案（2 花费）** 之间存在 2 情报跳跃。
- **判定**：布控 +2 使单次作案成本从 0 → 2，需额外 1 轮调查（成本 +50%+）——**跳跃幅度可控**（未达"成本不可承受"），但若叠加设伏/爆料情报值修正可到 +4~+6，此时罪犯理性转移目标。**无成本坍塌**（压 0 免费作案被回填 + 重压调查平衡）。

### 2.3 循环完整性检查（Token 全链路）

| Token | 产生 → 消耗 → 回收 | 闭环 |
| - | - | - |
| 情报 | 调查/地点/牌 → 花费回供应堆 | ✅ 闭环（花费后回公共堆） |
| 证据 | 供应堆→作案放置→侦查持有→抓捕入狱→出狱回供应堆 | ✅ 闭环 |
| 警员 | 供应堆→布控放置→黎明收回 | ✅ 闭环 |
| 英雄 | 供应堆→登场放置→黎明收回 | ✅ 闭环 |
| 混乱 | 受害者→放置→黎明收回 | ✅ 闭环 |
| 迷雾 | 供应堆→迷雾放置→侦查持有→抓捕回公共堆 | ✅ 闭环（2-3 人局） |
| 分数 | 公共→得分标记 → 终局 | ✅ 终局线 15 |

**结论**：所有 Token 循环闭合，无泄漏。✅

### 2.4 特殊能力×环境交互（交叉组合审查）

| 组合 | 效果 | 风险 |
| - | - | - |
| 疯子 连环作案 × 地下通道捷径（移证上城） | 快速上城布证 → 连环爆发 | 🔴 高风险（见 §1.2） |
| 老鼠 人群掩护 × 核心区压点 | 隐藏常驻 1，压点免防御代价 | 🔴 等级梯度失效 |
| 猎犬 天罗地网 × 免费布控 × 情报富集 | 一轮多控，压制面过广 | 🟡 建议"回合限一次" |
| 裁决者 从重判决 × 越权执法 × 看守所堆证 | 证据堆积 + 封锁出狱 + 登场得分 | 🟡 强 combo，需限制 |
| 双面人 金融犯罪 × 不打草惊蛇 | 3 情报→2 分，无版图暴露 | 🟢 低效但保险 |
| 情报泄露（移除方向）× 压 0 作案 | 移除回填 1 → 免费作案窗口延长 | 🟢 手牌资源约束 |

**结论**：最大交叉组合风险集中在**疯子（1.2）**与**裁决者（§4.1）**，其余组合可控。

## 3. 策略收敛检查

> 是否所有玩家都被迫涌向同一个最优策略？

### 3.1 罪犯侧（4 人局 3 罪犯）

| 策略 | 适用 | 收敛风险 |
| - | - | - |
| 压 0 → 核心区作案 | 全等级 | 通用但单点暴露（警长布控/侦查反制）→ 玩家需分散点 |
| 上城高影响（等级 3-4） | 高等级 | 高危险高回报，成本高不泛用 |
| 下城托底（码头仓库 -1 花费） | 等级 1-2 | 收益低（1-2 分/次），作保底 |

**判定**：核心区压 0 是最强通用策略，但版图有 6 张核心区地点、3 罪犯自然分散；警长布控/侦查可反制集中压点 → **收敛风险中低**。唯一失控点：**老鼠（等级 1）核心区零防御代价**放大集中度（§1.1）。

### 3.2 警长侧

| 策略 | 适用 | 收敛风险 |
| - | - | - |
| 抓低隐藏罪犯（高效 +1） | 铁腕 | 只对特定罪犯奏效 |
| 侦查取证 → 抓捕 | 通用 | 基础路径，对不同罪犯无差别 |

**判定**：警长策略收敛于"找容易抓的罪犯"——这是**合理的最优解而非死板收敛**（目标多样性来自罪犯隐藏/证据分布）。无"必胜策略"。

### 3.3 策略牌侧

- 情报报告（8 张）最高频通用 → 玩家倾向"攒情报 + 打情报"通用打法。
- 得分类牌（一夜成名等）仅 4 张，不构成"买分"收敛路径。
- **判定**：策略牌不产生单一最优，无收敛风险。

**策略收敛总判定**：主收敛风险 = **老鼠核心区压 0**（免防御代价放大集中度）；疯子为爆发型非收敛型。其余无必胜策略。

## 4. 非对称阵营综合对比（加权分）

> 跨阵营对比必须用加权分（§3.6）：纯得分 1.0、得分+剥夺 ≈1.33（抓捕/追偿）。

| 阵营 | 综合节奏 | KSA 次数（加权） | 加权分当量 | 判定 |
| - | - | - | - | - |
| 罪犯（等级 2） | 9-11 轮 | 5 次 | 15（×1.0） | ✅ 基准达成 |
| 罪犯（等级 1 老鼠） | 9-11 轮 + 防御优 | 5 次 | 15（×1.0） | 🔴 等级梯度失效 |
| 罪犯（等级 4 疯子） | 4-6 轮 | 3 次 | 15（×1.0） | 🔴 显著超模 |
| 警长（铁腕） | 8-11 轮 | 4-5 次 | 15-20（×1.33） | ✅ 合理 |
| 警长（猎犬/智囊） | 9-12 轮 | 5 次 | 15-20（×1.33） | 🟡 偏慢但可接受 |
| 超级英雄（夜枭/裁决者） | 10-12 轮 | 5-6 次 | 15（×1.0） | 🟡 合理偏强 |
| 受害者（艾登） | 10-12 轮 | 6-8 次 | 15-16（×1.5-2.0） | 🟡 合理偏强 |
| 受害者（艾米莉） | >12 轮 | 依赖触发 | 不可控 | 🟠 偏弱 |

**综合对比结论**：

1. **标准 4 人局主基准健康**：等级 2 罪犯 9-11 轮、警长 8-12 轮，均落在 8-12 区间。
2. **两处红色超模**：老鼠（等级 1 梯度失效）、疯子（等级 4 显著提速）——为当前最需修正项。
3. **扩展阵营分层**：艾登/掮客/夜枭/裁决者合理偏强，艾米莉偏弱——在 5-7 人局中需测试验证。
4. **猎犬天罗地网**加"回合限一次"可降低一轮多控风险。
