> 加入所有特殊能力、环境效果、卡牌效果后的综合结果评估。

## 1. 综合得分/进度预期（4 人局标准）

### 1.1 罪犯综合预期（含角色+地点+卡牌）

| 幽灵(Lv2) | 1.5 | 华丽骗术净 +1 情报/回合 → 调查腾出 1 行动 → 压区周期缩短 | — | ~1.7-1.9 | ~17-19 分 |

| 鬼手(Lv2) | 1.5 | 调查 1 行动→2 情报 → 压区 2D 变 1D → 周期 2 轮→1.5 轮 | — | **~2.0** | ~20 分 |
| 双面人(Lv3) | 1.0-1.33 | 金融犯罪直得 2 分/局限1 | — | ~1.3-1.5 | ~13-15 分 |

**结论**：

- **超模组**：鬼手（~2.0 分/轮）、疯子（~2.0 分/轮）、幽灵（~1.8）——均显著高于设计基准 1.17-1.25 分/轮
- **基准组**：老鼠/毒蛇/铁拳/屠夫（1.5-1.67）——已高于基准，但在"警长抑制存在"下可回落
- 罪犯群体综合预期 15-20 分 → **多数角色可单侧达成 15 分终局**（无视警长），与 r02 的"核心 18 分上限"一致，进一步确认：**警长抑制的规模必须足够大才能防止罪犯局局 15 分早胜**

### 1.2 警长综合预期（含角色+地点+卡牌）

| 角色 | 0 能力链（r02） | 角色修正 | 综合轮次效率 | 12 轮预期 |
| - | - | - | - | - |
| 鲍默尔 | 1.5（依赖压区） | +1 行动 → 侦查/抓捕节奏 +50% → 1.8-2.4 | ~2.0-2.4 | ~20-24 分 |
| 莫里斯 | 1.5 | 侦查返还 1 情报 → 侦查成本减半 → 1.7-2.2（叠加市政厅更强） | ~2.0-2.2 | ~20-22 分 |
| 温斯洛 | 1.5 | 无提速 → 1.0-1.5 | ~1.0-1.5 | ~12-15 分 |

**结论**：

- 鲍默尔/莫里斯综合预期 20-22 分 → **显著超模**，压制力可使 3 罪犯整局难受
- 温斯洛 12-15 分 → 明显偏弱，与鲍默尔差距 5-9 分 → **警长角色强度撕裂（角色失衡）**
- **关键警示**：若鲍默尔在局，罪犯核心压区作案会被频繁打断（每次抓捕 2-3 分 + 关押），净平衡可能是"警长过强"而非"罪犯过强" → 双高相互抵消，但体验可能极端（一方被彻底压制）

### 1.3 净平衡初判（跨方抑制，量化审查规则 §3.5）

| 配对 | 罪犯无干预 | 警长抑制量（估） | 净平衡 | 判定 |
| - | - | - | - | - |
| 普通罪犯 vs 普通警长 | 1.5 | 打断/关押扣除 ~0.3-0.5 分/轮 | ~1.0-1.2 | ✅ 接近基准 |
| 超模罪犯(鬼手/疯子) vs 普通警长 | 2.0 | 同上 | ~1.5-1.7 | 🔴 抑制不足 |
| 普通罪犯 vs 超模警长(鲍默尔) | 1.5 | 抓捕频率高 → 扣除 ~0.6-0.8 | ~0.7-0.9 | 🔴 罪犯被过度抑制 |
| 超模罪犯 vs 超模警长 | 2.0 | ~0.6-0.8 | ~1.2-1.4 | 🟡 双高对冲，体验极端 |

**审计行（抑制量折算依据）**：

- 警长抓捕一次 = 罪犯损失约 1-2 轮作案窗口（关押 2-4 格 → 2-4 个黎明）≈ -0.75~-1.5 分/次
- 每次抓捕警长得 2-4 分 + 罪犯失 1.5-3 分 → **单次抓捕的综合收益（自己得分 + 对手失分）极大**，是警长的主要强力杠杆
- 无证据奖励（+2/黎明）：压制成功后每黎明 +2，属于"滚雪球"奖励 → 需警惕

## 2. 资源循环深度检查

### 2.1 情报 Token 消耗趋势（原则 11 资源耗竭可预测）

| 资源池 | 产生 | 消耗 | 回收 | 枯竭风险 |
| - | - | - | - | - |
| 版图情报 | 初始 12 地点合计 ~37-40；复苏（3 区域各自最低 +1，不超初始）；火车站黎明 +1 | 调查（1 行动/次）、侦查、作案花费 | 无直接回收（消耗即永久） | 🟡 无枯竭（复苏保底）但**总量缓慢下降**：每轮 3 复苏 + 1 火车站 vs 玩家调查 4-6 次/轮 → 净消耗约 2-3/轮 → 12 轮约消耗 25-36 → 中期后版图普遍低情报 |
| 供应堆情报 | 无限（理论上） | 作案/侦查等 | — | 🟢 无枯竭 |

**关键推论**：

- **版图情报中后期普遍偏低**（2-3 轮后核心区普遍 1-2）→ 作案/侦查成本下降 → **游戏后期得分加速**（冲刺期），符合动态周期预期（§3.4）✓
- 但低情报也意味着：罪犯压区成本下降 → 核心区更拥挤；警长侦查成本下降 → 抓捕更容易 → **后期双方节奏同时加快，终局加速**。12 轮上限可能经常被"有人 15 分早胜"替代 → 需确认这是设计预期（用户想法已支持 15 分早胜）。

### 2.2 成本突变检查（原则 12 平滑过渡）

| 考察项 | 变化 | 判定 |
| - | - | - |

### 2.4 守所系统闭环

- 入狱（证据入看守所）→ 黎明右移 → 0 格出狱（隐藏重置上限）→ 证据回供应堆 → 可再次作案 ✅

## 3. 交叉组合风险（原则 14）

### 3.1 确认超模组合

| # | 组合 | 机制 | 判定 |
| - | - | - | - |
| C1 | 莫里斯 × 市政厅 | 侦查额外 +2 情报返还 → 低情报时侦查净赚 | 🔴 确认超模（r01/r03）→ 建议改市政厅监控效果 |
| C2 | 鬼手 × 压区循环 | 调查 1 行动→2 情报 → 压区提速 2× | 🔴 确认超模（r03 D4） |
| C3 | 疯子 × 上城连环 | 连锁条件易满足 → 6 分/案 | 🔴 确认超模（r03 D5） |
| C4 | 码头 × 布控 | 0 情报花费不受 +2 影响？ | 🟡 待确认规则口径：布控 +2 是"花费 +2"（0+2=2）→ 非盲区，但收益折扣（罪犯多花 2 仍完成作案）不如高情报地点显效 |

### 3.2 码头 × 布控口径确认（r03 D6 澄清）

- 规则书 §4.2：布控 = 罪犯计算该地点的**作案花费时 +2**。
- 作案花费 = 地点当前情报值（动态）+ 效果加值（布控/设伏/码头-1）。
- 码头"隐秘卸货" = 作案花费 -1（最低 0）。
- 推导：**先减后加** → 码头情报 1：1-1+2=2；码头情报 2：2-1+2=3 → **无盲区**，布控依然 +2 生效。
- r03 中"0 花费不受 +2 影响"的担忧**不成立**（加值在 0 基础上仍 +2）。→ 码头不值得作为布控盲区修复，但**需在 FAQ 明确运算顺序**（先减后加：效果加值在 -1 后计算，最低于 0 后仍可被 +2 抬高）。

### 3.3 新增发现：港口 × 压区协同

- 港口"走私通道"（➡️ 花行动移证据到下城）→ 罪犯可将危害最大的证据移离核心区 → 降低被侦查风险。
- 但走私通道需**花 1 行动**，与压区/作案抢行动 → 机会成本高 → 🟢 实际协同一般，不作为超模处理。

### 3.4 新增发现：蓄意伤害组合

- 铁拳"暴力催收"（弃对手手牌）可弃警长手牌 → 警长依赖策略牌提速（鲍默尔/莫里斯） → 铁拳对超模警长有弱克制 ✓
- 幽灵"华丽骗术"剥夺警长情报 → 对侦查链有压制 ✓
- 这些克制关系**不足以**抵消"超模警长 vs 弱势罪犯"（1.2 节），但缓解了部分极端。

## 4. 策略收敛检查（原则 15）

### 4.1 罪犯收敛判定

| 策略 | 0 能力效率 | 是否最优 | 收敛判定 |
| - | - | - | - |
| 核心压区作案 | 1.5 分/轮 | ✅ 全局最优 | **所有罪犯理性涌向核心**（8/8 角色中 6 个核心最优） |
| 上城作案 | 1.0-1.33 | 仅等级 3-4 | 屠夫/疯子专属 |
| 下城避难 | 1.0 | 低风险 | 压制期过渡 |

**判定**：🔴 **收敛风险高**。3 罪犯争抢 6 张核心地点（其中高价值 4 分情报的港口/火车站/红灯区 3 张）→ 证据密度高 → 警长侦查收益高 → **反而助长警长抓捕链** → 形成"罪犯全压核心 ↔ 警长在核心捞证据"的高密度对抗。虽然对抗激烈，但**策略单一**（缺乏"分兵下城/上城"的动机）。

### 4.2 警长收敛判定

- 警长最优 = 在罪犯压区的地点侦查→抓捕（0 能力 1.5 分/轮）。鲍默尔/莫里斯进一步强化该路线。
- **判定**：🟡 中收敛——警长的路线本质上绑定罪犯行为（罪犯压哪警长抓哪），策略弹性有限，但作为 1v3 的"反应方"可接受。

### 4.3 反收敛机制缺口

- 当前无机制鼓励"分散作案"：
  - 核心区无拥挤惩罚（同地点多证据无减值）
  - 下城/上城无奖励提升（影响值低/首次压降长）
  - 超额只在"≥ 犯罪等级"时 +1，等级 1-2 在核心全超额、去下城/上城反而少超额 → **系统性地惩罚分散**
- **建议**（供 r05 评估）：
  1. 引入"独占地盘奖励"：若某地点该轮只有你的证据，作案额外 +1（分散动机）
  2. 或提高上城对低等级的超额（等级 1 在上城影响 3 ≥ 1 已超额，但轮次效率仍低）→ 需同时解决首次压降成本
  3. 或核心拥堵惩罚：同一地点的证据 ≥2 时，警长在该地点侦查 -1 情报成本（鼓励压区分散）
