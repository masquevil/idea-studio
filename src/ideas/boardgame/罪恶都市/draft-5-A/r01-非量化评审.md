## 1. 规则书逻辑与一致性问题

### 1.1 🔴 行动总数矛盾（§4.2）

**位置**：`01-规则书初稿.md` §4.2 引言

> "游戏中共有 **11 种**行动"

但实际列出的行动为 **12 种**：

| 分组 | 行动 |
| - | - |
| 通用（3） | 调查、摸牌、出牌 |
| 警长（3） | 侦查、布控、抓捕 |
| 罪犯（2） | 隐藏、作案 |
| 超级英雄（2） | 登场、制裁 |
| 受害者（2） | 追偿、爆料 |

**问题**：3+3+2+2+2 = 12，与"11 种"矛盾。
**建议**：改为"12 种"。

### 1.2 🟡 布控免费触发的表述不一致（§4.2 vs §6.2）

- §4.2：布控"若当前版图上存在**属于角色**的'证据 Token'，可改为不花费行动（每回合限 1 次）"
- §6.2：布控免费条件"若当前版图上存在**属于其它角色**的'证据 Token'"
- §6.2 补充："'迷雾 Token'不属于任何角色，因此不能触发免费布控"

**问题**：两处主语不同（"属于角色"＝含自己？"属于其它角色"＝不含自己）。若警长自己也是角色，§4.2 的表述可被读成"自己的'证据 Token'也能触发免费布控"（虽然警长没有证据，实际无影响，但表述应统一）。
**建议**：统一为 §6.2 的"属于其它角色"，并在 §4.2 同步。

### 1.3 🟡 抓捕情报补差不足时的处理未定义（§6.2）

**位置**：`01-规则书初稿.md` §6.2 抓捕

> "若 X < 该罪犯的当前隐藏值：每相差 1 点，额外花费 1 个'情报 Token'"

**边界**：若警长当前"情报 Token"不足以支付补差，能否执行抓捕？能否只移入部分"证据 Token"使 X 达标？

- 现有"花费与效果分离"原则（§4.3）说明费用先付、效果后执行，但**未定义费用不足时的处置**（不能执行？还是允许强行执行但不享受补差？）。
- 同理"制裁"（费用 = 隐藏值 + 持证数）与"登场"（费用 = 地点情报值）也面临同一边界。

**建议**：在规则书正文（§4.3 花费与效果）或 FAQ 补一条统一规则："若无法支付全部费用，该行动不能执行"。此为**通用规则**，不放卡面。

### 1.4 🟡 出狱后隐藏值状态无明确表述（§7 看守所）

**推进 13 已删除"出狱重置"机制**，但当前规则书**没有任何文字说明出狱后隐藏值如何处理**：

- §4.6 隐藏值"被捕时不变"——仅说明被捕瞬间不变；
- §5.5④ 出狱成功 → 释放 → 返回角色供应堆——未写隐藏值后续。

**边界**：罪犯入狱数轮后出狱，隐藏值保留入狱前读数（可能很高，因为补给阶段回复隐藏值的规则在看守所内不生效？——看守所内"不能进行其他任何行动"，但补给阶段回复隐藏值是**自动效果**还是**行动**？§7.1 关押"仅能触发本地点上的能力，不能触发角色卡……也不能进行其他任何行动"。补给阶段回复属于"回合流程"而非"行动"，**但角色卡技能"隐藏狩猎"（疯子）的补给回复被关押禁止吗**？："不能触发角色卡或其他任何地点上的能力"——疯子补给回复量 2 点是角色卡上的**技能**（被动），看守所内是否生效？按关押文字"不能触发角色卡上的能力" → **不生效**。但基础隐藏值回复（§5.4②"若为罪犯：隐藏值 +1"）是回合流程不是角色卡能力 → **生效**。

- 由此推演：罪犯入狱后，每轮补给阶段隐藏值 +1，持续增长（只要不达上限）。出狱后带一个较高隐藏值回归。

**建议**：

1. 明确写"出狱后隐藏值保持当前值不变"（与删重置机制一致）；
2. FAQ 补一条：看守所内补给阶段的隐藏值回复是否生效 → **生效**（罪犯基础回复是回合流程）；角色技能附加回复（如疯子的 +2）**不生效**（被关押禁止角色卡能力）。
3. 疯子入狱期间的隐藏值增长值得注意：上限 2 → 入狱 1 轮就回到上限 2，出狱自带高隐藏防御。是否符合"高风险角色被捕损失大"的定位？需在 r03 审视。

### 1.5 🟡 追偿黎明结算的多个未定义点（§5.5② / §6.5）

**问题 A — 结算顺序**：同一黎明阶段存在多个"混乱 Token"（多名受害者、或同一受害者对 2 名角色追偿）时，逐个翻开的顺序**未定义**。若两名受害者互相给对方放了"混乱 Token"，结算顺序会影响谁能先夺分、谁被夺。

**问题 B — "得分"口径**：追偿检查"从放置至黎明收回期间获得分数 ≥ 2（含黎明阶段的和平奖励）"。该分数是否包含**本黎明阶段被其他追偿扣掉的分数**？若受害者 A 对 B 追偿、B 对 C 追偿，结算顺序不同会导致 B 的"得分"读数不同（若 B 在结算前被 A 扣 1 分，其黎明得分是否仍按"获得分数"计还是"净变化"计）。

**建议**：

- 追偿判定按"放置至黎明收回期间**获得的分数**（含和平奖励），不扣除被追偿的分数"——即只看正向获得；
- 多"混乱 Token"的翻面顺序：按当前回合顺序（从受害者起始玩家顺次），同一受害者的多个 Token 由该受害者自行决定顺序。
- 以上归口规则书正文（§5.5②）或 FAQ，不写卡面。

### 1.6 🟡 爆料翻面时机与重大行动被取消的顺序（§6.5 爆料）

**位置**：`01-规则书初稿.md` §6.5 爆料持续能力

> "↩️ '混乱 Token'所在的地点被其它角色的重大行动选择成为目标时：你可以翻开并收回该'混乱 Token'，若为阳面，你 +1 分"

**边界**：

1. **翻面时点**：是"选择成为目标时"立即翻面得分，还是"重大行动结算成功时"才翻面？若选目标时即得分，但该行动随后被「不在场证明」打断而效果失效，受害者的分已到手——是否合理？
2. **地点情报值修正的存续**：爆料放在地点上时"其它角色计算这些地点的情报值时 +1"。重大行动的花费若按 +1 修正计算后，受害者在**结算中途**翻开收回了"混乱 Token"——该 +1 修正在本次行动中是否仍有效（先看修正后翻面，还是先翻面后费用变成未修正）？

**建议**：明确为"该重大行动**成功执行**（费用已支付）后、效果结算前"翻开；翻回不影响本次已按修正计算的花费。归口 FAQ。

### 1.7 🟡 "混乱 Token"翻面随机性的体验问题（§6.5）

**现状**：「追偿」「爆料」放置时背面朝上，黎明随机翻面（一阴一阳）。存在两种体验风险：

1. **随机落空**：受害者投入 1 行动 + 2 情报进行追偿，若 2 枚均为阴面且无「门路」技能 → 完全落空（且已消耗重大名额）。
2. **对局信息不可控**：受害者无法通过操作提高翻面成功率，纯靠概率。

**建议**：评估是否引入"可控翻面"成本（如"追偿时可花费 1 情报改为将 1 枚'混乱 Token'翻为阳面"），或在 r03/r04 量化受害者的期望收益后决定。当前先记录为待定项，不改机制。

### 1.8 🟡 「大计划」延时效果的触发次数未定义（04-策略牌设计 #17）

**位置**：`04-策略牌设计.md` §4 #17

> "**⏳ 延时**。当你获得分数时：本次额外 +1 分"

**问题 A — 触发次数**：

- 读法 1："当你获得分数时"为持续条件 → **每次得分都 +1**。一场游戏得分 6-10 次 → 总收益 +6~10 分，**严重超模**；
- 读法 2：限一次 → 应写"下一次获得分数时额外 +1 分"即可，但当前文字不是这个意思。

**问题 B — 与多段得分动作的交互**：英雄"制裁"一次性获得 X 分（等差数列），"本次"指整次动作还是每 1 分？若按"每次得分事件"则可叠加在单次制裁上。

**建议**：若设计意图是"单次延时收益"，改文字为"下一次获得分数时将本次得分额外 +1 分，然后弃置此牌"（明确一次性）；若意图是收益随局累积则需大幅削弱。**当前读法 1 会直接破坏平衡**，倾向于一次性 +1。此条进入 r05 必须处理。

### 1.9 🟡 疯子「制造恐慌」在证据耗尽时的执行未定义（02-角色设计 罪犯4）

**位置**：`02-角色设计.md` "疯子"莱利

> "制造恐慌：➡️ 花费 X 个'情报 Token'（X = 版图上你的'证据 Token'数量），选择 1 个地点，在该地点放置 1 个你的'证据 Token'"

**边界**：当角色供应堆无可用"证据 Token"（5 枚全在版图）时，此行动能否执行？普通"作案"在此情形下改为移动 1 枚（§4.5 溢出），但"制造恐慌"没有对应说明。

**建议**：FAQ 或正文补："若角色供应堆无可用'证据 Token'，改为移动版图上 1 枚到目标地点"（与作案溢出同规则）。

### 1.10 🟡 5-7 人局回合顺序表述可读性（§5.4）

**现状**：

> "回合顺序：受害者 → 警长 → 罪犯 → 超级英雄……（4 人局为 1 警长 + 3 罪犯，实际顺序为警长 → 各罪犯）"

与 §3.3 ④"无受害者局由警长作为每轮起始玩家；有受害者局由受害者作为起始玩家"配合才完整。初次阅读易误以为受害者永远排第一（实际 4 人局无受害者）。

**建议**：改为"有受害者局：受害者 → 警长 → 罪犯 → 超级英雄；无受害者局：警长 → 罪犯"两行分写。

### 1.11 完整性核对结论

已归口/已覆盖的边界（评审确认无缺口）：

- ✅ Q1~Q12 覆盖：调查/作案 0 情报、多罪犯证据共存、越狱时警长持证、布控临时性、牌堆循环、延时牌去处、看守所能力、情报截获 0 值、情报值修正叠加等。

## 2. 角色定位与技能设计

### 2.1 🟡 幽灵「华丽骗术」与重大名额的冲突（02 罪犯 2A）

- **效果**：➡️ 重大。花 1 情报得 2 情报（净 +1），占 1 行动 + 本回合重大名额。
- **机会成本**：用了它本回合就不能"作案"（重大）。作案才是得分 KSA。
- **结论**：净 +1 情报 ≈ 一次"调查"（1 行动 → 1 情报 + 压 1 情报值）的输出，但调查还能压情报值。华丽骗术在正常蓄力局中**收益不优于调查且占用重大名额**，仅在没有可用调查地点（版图情报值普遍为 0）时才显价值——触发场景极窄。**偏弱**。

### 2.2 🟡 毒蛇「地下网络」触发条件苛刻（02 罪犯 2B）

- **效果**：若你的"情报 Token"为 0，补给阶段额外 +1。
- **问题**：理性罪犯不会让自己情报归零（归零 = 无法调查/布控应对），归零通常发生在"压 0 作案"的临界点。触发率低、且收益（1 情报）小。
- **暗度陈仓**（回收证据）：与作案抢重大名额，仅在"证据即将被警长侦查"时保命用，频率低。

### 2.3 🟡 双面人「金融犯罪」的效率（02 罪犯 3A）

- **效果**：➡️➡️ 重大。花 3 情报得 2 分，每局限 1 次。
- **对比**：等级 3 罪犯一次"作案"在核心区（影响 2+匹配 1）是 3 分，成本（压 0 后 0~1 情报 + 2 行动）。金融犯罪 3 情报 + 2 行动换 2 分，**效率明显低于作案**。
- **但价值在于"无版图依赖"**：当所有匹配地点被布控/设伏封锁时，金融犯罪是稳定保底。定位可接受，但作为"每局限 1 次"的高阶技能略显低效。可延后。

### 2.4 🟡 铁腕「铁腕执法」对高等级罪犯失效（02 警长 A）

- **效果**：抓捕隐藏值 ≤ 1 的罪犯额外 +1。
- **问题**：等级 3-4 罪犯常态隐藏值 2-3（上限 = 等级），除非被调查压到 ≤1 否则不触发。而等级 3-4 抓捕本身已得 3-4 分。**该技能实际利好"抓低等级罪犯"**，与"风险越高回报越高"梯度（应鼓励抓高等级）略冲突——抓等级 1（1 分）＋铁腕 +1 分＝2 分，接近抓等级 2 的 3 分。

### 2.5 🟡 智囊「战术分析」的时机与强度（02 警长 C）

- **效果**：⚡️ 查看 1 名角色手牌，可打出其中 1 张（视为你打出，需满足打出条件并支付对应行动力）。
- **问题 A（时机）**：⚡️ 任意时机？若在**其他玩家回合**打出目标手牌中的"快速"牌（无需行动），等于智囊能在全场任意时点借牌干扰——强度很高且文字需明确是否限自己回合。
- **问题 B（手牌来源）**："可打出其中 1 张"——该牌从对方手里打出，目标角色失去该牌（相当于被弃置+被你使用）。对目标角色的手牌是损失。反复对同一目标使用会显著压制其资源。
- **建议**：明确"仅在你的回合中"（与现行其他警长 ⚡️ 一致），避免跨回合操作复杂度。

### 2.6 角色技能整体观察

- 罪犯技能整体围绕"成本端/风险端"发力，与阵营设计原则一致 ✅。
- 英雄「越权执法」是 ⚡️ 免费移证入狱 + 1 分，每回合限 1 次——不占重大、不占行动，**频率高**，断言其强度需在 r03 量化（花 = 目标隐藏值情报，等级 2-3 罪犯隐藏 2-3 → 每次 2-3 情报换 1 分 + 剥夺 1 证据）。
- 受害者「门路」显著缓解"混乱 Token"随机翻面的落空体验 ✅（阴面也能触发）。

## 3. 策略牌设计

### 3.1 🔴 大计划：见 1.8，触发次数未定义（最高优先）

### 3.2 🟡 「不在场证明」对独占型 KSA 的打断强度（04 #18）

- **效果**：任意角色执行重大动作时弃 1 手牌使效果失效（花费不退）。
- **仅 1 张**。对警长抓捕（2 行动 + 情报）是毁灭性打断（行动和情报全亏）；对罪犯作案同理。因数量少（1 张）不构成普遍威胁，但**谁抽到谁拥有一次"废掉对方一回合"的能力**，方差大。可接受（快速牌投掷型干扰），标记为测试重点观察项。

### 3.3 🟡 「证据误导」的改选目标边界（04 #11）

- 警长侦查获得证据时，打出者可改选"相邻地点上的另一个证据"。
- **未定义**：若"相邻地点"没有其他"证据 Token"而只是"迷雾 Token"？迷雾被视为证据 Token → 应可改选迷雾。文字"另一个'证据 Token'"包含迷雾（迷雾视为证据）？建议 FAQ 补：改选目标可包含"迷雾 Token"。

## 4. 游戏节奏与上手难度

### 4.1 🟡 2-3 人局「和平奖励」实际可达性存疑（规则书 §5.5①）

- 2 人局每轮迷雾阶段放 2 枚"迷雾 Token"，3 人局放 1 枚；"迷雾 Token"视为"证据 Token"计入版图。
- **和平奖励条件**：版图上无任何"证据 Token"或"迷雾 Token"。
- **推演**：迷雾每轮新增（2 人局 2 枚/轮），警长每轮最多清 1 枚迷雾（1 次抓捕 = 2 行动独占）。**迷雾净增长**，版图迷雾长期存在 → 和平奖励在 2-3 人局**几乎不可达成**。
- **与设计意图的冲突**：迷雾的设计意图是"消耗警长侦查资源、放慢抓捕节奏"；但副作用是**彻底掐死了警长在 2-3 人局的被动得分源**（和平奖励），2 人局警长只能靠抓捕得分。
- **"迷雾 Token"数量（4 枚）上限**：若 4 枚全在版图，迷雾阶段"改为移动版图上已有的迷雾 Token"——所以迷雾不会无限涨，稳定在 4 枚内。但即便如此，4 枚迷雾在 9 张地点版图上，警长清不完（每轮最多 1 枚，还有 2 枚新生）。
- **建议**：评估 2-3 人局和平奖励是否应将"迷雾 Token"排除出判定（如"版图上无任何'证据 Token'（迷雾 Token 不计入）"），否则该得分源在迷雾局形同虚设。**此条需用户确认设计意图**。

### 4.2 🟡 看守所内"放风"与"越狱"的资源缺口

- 看守所内罪犯每轮只能：放风（2 行动 + 弃 1 牌 → 1 情报）或越狱（每格 2 情报 + 弃 1 牌）。
- 放风 1 情报 vs 越狱每格 2 情报：罪犯靠放风攒越狱资本，**每轮净 +1 情报，攒 2 情报需 2 轮**，同时还要弃牌（补给阶段只能摸 1 张，弃牌来源有限）。
- **节奏估算**：入狱证据在犯罪等级格（如等级 3 → 格 3），黎明每轮向左 1 格 = 3 轮自动出狱；越狱加速需 3 格 × 2 情报 = 6 情报 + 弃 3 牌。手动越狱的成本（6 情报 + 3 牌）明显高于等自动出狱（3 轮）的机会成本。**越狱在多数情况不如等待**，仅"黎明移动会让证据返回供应堆、而罪犯想拿到 +1 分"时才值得。可接受但需确认越狱的价值定位。
