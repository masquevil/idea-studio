# r01 · 非量化评审（第六轮）

> 评审范围：规则书逻辑漏洞、规则矛盾、描述歧义；角色定位与技能设计；策略牌平衡与趣味；游戏节奏与上手难度；规则完整性（边界情况归口）。
> 本评审完全基于当前 draft-5-A 文档内容，不参考历史评审记录。
> 优先级：🔴 高（严重影响体验/平衡，必须在当前阶段修复）｜🟡 中（潜在问题，建议当前阶段修复或列入测试观察）｜🟢 低（可优化项）

## 0. 核心规则理解核对

先通读规则书后的理解自检（评审基准，确认后续审查建立在正确理解上）：

| 维度 | 复述 | 与文档一致性 |
| - | - | - |
| 能力类型 | 被动（无图标，常驻）／↩️ 反应（满足条件触发，不耗行动）／⚡️ 免费（任意时机，不耗行动）／➡️ 行动（耗 1 行动） | ✅ |

## 1. 🔴 规则书逻辑漏洞与规则矛盾

### 1.1 【重大漏洞】英雄持有"证据 Token"的循环缺口（无合法出口）

- **位置**：规则书 §4.5 证据循环、§6.4 制裁
- **问题**：规则书 §4.5 定义的证据循环为「角色供应堆 → 作案（版图）→ 侦查（警长持有）→ 抓捕（看守所）→ 出狱（角色供应堆）」。英雄「制裁」动作从版图获得证据并"放在你面前，暂时持有"，但**没有任何规则定义英雄持有的证据如何返回循环**：
  - 警长侦查只能从"地点"获得证据（不能从英雄手里拿）
  - 英雄自身没有"抓捕"动作
  - 证据若永远在英雄手上 → 该罪犯的角色供应堆永久少 1 个证据 → 多次被制裁后罪犯作案能力被饿死；同时证据在英雄手上又**不计入版图**（影响警长无证据奖励判定）。
- **影响**：5-7 人局证据循环断链。英雄持续制裁可永久性削减某罪犯的资源上限。
- **归口**：规则书 §4.5 或 §6.4（正文补充），不得写入制裁卡面。
- **建议方向**：定义英雄持有证据的处置时机（如：黎明阶段英雄将持有的全部"证据 Token"归还对应罪犯的**角色供应堆**，或置于版图原位）。建议归还角色供应堆——使英雄制裁效果接近"清空罪证"，与"英雄是私刑者"的定位一致，且闭环清晰。

### 1.2 【规则矛盾】隐藏值补给回复未在 §5.4 补给阶段体现

- **位置**：规则书 §4.6 vs §5.4 ②
- **问题**：§4.6 写明隐藏值提高方式之一为"**每回合补给阶段自动回复 1**"，但 §5.4 ② 补给阶段只写"摸 1 张策略牌"，未包含隐藏值回复。实体游玩时该条极容易被漏执行。
- **归口**：规则书 §5.4 ② 补给阶段。
- **建议**：在补给阶段步骤中补写"若为罪犯：隐藏值 +1（不超过角色卡上限）"。

### 1.3 【规则矛盾】爆料的"混乱 Token"黎明收回未列入 §5.5

- **位置**：规则书 §6.5 爆料 vs §5.5 黎明阶段
- **问题**：爆料写明"黎明阶段收回（顺序见 §5.5②）"，但 §5.5② 只写"翻开受害者的混乱 Token 结算追偿（检查对应角色本轮得分 ≥ 2）"，**没有列出爆料地点上混乱 Token 的收回步骤**。爆料的混乱 Token 在黎明何时机收回、是否与追偿的翻开同一步骤，规则缺失。
- **归口**：规则书 §5.5②（明确"② 翻开受害者的混乱 Token：结算「追偿」（对应角色面前）并收回所有被翻开的混乱 Token；同时收回爆料放置在地点上的混乱 Token"）。

### 1.4 【规则矛盾】爆料的 +1 情报修正未限定影响范围

- **位置**：规则书 §6.5 爆料 vs §4.2 布控
- **问题**：布控明确"罪犯计算该地点的作案花费时 +2（**不影响该地点情报值本身，也不影响警长侦查等参考情报值的行动**）"。爆料只写"这些地点的情报值在计算时 +1（可与布控/设伏叠加）"——**未限定影响哪些计算**。按字面，爆料会影响侦查花费、制裁花费、登场花费等一切"参考该地点情报值"的行动，而非仅限罪犯作案。
- **影响**：受害者爆料可变相推高警长侦查/英雄制裁成本，使受害者拥有超预期的跨方压制能力；同时也使"算不算叠加上限"（若多个 +修正叠加）不明确。
- **归口**：规则书 §6.5 爆料（明确"该地点情报值的修正仅影响**罪犯计算作案花费**，不影响警长侦查、英雄制裁等行动"或按设计意图明确全范围）。

### 1.5 【规则矛盾】「裁决者」越权执法移入"1 区域" vs 看守所"犯罪等级对应区域"

- **位置**：02-角色设计.md 英雄 C「越权执法」 vs 规则书 §7.1 入狱
- **问题**：「入狱」强制能力规定证据放入看守所时"放置到其所属角色犯罪等级对应的数字区域"；「越权执法」则写"将其一个版图上的证据 Token 移入看守所的 **1 区域**"。若按字面固定放 1 区域，则同等犯罪等级证据存在两套放置规则；若为设计意图（越权执法固定轻判 1 轮），需显式豁免。
- **归口**：角色卡（越权执法可写"移入看守所的 1 区域（不受入狱的犯罪等级区域规则影响）"）或规则书正文。
- **建议**：确认设计意图。若为固定轻判，建议明确豁免表述，避免玩家按入狱规则放错区域。

### 1.6 【描述矛盾】「疯子」隐藏狩猎"每回合自动回复变为 2 点"表述歧义

- **位置**：02-角色设计.md 罪犯 4「隐藏狩猎」
- **问题**：规则书标准回复为每回合补给阶段 +1；疯子写"每回合自动回复变为 2 点"。两种读法：①每回合回复量变为 2（补给阶段 +2）；②每回合回复**上限**变为 2（即隐藏值上限 2，与前半句"上限为 2"重复）。歧义会导致实体游玩时规则解释冲突。
- **归口**：角色卡 + 规则书 §4.6（若存在回复量特例需在正文定义）。
- **建议**：统一表述为"你的隐藏值上限为 2；每回合补给阶段回复量改为 2 点"。若设计意图是回复量 2，需确认其与上限 2 的交互（0→2 一回合回满）。

## 2. 🟡 描述歧义与图标使用

### 2.1 「铁腕」雷霆行动图标应为 ⚡️ 而非 ↩️

- **位置**：02-角色设计.md 警长 A
- **问题**：「雷霆行动」类型标为 ↩️（反应触发），但效果是"在你的回合中……本回合进行额外 1 个行动（每回合限 1 次）"——这是**主动开启**能力，不是"满足特定条件时触发"的反应。按写作规范 §2.1.1，应归为 ⚡️ 免费触发能力。

### 2.2 制裁"复利累计"措辞不准确

- **位置**：规则书 §6.4 制裁、§8.2 得分途径
- **问题**：写"获得 X 分（X = 你当前拥有的证据 Token 数量，含本次获得的，按 1+2+3+… 复利累计）"。实际得分为等差数列（1+2+3+…+n），不是复利（复利指利滚利）。措辞误导，建议改为"等差数列累计"或直接删去括号内说明（卡面只写"获得 X 分（X＝你持有的证据数）"即可）。

### 2.3 「掮客」门路效果表述歧义

- **位置**：02-角色设计.md 受害者 C「门路」
- **问题**："你的追偿/爆料翻开为阴面时，若满足阳面得分的条件，你 +1 分"。
  - 追偿阳面条件＝"该角色本回合得分 ≥ 2"；爆料阳面条件＝"该地点被其它角色选择为目标时……翻开"。对爆料而言，翻开即发生（被选为目标时），"满足阳面条件"对所有翻开都成立——按字面门路会让爆料几乎总是 +1 分（阴阳皆可），与"阳/阴面"设计的概率性意图冲突。
- **归口**：角色卡 + FAQ（若定义"爆料满足阳面条件"的具体含义）。

### 2.4 「夜枭」狩猎标记表述

- **位置**：02-角色设计.md 英雄 A
- **问题**："目标罪犯的当前隐藏值视为 -1（最低 0）来计算花费"——"隐藏值视为 -1"易被误读为把罪犯隐藏值减 1（影响抓捕判定），实际意图应是**制裁花费计算时按（隐藏值 − 1）计**。建议改为"进行制裁动作时，花费计算中的目标隐藏值减少 1（最低 0）"。

### 2.5 「金库保险」「紧急躲避」的"目标"范围未定义

- **位置**：04-策略牌设计.md #09、#12
- **问题**：两张牌都以"被选为……目标"为触发/作用条件，但未定义"哪些效果算指定角色为目标"：
  - 抓捕/制裁/登场是"行动"，算不算"技能或卡牌效果的目标"？
  - 「尾随跟踪」「暗中观察」的"查看"算不算指定目标？
  - 「见风使舵」是反应能力而非指定目标，是否可被金库保险抵挡？
- **影响**：玩家对两张牌的实际防御范围无法预判，实战易起争议。
- **归口**：FAQ（统一给出"目标"判定清单：行动攻击类不算、查看类算、指定角色/地点的策略牌效果算）。

### 2.6 「通风报信」受益对象与主语不清

- **位置**：04-策略牌设计.md #14
- **问题**："当警长执行抓捕动作结算后，弃置 1 张手牌：弃置其 2 个情报 Token，或令其获得 2 个情报 Token"——"弃置其 2 个情报"的"其"指警长，"令其获得"也是警长，二者为打出者二选一。但"弃置 1 张手牌"是谁弃（打出者）、弃置的对象手牌还是警长手牌，字面不清。建议改为"打出者弃置 1 张手牌，然后选择：目标警长失去 2 个情报 Token，或目标警长获得 2 个情报 Token"。

### 2.7 "本轮得分"时间范围未定义

- **位置**：规则书 §6.5 追偿（黎明结算"该角色本轮得分 ≥ 2"）
- **问题**："本轮"起止未定义。混乱 Token 在夜晚阶段放置、黎明② 结算，警长黎明① +2 已写明计入——但夜晚阶段的得分、傍晚阶段的得分是否计入？建议 FAQ 定义："本轮＝从本轮傍晚阶段开始至黎明阶段结束"。

### 2.8 「智囊」战术分析打出他人延时牌的去向与受益者

- **位置**：02-角色设计.md 警长 C「战术分析」
- **问题**："查看一名角色的手牌，你可以打出其中的 1 张策略牌（该牌由你打出……）"。若打出的牌为**延时牌**：正面放置到谁的区域？延时效果结算时受益/触发对象如何判定？若打出「不在场证明」（抵消警长抓捕）这类对象敏感牌，语意混乱。
- **归口**：FAQ。
- **建议**：最简单方案是战术分析只能打出**非延时**牌；或定义"延时牌打出后放在原持有者区域，延时效果由原持有者结算"。

## 3. 🟡 边界情况缺口（归口 FAQ / 规则书正文）

以下边界情况当前规则未覆盖。按 §1.7 原则，**不写入卡面/技能描述**，统一归口 FAQ 或规则书正文。

### 3.1 追偿：2 枚"混乱 Token"可放置的对象限制

- 追偿写"分别放在 2 名角色面前"，未限定"2 名**不同**角色"且未排除**自己**。若可放自己面前，黎明结算"令其 -1、你 +1"会变成自己 -1 再 +1（净 0）逻辑冲突。
- **建议 FAQ**：必须为 2 名不同角色，且不能是自己。

### 3.2 追偿：目标角色分数扣减下限

- "令其 -1 分"——若目标只有 0 分，是否扣成负分？还是受害者仍 +1？
- **建议 FAQ**：分数最低为 0；即使目标实际扣不到 1 分，受害者仍获得 +1 分（扣分与夺分分离判定），避免受害者因目标低分而收益落空。

### 3.3 信息垄断：调查后地点情报为 0 时是否可响应

- 「掮客」信息垄断"每当其他角色进行调查动作时……从该调查地点获得 1 个情报 Token"。若调查者拿走的正是该地点最后一个情报（地点情报变为 0），掮客是否仍可花费 1 情报并取空？
- **建议 FAQ**：响应时该地点仍须有情报 Token（与"调查"一致，情报 0 无法获得）；若情报为 0 则不能响应。

### 3.4 地点情报 Token 是否可超过初始情报值

- 「情报干扰」（放置 2 情报）、「智囊」布局预判（相邻地点 +1 情报）、火车站明文"不超过初始情报值"——暗示存在超上限途径，但未统一规定。若可无限堆叠，叠加爆料 +1 后会让某地点作案成本失控。
- **建议 FAQ/正文**：任何"在地点放置/增加情报 Token"的效果均不超过该地点的**初始情报值**。

### 3.5 「栽赃陷害」能否移动"迷雾 Token"

- 迷雾 Token"视为证据 Token"处理，但"栽赃陷害"针对"1 个证据 Token"——是否包含迷雾？若可移动迷雾，会出现把迷雾搬到警长刚侦查过的地方等玩法，机制未被考虑。
- **建议 FAQ**：迷雾 Token 不可被"栽赃陷害"移动（迷雾不属于任何罪犯，栽赃陷害语义为陷害特定罪犯）。

### 3.6 抓捕被「见风使舵」失效后，警长持有证据的去向

- 「老鼠」见风使舵"使抓捕效果失效"——警长已持有（侦查所得）的该罪犯证据如何处置？保持警长手中（仅行动效果无效）？还是返回？
- **建议 FAQ**：效果仅取消"移入看守所 + 得分"；警长持有的证据保留在警长手中（花费不退），警长仍可在后续回合再次抓捕。

### 3.7 「英雄 Token」在看守所期间与"看守所禁地"的交互

- 「裁决者」从重判决允许"登场动作"以看守所为目标，但看守所"禁地"规定"不能被选为……任何行动的目标"。需显式豁免（从重判决可突破禁地以看守所为登场目标）。

### 3.8 应急：受害者的混乱 Token 黎明阶段被警长黎明① +2 触发连锁

- 追偿结算时机为黎明②，包含黎明① 得分（已写明）。但若受害者自己在黎明①后（警长+2）才想起未放混乱？——无此情况，混乱 Token 夜晚放置，仅确认结算顺序即可，无需补充。

### 3.9 涉及"事件时机"的定义缺口 —— 制裁与侦查同时参考同一证据时的交互

- 「证据误导」允许警长侦查时改为获得相邻地点的证据——若改选的目标地点同时被英雄「制裁」瞄准（同一轮），先后手判定未定义。建议 FAQ：按回合顺序与响应栈先后处理（主动行动者先结算）。

## 4. 角色设计审查

### 4.1 阵营互动频率总体评价

- 警长↔罪犯的猫鼠互动是核心，链路完整（作案→证据→侦查→抓捕→看守所→越狱/出狱→再作案）。
- 英雄↔罪犯、英雄↔警长的互动依赖"证据 Token"与版图情报，链路过窄且**受 §1.1 循环缺口影响**——英雄制裁若不闭环，其核心互动在长局中会崩坏。
- 受害者的互动是被动的（追偿/爆料依赖他人行动与得分），主动控制感弱。其"混乱 Token 阴阳面"引入随机性，与全游戏"无骰运"的确定性基调（无任何骰子/翻牌判定）不同调——这是否符合设计意图需确认（追偿/爆料的收益完全依赖他人行为 + 随机翻面，玩家难以规划）。

### 4.2 技能定位与趣味性

| 阵营 | 角色 | 定位评价 |
| - | - | - |

### 4.3 非对称阵营补偿观察

- 受害者无基础得分手段，补偿为：追偿/爆料**不额外消耗行动**（1 行动重大，对照其他阵营 2 行动重大）+ 夺分机制。整体方向正确，但追偿的"触发依赖他人本轮得分 ≥2"使受害者收益高度受控于场上节奏，补偿强度中等偏被动。
- 英雄的补偿为制裁复利分（依赖证据密度，且受循环缺口拖累，见 §1.1）。

### 5.2 P1 结论

- 🔴 **「不在场证明」**：3 个非罪犯阵营完全无法利用，违反 P1 核心原则。需重做或改为"抵消针对你的抓捕/制裁/越权执法"（但英雄制裁/越权执法在 5-7 人局才出现，标准局仍无效）。建议改为对"任何针对你的负面效果"生效或重做机制。
- 🟡 **「通风报信」**：警长自用近乎无代价白赚 2 情报，制造阵营间不对称收益，建议限定"若你为警长，只能选择弃置 2 情报（不能获得）"或调整触发对象。
- 🟡 **「设伏」**：对罪犯阵营弱正向，建议为标准局提供替代收益（如罪犯打出时可改选"该地点本轮情报值 -1"——降低自己未来作案成本）。
- 🟡 **「金库保险」「紧急躲避」**：因"目标清单"未定义，实际价值存疑，优先解决 §2.5，再评估强度。

### 5.3 牌库整体评估

- 34 张、三类分布（普通 20 / 快速 9 / 延时 5）合理；效果分类（资源/信息/防御/进攻/得分）比例均衡，无单类型垄断。
- 干扰类中"信息获取"占比不低（尾随跟踪/暗中观察/情报截获/线人报酬/战术分析），信息虽多但**收益反馈弱**（查看 ≠ 资源 ≠ 得分），中局可能出现"信息冗余"感。
- 延时牌 5 张中「设伏」「大计划」「不在场证明」均为强时机牌，节奏偏慢但收益不错——与"延时牌节奏慢"的已知风险（04 §7.3）一致，测试阶段观察使用率。

## 6. 游戏节奏、回合流畅度与上手难度

### 6.1 行动成本结构

- 作案/抓捕/登场/制裁均"**重大 + 额外 1 行动**"＝每回合 2 行动被占满。此结构带来的连锁影响：
  - **策略牌使用率被压缩**：普通牌需 1 行动，重大动作回合无法出普通策略牌（补给摸的牌当轮几乎只能靠快速牌打出）→ 手牌积压 + 修整弃牌频繁 → 玩家"摸牌—出牌"闭环体验弱。
  - 罪犯"调研—作案"链长：压情报（调查×N）→ 作案（占满）→ 被侦查/抓捕——单轮行动选择空间小，策略多体现在"跨轮规划"而非"轮内连招"。
- 这是重大设计的系统性成本，建议 r04 量化后评估是否需要给重大动作"免额外行动"的特例（如受害者已采用 1 行动重大）。

### 6.2 回合流畅度

- 五大子阶段（开始/补给/行动/修整/结束）标准清晰；黎明阶段 8 步偏多但有条理。
- 黎明①无证据奖励 → ②追偿 → ③收警员 → ④看守所移动 → ⑤收英雄 → ⑥黎明效果 → ⑦终局 → ⑧回合+1，顺序自洽（裁决者英雄 Token 在看守所时可正确作用于 ④；⑤ 在其后收回）。

### 6.3 上手难度

- 13 种行动 + 4 阵营 + 34 策略牌 + 24 张角色+地点牌的技能池，规则总量对"轻中策"偏重。建议教学路径：先 4 人局（警长+罪犯，13 行动中的 8 种），扩展阵营（英雄/受害者）作为进阶模块——当前文档结构已支持此教学顺序（§1.3、§5.4），仅需在规则书开头明确"首次游戏仅使用警长与罪犯"的引导提示。

### 6.4 游戏时长

- 12 轮 × 4 人 × 2 行动 + 阶段时间，按 40-60 秒/人/轮估算约 60-90 分钟（4 人局），落在"30-120 分钟"目标内。扩展局（5-7 人）会更长，属可接受范围。
