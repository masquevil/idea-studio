## 1. 角色卡牌格式

所有角色卡牌统一使用以下布局：

```
┌──────────────────────┐
│ 阵营图标 │ 代号        │  ← 阵营色条（警长蓝/罪犯红/英雄紫/受害者绿）
│                       │
│   角色名              │
│   职位                │
│                       │
│  ┌─────────────────┐  │
│  │ 角色插画区域      │  │
│  └─────────────────┘  │
│                       │
│  犯罪等级：★☆☆☆（仅罪犯）│  ← 黑色加粗小字
│  隐藏值上限：3  （仅罪犯）│  ← 仅罪犯卡有
│                       │
│  ── 技能 ──          │
│  [技能1名称]（类型）    │
│  技能效果描述          │
│  [技能2名称]（类型）    │
│  技能效果描述          │
│                       │
│  ── 隐藏值轨道 ──（仅罪犯）│
│  ┌─┬─┬─┬─┬─┬─┐        │
│  │0│1│2│3│4│5│        │  ← 数字格：0-5，共 6 格
│  └─┴─┴─┴─┴─┴─┘        │
│  ▓▓▓ 上限区域（带底色标记）│
│                       │
│  ── 背景故事 ──       │
│  一句话背景描述        │
└──────────────────────┘
```

### 隐藏值轨道说明

- 角色卡最下方印有一行 0-5 的数字小方格，共 6 格
- 其中 0～隐藏值上限 的方格带底色背景（如浅灰色），超出上限的方格无底色
- 玩家使用一个小方块（可从一个"情报 Token"中取一个异色）放在对应数字上，代表当前隐藏值
- 不使用独立骰子

### 技能类型标注

技能分为**持续能力（被动）**和**触发能力**两类。能力图标含义见规则书 §10.3，重大标签含义见 §4.4 和 §10.2。

| 图标/标记 | 类型 |
| - | - |
| 无 | 持续能力（被动） |
| ➡️ | 行动触发能力 |
| ↩️ | 反应触发能力 |
| ⚡️ | 免费触发能力 |

## 6. 角色分配流程

所有阵营的玩家在分配角色时均采用 **"抽2选1"** 方式——从对应阵营的角色池中随机抽取 2 张，选择其中 1 张作为本局角色。

```
标准 4 人局分配：
① 确定配置：1 警长 + 3 罪犯
② 警长玩家从 3 张警长角色中随机抽取 2 张，选择其中 1 张
③ 各罪犯玩家从 8 张罪犯角色中随机抽取 2 张，选择其中 1 张
④ 各玩家获得对应的角色卡、"证据 Token"（仅罪犯）
⑤ 罪犯玩家将一个小方块放在角色卡隐藏值轨道的上限数字上作为初始值
⑥ 所有玩家获得初始资源：1 张策略牌（从公共牌堆摸取）

扩展配置（5-7 人局）补充：
① 超级英雄玩家从 3 张超级英雄角色中随机抽取 2 张，选择其中 1 张
② 受害者玩家从 2 张受害者角色中随机抽取 2 张，选择其中 1 张
③ 超级英雄和受害者的初始资源同样为 1 张策略牌
```

**第二部分 · 设计思路（不进入打印）**

> 以下内容为角色设计的思路说明，供设计迭代与评审参考，不用于制作/打印。

## A. 警长设计思路

警长是 4 人局中唯一的执法者。三个角色分别侧重：

- **正面强攻型**：侦查效率高，适合主动出击
- **防守控制型**：布控能力强，适合区域压制
- **灵活战术型**：策略牌联动强，适合多变战术

## B. 罪犯设计思路

8 个罪犯角色分布在犯罪等级 1-4 之间：

- **犯罪等级 1**（1 个）：街头混混级，风险最低，但上限也低
- **犯罪等级 2**（4 个）：标准罪犯级，大部分角色的基准线
- **犯罪等级 3**（2 个）：重罪犯级，高回报高风险
- **犯罪等级 4**（1 个）：极端重罪犯级，最高回报最高风险

## C. 超级英雄定位

超级英雄是灰色地带的私刑者。他们不在乎法律，只在乎自己心中的正义。他们的所有行动都对警长和罪犯造成负面影响——警长视他们为法外之徒，罪犯视他们为眼中钉。

- 不设专属资源（无义警标记）
- 得分途径来自阻挠双方的私刑行为
- 可使用"情报 Token"执行专属行动

各英雄的干扰设计意图：

| 英雄 | 对警长的伤害 | 对罪犯的伤害 |
| - | - | - |
| 夜枭·铁拳制裁 | 销毁"证据 Token"使警长失去无证据奖励机会 + 抓捕线索减少 | 销毁"证据 Token"意味着犯罪白干 + 犯罪成果被清空 |
| 暗影·情报截获/战术干扰 | 截获情报使警长资源紧张；弃置手牌破坏警长战术 | 弃置关键策略牌或"证据 Token"，破坏作案计划 |
| 裁决者·法律漏洞/越权执法 | 减少警长得分 / 延长的看守所周期使警长已有的抓捕资源"沉淀" | 减少罪犯得分 / 看守所刑期被延长 |

## D. 受害者得分途径

受害者不通过"作案"或"抓捕"得分，而是通过调查曝光和情报交易获得分数。
