## 1. 角色卡牌格式

所有角色卡牌统一使用以下布局：

```
┌──────────────────────┐
│ 阵营图标 │ 代号        │  ← 阵营色条（警长蓝/罪犯红/英雄紫/受害者绿）
│                       │
│   角色名              │
│   职位                │
│                       │
│  ┌─────────────────┐  │
│  │ 角色插画区域      │  │
│  └─────────────────┘  │
│                       │
│  犯罪等级：★☆☆☆（仅罪犯）│  ← 黑色加粗小字
│  隐藏值上限：3  （仅罪犯）│  ← 仅罪犯卡有
│                       │
│  ── 技能 ──          │
│  [技能1名称]（类型）    │
│  技能效果描述          │
│  [技能2名称]（类型）    │
│  技能效果描述          │
│                       │
│  ── 隐藏值轨道 ──（仅罪犯）│
│  ┌─┬─┬─┬─┬─┬─┐        │
│  │0│1│2│3│4│5│        │  ← 数字格：0-5，共 6 格
│  └─┴─┴─┴─┴─┴─┘        │
│  ▓▓▓ 上限区域（带底色标记）│
│                       │
│  ── 背景故事 ──       │
│  一句话背景描述        │
└──────────────────────┘
```

### 隐藏值轨道说明

- 角色卡最下方印有一行 0-5 的数字小方格，共 6 格
- 其中 0～隐藏值上限 的方格带底色背景（如浅灰色），超出上限的方格无底色
- 玩家使用一个小方块（可从一个"情报 Token"中取一个异色）放在对应数字上，代表当前隐藏值
- 不使用独立骰子

### 技能类型标注

技能分为**持续能力（被动）**和**触发能力**两类。能力图标含义见规则书 §10.3，重大标签含义见 §4.4 和 §10.2。

| 图标/标记 | 类型 |
| - | - |
| 无 | 持续能力（被动） |
| ➡️ | 行动触发能力 |
| ↩️ | 反应触发能力 |
| ⚡️ | 免费触发能力 |

## 6. 角色分配流程

所有阵营的玩家在分配角色时均采用 **"抽2选1"** 方式——从对应阵营的角色池中随机抽取 2 张，选择其中 1 张作为本局角色。

```
标准 4 人局分配：
① 确定配置：1 警长 + 3 罪犯
② 警长玩家从 3 张警长角色中随机抽取 2 张，选择其中 1 张
③ 各罪犯玩家从 8 张罪犯角色中随机抽取 2 张，选择其中 1 张
④ 各玩家获得对应的角色卡、"证据 Token"（仅罪犯）
⑤ 罪犯玩家将一个小方块放在角色卡隐藏值轨道的上限数字上作为初始值
⑥ 所有玩家获得初始资源：1 张策略牌（从公共牌堆摸取）

扩展配置（5-7 人局）补充：
① 超级英雄玩家从 3 张超级英雄角色中随机抽取 2 张，选择其中 1 张
② 受害者玩家从 3 张受害者角色中随机抽取 2 张，选择其中 1 张
③ 超级英雄和受害者的初始资源同样为 1 张策略牌
```

## A. 角色设计思路（前置 · 阵营设计原则）

### A.1 得分链对照表

四阵营各有专属得分行动，但投入来源不同。设计角色前先明确各阵营的得分链：

| 阵营 | 专属得分行动 | 得分依赖 |
| - | - | - |
| 警长 | 抓捕（含高效+1）；和平奖励 +1 | 高效得分依赖版图证据 Token（需侦查取证）；和平奖励不依赖证据但低效、且难达成（罪犯作案必留证据） |
| 罪犯 | 作案（影响值 + 匹配+1） | 版图影响值（需压情报降成本）；匹配加分为影响值与犯罪等级相差 ≤ 1 时触发 |
| 超级英雄 | 登场（+X 分，X＝该地点证据数）+ 制裁（持证等差数列） | 版图证据 Token（他人作案产生）＋情报/隐藏值花费 |
| 受害者 | 追偿（夺 1 分）+ 爆料（翻面 1 分） | 他人得分 / 地点被选为目标（外部触发） |

### A.2 四阵营开放设计原则

每个阵营在"还没有具体角色"时，按以下原则设计其角色。原则只划定设计的发力场，不规定具体技能：

**警长**

- 要解决的核心问题：如何平衡"高效得分（依赖证据的抓捕）"与"低效保底（和平奖励）"
- 可发力的开放方向：任何服务于执法得分的机制（加速链路、提高单次收益、开辟其他执法手段）
- 唯一约束：不脱离"执法者靠侦查/抓捕得分"的阵营定位

**罪犯**

- 要解决的核心问题：如何平衡"作案得分"与"暴露被抓"
- 可发力的开放方向：收益端（单次更多分）、成本端（压低作案成本）、风险端（降低暴露与被抓损失）之间自由取舍
- 唯一约束：遵循"风险越高回报越高"的梯度（低等级低风险低回报 → 高等级高风险高回报）。梯度由两个机制共同锚定：**匹配加分**（影响值与犯罪等级相差 ≤ 1 时 +1，锚定收益端）＋**隐藏值上限 = 犯罪等级**（锚定风险端，疯子除外）

**超级英雄**

- 要解决的核心问题：得分筹码来自他人作案产生的证据、以及自己的情报投入，如何稳定取用并滚出分数
- 可发力的开放方向：围绕证据的获取、堆叠、转化来设计（制裁滚雪球、登场占位等）
- 唯一约束：**必须对其他阵营产生同等水平的正/负面影响，不能只帮一边或只害一边**（若未来出现有趣技能也可脱离登场/制裁，暂不设限）

**受害者**

- 要解决的核心问题：得分触发依赖他人得分与地点被选为目标，如何提高触发率与单次收益
- 可发力的开放方向：降低触发门槛、提升单次夺分/翻面收益、借版图布局提高触发机会
- 唯一约束：触发条件必须保持"依赖他人/版图"，不能完全自给自足

## B. 角色技能分析（后置 · 具体角色如何落地思路）

> 每个角色标注"围绕阵营得分链朝哪个方向发力 + 好处/坏处"。超级英雄/受害者额外标注对局影响。

### B.1 警长

| 角色 | 发力方向 | 好处 | 坏处 |
| - | - | - | - |
| 铁腕 | 压低罪犯防御 | 雷霆行动＝弃 1 手牌压目标罪犯 1 隐藏值（配合铁腕执法）；铁腕执法＝专抓低隐藏罪犯 +1 分 | 雷霆行动需弃 1 手牌且不直接得分；铁腕执法依赖调查压低隐藏值 |
| 猎犬 | 降低执法成本 | 追踪直觉＝侦查回扣 1 情报；天罗地网＝低成本布控 | 无爆发手段，得分依赖逐步积累 |

| 铁拳（2） | 干扰压制 | 暴力催收＝弃他人手牌直接干扰；硬汉体质＝越狱 -1 情报 | 干扰不直接得分 |
