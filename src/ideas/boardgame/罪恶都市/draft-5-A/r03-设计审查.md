# r03 · 设计审查

> 根据 r02 的量化基准检查设计质量
> 依据：地点牌设计、角色设计、策略牌设计 + r02 关键发现（零成本作案机制使罪犯得分潜力超出基准）

---

## 1. 地点系统审查

### 1.1 区域梯度

| 区域 | 初始情报 | 影响值 | 收益 | 破解成本 |
| - | - | - | - | - |
| 上城区 | 4~5 | 3~4 | 高（4~5分/次） | 需 4~5 次调查打空 |
| 核心区 | 3~4 | 2~3 | 中（3~4分/次） | 需 3~4 次调查打空 |
| 下城区 | 2~3 | 1~2 | 低（2~3分/次） | 需 2~3 次调查打空 |

**梯度合理**：高回报高破解成本、低回报低破解成本。✅

### 1.2 r02 关键发现的地点层面含义

**零成本作案机制**：地点情报打空后作案免费。r02 推演显示 4 人局第 1 轮就可能打空核心区地点。

**影响**：

- 上城区（情报 4~5）破解成本高，但一旦打空收益也最高（4~5分/次）
- 下城区（情报 2~3）破解快，是"零成本得分"的温床——2~3 次调查即可打空，之后免费得 2~3 分
- **玩家会被高收益+易破解的地点吸引**，上城区的博物馆（情报5/影响4）是终极目标

**风险评估**：🟡 低区域（下城区）可能成为持续零成本得分点。但下城区收益低（1~2分），且警长侦查成本也低，是天然的对抗区域。

### 1.3 特殊地点效果

各地点效果与前几轮评估一致，均在合理范围内。火车站的情报补充是本轮 r02 中提到的"减缓情报归零"机制的现有来源，但力量有限（每轮每地点+1，且限 1 地点）。

## 2. 警长角色审查

### 2.1 铁腕「雷霆行动」

每回合额外 1 行动。结合 r02 的"警长打断能力是关键杠杆"，铁腕的额外行动能加快侦查/抓捕链条，直接强化打断能力。

**评估**：🟡 偏强但方向正确——警长需要这样的效率提升来制衡罪犯的零成本得分。

### 2.2 猎犬「追踪直觉」+「天罗地网」

侦查额外 +1 情报，免费布控。追踪直觉降低侦查的动态成本，对打断节奏有帮助。

**评估**：🟢 合理。

### 2.3 智囊「战术分析」+「布局预判」

布控时相邻地点 +1 情报。布控改动（有证据免费）与布局预判协同良好。

**评估**：🟡 偏弱但信息能力有价值。

### 2.4 警长能力总体评价

r02 显示警长打断能力是关键平衡杠杆。当前 3 个警长角色的能力都对打断有帮助，但强度有限。**铁腕是打断能力最强的（额外行动），可能成为最优选**——这可能导致警长角色选择收敛。

## 3. 罪犯角色审查

### 3.1 各角色评估

| 角色 | 等级 | 能力 | 与零成本机制的关系 |
| - | - | - | - |
| 老鼠 | 1 | 核心区调查不掉隐藏值 | 完美配合核心区零成本循环 |
| 幽灵 | 2 | 1情报换2情报 | 资源型，加速破解情报 |
| 毒蛇 | 2 | 保底情报+回收证据 | 防守型，适应性 |
| 铁拳 | 2 | 抽手牌 | 干扰型，间接压迫 |
| 鬼手 | 2 | 调查双倍情报 | **加速打空地点**，与零成本机制强协同 |
| 双面人 | 3 | 3分爆发 | 直接得分，与零成本叠加 |
| 屠夫 | 3 | 上城区+1分 | 高收益区域强化 |
| 疯子 | 4 | 连环+3 | 版图布局，与地图博弈 |

**关键发现**：**鬼手（调查双倍情报）与零成本机制强协同**——他能更快打空地点，让全队更快进入零成本作案状态。这会使鬼手成为罪犯方的最优选，可能导致罪犯角色选择收敛。

**其他角色**：大部分合理。但需警惕"加速破解情报"类能力（鬼手）与零成本机制的乘数效应。

### 3.2 角色平衡风险

罪犯方可能出现"鬼手最优"的收敛。同时警长方可能出现"铁腕最优"。两边各有一个超强角色，需要通过测试确认是否破坏多样性（评审原则 15）。

## 4. 超级英雄/受害者审查

### 4.1 超级英雄

各角色能力与之前评估一致，均合理。夜枭的销毁证据能力能减少罪犯版图上的证据（间接降低零成本作案的收益）。

### 4.2 受害者

**掮客无直接得分手段**，与 r01 结论一致，🔴 需要修复。

## 6. 非对称阵营补偿

r02 显示：

- 罪犯乐观情景 20~30 分 vs 基准 14-15 分 → **罪犯偏强**
- 警长直接得分 10~14 分，靠抓捕间接价值平衡

**问题**：当前非对称设计下，**罪犯（尤其乐观情景）得分潜力明显高于设计基准**。警长的抓捕若不够及时，无法抑制罪犯的零成本得分。

**结论**：🔴 需要关注。要么削弱罪犯零成本作案的收益，要么强化警长打断能力，或两者结合。

## 7. 总结

| 系统 | 关键发现 | 严重度 |
| - | - | - |
| 地点系统 | 梯度合理，但低区域易形成零成本得分点 | 🟡 |
| 警长角色 | 铁腕偏强；打断能力整体偏弱 | 🟡 |
| 罪犯角色 | **鬼手与零成本机制强协同，可能收敛** | 🟡 |
| 受害者 | 掮客无得分手段 | 🔴 |
| 非对称平衡 | **罪犯乐观得分超出基准，需关注** | 🔴 |
| 策略牌 | 描述问题同前，缺乏零成本抑制手段 | 🟡 |
