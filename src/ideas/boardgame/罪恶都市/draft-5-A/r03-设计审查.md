# 评审③ · 设计审查（第十轮）

> 依据 r02 的 0 能力基准，检查地点/角色/策略牌的设计质量与成本收益。
> 对比基准：罪犯 3 分/次 ≈ 0.88 分/IC；警长 3 分/次 ≈ 0.6 分/IC（加权后对比）。
> 判定：特殊能力效率 ≤ 基础效率（§4.2 原则 4）；无基础得分手段的阵营靠特殊能力补偿（原则 16）。

## 1. 地点/地图系统审查

### 1.1 区域梯度合理性

| 区域 | 参考情报/影响 | 初始情报值 | 影响值 | 匹配加分适配等级 | 梯度判定 |
| - | - | - | - | - | - |
| 上城 | 4/3 | 4-5 | 3-4 | 等级 3-4 | ✅ 高回报高成本 |
| 核心 | 3/2 | 3-4 | 2-3 | 等级 1-3 | ✅ 标准区 |

**结论**：区域梯度与犯罪等级匹配加分（§4.7）吻合，等级 1-2 保底下城/核心、等级 3-4 深耕上城的定位清晰。

## 2. 警长角色审查

> 对比基准：警长 0 能力 ≈ 0.6 分/IC（r02 §3.3），抓捕含 1.33 加权（§3.6 量化规则）。

### 2.1 铁腕「鲍默尔」

| 技能 | 类型 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 雷霆行动 | ⚡️ 回合限一次 | 弃 1 手牌 | 目标罪犯隐藏 -1 | 弃 1 牌 ≈ 0.5-1 行动，压 1 隐藏 ≈ 省警长 1 情报补差 → **合理**，配合铁腕执法 |
| 铁腕执法 | 被动 | 无 | 抓隐藏 ≤1 罪犯 +1 分 | 将单次 3 分 → 4 分，KSA 次数 5→4（接近罪犯 4 分线）→ **合理补强** |

**判定**：铁腕为"低隐藏专精"警长，技能效率 ≈ 1 弃牌 → 1 情报 + 1 分，达标。**强度合理**。

### 2.2 猎犬「莫里斯」

| 技能 | 类型 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 追踪直觉 | ↩️ 侦查时 | 0 / 花 1 情报 | 选项 1：+1 情报；选项 2：+1 证据 +1 分 | 选项 1 侦查回扣（侦查 0 花费时≈净赚 1 情报，1 行动→2 价值）；选项 2 花 1 情报换 1 证+1 分（≈1.6 分当量）→ **效率略高于基础调查**，但限侦查时触发 |
| 天罗地网 | ⚡️ 回合中 | 1 情报/次，无限制 | 任意地放置警员（布控 +2） | 1 情报 ≈ 1 行动，布控本身值 1 行动——**无额外收益但可多次**（r01 §2.5 已注"一轮多放"）。多次使用情报成本线性 → 需看情报流速 |

**判定**：追踪直觉**合理偏优**；天罗地网"次数无限 + 免费布控触发器"组合，在情报充裕时可一轮多放（配合地下酒吧/情报报告）——**潜在风险，建议加"回合限一次"**（已列 r01）。

### 2.3 智囊「温斯洛」

| 技能 | 类型 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 战术分析 | ⚡️ | 0（查看+打出对方牌） | 借用他人手牌 1 张 | 信息 + 免费借牌，回合外触发存疑（r01 §2.1）——修正后为"回合限一次"，收益 = 别人的 1 张牌（≥1 资源）→ **0 成本获取 1 牌，效率超标，但依赖对方手牌质量** |
| 布局预判 | 被动 | 布控时 | 相邻地点 +1 情报 | 免费 +1 情报，白赚 1 资源 → **纯增益**，配合免费布控 |

**判定**：智囊技能**偏强**（0 成本借牌 + 布控免费送情报），但因战术分析被限"你的回合"后频率受控，整体仍在合理上界。**综合三类：铁腕稍强、猎犬合理、智囊上界**——无超模级警长。

## 3. 罪犯角色审查

> 对比基准：罪犯等级 2 核心区 3 分/次、5 次 KSA、9-11 轮（r02 §2）。
> 关键前提：等级 1 在核心区（影响值 2）同样触发匹配加分 → **单次得分与等级 2 相同（3 分）**；等级差异主要体现在隐藏值上限（防御）与入狱格数。

### 3.1 等级 1 · 老鼠「汤米」

| 技能 | 类型 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 人群掩护 | 被动 | 无 | 核心区调查隐藏值不降低 | 核心区是等级 1 主战区 → **调查压点零防御代价**，隐藏值维持上限 1 常驻 |
| 见风使舵 | ↩️ 每局限 1 | 4 情报 | 打断一次抓捕 | 成本高，但打断抓捕 = 保护 1 执行轮 + 证据不入狱 → 保底技 |

**审查**：

1. **等级 1 得分与等级 2 持平**：核心区 3 分/次 → 同样 5 次 KSA 达 15 分。等级梯度（低等级低回报）的收益端锚定**失效**——等级 1 无单次得分惩罚，只有隐藏上限 1 的防御差异。
2. **人群掩护大幅抵消防御差异**：老鼠在核心区调查不掉隐藏，压点链中隐藏值始终保持上限 → 警长抓捕需补差情报，且有「见风使舵」保底。**老鼠实际强度接近甚至超过等级 2 普通罪犯**。
3. 入狱格 1 → 出狱最快，被捕损失小于高等级。

**判定**：🔴 **超模候选**——等级 1 无得分惩罚 + 核心区免防御代价，与"低等级低回报"设计原则冲突。建议方向：① 等级 1 匹配加分下调（仅影响值 1 触发 → 核心区 3 分变 2 分）；② 或「人群掩护」加限制。

### 3.2 等级 2 · 四人组

| 角色 | 技能 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 幽灵 | 华丽骗术 | 1 情报（重大） | +2 情报（净 +1） | 占据重大配额——资源转换占用得分轮 |
| 幽灵 | （无被动） | - | - | 单技能角色，资源引擎不转化为得分优势时偏弱 |
| 毒蛇 | 地下网络 | 0（情报=0 触发） | 补给 +1 情报 | 触发窗口窄（r01 §2.4），难触发 |
| 毒蛇 | 暗度陈仓 | 2 情报（重大） | 回收 1 版图证据 | 防御向，占用重大 → 性价比低 |
| 铁拳 | 暴力催收 | 1 情报（重大） | 弃他人 1 手牌 | 干扰向，不直接得分；弃 1 牌 ≈ 0.5-1 资源当量 |
| 铁拳 | 硬汉体质 | 被动 | 越狱 -1 情报 | 被捕保底技，价值随被捕频率 |
| 鬼手 | 精妙手法 | ↩️ 修整 | 调查回合 +1 情报 | 白赚资源，配合压点链稳定触发 → 效率高 |
| 鬼手 | 后巷密道 | ⚡️ 1 情报 | 移 1 证据至相邻 | 防御/调控向，成本低 |

**审查**：

- **幽灵**：华丽骗术牺牲重大配额，等效"1 回合 1 行动 + 1 情报 → 2 情报"，净 +1 情报但损失一次作案机会（3 分）。**偏弱**——玩家理性选择是放弃此技能。
- **毒蛇**：地下网络触发难 + 暗度陈仓占重大低性价比 → **偏弱**。
- **铁拳**：暴力催收弃手牌是纯干扰不产分；硬汉体质是被捕保底。**中庸偏弱**。
- **鬼手**：精妙手法是稳定白赚资源（调查回合 +1 情报，不占行动），压点链每轮调查 → 每轮 +1 情报，**成本 0 收益 1 资源，全罪犯最高频率被动**。后巷密道 1 情报移证成本低。**合理偏强**。

**等级 2 小结**：鬼手 **合理偏强**；幽灵/毒蛇 **偏弱**；铁拳 **中庸偏弱**。角色内部分化明显：资源型（鬼手）> 干扰型（铁拳）> 防御型（毒蛇）> 纯转换型（幽灵）。

### 3.3 等级 3 · 双面人 / 屠夫

| 角色 | 技能 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 双面人 | 金融犯罪 | 3 情报 + 2 行动（重大，每局限 1） | +2 分 | 效率远低于作案（0.4 分/IC vs 0.88）→ 应急/不动版图时用 |
| 双面人 | 打点关系 | ↩️ 每局限 1，4 情报 | 侦查时救 1 证据回供应堆 | 成本高但救关键证（防被拿去抓捕） |
| 屠夫 | 消灭痕迹 | ➡️ 1 情报 | 移除自己 1 版图证据 | 防抓捕门票消失，防御向 |
| 屠夫 | 亡命之徒 | 被动 | 越狱 -2 情报 | 被捕保底，配合等级 3 入狱格 3 |

**审查**：

- **双面人**：金融犯罪效率低但提供"不依赖版图的确定得分"；打点关系是唯一能防"侦查取证"这步的保底。**合理偏弱**。
- **屠夫**：消灭痕迹主动移除证据降被抓风险；亡命之徒让越狱几乎免费。**合理**——防御型，得分依赖上城高影响区（等级 3 匹配 3-4），成本高暴露高，技能补偿防御面。

**等级 3 小结**：双面人 **合理偏弱**；屠夫 **合理**。

### 3.4 等级 4 · 疯子「莱利」

| 技能 | 类型 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 连环作案 | 被动 | 无 | 每个相邻有证地点 +1 分 | 核心区密集布证（工厂/老城/酒吧相邻），单次作案最多 +2~3 → 上城影响值 3 + 连环 1-3 = **4-6 分/次** |
| 制造恐慌 | ➡️ X 情报（X=版图证据数） | 版图证据数 | 任意地放置 1 证据 | 不产分，用于铺相邻网络；成本 X 随布证增长 |
| 隐藏狩猎 | 被动 | 隐藏上限 2，调查额外 -1 | 补给回复 2 | 防御端弱化但回复快 |

**审查**：

1. **连环作案强度**：核心区 3 分（影响 2+匹配）+ 连环 2-3 = **5-6 分/次**。达 15 分仅需 **2.5-3 次 KSA**——跌破 4-6 次主基准下限。🔴 **超模候选**。
2. **制造恐慌**铺证滚动，布证越多下轮连环分越高，形成滚雪球。
3. **隐藏狩猎**：回复 2 点隐藏使压低隐藏的努力失效（调查 -1 vs 回复 2）→ 实际防御不弱。

**判定**：疯子 🔴 **超模候选**（潜在最强得分速度）。风险缓冲：高影响区初始情报高（压点成本高）、警长集中反制。但配合「地下通道·捷径」可快速上城布证→连环爆发，**需 r04 综合验证是否显著突破 8 轮下限**。

## 4. 扩展阵营审查（超级英雄 / 受害者，5-7 人局）

> 扩展阵营 0 能力高度依赖版图/他人状态（r02 §3.4 结论 3），按"特殊能力是核心竞争力"原则（§4.2 原则 16）审查其综合得分能力。

### 4.1 超级英雄

| 角色 | 技能 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 夜枭 | 狩猎标记（制裁花费隐藏值 -1） | 被动 | 降低制裁成本 | 制裁滚雪球 1+3+6+10+15 等差数列，配合一网打打尽堆叠 |
| 夜枭 | 一网打尽（制裁后花 2 情报取同地另 1 证） | ↩️ 每回合限 1 | 多取 1 证（不产分，只堆叠） | 加速等差数列，成本 2 情报/次 |
| 暗影 | 影随（登场后 +1 情报；相邻有证 +1 分） | 被动 | 登场回本 + 附加分 | 登场（X=地点证据数）+1 分，扩展开分途径 |
| 暗影 | 情报截获（获情报时额外 +1） | ↩️ 每回合限 1 | 资源增幅 | 提高情报流速 |
| 裁决者 | 从重判决（登场看守所压证据） | 被动 | 封锁出狱 + 登场得分 | 强 combo（r01 §2.2 已注） |
| 裁决者 | 越权执法（移 1 版图证据入狱） | ➡️ 每回合限 1 | +1 分 + 证据入狱 | 相当于额外轻量 KSA（1 行动 +1 分） |

**审查**：

- **登场路线**：登场得 X 分（X=地点证据数）。5-7 人局 3-4 罪犯布证密度高，登场单次 2-4 分常见 → 5-6 次登场达标。但登场需花"地点当前情报值"并占独占轮 → 成本结构类似罪犯压点。**合理**。
- **制裁路线（夜枭）**：等差数列使单次收益递增（1→2→3→4→5），滚雪球强但需持续取证（他人作案产生）。5-7 人局证据充足 → 夜枭 **偏强**，需测试验证是否过速。
- **裁决者**：越权执法 = 1 行动 + 1 分 + 移证入狱（剥夺），效率接近受害者追偿的轻量模型 → **合理偏强**；配合从重判决的看守所封锁 combo 有压制过强风险（r01 §2.2）。
- **暗影**：登场 +1 分附加 + 情报截获资源增幅，**合理**——收益分散但稳定。

### 4.2 受害者

| 角色 | 技能 | 成本 | 收益 | 审查 |
| - | - | - | - | - |
| 艾米莉 | 现场跟拍（阳面混乱收回时该地有证 +1 分） | 被动 | 追偿附带 +1 | 提高追偿收益 |
| 艾米莉 | 独家头条（爆料基础效果得分 +1） | 被动 | 爆料 +1 | 提高爆料收益 |
| 艾登 | 有备而来（追偿门槛 ≥1） | 被动 | 触发率提升 | 追偿命中大幅提升 |
| 艾登 | 连本带利（追偿基础效果 +1） | 被动 | 追偿 +1 | 单次追偿净 2 分（目标 -1 你 +2） |
| 掮客 | 情报交易（看顶 3 选 1） | ➡️ | 检索 | 资源获取 |
| 掮客 | 信息垄断（他人调查时花 1 情报同地点 +1 情报） | ⚡️ | 伴调查取情报 | 观察全场 + 白赚 |
| 掮客 | 门路（阴面可弃牌视为阳面） | ⚡️ | 追偿/爆料命中保障 | 保底 |

**审查**：

- **受害者 KSA 特点**：追偿/爆料为轻量型（1 行动 + 1 情报），频率高但触发依赖他人。0 能力下追偿约需 8-15 次（每次 ±1），爆料依赖重大行动选择目标地点（翻面阳面 50%）→ **0 能力极慢**。
- **艾登**：有备而来（门槛 ≥1）+ 连本带利（+1）使追偿单次净收益 2 分当量（目标 -1、你 +2）→ 6-8 次追偿可达标。**合理偏强但符合"特殊能力补偿"原则**。
- **艾米莉**：爆料强化依赖"地点被选为目标"的外部触发，频率不可控。**偏弱**——触发率过低时技能空置。
- **掮客**：信息垄断是稳定的伴生资源（任何人调查都触发），情报交易+门路保证追偿/爆料命中。**合理偏强**——资源与命中双保障，但收益分散。

**扩展阵营小结**：超级英雄整体 **合理偏强**（制裁/越权执法有加速风险，需测试）；受害者分化：艾登/掮客 **合理偏强**、艾米莉 **偏弱**（触发依赖过重）。
