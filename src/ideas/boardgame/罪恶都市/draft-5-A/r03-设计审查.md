### 1.3 地点系统结论

- 区域梯度合理，但**上城/核心的效率超出基准 2.4 倍**是 0 能力基准超模的主因之一（r02 B2-1 + §2.4）。
- 红灯区（4/2/侦查惩罚）存在沦为"冷区"的风险；地下通道"移上城"用途模糊。均列入 🟡 观察。
- 火车站"双回填"、黑市"反哺"是有效的策略多样性来源。

## 三、能力强度分布汇总

| 强度 | 角色/技能 | 依据 |

| 🔴 超模风险 | 疯子·连环作案（极端 7 分/次） | 博物馆 4+超额 1+相邻证据 2 = 7 分/次；高风险高回报需平衡 |

## 四、卡牌/特殊手段系统分析

### 4.1 策略牌效率分层（结合 r01 的 P1 结论）

| 层级 | 牌 | 效率特征 |
| - | - | - |
| 高效 | 情报报告（+2 情报）、留一手（0 行动摸 1）、恰到好处（被动 +1 情报） | 资源转换效率 ≥1，无针对性，通用价值最高 |
| 中效 | 情报截获（调查+取情报但隐藏不降）、线人报酬（牌质量）、暗箱行动（隐藏值调控） | 条件性收益，通用 |
| 低效/针对性 | 尾随跟踪/暗中观察（信息）、栽赃陷害（移动证据）、情报干扰（放置情报） | 信息或布局价值，收益反馈弱 |
| 阵营偏斜 | 设伏（罪犯作案+2）、不在场证明（抵消抓捕）、证据误导（警长侦查触发）、通风报信（警长抓捕触发） | 天然偏袒某阵营，r01 已标 🔴/🟡 |

### 4.2 是否导致单一策略最优

- **快速牌无行动成本** → 在重大动作占满 2 行动的回合仍可打出 → 快速牌是"行动被占满时唯一可用"的牌，**快速牌价值系统性高于普通牌**（9/34 ≈ 26%占比）。玩家摸到快速牌几乎总是打出（除留手时机外），普通牌则常被修整弃置。
- **结论**：策略牌维度存在"快速牌垄断"倾向——普通牌因行动占用在与重大动作争抢中落败，使用率低；快速牌成为绝对主导。建议测试阶段重点观察普通牌使用率，若过低需考虑"重大动作免额外行动"或降低普通牌打出成本（r01 §6.1 已提）。

### 4.3 特殊手段的资源循环

- 「情报截获」「情报报告」「恰到好处」「线人报酬」：从**供应堆**获得情报 → 不消耗版图 → 无资源枯竭风险（资源通胀源，r04 检查）。
- 「情报干扰」：放情报到地点 → 增加版图情报 → **消耗供应堆 + 提高地点成本**，双向循环闭合 ✓。
- 「栽赃陷害」「证据误导」：移动证据不产生/消耗 → 状态调整，不影响循环 ✓。

## 五、策略收敛检查

### 5.1 罪犯侧的收敛压力

- r02 已指出：等级 2 核心区稳态 1.0 分/资源 + 上城 1.33-2.0 → **所有罪犯理性涌向上城**（等级 3/4）或**核心区**（等级 2）。3 罪犯挤同一高价值区 → 警长布控/侦查/抓捕集中到单区 → 警长的边控成本下降 → **罪犯被一网打尽的概率上升**；但若警长兵力分散，罪犯则白嫖高回报区。
- 收敛结果形成"核心区/上城的军备竞赛"，而下城沦为无人问津（等级 2+ 无超额价值）。

### 5.2 警长侧的收敛压力

- 警长最优 = 布控核心/上城（免费布控机制）+ 1 证据高效抓捕 → **单一"布控+1证据抓"套路**；无证据奖励（+2/轮）因与抓捕互斥基本放弃。
- 猎犬·天罗地网（1 情报布控）进一步把这套路成本压低 → 警长也收敛到同一条路。

### 5.3 扩展阵营的收敛

- 裁决者·越权执法（0 成本 1 分/回合）+ 从重判决（看守所 X 分）→ 裁决者收敛到"越权执法刷分"→ 其收益依赖"证据入狱"供应（来自警长抓捕），当警长不抓捕则裁决者无分可刷 → **扩展阵营收益绑定警长行为**，警长不作为时英雄/受害者输出骤降（互动依赖度高的副作用）。

## 六、无基础得分手段阵营的补偿检查

| 阵营 | 0 技能基准（r02） | 技能补偿 | 补偿是否充足 |
| - | - | - | - |
| 受害者 | 0.33-0.67 分/资源 | 艾登降门槛+连本带利（追偿爆发）、掮客信息垄断+门路（资源+保底）、艾米莉爆料强化 | **整体达标甚至偏强**（艾登 4 分/次尤其）——补偿充分，且有超模风险需下修 |
| 英雄 | 0.33 分/资源 | 夜枭制裁减费、暗影情报+1（登场回补）、裁决者越权执法（免费分） | **严重不均衡**：裁决者越权执法超模（免费分）；夜枭/暗影仍偏低（依赖制裁链，而制裁链受 r01 §1.1 循环缺口拖累）——**英雄阵营内部失衡 + 整体补偿不足** |

**关键结论**：

1. 受害者补偿**过分**（艾登流超基准 3 倍），需下修。
2. 英雄补偿**不均**：裁决者破格超模，夜枭/暗影补偿不足；且英雄制裁循环缺口（r01 §1.1）若不修复，制裁流（夜枭核心）彻底失去竞争力。

## 七、审查结论

1. **地点层**：核心区/上城效率超基准 2.4 倍 + 红灯区冷区 + 地下通道用途模糊 → 建议调整区域数值（r05）或接受并用玩家策略多样性平衡
2. **角色层（4 人局基准）**：超模集中（屠夫 5 分/次、疯子 7 分/次极端、鬼手无限移证、疯子在 p0 防御）；偏弱集中（老鼠/双面人救场技、毒蛇死技、疯子防御崩坏）
3. **策略牌层**：快速牌垄断普通牌；设伏/不在场/通风报信违反 P1（r01 已标）
4. **策略收敛**：罪犯涌上城/核心；警长收敛"布控+1 证据抓"；扩展阵营收益绑定警长行为
5. **补偿检查**：受害者过度补偿（艾登）、英雄补偿不均（裁决者超模 vs 夜枭/暗影不足）+ 循环缺口
6. 以上超模/偏弱项均进入 r04 综合计算验证交叉组合与净平衡。
