## 1. 地图/地点系统审查

### 1.1 区域梯度（原则 1 得分效率一致）

| 区域 | 参考情报 | 参考影响 | 0 能力轮次效率（r02 §3.5） | 超额区间 | 判定 |
| - | - | - | - | - | - |
| 下城 | 2 | 1 | 1.0 分/轮 | 等级1 | 🟡 效率低但安全 |
| 核心 | 3 | 2 | **1.5 分/轮** | 等级≤2 | 🔴 全面最优 |
| 上城 | 4 | 3 | 1.0（等级1-2）/ 1.33（等级3+） | 等级≥3 | 🟡 等级3+专属 |

**判定**：

- **核心区成为绝对优势区**（r02 Q1）：轮次效率 1.5 显著高于上下城（1.0），且等级 1-2（占罪犯池 5/8）全部为核心超额。
- **上城区对低等级罪犯无吸引力**：等级 1 在影响 3 超额外只多 1 分，但首次压降 4→1 需 3 轮（R1-R3），轮次效率反而不如核心。仅等级 3-4 有动机。
- **下城区沦为避难区**：仅在被压制/看守所后用于低风险回血，收益上限 12 分不足以争胜。

### 1.2 高价值地点检查

| 地点 | 参数 | 0 能力下价值 | 判定 |

| 港口区 | 情报4/影响3 | 走私通道（证据→下城）帮罪犯转移证据避免被侦查 | 🟡 效果与核心"压区作案"协同过强？见 r04 |
| 火车站 | 情报4/影响3 | 流动人口回填，几乎不会低于 2；高情报使作案/侦查成本高 | 🟡 毒瘤（双方都不爱去），但作为情报泵必要 |

### 1.3 无基础得分手段阵营的补偿（原则 16）

- 4 人局仅警长+罪犯。警长无"基础作案/抓捕外的稳定得分"，但抓捕=直接得分（非剥夺），且无证据奖励是清场奖励。基本符合原则 16（抓捕即得分）✓
- 但 r02 §4.3 显示警长链依赖罪犯压区行为 → 若罪犯选择高情报区不动（不压区），警长侦查成本高、得分效率骤降 → **警长的"稳定得分手段"实际脆弱**。

### 1.4 下城区效果叠加审查（对应 r01 §4.2）

| 组合 | 效果 | 作案实际情报花费 | 0 能力等效效率 | 判定 |
| - | - | - | - | - |
| 黑市 | 作案花费返还 1 | 3-1=2 | 2 情报/案（2 分）→ 1.0 分/情报（真花费口径） | 🟡 与码头相当，不超模 |
| 码头 | 作案花费 -1(最低0) | 2-1=1 | 1 情报/案（2 分） | 🟡 见 Q5 |
| 黑市+码头（不同地点，不可叠加） | — | — | — | 🟢 无组合 |
| 码头 0 情报循环 | 2D+1C 每 2 轮 | 0 | 2 分/2轮=1.0 分/轮，但行动全用满 | 🟡 效率虽非最高，但**情报零消耗 = 无视警长布控/设伏的+2**（布控+2 对 0 花费无效，因为花费=0，+2 仍为 0？） |

> **🟡 关键发现**：码头"隐秘卸货 -1"与布控/设伏(+2)交互时，若作案花费被减到 **0**，布控的 +2 只使花费变 2（而非 +2 从 0→2 正常），回填到"0→需 2 情报"，削弱了警长压制效果。若地点情报 1 + 码头 -1 = 0，布控 +2 → 2。这使码头成为**警长压制的盲区**。r04 需量化。

### 1.5 上城/核心/下城的"证据物流"（原则 15 策略多样性）

- 港口（核心→下城）+ 捷径（下城→上城）+ 溢出自选 → 证据可在任意两点间流动。
- 正面：证据流向多样，警长需追踪的"证据散布面"大，博弈复杂化 ✓
- 负面：结合的"金库"限制使部分证据不可移动 → 证据管理难度对新手偏高（可接受，作 FAQ）

## 2. 角色/能力审查

### 2.1 警长角色强度

| 角色 | 技能 | 收益形式 | 相对基准（警长 1.0-1.5 分/轮） | 判定 |
| - | - | - | - | - |
| **鲍默尔** | +1 行动/回合；隐藏≤1 抓捕+1 | 行动 +50%；得分 +1/次 | 资源上限提高 → 侦查/抓捕节奏加快，估计升至 1.8-2.4 分/轮 | 🔴 超模风险（4 人局 1v3 压制力） |
| **莫里斯** | 侦查+1情报；花1情报⚡️布控 | 侦查净返还 1/次；布控费用化 | 侦查链成本下降 → 1.7-2.2 分/轮（叠加市政厅更甚，见 r01 §2.2） | 🔴 超模风险 + 交叉组合 |
| **温斯洛** | 看手牌+延时牌；布控相邻放情报 | 信息 + 微辅助 | 无资源/得分效率提升 → 仍约 1.0-1.5 分/轮 | 🟡 偏弱 |

**结论**：

- 鲍默尔 +1 行动在 4 人局（警长 1 人 vs 3 罪犯轮流 2 行动）中，使警长**行动密度**提升 50%。若维持，需确认罪犯方有足够反制（抓捕打断/布控成本）。**倾向削减为"每回合额外 1 次 ◇ 行动（不得用于抓捕/作案等重大行动）"或删除该技能、改为资源型技能**。
- 莫里斯"追踪直觉"使侦查成本近似减半 → **建议改为"进行'侦查动作'时，若花费 ≥2，返还 1"**（限制高情报侦查，保留低情报激励），避免"侦查净赚"。配合市政厅叠加问题（r01 §2.2）一并处理。

### 2.2 罪犯角色强度

| 角色 | 技能 | 收益形式 | 相对基准（罪犯核心 1.5 分/轮） | 判定 |
| - | - | - | - | - |
| **老鼠**(Lv1) | 核心调查不降隐藏；4 情报打断抓捕 | 降低压区代价 + 保命 | 核心压区循环的隐藏代价 → 0 → 效率不变但风险大降 | 🟡 强（隐藏=0 长期不降） |
| **幽灵**(Lv2) | 花1情报夺2情报（重大） | 净 +1 情报/回合（剥夺） | 情报供给 +1/回合 → 手牌/调查腾出 → 间接提速 | 🟡 超模风险（见 r01 §2.3） |
| **毒蛇**(Lv2) | 0 情报时补给 +1；花2移证据回手 | 资源保底 + 证据回收 | 保底节奏 + 防警长攒证 | 🟢 合理 |
| **铁拳**(Lv2) | 弃对手手牌；越狱-1情报 | 干扰 + 快速出狱 | 干扰型，无直接提效 | 🟢 合理 |
| **鬼手**(Lv2) | 调查+1情报；花1移证据相邻 | 调查双倍 + 证据移动 | 调查 1 行动→2 情报 → 压区效率翻倍 | 🟡 强（与地下酒吧叠加更甚） |
| **双面人**(Lv3) | 花3得2分(每局限1)；4情报返证据 | 直接得分 + 保命 | 金融犯罪：3 情报+2 行动 → 2 分 → 0.67 分/资源、2 分/轮（单次） | 🟢 合理（每局限1） |
| **屠夫**(Lv3) | 上城作案+1；花1移除证据；越狱-2 | 上城超额叠加 | 上城(影响3+屠夫+超额)=5分/案，但 3 轮周期 → 1.67 分/轮 | 🟡 偏强但受上城限制 |
| **疯子**(Lv4) | 连环+X；恐慌放情报；隐藏-1调查 | 上城/核心连环 | 若相邻已有 2 证据 → 上城作案额外+2+超额 = 影响3+2+1 = 6 分/案 → 2.0 分/轮 | 🔴 超模（若链建立） |

**关键结论**：

1. **"鬼手"精妙手法**：调查 1 行动 → 2 情报，使核心压区（需 2 次调查=2 情报）变成"1 行动 2 情报"→ **压区循环缩短 1 轮**，效率大幅提升。需遏制："额外获得 1 个'情报 Token'"在压区时与调查双效叠加，建议限制"调查核心区时"或改为"出牌后"。
2. **"疯子"连环作案**：上限 +2 且无条件限制（只要相邻有自己证据），上城 6 分/案过于爆炸。建议上限 +1，或将触发改为"该地点与其相邻地点均有你的证据"更严格。
3. **"老鼠"人群掩护**：核心调查不降隐藏，长期 0 风险压区。建议限于"核心区"已限定，但可调整为"调查时隐藏不降（每局限 X 次）"。

### 2.3 无基础得分阵营补偿（原则 16，5-7 人扩展视角）

- **超级英雄**：全部技能围绕"干扰+得分"耦合（铁拳制裁=清证据+每证据1分；情报截获=资源偷取）→ 有得分手段 ✓
- **受害者"记者"**：独家头条（花2情报→2分）→ 2 分/2 情报 = 1.0 分/情报，高于警长基准 → 合理 ✓
- **受害者"掮客"**：情报交易（看3选1+1分）→ 1 行动+1 手牌 → 1 分 + 手牌增益，效率偏低但信息价值弥补 → 🟢 合理

## 3. 策略牌（特殊手段系统）审查

### 3.1 分阵营可用性分析

| 牌 | 罪犯 | 警长 | 备注 |
| - | - | - | - |
| 情报报告(2情报) | ✅ 核心 | ✅ | 通用 |
| 证据误导 | ✅ | ⚠️ 无效(弃置补偿) | 阵营明确 |
| 尾随跟踪 | ✅ 看隐藏 | ✅ 看隐藏 | 警长更优 |
| 暗中行动(±1隐藏) | ✅ 自保 | ✅ 降隐藏 | 双阵营有用 |
| 通风报信 | ⚠️ 歧义 | ⚠️ 歧义 | 见 r01 §3.1 |
| 恰到好处(得分时+1情报) | ✅ | ✅ | 通用，收益低 |
| 设伏(+2作案) | ⚠️ 反作用 | ✅ 压制 | 警长优 |
| 大计划(+1抓捕/作案) | ✅ | ✅ | 通用 |
| 不在场证明 | ✅ | ✅ 无 | 罪犯保命 |

**判定**：

- **牌库整体对双阵营有可用性** ✓（除少数明确阵营牌）
- **设伏/不在场证明/证据误导/尾随跟踪呈阵营偏斜** —— 合理，构成策略差异。

### 3.2 成本收益审查（原则 4 特殊能力 ≤ 基础效率）

| 牌 | 投入 | 收益 | 资源效率 | 与基准比较 | 判定 |
| - | - | - | - | - | - |
| 情报报告 ×3 | 1行动+1手牌 | 2情报 | 2情报/1资源（转换） | 转换效率高 | 🟢 合理 |
| 线人报酬 | 1行动+1手牌+1情报 | 看3选1 | 手牌+1 + 选择权 | — | 🟢 合理 |
| 证据交易 | 1行动+1手牌 | 1其他罪犯证据移回 + 2情报 | 干扰+2情报 | 剥夺+资源双效 | 🟢 可接受（跨罪犯向） |
| 大计划 | 1行动+1手牌(延时) | 作案/抓捕+1分 | +1分/案 | +1/2轮 ≈ +0.5分/轮 | 🟢 合理 |
| 设伏 | 1行动+1手牌(延时) | 地点作案+2 | 压制 | 见 r01 §3.2 性价比低 | 🟡 偏弱 |
| 通风报信 | 1手牌(快速) | 效果歧义 | — | 见 r01 §3.1 | 🔴 需重设计 |

### 3.3 是否导致单一策略最优（原则 15）

- 罪犯最优策略 = 核心压区作案（r02 Q1）。策略牌中：
  - 情报报告/线人报酬 **加速压区准备** → 强化核心最优
  - 设伏/证据误导/不在场证明 **反制/保命** → 提供差异
- **结论**：牌库整体**强化而非削弱**了核心收敛。需要引入反收敛机制：如提升下城/上城收益梯度、或核心区布控/设伏可叠加压制到"完全不可行"。
