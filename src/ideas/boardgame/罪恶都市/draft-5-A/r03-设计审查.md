## 0. 与 r02 的衔接

r02 核心结论：

1. 罪犯 0 能力单机最优 18-20 分，超出设计基准 +20%~+43%（轮次效率 1.50-1.67 vs 1.17-1.25）。
2. 警长 0 能力单机 9-13 分，低于基准 -8%~-40%。
3. 平衡依赖三大抑制源：罪犯间竞争、警长抑制的时间分配、压区导致的隐藏暴露。

r03 逐一检查：这些抑制源在机制层面是否成立、是否稳定，以及各子系统（地图/角色/卡牌）的设计质量。

## 1. 地图 / 地点系统：区域资源与收益梯度

### 1.1 区域参数梯度（设计原则 1：得分效率一致 / 原则 3：梯度合理）

| 区域 | 参考情报 | 参考影响 | 单次作案（初始态） | 压区后稳态 | 风险层 |
| - | - | - | - | - | - |
| 下城 | 2-3 | 1-2 | 0.25-0.60 分/IC | 0.86-1.33（等级 2） | 低（警长较少去下城）但竞争 3 地点 |
| 核心 | 3-4 | 2-3 | 0.60-0.67 | 0.86-1.33 | 中 |
| 上城 | 4-5 | 3-4 | 0.67-0.71 | 同左 | 高（复苏回填到高位+警长焦点） |

- **梯度方向成立**：从下城到上城，单次回报（1→4 分）与初始成本（2→5 情报）同步上升，符合"高回报高风险"。
- **问题 a（原则 1 违反）**：**下城 1 值地点（贫民窟/地下通道/码头仓库）对等级 2+ 罪犯是"0.25 分/IC"的陷阱**，明显低于核心/上城的 0.60-0.71。区域内部的梯度失衡——下城自身 1 值与 2 值（黑市）的回报差 3 倍，而风险差远小于此。
- **问题 b（原则 8：操作频率）**：下城 1 值地点单次仅 1 分（等级 2+），需 15 次作案才达 15 分，远超 12 轮上限 → **等级 2+ 罪犯理性回避下城 1 值，下城 1 值地点实际只服务等级 1 罪犯**。这与"下城区是安全但收益低"的定位一致，但使下城区域对 8/9 的罪犯几乎无吸引力——区域利用率失衡。
- **问题 c（原则 6：仅基础资源获取消耗版图资源）**：调查是唯一消耗版图情报存量的操作。上城初始 4-5 + 复苏回填 → 上城情报长期高位，罪犯压区成本最高；下城初始 2-3 → 压区成本低。这正向强化梯度 ✓。

| 地点 | 效果 | 评价 |
| - | - | - |

## 2. 角色 / 能力：成本收益分析（设计原则 4、9、10、16）

### 2.1 警长角色（3 张）

基准参照：警长 0 能力 = 9-13 分/12 轮（低于基准）。

| 角色 | 技能 | 类型 | 成本收益分析 | 强度 |
| - | - | - | - | - |
| 「铁腕」鲍默尔 | 雷霆行动（每回合 +1 行动） | 被动 | 12 轮 +12 行动（+6 IC 供给）。把 4 轮抓捕链压缩为 3-4 轮（侦查+抓捕同位回合）。12 轮可做 4 次抓捕（+1 次）。估值 ≈ +3~4 分 | 🟡 合理偏强（配合抓捕链，是警长三大技能中最直接的爆发源） |
| | 铁腕执法（隐藏 ≤1 时抓捕 +1） | 被动 | 罪犯压区打隐藏 0 是常态 → 条件易满足。与"隐藏暴露抑制源"直接联动，是对罪犯压区行为的针对性惩罚 | 🟡 合理 |
| 「猎犬」莫里斯 | 追踪直觉（侦查额外 +1 情报） | 被动 | 每次侦查 +1 情报，12 轮若 6-8 次侦查 ≈ +6-8 情报 ≈ +2-3 分等效（降低侦查资源压力） | 🟢 合理，稳定收益 |
| | 天罗地网（⚡️ 花 1 情报布控，每回合 1 次） | ⚡️ | 布控不花行动，可边侦查边布控。若布控口径②（提情报值）则威胁大；若口径①（仅侦查）则价值骤降 | 🟡 依赖布控口径裁定 |
| 「智囊」温斯洛 | 战术分析（⚡️ 看手牌） | ⚡️ | 纯信息。对抓捕决策价值中（知道罪犯保留的资源/防御牌），但**无直接成本收益** | 🟢 偏弱（信息型技能在量化上难以估值，需实测） |

**警长侧强度分布**：1 超模偏高（鲍默尔）、1 合理（莫里斯）、1 偏弱（温斯洛）。警长整体偏弱（0 能力基准 -8%~-40%），因此鲍默尔的偏高**部分合理**（补偿警长基础劣势），但温斯洛需要加强或确认定位。

## 3. 卡牌 / 特殊手段系统（策略牌）

| 暗中行动 #07 | 普通 | 1 行动 | 隐藏 ±1 | 改变抓捕补差 | 🟢 合理（警长降隐藏=降 Z；罪犯升隐藏=升 Z） |
| 金库保险 #08 | 普通 | 1 行动 | 免疫指定 | 防御 | 🟢 合理 |
| 证据交易 #09 | 普通 | 1 行动 | 3 情报 + 证据回收 | 1 行动 → 3 情报 | 🟡 **超模风险（对罪犯）**：弃自己的证据 = 回收证据 + 3 情报。与毒蛇暗度陈仓（花 2 情报回收）对比，该牌净赚 5 情报差值。罪犯打出收益显著高于基准转换效率 |
| 线人报酬 #10 | 普通 | 1 行动 + 2 情报 | 看 3 选 1 牌 | 2 情报 → 1 牌 | 🟡 偏弱（2 情报 + 1 行动换 1 手牌，等价于花 3 资源摸 1 牌，效率低） |
| 证据误导 #11 | 快速 | 0 行动 | 换侦查目标 | 防御 | 🟡 **对警长废牌**（r01 3.2）：警长自己无法受益；违反"所有牌对所有阵营有正面潜力"（§7.2） |
| 紧急躲避 #12 | 快速 | 0 行动 | 免疫指定 | 防御 | 🟢 合理 |
| 留一手 #13 | 快速 | 0 行动 | 不占上限 | 手牌容量 | 🟢 合理 |
| 通风报信 #14 | 快速 | 0 行动 | 信息+响应 | 待定 | ⚠️ 效果不完整（r01 1.5） |
| 恰到好处 #15 | 快速 | 0 行动 | 1 情报/有人得分 | 被动收益 | 🟢 合理 |
| 设伏 #16 | 普通延时 | 1 行动 | 地点 +2 情报（下轮） | 抬高成本 | 🟡 时机模糊（r01 1.7）；对警长=防御性布控，对罪犯=自伤（抬高自己作案成本）→ **对罪犯价值为负**，违反"对所有阵营有正面潜力" |
| 大计划 #17 | 普通延时 | 1 行动 | 作案/抓捕 +1 分 | 1 行动 → 1 分 | 🟢 合理（1.0 分/资源，作为"行动换分"牌尚可，但需与金融犯罪对比，注意强度累积） |
| 不在场证明 #18 | 普通延时 | 1 行动 | 抵消抓捕 | 防御 | 🟢 合理，但注意全局"抵消抓捕"手段数量（r04 交叉组合） |

### 3.2 是否导致单一策略最优（原则 15）

- **情报报告 + 证据交易**组合：罪犯可通过"摸牌→出情报报告/证据交易"快速堆情报 → 压区流被进一步放大。**证据交易的存在使罪犯资源循环效率超过设计上限**（r04 交叉验证）。
- **信息牌**（尾随/暗中观察/战术分析）：不直接得分，不导致单一策略，但压缩信息不对称→降低"赌博式抓捕/作案"的趣味，需注意信息过载方向（§7.3 已列调整方向）✓。
- **结论**：目前最可能导致策略收敛的是"压区流（调查D×2 → 作案C）"本身，卡牌系统没有提供足够打破该循环的手段（最接近的是情报干扰#04、设伏#16，但前者被后者价值为负抵消）。**r04 需专项验证"压区快攻"是否成为必胜策略**。

### 3.3 卡牌系统问题优先级

| # | 问题 | 优先级 | 建议 |
| - | - | - | - |
| 3.1a | 证据交易对罪犯超模（+5 情报差值） | 🔴 | 改为"获得 X 情报（X=该证据回收后罪犯可立即使用的收益）"，或加"仅警长可用"限制，或下调至 2 情报 |
| 3.1b | 设伏/证据误导对部分阵营价值为负/近废 | 🟡 | 设伏改为"选择 1 个地点：该地点本轮内侦查/作案花费 +2"（双阵营都可利用）；证据误导改为"可指定警长侦查的目标证据"且警长可用（如换给自己想收的证据）或改为罪犯专属牌 |
| 3.1c | 通风报信不完整 | 🔴 | 补全响应效果 |
| 3.1d | 线人报酬偏弱 | 🟢 | 降消耗至 1 情报 或 改为"看 4 选 1" |

## 4. 无基础得分手段阵营的补偿（原则 16，扩展局）

### 4.1 超级英雄

| 角色 | 技能 | 补偿评估 |
| - | - | - |
| 夜枭 | 暗影追踪（调查+销毁/情报）；铁拳制裁（销毁证据得 1 分/枚，每局限 1） | 得分依赖"场上证据密度"——若罪犯被警长压制、证据少，夜枭得分困难 → **依赖对手行动频率，不稳定**。铁拳制裁的"不能作案"额外限制很强（若销毁后罪犯无法返场） |
| 暗影 | 情报截获（被动截流）；战术干扰（弃牌得 2 分） | 得分绑定"弃对手策略牌"；概率性收益（对手未必有牌可弃），稳定性中 |
| 裁决者 | 法律漏洞（禁得分+窃分）；越权执法（延长刑期得分） | 法律漏洞是"相对抑制+窃分"，得分依赖对手当轮得分行为；越权执法每局限 1（1 格得 1 分，可多次延长） |

- **结论**：英雄的补偿全部绑定"对手行动/被压制状态"，在对手不配合时无分。这符合"灰色地带私刑者"叙事，但**补偿强度的下限偏低**，属于"高方差阵营"。在 5+ 人局中，英雄活跃度 = 场上冲突频率，若该局罪犯保守、警长消极，英雄会空转。建议测试阶段重点观察，并考虑给每名英雄 1 个"主动得分"小技能（如夜枭的暗影追踪本身可提供条件性得分）。

### 4.2 受害者

| 角色 | 技能 | 补偿评估 |
| - | - | - |
| 记者 | 深度调查（信息）；独家头条（花 2 情报，有证据地点 +2 分） | 独家头条得分条件易满足（有证据地点常见）→ 2 情报 → 2 分 = 1.0 分/资源，**高于基准**但需 2 行动，是"行动换分"型；稳定性中高 |
| 掮客 | 情报交易（看 3 选 1 + 得分 1）；信息垄断（被动截流）；黑料曝光（弃牌得分） | 情报交易是唯一"主动每回合得分锚"（+1 分/次，每回合限 1）→ 12 轮最高 +12 分（理论上限），稳定性高 |

- **结论**：受害者补偿比英雄稳定（有主动得分锚），但记者/掮客的"2 行动换 2 分"、"1 行动换 1 分"接近资源→IV 直购，若不加行动约束可能过高（r04 扩展段验证）。

### 4.3 扩展阵营结论

| # | 问题 | 优先级 | 建议 |
| - | - | - | - |
| 4.1 | 英雄得分高方差、下限低 | 🟡 | 加主动得分小技能，或在测试中观察 |
| 4.2 | 受害者"行动换分"效率接近直购 | 🟡 | 复核是否需加情报成本约束 |
