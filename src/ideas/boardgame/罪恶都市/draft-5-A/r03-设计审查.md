# r03 · 设计审查

> 根据 r02 的基准检查设计质量
> 审查内容：地图/地点系统、角色/能力成本收益、卡牌/特殊手段、阵营补偿

---

## 1. 地点系统审查

### 1.1 区域资源梯度评估

| 区域 | 平均情报值 | 平均影响值 | 平均得分/行动(等级2) | 梯度评价 |
| - | :-: | :-: | :-: | - |
| 下城区 | 2.25 | 1.25 | 0.29 | 基准线（回报最低） |
| 核心区 | 3.38 | 2.25 | 0.42~0.60 | 适中（主流选择） |
| 上城区 | 4.25 | 3.25 | 0.52~0.68 | 高回报但成本大 |
| 博物馆(特殊) | 5 | 4 | 0.57~0.71 | 极端高回报 |

**评估**：梯度合理。下城区安全但回报低，核心区标准，上城区回报高风险高。博物馆作为唯一的"顶级作案点"设计合理（只需要 1 个）。

### 1.2 特殊地点效果评估

| 地点 | 效果 | 强度评估 | 问题 |
| - | - | - | - |
| 金融中心·金库 | 证据不能被侦查以外方式操作 | 🟡 中等 | 阻止了"证据交易"#09 和"后巷密道"等能力，但这些都是特殊手段，属于合理的限制 |
| 市政厅·监控 | 侦查时额外得 1 情报 | 🟢 偏弱 | 需要先在这里侦查。警长侦查已经花费大量情报，回血 1 点帮助有限 |
| 火车站·流动人口 | 黎明阶段放置 1 情报 | 🟢 中等 | 每轮自动补充情报，等于该地点持续有可用情报。但不超过初始值（4），所以最多补充到满 |
| 红灯区·鱼龙混杂 | 侦查花费 +1 | 🟡 偏弱 | 仅多 1 情报成本对警长整体侦查成本影响不大 |
| 港口区·走私通道 | 移动证据到上城 | 🔴 强 | 罪犯可以用此能力将证据从下城/核心区转移到上城，配合上城的高影响值得分。但需要 1 行动，性价比需评估 |
| 地下通道·捷径 | 移动证据到上城 | 🔴 强 | 同上城转移，配合作案战略价值高 |
| 黑市·地下经济 | 花费情报时回血 1 | 🟡 中等 | 每回合限 1 次的回血机制，可降低在此地的长期消耗 |
| 码头仓库·隐秘卸货 | 作案情报花费 -1 | 🔴 强 | 大幅度降低作案成本，尤其高影响值高情报值的上城效果更明显 |

**评估**：

- 下城区地下通道（捷径）+ 码头仓库（减情报花费）的组合，使得下城区成为低成本作案 + 证据转移到上城的战略点。这可能创造"下城作案减耗费 + 转移证据到上城"的组合策略。
- 但作案的得分是基于作案**地点**的影响值，而非证据位置。所以证据位置虽然重要（影响侦查），但得分只取决于作案地点。因此证据移动本身不直接产生分数。

### 1.3 版图布局问题

§5.3 版图布局建议排成 3×4 网格，但没有任何移动距离限制——玩家可以任意选择版图上任何地点行动。

**问题**：既然没有移动限制，版图布局的视觉分层（上城在顶、下城在底）就只是装饰性设计。这对于理解"区域等级"有一定帮助，但实际游戏中玩家不需要考虑位置关系，只需要看数字。

**建议**：要么增加移动限制（如每轮可行动的地点有范围限制），要么接受版图仅为视觉辅助。

## 2. 角色/能力审查

### 2.1 警长角色成本收益分析

#### 警长 A："铁腕"鲍默尔

| 技能 | 分析 |
| - | - |
| **雷霆行动**（被动：每回合 +1 行动） | 3 行动/回合 vs 标准 2 行动。效率提升 50%。这意味着铁腕在 12 轮中相当于有 36 次行动 vs 标准的 24 次行动，多出 12 次行动。折算为分数（按 0.36 分/行动补差抓捕计算）：12 × 0.36 = **4.32 分超模** |
| **铁腕执法**（被动：抓捕隐藏值 ≤1 罪犯 +1 分） | 条件触发。隐藏值 ≤ 1 的罪犯：屠夫(隐藏上限 2)、疯子(自愈 2)。这两个角色经常处于低隐藏值。额外 +1 分意味着抓捕效率更高。 |

**整体评估**：🔴 雷霆行动可能过强。每回合多 1 行动是全局性增益，不像其他技能有触发条件。12 轮下来多 12 行动的超模收益显著。

#### 警长 B："猎犬"莫里斯

| 技能 | 分析 |
| - | - |
| **追踪直觉**（被动：侦查时额外得 1 情报） | 侦查消耗 = 地点情报值情报，额外得 1 情报 = 回血 33%（按平均 3.32 算）。这意味着侦查的实际情报成本从 3.32 降到 2.32，效率提升约 30%。 |
| **天罗地网**（⚡️：花费 1 情报快速布控，每回合 1 次） | 标准布控：1 行动 + 1 警员 Token。此技能：1 情报 + 1 警员 Token（⚡️不消耗行动）。节省 1 行动。超模评估：每轮省 1 行动 → 12 轮多出 12 次行动，但与铁腕不同——铁腕是"真多 12 行动"，猎犬是"用情报换时间"。 |

**整体评估**：🟡 两个技能联动良好，整体略强但不超模。侦查得情报 → 情报用来布控 → 布控增加侦查成本（对罪犯）→ 更多侦查需求 → 更多情报。良性的自循环设计。

#### 警长 C："智囊"温斯洛

| 技能 | 分析 |
| - | - |
| **战术分析**（⚡️：查看手牌，每回合 1 次） | 信息型能力。在 4 人局中，查看 1 个对手的手牌（3 张上限），可以预判对手的下一步。但无法直接得分或阻止对手。效用依赖于玩家的分析和应对能力。 |
| **布局预判**（被动：布控时给相邻地点 1 情报） | 有限的资源回流。布控本身消耗 1 行动。相邻地点的定义——在 3×4 网格中，某地点的相邻最多 4 个（上下左右）。白给 1 情报的收益约等于 1 次调查。 |

**整体评估**：🟡 偏弱。"智囊"的技能在资源获取和直接得分上都不如铁腕和猎犬。信息型能力在休闲局中价值低，布局预判的收益过小。

### 2.2 罪犯角色成本收益分析

#### 等级 1："老鼠"汤米

| 技能 | 分析 |
| - | - |
| **人群掩护**（核心区调查不降隐藏值） | 核心区调查时，隐藏值不变。但核心区是所有罪犯都会涉足的区域。此技能让老鼠可以在不暴露自己的情况下积累情报。 |
| **见风使舵**（↩️：花费 2 情报使抓捕失效，每局限 1 次） | 绝对的保命技能。花费 2 情报 vs 被捕损失（抓捕后失去作案能力直到出狱），性价比极高。 |

**整体评估**：🟢 合理。低等级罪犯有强生存能力，但犯罪等级 1 的得分上限有限（作案拿 1~2 分），所以综合强度合理。

#### 等级 2："幽灵"琪琪

| 技能 | 分析 |
| - | - |
| **华丽骗术**（➡️ 重大：花费 1 情报，从任意玩家处获得 2 情报） | 净赚 1 情报。但"从任意玩家处"意味着从玩家供应堆而非公共供应堆获取，所以是"偷"而非"造"。会导致目标的资源损失。 |

**成本分析**：

| 步骤 | 行动 | 情报 |
| - | - | - |
| 获取 1 情报（之前） | 1 行动 | - |
| 施展骗术 | 1 行动（重大） | 花费 1 → 从目标处得 2 |
| **合计** | 2 行动 | 净得 1 (1→2) |

直接收益不大（净赚 1 情报），但更重要的是**削弱对手**——从其他玩家处拿走 2 情报意味着那些玩家少了 2 情报可用。这在高对抗局中价值大。

**整体评估**：🟢 技能设计有趣，收益适中。

#### 等级 2："毒蛇"理查德

| 技能 | 分析 |
| - | - |
| **地下网络**（无情报时补给阶段额外得 1 情报） | 保底机制。被清洗后至少每轮有 1 情报进账。 |
| **暗度陈仓**（➡️ 重大：花费 2 情报，将版图上 1 证据移回手中） | 花费 2 情报，将 1 个已在地点上的证据 Token 移回供应堆。这是**反侦查**手段——警长不能再通过侦查获得该证据。 |

**成本分析**：

- 暗度陈仓 vs 警长侦查：暗度陈仓花费 2 情报 + 1 行动 = 提前收回证据。警长的侦查已花费的成本全部白费（如果之前蹲点的话）。
- 但这个技能需要先作案（花费情报得 1 分），然后发现有人要侦查再收回来。节奏上是"行动→得分→收回证据→再行动"。

**整体评估**：🟢 设计稳健。暗度陈仓是有效的反侦查手段，但需要预先花费情报作案，2 情报的收回成本合理。

#### 等级 2："铁拳"马库斯

| 技能 | 分析 |
| - | - |
| **暴力催收**（➡️ 重大：花费 1 情报，抽取 1 名玩家 2 张手牌） | 超强！手牌上限 3 张，抽取 2 张意味着目标几乎失去全部手牌。而且可以针对任何人（包括警长）。花费仅 1 情报，成本极低。 |
| **硬汉体质**（越狱时总情报花费 -1） | 越狱时每格花费 2 情报，减 1 等于总花费减 1。效果有限（越狱次数少）。 |

**暴力催收的超模分析**：

- 从任意 1 名玩家手中抽取 2 张手牌。手牌是策略牌，是玩家的战术储备。
- 抽取意味着被抽者失去这 2 张牌，等于被抢了 ≈2 次摸牌行动 + 可能的牌效价值。
- 花费仅 1 情报（≈1 次调查），获得的收益是极大的战略优势。

**整体评估**：🔴 暴力催收可能超模。对比"幽灵"的华丽骗术（花费 1 情报得 2 情报），暴力催收花费 1 情报就是剥夺对手 2 张手牌，战略价值远高于 2 情报。

#### 等级 2："鬼手"阿列克谢

| 技能 | 分析 |
| - | - |
| **精妙手法**（调查额外得 1 情报） | 每调查 1 次得 2 情报而不是 1。效率翻倍。这是本设计中最好的资源型技能之一。 |
| **后巷密道**（⚡️：花费 1 情报，将证据移至相邻地点） | 灵活的证据移动。可以在警长即将侦查前移开证据，也可以配合作案策略。⚡️不消耗行动，性价比高。 |

**成本分析**：

- 调查效率翻倍意味着鬼手积累情报的速度是其他人的 2 倍。
- 2 次调查 = 4 情报（别人只有 2），用 2 行动完成别人 4 行动的工作量。
- **超模评估**：每轮 2 行动全部调查 → 4 情报/轮（普通 2 情报/轮）。12 轮多出 24 情报的差距。

**整体评估**：🔴 精妙手法可能超模。调查效率翻倍在长时间游戏中累积优势过大。

#### 等级 3："双面人"维克托

| 技能 | 分析 |
| - | - |
| **金融犯罪**（➡️➡️ 重大：花费 3 情报得 3 分，每局限 1 次） | 1:1 情报到分的转化率。对比作案：3 情报在上城区作案的回报 ≈ 3.25+1=4.25 分。所以金融犯罪的效率低于上城作案，但优势是**不暴露证据 Token**（即不给警长侦查目标）。 |
| **金蝉脱壳**（↩️：花费 2 情报防止证据被侦查获得，每局限 1 次） | 阻止一次侦查。花费 2 情报，阻止警长的侦查投入（≈3.32 情报 + 1 行动）全部白费。 |

**金融犯罪的量化**：

- 3 情报 = 3 分，每局限 1 次
- 3 情报的获取成本：3 次调查 = 3 行动
- 金融犯罪本身：2 行动（➡️➡️）
- **总成本**：5 行动 → 3 分 = 0.6 分/行动
- 对比上城作案（等级 3 有超额）：≈ 0.68 分/行动
- 金融犯罪效率略低于作案，但无证据暴露风险。**设计合理**。

**整体评估**：🟢 合理。两个技能一攻一防，配合良好。

#### 等级 3："屠夫"汉斯

| 技能 | 分析 |
| - | - |
| **致命打击**（上城作案额外 +1 分） | 上城区作案 3.25 分 + 超额 1 分（等级 3 在上城触发）+ 额外 1 分 = 5.25 分/次。这是极高的得分效率。 |
| **消灭痕迹**（➡️：花费 1 情报，移除版图 1 证据） | 花费 1 情报移除 1 个证据，防止被侦查。高效的反侦查手段。 |
| **亡命之徒**（补给阶段隐藏值回复至上限） | 每轮自动回满隐藏值（上限 2）。警长如果要抓屠夫，至少需要 2 个证据或情报补差。 |

**屠夫的得分效率**：

- 上城作案（平均情报 4.25）：4.25 情报获取成本 = 4.25 行动
- 作案本身：2 行动
- 总成本：6.25 行动
- 收益：3.25（影响值）+ 1（超额）+ 1（致命打击）= **5.25 分**
- **效率**：5.25 / 6.25 = **0.84 分/行动**
- 这是所有角色中**效率最高的得分手段**之一。

**整体评估**：🟡 得分效率高但隐藏值上限低（2），平衡了高风险高回报。配合亡命之徒的自动回满，屠夫的生存能力不错。

#### 等级 4："疯子"莱利

| 技能 | 分析 |
| - | - |
| **连环作案**（相邻有证据时额外 +X 分，上限 +3） | 最复杂技能。如果场上已有其他证据，在新地点作案时额外加分。上限 +3 意味着最多可得 4（影响值）+ 1（超额）+ 3（连环）= 8 分/次。 |
| **制造恐慌**（➡️：花费 2 情报，在无证据地点放 1 情报，额外得 1 情报） | 净收益：花费 2 情报，放置 1 情报+获得 1 情报= 净得 0 情报。但放置情报可以影响该地点的情报值。 |
| **隐藏狩猎**（被动：隐藏值上限 2，每轮回 2 隐藏值） | 被设计为"永远满隐藏值"（上限 2，每轮回 2）。警长必须补差 4 情报才能抓捕。 |

**连环作案的连锁实例**：

- 假设场上已有 3 个疯子莱利的证据（Token 分散在各处）
- 莱利在博物馆作案（影响值 4，情报值 5）
- 检查相邻地点是否有莱利的证据：如果博物馆的邻居有，触发连环
- 连环 X = 场上已有的莱利证据数（上限 3）= 3
- **收益**：4（影响值）+ 1（超额）+ 3（连环）= **8 分**

达成条件苛刻（需要 3 个相邻地点都有证据），但如果成功，单次作案可得 8 分——约占胜利 15 分的 53%。

**整体评估**：🟡 高上限但需要复杂部署，设计优秀。

### 2.3 超级英雄审查

超级英雄仅在 5-7 人局可用，此处做概要审查，但在 4 人局基准场景中不做主分析。

**核心问题**：情报截获（暗影）和铁拳制裁（夜枭）都对警长的抓捕周期产生严重影响。在 5-7 人局中，警长人数不变（1 人），但额外多了 1-2 个干扰者（超级英雄/受害者）。警长的劣势将会非常显著。

## 3. 策略牌审查

### 3.1 各策略牌效率分析

| 牌名 | 行动消耗 | 情报消耗/获得 | 得分 | 效率评估 |
| - | - | - | - | - |
| 情报报告 #01 | 1 | +2 | 0 | 2 情报/行动，效率相当于 2 次调查。超模？不，因为调查是基本操作，策略牌是有限的（仅 3 张）。**合理** |
| 情报截获 #02 | 1 | +1 | 0 | 相当于 1 次调查，但从任意地点拿。**偏弱但灵活** |
| 情报共享 #03 | 1 | 双方各 +1 | 0 | 社交型卡牌。**偏弱** |
| 情报干扰 #04 | 1 | 放置 2 情报在地点 | 0 | 增加地点的情报值→增加侦查和作案成本。**双刃剑** |
| 证据交易 #09 | 1 | +3 | 0 | 弃 1 证据得 3 情报。证据 Token 离开版图，警长失去侦查目标。**强** |
| 线人报酬 #10 | 1+2情报 | 0 | 0 | 牌库顶看 3 选 1。预设性地优化手牌。**中等** |
| 设伏 #16(延迟) | 1 | 0 | 0 | 延迟一轮使地点情报值 +2。**偏弱** |
| 大计划 #17(延迟) | 1 | 0 | +1(下次作案/抓捕) | 延迟一轮的固定 +1 分。**中等** |

### 3.2 策略牌的整体强度判断

**情报报告（#01）** 的效果是"从供应堆获得 2 情报"——即凭空产生资源。这是策略牌中最直接的资源获取，且效率是调查的 2 倍。但策略牌有限（3 张），且需要消耗行动打出，所以**合理**。

**证据交易（#09）** 是超强牌。弃 1 版图上的证据 Token，得 3 情报，同时使得警长无法侦查逃跑的证据。对于罪犯来说，这是"破坏警长计划 + 获得大量资源"的超值组合。

**紧急躲避（#12）** 是关键保命牌。当被指定为目标时，使效果失效。对于罪犯，这是防止被捕的最后手段。⚡️快速不消耗行动，但使用时机很关键（需要在被指定为目标时立即触发）。

## 4. 能力强度分布总结

## 5. 无基础得分手段的阵营补偿

### 5.1 受害者的得分途径

受害者（仅在 5-7 人局）不通过作案或抓捕得分，而是通过：

- **独家头条**（记者）：花费 2 情报，在已有证据的地点获得 2 分（重大，每局限 1 次）
- **黑料曝光**（掮客）：花费 2 情报，弃置目标手牌
- **越权执法**（裁决者）：延长刑期得分

**分析**：受害者的得分能力严重不足。记者的独家头条（2 情报→2 分）的效率是 1:1（情报:分），需要看 1 次消耗情报成本后，再做额外投入。对比罪犯的作案效率和警长的抓捕效率，受害者的得分效率偏低。

**结论**：受害者阵营的补偿不足。在 5-7 人局中，受害者可能处于极度劣势。

### 5.2 超级英雄的得分途径

- **铁拳制裁**（夜枭）：销毁证据得分。每销毁 1 个得 1 分。如果版图上有 3 个证据，一次行动可得 3 分。但重大+每局限 1。
- **战术干扰**（暗影）：弃置对手策略牌时得 2 分。如果成功弃置 1 张策略牌，得 2 分。每局限 1。
- **法律漏洞**（裁决者）：阻止得分并自己得 1 分。

**分析**：超级英雄的得分效率约等于或略低于警长。但与受害者的区别是：超级英雄可以直接阻止对手得分（法律漏洞、战术干扰）。这意味着超级英雄的竞争力不仅来自自身得分，还来自**削弱对手**。

**结论**：超级英雄的补偿合理，但受害者需要加强。

## 6. 审查总结

| 维度 | 结果 | 重点问题 |
| - | - | - |
| 地点梯度 | ✅ 合理 | 下→核心→上梯度清晰，博物馆作为顶点合理 |
