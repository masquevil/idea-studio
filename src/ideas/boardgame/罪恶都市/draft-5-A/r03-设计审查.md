# r03 · 设计审查（第四轮）

> 目标：根据 r02 基准检查地点/角色/策略牌设计质量
> 基础效率参照（r02）：罪犯打空作案稳态 0.5 分/资源、1.5 分/轮；警长抓捕链 0.5/1.5；设计基准 0.39-0.42 / 1.17-1.25

## 一、地点/区域梯度

### 1.1 区域参数梯度（r02 口径验证）

| 区域 | 初始情报 | 影响值 | 打空首次成本 | 作案回报 | 梯度评价 |
| - | - | - | - | - | - |
| 上城 | 4（博物馆 5） | 3（博物馆 4） | 4~5 调查 + 作案 = 2.5~3 轮 | 3~4 分 + 超额 | 高投入高回报 ✓ |
| 核心 | 3~4 | 2~3 | 3~4 调查 + 作案 = 2~2.5 轮 | 2~3 分 + 超额 | 标准 ✓ |
| 下城 | 2~3 | 1~2 | 2~3 调查 + 作案 = 1.5~2 轮 | 1~2 分 + 超额 | 低投入低回报 ✓ |

### 1.2 下城「安全低回报」的机制真相（🟡）

- 规则书/地点设计说"下城是安全缓冲区"，但**地理无移动限制**（§5.3 明确），所有玩家可任意选点行动
- 下城真实特征不是"安全"，而是**警长不重视**——影响值 1-2 的犯罪回报低 → 证据价值低 → 警长选择性忽视
- **风险**：下城成为罪犯"零风险种证据"区，长期放置证据但不作案得低分，用于诱骗警长浪费侦查资源；或因初始情报 2 打空极快（码头仓库作案 -1 → 成本 1→0），成为**稳定低风险得分点**
- 码头仓库：初始 2、影响值 1、作案 -1 → 打空后 0 情报成本作案，每次 1 分（+超额 1 = 2 分）
  - 首次成本：2 调查 + 作案 = 1.5 轮 → 得 2 分
  - **全局效率 = 2 / (1.5 轮 × 3) ≈ 0.44**——接近基准且几乎无被抓风险（低价值证据）
  - 这是等级 1-2 罪犯的安全逃逸路径，🟡 可接受（效率不超基准），但注意其"0 风险"属性与设计意图"下城为缓冲"一致，不算缺陷

### 1.3 特殊地点交叉效应（🔴 火车站 + 黑市）

- **火车站（初始 4，黎明强制 +1）**：永不低于初始的"高情报点"。对罪犯是作案高成本陷阱；对警长是**侦查成本恒高**（4+）——但全版图最干旱时它反而是唯一有证据可查的点
- **黑市（初始 3，花费情报时 +1，每回合 1 次）**：地下经济与"码头仓库"-1 叠加？——黑市本身是无条件 +1，码头是作案 -1，可叠加：在黑市作案花费 I 情报 → 返还 1 = 净 I-1。若黑市打空（I=0）+ 地下经济 → 0 花费作案还 +1 情报 = **负成本作案**
- **关键组合**：黑市（3/2）+ 码头（2/1）同版图时（下城 3 张抽 3 必含 1~2 张），罪犯可构建"下城零成本回路"
  - 黑市打空：每次作案 0 情报花费（地点 0）+ 地下经济返还 1 → **净 +1 情报 + 2 分**（影响 2 无超额或超额）
  - 这是**负成本得分**，效率 = ∞（0 花费得 2 分 + 赚 1 情报），严重违反设计原则 6（仅基础资源获取消耗版图资源）与原则 14（交叉组合不超预期）
  - **结论**：🔴 地下经济应限定触发条件（如"花费≥1 时"或"本地点情报值>0 时"），或参照码头改为"作案花费 -1"。r05 将给出修改指令

### 1.4 区域梯度总评

| 结论 | 说明 |
| - | - |
| 梯度方向正确 | 上>核>下的投入回报梯度成立 |
| 下城低风险属性成立 | 但黑市交叉产生负成本回路（🔴） |
| 上城博物馆（5/4） | 25% 局不展出时等级 4 超额失效（r01 3.1，结构问题） |

### 2.3 能力强度分布总结

| 评级 | 角色·技能 | 依据 |
| - | - | - |
| 🔴 超模 | 铁腕·雷霆行动、猎犬·天罗地网、幽灵·华丽骗术、鬼手·精妙手法、双面人·金融犯罪 | 资源/得分效率显著超基础（0.5）与基准（0.42） |
| 🟡 合理 | 铁腕·铁腕执法、猎犬·追踪直觉、智囊·布局预判、老鼠全技能、毒蛇·暗度陈仓、铁拳全技能、鬼手·后巷密道、双面人·金蝉脱壳、屠夫全技能、疯子·连环作案/隐藏狩猎 | 条件型/机会型/保命型，效率在基础附近 |
| 🟢 偏弱/缺陷 | 智囊·战术分析、毒蛇·地下网络、疯子·制造恐慌 | 收益低或设计不清 |

> 🔴 超模 5 项集中在「资源效率翻倍 + 行动松绑」两类。而 4 人局警长抽 2 选 1（铁腕/猎犬出现的确定性高），罪犯 3 人抽 2 选 1——**幽灵/鬼手/双面人/铁腕/猎犬被抽中的概率极高**，超模角色几乎必然出现在每局游戏中。

### 2.4 等级梯度检查（原则 9/10：防御与等级正相关）

| 等级 | 隐藏上限 | 调查降隐藏 | 被捕风险 | 梯度评价 |
| - | - | - | - | - |
| 1 老鼠 | 3 | 正常 -1 | 低（核心区调查免疫） | ✓ 低风险小罪犯 |
| 2 幽灵/毒蛇/铁拳/鬼手 | 3 | 正常 -1 | 中 | ✓ 标准 |
| 3 屠夫 | 2 | 正常 -1 | 高（隐藏 2 易补差） | ✓ 高风险 |
| 4 疯子 | 2+加速 | 正常 -1 且调查额外 -1 | 极高（隐藏 2，调查即掉） | ✓ 最高风险 |

- 梯度整体成立，但**等级 3/4 的高风险补偿是否足够**？屠夫上城 +1、疯子连环 +2/链——回报对得起风险 ✓
- **但等级 1 老鼠"核心区调查免疫"使其隐藏几乎恒定**，而等级 1 作案回报也低（下城 1-2 分），效率 ≈ 0.44（§1.2）不超基准 → 老鼠实际是"低风险低回报"的稳健选择，可接受 ✓

### 3.2 策略收敛检查（原则 15）

| 维度 | 检查 | 结论 |
| - | - | - |
| 罪犯单一最优 | 打空作案稳态 0.5 vs 直接作案 0.33~0.5 | 打空略优但受复苏内卷制约 → 无绝对收敛，但**下城负成本回路（§1.3）若成立则策略强收敛** |
| 警长单一最优 | 抓捕链 vs 无证据奖励 | 抓捕链明确最优，无证据奖励是政策性收益 → 收敛合理（警长本应主抓） |
| 牌堆收敛 | 情报报告 3 张最常见卡 | 资源牌占比 29%（10/34），不会过度收敛 ✓ |

### 3.3 牌堆与角色联动

- 鬼手·精妙手法 + 情报报告/截获：调查翻倍 × 资源牌 → 资源积累爆炸（🔴 与 2.2 鬼手超模叠加）
- 疯子·连环作案 + 大计划：单次作案 5 分（3 影响+2 连环+1 大计划）——上城打空成本对冲 ✓（🟡 可观察）
- 铁腕 + 大计划：抓捕 +1 再 + 高效 +1 → 单次抓捕 4-5 分（等级 3+）——配合雷霆行动每轮 1 次（🔴 铁腕超模的倍增器）
