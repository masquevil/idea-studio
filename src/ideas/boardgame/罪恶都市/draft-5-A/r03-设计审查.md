# r03 · 设计审查（第五轮）

> 评审范围：根据 r02 的 0 能力基准，对设计质量进行审查看——地图/地点系统区域梯度、角色/能力成本收益分析、能力强度分布（超模/合理/偏弱）、卡牌效果成本分析、策略收敛检查、无基础得分手段阵营的补偿。
>
> 依据：r02 基准（罪犯 0 能力 1.0-2.0 分/资源、警长抓捕链 0.6-1.1 分/IR）；设计基准 0.39-0.42 分/资源。

## 一、地点系统梯度审查

### 1.1 区域收益梯度

| 区域 | 参考情报/影响 | 0 能力稳态作案效率 | 梯度评价 |
| - | - | - | - |
| 下城（影响1） | 2/1 | 0.33 分/资源 | ⚠️ 等级 2+ 无超额 → 收益过低，仅作避险 |
| 核心（影响2） | 3/2 | 1.0 分/资源 | ✅ 等级 1-2 主战场，梯度合理 |
| 上城（影响3） | 4/3 | 1.33-2.0 分/资源 | ⚠️ 等级 3 的超额条件（≥3）仅上城达标，梯度尚可 |
| 博物馆（影响4） | 5/4 | 1.33-2.0 分/资源 | ⚠️ 等级 4 唯一超额点，准备成本过高 |

**问题 D3-1（下城收益过低）**：下城影响值 1 对等级 2+ 罪犯无超额 +1，稳态每次作案仅 1 分（2 行动 + 1 情报 = 3 资源换 1 分 = 0.33 分/资源），显著低于核心区 1.0。作为"安全避风港"其效率惩罚过重——罪犯宁可冒险也不去下城，下城 3 张地点牌在大部分对局中沦为"情报砖"。

**问题 D3-2（博物馆对等级 4 的成本悬崖）**：等级 4 疯子仅博物馆（影响 4）可超额，但需压 5 次调查（初次成本极高）+ 隐藏上限 2 使调查自损风险巨大。若疯子不上博物馆，则与等级 2 一样吃核心区（影响 2，无超额，仅 2 分/次=0.67 分/资源），等级 4 的高风险未换来对应回报 → **等级 4 的结构劣势**。

| 地点 | 效果 | 评价 |
| - | - | - |

| 博物馆 | 高情报值 5 | ✅ 借数值体现梯度，无文字冗余 |
| 港口区·走私通道 | 移动证据至下城 | ✅ 战术向（转移侦查焦点/藏证据） |

| 地下酒吧·情报黑市 | 调查 +1 情报 | ✅ 资源点，配合调查双效 |
| 医院·康复中心 | 调查 +1 隐藏恢复 | ✅ 让罪犯"调查不亏"，弥补调查自损 |
| 学校和图书馆·安静区域 | 禁止布控 | ✅ 防御型避难所 |
| 黑市·地下经济 | 花费情报 +1 回馈 | ✅ 用情报换情报的循环点 |
| 码头仓库·隐秘卸货 | 作案花费 -1 | ✅ 低阶罪犯友好（下城唯一亮点） |

**问题 D3-3（医院·康复中心 与 隐藏自损的张力）**：医院"调查恢复 1 隐藏"实际上**抹平了调查的隐藏自损**（调查 -1 隐藏 → 恢复 +1）。这让罪犯在医院的调查变得"免费"，与规则书 §6.1"调查使罪犯隐藏值 -1"的核心代价相冲突——调查是"资源+隐藏"双代价，医院把这个代价改成单资源。若罪犯可长期赖在医院调查，则压 0 成本进一步下降，放大 r02 的超模问题。**建议评估：医院效果改为"调查时隐藏不降低"（与老鼠·人群掩护同款）还是"调查后恢复 1"，两种取向对压 0 超模的影响不同。**

**问题 D3-4（核心区 vs 下城情报分布）**：黑市（下城，情报 3/影响 2）是下城唯一影响 2 的例外，其收益梯度打破了"下城 = 影响 1"的一致性。等级 2 罪犯若专注黑市可获 1.0 分/资源（与核心区相同）——但黑市地处下城，安全。**下城出现一个高性价比点使下城不再纯粹"避风港"，梯度被局部打破但增加了选择多样性**，判定为 🟡 可接受，需注意黑市是否成为等级 2 罪犯的新最优解（若黑市过强，则核心区反而无优势）。

### 3.2 策略收敛检查

**收敛风险 D3-5**：若把"牌效 × 打出便利"综合排序，**高价值牌集中在 07/09/13/14（+偏斜的 17/18）**，而信息牌 05/06 价值偏低。理性玩家会倾向抓取/保留高价值牌，导致**牌库内策略多样性被压缩**到少量强牌。与 r02 的压 0 作案收敛叠加（见 r04），存在双收敛风险。

## 四、无基础得分手段阵营补偿审查

### 4.1 英雄补偿

- 英雄无"作案/抓捕"基础动作，得分全靠技能。
