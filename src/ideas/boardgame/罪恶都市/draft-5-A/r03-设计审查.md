# r03 · 设计审查：基于 r02 基准检查地点/角色/策略（第七轮）

> 依据 r02 的 0 能力基准，逐项检查：地点梯度、角色技能成本收益、策略牌影响。
> 评审基准：4 人局（1 警长 + 3 罪犯）。加权口径：得分+剥夺 ≈1.33（§3.6）。
> 强度分级：超模 / 合理 / 偏弱。

---

## 一、地点系统审查

### 1.1 区域梯度

| 区域 | 参考情报/影响 | 0 能力效率 | 判定 |
| - | - | - | - |
| 下城 | 2 / 1 | 2 分/次，准备 1 轮，效率 0.67 分/IC | 低效但安全（等级 1-2 托底） |
| 核心 | 3 / 2（高值 4/3） | 3 分/次，效率 1.00 分/IC | 标准区，主战场 ✓ |
| 上城 | 4~5 / 3~4 | 4 分/次，准备 2 轮，效率 ~0.89 分/IC | 高回报高风险 ✓ |

**判定**：梯度合理。下城 0.67 < 核心 1.00 < 上城 ~0.89？——**上城单次 IV 高但准备轮长（2 轮），资源效率反而略低于核心区**。这是"高回报高风险"的解读：上城收益通过"单次 4 分 + 暴露风险"体现，而非资源效率。可接受，但上城对等级 3/4 的价值主要在"短周期达标"（4 次即 16 分）而非效率。

**关注点**：上城初始情报 4-5，等级 3/4 罪犯压点需 2 个调查轮（4 行动），期间暴露无防御 → 若警长在此期间布控上城，罪犯评估后可能转向核心区。**核心区高值地点（港口/火车站 4/3）是关键平衡阀**：它们让等级 2 罪犯也能享受影响 3 的 4 分收益（匹配 ✓），防止"只有上城才有高分"。

### 1.2 特殊地点效果

| 地点 | 效果 | 审查 |
| - | - | - |
| 金库（金融中心） | 证据不能被策略牌选中 | ✓ 保护证据，强化上城防御；与"栽赃陷害/证据误导"等牌交互形成明确约束 |
| 监控（市政厅） | 侦查额外 +1 情报 | ⚠️ 与猎犬"追踪直觉"叠加：侦查净花费 = 地点情报 -1。核心区情报 1 的地点侦查 = 0 净花费还 +1 情报？需注意侦查从**地点**花钱，回的是**供应堆**情报，顺序是"花 X → 回 1"，净 X-1。若地点情报 1 → 净 0。**侦查成本可降到 0 是强加成**，叠加后效率需观察（r03 标记测试） |
| 鱼龙混杂（红灯区） | 侦查花费 +1 | ✓ 平衡高影响值核心区（2/4），给警长制造取舍 |
| 流动人口（火车站） | 黎明 +1 情报（≤初始值） | ✓ 核心高值区的情报回填，维持其 4 分作案成本不被压死；注意"不超过初始值"限制正确（防溢出） |
| 情报黑市（地下酒吧） | 调查额外 +1 情报 | ✓ 每回合限 1 次；配合鬼手"精妙手法"（调查后回 1）可叠加 → 调查 1 行动得 3 情报（1 地点 +1 黑市 +1 精妙）+ 压点。**资源产出增强，需 r03 评估是否过快**（见角色审查） |
| 康复中心（医院） | 黎明回复隐藏值 | ✓ 与罪犯调查掉隐藏形成对冲，低风险续航 |
| 安静区域（学校） | 不能布控 | ✓ 为罪犯保留无布控的"安全点" |
| 走私通道（港口）/ 捷径（地下通道） | 移动证据 | ⚠️ 适用者未定义（r01 3.2）；若任何角色可用，警长可用它把证据移到便于统一侦查处，英雄可移动至便于制裁处——**扩大适用面的策略空间可接受，但需 FAQ 明确** |
| 地下经济（黑市） | 花费情报回 1（每回合限 1） | ⚠️ 触发归属未定义（r01 3.1）；若"每回合全局 1 次"则多人竞争低效，若"每人 1 次"则黑市成为强力资源点。**建议"每人每回合限 1 次"，黑市作为下城唯一情报 3 地点，是下城区经济中枢** |
| 隐秘卸货（码头仓库） | 作案花费 -1（最低 0） | ✓ 下城作案成本再降，配合压 0 后花费 0，等级 1-2 的低成本路线明确 |

### 1.3 地点系统结论

- 梯度合理，核心高值点是平衡阀 ✓
- "监控 + 猎犬"叠加需测试观察（🟡）
- "黑市地下经济 / 港口走私通道"适用者需 FAQ 明确（🟡）

## 二、角色技能审查（叠加 r02 基准）

### 2.1 警长角色

| 角色/技能 | 成本 | 收益 | 审查判定 |
| - | - | - | - |
| 铁腕·雷霆行动 | 弃 1 手牌 | 本轮 +1 行动 | **合理**。1 牌换 1 行动（1:1），手牌上限 3 限制频率；配合抓捕可"侦查+抓捕同轮"（省 1 个侦查轮）→ 抓捕周期 2 轮→1 轮强化。强度中等 |
| 铁腕·铁腕执法 | 0 | 抓隐藏 ≤1 罪犯 +1 分 | **合理**。鼓励调查压制隐藏后抓捕；隐藏 ≤1 需罪犯调查过或初始上限 1（老鼠）。条件型加成 |
| 猎犬·追踪直觉 | 0 | 侦查额外 +1 情报 | ⚠️ **偏强**。侦查净花费 = 地点情报 -1；核心压 1 后侦查净 0，等于免费取证。叠加市政厅监控则**净 -1（倒赚）**。建议观察：使侦查的资源成本可忽略 → 警长取证链大幅加速。**标记测试重点** |
| 猎犬·天罗地网 | 1 情报 | 免行动布控（每回合限 1） | **合理偏强**。免费布控相当于把布控的行动成本转化为 1 情报（行动是上游资源，1 行动 ≈ 1 情报，等价但更灵活）。OK |
| 智囊·战术分析 | 1 行动？+ 借用 | 查看手牌 + 借牌打出 | ⚠️ **偏强（信息+行动双收益）**。查看手牌是信息收益，借牌打出是行动收益；"支付对应行动力"使其受行动位限制，但每回合限 1 次仍强。**若借到"大计划"等得分加成牌，收益叠加**。建议每回合限 1 次已存在，维持，测试观察 |
| 智囊·布局预判 | 0 | 布控时相邻地点 +1 情报 | **合理**。布控的衍生收益，鼓励相邻布局 |

**警长结论**：猎犬"追踪直觉"为当前最强技能候选（侦查几乎免费），其余合理。铁腕与智囊提供爆发/信息，定位清晰。

### 2.2 罪犯角色（按等级）

**等级 1 · 老鼠**

| 技能 | 成本 | 收益 | 判定 |
| - | - | - | - |
| 人群掩护 | 0 | 核心区调查不降隐藏 | **合理偏强**。老鼠隐藏上限 1（最低），若不降隐藏则调查无代价 → 老鼠可高频调查攒情报无防御损耗。结合"低等级易被抓"的设计，此技能化解了等级 1 的核心弱点，使老鼠存活率大增 → **等级 1 的"易被抓"补偿**。合理 |
| 见风使舵 | 4 情报 | 取消抓捕（每局限 1 次） | **合理**。4 情报约等于 2 个调查轮收益，一次保命；全局 1 次。成本高，权衡明确 |

**等级 2 · 幽灵 / 毒蛇 / 铁拳 / 鬼手**

| 角色 | 技能 | 判定 |
| - | - | - |
| 幽灵·华丽骗术 | 1 情报 → 2 情报（重大） | **偏弱**。占用重大位（与作案冲突）+ 1 行动 + 1 情报 → 净 +1 情报。对比直接调查（1 行动 → 1 情报 + 压点），华丽骗术只多 1 情报但**牺牲本回合作战权**。幽灵若频繁用骗术则作战频率下降 → 实际是"用作战频率换资源密度"。**效率偏低，幽灵可能干脆不用它**。建议加强（如改为 1 情报 → 3 情报，或去掉重大限制） |
| 毒蛇·地下网络 | 0（条件：情报为 0） | 补给额外 +1 | **合理**。触发条件苛刻（情报恰 0），是"贫困反弹"设计。配合读报/大开销路线 |
| 毒蛇·暗度陈仓 | 2 情报（重大） | 回收 1 版图证据 | **合理**。重大位冲突：回收证据 = 防抓，但与作案冲突 → 回合做不了两件事。属于防御性取舍 |
| 铁拳·暴力催收 | 1 情报（重大） | 查看弃 1 手牌 | **合理偏强**。尽管重大位冲突，但"查看+弃牌"是硬干扰；若**无限定**（r01 审查发现），每回合同样可多次（仅受行动限制：2 行动可 2 次弃 2 牌）→ 建议加"每回合限 1 次" |
| 铁拳·硬汉体质 | 0 | 越狱 -1 情报 | **合理**。越狱补充流增幅 |
| 鬼手·精妙手法 | 0（条件：本回合调查过） | 修整 +1 情报 | **合理**。调查联动 → 每次调查轮多 1 情报。叠加地下酒吧（+1/回合）可得 1 行动 3 情报，资源产出偏快但依赖特定地点在场。**标记测试** |
| 鬼手·后巷密道 | 1 情报 | 移动 1 证据至相邻 | **合理**。布局/规避布控 |

**等级 3 · 双面人 / 屠夫**

| 角色 | 技能 | 判定 |
| - | - | - |
| 双面人·金融犯罪 | 2 行动 + 3 情报（重大，全局 1 次） | **合理**。2 分/次，效率 2/5 = 0.4 分/IC（远低于作战 1.00）——但**不依赖版图、不暴露**。是"无风险保底"，价值在稳定性而非效率。全局 1 次限制正确 |
| 双面人·金蝉脱壳 | 4 情报（每局限 1） | **合理**。高成本救关键证据（防高效抓捕） |
| 屠夫·消灭痕迹 | 1 情报 | 回收版图证据 | **合理**。低成本回收防抓；与暗度陈仓（2 情报）对比，屠夫更高效 |
| 屠夫·亡命之徒 | 0 | 越狱 -2 情报 | **合理**。强化越狱流 |

**等级 4 · 疯子**

| 技能 | 成本 | 收益 | 判定 |
| - | - | - | - |
| 连环作案 | 0 | 相邻每 1 证据 +1 分（无上限） | **爆发核心，需重点评估**。理想布阵：疯子用制造恐慌在相邻地点布 3-4 证据，一次作战 = 影响 3-4 + 匹配 1 + 相邻加成 3-4 = **7~9 分**。单次超模嫌疑大 |
| 制造恐慌 | 1 行动（**无情报费**） | 放置 1 证据 | ⚠️ **布证成本为零情报**。对比正常作案的"证据放置"需要 1 情报 + 影响值花费，制造恐慌只用 1 行动。疯子在 4 回合内可免费布 4 证据（2 行动/回合 × 2 回合）→ 第 3 回合一次连环作案爆发 7-9 分。**这是超模候选**。建议：给制造恐慌加情报费（如花费 2 情报），或限制"放置的证据不能用于连环作案相邻加成"（不推荐，机制复杂），或加"重大"限制 |
| 隐藏狩猎 | 0 | 上限 2；补给回 2；调查额外 -1 | 防御极弱是刻意的风险锚。**但注意：补给回 2 与调查 -2 抵消**，疯子若不上城调查则隐藏保持 2 → 警长抓疯子（等级 4 = 4 分 + 高效）收益极大，风险锚成立 |

**疯子推演（当前规则）**：R1 制造恐慌×2（核心区相邻 2 证据）；R2 制造恐慌×2（再 2 证据）；R3 连环作案（核心区影响 2，相邻 2-4 证据）→ 2+1+3~4 = **6~7 分/次**。1 次作战 ≈ 正常罪犯 2 次作战。**虽风险高（隐藏 2），但收益严重超线**。**判定：超模，需 nerf 制造恐慌（加情报费或频率限制）**。

### 2.3 角色技能强度分布汇总

| 阵营 | 超模候选 | 合理 | 偏弱 |
| - | - | - | - |
| 警长 | 猎犬·追踪直觉（侦查近免费，🟡 偏强） | 铁腕全技能、猎犬·天罗地网、智囊·布局预判 | — |
| 罪犯 | **疯子·制造恐慌**（0 情报布证，🔴 超模）；铁拳·暴力催收（若无限定频率，🟡） | 老鼠全、毒蛇全、鬼手全、双面人全、屠夫全 | 幽灵·华丽骗术（🟡 效率低） |
| 英雄/受害者 | — | 见 r04（扩展局） | 受害者需依赖爆料修复（r01 1.2） |

**原则 4 检查**（特殊能力效率 ≤ 基础效率）：

- 疯子的连环作案+制造恐慌组合效率 ≈ 6~7 分 /（2 行动+少量情报）远超基础 1.00 分/IC → **违反原则 4**
- 其余角色技能大多在基础效率附近或以下是条件型/防御型 → 通过

## 三、策略牌影响审查（叠加基准）

### 3.1 资源类

| 牌 | 效率评估 |
| - | - |
| 情报报告（2 情报） | 1 行动 + 1 牌 → 2 情报。对比调查（1 行动 → 1 情报 + 压点），信息报告多 1 情报但**不压点**。各有优劣，合理 |
| 情报截获（1 情报） | 1 行动 + 1 牌 → 1 情报（从任意地点）。与调查等价但**不降地点情报、不降罪犯隐藏** → 对罪犯有利（调查不掉隐藏）、对警长不利（不压点）。战术价值中等，合理 |
| 情报共享（双方 +1） | 1 行动 + 1 牌 → 双方各 1 = 2 情报（分给两人）。总量等价，但**让对手获益** → 使用时机受限。合理（外交牌） |
| 情报干扰（地点 +2） | 1 行动 + 1 牌 → 目标地点 +2 情报。**反向调查**——抬高地点的作案/侦查成本。罪犯可用来抬警长侦查成本？地点情报高 → 警长侦查花更多。**全阵营有干扰价值**。合理 |
| 线人报酬 | 1 行动 + 1 牌 + 1 情报 → 检索 1 张。检索成本 ≈ 1.5 牌 → 合理 |

### 3.2 信息/干扰类

| 牌 | 评估 |
| - | - |
| 尾随跟踪 / 暗中观察 | 信息价值，1 行动 1 牌换信息。合理（纯信息不产资源/分数） |
| 栽赃陷害 | 移动证据 1 格。对警长的价值：聚集证据便于一次侦查多拿；对罪犯：防御布控/转移证据。合理 |
| 暗中行动 | 隐藏 ±1。警长降隐藏利于抓捕；罪犯提隐藏防抓；英雄降隐藏利于制裁花费。**全阵营收益明确**。合理 |

### 3.3 防御/反击/得分类

| 牌 | 评估 |
| - | - |
| 金库保险 / 紧急躲避 / 不在场证明 | 干扰/防御韧性。合理；"不在场证明"打断重大动作是强干扰但只有 1 张，频率低可接受 |
| 通风报信 | ±2 情报。强资源干扰，但需弃 1 牌。合理 |
| 恰到好处 | 他人得分 → 你 +1 情报。**被动资源流**，在 4 人局高频触发（每轮多人得分）→ 长期累计可观。合理偏强但非超模 |
| 设伏 | 目标地点情报 +2（下个花费情报的行动）。与布控（+2）叠加 → +4。**强压制但延时条件性**。合理 |
| 大计划 | 🔴 **P1 违反**（r01 1.3）+ 得分加成仅 2 张。修复后需注意"额外 +1 分"对全阵营 KSA 的普适加成是否过强（每次作案/抓捕 +1 → 罪犯 5 次 +5 分超标？）——**修复时应考虑限制频率**（如"每次行动适用，但每张牌全局限用 1 次"或改为"一次性 +X 分"） |

### 3.4 策略牌结论

- 大部分牌合理；"大计划"需修复（P1）+ 修复时控制强度
- 牌库整体资源/信息/干扰平衡，得分加成过少（6%）导致追分主要靠 KSA 本身

## 四、无基础得分手段的阵营补偿

- 4 人局仅警长/罪犯，两者都有基础得分手段（抓捕/作案）→ 不涉及。
- 英雄/受害者（5-7 人局）在 r04 综合评估。
- 罪犯阵营中**幽灵**（无直接得分技能）依赖作战基础手段，不存在"无基础得分手段"问题。
- 警长无技能时依赖抓捕 + 和平（和平窗口短），**警长基础分手段偏弱**（依赖罪犯行动）→ 通过技能（猎犬侦查加速/铁腕爆发）补偿，机制上成立。

## 五、r03 结论摘要

**🔴 超模候选**：

1. **疯子·制造恐慌**（0 情报布证）→ 连环作案爆发 6-7 分/次，违反原则 4。建议给制造恐慌加情报费（2 情报）或加"重大"限制。

**🟡 偏强/关注**：
2. 猎犬·追踪直觉 + 市政厅监控叠加 → 侦查近免费/倒赚。建议测试观察或限制（如"追踪直觉"改为"侦查后从供应堆获得 1 情报"已如此——是侦查花地点情报、回供应堆情报，净 X-1；叠加监控净 X-2。核心区压 1 时净 -1 倒赚）。
3. 铁拳·暴力催收无限定频率。
4. 鬼手·精妙手法 + 地下酒吧叠加（1 行动 3 情报）。

**🟡 偏弱**：
5. 幽灵·华丽骗术（重大位冲突导致效率低）。

**其他**：地点梯度合理、核心高值点是平衡阀、大多数技能定位清晰。
