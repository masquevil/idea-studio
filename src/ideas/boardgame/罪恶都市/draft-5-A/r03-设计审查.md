# r03 · 设计审查（第九轮 · 修订版）

> 评审依据：当前版设计文档 + 同轮 `r02-量化基准.md`（第九轮：0 技能基准，作案回填 +1 口径）。
> 范围：按 r02 基准检查设计质量——地点系统收益梯度、角色特殊能力成本收益、策略牌效果、无基础得分手段阵营的补偿。
> 能力强度评级：🔴超模 / 🟡合理偏强 / ✅合理 / ⚪偏弱。

## 1. 地点系统审查

### 1.1 区域收益梯度（对照 r02 基准）

| 区域 | 参考情报/影响 | r02 单次作案（等级2） | 效率（分/资源） | 评价 |
| - | - | - | - | - |
| 上城 | 4/3 | 影响3+匹配1 = 4 分；压 1 需 3 次调查；回填后重压成本高 | 4/(2+3+重压) ≈ 0.5-0.6 | 高回报但压点/重压成本高，暴露大 |
| 核心 | 3/2 | 影响2+匹配1 = 3 分；压 0 后成本 0→1→2 递增 | 0.75（压0流 15/20） | **效率最优**，基准点 ✅ |
| 下城 | 2/1 | 影响1+匹配1 = 2 分 | 0.56（码头） | 低回报高安全；码头仓库为等级1-2 安全区 ✅ |
| 博物馆 | 5/4 | 影响4（等级4匹配） | 0.5 左右 | 等级 4 专属；压点成本极高（5 情报压 0 需 3 轮） |

**结论**：区域梯度合理。核心区效率最优（0.75）符合基准区定位；上城（0.5-0.6）高回报高风险、下城（0.56）低回报高安全。**作案回填使各区"持续刷分效率"更接近**（都要周期性重压），区域差异主要由"单次回报"和"压点深度"体现。

### 1.2 特殊地点效果审查（重点更新）

| 地点 | 效果 | 成本/收益（含回填后） | 评价 |
| - | - | - | - |
| 火车站·流动人口 | 黎明回填 1 情报 | 与作案回填同为情报抬升源；**反压点**——罪犯压 0 后火车站每黎明 +1，需更频繁重压 | 🟡 偏强（对罪犯压点流是持续干扰；对警长是侦查成本回升的隐患）。**注意：火车站是双刃剑，既防版图枯竭又抬侦查成本** |
| 码头仓库·隐秘卸货 | 作案花费 -1（最低 0） | 压 0 后成本序列 0、0、1（r02 §2.3） | ✅ 合理（前 2 次 0 成本，但总量低） |
| 市政厅/地下酒吧/黑市 | 侦查/调查回扣 | 与上轮结论一致 | ✅ 合理 |
| 医院·康复中心 | 黎明有证据 +1 隐藏 | 罪犯每轮被动回 1 隐藏（与补给回复叠加） | 🟡 偏强：配合补给回复，压点流罪犯隐藏回复速度 ×2，显著提高防抓。r04 观察 |
| 红灯区/学校/港口/地下通道 | 压制/保护 | 与上轮一致 | ✅ 合理 |

**注意点（新）**：作案回填 +1 使"压 0"成本曲线不再平坦，对**多罪犯共挤一点**的局面有自然抑制（3 个罪犯全压同一地点 → 各自作案都会回填，抬升彼此下一次的成本）→ **间接缓解策略收敛** ✅（r04 详查）。

## 2. 角色能力审查（对照 r02 基准）

> 基准：罪犯资源效率 0.75、警长 1.0（抓压点）。特殊能力效率不应显著高于基础效率（原则 4）。

### 2.1 警长角色

| 角色 | 技能 | 成本/收益 | 评级 |
| - | - | - | - |
| 铁腕·雷霆行动 | 弃 1 牌 +1 行动 | 警长 → 3 行动/回合，把"取证+抓捕"2 轮压成 1 轮 | 🟡 偏强（×1.5 提速） |
| 铁腕·铁腕执法 | 抓隐藏 ≤1 +1 分 | 利好抓低等级/压点罪犯（隐藏 0-1）——**与作案回填时代"罪犯压点暴露"常态契合** | ✅ 合理 |
| 猎犬·追踪直觉 | 侦查回扣 1 情报 | 取证成本 -1 | ✅ 合理 |
| 猎犬·天罗地网 | 1 情报布控 | 布控成本行动→情报 | ✅ 合理偏强 |
| 智囊·战术分析 | 借牌（需限自己回合） | 借牌收益 | ✅ 合理（需补时机约束，r01 N14） |
| 智囊·布局预判 | 布控时相邻 +1 情报 | 白嫖情报 | ✅ 合理 |

**警长总结**：铁腕（×1.5）仍显著强于猎犬/智囊（成本削减型），阵营内差异留存（r04 C05，测试观察）。技能整体可补足 0 技能偏慢，将警长拉到 ~9-10 轮。

| 角色 | 技能 | 成本/收益（含回填） | 评级 |
| - | - | - | - |
| 老鼠·人群掩护 | 核心调查不减隐藏 | **价值上升**：压0 流需多次调查（首压+重压），隐藏损失大；此技能让核心压点完全免隐藏代价 | 🟡 偏强（等级 1 核心生存技能） |

| 双面人·金融犯罪 | 3 情报 2 分 | 效率 0.4 低，但无版图依赖（被封锁时保底） | ⚪ 偏弱（保底定位可接受） |
| 双面人·金蝉脱壳 | 4 情报救证 | 保命低频 | ⚪ 偏弱 |
| 屠夫·消灭痕迹 | 1 情报移除证据 | 防侦查 | ✅ 合理 |
| 屠夫·亡命之徒 | 越狱 -2 情报 | 越狱低频 | ⚪ 偏弱 |
| **疯子·连环作案** | 相邻证据逐个 +1（无上限） | **r04 详算**：作案回填使成本递增，疯子爆发被自然抑制（每次作案后地点 +1，无法持续 0 成本连击）——但相邻加成仍可能使单次 5-7 分 | 🔴 待 r04 量化（风险较上轮下降） |

**罪犯总结**：

- **幽灵/鬼手/老鼠的技能价值在回填时代上升**（压点调查频率高 → 调查回扣/免隐藏更有用）。
- **疯子火力被作案回填自然抑制**（成本递增打断连续刷分），超模风险较上轮下降，但仍需 r04 精确核算。
- 低等级偏弱、高等级偏强的梯度保留 ✅。
