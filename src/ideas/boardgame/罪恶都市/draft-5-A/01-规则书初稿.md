# 规则书初稿

> 标准配置 4 人局（1警长+3罪犯）为设计基准

---

## 1. 游戏概述

### 1.1 背景故事

罪恶都市——一座被黑暗笼罩的城市。警长在体制内艰难执法，罪犯在街头暗中活动。所有人都在这座城市里追逐自己的利益，互相利用、互相压制。谁能第一个达到 15 分，谁就能在这场无休止的博弈中胜出。

### 1.2 游戏目标

- **跑分制**：游戏结束时，分数最高者获胜
- **终局条件**：① **有玩家达到 15 分，且本轮结束**；② **第 12 轮结束**
- **同分处理**：若多名玩家分数相同，则**共同获胜**
- **同时达标**：若多名玩家在同一轮结束时同时达到 ≥ 15 分，按分数高低排名；同分则共同获胜

### 1.3 游戏人数与阵营

本游戏共有 4 个阵营：**警长**、**罪犯**、**超级英雄**、**受害者**。标准 4 人局仅使用警长和罪犯；5 人及以上时逐步加入超级英雄和受害者。

| 人数 | 警长 | 罪犯 | 超级英雄 | 受害者 | 说明 |
| :-: | :-: | :-: | :-: | :-: | - |
| 2 | 1 | 1 | | | 迷雾阶段 2 次/轮 |

## 2. 配件说明

以下为游戏设置和进行过程中必需的核心配件：

| 配件 | 用途 |
| ------ | ------ |
| 地点牌（16 张，4 人局每局展出 12 张） | 组成城市版图，含 1 张特殊地点牌「看守所」 |
| 角色卡（每名角色 1 张） | 确定身份和技能，罪犯角色卡底部印有隐藏值轨道 |
| 策略牌（34 张，公共牌堆） | 提供战术选择 |
| "情报 Token"（蓝色方块，共 80 枚） | 全阵营通用资源 |
| "证据 Token"（罪犯头像圆片） | 标记作案 + 抓捕门票 |
| "警员 Token"（警徽圆片） | 警长布控专用 |
| "英雄 Token"（英雄头像圆片） | 超级英雄专属配件（每名超级英雄 1 枚），不同角色有不同效果 |
| "混乱 Token"（双面圆片，2 枚） | 受害者专属配件，背面灰色角色头像，正面一阴一阳 |
| "迷雾 Token"（红色圆片，4 枚） | 迷雾阶段专用，视为 "证据 Token"，不属于任何角色 |
| 隐藏值指示物（4个，黄色小方块） | 放在角色卡隐藏值轨道上标记当前隐藏值 |
| 分数/回合共用面板 | 一条轨道标记各角色分数（0-15），另一条标记当前回合（1-12） |

**供应堆**分为两类：

- **公共供应堆**：牌堆、分数标记、"情报 Token" 储备等
- **角色供应堆**：每个角色自身拥有的配件，如警长的"警员 Token"、罪犯的"证据 Token"等

## 3. 游戏准备

### 3.1 版图设置

```
① 将 16 张地点牌按上城（4 张）、核心（8 张）、下城（4 张）分成 3 堆
② 从上城主堆中随机抽取 3 张，核心区抽 6 张，下城区抽 3 张
③ 将 12 张地点牌全部展出，排成 3×4 网格（4 人及以上局）；2-3 人局改为上 3+核心 3+下 3 = 9 张，排成 3×3
④ 将「看守所」地点牌放在版图旁边（单独放置，不参与版图网格）
⑤ 在每个地点上放置等于其初始情报值数量的"情报 Token"（共 80 枚，放置后剩余部分放入公共供应堆）
```

### 3.2 角色分配

详见 [02-角色设计.md](./02-角色设计.md) 第 6 节。

```
① 所有玩家从自己所属阵营的角色池中随机抽取 2 张，选择其中 1 张作为本局角色
② 各玩家获得对应角色卡
③ 警长玩家获得：5 个"警员 Token"（放入自己的角色供应堆）
④ 罪犯玩家获得：
   ├─ 5 个印有自己角色头像的"证据 Token"（放入自己的角色供应堆）
   └─ 1 个黄色小方块，放在角色卡隐藏值轨道的上限数字上作为初始值
⑤ 超级英雄玩家获得：1 个"英雄 Token"（放入自己的角色供应堆）
⑥ 所有玩家获得初始资源：1 张策略牌（从公共牌堆摸取）
```

### 3.3 其他设置

```
① 将 34 张策略牌洗混，形成公共牌堆，放在版图旁边
② 将分数标记等放在公共供应堆
③ 设置回合标记为 1（第 1 轮）
④ 起始玩家：无受害者局（2-4 人）由警长作为每轮的起始玩家；有受害者局（5-7 人）由受害者作为每轮的起始玩家。各阵营行动顺序见 §5.4
```

## 4. 核心规则

### 4.1 能力

能力是描述卡牌效果的文字。卡牌必须**在场上**（角色牌、已展出的地点牌等）才能发动其能力。

#### 持续能力（被动）

没有额外图标，常驻生效。例如地点牌「火车站·流动人口」的强制能力——**强制 -** 黎明阶段在该地点放置 1 个"情报 Token"。

#### 触发能力

在效果文字前标有图标，玩家必须满足触发条件才能主动触发：

| 图标 | 类型 | 说明 |
| ------ | ------ | ------ |
| ⚡️ | 免费触发能力 | 任意时机触发，不消耗行动。可能附带限制条件，如`⚡️ 若你没有手牌：XXX` |
| ↩️ | 反应触发能力 | 满足特定条件时触发，条件多与时机相关。格式：`↩️ [触发时机]：[效果]`，如`↩️ 回合结束时：XX` |
| ➡️ | 行动触发能力 | 在你的回合中花费 1 个行动来主动触发。格式：`➡️ [费用/条件]：[效果]` |

示例：

- 无额外费用：`➡️：获得 1 "情报 Token"`
- 有条件：`↩️ 在你打出策略牌后：摸 1 张牌`
- 地点牌上的能力：`➡️ 花费 2 情报：获得 1 分`

#### 强制能力

效果文字前标注 `**强制 -**`，在特定条件下自动启用，不消耗行动，与其他能力或动作产生互动。玩家不能拒绝或阻止强制能力的效果。

> 示例：看守所的"**禁地**"——看守所不能被选为调查、侦查、作案等任何行动的目标。这是一个始终生效的强制限制。

### 4.2 行动

每回合可执行最多 2 个行动。游戏中共有 11 种行动，按所在阵营分组如下：

**通用行动**：

| 行动 | 效果 |
| ------ | ------ |
| 调查 | 从任意地点获得 1 个"情报 Token"（罪犯使用时，自身隐藏值 -1） |
| 摸牌 | 从公共策略牌堆摸 1 张牌 |
| 出牌 | 打出手中的 1 张策略牌 |

**警长行动** 🔵：

| 行动 | 效果 |
| ------ | ------ |
| 侦查 | 选择一个地点，花费等于该地点当前情报值的"情报 Token"，获得该地点上 1 个"证据 Token" |
| 布控 | 选择一个地点，放置 1 个"警员 Token"，其它角色计算该地点的情报值时 +2（本轮有效）。若当前版图上存在属于角色的"证据 Token"，可改为不花费行动（每回合限 1 次） |
| 抓捕 | **重大**。额外花费 1 个行动。选择一名罪犯，将你持有其的全部 X 枚"证据 Token"移入看守所，其版图上的"证据 Token"返回其角色供应堆。若 X < 其当前隐藏值，每差 1 额外花费 1"情报 Token"。获得犯罪等级对应分数。如果 X < 犯罪等级，额外 +1 分。（对"迷雾 Token"执行效果参见迷雾阶段的描述） |

**罪犯行动** 🔴：

| 行动 | 效果 |
| ------ | ------ |
| 隐藏 | 提高隐藏值 1 点（不超过角色卡上限） |
| 作案 | **重大**。额外花费 1 个行动。选择地点，花费情报（=地点当前情报值），放置 1 个"证据 Token"，在该地点放置 1 个"情报 Token"，获得影响值对应分数；若地点影响值与犯罪等级相差 ≤ 1，额外 +1 分；若 5 个"证据 Token"全在版图上则改为移动 1 个 |

**超级英雄行动**：

| 行动 | 效果 | 适用 |
| ------ | ------ | ------ |
| 登场 🟣 | **重大**。额外花费 1 个行动。选择 1 个地点，花费 = 该地点当前情报值的"情报 Token"，将你的"英雄 Token"放置到该地点，获得 X 分（X = 该地点"证据 Token"数量；黎明阶段收回） | 超级英雄专用 |
| 制裁 🟣 | **重大**。额外花费 1 个行动。选择版图上的 1 个"证据 Token"，花费 = 该"证据 Token"所属罪犯当前隐藏值 + 你当前拥有的"证据 Token"数量 的"情报 Token"。获得该"证据 Token"。获得 X 分（X = 你当前拥有的"证据 Token"数量） | 超级英雄专用 |

**受害者行动**：

| 行动 | 效果 | 适用 |
| ------ | ------ | ------ |
| 追偿 🟢 | **重大**。花费 2 个"情报 Token"。将你的 2 枚"混乱 Token"背面向上放在 2 名角色面前。黎明阶段翻开并收回：若持有阳面"混乱 Token"的角色从放置至黎明收回期间得分 ≥ 2，你可令其 -1 分、你 +1 分 | 受害者专用 |
| 爆料 🟢 | **重大**。花费 2 个"情报 Token"。将你的 2 枚"混乱 Token"背面向上放在 2 个不同地点。其它角色计算这些地点的情报值时 +1（可与布控/设伏叠加）。黎明阶段收回。地点上存在"混乱 Token"时你获得能力：↩️ 该地点被其它角色的重大行动选择成为目标时，你可翻开并收回该"混乱 Token"，若为阳面你 +1 分 | 受害者专用 |

### 4.3 花费与效果

执行一切行动时，遵循以下规则：

- **花费与效果分离**：先支付行动的花费（行动、"情报 Token"等），再执行行动的效果
- **效果被取消时不退费**：若某个行动或卡牌的效果被取消（如被 ↩️ 能力阻止），已支付的花费**不予退回**
- **花费的类型**：行动、"情报 Token"、弃置手牌等都属于花费；"获得分数"、"将证据移入看守所"、"使效果失效"等属于效果

> **示例**：警长进行"抓捕动作"时，额外花费 1 个行动，再执行将"证据 Token"移入看守所并获得分数（效果）。若罪犯使用 ↩️ 能力使效果失效，已花费的行动不会退回。

### 4.4 标签

标签是出现在卡牌上的简短规则标记，比如：“**重大**”所有标注该标签的效果每回合仅能执行 1 次。如抓捕、作案均为重大行动。完整定义见 §10.2。

### 4.5 资源

**放置/获得的来源约定**："放置"某 Token 默认从**公共供应堆**拿取放置；"放置**你的** ××"表示从你自己已有的资源中拿取。"获得"默认从公共供应堆获得；来源为其他处（如某地点、某玩家）时需明确写出。

#### 情报 Token

蓝色方块，全阵营通用基础资源，存放在公共供应堆。

- 玩家通过"调查"行动从地点获得
- 几乎所有的行动都需要花费"情报 Token"
- **无持有上限**（手牌有上限 3 张）
- 若公共供应堆的"情报 Token"不足，则少发（不足则不获得）
- 花费的「公共资源型」Token（如"情报 Token"）在花费后返回**公共供应堆**，可被再次获取
- 角色专属 Token（"证据 Token""警员 Token""英雄 Token"）按各自循环规则返回**角色供应堆**

#### 证据 Token

每个罪犯角色有 5 个印有自己头像的圆形 Token，存放在自己的**角色供应堆**。

- **放置**：罪犯进行"作案动作"时，将 1 个自己的"证据 Token"从角色供应堆放置到地点上
- **同一地点可叠放**：允许同一罪犯在同一地点放置多个自己的"证据 Token"（例如"作案溢出"移动到已放有自己"证据 Token"的地点）
- **获得**：警长进行"侦查动作"时，花费情报获得地点上的 1 个"证据 Token"（暂时持有）
- **抓捕**：警长进行"抓捕动作"时，将持有的全部该罪犯"证据 Token"移入看守所
- **溢出**：若 5 个"证据 Token"已全部在版图上（角色供应堆为空），进行"作案动作"时改为将其中 1 个已在地点上的"证据 Token"移动到新的目标地点（原地点上的"证据 Token"消失）

> **"证据 Token" 循环**：角色供应堆 → 作案（放置到地点）→ 侦查（警长暂时持有）→ 抓捕（移入看守所）→ 出狱（返回角色供应堆）
>
> 抓捕时：警长持有的该罪犯"证据 Token"全部移入看守所；该罪犯留在版图上的"证据 Token"全部返回其角色供应堆（不经看守所）。

### 4.6 隐藏值（仅罪犯）

每个罪犯角色有一个隐藏值（0 到角色卡上限），用角色卡底部的隐藏值轨道（0-5 共 6 格）表示。

- **提高方式**：进行"隐藏动作"（+1）/ 每回合补给阶段自动回复 1
- **降低方式**：进行"调查动作"（-1，可降至 0）
- **核心作用**：警长执行"抓捕"时，若消耗的"证据 Token"数量 < 当前隐藏值，每相差 1 点需额外花费 1 个"情报 Token"
- **被捕时不变**：罪犯被逮捕时隐藏值保持不变（作为抓捕时的读数），不会因被捕而变动

### 4.7 犯罪等级（仅罪犯）

角色卡上标注的犯罪等级（1-4），决定抓捕得分、看守所位置、匹配加分条件。

- **匹配加分**：在影响力与自身犯罪等级相差 ≤ 1 的地点作案时，额外 +1 分

| 犯罪等级 | 匹配加分条件 | 符合条件的区域 |
| --------- | ------------ | -------------- |
| 1 | 影响值 1-2 | 下城区(1)✅ + 影响值 2 的地点(核心)✅ |
| 2 | 影响值 1-3 | 下城区(1)✅ + 核心区(2)✅ + 影响值 3 的地点(上城/港口区/火车站)✅ |
| 3 | 影响值 2-4 | 影响值 2 的地点(核心/黑市)✅ + 上城区(3/4)✅ |
| 4 | 影响值 3-4 | 上城区(3/4)✅ |

## 5. 回合流程

### 5.1 回合结构总览

```
一轮结构（时长待实测后回写 / 4人局）
① 傍晚阶段（约 30 秒）
② 夜晚阶段（核心行动阶段，按顺序进行每个玩家的回合）
③ 黎明阶段（约 1 分钟）
```

> 2-3 人局额外有迷雾阶段：**傍晚 → 迷雾 → 夜晚 → 黎明**

### 5.2 傍晚阶段

```
① 触发"新的一轮开始时"效果的能力
② 宣布"傍晚结束，进入夜晚阶段"
```

### 5.3 迷雾阶段（仅 2-3 人局）

> 迷雾阶段通过放置"迷雾 Token"来消耗警长的侦查资源，放慢抓捕节奏。

```
① 由警长操作，执行（3 - 罪犯人数）次迷雾行动
② 每次：从情报值最高的地点中选 1 个 → 移除 1"情报 Token"
   → 在该地点放置 1 个红色"迷雾 Token"
③ 宣布"迷雾阶段结束，进入夜晚"
```

**迷雾 Token 的规则**：

```
"迷雾 Token"视为不属于任何角色的"证据 Token"处理（代表身份不明的作案者留下的痕迹）：
├─ 数量：共 4 枚。若不足，改为移动版图上已有的"迷雾 Token"
├─ 获取：警长对带有"迷雾 Token"的地点进行"侦查动作"时，花费等于该地点当前情报值的"情报 Token"，获得该"迷雾 Token"（与其他"证据 Token"同规则）
└─ 抓捕：警长对已获得的"迷雾 Token"执行"抓捕动作"，将其返回公共供应堆，每个获得 1 分（不进入看守所、无需选择目标罪犯）
```

> 2 人局 2 次迷雾操作 → 每轮至少有 2 个地点被迷雾覆盖，警长需要花费侦查资源获取后抓捕得分。3 人局 1 次迷雾操作。

### 5.4 夜晚阶段 — 玩家回合

**回合顺序**：受害者 → 警长 → 罪犯 → 超级英雄；同一阵营内按顺时针依次进行。（4 人局为 1 警长 + 3 罪犯，实际顺序为警长 → 各罪犯；受害者、超级英雄出现于 5-7 人局，完整顺序在扩展局生效）

每个玩家的回合包含 5 个子阶段：

#### ① 开始阶段

```
触发"回合开始时"效果的能力
```

#### ② 补给阶段

```
摸 1 张策略牌（从公共牌堆顶部摸取）
若为罪犯：隐藏值 +1（不超过角色卡上限）
```

#### ③ 行动阶段

每回合可执行最多 2 个行动。行动清单见 §4.2。

> 有些动作额外花费 1 个行动。出牌时若策略牌带有"快速"标签则不消耗行动。

#### ④ 修整阶段

```
检查手牌中的策略牌数量：
- 若 > 3 张，弃置多出的牌，直到手牌 = 3 张
- "情报 Token"无上限，无需弃置
```

#### ⑤ 结束阶段

```
触发"回合结束时"效果的能力
宣布"我的回合结束"，轮到下一位玩家
```

### 5.5 黎明阶段

```
① 警长检查：若版图上无任何"证据 Token"或"迷雾 Token"（警长手中持有的不计入版图）→ 警长得 1 分
② 翻开受害者的"混乱 Token"结算「追偿」（检查对应角色从放置至黎明收回期间得分 ≥ 2，含本阶段 ① 的得分），同时收回爆料放置在地点上的"混乱 Token"
③ 收回所有"警员 Token"（布控等效果结束，有技能特殊说明的除外）
④ 看守所中的"证据 Token"向左移动 1 格（数字减少 1）
   Token 到达 0 格 → 出狱成功 → 释放 → 返回角色供应堆
⑤ 收回所有"英雄 Token"（有技能特殊说明的除外）
⑥ 触发"黎明阶段"效果的能力
⑦ 检查终局条件：
   ├─ 是否有玩家分数 ≥ 15 分 → 进入游戏结算
   └─ 当前轮次是否为第 12 轮 → 进入游戏结算
⑧ 未结束 → 回合标记 +1 → 进入下一轮的傍晚阶段
```

## 6. 各阵营行动详解

### 6.1 通用行动

#### 调查

```
选择 1 个地点，从该地点获得 1 个"情报 Token"。
如果该地点当前情报值为 0，则无法获得。
如果执行者是罪犯，隐藏值 -1（降至 0 为止，不会为负数）。
```

#### 摸牌

```
从公共策略牌堆顶部摸 1 张牌。
如果牌堆为空，将弃牌堆洗混作为新的牌堆。
手牌上限为 3 张（修整阶段弃置超出部分）。
```

#### 出牌

```
打出手中的 1 张策略牌。

- 若策略牌带有"快速"标签：无需花费行动
- 若无"快速"标签：消耗 1 个行动
- 若策略牌带有"⏳ 延时"标签：打出时正面向上放在你的角色区域。结算其打出效果。满足条件时结算其延时效果
- 策略牌上若有其他打出限制（如"仅在你的回合"等），须满足后才能打出
```

### 6.2 警长专属行动

#### 侦查

```
条件：
├─ 选择 1 个地点（任意区域）
├─ 拥有 ≥ 该地点当前情报值 数量的"情报 Token"
└─ 该地点至少有 1 个"证据 Token"

执行：
├─ 花费 = 地点当前情报值 的"情报 Token"
├─ 从该地点获得 1 个"证据 Token"（选择要拿哪个罪犯的；若该地点有"迷雾 Token"也可选择获得）
└─ 将获得的"证据 Token"放在自己面前（暂时持有）
```

#### 警员 Token 与布控

"警员 Token"是警长专用的布控工具，共 5 枚，放在警长的**角色供应堆**。

- 放置在地点上 → 其它角色计算该地点的情报值时 +2（本轮有效），但同一地点不能放置 2 个以上
- 黎明阶段自动收回所有"警员 Token"

```
条件：
├─ 选择 1 个地点（"学校和图书馆"除外）
└─ 有可用的"警员 Token"

执行：
├─ 其它角色计算该地点的情报值时 +2（本轮有效）
└─ 该地点上已有的"证据 Token"不受影响

免费布控：
├─ 若当前版图上存在属于其它角色的"证据 Token"，你进行"布控动作"时可不花费行动（每回合限 1 次）
└─ "迷雾 Token"不属于任何角色，因此不能触发免费布控
```

#### 抓捕

```
**重大**。额外花费：1 个行动

条件：
├─ 选择 1 名罪犯作为目标
├─ 持有至少 1 个该罪犯的"证据 Token"

执行（花费 → 效果）：
├─ 【花费】额外花费 1 个行动
├─ 【花费】（额外的）"情报 Token"
│   └─ 若 X < 该罪犯的当前隐藏值（X = 你持有并移入看守所的该罪犯"证据 Token"数量）：每相差 1 点，额外花费 1 个"情报 Token"
├─ 【效果】你持有的该罪犯"证据 Token"全部移入看守所，该罪犯留在版图上的"证据 Token"全部返回其角色供应堆
├─ 【效果】获得分数 = 该罪犯的犯罪等级
├─ 【效果】若 X < 该罪犯的犯罪等级，额外 +1 分

抓捕"迷雾 Token"：
├─ 警长也可对已获得的"迷雾 Token"执行"抓捕动作"
├─ 每个"迷雾 Token"返回公共供应堆，警长获得 1 分
└─ "迷雾 Token"不进入看守所、无需选择目标罪犯

注意：
- 被捕时罪犯的隐藏值保持不变（作为抓捕时的读数），不会因被捕而变动

示例：
├─ 罪犯"毒蛇"（犯罪等级 2，当前隐藏值 2）
├─ 警长手中持有 2 个"毒蛇"的"证据 Token"
├─ 移入全部 2 个"证据 Token" → 放入看守所
├─ 移动数 2 = 隐藏值 2，无需额外"情报 Token"
├─ 获得 2 分（犯罪等级 2）

示例 2（证据不足，用情报补差）：
├─ 罪犯"屠夫"（犯罪等级 3，当前隐藏值 2）
├─ 警长手中持有 1 个"屠夫"的"证据 Token"
├─ 移入全部 1 个"证据 Token"
├─ 移动数 1 < 隐藏值 2 → 差 1 → 额外花费 1"情报 Token"
├─ 放入看守所
├─ 获得 3 分（犯罪等级 3）
└─ 移动 1 < 犯罪等级 3 → 高效抓捕额外 +1 分 = 共 4 分
```

### 6.3 罪犯专属行动

#### 隐藏

```
条件：当前隐藏值 < 角色卡上限

执行：隐藏值 +1（不超过角色卡上限）

作用：增加警长抓捕所需的情报代价（每多 1 隐藏值，警长需多花费 1 情报或更多证据）
```

#### 作案

```
**重大**。额外花费：1 个行动

条件：
├─ 选择 1 个地点
├─ 拥有 ≥ 该地点当前情报值 数量的"情报 Token"
├─ 没有自己的"证据 Token"在看守所中

执行（角色供应堆中有可用的"证据 Token"）：
├─ 花费 = 地点当前情报值 的"情报 Token"
├─ 将 1 个自己的"证据 Token"从角色供应堆放置到该地点上
├─ 在该地点放置 1 个"情报 Token"
├─ 获得分数 = 该地点的影响值
├─ 若该地点的影响值与你的犯罪等级相差 ≤ 1，额外 +1 分

执行（角色供应堆中无可用"证据 Token"，全部在版图上）：
├─ 花费 = 地点当前情报值 的"情报 Token"
├─ 选择 1 个自己已在版图上的"证据 Token"，移动到新目标地点（新目标地点允许已有自己的"证据 Token"）
├─ 在该地点放置 1 个"情报 Token"
├─ 获得分数 = 该地点的影响值
├─ 若该地点的影响值与你的犯罪等级相差 ≤ 1，额外 +1 分
└─ 移动与正常作案判定一致（含地点情报值为 0 时花费 0 情报 + 正常得分 + 匹配加分判定）

示例：
├─ 罪犯"老鼠"（犯罪等级 1）在贫民窟（影响值 1）作案
├─ 花费 2"情报 Token"，放置 1"证据 Token"
├─ 获得 1 分（影响值）
└─ 影响值 1 = 犯罪等级 1 → 匹配加分 +1 分 = 共 2 分

示例 2：
├─ 罪犯"毒蛇"（犯罪等级 2）在博物馆（影响值 3）作案
├─ 花费 5"情报 Token"，放置 1"证据 Token"
├─ 获得 3 分（影响值）
└─ 影响值 3 与犯罪等级 2 相差 1 → 匹配加分 +1 分 = 共 4 分
```

### 6.4 超级英雄专属行动

#### 登场

```
**重大**。额外花费：1 个行动

条件：
├─ 选择 1 个地点
├─ 拥有 ≥ 该地点当前情报值 数量的"情报 Token"
└─ 可用"英雄 Token"在你的角色供应堆

执行：
├─ 花费 = 该地点当前情报值 的"情报 Token"
├─ 将你的"英雄 Token"放置到该地点
└─ 获得 X 分（X = 该地点"证据 Token"数量）

黎明阶段：所有"英雄 Token"收回（规则书 §5.5⑤，与"警员 Token"同规则）
```

#### 制裁

```
**重大**。额外花费：1 个行动

条件：
├─ 选择版图上的 1 个"证据 Token"（"迷雾 Token"不可选作目标）
├─ 拥有 ≥（该"证据 Token"所属罪犯的当前隐藏值 + 你当前拥有的"证据 Token"数量）数量的"情报 Token"

执行：
├─ 花费 = 该"证据 Token"所属罪犯的当前隐藏值 + 你当前拥有的"证据 Token"数量 的"情报 Token"
├─ 获得该"证据 Token"（放在你面前，暂时持有）
└─ 获得 X 分（X = 你当前拥有的"证据 Token"数量，含本次获得的，按 1+2+3+… 等差数列累计）
```

### 6.5 受害者专属行动

#### 追偿

```
**重大**。花费 2 个"情报 Token"。

执行：
├─ 将你的 2 枚"混乱 Token"背面向上，分别放在 2 名角色面前
└─ 黎明阶段翻开并收回（顺序见 §5.5②）

黎明结算：
├─ 若翻开的"混乱 Token"为【阳面】：
│   ├─ 若该角色从该"混乱 Token"放置至黎明收回期间获得的分数 ≥ 2（含黎明阶段的"和平奖励"）
│   └─ 你可以令其 -1 分，然后你 +1 分
└─ 若为【阴面】：无效果
```

#### 爆料

```
**重大**。花费 2 个"情报 Token"。

执行：
├─ 将你的 2 枚"混乱 Token"背面向上，分别放在 2 个不同地点
├─ 其它角色计算这些地点的情报值时 +1（可与"布控""设伏"等情报值修正效果叠加）
└─ 黎明阶段收回（顺序见 §5.5②）

持续能力：
├─ 地点上存在你的"混乱 Token"时，你获得以下能力：
│   └─ ↩️ "混乱 Token"所在的地点被其它角色的重大行动选择成为目标时：
│       你可以翻开并收回该"混乱 Token"，若为【阳面】，你 +1 分
```

## 7. 看守所

看守所是一张特殊的**地点牌**，放置在版图旁边（不加入版图网格）。它拥有以下能力：

### 7.1 持续能力

**禁地**：**强制 -** 看守所不可以被选为调查、侦查、作案等任何行动的目标。

**入狱**：**强制 -** "证据 Token"被放入看守所时，放置到其所属角色犯罪等级对应的数字区域。每个黎明阶段所有 "证据 Token" 向左移动 1 格（数字减少 1）。"证据 Token" 移动至 0 时，返回角色供应堆。

**关押**：**强制 -** "证据 Token"位于看守所的角色，仅能触发**本地点**上的能力。不能触发角色卡或其他任何地点上的能力，也不能进行其他任何行动（含"出牌行动"，因此不能打出任何策略牌，包括"快速"牌）。

**放风**：➡️ 额外花费 1 个行动，弃置 1 张手牌。获得 1 个"情报 Token"。

### 7.2 触发能力

**越狱**（➡️➡️ 重大）：将自己的全部"证据 Token"向左移动，每移动 1 格需要花费 2"情报 Token"并弃置 1 张手牌。若移动到 0，你获得 +1 分。

> 越狱可分散在多个自己的回合中完成：每次执行"越狱"推进若干格，累计推进至 0 格即出狱。
>
> 示例：若你在格 3 且想要越狱（推进到格 0），共需要推进 3 格、花费 6 情报 + 弃 3 张手牌、获得 1 分；你可以分多个回合逐步推进。

## 8. 胜利条件与计分方式

### 8.1 终局触发

| 条件 | 触发时机 |
| ------ | --------- |
| 任意玩家分数 ≥ 15 分 | 当前轮黎明阶段结束时 |
| 第 12 轮结束 | 第 12 轮黎明阶段结束时 |

### 8.2 得分途径

| 阵营 | 途径 | 分数 | 说明 |
| ------ | ------ | ------ | ------ |
| 罪犯 | 作案动作 | 地点影响值（1-4 分） | 每次作案获得 |
| 罪犯 | 匹配加分 | 额外 +1 | 作案地点影响值与犯罪等级相差 ≤ 1 |
| 罪犯 | 越狱 | +1 | 越狱时移动到 0 格获得 +1 分 |
| 警长 | 抓捕动作 | 犯罪等级（1-4 分） | 每次抓捕获得 |
| 警长 | 高效抓捕 | 额外 +1 | 移动证据数 < 犯罪等级 |
| 警长 | 和平奖励 | +1 | 每个黎明阶段，版图上无任何"证据 Token"或"迷雾 Token"（警长手中持有的不计入版图）时 |
| 警长 | 抓捕迷雾 | 1 分/枚 | 对已获得的"迷雾 Token"执行"抓捕动作"时（返回公共供应堆） |
| 超级英雄 | 登场动作 | 证据数 X 分/次 | 放置"英雄 Token"到地点，得 X 分（X = 该地点"证据 Token"数量） |
| 超级英雄 | 制裁动作 | 持有证据数（等差数列累计） | 获得版图上 1 个"证据 Token"，得 X 分（X = 持有的证据数） |
| 超级英雄 | 角色能力 | 视具体能力而定 | 详见角色卡能力描述 |
| 受害者 | 追偿动作 | ±1（夺分） | 黎明时持有阳面"混乱 Token"的角色从放置至黎明收回期间得分 ≥ 2，令其 -1、你 +1 |
| 受害者 | 爆料反击 | 1 分/次 | 地点被选为目标时翻开"混乱 Token"，阳面则 +1 分并收回 |
| 受害者 | 角色能力 | 视具体能力而定 | 详见角色卡能力描述 |

### 8.3 同时达标处理

若多名玩家在同一黎明阶段达到 ≥ 15 分：

```
① 按分数高低排名
② 分数相同时 → 共同获胜
```

## 10. 术语表

### 10.1 基础概念

| 术语 | 说明 |
| ------ | ------ |
| 轮（Round） | 一轮包含傍晚→夜晚→黎明三个阶段 |
| 回合（Turn） | 一名玩家的完整行动流程（开始→补给→行动→修整→结束） |
| 行动力 | 每回合拥有的行动点数，默认 2 点。执行 1 个行动消耗 1 点行动力 |
| "情报 Token" | 蓝色方块，全阵营通用资源，通过调查行动从地点获取 |
| "证据 Token" | 罪犯头像圆片，标记作案位置和抓捕门票 |
| 隐藏值 | 罪犯的隐蔽程度（0 到角色卡上限），决定抓捕的情报补差成本。轨道为 0-5 共 6 格 |
| 犯罪等级 | 罪犯角色的危险等级（1-4），决定得分和看守所位置 |
| 相邻 | 与目标地点共享一条边的地点（四方向，不含斜角） |

### 10.2 效果标签

| 标签 | 出现范围 | 说明 |
| ------ | -------- | ------ |
| **重大** | 任意卡牌或能力的效果 | 每回合仅能执行 1 次标注"重大"的效果 |
| **强制** | 持续能力的效果 | 标注"强制"的能力会在特定条件下自动启用，不消耗行动 |
| ⏳ **延时** | 仅策略牌的效果 | 打出时正面向上放在你的角色区域。结算其打出效果。满足条件时结算其延时效果 |
| **快速** | 仅策略牌的效果 | 可在任意玩家回合中、满足牌面条件时打出；打出该策略牌时无需花费行动 |

### 10.3 能力类型

| 图标/标记 | 类型 | 说明 |
| --------- | ------ | ------ |
| 无 | 持续能力（被动） | 常驻生效，无需触发。部分持续能力以 `**强制 -**` 标注，在特定条件下自动启用 |
| ⚡️ | 免费触发能力 | 任意时机触发，不消耗行动，可能附带限制条件 |
| ↩️ | 反应触发能力 | 满足特定条件（多与时机相关）时触发 |
| ➡️ | 行动触发能力 | 在你的回合中花费 1 个行动来主动触发 |

### 10.4 游戏元件

| 术语 | 说明 |
| ------ | ------ |
| 公共供应堆 | 牌堆、分数标记、"情报 Token"储备等公共资源的存放处 |
| 角色供应堆 | 每个角色自身拥有的配件存放处（如警员的"警员 Token"、罪犯的"证据 Token"） |
| 看守所 | 一张特殊的地点牌，被捕罪犯的"证据 Token"放置于此 |
| "警员 Token" | 警长布控工具，使其它角色计算目标地点的情报值时 +2 |
| "英雄 Token" | 超级英雄专属配件（每名超级英雄 1 枚），用于「登场」动作及角色技能相关的能力 |
| "混乱 Token" | 受害者专属配件（2 枚），背面灰色角色头像，正面一阴一阳，用于「追偿」「爆料」动作 |
| "迷雾 Token" | 2-3 人局专用，红色双面 Token，视为"证据 Token"处理 |
| 策略牌 | 公共卡牌，提供战术选择（可标注"快速"标签免行动打出） |

## 11. 常见边界条件 FAQ

### Q1：地点上"情报 Token"为 0 时还能调查吗？

**不能**。情报值 0 的地点无法执行"调查"行动。

### Q2：地点上"情报 Token"为 0 时还能作案吗？

**能**。地点上"情报 Token"为 0，代表该地点所有未知情况均已被探明，可以轻松完成作案。此时进行"作案动作"无需花费"情报 Token"，但仍需放置"证据 Token"、在该地点放置 1 个"情报 Token"并正常获得分数。

### Q3：多个罪犯在同一地点放置了"证据 Token"，警长侦查时选哪个？

警长选择其中一个罪犯的"证据 Token"获得。

### Q4：警长手中持有"证据 Token"时，罪犯越狱了，"证据 Token"如何处理？

警长手中持有的该罪犯的"证据 Token"全部移入看守所。看守所的持续能力会将其放置到对应犯罪等级的数字区域。

### Q5：罪犯的隐藏值能降到负数吗？

**不能**。隐藏值最低为 0。调查仅将隐藏值降至 0，不会为负。

### Q6：警长布控的地点，其它角色计算该地点的情报值时 +2 是永久性的吗？

**不是**。仅在当前轮有效，黎明阶段收回"警员 Token"后恢复原值。

### Q7：策略牌打完后去哪里？

公共弃牌堆。牌堆为空时，将弃牌堆洗混形成新的牌堆。

### Q8：延时策略牌结算后去哪里？

结算效果后进入公共弃牌堆。

### Q9：罪犯被捕后还能使用 ⚡️ 和 ↩️ 能力吗？

**不能**。在看守所中只能触发**看守所本地点**上的能力，不能触发其他任何地点上的能力。

### Q10：使用"情报截获"时，目标地点的情报值为 0 可以吗？

**不可以**。"情报截获"的目标地点情报值必须 ≥ 1（与"调查动作"一致），不能从情报值 0 的地点获得资源。

### Q11：同一地点的情报值修正加成可以叠加吗？

可以叠加，**无叠加上限**。布控、设伏与爆料均使"其它角色计算该地点的情报值时"获得修正（布控 +2、设伏 +2、爆料 +1），所有修正效果可同时生效。

### Q12：金库保险、紧急躲避中的"被选为目标"如何判定？

「金库保险」选择 1 名角色使其本回合不能被选为任何技能或卡牌效果的目标；「紧急躲避」在被其他角色的策略牌指定为目标时使其效果对你失效。判定清单如下：

- **算"目标"**：其他角色的策略牌明确以你为目标的效果（如「暗中行动」提高/降低你的隐藏值、「栽赃陷害」移动你的"证据 Token"、「通风报信」令你获得/失去"情报 Token"），以及以你为目标的信息类牌（如「尾随跟踪」查看你的隐藏值和手牌数量）
- **不算"目标"**：① 各种行动（抓捕、侦查、作案、制裁、登场等）；② 以地点为对象的策略牌（如「暗中观察」查看地点、「设伏」放置在地点牌旁）；③ 反应类能力（如「见风使舵」）与双方获益效果（如「情报共享」）
