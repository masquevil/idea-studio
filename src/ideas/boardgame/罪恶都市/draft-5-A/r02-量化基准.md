# 评审② · 量化基准（第十轮）

> 在 0 特殊能力（不含角色技能、不含策略牌）下，建立各阵营主得分路线的数值基准。
> 依据：当前规则书（01）数值；标准 4 人局（1 警长 + 3 罪犯）。
> 主基准：各阵营达到 15 分所需的 KSA 次数 4-6 次、全周期轮次 8-12 轮（§4.1 量化规则）。

---

## 1. 基础操作投入产出一致性检查

> 第一步：检查规则书中各基础操作的投入产出关系是否一致，有矛盾的先修复。

### 1.1 KSA 行动占用与得分对照（§2.4 标定）

| KSA | 阵营 | 行动占用 | 类型 | 单次基础得分 | 得分依赖 |
| - | - | - | - | - | - |
| 作案 | 罪犯 | 2 行动 | 独占型 | 影响值（1-4）+ 匹配 +1 | 地点情报值（花费=当前情报值，作案回填 +1） |
| 抓捕 | 警长 | 2 行动 | 独占型 | 犯罪等级（1-4）+ 高效 +1 | 证据 Token（需侦查取证）+ 隐藏值补差 |
| 制裁 | 超级英雄 | 2 行动 | 独占型 | 持有证据数（1+2+3…） | 版图证据 + 隐藏值/持证花费 |
| 登场 | 超级英雄 | 2 行动 | 独占型 | 该地点证据数 X | 地点情报值花费 |
| 追偿 | 受害者 | 1 行动 + 1 情报 | 轻量型 | 条件 ±1（剥夺） | 他人黎明前得分 ≥ 2 |
| 爆料 | 受害者 | 1 行动 + 1 情报 | 轻量型 | 条件 +1 | 重大行动选为目标的翻面命中 |

**一致性结论**：

- ✅ 作案/抓捕同为 2 行动独占型，单次基础得分量级一致（犯罪等级 vs 影响值为同一梯度表 1-4）。
- ✅ 受害者两 KSA 为 1 行动轻量型，但单次得分低（±1），频率由"不占满回合"补偿——结构自洽。
- ⚠️ 制裁（等差数列）在 0 能力下被登场覆盖；0 能力英雄主路线为登场（X=地点证据数），制裁依赖"已持证"滚雪球，属技能层（r03）。
- ⚠️ 抓捕依赖"侦查取证"前置链，作案依赖"压点调查"前置链——准备轮口径在 §3 统一。

### 1.2 规则书内部数值矛盾检查

| 检查项 | 结果 |
| - | - |
| 匹配加分条件（影响值相差 ≤1）与犯罪等级各区域可达性 | ✅ 等级 1（影响值 1-2）、2（1-3）、3（2-4）、4（3-4），与地点影响值分布（§03 统计）吻合 |
| 隐藏值上限 = 犯罪等级（疯子 2 除外） | ✅ 与等级梯度锚定一致 |
| 作案回填 +1（规则书 §6.3 与 FAQ Q2） | ✅ 规则书明文一致 |
| 抓捕补差（X < 隐藏值，每差 1 花费 1 情报） | ✅ §6.2 与 §4.6 一致 |
| 高效抓捕 +1（X < 犯罪等级） | ✅ §6.2 与 §8.2 一致 |
| 迷雾 Token 视为证据、抓捕得 1 分 | ✅ §5.3/§8.2 一致 |
| 追偿/爆料花费 1 情报、黎明收回 | ✅ §6.5 一致 |
| 出场费用（登场/制裁） | ✅ §6.4 一致 |

**结论**：规则书基础操作层无数据矛盾。以下进入 0 能力基准推演。

## 2. 罪犯 0 能力数值基准（4 人局 1 警长 + 3 罪犯）

> 场景：等级 2 罪犯（隐藏值上限 2），主目标核心区影响值 2 地点（匹配 +1 → 3 分/次）；备选影响值 3 地点（4 分/次）。

### 2.1 单次 KSA 得分与次数目标

| 路线 | 单次得分 | 达 15 分 KSA 次数 | 判定 |
| - | - | - | - |
| 核心区（影响值 2 + 匹配） | 3 分 | ⌈15/3⌉ = 5 次 | ✅ 落在 4-6 |
| 高影响区（影响值 3 + 匹配） | 4 分 | ⌈15/4⌉ = 4 次 | ✅ 落在 4-6 |

### 2.2 准备轮（压点调查链）推演

> 作案动态花费 = 地点当前情报值，且作案回填 +1 → 成本随连续作案递增，需周期性重压。

**目标核心区地点初始情报 3**（最常见，6 张核心含影响值 2 的占 5 张）：

| 阶段 | 行动序列 | 情报值变化 | 情报收入 | 情报花费 | 备注 |
| - | - | - | - | - | - |
| 首压（2 轮） | R1 调查×2；R2 调查×1 + 备用行动 | 3→1→0 | +3 | 0 | 调查双效应（+1 情报、-1 情报值） |
| 作案 1 | 作案（独占型 2 行动） | 0→1（回填） | 0 | 0 | 得 3 分 |
| 重压 1（1 轮） | 调查×1 + 备用 | 1→0 | +1 | 0 | 压回 0 |
| 作案 2 | 作案 | 0→1 | 0 | 0 | 得 3 分 |
| 重压 2 | 调查×1 + 备用 | 1→0 | +1 | 0 | 压回 0 |
| 作案 3 | 作案 | 0→1 | 0 | 0 | 得 3 分 |
| ... | 循环 | ... | ... | ... | ... |

**关键结论**：由于"作案回填 +1"，核心区（初始情报 3）每 1 次作案后需 1 次调查压回 0（1 行动）。**单次作案的动态花费为 0（压 0 后），但每次作案夹带 1 个调查行动（重压）**——即"作案 + 重压"构成最小闭合循环。

**循环闭合分析**：`压 0 → 作案(0 花费, 3 分) → 回填+1 → 调查压回 0 → 作案(0 花费, 3 分)…`。

- 每次作案需：1 个执行轮（独占 2 行动）+ 0.5 个准备轮（1 次调查，可与备用行动/补给重叠）→ **每次作案 ≈ 1.5 轮**（含重压）。
- 首次还需额外一次性首压：~2 轮（压 3→0 需 3 次调查）。

### 2.3 全周期轮次预算（0 能力、无警长干扰）

**核心区 3 分/次 × 5 次 = 15 分**：

| 组分 | 轮数 | 说明 |
| - | - | - |
| 首压 | 2 轮 | 3 次调查压 3→0（R1 调查×2、R2 调查×1） |
| 执行轮 | 5 轮 | 5 次作案 × 1 轮（独占型） |
| 重压轮 | 2 轮 | 每次作案后 1 次调查压回；第 5 次作案后无需（已 15 分）[注：5 次作案中间 4 次重压；4×0.5=2 轮] |
| 干扰轮 | 0-2 轮 | 无干扰 0；若被捕 1 次，损失 1 执行轮 + 重积累 |
| **总轮次** | **9-11 轮** | ✅ 落在 8-12 主基准 |

**敏感性**：

| 变量 | 变化 | 对完整成本的影响 |
| - | - | - |
| 布控 +2 | 作案花费 0→2 情报 | 需额外 1 轮调查攒 2 情报 → 单次作案 +1 轮 |
| 火车站回填 | 压 0 地点黎明 +1 | 回填使压 0 后需重新压（火车站为主要目标时成本 +25%） |
| 情报干扰（牌） | 地点 +2 | 同布控，策略层（r04 计） |
| 被捕 | 进看守所 ≥1 轮 | 损失 1 执行轮 + 需越狱/放风，总轮次 +2~3 |

**资源效率（后验）**：5 次作案累计 IV=15 分；累计完整成本 ≈ 5 执行轮×2 行动(=10 行动) + 首压 3 行动 + 重压 4 行动 + 0 动态情报 = 17 行动（=17 IC）→ 约 0.88 分/行动。多次作案动态花费为 0 压低分母，**资源效率偏高**源于压 0 后免费作案；但被"作案回填→需重压调查"的行动成本平衡。**核心观察**：罪犯的资源约束是"行动"而非"情报"——压 0 后情报花费归零，行动成为稀缺资源。

## 3. 警长 0 能力数值基准（4 人局）

> 场景：目标为等级 2 罪犯（隐藏值上限 2）。主路线：侦查取证 → 抓捕。
> 搭便车效应：罪犯压 0 的地点侦查花费低（0-1 情报），警长侦查成本被罪犯的压点行为间接压低。

### 3.1 单次抓捕得分与次数目标

| 持证情况 | 抓捕得分 | 说明 |
| - | - | - |
| 持 1 证据抓隐藏 2 | 2（等级）+1（高效）= 3 分 | 补差 1 情报（X=1 < 隐藏 2） |
| 持 1 证据抓隐藏 0 | 2+1 = 3 分 | 无需补差 |
| 持 2 证据抓隐藏 2 | 2 分 | X=2 = 等级 → 无高效 +1（理性上不应如此抓） |

**最优路径**：每次持 1 证据抓捕，得 3 分。15 分需 **5 次抓捕**（⌈15/3⌉，不考虑和平奖励）。

### 3.2 准备链推演（侦查 + 抓捕）

| 轮次 | 行动序列 | 情报值（目标地点） | 供给 IC | 情报余额 | 动态花费 | 说明 |
| - | - | - | - | - | - | - |
| R1 | 调查×1 + 侦查×1 | 0（罪犯已压） | 3 | 0→1→0 | 侦查 0 情报 | 调查攒补差 1 情报；侦查花 0 得 1 证据 |
| R2 | 抓捕（2 行动独占） | 0 | 3 | 0 | 补差 1 情报 | 得 3 分 |
| R3 | 调查×1 + 侦查×1 | 0 | 3 | 0→1→0 | 0 | 下一目标 |
| R4 | 抓捕 | 0 | 3 | 0 | 1 | 得 3 分 |
| ... | 循环 | ... | ... | ... | ... | ... |

**关键假设**：目标地点情报值已被罪犯压到 0（罪犯压 0 作案后回填 1，但若警长随后调查 1 次可再压回 0；实际取"罪犯压 0 后警长侦查"的搭便车场景，侦查花费 0-1）。

**循环闭合**：`调查(攒 1 情报) + 侦查(花 0-1 得证) → 抓捕(补差 1, 3 分)` 构成 2 轮闭合循环，每次抓捕净成本 = 1 准备轮 + 1 执行轮。

### 3.3 全周期轮次预算（0 能力、无罪犯干扰）

| 组分 | 轮数 | 说明 |
| - | - | - |
| 准备轮 | 5 轮 | 每次抓捕前 1 轮（调查+侦查） |
| 执行轮 | 5 轮 | 5 次抓捕 × 1 轮（独占型） |
| 和平奖励 | 0-1 次 | 3 罪犯留证据，版图常驻证据 → 和平几乎不可得（保守 0-1） |
| 干扰轮 | 0-2 轮 | 罪犯隐藏高位 → 补差情报多，需额外调查轮 |
| **总轮次** | **10-13 轮** | ⚠️ 临界——无和平奖励时贴近 12 轮上限 |

**敏感性**：

| 变量 | 变化 | 对完整成本的影响 |
| - | - | - |
| 罪犯隐藏保持上限 2 | 补差 1 情报/次 → 每次需先调查 1 次 | 准备轮已含；若罪犯反击压低警长情报，成本 +1 轮/次 |
| 目标地点情报未压 0 | 侦查花费 = 当前情报值（2-4） | 需多轮攒情报 → 每次抓捕 +1~2 准备轮 |
| 布控免费（版图有他人证据时） | 布控 +2 情报压制 | 提高罪犯作案成本，间接保护警长节奏 |
| 和平奖励 | 黎明版图无证据 | 3 罪犯局几乎不可触发（0-1 次） |

**资源效率（后验）**：5 次抓捕 15 分；累计成本 ≈ 准备轮 5 行动（调查）+ 侦查 5 行动 + 执行轮 10 行动 + 补差 5 情报 = 20 行动 + 5 情报 = 25 IC → 0.6 分/IC。**低于罪犯（0.88）**——警长 0 能力表面资源效率偏弱，但其抓捕含"剥夺含金量"（r03 加权 1.33 后对比），且依赖罪犯留下的证据（被动收益）。

### 3.4 0 能力跨阵营 KSA 节奏对比（主平衡轴）

| 阵营 | 单次基础得分 | KSA 次数 | 总轮次（无干扰） | 判定（8-12 轮） |
| - | - | - | - | - |
| 罪犯（等级 2 核心） | 3 分 | 5 次 | 9-11 轮 | ✅ 达标 |
| 罪犯（等级 3 高影响） | 4 分 | 4 次 | 8-10 轮 | ✅ 达标 |
| 警长（抓等级 2） | 3 分 | 5 次 | 10-13 轮 | ⚠️ 临界偏慢 |
| 超级英雄（0 能力登场） | X=证据数 | 依赖版图 | 见 §4 注记 | 扩展阵营单独处理 |
| 受害者（0 能力） | 条件 ±1 | 依赖他人 | 见 §4 注记 | 扩展阵营单独处理 |

**0 能力基准结论**：

1. 罪犯 0 能力节奏健康（9-11 轮），等级 2/3 均在 4-6 次 KSA 内。
2. 警长 0 能力贴近 12 轮上限，依赖"罪犯压点搭便车"（侦查便宜）+ 高效抓捕 +1 才能达标——**警长偏慢的风险点在 r03/r04 需结合技能与策略牌复核**（历史上已有补强）。
3. 扩展阵营（英雄/受害者）0 能力高度依赖版图/他人状态，无法独立达标 → 符合"特殊能力是核心竞争力"设计原则（§4.2 原则 4），其综合节奏在 r04 含技能一并评估。
