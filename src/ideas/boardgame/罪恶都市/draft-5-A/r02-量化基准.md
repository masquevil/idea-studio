# r02 · 量化基准

> 建立 0 特殊能力下的数值基准
> 使用 IC（固定成本+动态成本拆分）/ IV（分数）统一计量
> 设计基准：0 能力 4 人局 12 轮发挥极好约 14-15 分
> 依据：最新版规则书（含布控改动）、04-量化审查规则.md §1.6 成本拆分原则

---

## 1. 成本拆分基础

### 1.1 核心操作成本拆分

| 操作 | 固定成本（不可降低） | 动态成本（可随策略/版图变化） |
| - | - | - |
| 调查 | 1 行动 | 0（需地点情报值 > 0） |
| 作案 | 2 行动 | 情报花费 = 地点当前情报值（可降至 0） |
| 侦查 | 1 行动 | 情报花费 = 地点当前情报值（可因布控增加） |
| 抓捕 | 2 行动 | 情报补差 = （隐藏值 - 证据数）× 2 |
| 布控 | 0~1 行动（有证据免费） | 消耗警员 Token |

### 1.2 动态成本的关键推演：地点情报耗尽速度

**核心区地点示例（初始情报 3）**：每次调查使情报 -1，集满 3 次调查后归零。

**4 人局（1 警 + 3 罪犯）第 1 轮推演**——假设 3 个罪犯集中进攻同一核心区地点：

| 玩家（按顺序） | 行动 | 地点情报值变化 | 说明 |
| - | - | - | - |
| 罪犯A | 调查×2 | 3 → 1 | 得 2 情报 |
| 罪犯B | 调查×1 + 作案×1 | 1 → 0 | 调查后情报 0，作案花费 0，得 2+1=3 分 |
| 罪犯C | 作案×1 + 摸牌×1 | 0 → 0 | **第 1 轮即可零成本作案**，得 2+1=3 分 |

**结论**：在 4 人局中，一个初始情报 3 的核心区地点**第 1 轮就可能被打空**，后续罪犯可以零成本连续作案。这不是"极后期"现象，而是开局即可出现的高频状态。

**推演依据**：3 个罪犯每轮共 6 个行动。若集中（或部分集中）于同一地点，调查次数可快速累积（实际推演，符合 04 §1.2"基于实际数值分析"）。

### 1.3 版图情报总量的总体节奏

初始版图情报总量：12 地点 × 平均 3.31 ≈ 40 情报。

- 每轮罪犯调查（从地点拿走情报） + 作案/侦查（花费情报）共同消耗版图情报
- 4 人局每轮约 5~8 次涉及情报消耗的操作
- 版图情报在 4~6 轮内快速下降，大量地点转为 0 情报状态
- 0 情报地点：作案动态成本 = 0，成为罪犯的"免费得分点"（但同时是警长低侦查成本点）

## 2. 罪犯基准：以"地点耗尽周期"为分析单元

### 2.1 单个地点耗尽周期的完整推演

以核心区普通地点（初始情报 3、影响 2）为例，单个罪犯独立攻略该地点：

| 回合 | 行动 | 动态成本 | 情报储备 | 得分 | 累计 |
| - | - | - | - | - | - |
| R1 | 调查×2 | 0 | +2 | 0 | 0 |
| R2 | 调查×1 + 作案×1 | 作案花费 = 0（调查后情报已 0） | +1-0=+1 | 3（2+超额1） | 3 |
| R3 | 切换新地点 调查×2 | 0 | +2 | 0 | 3 |

**该地点耗尽周期**：2 回合完成一次作案，固定成本 5 行动（3 调查 + 2 作案），动态成本 0。

**效率**：3 分 / 5 行动 = **0.60 IV/IC**（仅计固定成本）

**注意**：单人需要跨地点轮换调查，但多罪犯合力可更快打空同一地点，见 §1.2。

### 2.2 多罪犯合力下的效率（关键场景）

4 人局 3 罪犯若集结于满情报地点（如核心区）：

- 第 1 轮：3 个罪犯合力，地点情报快速归零（见 §1.2 推演）
- 第 2 轮起：罪犯轮流零成本作案，每次 2 行动固定成本 → 得 3 分（影响2+超额1）
- 单次作案效率：3 / 2 = **1.50 IV/IC**（动态成本为 0）

**这是当前规则下罪犯的核心得分模式**：多人合力打空地点 → 零成本连续作案。若警长不去干预，罪犯得分会非常高。

### 2.3 12 轮预期得分（罪犯，乐观情景）

假设罪犯有效行动 20 次（12 轮 × 2 行动 - 摸牌/移动等损耗）：

| 情景 | 作案次数 | 效率 | 12 轮得分 |
| - | - | - | - |
| 全零成本作案（理想） | ~10 次 | 1.50 IV/IC | **~30 分** |
| 混合（部分需调查准备） | ~8 次 | 1.0~1.5 IV/IC | **~20~25 分** |
| 被警长频繁抓捕打断 | ~5 次 | 0.8~1.0 IV/IC | **~10~15 分** |

**与设计基准（14-15 分）对照**：

- 被频繁抓捕时（10~15 分）接近基准
- 较少被抓捕时（20~30 分）**大幅超出基准**

**如实结论**：当前数值下，罪犯的得分上限显著高于设计基准。"发挥极好 14-15 分"可能需要重新审视——在现有规则下，发挥极好的罪犯可能达到 20+ 分。核心原因是：**情报快速归零使大量作案零成本**，而 12 轮的固定行动量足以支撑约 10 次零成本作案。

## 3. 警长基准

### 3.1 警长决策链与约束

警长 4 人局每轮 1 回合（2 行动）。核心约束：

- 侦查花费 = 地点当前情报值（前期 3~4，后期 0~1）
- 情报来源：调查（但调查也消耗版图情报）
- 布控改动：有证据地点免费布控（提升侦查成本压制罪犯）

### 3.2 典型抓捕路径（高效抓捕）

目标：犯罪等级 2、隐藏值 3 的罪犯，其证据在某核心区地点。

| 回合 | 行动 | 情报储备 | 证据 | 备注 |
| - | - | - | - | - |
| R1 | 调查×2 | +2 | 0 | 积累情报 |
| R2 | 侦查（花费 2~3 情报）+ 调查 | 波动 | 0→1 | 得 1 证据 |
| R3 | 抓捕（1 证据 < 隐藏 3，补差 4 情报） | -4 | 1→0 | 得 2+1=3 分 |

**效率**：一次高效抓捕约需 6~8 行动（含情报积累），得 3 分 → **0.40~0.50 IV/IC**。低于罪犯的零成本作案效率（1.50）。

### 3.3 警长 12 轮预期

- 高效抓捕 3~4 次：9~12 分
- 无证据奖励 1~2 次：1~2 分
- **直接得分约 10~14 分**
- 抓捕的间接价值（关押罪犯 2~4 回合，阻止其零成本得分）：每次阻止 6~12 分

**结论**：警长直接得分效率低，但其抓捕能有效阻止罪犯的零成本得分循环。非对称设计成立的前提是：警长能**及时**打断罪犯的作案节奏。若警长侦查/抓捕链条过长（需 2~3 轮），罪犯可能已借零成本作案积累 10+ 分。

## 4. 与设计基准的综合对照

### 4.1 对照表

| 阵营 | 场景 | 计算得分 | 设计基准 | 差值 |
| - | - | - | - | - |
| 罪犯 | 少被捕（乐观） | ~20~30 分 | 14-15 分 | **+5~15 分** |
| 罪犯 | 常被捕（悲观） | ~10~15 分 | 14-15 分 | 接近 |
| 警长 | 直接得分 | ~10~14 分 | — | — |

### 4.2 如实结论

1. **罪犯得分潜力超出设计基准**。当前规则下，地点情报快速耗尽 + 零成本作案机制，使罪犯乐观情景可达 20~30 分。若设计目标确实是"发挥极好 14-15 分"，则当前数值偏高。
2. **警长打断能力是关键平衡杠杆**。警长能否高效抓捕直接决定罪犯实际得分。当前警长单次抓捕需 2~3 轮准备，节奏可能偏慢。
3. **布控改动的影响**：免费布控提升警长压制力，但主要影响侦查成本，对"罪犯零成本作案"这一核心得分模式抑制有限。

### 4.3 可能的调整方向（供设计师判断）

| 方向 | 效果 |
| - | - |
| 引入版图情报补充机制（如每轮部分地点回复） | 减缓情报归零，提高动态成本下限 |
| 上调作案的情报花费系数（如花费 = 情报值 × k） | 提高零成本作案的动态成本 |
| 强化警长侦查/抓捕效率（如降低侦查情报花费） | 更及时打断罪犯节奏 |
| 多个小幅调整组合 | 累积校正 |

> 说明：以上为基于当前规则的实际推演结果。判定是否调整及如何调整，由设计师决定。本评审只如实报告计算与基准的差值（04 §1.5）。
