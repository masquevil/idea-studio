# r02 · 量化基准（第五轮）

> 评审范围：① 检查规则书各基础操作的投入产出关系是否一致；② 建立 0 特殊能力下的数值基准（资源投入产出比、执行周期、理性目标选择、各情景预期得分/进度）。
>
> 方法论：遵循 `progress-5/04-量化审查规则.md` §2 基本单位、§3 量化分析方法论（强制逐回合流水账、成本拆分、双维度效率、双重约束与强制报告）。
>
> 设计基准（§4.1）：0 能力 4 人局 12 轮预期 14-15 分 → 资源效率 ≈ 0.39-0.42 分/资源；轮次效率 ≈ 1.17-1.25 分/IR。

## 第一部分：基础操作投入产出一致性检查

### 1.1 各基础操作成本收益总表

| 操作 | 固定成本 | 动态成本 | 收益 | 性质 | 一致性 |
| - | - | - | - | - | - |
| 调查 | 1 行动 | — | 1"情报 Token" + 地点情报值 -1 | 资源转换 | ✅ |
| 摸牌 | 1 行动 | — | 1 张手牌 | 资源转换 | ✅ |
| 出牌 | 0-1 行动（快速 0） | 1 手牌 | 牌面效果 | 视牌而定 | ✅ |
| 读报 | 2 行动（见 R1-4） | 弃 1 手牌 | 1"情报 Token" | 资源转换（刻意低效） | ⚠️ 总消耗未写明（R1-4） |
| 侦查 | 1 行动 | 地点当前情报值 | 1 个"证据 Token" | 状态前置 | ✅ |
| 布控 | 1 行动 | —（免费布控 0） | 目标地点作案花费 +2（本轮） | 状态性 | ✅ |
| 抓捕 | 2 行动 | 补差"情报 Token" | 犯罪等级分（+高效 +1） | 资源→IV | ✅ |
| 隐藏 | 1 行动 | — | 隐藏值 +1 | 状态性 | ✅ |
| 作案 | 2 行动 | 地点当前情报值 | 影响值分（+超额 +1） | 资源→IV | ⚠️ 见下方 |

### 1.2 发现的不一致

#### 🔴 B2-1 地点情报值为 0 时"作案"与"侦查"的收益不对称

- 规则书 Q2：地点情报值 0 时仍可"作案动作"，花 0"情报 Token"，仍放证据、正常得分（含超额判定）。
- 规则书 §6.2：警长"侦查动作"花费 = 地点当前情报值 → 地点情报 0 时侦查也花 0 情报。
- **不对称点**：罪犯把地点压到 0（调查双效）后，**每次作案省 1 情报**（首次压 0 需数轮调查，但稳态每轮作案都因压 0 省 1 情报）；警长把地点压到 0 后，仅**单次侦查省 1 情报**（证据被拿走即结束）。
- **量化差异**：压 0 对罪犯的价值 = "此后每次作案 -1 情报 × 作案次数"（可累计多次）；对警长的价值 = "本次侦查 -1 情报"（一次性）。
- **判定**：非矛盾，但造成**压 0 的单向动机**——罪犯有强动机压 0，警长无同等动机。结合 §3.2 版图权衡，压 0 地点的"双向低成本"应向罪犯倾斜收益（得分面）vs 向警长倾斜风险面（取证面），当前设计罪犯净收益显著大于警长。此为 r04 交叉风险重点检查项。

#### 🟡 B2-2 高效抓捕与"证据不足补差"的收益叠加

- 抓捕得分 = 犯罪等级 + 高效抓捕（移动数 < 犯罪等级 → +1）。
- 补差 = 移动数 < 当前隐藏值 → 每差 1 花 1 情报。
- **一致性检查**：高效抓捕鼓励"证据不足少量抓捕"，而补差惩罚"证据不足"。两条规则同时存在，导致警长在"用 1 证据抓高犯罪等级"时：
  - 得：犯罪等级分 + 高效 +1
  - 付：补差（移动 1 < 隐藏值 → 差（隐藏值-1）情报）
  - 例：等级 3、隐藏 2，警长 1 证据：花补差 1 情报，得 3+1=4 分 → 5 资源 4 分 = 0.8 分/资源，**显著优于"2 证据正常抓"**（2 证据 = 移动数 2 = 隐藏 2 无补差，得 3 分，不触发高效，7 资源 3 分 = 0.43）。
- **判定**："1 证据 + 补差"成为警长理性最优。规则本身不自洽（鼓励用最少证据），但其效率仍低于罪犯基线（见 §2/§3），暂列 🟡 观察项，r04 纳入抓捕链综合评估。

#### 🟡 B2-3 读报总消耗表述（承接 R1-4）

- §6.1 读报未写明总消耗，按句式"额外花费 1 个行动"可读作 2 行动（与抓捕/作案一致）。建议补"总消耗 2 点行动力"。
- 此点因非纯数值，已在 r01 记录；此处仅确认不影响基准计算（按 2 行动计）。

### 1.3 结论

基础操作在"固定成本 + 动态成本"口径下总体一致，无直接数值矛盾。**核心结构问题**为 B2-1（压 0 单向动机）与 B2-2（高效+补差叠加），两者均进入 r04 深入检查。

## 第二部分：0 特殊能力数值基准

### 2.0 起点状态声明

- 推演场景：标准 4 人局（1 警长 + 3 罪犯）、12 轮上限、目标 15 分。
- 0 能力：双方仅使用基础行动（§4.2），无角色技能、无策略牌、无地点特殊效果（后续 r04 再逐项加入）。
- 复苏机制生效：每个情报值为 0 的地点，次日傍晚 +1"情报 Token"（§5.2②）。
- 作案不改变地点情报值；只有调查降低地点情报值（§3.3 机制前提）。
- 跟踪对象：罪犯取犯罪等级 2（基准线）；目标地点取核心区影响值 2、初始情报 3（区域基准）。

### 2.1 罪犯单侧无干预流水账

**策略**：核心区 A（初始情报 3、影响值 2）压情报后连续作案（超额 +1）。

行动代号：D = 调查（转换）、C = 作案（资源→IV）、B = 摸牌（转换）。

| 回合 | 行动序列 | 地点A情报(初→行后→傍晚) | 供给IC | 花费IC(仅资源→IV) | 情报余额 | 手牌余额 | 本回合IV |
| - | - | - | - | - | - | - | - |
| R1 | D、D | 3→1→1 | 3 | 0 | 2 | 1 | 0 |
| R2 | C、B | 1→1→1 | 3 | 2行动+1情=3 | 1 | 2 | 3 |
| R3 | C、B | 1→1→1 | 3 | 2行动+1情=3 | 0 | 3 | 3 |
| R4 | D、B | 1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| R5 | C、B | 1→1→1 | 3 | 2行动+1情=3 | 0 | 3 | 3 |
| R6 | D、B | 1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| R7 | C、B | 1→1→1 | 3 | 2行动+1情=3 | 0 | 3 | 3 |
| R8 | D、B | 1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| **审计行** | — | — | **24** | **12** | — | — | **12** |

- **起点**：初始情报 0、手牌 0（随后补给）、A 情报 3；复苏：情报 0 的地点傍晚 +1（R4、R6、R8 压 0 后当轮傍晚回填 1）。
- **备注**：R1 调查产生 2 情报启动资金；随后每 2 轮 1 次调查（压回 0）+ 1 次作案。
- **表内 IV 计算**：作案 = 影响值 2 + 超额 1 = 3 分/次。
- **累计**：8 轮累计供给 24 IC、真正投入 IV 的花费 12 IC、累计结余（转换层）12 IC（调查转换 + 手牌闲置）、累计 IV 12 分。

**效率**：

- **资源效率 = 12 / 12 = 1.0 分/资源**（分母=真正资源→IV 花费）
- **轮次效率 = 12 / 8 = 1.5 分/IR**
- **可持续性**：可连续执行；证据 5 枚限制在 5 次作案后（约 R12）触发移动转型，转型后需新地点压情报（见推演 1b）。

#### 推演 1b：证据耗竭后的移动转型（R9-R12 延伸）

| 回合 | 行动序列 | 地点情报 | 供给IC | 花费IC | 情报余额 | 手牌 | IV |
| - | - | - | - | - | - | - | - |
| R9 | C(第5次作案)、B | A:1 | 3 | 3 | 0 | 3 | 3 |
| R10 | D(D:B 3→2)、D(B:2→1) | B:3→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| R11 | C(移动至B)、B | B:1 | 3 | 3 | 0 | 3 | 3 |
| R12 | D(B:1→0)、B | B:1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |

- R9-R12 累计：供给 12、花费 6、IV 6。
- **证据满 5 后移动**：移动同样花目标地点当前情报值、同样得分（§6.3），版图证据数维持 5 → 移动本身不腾出"证据 Token"，但可转移至新地点继续作案。
- **累计 R1-R12 合计**：供给 36、花费 18、IV 18 → **资源效率 1.0 分/资源、轮次效率 1.5 分/IR**。

### 2.2 警长单侧无干预流水账（抓捕链）

**前提**：目标罪犯等级 2、隐藏值 3（初始）、其"证据 Token"位于核心区 A（情报 1）。警长需先侦查取证再抓捕。

行动代号：D = 调查（转换）、S = 侦查（前置）、A1 = 抓捕（资源→IV）、B = 摸牌。

| 回合 | 行动序列 | 花费IC(仅资源→IV) | 情报余额 | 手牌 | IV |
| - | - | - | - | - | - | - |
| R1 | D、B | 0 | 1 | 1 | 0 |
| R2 | D、B | 0 | 2 | 2 | 0 |
| R3 | S(A情报1)、B | 0（侦查花 1 情报，属前置非 IV） | 1 | 3(弃1) | 0 |
| R4 | D、B | 0 | 2 | 3(弃1) | 0 |
| R5 | A1(补差 2 情报)、B | 2行动+2情=4 | 0 | 3(弃1) | 3 |
| **审计行** | — | **4** | — | — | **3** |

- 抓捕结算：证据 1 < 隐藏 3 → 差 2 → 补差 2 情报；移动数 1 < 犯罪等级 2 → 高效 +1；得分 = 2 + 1 = 3。
- **起点**：警长初始情报 0、目标 A 情报 1（罪犯已压）、目标罪犯隐藏 3。

**效率**：

- **资源效率 = 3 / 4 = 0.75 分/资源**（侦查花 1 情报为前置，含入则 3/6 ≈ 0.5）
- **轮次效率 = 3 / 5 = 0.6 分/IR**（含 2 轮准备与 1 轮侦查）
- **可持续性**：受证据可获得性约束；目标罪犯证据被回收/清空则链中断。

### 2.3 警长补偿路径结构分析

警长得分途径（规则书 §8.2）在 0 能力下的可获得性：

| 途径 | 触发条件 | 0 能力可达性 | 单次收益 |
| - | - | - | - |
| 抓捕 | 需目标罪犯的"证据 Token" | 依赖罪犯作案（被动） | 2-4 |
| 高效抓捕 | 移动数 < 犯罪等级 | 易达成 | +1 |
| 无证据奖励 | 黎明版图无任何"证据/迷雾 Token" | ⚠️ 极难：罪犯作案即破 | +2/轮 |
| 清除迷雾 | 仅 2-3 人局 | 2-3 人局可用 | +1/枚 |

- **结构矛盾（B2-4）**："无证据奖励"与"抓捕链"相互冲突——要触发无证据奖励，版图必须无证据；要执行抓捕，警长必须先有证据（侦查取证）。警长若走抓捕路线，几乎必然破坏无证据奖励条件；若走无证据奖励路线，则放弃抓捕得分。
- **量化含义**：无证据奖励名义上每轮 +2（12 轮最多 +24），实际因罪犯会持续作案，**触发的先决条件是"罪犯全体被压制到无法在版图留证据"**（全被抓/无证据可放）。0 能力下罪犯单侧 1.5 分/IR 的作案压力下，警长很难达成"版图净空"。
- **结论（B2-5）**：0 能力下警长基准 = 抓捕链 0.6 分/IR + 无证据奖励偶发（假设每 4 轮 1 次 → +0.5 分/IR）≈ **1.1 分/IR**，低于设计基准 1.17-1.25。若配合罪犯被有效抑制（见 r04 净平衡），警长勉强达标；**结构上依赖"无证据奖励"作为主补偿，但该补偿与抓捕链互斥**，是本轮评审的核心量化风险。

### 2.4 理性目标选择分析（罪犯 0 能力）

**首次成本 vs 稳态成本**（目标地点类型 × 犯罪等级）：

| 地点类型 | 初始情报 | 影响值 | 压0调查次数 | 首次作案成本(距压0) | 稳态每次作案成本 | 每次得分(等级2) | 得分效率(稳态) |
| - | - | - | - | - | - | - | - |
| 下城 | 2 | 1 | 2 | 2D+2行动+1~2情 | 2行动+1情 | 1（无超额） | 0.33 分/资源 |
| 核心 | 3 | 2 | 3 | 3D+2行动+1~3情 | 2行动+1情 | 3（含超额） | 1.0 分/资源 |
| 上城 | 4 | 3 | 4 | 4D+2行动+0~4情 | 2行动+0~1情 | 4（含超额） | 1.33~2.0 分/资源 |
| 博物馆 | 5 | 4 | 5 | 5D+2行动 | 2行动+0~1情 | 4（等级2无超额） | 1.33~2.0 分/资源 |

- **理性选择**：等级 2 罪犯 → **核心区（影响 2）为最优区间**：超额条件满足、压情报成本可接受（3 次调查）、稳态 1.0 分/资源。下城影响值 1 因超额不满足（等级 2 需影响值 ≥2）导致回报过低，仅作避险。上城回报最高但准备周期长（4 次调查），适合中后期。
- **执行周期**：核心区首次作案 = 2 轮（R1 压 2 次 + R2 作案）；稳态 = 约每 2 轮作案 1 次（调查轮 + 作案轮交替）。
- **等级 1 vs 等级 4 对比**：
  - 等级 1（老鼠）：任意地点超额（影响值 ≥1），下城也可 2 分/次（1+1）；风险最低、梯度回报低。
  - 等级 4（疯子）：仅博物馆超额（影响值 ≥4），压 5 次调查成本极高；若不超额则上城得 4 分/次。高风险高回报成立，但"2 次调查-1 隐藏"使其极易被捕（详见 r03）。

### 2.5 基准对照汇总

| 对象 | 资源效率(分/资源) | 轮次效率(分/IR) | 偏离基准 |
| - | - | - | - |
| 设计基准 | 0.39-0.42 | 1.17-1.25 | — |
| 罪犯无干预（等级2核心区） | 1.0 | 1.5 | 🔴 显著偏高 |
| 罪犯无干预（上城稳态） | 1.33-2.0 | ~2.7-3.3（折算） | 🔴 严重偏高 |
| 警长抓捕链 | 0.5-0.75 | 0.6 | 🟡 偏低 |
| 警长含偶发无证据奖励 | ~0.75 | ~1.1 | 🟡 略偏低 |

**如实报告**：0 能力下罪犯单侧无干预效率**远高于设计基准**（约 2.4-2.6 倍）。此差值部分将由警长抑制（侦查/抓捕/布控）在 r04 中扣除；但差值幅度过大，若抑制不足以抵消，说明**作案得分（影响值+超额）或压 0 机制本身过强**，需在 r05 给出调整建议。

## 第三部分：基准结论

1. **基础操作一致**：无直接数值矛盾；B2-1（压 0 单向动机）、B2-2（高效+补差叠加）为结构性问题，r04 深入检查。
2. **罪犯 0 能力基准显著超模**（1.0-2.0 分/资源 vs 基准 0.39-0.42），核心驱动：核心区/上城高影响值 + 压 0 低情报成本 + 超额 +1。
3. **警长 0 能力基准偏低**（0.6-1.1 分/IR vs 基准 1.17-1.25），结构依赖"无证据奖励"，但与抓捕链互斥（B2-4）。
4. **12 轮上限 vs 15 分**：罪犯无干预 12 轮可得 18 分 → 会提前触发 15 分终局，12 轮上限仅在"罪犯被显著抑制"时才有意义。
5. 以上净平衡（罪犯无干预效率 − 警长抑制量）在 r04 中完成；若差值无法通过抑制抵消，r05 将建议数值修正（如调低影响值/超额分、限制压 0 收益、加强无证据奖励可达性等）。
