## 1. 第一步：规则一致性检查

### 1.1 作案回填已定案（原 D1 关闭）

- 本次修订后，规则书（§6.3 作案执行、FAQ Q2）与量化规则（§3.3 机制前提）已在"作案后回填 1 情报 Token"上**完全一致**，不再存在口径冲突。
- **量化后果（本条为全轮核心）**：压 0 不再能"持续 0 成本刷分"。地点情报值按 0→1→2→3… 递增，连续作案成本随之递增，需**周期性重压调查**。这同时缓解了旧口径下"版图情报快速枯竭"的问题——作案回填 + 火车站回填使版图情报动态平衡。

### 1.2 码头仓库「花费 -1」与作案回填的交互（新发现问题）

- 码头仓库（下城，初始情报 2 / 影响 1，效果"作案情报花费 -1，最低 0"）。
- **压 0 后作案成本序列（含回填）**：花费 = max(地点情报值 - 1, 0)：
  - 第 1 次作案：地点 0 → 花费 max(0-1,0)=**0** → 回填 0→1
  - 第 2 次作案：地点 1 → 花费 max(1-1,0)=**0** → 回填 1→2
  - 第 3 次作案：地点 2 → 花费 max(2-1,0)=**1** → 回填 2→3
- **对比**：普通下城地点（无 -1）压 0 后成本序列为 0、1、2…；码头仓库为 **0、0、1**——前 2 次作案 0 成本。
- 对等级 1 老鼠（人群掩护：核心区调查不减隐藏）在码头的组合：压点不降隐藏 + 0 成本作案 ×2 → 低风险高效率刷分点。**总量级别**：每次作案 2 分（影响 1 + 匹配 +1），需 8 次作案才 16 分 → 总体偏慢，不构成全局超模；但在等级 1-2 罪犯中属于"安全稳定"的最优路线之一，标记为 r04 观察项。

### 1.3 其他一致性

- 行动数"11 种"实为 12 种（r01 N03）——纯文字，无数值影响。
- 布控免费触发表述不一致（r01 N04）——纯文字。
- 其余基础操作投入产出关系全文一致 ✅。

## 2. 第二步：0 技能数值基准

### 2.1 罪犯基准 · 压 0 流（等级 2 · 老城区）

> 起点声明：R1 前老城区情报 3；罪犯等级 2、隐藏 2（上限）、情报 0、手牌 1；无技能；警长本表不干扰（干扰计入 §2.4）。行动代号：D=调查（转换）、C=作案（KSA，2 行动）、M=摸牌（行动阶段额外摸）。每回合补给自动摸 1 牌 + 罪犯隐藏 +1。

| 回合 | 行动序列（去向） | 地点情报(行前→行后) | 行动占用 | 动态花费 | 情报余额 | 隐藏(行前→行后) | IV |
| - | - | - | - | - | - | - | - |
| R1 | D、D | 3→1 | 2 | 0 | 0→2 | 2→0 | 0 |
| R2 | D、M | 1→0 | 1 | 0 | 2→3 | 1→0 | 0 |
| R3 | C（作案） | 0→1 | 2 | 0 | 3 | 1 | **3** |
| R4 | C（作案） | 1→2 | 2 | 1 | 3→2 | 1 | **3** |
| R5 | C（作案） | 2→3 | 2 | 2 | 2→0 | 1 | **3** |
| R6 | D、D（重压） | 3→1 | 2 | 0 | 0→2 | 1→0 | 0 |
| R7 | D、M（重压） | 1→0 | 1 | 0 | 2→3 | 1→0 | 0 |
| R8 | C（作案） | 0→1 | 2 | 0 | 3 | 1 | **3** |
| R9 | C（作案） | 1→2 | 2 | 1 | 3→2 | 1 | **3** |

**审计行（R1-R9）**：

| 累计供给 | 累计行动占用 | 累计动态花费 | 累计 IV | 备注 |
| - | - | - | - | - |
| 27 IC（9 轮×3） | 16（D×5 + M×2 + C×5×2） | 4（R4=1、R5=2、R9=1） | **15** | 行动去向全覆盖，无空过 |

**KSA 节奏审计**：① 5 次 KSA；② 执行轮 5（独占 1/次）；③ 准备轮 4（R1/R2 首压 + R6/R7 重压）；④ 干扰轮 0（本表假设）；⑤ 总周期 9 轮。

**结论**：压 0 流 5 次作案 = 15 分，**9 轮**（含 2 段压点准备）。因作案回填，需在 3 次作案后重压（地点回到 3）。

### 2.2 罪犯基准 · 压 1 流（等级 2 · 老城区，备选）

- 压 1：调查 2 次（情报 3→1）→ 作案花费 1 → 回填 1→2 → 再作案花费 2 → 回填 2→3 → 重压。
- 成本序列 1、2、1、2…，单次 3 分。每次作案前需 1 次调查回压（0.5 轮/次）。
- 节奏：5 次作案 ≈ 5 执行轮 + 2.5 重压轮 + 1 首压轮 ≈ **8.5-9 轮**，与压 0 流接近。
- **结论**：压 1 与压 0 效率相近（压 0 首段更便宜但需完整重压段）。理性罪犯会选压 0（前期 0 成本爆发）。

### 2.4 警长基准（侦查 → 抓捕链 + 和平奖励）

> 目标：抓压 0 罪犯（老城，地点情报 0，隐藏 1——因补给回补）。

| 回合 | 行动序列 | 动态花费 | IV |
| - | - | - | - |
| R1 | S（侦查，花费 0）、M | 0 | 0 |
| R2 | A（抓捕：1 证 vs 隐藏 1 → 补差 0） | 0 | **3**（等级2+高效1） |

- 周期 2 轮/次，5 次 = 10 轮；效率 3/(3+0) = 1.0 分/资源，1.5 分/轮。
- **和平奖励独立推演（4 人局）**：3 罪犯持续作案使版图证据常在 → 和平奖励触发率低（每 5-8 轮 1 次 ≈ 1-2 分/局）。警长 0 技能达标 ≈ **10-11 轮**。

### 2.5 KSA 终局节奏对照主基准（§4.1）

| 阵营/路线 | 单次KSA | KSA次数 | 执行轮 | 准备轮 | 干扰轮 | 总轮次 | 主基准判定（8-12轮） |
| - | - | - | - | - | - | - | - |
| 罪犯·压0（等级2，老城） | 3 分 | 5 | 5 | 4（首压2+重压2） | 1-2（被捕） | **10-11** | ✅ |
| 罪犯·压1（等级2） | 3 分 | 5 | 5 | 3.5（首压+重压） | 1-2 | **10-11** | ✅ |

**结论**：

- **罪犯（等级 2，0 技能）≈ 10-11 轮达标**（因作案回填，比旧口径 9-10 轮略慢，仍在 8-12 内 ✅）。
- **警长（0 技能）≈ 10-11 轮**，与罪犯基本对齐 ✅。警长依赖罪犯压点暴露（0 情报取证）；若罪犯不压点（隐藏 2、地点情报 3），警长效率降至 ≈0.43 分/资源、12 轮内难达标。
- **两端对齐**：0 技能基准下警长与罪犯均 10-11 轮，**平衡良好**（较旧口径改善——旧口径警长 10-12、罪犯 9-10 有 1-3 轮差距）。

## 3. 结论（供 r03/r04 引用）

1. **作案回填已定案**：全轮计算以"回填 +1、成本 0→1→2 递增"为准；压 0 不再持续 0 成本，需周期性重压。
2. **主基准判定**：罪犯 ≈10-11 轮、警长 ≈10-11 轮，均落 8-12 主基准 ✅，**双方对齐良好**（较旧口径改善）。
3. **版图情报动态平衡**：作案回填 + 火车站回填使版图情报不再快速枯竭，资源循环更健康（r04 详查）。
4. **码头仓库**：压 0 后成本序列 0、0、1，为等级 1-2 安全刷分点；效率低于核心区，不超模，r04 观察。
5. **警长依赖压点暴露**：罪犯压点（隐藏 0-1、地点 0 情报）是警长 0 成本取证窗口；不压点的罪犯让警长效率大跌——猫鼠博弈的核心张力保留。
6. **迷雾局和平奖励**：2-3 人局依旧被迷雾掐死（r01 N16），待用户确认设计意图。
