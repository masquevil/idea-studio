# r02 · 量化基准（第九轮）

> 评审目标：① 检查规则书基础操作投入产出一致性；② 建立 0 特殊能力下的数值基准
> 评审基准：`progress-5/04-量化审查规则.md`（KSA 分类 §2.4、方法论 §3、主基准 §4.1）
> 推演口径：4 人局（1 警长 + 3 罪犯）为设计基准；超级英雄/受害者按 5-7 人局简述
> 独立推演原则：和平奖励等触发率由推演得出，不预设

## 1. 第一步：基础操作投入产出一致性检查

### 1.1 通用行动

| 行动 | 投入 | 产出 | 一致性判定 |
| - | - | - | - |
| 调查 | 1 行动 | 1"情报 Token" + 地点情报值 -1 | ✅ 双效一致（§3.1） |
| 摸牌 | 1 行动 | 1 手牌 | ✅ |
| 出牌 | 1 行动（普通）/ 0（快速） | 策略牌效果 | ✅ |
| 夜行 | 弃 2 手牌 | +1 行动 | ✅ 2 手牌（2 资源）→ 1 行动（1 资源），低效转换，符合设计意图 |

### 1.2 阵营专属行动

| 行动 | 行动占用 | 动态花费 | 产出 | 一致性判定 |
| - | - | - | - | - |
| 侦查（警） | 1 行动 | 地点当前情报值 | 1"证据 Token" | ✅ 成本与版图状态挂钩 |
| 布控（警） | 1 行动（免费条件存在） | 0 | 地点情报值修正 +2 | ✅ 状态性行动 |
| 抓捕（警） | 2 行动 | 补差情报（可 0） | 犯罪等级分 + 高效 +1 | ✅ |
| 隐藏（罪） | 1 行动 | 0 | 隐藏值 +1 | ✅ 状态性行动 |
| 作案（罪） | 2 行动 | 地点当前情报值 | 影响值分 + 匹配 +1 + 回填 1 情报 | ✅ 回填使成本递增（§3.3） |
| 登场（英） | 2 行动 | 地点当前情报值 | 该地点证据数 X 分 | ✅ |
| 制裁（英） | 2 行动 | 隐藏值 + 已持证据数 | 等差数列分 | ✅ |
| 追偿（受） | 1 行动 + 1 情报 | 1 情报 | 黎明条件夺分 ±1 | ✅ 轻量型 |
| 爆料（受） | 1 行动 + 1 情报 | 1 情报 | 翻面条件 +1 | ✅ 轻量型 |

### 1.3 一致性发现

**结论**：所有基础操作的投入产出关系一致，无矛盾。以下为 1 处需在量化中重点跟踪的结构性现象（非矛盾）：

- **和平奖励的边界**：黎明"版图上无任何'证据 Token'或'迷雾 Token'"时警长 +1。在 3 罪犯局中，罪犯每轮作案产生新证据，警长每轮最多 2 行动（侦查 2 次），**无法清空 3 罪犯每轮新增的 3 个证据** → 和平奖励的触发被结构性压制，独立推演见 §2.6。

## 2. 第二步：0 能力数值基准

### 2.1 罪犯基准（等级 2 · 核心区）

#### 场景声明

- 目标：罪犯等级 2（隐藏值上限 2），核心区地点（初始情报 3、影响值 2、无特殊效果）
- 0 特殊能力，默认无夜行（手牌上限 3、打牌竞争，主基准不预设夜行）
- 初始隐藏值 2，调查降隐藏（-1）、补给阶段隐藏回复（+1）逐轮计入
- 作案回填机制生效（每次作案地点情报值 +1）

#### 单次 KSA 得分

`影响值 2 + 匹配加分 1（等级 2 与影响值 2 相差 0）= 3 分/次`

#### KSA 次数目标

`⌈15 ÷ 3⌉ = 5 次作案`

**罪犯基准结论**：等级 2 罪犯目标 5 次作案（3 分/次），**9-11 轮**达标。资源效率 1.07~1.5 分/资源（策略 A/C），轮次效率 1.36~1.67 分/轮。主基准 ✅

### 2.2 警长基准

#### 场景声明

- 目标：4 人局 3 罪犯，无受害者/英雄；警长 0 特殊能力
- 抓捕目标为等级 2 罪犯（隐藏值上限 2）与等级 3 罪犯（隐藏值上限 3）两档对比
- 抓捕依赖罪犯在版图留下证据（无证据则无法侦查）
- 警长调查降的"隐藏值"概念不适用（非罪犯），只追情报与行动账

#### 单次 KSA 得分

- 抓等级 2（1 证据）：「犯罪等级 2 + 高效 +1 = **3 分**」
- 抓等级 3（1 证据）：「犯罪等级 3 + 高效 +1 = **4 分**」

#### 侦查/抓捕链成本（每次抓捕）

- 侦查：1 行动 + 地点当前情报值（罪犯压 0 作案后回填 1 → 通常 1 情报）
- 抓捕：2 行动 + 补差（X=1 < 隐藏值 2 → 补差 1；X=1 < 隐藏值 3 → 补差 2）
- **单次抓捕完整成本（等级 2 目标）= 3 行动 + 2 情报**（侦查 1 情报 + 补差 1 情报）
- **单次抓捕完整成本（等级 3 目标）= 3 行动 + 3 情报**（侦查 1 情报 + 补差 2 情报）

| R8 | S, M | 3 | 0 | 1 | 2 | 3 | 0 |
| R9 | A, M | 3 | 2 | 1 | 1 | 3 | 3 |
| R10 | D, D | 3 | 0 | 0 | 3 | 3 | 0 |

#### 和平奖励独立推演（§2.6）

**触发条件**：黎明时版图无任何"证据 Token"或"迷雾 Token"（警长手中持有的不计）。

4 人局推演：

| 阶段 | 版图证据状态 | 和平可达？ |
| - | - | - |
| R1 首轮 | 罪犯压点中（3 罪犯中 1-2 人可能已作案留证） | 可能（若均未作案） |
| R2 起常态 | 3 罪犯每轮各作案 1 次 → 版图稳态 3+ 证据；警长每轮侦查取 1-2 个 → 版图仍有 1-3 个 | ❌ 几乎不可达 |
| 罪犯被压制期 | 若 1-2 罪犯入狱，作案减少；警长清证 | 偶发（+1） |
| 罪犯集中爆发期 | 证据快速增加 | ❌ |

**独立推演结论**：和平奖励正常对局 **触发 1-2 次**（首轮 + 罪犯入狱真空期各 1），按 **1.5 分** 计入基准。设计意图"和平奖励为警长保底"在 3 罪犯局基本失效——罪犯每轮作案与警长每轮 2 行动清证速度不匹配（3 新增 vs 2 清除），版图证据净增长，和平奖励结构性不可达。

#### 警长基准结论

| 目标 | 抓捕次数 | 12 轮实际分 | 判定 |
| - | - | - | - |
| 等级 2 | 4 次 + 和平 | 13 分 | ❌ 未达 15 |
| 等级 3 | 3 次 + 和平 | 13 分 | ❌ 未达 15 |
| 混合（2 次等级 3 + 2 次等级 2） | 4 次 | 14 分 + 和平 | ❌ 边缘 |
| 理想（4 次等级 3，14-15 轮） | 4 次 | 16 分 + 和平 | ✅ 但超 12 轮 |

**警长 0 能力基准：12 轮内约 13-14 分，达不到 15 分终局线** ⚠️

- 加权当量视角（§3.6）：4 次抓捕 × 3 分 × 1.33 ≈ 16 当量，跨阵营对比不弱；但**终局触发看实际分**（15 分是实际分门槛），警长实际分不足
- 关键依赖：警长必须抓等级 3-4 罪犯才有单次高分；若罪犯全部选低等级（等级 1-2），警长到 15 分需 6-8 次抓捕，12 轮内完全不可能
- **结构性风险：警长纯分能力偏弱，需角色技能补偿**（r03/r04 验证铁腕/猎犬/智囊能否补足 2-3 分缺口）

### 2.3 超级英雄基准（5-7 人局简述）

#### 制裁路线（主 KSA，夜枭口径）

- 单次得分：持有证据数（1、2、3…0），等差数列 **1+2+3+4+5 = 15 分（5 次）**
- KSA 次数：**5 次制裁**
- 每次成本：2 行动 +（目标隐藏值 + 已持证据数）情报
  - 第 1 次：2 + 0 = 2；第 2 次：2 + 1 = 3；第 3 次：2 + 2 = 4；第 4 次：2 + 3 = 5；第 5 次：2 + 4 = 6
  - 累计动态花费 = 20 情报（若目标隐藏值恒 2）
- 准备轮：5 执行轮（独占型）+ 攒情报轮 ≈ 3-4 轮（每次制裁前需 2-4 情报）
- **总周期：8-9 轮 ✅**（证据供给依赖 3-4 罪犯作案，5-7 人局罪犯人数充足）

> 注：制裁每轮 1 次（重大），且制裁后英雄持有证据 → 版图证据减少 → 间接利警（和平奖励在 5-7 人局 4 罪犯下依旧难触发）。

#### 登场路线（次要）

- 单次得分 = 该地点证据数 X（通常 1-2）
- 15 分需 8-15 次登场，效率低；登场是"制裁的补充/转移焦点"工具
- **基准判定**：英雄主 KSA = 制裁，5 次 15 分，8-9 轮 ✅

### 2.4 受害者基准（5-7 人局简述）

#### 追偿路线（主 KSA，轻量型）

- 单次：1 行动 + 1 情报；触发条件"目标期间得分 ≥ 2"
- 实际分收益：目标 -1、自己 +1 → **自己 +1 实际分/次**（当量 1.5-2.0 加权）
- 15 分需 **15 次追偿触发** + 每次情报积累
- 轻量型节奏：每轮 2 行动的 1 行动做追偿，另 1 行动调查 → 追偿频率高（每轮 1 次），但单次仅 +1
- 触发率独立推演：目标"期间得分 ≥ 2"在 5-7 人局高活跃度下**触发率中等**（高分玩家每轮 2-3 分常见；低分玩家难触发）
- **总周期估算**：15 次追偿（每次 1 轮频率）+ 情报采集 + 未触发率修正 → **12+ 轮，超预算** ⚠️

> 0 能力受害者的 15 实际分极难达成（依赖 15 次外部触发）。设计意图符合 §4.2 原则 16"无基础得分手段阵营靠技能补偿"——受害者 3 角色（艾登+1/门槛降、记者爆料强化、掮客门路）正是补偿机制，r03 验证补偿是否充分。

#### 爆料路线（辅助）

- 单次：1 行动 + 1 情报；翻面 +1（条件：地点被重大行动选为目标）
- 触发被动（需他人行动），频率低；作为追偿外的补充
- **基准判定**：受害者 0 能力不达标 ⚠️，依赖技能补偿

## 3. 对照主基准判定（§4.1）

| 阵营 | 0 能力 KSA 次数 | 单次分 | 12 轮内实际分 | 达标？ |
| - | - | - | - | - |
| 罪犯（等级 2） | 5 次作案 | 3 分 | 15 分（9-11 轮） | ✅ 达标 |
| 警长（等级 2 目标） | 4-5 次抓捕 | 3 分 | 13-14 分 | ❌ 差 1-2 分 |
| 警长（等级 3 目标） | 3-4 次抓捕 | 4 分 | 13-16 分 | ❌ 12 轮内 3 次仅 13 分 |
| 超级英雄（制裁） | 5 次 | 等差数列 | 15 分（8-9 轮） | ✅ 达标 |
| 受害者（追偿） | 15 次 | +1 实际分 | 12+ 轮难达 | ❌ 依赖技能 |

**核心发现**：

1. **警长 0 能力偏弱**：达到 15 分目标，警长比罪犯多需 2-4 个有效抓捕轮。和平奖励（设计保底）在 3 罪犯局结构性不可达（§2.6），警长纯分缺口 **2-3 分**，必须由角色技能补足。
2. **受害者 0 能力偏弱**：追偿单次 +1 实际分、需 15 次触发，靠技能补偿（设计意图允许）。
3. **罪犯与英雄达标**：等级 2 罪犯 9-11 轮、制裁 5 次 8-9 轮，节奏健康。
4. **节奏梯度观察**：罪犯选低等级（1）时单次仅 2 分（影响 1 + 匹配 1），需 8 次作案 → 超 12 轮；高等级（3-4）单次 4-5 分但准备长。等级 2 是效率甜点——**存在"等级 2 最优"策略收敛风险**（§3.15 策略多样性），r04 深入检查。

## 5. 结论与移交

**r02 主判定**：

1. 🔴 **警长 0 能力 12 轮内仅 13-14 分，未达 15 分终局线**。原因：① 抓捕依赖罪犯作案留证（被动）；② 单次 3 分需 5 次才达标，但每 2 轮仅能完成 1 次；③ 和平奖励保底失效（3 罪犯局结构性不可达）。**需角色技能补偿 2-3 分缺口**——移交 r03 检查 3 张警长卡技能的实际补偿量。
2. 🔴 **和平奖励机制在 3 罪犯局失效**：每轮 3 新证据 vs 警长 2 行动清证，版图证据净增长。设计意图（保底）与实际触发（1-2 次）脱节，需在 r03/r04 评估是否调整（如"版图证据 ≤ 1"或"警长清空所有证据"的奖励重设）。
3. 🟡 **受害者 0 能力不达标**（设计允许，靠技能）——r03 验证技能补偿量。
4. 🟡 **罪犯等级 2 效率最优**，存在策略收敛候选——r04 深入。
5. ✅ 罪犯、英雄达标，地点梯度合理。

**移交 r03**：基于本基准，对照检查角色技能的成本收益（尤其警长 3 卡能否补 2-3 分缺口）、地点特殊效果的效率、以及和平奖励机制的处置建议。
