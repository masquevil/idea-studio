# r02 · 量化基准（第三轮）

> 范围：① 检查规则书基础操作投入产出一致性 → ② 建立 0 特殊能力数值基准。
> 0 能力口径：不计角色技能、不计地点特殊效果、不计策略牌兑现（手牌仅按轮次供给记账）。
> 基准对照：量化审查规则 §4.1 —— 0 能力 4 人局 12 轮预期 **14-15 分**（≈ 0.39-0.42 分/资源、1.17-1.25 分/轮）。

### 1.2 一致性结论

- 除 **B1**（影响值上限描述）外，基础操作投入产出关系无原则性矛盾。
- 关键机制组合（B4）需要重点量化：**调查降情报 vs 复苏回填** 的组合决定了作案的真实动态成本，是本节基准的核心变量。

## 2. 资源模型与基准

### 2.1 双维度基准

| 指标 | 公式 | 设计基准 |
| - | - | - |
| 资源效率 | IV / 累计真花费 IC（仅资源→IV 的投入） | ≈ 0.39-0.42 分/资源 |
| 轮次效率 | IV / 完整周期轮数（含准备轮） | ≈ 1.17-1.25 分/轮 |

- 单玩家总资源池 = 12 轮 × 3 资源（2 行动 + 1 手牌）= 36 资源
- 14-15 分 / 36 资源 ≈ 0.39-0.42 分/资源

### 2.2 动态成本定义（核心变量）

**作案动态成本 = 目标地点当前情报值（0~5）**，受两种机制驱动：

| 机制 | 方向 | 触发 | 影响 |
| - | - | - | - |
| 调查 | 降低 1 | 行动（罪犯隐藏 -1） | 降低该地点作案/侦查成本 |
| 傍晚复苏 | 提高 1 | 每轮傍晚，区域最低地点 +1（不超初始；并列全放） | 抬高该区域最低地点的成本 |

**关键推论（首次 vs 稳态成本）**：

- **首次成本**（把地点从初始压到低位的代价）：核心 3→2→1 需 2 次调查；上城 4→1 需 3 次调查；下城 2→1 需 1 次调查
- **稳态成本**（作案后该地点情报回到 X）：因"作案不减情报 + 傍晚回填"，作案后地点情报会被回填抬升 → **每次作案前都需重新压低**

## 3. 0 能力罪犯基准

### 3.1 通用作案流水账模板（解释口径）

> 记账规则：调查 = 资源转换（1 行动 → 1 情报，不记入真花费 IC，只记余额）；作案 = 资源→IV（情报花费记入真花费 IC）。每轮供给 IC = 2 行动 + 1 手牌（手牌不兑现）。
> 行动代号：D = 调查（转换）、C = 作案（资源→IV）。

### 3.2 场景 A：核心区作案（影响 2 · 初始情报 3 · 隐藏上限 3 · 犯罪等级 2）

**起点状态**：目标地点 P 初始情报 3（核心区典型值）；罪犯情报 0、隐藏 3；复苏机制生效。

| 回合 | 行动序列 | P 情报值(行前→行后→傍晚) | 供给 IC | 花费 IC(真) | 情报余额 | 手牌余额 | 本回合 IV |
| - | - | - | - | - | - | - | - |
| R1 | D(D:3→2)、D(2→1) | 3→1→2 | 3 | 0 | 2 | 1 | 0 |
| R2 | C(花2情报,3分) | 2→2→3 | 3 | 2 | 0 | 2 | 3 |
| R3 | D(3→2)、D(2→1) | 3→1→2 | 3 | 0 | 2 | 3 | 0 |
| R4 | C(花2,3分) | 2→2→3 | 3 | 2 | 0 | 4 | 3 |

**循环判定**：R1-R2 构成完整闭合循环（R3 起点状态与 R1 可比：P=3、情报 2、隐藏 1（隐藏递减但 ≥0 后稳定））。循环：2 轮 / 2 次真花费 / 3 分。

**效率**：

- 资源效率（真花费）= 3/2 = **1.5 分/资源**（显著高于基准 0.39-0.42）
- 轮次效率 = 3/2 = **1.5 分/轮**（高于基准 1.17-1.25）
- 全资源口径（4 行动 + 2 情报 = 6 资源/案）：3/6 = **0.5 分/资源**（贴近基准上限）
- 可持续性：证据 5 枚后移动继续（得分不变）；隐藏降至 0 后停止递减，但 0 隐藏使警长抓捕补差为 0 → **风险敞口随循环累积**
- 12 轮上限 → 6 案 → **18 分**（无视警长干预的理论上限）

### 3.3 场景 B：下城区码头作案（影响 1 · 初始 2 · 隐秘卸货 -1 作为敏感性对照）

**起点**：码头初始 2；隐藏 3；情报 0。此场景含地点效果（敏感性分析，非纯 0 能力）。

| 回合 | 行动序列 | 码头情报(行前→行后→傍晚) | 供给 IC | 花费 IC(真) | 情报余额 | IV |
| - | - | - | - | - | - | - |
| R1 | D(2→1)、D(1→0) | 2→0→1 | 3 | 0 | 2 | 0 |
| R2 | C(花1-1=0,2分) | 1→1→2(上限2不加) | 3 | 0 | 2 | 2 |
| R3 | D(2→1)、D(1→0) | 2→0→1 | 3 | 0 | 3 | 0 |
| R4 | C(花0,2分) | 1→1→2 | 3 | 0 | 3 | 2 |

**效率**：

- 资源效率（真花费）：作案情报 0 → 分子为 0，**畸形无穷大** → 反映"情报 Token 花费之外的劳动全在调查转换中"
- 轮次效率 = 2/2 = **1.0 分/轮**（低于核心 1.5）
- 全资源口径（3 行动 + 0 情报 = 3 资源/案）：2/3 = **0.67 分/资源**
- **关键**：码头模式行动密集（每案 3 行动/2 轮）但情报消耗为 0 → 手牌无法通过读报变现，3 罪犯同时刷码头会使每轮实际只用 2 行动，第 3 行动只能摸牌/出牌
- 风险代价相同：调查使隐藏 -1 → 0，易被警长抓捕

### 3.4 场景 C：上城区作案（影响 3 · 初始 4 · 犯罪等级 3 才有超额）

**起点**：上城 P 初始 4；隐藏上限 2（等级 3 典型）；情报 0。

| 回合 | 行动序列 | P 情报(行前→行后→傍晚) | 供给 IC | 花费 IC(真) | 情报余额 | IV |
| - | - | - | - | - | - | - |
| R1 | D(4→3)、D(3→2) | 4→2→3 | 3 | 0 | 2 | 0 |
| R2 | D(3→2)、D(2→1) | 3→1→2 | 3 | 0 | 4 | 0 |
| R3 | C(花2,3分) | 2→2→3 | 3 | 2 | 2 | 3 |

**效率**：

- 资源效率 = 3/2 = **1.5 分/资源**（同核心）
- 轮次效率 = 3/3 = **1.0 分/轮**（低于核心，因首次压降需 3 轮）
- 全资源口径（4 行动 + 2 情报 = 6 资源/案）：3/6 = **0.5 分/资源**
- 若等级 3 且有超额（上城 3≥3）→ +1 = 4 分/案 → 4/3 = 1.33 分/轮，反超核心

### 3.5 罪犯理性选择（0 能力）

| 路线 | 影响 | 初始情报 | 首次周期 | 稳态轮次效率 | 超额条件 |
| - | - | - | - | - | - |
| 核心区 | 2 | 3 | 2 轮（2D+1C） | **1.5 分/轮** | 等级 ≤2 全超额 |
| 下城区 | 1 | 2 | 2 轮（2D+1C） | 1.0 分/轮 | 等级 1 超额 |
| 上城区 | 3 | 4 | 3 轮（4D+1C） | 1.0 分/轮（等级1-2）；1.33 分/轮（等级3+） | 等级 3-4 超额 |

**理性结论**：

1. **核心区为 0 能力下最优作案区**（1.5 分/轮），且等级 1-2 罪犯全部超额 → **全部罪犯理性涌向核心区**，策略收敛风险成立（预计 3 罪犯争抢 6 张核心地点）
2. 下城/上城为次优路线，仅在核心被争抢/布控/设伏时使用 → 区域梯度存在但收益差不足以支撑多样性
3. 全局理论上限（无视警长）× 罪犯路线分歧：核心 18 分 > 下城 12-14 分 > 上城 12-16 分 → **核心区为必胜策略**（在无干预假设下）

> ⚠️ 以上为**单侧 0 干预**上限值。真实对局中警长抑制（侦查夺证据、抓捕、无证据奖励）会显著下修，净平衡判定在 r04。但"罪犯理性全部涌向核心"的判断在抑制存在时依然成立（相对优势不变），需在 r03 重点审查。

## 4. 0 能力警长基准

### 4.1 场景 D：核心区侦查→抓捕链（犯罪等级 2 · 隐藏 3）

**起点**：目标罪犯隐藏 3（初始）；地点 P 情报 1（被罪犯调查压低后的有利侦查位）；警长情报 4。

| 回合 | 行动序列 | 花费 IC(真) | 情报余额 | 说明 |
| - | - | - | - | - |
| R1 | 侦查P(花1,得1证据)、侦查P(花1,得2证据) | 2 | 2 | 持 2 证据 |
| R2 | 抓捕(花2行动+补差1,3分) | 1 | 1 | X=2<隐藏3 差1→补1；C级2，X=2 高效? X<2 否 |
| 合计 | 3 行动 + 3 情报 | 3 | - | IV = 3 分 |

**效率**：

- 资源效率 = 3/3 = **1.0 分/资源**（高于基准 0.39-0.42）
- 轮次效率 = 3 分/2 轮 = **1.5 分/轮**
- 若持 3 证据（无补差）：抓获得 2 分（X=3 不高效），2 分/轮 → 1.0 分/轮
- 若高效触发（X=1 < 等级 2，隐藏 0 时）：3+1 = 4 分/次 → 2.0 分/轮

**审计行**：R1-R2 累计供给 6 资源 / 真花费 3 / 累计 IV 3。侦察 2 次为转换（情报→证据），计入行动消耗但不计入真花费。

### 4.2 场景 E：无证据奖励（+2/黎明）

- 条件：黎明时版图无任何"证据 Token"（警长手中持有不计入）。
- 前提：需在当轮内，罪犯的全部版图证据被警长侦查/金库/英雄清空，或罪犯未作案。
- 0 能力下罪犯每 2 轮至少 1 案（场景 A），版图证据持续存在 → **无证据奖励 0 能力下难以触发**，属于中期压制成功后的额外收益（非线性）。
- 估值：若在 12 轮中成功压制 2-3 个黎明 → +4~6 分（若触发，警长总分会显著上升）。

### 4.3 警长理性选择

| 路线 | 条件 | 轮次效率 | 备注 |
| - | - | - | - |
| 低情报地点侦查→抓捕 | 罪犯把地点压到 1 | 1.5 分/轮（补差 1） | 依赖罪犯行为 |
| 高情报地点侦查→抓捕 | 地点情报 3-4 | 侦查花 3-4×2 证据 → 0.75-1.0 分/轮 | 自建链低效 |
| 布控压制 | 无直接 IV | 机会成本 | 抬高罪犯作案成本 2/案 |
| 无证据奖励 | 需清场 | 中期 +2/黎明 | 不稳定 |

**理性结论**：警长单侧 0 能力效率（1.0-1.5 分/轮）**与罪犯核心路线（1.5 分/轮）基本持平**，但警长的侦查链**依赖罪犯压低地点情报**（罪犯压低 → 警长侦查便宜）。这形成"罪犯压区助警"的结构性关联。

## 5. 与设计基准对照

| 指标 | 设计基准 | 罪犯核心(单侧) | 警长链(单侧) | 判定 |
| - | - | - | - | - |
| 资源效率(真花费) | 0.39-0.42 | 1.5 | 1.0 | 🔴 显著偏高 |
| 轮次效率 | 1.17-1.25 | 1.5 | 1.5 | 🟡 偏高 |
| 全资源口径 | ~0.39-0.42（36 资源→14-15 分） | 0.5 | 0.33-0.5 | 🟡 偏高/持平 |
| 12 轮上限总分 | 14-15 | 18（无视警长） | ~12-18（视压制） | 🔴 罪犯上限超标 |

### 5.1 偏差归因（如实报告）

1. **"真花费"口径的固有偏差**：资源效率分子只含作案/抓捕情报消耗，而准备链（调查/侦查）的行动消耗被排除在外 → 数值天然虚高。**全资源口径（含转换行动）与基准更可比**。
2. **16/36 资源闲置**：0 能力下罪犯每案只花 2 情报（场景 A），大量手牌/摸牌资源闲置 → 单侧流程未用满 36 资源池，与基准"36 资源全用"前提不一致。
3. **无外部抑制**：单侧流水账不含警长干预，θ 值（抑制量）需在 r04 计算。罪犯上限 18 分 > 15 分终局线，说明**若无抑制，罪犯过早达成终局** → 平滑抑制机制（警长抓捕/无证据奖励）是必要的。

### 5.2 关键基准结论（供 r03/r04 使用）

| # | 结论 | 级别 |
| - | - | - |
| Q1 | 核心区 0 能力作案为全游戏最优（1.5 分/轮），理性罪犯全部涌向核心 → 策略收敛风险 | 🔴 |
| Q2 | 罪犯"压区→作案"循环会降低地点情报 → 同时降低警长侦查成本（跨方联动） | 🔴 |
| Q3 | 复苏回填使单点难以压到 0 并保持（区域最低必回填），但多点齐压可让回填分散 | 🟡 |
| Q4 | 警长 0 能力链（1.0-1.5 分/轮）与罪犯核心持平，但依赖罪犯压区行为 | 🟡 |
| Q5 | 码头（隐匿卸货 -1）可形成 0 情报作案循环 → 需关注与"黑市返还"的叠加（见 r01 §4.2） | 🟡 |
| Q6 | 隐藏越压越低 → 抓捕风险上升，是罪犯压区循环的天然刹车（效率 vs 风险权衡） | 🟢 |
