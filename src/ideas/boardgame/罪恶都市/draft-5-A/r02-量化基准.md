# r02 · 量化基准

> 建立 0 特殊能力下的数值基准
> 审查内容：基础操作的计算与效率分析

---

## 1. 分析前提

### 1.1 基准定义

本基准假设所有角色无特殊能力（即"基础牌"状态），仅使用规则书中的基本操作。4 人局（1 警长 + 3 罪犯），标准版图 12 张。

### 1.2 基本单位

| 单位 | 说明 |
| - | - |
| **1 行动** | 最小时间单位，1 回合 = 2 行动。抓捕/作案额外消耗 1 行动 ≈ 2 行动 |
| **1 情报** | 最小资源单位 |
| **1 分** | 最终目标单位 |
| **1 手牌** | 策略牌，有上限 3 |
| **1 轮** | 一轮 = 所有玩家回合结束 |

### 1.3 版图平均参数

标准 4 人局随机抽取版图（上 3 + 核心 6 + 下 3）：

| 区域 | 平均初始情报值 | 平均影响值 | 平均得分/次作案 |
| - | :-: | :-: | :-: |
| 上城区 | 4.25 | 3.25 | 3.25 + 超额 = 约 4.25 |
| 核心区 | 3.38 | 2.25 | 2.25 + 超额(条件) = 约 2.25~3.25 |
| 下城区 | 2.25 | 1.25 | 1.25 + 超额(条件) = 约 1.25~2.25 |

**版图加权平均**（以抽取数量加权）：

- 平均初始情报值：(3×4.25 + 6×3.38 + 3×2.25) / 12 = (12.75 + 20.28 + 6.75) / 12 = **3.32**
- 平均影响值：(3×3.25 + 6×2.25 + 3×1.25) / 12 = (9.75 + 13.5 + 3.75) / 12 = **2.25**

## 2. 通用操作的投入产出表

### 2.1 各操作消耗与收益

| 操作 | 行动消耗 | 情报消耗 | 手牌消耗 | 直接收益 | 隐藏值变化(罪犯) | 效率(分/行动) |
| - | - | - | - | - | - | - |
| **调查** | 1 | 0 | 0 | 1 情报 | -1（仅罪犯） | 0（非直接得分） |
| **摸牌** | 1 | 0 | 0 | 1 手牌 | — | 0 |
| **出牌** | 0/1 | 0 | -1 手牌 | 牌效果 | — | 看牌 |
| **读报** | 1+1=2 | 0 | -1 手牌 | 1 情报 | — | 0 |
| **侦查** 🔵 | 1 | =地点当前情报值 | 0 | 1 证据 | — | 0（非直接得分） |
| **布控** 🔵 | 1 | 0 | 0 | 地点情报值 +2（本轮） | — | 0 |
| **抓捕** 🔵 | 1+1=2 | 情报补差 | 0 | 犯罪等级 + (0/1)分 | — | 1~2 分/行动 |
| **隐藏** 🔴 | 1 | 0 | 0 | 隐藏值 +1 | +1 | 0 |
| **作案** 🔴 | 1+1=2 | =地点情报值 | 0 | 影响值 + 超额(0/1)分 | — | 见下文 |

### 2.2 调查的效率

调查获得情报的效率：

- 1 行动 → 1 情报（罪犯额外 -1 隐藏值）
- **效率**：1 行动 = 1 情报

调查是**核心资源获取手段**。在 0 特殊能力下，玩家平均 1 调查拿 1 情报，这是所有后续操作的基石。

### 2.3 摸牌的效率

摸牌获得策略牌的效率：

- 1 行动 → 1 手牌

但手牌上限 3 张意味着不能无限积累策略牌。策略牌的平均价值取决于以下分析。

#### 策略牌平均价值估算

35 张牌中：

| 牌类 | 数量 | 情报等价价值 |
| - | - | - |
| 情报报告(3张) | 3 | 2 情报 |
| 情报截获(2张) | 2 | 1 情报 |
| 情报共享(1张) | 1 | 2 情报（双方各 1） |
| 其他(28张) | 28 | 非直接情报，难以量化 |
| 快速牌(9张) | 9 | 0 行动消耗 → 免费价值 |

粗略估算：

- 情报类 6 张平均价值 ≈ 1.7 情报
- 非情报类难以精确量化，但至少有情报等价价值（替代）
- 按情报等价 ≈ 1 情报/牌（保守）

**摸牌的期望收益**：1 行动 → ≈1 情报等价（策略牌出牌还需额外行动，但快速牌除外）

### 2.4 读报的效率（看守所保底）

读报的性价比：

- 2 行动 + 1 手牌 → 1 情报
- 手牌成本：若手牌本身是通过摸牌获得的，则 1 手牌 ≈ 1 行动
- 总成本：2 行动（读报）+ 1 行动（获得手牌）= 3 行动 → 1 情报

**效率**：1 情报/3 行动，远低于调查的 1 情报/1 行动。这符合"看守所保底手段"的设计意图。

## 3. 警长基础操作分析

### 3.1 警长的得分来源

警长在 0 特殊能力下只有一种得分方式：**抓捕**。

| 得分途径 | 条件 | 分数 |
| - | - | - |
| 抓捕（犯罪等级） | 成功抓捕 | 1-4 分 |
| 高效抓捕 | 移动证据 < 犯罪等级 | +1 |
| 无证据奖励 | 黎明阶段版图无任何证据 | +1 |

### 3.2 抓捕的标准化成本-收益分析

假设罪犯犯罪等级为 C，当前隐藏值为 H，警长持有 k 个该罪犯的"证据 Token"。

**抓捕成本**：

- 2 行动
- 情报补差：若 k < H，额外 (H-k) × 2 情报
- 获取这 k 个证据的先期成本：k 次侦查（每次 1 行动 + 地点情报值情报）

**侦查成本平均估算**：

- 平均地点情报值 = 3.32
- 每次侦查成本 = 1 行动 + 3.32 情报
- 每次侦查获得 1 个"证据 Token"

**完整抓捕流程成本**（正常收集证据，不用情报补差）：

| 步骤 | 行动 | 情报 | 备注 |
| - | - | - | - |
| k 次侦查 | k | k × 3.32 | k = 需要的证据数 |
| 1 次抓捕 | 2 | 0（k ≥ H 时） | — |
| **合计** | **k + 2** | **k × 3.32** | |

**收益**：C 分（+1 高效抓捕如果 k < C）

### 3.3 典型场景下的得分效率

#### 场景 A：犯罪等级 2，隐藏值 2，收集 2 证据抓捕

- 2 次侦查：2 行动 + 6.64 情报
- 1 次抓捕：2 行动 + 0 情报（k=2 ≥ H=2）
- **总成本**：4 行动 + 6.64 情报
- **总收益**：2 分（犯罪等级 2）
- **侦查情报回收计算**：侦查花费的情报回到供应堆，但情报本身需要先获取。
- **获取 6.64 情报的成本**：6.64 次调查 = 6.64 行动（罪犯调查不减隐藏值，仅损失隐藏值？此处暂不计入）

**真实总成本**：

- 6.64 行动（调查获取情报）+ 4 行动（侦查+抓捕）= **10.64 行动**
- **得分效率**：2 分 / 10.64 行动 = **0.19 分/行动**（≈ 5.3 行动得 1 分）

#### 场景 B：犯罪等级 2，隐藏值 2，只收集 1 证据，情报补差抓捕

- 1 次侦查：1 行动 + 3.32 情报
- 1 次抓捕：2 行动 + (2-1)×2 = 2 情报补差
- **总成本**：3 行动 + 5.32 情报
- **情报获取成本**：5.32 行动（调查）
- **真实总成本**：5.32 + 3 = **8.32 行动**
- **收益**：2 分（犯罪等级 2）+ 1 分（高效抓捕：1<2）= **3 分**
- **得分效率**：3 / 8.32 = **0.36 分/行动**（≈ 2.77 行动得 1 分）

**结论**：高效抓捕（情报补差策略）的效率远高于正常收集证据。鼓励警长在证据不足时用情报补差抓捕。

#### 场景 C：犯罪等级 3，隐藏值 2，收集 2 证据抓捕

- 2 次侦查：2 行动 + 6.64 情报
- 1 次抓捕：2 行动 + 0（k=2 ≥ H=2）
- **总成本**：4 行动 + 6.64 情报
- **情报获取成本**：6.64 行动
- **真实总成本**：10.64 行动
- **收益**：3 分
- **效率**：3 / 10.64 = **0.28 分/行动**（≈ 3.55 行动得 1 分）

#### 场景 D：犯罪等级 4，隐藏值 2，收集 2 证据抓捕

- 同理：10.64 行动
- **收益**：4 分
- **效率**：4 / 10.64 = **0.38 分/行动**（≈ 2.66 行动得 1 分）

#### 场景 E：犯罪等级 3，隐藏值 2，收集 1 证据，情报补差

- 1 次侦查：1 行动 + 3.32 情报
- 1 次抓捕：2 行动 + (2-1)×2 = 2 情报
- **总成本**：3 行动 + 5.32 情报
- **情报获取成本**：5.32 行动
- **真实总成本**：8.32 行动
- **收益**：3 分 + 1 分（高效抓捕）= **4 分**
- **效率**：4 / 8.32 = **0.48 分/行动**（≈ 2.08 行动得 1 分）

### 3.4 无证据奖励分析

黎明阶段版图上无任何"证据 Token"时警长 +1 分。

假设游戏进行 12 轮满，警长每轮都拿到无证据奖励：

- 12 轮 × 1 分 = 12 分（接近胜利的 15 分）
- 但实现难度：罪犯必然作案，要保证版图上无证据，需要每次罪犯作案后立即清空

**实际可实现性**：极低。3 个罪犯每轮至少 3 次作案（每人 1 次），每次作案放置 1 个证据。警长需要清空这些证据才能拿无证据奖励。

**结论**：无证据奖励更多是"额外彩蛋"，不能作为稳定得分来源。

## 4. 罪犯基础操作分析

### 4.1 罪犯的得分来源

| 得分途径 | 条件 | 分数公式 |
| - | - | - |
| 作案 | 选择地点，花费情报 | 地点影响值 |
| 超额作案 | 作案地点影响值 ≥ 犯罪等级 | +1 |

### 4.2 作案的标准化成本-收益分析

**一次完整作案的成本**：

- 2 行动（作案固定消耗）
- = 地点当前情报值 的情报（需要先获取）

**收益**：影响值 + (影响值 ≥ 犯罪等级 ? 1 : 0)

#### 场景 A：下城区作案（平均影响值 1.25，平均情报消耗 2.25）

- 情报获取成本：2.25 行动
- 2 行动（作案）
- **总成本**：4.25 行动
- **收益**：1.25 分 + 超额(仅犯罪等级 1 可触发) ≈ 1.25 分
- **效率**：1.25 / 4.25 = **0.29 分/行动**（≈ 3.4 行动得 1 分）

#### 场景 B：核心区作案（平均影响值 2.25，平均情报消耗 3.38）

- 情报获取成本：3.38 行动
- 2 行动（作案）
- **总成本**：5.38 行动
- **收益**：2.25 分 + 超额(犯罪等级 ≤ 2 可触发) ≈ 2.25~3.25 分
- **效率**（无超额）：2.25 / 5.38 = **0.42 分/行动**（≈ 2.39 行动得 1 分）
- **效率**（有超额）：3.25 / 5.38 = **0.60 分/行动**（≈ 1.65 行动得 1 分）

#### 场景 C：上城区作案（平均影响值 3.25，平均情报消耗 4.25）

- 情报获取成本：4.25 行动
- 2 行动（作案）
- **总成本**：6.25 行动
- **收益**：3.25 分 + 超额(犯罪等级 ≤ 3 可触发) ≈ 3.25~4.25 分
- **效率**（无超额）：3.25 / 6.25 = **0.52 分/行动**
- **效率**（有超额）：4.25 / 6.25 = **0.68 分/行动**（≈ 1.47 行动得 1 分）

#### 场景 D：博物馆作案（情报值 5，影响值 4）

- 情报获取成本：5 行动
- 2 行动（作案）
- **总成本**：7 行动
- **收益**：4 分 + 超额(仅犯罪等级 ≤ 4) = 最多 5 分
- **效率**：4 / 7 = **0.57 分/行动**
- **效率**（有超额）：5 / 7 = **0.71 分/行动**（≈ 1.4 行动得 1 分）

### 4.3 各罪犯等级的最佳策略选择

基于 0 特殊能力，分析各犯罪等级的理性选择：

| 犯罪等级 | 最佳作案区域 | 得分/行动 | 超额条件 | 评语 |
| - | - | - | - | - |
| 1 | 任意（下城核心均可） | 0.29~0.42 | 所有区域 ✅ | 低投入低回报，但稳 |
| 2 | 核心/上城 | 0.42~0.68 | 核心 ✅ 上城 ✅ | 效率适中，灵活 |
| 3 | 上城区 | 0.52~0.68 | 仅上城 ✅ | 高投入高回报 |
| 4 | 博物馆（唯一超额） | 0.57~0.71 | 仅博物馆(4) ✅ | 投入最高但回报最高 |

**关键发现**：在 0 特殊能力下，所有等级的罪犯**理性选择都是向上城/核心区聚集**。因为下城区的回报过低（0.29 分/行动），不如下城 2 次作案（1.25×2=2.5 分）理论上也可以在差不多的成本下得到，但既然行动力有限，上城区的高回报率天然更有吸引力。

这可能导致**上城区拥挤问题**——3 个罪犯都往上城核心跑。

## 5. 警长 vs 罪犯的效率对比

### 5.1 关键效率对比表

| 阵营 | 操作 | 得分效率(分/行动) | 1 分所需行动(近似) |
| - | - | - | - |
| 警长 | 完整抓捕(等级2, 2证据) | 0.19 | 5.3 行动 |
| 警长 | 情报补差抓捕(等级2, 1证据) | 0.36 | 2.77 行动 |
| 警长 | 情报补差抓捕(等级3, 2证据) | 0.28 | 3.55 行动 |
| 警长 | 情报补差抓捕(等级3, 1证据) | 0.48 | 2.08 行动 |
| 警长 | 情报补差抓捕(等级4, 2证据) | 0.38 | 2.66 行动 |
| 罪犯(等级1) | 下城作案 | 0.29 | 3.4 行动 |
| 罪犯(等级2) | 核心区作案 | 0.42~0.60 | 1.65~2.39 行动 |
| 罪犯(等级3) | 上城作案 | 0.52~0.68 | 1.47~1.92 行动 |
| 罪犯(等级4) | 博物馆作案 | 0.57~0.71 | 1.4~1.75 行动 |

### 5.2 重要发现

1. **罪犯得分效率普遍高于警长**。在 0 特殊能力下，罪犯的得分效率（0.29~0.71 分/行动）普遍高于警长（0.19~0.48 分/行动）。

2. **警长的情报补差抓捕效率显著提升**——用情报替代证据收集过程，效率提升 50~100%。

3. **罪犯的最佳策略是上城区作案**，但上城区情报值也最高（情报获取成本大）。尽管如此，平均分/行动比仍是最优。

4. **警长面对多个罪犯时，抓捕哪个的决策影响很大**：
   - 抓等级 2 罪犯（1 证据补差）→ 3 分 / 8.32 行动 = **0.36**
   - 抓等级 3 罪犯（1 证据补差）→ 4 分 / 8.32 行动 = **0.48**
   - 抓等级 4 罪犯（2 证据补差）→ 4 分 / 10.64 行动 = **0.38**

   优先抓等级 3 效率最高。

### 5.3 达到 15 分所需的回合数估算

#### 罪犯（等级 2，核心区作案）

- 每轮 2 行动 → 作案需 2 行动 = 每轮 1 次作案
- 假设情报储备足够（前期调查储备）
- 每轮得分 ≈ 2.25 分 + 超额 1 分 = 3.25 分（平均）
- 但前几轮需要调查积累情报，实际前 2~3 轮得分为 0
- 12 轮中：3 轮准备 + 9 轮作案 = 9 × 3.25 = 29.25 分（远超出 15 分）

**但这是理想的"无限资源"假设**——实际上情报获取限制了作案频率。每轮最多调查获取 3.32 情报（平均），作案消耗 ≈ 3.38 情报。所以需要调查 1 轮才能作案 1 次。

**更实际的节奏**：

- 第 1 轮：调查 × 2（收集 2 情报，消耗 2 行动）
- 第 2 轮：调查 × 1（1 情报）+ 作案（3 情报 + 2 行动）= 2 分
- 第 3-4 轮：同第 2 轮，每轮得 2 分
- 以此类推，每 2 轮作案 1 次，每次约 2.25+1=3.25 分
- 12 轮 ≈ 6 次作案 ≈ 19.5 分
- **达到 15 分约在第 9~10 轮**

#### 警长（目标等级 3 罪犯，1 证据补差）

- 每轮 2 行动 → 但抓捕需 2 行动，所以每轮 1 次抓捕
- 但需要先侦查获取至少 1 个证据
- **典型节奏**：
  - 第 1 轮：调查 × 2（收集情报）
  - 第 2 轮：侦查 × 1（得 1 证据）+ 抓捕（2 行动）= 4 分
  - 第 3 轮：调查 × 2（补充情报）
  - 第 4 轮：侦查 × 1 + 抓捕 = 4 分
  - 以此类推，每 2 轮 ≈ 4 分
  - 12 轮 ≈ 6 次抓捕 ≈ 24 分（远超 15 分）
  - **达到 15 分约在第 7~8 轮**

**结论**：在 0 特殊能力基准下，**双方都能在 12 轮内达到 15 分**。警长略快（如果目标等级 3 罪犯），但差异不过大。加上其他因素（证据 Token 有限、被捕后暂停等），节奏在可接受范围内。

## 6. 证据 Token 循环与资源枯竭

### 6.1 证据 Token 的循环周期

每个罪犯有 5 个证据 Token。完整循环：

1. 角色供应堆（5 个）
2. 作案：放置到地点上（-1 从供应堆，+1 在地点）
3. 侦查：警长获得（从地点转移）
4. 抓捕：移入看守所（从警长转移）
5. 黎明阶段：每轮向右移动 1 格，移动到 0 时返回角色供应堆

**关键**：证据 Token 不会消耗（从不在供应堆消失），只是在不同区域间转移。

### 6.2 证据 Token 的上限与惩罚

5 个证据全部在版图上时，罪犯不能再放置新证据，只能移动现有证据。

**实际影响**：

- 罪犯第 1 次作案：用掉第 1 个 Token（供应堆剩 4）
- 第 2 次作案：用掉第 2 个 Token（供应堆剩 3）
- ...
- 第 5 次作案后：供应堆空，只能移动
- **5 次作案后不能再获得"新"作案位置**，只能移动

**出狱速度**：

- 犯罪等级 1：黎明阶段格数 = 1（只需 1 轮出狱）
- 犯罪等级 2：黎明阶段格数 = 2（需 2 轮出狱）
- 犯罪等级 3：黎明阶段格数 = 3（需 3 轮出狱）
- 犯罪等级 4：黎明阶段格数 = 4（需 4 轮出狱）

这意味着低等级罪犯虽然得分低，但被捕后出狱快，证据 Token 回收快。高等级得分高，但被捕一次严重影响节奏。

## 7. 操作频率预期

### 7.1 各等级罪犯的核心操作频率

基于每轮 2 行动力，不考虑特殊能力：

| 角色 | 每轮操作节奏 | 作案频率 |
| - | - | - |
| 等级 1 罪犯 | 调查 × 1 + 隐藏 × 1（保隐藏值），隔轮作案 | 约每 2 轮 1 次 |
| 等级 2 罪犯 | 调查 × 1 + 作案（侦查/作案 2 轮一次） | 约每 2 轮 1 次 |
| 等级 3 罪犯 | 调查积累 2~3 轮，上城作案 1 次 | 约每 3 轮 1 次 |
| 等级 4 罪犯 | 调查积累 3 轮，博物馆作案 1 次 | 约每 3~4 轮 1 次 |

### 7.2 被捕概率影响

隐藏值决定了警长抓捕的补差成本：

| 罪犯等级 | 隐藏值上限 | 平均隐藏值 | 警长补差成本基准 |
| - | - | - | - |
| 1 | 3 | 3（刚补给后） | 额外 6 情报（3 证据差距） |
| 2 | 3~4 | 3~4 | 额外 6~8 情报 |
| 3 | 2~3 | 2~3 | 额外 4~6 情报 |
| 4 | 2 | 2 | 额外 4 情报 |

**矛盾发现**：按照审查原则 §12"隐藏/防御值与等级正相关"，高等级应该更难被抓。但实际上：

- 等级 1：隐藏值上限 3（较高）→ 被抓成本大
- 等级 4：隐藏值上限 2（较低）→ 被抓成本小

**结论**：当前设计违反了"隐藏值与等级正相关"原则。高等级罪犯隐藏值更低，反而更容易被捕。这可能是故意的——高等级通过高得分补偿高风险——但需要在审查中标记。

## 8. 基准结论

| 维度 | 结论 | 说明 |
| - | - | - |
| **得分效率一致性** | ⚠️ 存在差异 | 罪犯（0.42~0.71）普遍高于警长（0.19~0.48），但警长可用高效抓捕缩小差距 |
| **规则一致性** | ✅ 合格 | 全局规则统一 |
| **蓄力行为** | ✅ 合理 | 调查积累情报是蓄力，作案/抓捕是兑现 |
| **读报是看守所保底** | ✅ 合格 | 效率明显低于调查 |
| **操作频率预期** | ⚠️ 部分合理 | 低等级作案频率应高于高等级，但当前资源消耗数据下差异不明显 |
| **隐藏/防御值** | 🔴 违反原则 | 等级 4 隐藏值 2 反而比等级 1 隐藏值 3 更低 |
| **得分效率达标** | ✅ 12 轮内可达 15 分 | 双方都能在 12 轮内达到 15 分，节奏适中 |

> 本基准为 r03（设计审查）和 r04（综合计算）提供基础比较数据。
