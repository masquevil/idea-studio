## 第一部分：基础操作投入产出一致性检查

### 1.1 各基础操作成本收益总表（当前版本）

| 操作 | 固定成本 | 动态成本 | 收益 | 性质 | 一致性 |
| - | - | - | - | - | - |
| 调查 | 1 行动 | — | 1"情报 Token" + 地点情报值 -1（罪犯再 -1 隐藏值） | 资源转换 | ✅ |
| 摸牌 | 1 行动 | — | 1 张手牌 | 资源转换 | ✅ |
| 出牌 | 0-1 行动（快速 0） | 1 手牌 | 牌面效果 | 视牌而定 | ✅ |
| 读报 | 2 行动 | 弃 1 手牌 | 1"情报 Token" | 资源转换（刻意低效） | ✅（按 2 行动计） |
| 侦查 | 1 行动 | 地点当前情报值 | 1 个"证据 Token" | 状态前置 | ✅ |
| 布控 | 1 行动（免费布控 0） | — | 目标地点作案花费 +2（本轮） | 状态性 | ✅ |
| 抓捕 | 2 行动 | 补差"情报 Token" | 犯罪等级分（+高效 +1） | 资源→IV | ⚠️ 见 B2-2 |
| 隐藏 | 1 行动 | — | 隐藏值 +1 | 状态性 | ✅ |
| 作案 | 2 行动 | 地点当前情报值 | 影响值分（+超额 +1） | 资源→IV | ⚠️ 见 B2-1 |
| 登场 | 2 行动 | 地点当前情报值 | 1 分 + 放置英雄 Token | 资源→IV + 状态 | ✅ |
| 制裁 | 2 行动 | 地点情报值 + 目标隐藏值 | 持有证据数（等差数列） | 资源→IV | ⚠️ 首次成本极高（见 §2.3） |
| 追偿 | 1 行动 + 2 情报 | — | 黎明夺分（条件触发） | 资源→IV（条件） | ⚠️ 见 §2.3 |
| 爆料 | 1 行动 + 2 情报 | — | 情报修正 + 翻开得分（条件） | 状态性 + 条件得分 | ⚠️ 见 §2.3 |

> 注：读报按"额外花费 1 个行动"句式计总消耗 2 行动（与抓捕/作案一致，r01 已建议正文补"总消耗 2 点行动力"）。

### 1.2 发现的投入产出不一致

#### 🔴 B2-1 地点情报值 0 时"作案"与"侦查"的收益不对称（压 0 单向动机）

- 作案不改变地点情报值；侦查一次性取走证据即结束。罪犯把地点压到 0 后**每次作案省 1 情报**（可累计多次）；警长把地点压到 0 后仅**单次侦查省 1 情报**。
- 压 0 对罪犯的价值 = "此后每次作案 −1 情报 × 作案次数"（多次复利）；对警长 = 一次性。
- **判定**：压 0 机制使罪犯获得系统性动态成本优势，这是 0 能力基准超模的首要驱动（见 §2.4 罪犯效率）。

#### 🟡 B2-2 高效抓捕与"证据不足补差"的收益叠加

- 高效抓捕（移动数 < 犯罪等级 → +1）鼓励"少证据抓捕"；补差（移动数 < 隐藏值 → 补情报）惩罚"少证据抓捕"。两条规则并存，使"1 证据抓高等级罪犯"成为警长最优（例：等级 3 隐藏 2，1 证据 → 花补差 1 情报得 3+1=4 分 ≈ 0.8 分/资源，优于 2 证据正常抓的 3 分）。
- **判定**：规则自身存在鼓励用最少证据的张力，但效率仍低于罪犯基线，列入 r04 抓捕链综合评估。

#### 🟡 B2-3 读报总消耗表述

- §6.1 读报未写明总消耗，建议补"总消耗 2 点行动力"（r01 已记录，此处不影响基准计算）。

### 1.3 第一部分结论

基础操作在"固定+动态"口径下无直接数值矛盾。**结构性风险**仍集中在 B2-1（压 0 单向动机）与 B2-2（高效+补差叠加），两者进入 r04 深入检查。

## 第二部分：0 特殊能力数值基准

### 2.0 起点状态声明

- 推演场景：标准 4 人局（1 警长 + 3 罪犯）、12 轮上限、目标 15 分；扩展阵营（英雄/受害者）基准按 5-7 人局专用规则单独评估（§2.3）。
- 0 能力：仅基础行动（§4.2），无角色技能、无策略牌、无地点特殊效果（r04 再逐项加入）。
- 复苏机制生效：每个情报值 0 的地点，傍晚 +1"情报 Token"（§5.2②）。
- 作案不改变地点情报值；只有调查降低（§3.3 机制前提）。
- 隐藏值初始 = 角色卡上限；补给阶段回复 +1（§4.6）；罪犯调查 −1。0 能力单侧推演不考虑警长抓捕，故隐藏值不影响得分节奏。
- 每回合供给 = 2 行动 + 1 手牌 = 3 IC；**行动序列严格 ≤ 2 行动/回合**（本推演修正了"单回合列出 3 行动"的流水账问题，见各账）。

### 2.1 罪犯单侧无干预流水账（等级 2 · 核心区）

**策略**：核心区 A（初始情报 3、影响值 2）压情报后连续作案（超额 +1）。行动代号：D = 调查（转换）、C = 作案（资源→IV）、B = 摸牌（转换）。

| 回合 | 行动序列 | 地点A情报(初→行后→傍晚) | 供给IC | 花费IC(仅资源→IV) | 情报余额 | 手牌余额 | 本回合IV |
| - | - | - | - | - | - | - | - |
| R1 | D、D | 3→1→1 | 3 | 0 | 2 | 1 | 0 |
| R2 | C | 1→1→1 | 3 | 2行动+1情=3 | 1 | 2 | 3 |
| R3 | C | 1→1→1 | 3 | 2行动+1情=3 | 0 | 3 | 3 |
| R4 | D、B | 1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| R5 | C | 1→1→1 | 3 | 2行动+1情=3 | 0 | 3 | 3 |
| R6 | D、B | 1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| R7 | C | 1→1→1 | 3 | 2行动+1情=3 | 0 | 3 | 3 |
| R8 | D、B | 1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| **审计行** | — | — | **24** | **12** | — | — | **12** |

- **起点**：情报 0、手牌 0（补给后 1）、A 情报 3；复苏生效。
- **备注**：R1 调查 2 次压至 1 并攒 2 情报；此后作案轮（C 占满 2 行动）与调查轮（D+B 压 0，傍晚复苏回 1）交替。
- **表内 IV**：作案 = 影响 2 + 超额 1 = 3 分/次。
- **效率**：资源效率 = 12/12 = **1.0 分/资源**；轮次效率 = 12/8 = **1.5 分/IR**。
- **可持续性**：R9 第 5 次作案后证据 5 枚满，需转型移动（推演 1b）。

#### 推演 1b：证据满 5 后的移动转型（R9-R12）

| 回合 | 行动序列 | 地点情报 | 供给IC | 花费IC | 情报余额 | 手牌 | IV |
| - | - | - | - | - | - | - | - |
| R9 | C | A:1 | 3 | 3 | 0 | 3 | 3 |
| R10 | D、B | A:1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |
| R11 | C(移动) | A:1 | 3 | 3 | 0 | 3 | 3 |
| R12 | D、B | A:1→0→1 | 3 | 0 | 1 | 3(弃1) | 0 |

- R9-R12 累计：供给 12、花费 6、IV 6。移动同样花目标地点当前情报值、同样得分（§6.3）。
- **累计 R1-R12**：供给 36、花费 18、累计 IV 18 → **资源效率 1.0 分/资源、轮次效率 1.5 分/IR**。
- **循环闭合性**：R1→R12 构成闭合循环（每次作案后调查压 0 + 傍晚复苏回 1，末状态与初可比），可持续至第 12 轮。

### 2.2 警长单侧无干预流水账（抓捕链）

**前提**：目标罪犯等级 2、隐藏值 3（初始上限）、其"证据 Token"位于核心区 A（情报 1）。警长需先调查攒情报 → 侦查取证 → 抓捕。行动代号：D = 调查、S = 侦查（前置）、A1 = 抓捕（资源→IV）、B = 摸牌。

| 回合 | 行动序列 | 花费IC(仅资源→IV) | 情报余额 | 手牌余额 | 本回合IV |
| - | - | - | - | - | - |
| R1 | D、D | 0 | 2 | 1 | 0 |
| R2 | S、B | 0（侦查花 1 情报，属前置） | 1 | 2 | 0 |
| R3 | D、D | 0 | 3 | 2 | 0 |
| R4 | A1 | 2行动+2情=4 | 1 | 2 | 3 |
| R5 | D、B | 0 | 2 | 3 | 0 |
| **审计行** | — | **4** | — | — | **3** |

- **抓捕结算**：证据 1 < 隐藏 3 → 差 2 → 补差 2 情报；移动数 1 < 犯罪等级 2 → 高效 +1；得分 = 2 + 1 = 3。
- **效率**：资源效率 = 3/4 = **0.75 分/资源**（含侦查前置则 3/6 ≈ 0.5）；轮次效率 = 3/5 = **0.6 分/IR**。
- **可持续性**：受证据可获得性约束；目标证据被回收/清空则链中断。

#### 抓捕链结构矛盾（B2-4）：无证据奖励与抓捕互斥

- 无证据奖励（黎明版图无任何证据/迷雾 → +2）与抓捕链（需警长先侦查取得证据）直接互斥。走抓捕路线必然破坏无证据奖励触发条件。
- 0 能力下 3 罪犯持续作案（单侧 1.5 分/IR），警长几乎无法达成"版图净空"，无证据奖励实际触发率低。
- **估（B2-5）**：警长 0 能力基准 ≈ 抓捕链 0.6 分/IR + 无证据奖励偶发（假设每 4 轮 1 次 → +0.5 分/IR）≈ **1.1 分/IR**，低于基准 1.17-1.25。警长侧结构依赖"无证据奖励"但该途径与抓捕互斥，为本轮核心量化风险之一。

### 2.3 扩展阵营 0 技能基准（第六轮新增）

> 英雄/受害者无"基础得分手段"（无作案/抓捕类独立资源得分循环），其专属行动即为基础路径。此处建立其 0 角色技能下的基准，验证补偿是否充足。

#### 受害者（追偿/爆料链）

| 路径 | 成本 | 收益 | 触发条件 | 效率估算 |
| - | - | - | - | - |
| 追偿 | 1 行动 + 2 情报（3 IC/次） | 黎明夺分：目标本轮得分 ≥2 → 其 −1、你 +1 | 4 人局中罪犯作案 3 分、警长抓捕 2-4 分，触发率高 | 理想 2 目标均达标：夺 2 分 → 0.67 分/资源；仅 1 达标：0.33 分/资源；周期约 2 轮（1 轮调查攒情报 + 1 轮追偿）→ 0.5-1.0 分/IR |
| 爆料 | 1 行动 + 2 情报（3 IC/次） | 2 地点作案花费 +1（本轮）+ 翻开阳面 +1 分 | 依赖他人选择该地点为行动目标（被动） | 基础收益为"间接压制"（加成本），可稳定得分的可能性低；轮次效率 ≈ 0.3-0.5 分/IR |

- **结论**：受害者 0 技能基准约 **0.33-0.67 分/资源、0.5-1.0 分/IR**，仅追偿理想（夺 2 分）时接近/略超设计基准。整体补偿依赖角色技能（艾登降门槛 + 连本带利、掮客阴面保底、艾米莉爆料强化）。
- **剥夺价值说明**：追偿含"扣他人分"（相对优势），按 §4.2 原则 3"得分收益 ≠ 剥夺收益"，此处仅计自身 +分，剥夺部分在 r04 不对称对比中另行评估。

#### 英雄（登场/制裁链）

| 路径 | 成本 | 收益 | 效率估算 |
| - | - | - | - |
| 登场 | 2 行动 + 地点当前情报值 | 1 分 + 放置英雄 Token（供技能） | 核心区情报 1：3 IC → 1 分 ≈ 0.33 分/资源；主要价值在 Token 状态而非得分 |
| 制裁 | 2 行动 +（地点情报 + 目标隐藏值） | 持有证据数（1、1+2、1+2+3…） | 首次制裁：6 IC → 1 分；连续 3 次（若能保留证据）：18 IC → 6 分 ≈ 0.33 分/资源 |

- **结论**：英雄 0 技能基准约 **0.33 分/资源、0.3-0.5 分/IR**，远低于设计基准。完全依赖角色技能（夜枭制裁减费、暗影情报+1、裁决者看守所得分）才有竞争力——属"无基础得分手段阵营靠特殊能力补偿"的设计意图，但**补偿缺口较大**，r03/r04 逐角色验证技能是否补足。

### 2.4 理性目标选择分析（罪犯 0 能力）

**首次成本 vs 稳态成本**（目标地点类型 × 犯罪等级）：

| 地点类型 | 初始情报 | 影响值 | 压0调查次数 | 首次作案成本 | 稳态每次作案成本 | 得分(等级2) | 稳态效率 |
| - | - | - | - | - | - | - | - |
| 下城 | 2 | 1 | 2 | 2D+2行动+2情 | 2行动+1情 | 1（等级2无超额） | 0.33 分/资源 |
| 核心 | 3 | 2 | 3 | 3D+2行动+1~3情 | 2行动+1情 | 3（含超额） | 1.0 分/资源 |
| 上城 | 4 | 3 | 4 | 4D+2行动+0~4情 | 2行动+0~1情 | 4（含超额） | 1.33~2.0 分/资源 |
| 博物馆 | 5 | 4 | 4~5 | 5D+2行动 | 2行动+0~1情 | 4（等级2无超额） | 1.33~2.0 分/资源 |

- **理性选择**：等级 2 → **核心区最优区间**（超额满足、压情报成本可接受、稳态 1.0 分/资源）；上城回报最高但准备周期长（4 次调查 + 风险高），适合中后期转入；下城因等级 2 无法超额仅作避险。
- **执行周期**：核心区首次作案 = 2 轮（R1 压 2 次 + R2 作案）；稳态 = 约每 2 轮作案 1 次（调查轮 + 作案轮交替）。**注意**：因作案占满 2 行动，罪犯在作案轮无法出普通策略牌（策略牌使用率受结构性压缩，呼应 r01 §6.1）。
- **等级跨档对比**：
  - 等级 1（老鼠）：任意地点超额（影响值 ≥1），下城也可 2 分/次 → 低风险梯度回报，可用下城做托底。
  - 等级 3：上城（影响 3）超额 +1 → 4 分/次；核心（影响 2）不超额 → 2 分/次，收益断层明显，理性强推上城。
  - 等级 4（疯子）：仅博物馆（影响 4）超额 +1 → 5 分/次；上城 4 分/次（不超额）。压 5 次调查成本极高 + 调查 −2 隐藏值（自身特性），高风险高回报成立，但**防御性极差**（r03 重点）。

### 2.5 基准对照汇总

| 对象 | 资源效率(分/资源) | 轮次效率(分/IR) | 偏离基准 0.39-0.42 / 1.17-1.25 |
| - | - | - | - |
| 罪犯无干预（等级2核心区） | 1.0 | 1.5 | 🔴 显著偏高（~2.4 倍） |
| 罪犯无干预（上城稳态） | 1.33-2.0 | ~2.7-3.3（折算） | 🔴 严重偏高 |
| 警长抓捕链 | 0.5-0.75 | 0.6 | 🟡 偏低 |
| 警长含偶发无证据奖励 | ~0.75 | ~1.1 | 🟡 略偏低 |
| 受害者 0 技能（追偿流） | 0.33-0.67 | 0.5-1.0 | 🟡 偏低（补偿型，设计意图） |

**如实报告**：0 能力下罪犯单侧无干预效率**远高于设计基准**（约 2.4 倍），主要驱动 = 核心区/上城高影响值 + 压 0 低情报成本（B2-1）+ 超额 +1 的叠加。此差值将部分由警长抑制量在 r04 扣除；若扣除后仍显著超基准，需在 r05 给出数值修正（调低影响值/超额、限制压 0 收益、或提高警长无证据奖励可达性等）。

## 第三部分：基准结论

1. **基础操作一致**：无直接数值矛盾；B2-1（压 0 单向动机）与 B2-2（高效+补差叠加）为结构性风险，r04 深入检查。
2. **罪犯 0 能力显著超模**（1.0-2.0 分/资源 vs 基准 0.39-0.42），核心驱动：压 0 动态成本优势 + 超额 +1 + 区域高影响值。
3. **警长 0 能力偏低**（0.6-1.1 分/IR vs 基准 1.17-1.25），结构依赖"无证据奖励"但与抓捕链互斥（B2-4）。
4. **扩展阵营 0 技能基准偏低**属设计意图，但英雄补偿缺口最大（0.33 分/资源），需 r03 逐技能核对是否补足。
5. **12 轮上限 vs 15 分**：罪犯无干预 12 轮可得 18 分 → 提前触发 15 分终局；12 轮上限仅在罪犯被有效抑制时才有意义。
6. 净平衡（罪犯无干预效率 − 警长抑制量）在 r04 完成；若无法抵消，r05 将给出数值修正方向。
