## 0. 评审口径与假设声明

### 0.1 基准设定（4 人局，0 特殊能力）

| 项 | 设定 |
| - | - |
| 人数 | 4 人（1 警长 + 3 罪犯） |
| 轮数 | 12 轮 |
| 单玩家供给 | 每轮 2 行动 + 1 手牌 = 3 资源 → 12 轮 36 资源 |
| 设计基准（§4.1） | 发挥极好 14-15 分；资源效率 ≈ 0.39-0.42 分/资源；轮次效率 ≈ 1.17-1.25 分/轮 |
| 地形假设 | 上城{商业街 4/3、市政厅 4/3、博物馆 5/4}；核心{老城区 3/2、废弃工厂 3/2、地下酒吧 3/2、港口区 4/3、红灯区 4/2、火车站 4/3}；下城{贫民窟 2/1、黑市 3/2、码头仓库 2/1} |
| 复苏机制 | 生效。每傍晚每区域"当前情报值最低的地点 +1（不超过初始情报值；并列最低全部放置）" |
| 他人行动 | 单人基准推演中，非本情景玩家对目标地点的行动视为中性（不额外压区），以便分离单机效率；真实 4 人局竞争在 r04 中纳入 |
| 作案不改变地点情报值 | 已确认（§3.3 机制前提）：只有"调查动作"降低情报，"作案/侦查"不改变 |
| 证据限制 | 5 枚证据 Token；第 6 次作案起为"移动"模式（本推演仅到第 5-6 次，注明） |

### 0.2 记账代号

- D = "调查动作"（资源转换：获得 1"情报 Token"+ 地点情报值 -1；罪犯隐藏值 -1）
- M = "摸牌动作"（资源转换：1 行动 → 1 手牌）
- C = "作案动作"（资源→IV：2 行动 + X 情报 → 分数）
- S = "侦查动作"（资源转换：1 行动 + 地点当前情报值 → 1"证据 Token"）
- A = "抓捕动作"（资源→IV：2 行动 + 补差情报 → 分数）
- 读报 = 1 行动 + 弃 1 手牌 → 1"情报 Token"（手牌→情报的资源转换）

### 0.3 调查双效（强制计入）

每个 D 同时计入：①获得 1"情报 Token"；②目标地点情报值 -1。单人推演中复苏（每轮傍晚 +1）与调查的交互**逐轮核算**，不一次性折算。

## 1. 基础操作投入产出一致性检查（r02 第一步）

> 规则：先检查规则书中各基础操作的投入产出关系是否一致，有矛盾的先在此标记，供 r05 修复。

### 1.1 作案动作的 IC 构成

- 投入 = 固定 2 行动 + 动态 X 情报（X = 目标地点当前情报值，§4.2/§6.3）
- 产出 = 影响值（1-4）+ 超额（若影响值 ≥ 犯罪等级）+1

**一致性检查**：

| 地点类型 | 初始情报 X | 投入 IC（固定+动态） | 产出分（影响+超额） | 单次分/IC（未压区） |
| - | - | - | - | - |
| 下城 1 值（贫民窟/码头） | 2 | 2+2=4 | 1（等级 2 无超额） | 0.25 |
| 下城 2 值（黑市） | 3 | 2+3=5 | 3（2+1） | 0.60 |
| 核心 2 值（老城区等） | 3 | 2+3=5 | 3（2+1） | 0.60 |
| 核心 3 值（港口/火车站） | 4 | 2+4=6 | 4（3+1） | 0.67 |
| 上城 3 值（商业街/市政厅） | 4 | 2+4=6 | 4（3+1） | 0.67 |
| 上城 4 值（博物馆） | 5 | 2+5=7 | 5（4+1） | 0.71 |

- **结论 a**：未压区直接作出案，单次分/IC 在 0.25-0.71 间；压区后（X→0~2）单次分/IC 可达 0.86-2.0（见 §2）。**同一动作的动态成本跨度达 2~7 资源，区间必须按曲线报告**（§2）。
- **结论 b**：下城 1 值地点（影响 1）对犯罪等级 ≥2 的罪犯**永无超额**，单次仅 1 分 —— 对等级 2+ 罪犯为"陷阱地点"，理性玩家回避（见 §8 目标选择）。此点与"下城区是安全收益区"的设计定位不矛盾但需确认（下城对等级 1 罪犯仍是超额区）。

### 1.2 抓捕动作的 IC 构成（含侦查前置链）

- 侦查前置：投入 = 1 行动 + 动态 Y 情报（Y = 地点当前情报值）；产出 = 1"证据 Token"（中间产出，不计 IV）
- 抓捕：投入 = 固定 2 行动 + 动态 Z 情报（Z = max(0, 隐藏值 − 证据数) × 2）；产出 = 犯罪等级分 + 高效 +1（若证据数 < 犯罪等级）

**一致性检查**（目标：等级 2、隐藏 2 的罪犯）：

| 链方案 | 前置 | 抓捕补差 | 总投入 IC | 产出 | 分/IC |
| - | - | - | - | - | - |
| 收 1 证据即抓 | 1 行动（转换）+ Y 情报 | 2 行动 + 2 情报 | 2+2=4 | 2+1=3 | 0.75 |
| 收 2 证据再抓 | 2 行动（转换）+ 2Y 情报 | 2 行动 + 0 情报 | 2 | 2+1=3 | 1.50 |

- **结论 c**：多收证据的抓捕链"资源效率"更高，但轮次更长（2 次侦查需 2 轮）。这与"证据不足用情报补差"的机制形成双路径权衡，机制合理。
- **结论 d**：抓捕链的 Y（侦查情报花费）依赖罪犯压区成果——**罪犯把地点情报打低的同时，警长侦查成本同步降低**。这是全局最强的跨方联动点，也是 §0.1"他人中性"假设下警长基准最受益的来源（见 §6）。

### 1.3 需先修复的数值/规则矛盾（承接 r01）

- **布控 +2 作用范围**（r01 1.1）：§4.2"情报值 +2（本轮有效）" vs §6.2"仅在计算侦查成本时生效"。两口径下布控对罪犯的抑制量完全不同，**r02 按以下双口径分别报告**：口径①布控只提侦查成本（抑制量 = 0 对罪犯作案）；口径②布控提升地点情报值（作案动态成本 +2）。最终裁定交 r05。
- **情报上限交互**（r01 1.2/1.3）：布控/设伏把情报抬到初始值以上时，复苏"不超过初始情报值"的边界未定义。r02 动态成本曲线按"布控叠加后不受复苏影响的上限外压"场景单独标注，具体裁定交 r05。

## 2. 动态成本曲线（强制区间，禁单点值）

### 2.1 作案动作的动态成本

作案投入 = **固定 2 行动 + 动态 X 情报**（X = 地点当前情报值）。

**X 随版图状态的变化区间**：

| 版图状态 | X | 作案总投入 IC | 产出（以等级 2 为例） | 单次分/IC |
| - | - | - | - | - |
| 上城 4 值初始（博物馆） | 5 | 7 | 5 | 0.71 |
| 上城 3 值初始（商业街等） | 4 | 6 | 4 | 0.67 |
| 核心/下城 2-3 值初始 | 3 | 5 | 3 | 0.60 |
| 压区后（复苏维持低位） | 1~2 | 3~4 | 3~4 | 0.86~1.33 |
| 压到底（复苏前瞬间） | 0 | 2 | 3~4 | 1.5~2.0 |

- **首次成本 vs 稳态成本**（强制区分）：
  - **首次成本** = 完整前置准备（把地点从初始情报压到可作案区间）。以老城区（初始 3）为例：需连续压区（D 的净效果 = −1/轮，因复苏 +1 抵消 1 次调查）→ 首次成本 = 2 轮压区（4 次 D）+ 1 次作案轮 ≈ **3-4 轮周期**完成第 1 次作案。
  - **稳态成本** = 前置完成后"每次作案"的投入 = 2 行动 + 1~2 情报 = **3~4 IC**（对比首次的 5~7 IC）。两者差异显著，必须分别列出（本表即首次/稳态对照的曲线口径）。
- **布控对作案动态成本的影响（双口径）**：
  - 口径①（仅侦查成本）：布控对作案 X 无影响 → 作案曲线不变。
  - 口径②（提升地点情报值）：目标地点作案 X +2 → **单次作案 IC +2**；若目标地点本已压到 0，布控使其回到 2 → 作案从"2 IC 得 4 分"退化为"4 IC 得 4 分"，抑制幅度达 50%。

### 2.2 侦查动作的动态成本

侦查投入 = **1 行动 + 动态 Y 情报**（Y = 地点当前情报值）。

| 版图状态 | Y | 侦查总投入 | 产出 |
| - | - | - | - |
| 未压区（初始 3-4） | 3-4 | 4-5 资源 | 1"证据 Token"（无 IV） |
| 罪犯压区后（1-2） | 1-2 | 2-3 资源 | 1"证据 Token" |
| 压到底（0） | 0 | 1 行动 | 1"证据 Token"（白嫖罪犯压区成果） |

- **首次 vs 稳态**：警长首次侦查（搭罪犯压区成果）Y=1-2；若罪犯中途换点，警长需重新压区，Y 回升至 3-4。**警长侦查成本与罪犯作案地点高度耦合**。

### 2.3 抓捕的动态成本

抓捕投入 = **固定 2 行动 + 动态 Z 情报**（Z = max(0, 隐藏值 − 当前证据数) × 2）。

| 罪犯隐藏值 | 警长持证据数 | Z | 抓捕总投入 IC | 产出（等级 2） |
| - | - | - | - | - |
| 0（被压区打到 0） | 1 | 0 | 2 | 3（2+高效 1） |
| 2 | 1 | 2 | 4 | 3 |
| 2 | 2 | 0 | 2 | 3 |
| 4（幽灵上限） | 1 | 6 | 8 | 3 |

- **隐藏值从 0→4，抓捕 Z 从 0→8**：区间跨度极大，**隐藏值是最强动态成本变量**。这也是罪犯压区（隐藏-1/次调查）的核心风险：**压区提升得分效率的同时把隐藏打到 0，使警长抓捕成本降至最低**。

- 累计真花费 IC = 21（6 次作案 × (2 行动 + 平均 1.5 情报)）

- 累计 IV = 18

### 3.2 效率与判定

| 指标 | 值 | 设计基准 | 偏差 |
| - | - | - | - |
| 轮次效率 IV/IR | 18 / 12 = **1.50 分/轮** | 1.17-1.25 | **+20%~+28% 超模** |
| 资源效率 IV/IC | 18 / 21 = **0.86 分/资源** | 0.39-0.42 | 超模（口径注：IC 分母不含调查转换，见 §0.2） |
| 总资源视角 | 18 / 36 = 0.50 分/资源（若把闲置手牌计入） | 0.39-0.42 | +19% |

- **周期与闭合**：R1-R4 首次（压区 2 轮 + 作案 2 轮），R5-R8 / R9-R12 为稳态重复。**从"老城区 3 满"到"老城区 3 满"构成闭合循环**；循环末情报/手牌可比（情报因压区调查净增 3，属盈余）。
- **可持续性**：可连续执行 12 轮；依赖条件：①老城区保持为核心区最低被复苏回填（若他罪犯也压低更多地点，回填更快，动态成本更低）；②证据 5 枚限制——**第 6 次作案起转为"移动"模式**（12 轮内 6 次作案恰好触发第 6 次移动，目标地点若回到影响 2+ 区域仍得 3 分）。
- **隐藏值追踪**：12 次 D → 隐藏 3 → 0（第 3 次调查后已为 0）。**单机推演无警长，隐藏值 0 不影响得分；但在真实 4 人局中此状态使警长抓捕补差 Z=0，是罪犯被压制的最大风险敞口**（§6 抑制量）。
- **定位**：这是 0 能力罪犯的"标准最优节奏"之一。首次 4 轮 3 分（0.75 分/轮）→ 稳态 2 轮周期 3 分（1.5 分/轮），属"前期低效、中后期冲分"曲线。

## 6. 警长基准 · 情景 4：侦查→抓捕链 + 无证据奖励 + 抑制量

### 6.1 警长自身双效率（0 能力）

> 目标：等级 2 罪犯（基准设其隐藏已被压区行为打到 2）；地点：老城区（情报 1-2 的压区态，搭罪犯压区成果）。
> 起点：老城区状态随罪犯压区；警长情报 0；手牌 1。

**审计行**：累计供给 36；累计真花费 IC = 12（3 次抓捕）；情报净 +3；累计 IV = 9（抓捕）+ 无证据奖励 0~4（见下）。

### 6.2 警长效率判定

| 指标 | 值 | 基准 | 偏差 |
| - | - | - | - |
| 轮次效率 | 9~13 / 12 = **0.75~1.08 分/轮** | 1.17-1.25 | **低于基准 -8%~-40%** |
| 资源效率 | 9 / 12 = 0.75 分/资源 | 0.39-0.42 | 高于基准（口径注：侦查转换不计 IC） |
| 总资源视角 | 9~13 / 36 = 0.25-0.36 分/资源 | 0.39-0.42 | 低于基准 |

- **无证据奖励（黎明版图无证据 +1）**：基准中其他 2 罪犯持续作案 → 版图几乎总有证据，奖励**多数轮不触发**。仅当警长清场且罪犯都被压制时触发。诚实估算 **0~4 分/12 轮**（计入区间）。
- **执行周期**：一次抓捕链 = 2 轮压区 + 1 轮侦查 + 1 轮抓捕 = **4 轮周期**，得 3 分。
- **最优增量路径**：搭罪犯压区成果（Y=1）比自行压区省 2-4 情报/链。**警长的最优策略是"等罪犯压区，再低成本收割"**——这使 4 人局中警长与罪犯形成天然的攻防节奏。

### 6.3 警长对罪犯的抑制量（跨方抑制，强制）

> 按 `04-量化审查规则.md` §3.5：警长量化必须含"自身双效率 + 对被压制方的抑制量"。

| 手段 | 机制 | 对罪犯的影响（量化口径） |
| - | - | - |
| 布控 +2 情报 | 口径①：仅侦查成本 → 对罪犯作案无影响 | 抑制量 0 |
| | 口径②：提升地点情报值 → 罪犯作案情报花费 +2 | 单次作案 IC 3~4 → 5~6（**-33%~-50% 作案效率**） |
| 侦查（取走证据） | 减少罪犯持有证据 | 打断 5 枚封顶循环；迫使中途移动或转移（每打断 1 次 ≈ 损失 1 次移动得分，3 分/3 轮） |
| 抓捕（入狱） | 罪犯入狱 2 轮（等级 2：格 2 → 2 个黎明后释放） | 罪犯损失 2 轮作案 ≈ 2 × 1.5 分/轮 = **3 分/次**；且出狱后需重新压区（再 +1 轮 ≈ +1.5 分）→ 合计 **≈ 4.5 分/次** |

**净平衡核算（单罪犯视角，4 人局）**：

- 罪犯无干预效率（情景 1/3）≈ 18 分/12 轮
- 警长抑制量（按 12 轮内对该罪犯 2 次抓捕 + 3 次侦查打断）≈ 2×4.5 + 3×打断 0.5 ≈ 9~11 分
- **净平衡 = 18 − 9~11 = 7~9 分/12 轮 → 显著低于设计基准 14-15 分**
- **判定**：单看"1 警长 vs 1 罪犯"，警长抑制足以把罪犯压到基准以下；但 4 人局有 3 名罪犯，警长抑制被三分摊 → 每罪犯净抑制 ≈ 3~4 分 → 净得分 ≈ 14~15 分，**恰好落回基准**。**平衡的实现高度依赖"警长抑制的时间分配"与"罪犯间的竞争"，这是 r04 综合计算的核心验证点**。

## 8. 理性选择下玩家优先选择的目标

### 8.1 罪犯侧目标排序（0 能力、等级 2）

| 优先级 | 目标 | 理由 | 风险 |
| - | - | - | - |
| 1 | 下城黑市 / 核心低值 2 值地点 | 影响 2 + 超额 ✓；复苏回填节奏可控；单次 3 分/3-4 IC | 与 1-2 名罪犯竞争；隐藏暴露 |
| 2 | 上城商业街/市政厅、核心港口/火车站（影响 3） | 单次 4 分最高 | 复苏回填到高位、竞争激烈、证据堆叠被警长集中收割 |
| 3 | 下城 1 值地点 | 影响 1 无超额（等级 2），单次仅 1 分 | 陷阱地点，理性回避 |
| 4 | 博物馆（影响 4） | 单次 5 分极限 | 初始情报 5 压区成本最高；复苏回填到 5；仅等级 4 罪犯超额 |

**等级差异修正**：等级 1 罪犯在所有地点超额 ✓（下城 1 值也可超额得 2 分）→ 等级 1 的最优目标扩大到全部区域；等级 3/4 罪犯仅上城/博物馆超额，被迫走高风险区（"高等级高回报高风险"成立）。

### 8.2 警长侧目标排序（0 能力）

| 优先级 | 目标 | 理由 |
| - | - | - |
| 1 | 罪犯正在压区/已压区的地点 | 借用罪犯压区成果，侦查 Y=1-2 低成本收割 |
| 2 | 隐藏值已降到 0 的活跃罪犯 | 抓捕补差 Z=0，最高效 |
| 3 | 证据堆叠 2+ 枚的罪犯 | 一次抓捕多证据入狱；高效奖励门槛低 |

**警长最优打法 = 追踪罪犯压区轨迹，在罪犯"即将连续作案"前完成侦查，在证据堆叠后抓捕。** 这与 §6.2 的"等罪犯压区再收割"结论一致。
