# r02 · 量化基准：0 特殊能力数值基准（第七轮）

> 评审目标：建立 0 特殊能力（无角色技能、无策略牌）下的基础数值基准，作为 r03/r04 的锚。
> 评审基准：4 人局（1 警长 + 3 罪犯）、12 轮上限、15 分终局线。
> 依据：`progress-5/04-量化审查规则.md` §2 基本单位、§3 方法论、§4.1 主基准。
> 本评审独立推演，不参考历史评审记录；参考锚仅作偏差解释，不预设结论。

---

## 〇、核心口径声明（先理解核心规则）

- **KSA 行动占用**（§2.4）：作案 = 2 行动（独占型，1 次 = 1 执行轮）；抓捕 = 2 行动（独占型）；追偿/爆料 = 1 行动（轻量型，不占满回合）。
- **调查双效**：1 行动 → 获得 1 情报 + 该地点情报值 -1。两个效应同时计入（§3.1）。
- **作案不改变地点情报值**；只有调查降低，复苏提高（§3.3）。
- **复苏规则**：傍晚阶段对情报值为 0 的地点 +1 情报 → 压 0 无法长期维持，稳态作案情报花费 ≥ 1。
- **主基准**：15 分终局线；KSA 次数 4-6 次；全周期 8-12 轮（§4.1）。
- 本基准为 0 能力、无策略牌、无布控/隐藏等状态性干预的"理想节奏"，干扰影响在 r03/r04 加入。

## 一、基础操作投入产出一致性检查

### 1.1 核心转换操作

| 操作 | 投入 | 产出 | 一致性 |
| - | - | - | - |
| 调查 | 1 行动 | 1 情报 + 地点情报 -1 | ✓ 转换，不产分 |
| 摸牌 | 1 行动 | 1 手牌 | ✓ 转换 |
| 读报 | 1 行动 + 弃 1 手牌 | 1 情报（供应堆） | ✓ 比调查多弃牌，换取不降隐藏/不耗版图（看守所保底，§4.2 原则 5） |
| 布控 | 1 行动（或免费） | 目标地点"其它角色计算情报值 +2"（本轮） | ✓ 状态性 |
| 隐藏 | 1 行动 | 隐藏值 +1 | ✓ 状态性 |

**检查结论**：基础操作投入产出自洽，无矛盾。读报效率（1 行动 + 1 牌 → 1 情报）低于调查（1 行动 → 1 情报 + 压点），符合"看守所保底刻意低效"的设计（原则 5）。

### 1.2 首发投入 vs 稳态成本

为便于后续基准，先定义罪犯作案与警长抓捕的**首发成本**与**稳态成本**：

| 路线 | 首发成本（首次执行前） | 稳态成本（首发后每次） |
| - | - | - |
| 罪犯作案（核心区影响 2，初始情报 3） | 压点调查 ×2（1 轮）→ 情报 3→1 | 每 2 轮 1 次（1 调查轮 + 1 执行轮），作案情报费 1 |
| 警长抓捕（等级 2，隐藏 2） | 0（依赖罪犯先作案产生版图证据） | 侦查 1 行动 + 抓捕 2 行动，情报费 = 侦查地点情报 + 补差 |

## 二、罪犯基准（0 能力，4 人局）

### 2.1 单次作案得分（无技能、无匹配失败场景）

| 区域 | 影响值 | 等级 1 匹配 | 等级 2 匹配 | 等级 3 匹配 | 等级 4 匹配 |
| - | - | - | - | - | - |
| 下城（影响 1，情报 2） | 1 | ✓ +1 = 2 分 | ✓ +1 = 2 分 | ✗ = 1 分 | ✗ = 1 分 |
| 核心（影响 2，情报 3~4） | 2 | ✓ +1 = 3 分 | ✓ +1 = 3 分 | ✓ +1 = 3 分 | ✗ = 2 分 |
| 核心高值（影响 3，情报 4） | 3 | ✗ = 3 分 | ✓ +1 = 4 分 | ✗ = 3 分 | ✓ +1 = 4 分 |
| 上城（影响 3~4，情报 4~5） | 3~4 | ✗ = 3 分 | ✓(影响3) = 4 分；✗(影响4) = 4 分 | ✓ +1 = 4~5 分 | ✓ +1 = 4~5 分 |

> 等级匹配条件见规则书 §4.7（相差 ≤ 1）。上城影响值 3 的 3 张的匹配面：等级 2 只匹配影响 3（不匹配 4）；等级 3/4 匹配 3、4。

### 2.2 主路线推演：等级 2 罪犯 · 核心区（影响 2，初始情报 3）

**场景声明**：目标地点核心区影响值 2、初始情报 3；罪犯等级 2、隐藏值上限 2；无复苏以外的版图供给；无技能/无牌/无警长干预。

**逐回合流水账**（D = 调查，C = 作案，M = 摸牌）：

| 回合 | 行动序列 | 地点情报(行前→行后→傍晚) | 供给 IC | 行动占用 | 动态花费 IC | 情报余额 | 手牌 | 本回合 IV |
| - | - | - | - | - | - | - | - | - | - |
| R1 | D, D | 3→1→1 | 3 | 0 | 0 | 2 | 1 | 0 |
| R2 | D, M | 1→0→1 | 3 | 0 | 0 | 3 | 2 | 0 |
| R3 | C(作案) | 1→1→1 | 3 | 2 | 1 | 2 | 3 | 3（影响 2 + 匹配 1） |
| R4 | D, M | 1→0→1 | 3 | 0 | 0 | 3 | 4→修整弃至 3 | 0 |
| R5 | C | 1→1→1 | 3 | 2 | 1 | 2 | 4→3 | 3 |
| R6 | D, M | 1→0→1 | 3 | 0 | 0 | 3 | 4→3 | 0 |
| R7 | C | 1→1→1 | 3 | 2 | 1 | 2 | 4→3 | 3 |
| R8 | D, M | 1→0→1 | 3 | 0 | 0 | 3 | 4→3 | 0 |
| R9 | C | 1→1→1 | 3 | 2 | 1 | 2 | 4→3 | 3 |

> 说明：R2 调查把地点压到 0，R3 前傍晚复苏回 1 → R3 作案情报费 1。此后每轮傍晚"情报 1"不复苏，作案前无需再压点（作案不耗地点情报），故 R4、R6、R8 的调查是**本轮无 C 时的行动填充**（马点不再下降，唯一作用是攒情报+摸牌）。

**累计（R1-R9）**：IV = 12 分（4 次作案 × 3 分）；KSA 完整成本 = 4 次 ×（2 行动 + 1 情报）= 8 行动 + 4 情报 = 12 IC；行动去向 = 8 次 C + 5 次 D + 4 次 M（R1-R9 共 18 行动位，C8+D5+M4=17，余 1 空过）。资源效率 = 12/12 = **1.00 分/IC**（含行动）。

**KSA 节奏审计**：

- 共 4 次 KSA；执行轮 4（独占 1 轮/次）；准备轮 1（R1 压点）；干扰轮 0；**总周期 5 轮 → 尚未到 15 分**
- 第 5 次作案（R11）后 IV = 15 分：总周期 = 准备 1 + 执行 5 + 调查填充轮 4 = **10 轮**
- 判：**10 轮落在 8-12 主基准内** ✓

**可续性**：R9 后情报余额 2 → R10 D+M（+1，余额 3）→ R11 C（-1，=2）…… 循环可持续。若中途被布控（+2 情报费）、被抓捕，节奏被拉长，见 r03。

### 2.3 等级 1 罪犯主路线（下城影响 1，初始情报 2）

**场景声明**：下城区影响值 1、初始情报 2；等级 1、隐藏上限 1。匹配 ✓（影响 1 与等级 1 差 0）。

| 回合 | 行动序列 | 地点情报(行前→行后→傍晚) | 动态花费 IC | 情报余额 | IV |
| - | - | - | - | - | - |
| R1 | D, D | 2→0→1 | 0 | 2 | 0 |
| R2 | D, M | 1→0→1 | 0 | 3 | 0 |
| R3 | C | 1→1→1 | 1 | 2 | 2（1+匹配1） |
| ... | 每 2 轮 1 次 C，节奏同 2.2 | | | | 2 分/次 |

**推算**：单次 2 分 → 15 分需 8 次作案（2×8=16 超线，7 次=14 未到，必须 8 次）。周期 = 准备 1 + 执行 8 + 填充轮 ≈ **17+ 轮** → **远超 12 轮** ✗。

> ⚠️ 等级 1 罪犯（老鼠）0 能力下**无法在 12 轮内达到 15 分**。但其隐藏上限 1（易被抓也易防抓）…… 需注意：等级 1 单次得分 2 分，8 次作战才达标，12 轮内最多执行 ~5-6 次（独占型每 2 轮 1 次）。**等级 1 无技能无法触发终局，必须依赖技能（老鼠无直接得分技能）或改走核心区**（影响 2 也匹配，单次 3 分）。
>
> **修正路线**：老鼠（等级 1）应优先核心区影响 2 作案（匹配 ✓，单次 3 分），与等级 2 同节奏 → 10 轮达标。下城区是保底/避难，非主路线。此结论符合设计（低等级靠"更高的匹配自由度"而非"单次高分"）。

**结论**：等级 1 主路线 = 核心区影响 2（单次 3 分，节奏同等级 2，10 轮达标）。下城为避难/过渡。

### 2.4 等级 3 / 等级 4 主路线（上城影响 3~4，初始情报 4~5）

**场景声明**：上城区影响值 3、初始情报 4；等级 3、隐藏上限 3。匹配 ✓（影响 3 与等级 3 差 0）。

| 回合 | 行动序列 | 地点情报(行前→行后→傍晚) | 动态花费 IC | 情报余额 | IV |
| - | - | - | - | - | - |
| R1 | D, D | 4→2→2 | 0 | 2 | 0 |
| R2 | D, D | 2→0→1 | 0 | 4 | 0 |
| R3 | C | 1→1→1 | 1 | 3 | 4（3+匹配1） |

**推算**：单次 4 分 → 15 分需 4 次作案（4×4=16 超线，3 次 = 12 未到，必须 4 次）。周期 = 准备 2（压 4→1）+ 执行 4 + 填充轮 3 ≈ **9 轮** → 落在 8-12 区间 ✓（前段）。但上城情报高（4-5），压点准备轮长（2 轮），且暴露在警长布控高成本下（上城布控后作案情报费 +2 达 3），防御压力大。**风险调整后总周期预计 10-12 轮**，仍在区间内。

**等级 4（影响 3~4，初始情报 4~5，隐藏上限 2）**：隐藏上限 2 需 2 证据即满足补差 0，但上城情报高 → 压点链（2 轮）+ 暴露高。单次 4~5 分（影响 3 或 4 + 匹配），4 次达标。**周期约 9-12 轮**，与等级 3 接近，但防御最弱（易被补差：等级 4 抓捕分 4，高效 +1 = 5 分，警长抓疯子的收益最大）。

### 2.5 罪犯基准汇总

| 等级 | 主路线 | 单次 IV | 达标次数 | 理想周期 | 主基准判定 |
| - | - | - | - | - | - |
| 1 | 核心影响 2 | 3 | 5 | ~10 轮 | ✓（但依赖匹配不失误） |
| 2 | 核心影响 2 | 3 | 5 | 10 轮 | ✓ |
| 3 | 上城影响 3 | 4 | 4 | 9~12 轮 | ✓ |
| 4 | 上城影响 3~4 | 4~5 | 4（3 次 12 未到） | 9~12 轮 | ✓（边缘） |

**理性选择分析**：0 能力下等级 2 罪犯主攻核心区（效率 1.00 分/IC）、等级 3/4 主攻上城（单次 4~5 分但准备长）。下城区对等级 1-2 是托底（单次 2 分效率 0.67 分/IC，显著低于核心），**非最优但安全**——符合"下城安全但低收益"的区域意图。

## 三、警长基准（0 能力，4 人局）

### 3.1 单次抓捕得分

| 目标 | 犯罪等级分 | 高效+1（持证数 < 等级） | 合计 |
| - | - | - | - |
| 等级 1 | 1 | ✓（1 证 < 1？否，需 0 证？——高效判定：移动证数 < 等级） | 1 分；若 0 证不能抓（需 ≥1 证）→ 高效一般不可触发 |
| 等级 2 | 2 | ✓（1 证 < 2） | 3 分 |
| 等级 3 | 3 | ✓（1~2 证 < 3） | 4 分（1~2 证时） |
| 等级 4 | 4 | ✓（1~3 证 < 4） | 5 分（1~3 证时） |

> 等级 1 目标：高效条件"移动证数 < 1"——但抓捕需 ≥1 证，1 证 = 等级 1，不触发高效。即**抓等级 1 罪犯固定 1 分，无高效**。抓等级 2+ 才常见高效 +1。

### 3.2 主路线推演：抓捕等级 2 罪犯（隐藏 2，持 1 证）

**场景声明**：目标罪犯已在核心区作案（版图有证据）；作案点被罪犯自行压到情报 1；隐藏值 2；警长无技能。

**侦查**：花费 = 地点当前情报值 1 情报 → 获得 1 证据。
**抓捕**：2 行动；持 1 证 < 隐藏 2 → 补差 1 情报；得 2（等级）+ 1（高效）= 3 分。

**逐回合流水账**（S = 侦查，A = 抓捕，D = 调查，M = 摸牌；假设 R1-R2 罪犯作案、R3 起版图有证据）：

| 回合 | 行动序列 | 动态花费 IC | 情报余额(起始按储蓄计) | 手牌 | 本回合 IV |
| - | - | - | - | - | - |
| R1（罪犯已作案，无行动压力） | D, D | 0 | 2 | 1 | 0 |
| R2 | S(1情报), M | 1 | 1 | 2 | 0 |
| R3 | A(抓捕, 2行动+1补差) | 1 | 0 | 3 | 3 |
| R4 | D, D | 0 | 2 | 4→3 | 0 |
| R5 | S, M | 1 | 1 | 4→3 | 0 |
| R6 | A | 1 | 0 | 4→3 | 3 |

**累计（R1-R6）**：IV = 6 分（2 次抓捕 ×3）；KSA 成本 = 2 ×（2 行动 + 侦查 1 情报 + 补差 1 情报）= 4 行动 + 4 情报 = 8 IC；行动去向 = 2×A + 2×S + 4×D + 2×M = 12 行动位。资源效率 = 6/8 = **0.75 分/IC**（表面分）。

**含金量加权**（§3.6）：抓捕为得分+剥夺型，等级 2 目标加权 ~1.33 → 加权 IV = 6 × 1.33 ≈ **8.0 加权分**，加权效率 ≈ 1.00 加权分/IC。

**KSA 节奏审计**：

- 每次抓捕：侦查轮（S+M 或 S+D）+ 抓捕轮（A）= 2 轮/次
- 5 次抓捕 × 2 = 10 轮执行；另加前期和平（独立推演见 3.4）
- 15 分：5 次抓捕表面分 15 → 周期 ≈ 10 轮 + 初始攒情报轮 1 = **11 轮**；若 4 次抓捕（12 表面分）+ 和平 2~3 = 14~15 分 → 周期 = 8 执行轮 + 攒情报 ≈ **9-10 轮**
- 判：**9-11 轮落在 8-12 主基准内** ✓（边缘偏紧）

**可续性**：抓捕依赖版图证据（罪犯作案产生）。若 3 罪犯中仅 1-2 人作案，警长目标充足；若罪犯集体避战（不作案），警长无目标可抓 → 只能和平奖励 + 布控施压。**警长的得分节奏绑定罪犯的行动频率**，这是非对称设计的固有特征。

### 3.3 和平奖励触发率（独立推演）

**推演 4 人局（1 警长 + 3 罪犯）每黎明"版图无证据/迷雾"的概率**：

- R1 黎明：罪犯 R1 是否作案？罪犯最优策略是尽量早作案（得分），但 R1 无情报（初始 1 牌 0 情报），需先调查攒情报。**R1 罪犯全体的最优为调查+摸牌（不作战）** → R1 黎明无证据 → 和平 +1 ✓
- R2 黎明：罪犯 R1 已攒 2-3 情报，R2 是否作案？R2 作案 = 3 分（核心区，匹配），收益高 → **至少 1 名罪犯 R2 作案** → R2 黎明版图有证据 → 和平停止

> 保守推演：和平奖励约 **R1、R2 两次**（罪犯最迟 R3 开始作案）。若罪犯 R1 即可作案（若有快速情报/情报报告牌），R2 黎明即停 → 和平 1 次。

**结论**：4 人局 0 能力下，和平奖励独立推演 ≈ **1~2 分**（参考锚 2-3 分，量化略低于锚 —— 因 3 罪犯竞争下作案动机强，和平窗口短）。**和平奖励不能作为警长主要得分来源**，警长主要靠抓捕。

### 3.4 警长基准汇总

| 路线 | 单次 IV | 达标组合 | 周期 | 主基准判定 |
| - | - | - | - | - |
| 抓捕等级 2（主路线） | 3 表面 / ~4 加权 | 5 次抓捕 或 4 次抓捕 + 和平 2 | 9~11 轮 | ✓（边缘） |
| 抓捕等级 3 | 4 表面 / ~5.3 加权 | 4 次（16 表面） | 8~10 轮 | ✓ |
| 和平奖励（辅） | 1/黎明 | 前期 1~2 次 | — | 补充 |

**理性选择**：警长优先抓等级 3+ 目标（单次 4 分）或等级 2 高效（3 分）；抓等级 1 固定 1 分无高效，除非为了压制老鼠的作案节奏，否则效率低。**警长应与罪犯等级分布匹配**：3 罪犯中等级高者优先被针对。

## 四、双阵营对比（0 能力主基准判定）

| 阵营 | 0 能力达标组合 | 加权口径 | 周期 | 判定 |
| - | - | - | - | - |
| 罪犯（等级 2 主路线） | 5 次作案 ×3 分 | 纯得分 1.0 | 10 轮 | ✓ 主基准内 |
| 罪犯（等级 3-4） | 4 次 ×4 分 | 纯得分 1.0 | 9~12 轮 | ✓ 边缘 |
| 警长 | 4-5 次抓捕 + 和平 1~2 | 得分+剥夺 ~1.33 | 9~11 轮 | ✓ 边缘 |

**结论**：0 能力下双方理想节奏都在 8-12 轮主基准内，但**都偏紧**（10 轮附近）：

- 罪犯 10 轮 = 理想无干扰；一旦警长布控（+2 情报费）或抓捕（损失执行轮），很容易被拉到 12 轮以上
- 警长 9-11 轮 = 依赖罪犯作案频率与目标集中；若罪犯分散/避战，警长得分断档
- **关键敏感点**：① 布控对罪犯作案成本的抬升；② 抓捕对罪犯执行轮的剥夺；③ 和平奖励窗口极短（1-2 分），警长补分能力弱

### 敏感性分析（§3.8）

| 变量 | 基准 | 变化 | 对完整成本的影响 |
| - | - | - | - |
| 布控 +2 情报 | 作案情报费 1 | 1 → 3 | 动态花费 +2 → 罪犯需要额外 1 个调查轮/次 → 周期 +2~4 轮，可能出界 |
| 高效抓捕补差 | 1 证抓隐藏 2 | 差 1 补 1 | 警长每次 +1 情报 → 需提前攒情报，抓捕周期 +0.5~1 轮 |
| 复苏回填 | 压 0 后回 1 | 作案费稳定 1 | 罪犯稳态可续；若无复苏（压 0 永 0），罪犯每 2 轮省 2 情报，周期大幅缩短 → **复苏是控制罪犯节奏的关键机制** |
| 3 罪犯集中同点 | 1 人压点 | 多人共享压 0 成果 | 地点情报 1 → 3 罪犯轮流作案成本都低 → 警长如不布控，罪犯方总作案频率 ×3 → 需要跨方抑制（r03） |

---

## 五、r02 结论摘要

1. **0 能力主基准通过**：罪犯（等级 2）10 轮、等级 3-4 罪犯 9-12 轮、警长 9-11 轮，均落在 8-12 轮区间，但**全部偏紧**（都在区间上部/边缘）。
2. **和平奖励窗口极短（1-2 分）**，低于参考锚 2-3 分；警长补分能力弱，对抓捕节奏依赖度高。
3. **等级 1 罪犯无法靠下城区达标**（单次 2 分效率低），必须走核心区影响 2；下城区仅为避难地。
4. **布控是最有效的跨方抑制**（+2 情报费），单次布控可使罪犯作案成本翻倍（1→3）；复苏机制是罪犯稳态的基石。
5. 主基准建立完毕，r03 将在此基础上叠加角色技能、地点效果、策略牌，并输出"设计审查"。

> 参考锚对照：罪犯 8-12 轮 ✓（量化 10 轮）、警长 8-11 轮 ✓（量化 9-11 轮）、和平 2-3 分 ⚠️（量化 1-2 分，偏低——偏差如实报告，由设计师裁决是否通过"警长更多抓捕"补偿）。
