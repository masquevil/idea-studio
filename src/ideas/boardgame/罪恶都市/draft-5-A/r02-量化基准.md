### 0.1 复苏机制的关键解读（r02 全部结论的基石）

- 复苏每区域只回填"**最低**"地点；最低点若并列则**全部回填**
- 推论 A：**单人压单点无效**——某点被调查降至区域最低，下一轮傍晚必然被复苏拉回（除非有其他点垫底更低）
- 推论 B：**多人压多点内卷**——两个点并列区域最低，复苏对两点各 +1，双倍回填
- 推论 C：罪犯想压低作案成本，必须**构造"单点最低 + 其余点较高"的非对称格局**，但最低点唯一 → 3 罪犯互相竞争唯一低点
- 推论 D：唯一例外是**版图整体干涸**（多点多 = 0 并列最低，复苏分散），此时所有点作案成本趋近 0——但这是"3 罪犯集体压低全局"的宏观结果

> ⚠️ 该机制导致"打空某点作案"的**首次成本极高**（见 §2.2），且**多人共享低点被结构禁止**（见 §2.4）。这是本轮最重要的机制发现。

## 2. 罪犯 0 技能基准

### 2.1 直接作案（不专门维持低点）

**成本拆分（首次 & 稳态）**：

| 项目 | 值 | 性质 |
| - | - | - |
| 固定成本 | 2 行动（作案） | 固定 |
| 动态成本·情报 | 地点当前情报值 I（初始 2~5，受全员调查影响） | 动态，区间 [0, I₀] |
| 动态成本·调查前置 | 调查次数 n（把情报降下来需要的前置投入） | 动态，见 2.2 |

**动态成本曲线**：作案情报花费 I 随版图调查总量变化，区间 **0 ~ 初始情报值**：

- 前期（版图情报富余）：I ≈ 2~4（直接全价作案）
- 中期（罪犯压点后）：I ≈ 1~2（单点最低，逐轮被复苏回拉）
- 后期（版图整体干涸）：I ≈ 0~1（多最低点复苏分散）

**直接作案效率（前期，等级 2，核心点 I=2 预估）**：

| 场景 | 单次作案 IV | 真花费 IC | 轮次消耗 |
| - | - | - | - |
| 核心点全价（I=3） | 2+1=3 | 3 情报 | 2 行动（½ 轮）+ 情报积累前置 |
| 核心点半价（I=2） | 3 | 2 情报 | ½ 轮行动 |
| 核心点打空（I=0~1） | 3 | 0~1 情报 | ½ 轮行动 + 前置压点轮 |

> 直接作案的"真花费效率"虚高（3 分/2-3 情报 = 1~1.5），**因为它没有计入前置调查投入的轮次**。如实口径必须看完整周期（§2.2）。

### 2.2 打空作案（完整周期，0 技能，等级 2，核心点 X 初始 3）

**逐回合流水账**（起点：X=3，罪犯隐藏=上限 3；复苏生效；假设 X 为核心区唯一最低点）：

| 回合 | 行动序列 | X 情报值(初→行后→傍晚) | 供给 IC | 花费 IC | 情报余额 | 本回合 IV |
| - | - | - | - | - | - | - |
| R1 | 调查 X（3→2，获 1 情）；调查 X（2→1，获 1 情） | 3→1→(只 X 最低)2 | 3 | 0（均为转换） | 2 | 0 |
| R2 | 调查 X（2→1）；调查 X（1→0） | 2→0→(最低)1 | 3 | 0 | 4 | 0 |
| R3 | 作案 X（花费 1 情 → 2 行动）；摸牌 | 1→1 | 3 | 1 | 3 | 3（影响 2 + 超额 1） |
| R4 | 调查 X（1→0）；调查 X（0 无效→ 摸牌）* | 1→0→(最低)1 | 3 | 0 | 4 | 0 |
| R5 | 作案 X（花费 1 情 → 2 行动）；摸牌 | 1→1 | 3 | 1 | 3 | 3 |

*R4 副行动：调查 X 至 0 后无情报可捞，改摸牌（若版图其他点情报 >0 可调查，本例简化）。

**审计行（R1~R5 完整周期）**：

| 累计供给 | 累计真花费 | 累计结余 | 累计 IV |
| - | - | - | - |
| 15 | 2 情报 | 3 | 6 |

**结论（双维度 + 可持续性）**：

- **首次成本（R1~R3，第一次作案）**：3 轮 / 6 行动/轮资源 / 真花费 1 情报 → IV=3
  - 真花费效率 = 3 / 1 = 3.0（口径虚高，见 §1 说明）
  - **全局效率 = 3 / (3 轮 × 3 资源) = 0.33 分/资源**（低于基准 0.39-0.42）
  - **轮次效率 = 3 / 3 轮 = 1.0 分/轮**（低于基准 1.17-1.25）
- **稳态成本（R4 起，每 2 轮 1 次作案）**：
  - 周期 2 轮，IV=3，真花费 1 情报
  - **全局效率 = 3 / (2 轮 × 3 资源) = 0.5 分/资源**（高于基准）
  - **轮次效率 = 3 / 2 轮 = 1.5 分/轮**（高于基准 1.17-1.25）
- **可持续性**：R4 起的循环可无限延续（前提：X 维持核心区最低且无他人把 X 压低到 0 并列）。依赖条件苛刻——见 §2.3/§2.4。
- **循环闭合**：R3→R5 构成闭合循环（起点情报余额 3=重点 3，X 情报 1=1），✓ 可比

> **关键发现 1**：打空作案"首轮效率远低于基准（0.33 vs 0.39）、稳态效率高于基准（0.5 vs 0.42）"——罪犯的得分节奏呈"慢启动、后加速"，且稳态效率突破基准上沿。这个"后半程加速"叠加终局条件（≥15 且本轮结束）可能使后期领先者锁定胜局。

### 2.3 复苏对打空策略的反制（成本随时间的真实曲线）

以 §2.2 场景推演多轮 X 情报值变化，验证"每次作案后 X 是否维持低位"：

| 轮 | X 情报（罪犯操作后） | 傍晚复苏目标 | 复苏后 X | 罪犯作案成本 |
| - | - | - | - | - |
| R1 | 1 | X（仅 X 最低） | 2 | — |
| R2 | 0 | X | 1 | — |
| R3 | 1（作案后不变） | 其他点 | 1 | 1 |
| R4 | 0 | X | 1 | — |
| R5 | 1（作案后不变） | 其他点 | 1 | 1 |

> **关键发现 2**：作案动作**不改变地点情报值**（规则书 §3.3 机制前提），所以稳态下 X 只需 R4 一次调查压回 0，复苏回 1，R5 以 1 成本作案。**只要 X 是核心区唯一最低点，稳态可自维持**。但──

### 2.4 多罪犯共享低点的结构禁止（内卷量化）

设核心区有 X、Y 两点，罪犯 A、B 都想压低：

| 格局 | 复苏行为 | 结果 |
| - | - | - |
| X=1, Y=3（A 独占 X） | 只回填 X → 2 | A 的压点在 2 轮内被打回半价 |
| X=1, Y=1（A、B 各压一点） | **并列最低 → X、Y 均 +1** | 两点回到 2，两人白压各 1 次调查 |
| X=0, Y=0（两人都打空） | 并列最低 → 均 +1 | 回到 1，仍可作案但成本 1 |
| X=0, Y=1, Z=2（B 独占 X 已 0） | 只回填 X → 1 | 独占者被迫接受 +1 |

**量化结论**：

- **3 罪犯若各自压低不同点**：产生 3 个最低点 → 复苏 3 倍回填，每人每轮需 1 次调查抵消自己的点 → 每人每轮只剩 1 行动，**无人能凑足作案所需的 2 行动**（稳态瓦解）
- **3 罪犯若共用 1 个低点 X**：X 被反复调查降 0，但**谁用 X 作案？** 只有 1 个低点，3 人争抢；且多人调查 X 时 X 长时间 0 → 警长也以 0 成本侦查 X（§3.3）
- **唯一高效路径**：3 罪犯集体压空全部核心区（多 0 点并列），复苏分散 → 12 轮后期全员 0~1 成本作案

> **关键发现 3**：复苏机制造成"罪犯群体性干涸版图"才是唯一稳态最优——每人每轮 1 次作案 + 1 次调查维持。这将导致**后期版图情报趋近 0**，警长侦查成本同步趋近 0（§3.2），形成"双低情报"后期环境。此机制对警长可能反而是利好（低成本侦查源），需 r04 综合验证。

## 3. 警长 0 技能基准

### 3.1 侦查→抓捕链（目标：等级 2 罪犯，隐藏值 H）

**成本拆分**：

| 项目 | 值 | 性质 |
| - | - | - |
| 侦查固定成本 | 1 行动 | 固定 |
| 侦查动态成本 | 地点当前情报值 I（[0, I₀]） | 动态，与罪犯压点程度共享 |
| 抓捕固定成本 | 2 行动 | 固定 |
| 抓捕动态成本 | 补差（H − 证据数），0~H | 动态，依赖罪犯隐藏值 |
| 抓捕得分 | 犯罪等级（2）+ 高效+1（证据 < 等级） | — |

**逐回合流水账**（目标等级 2 罪犯，隐藏 H=1，侦查点 Y 情报 2；警长 R1 侦查 R2 抓捕）：

| 回合 | 行动序列 | Y 情报值 | 供给 IC | 花费 IC（真） | 情报余额 | 本回合 IV |
| - | - | - | - | - | - | - |
| R1 | 侦查 Y（花 2 情，获 1 证据）；调查 Y（2→1，获 1 情） | 2→1 | 3 | 2 | 3−2+1=2 | 0 |
| R2 | 抓捕（2 行动，证据 1，H=1 补差 0，得 2+1=3 分）；摸牌 | — | 3 | 0 | 2 | 3 |

**审计行（R1~R2）**：累计供给 6 / 累计真花费 2 / 累计结余 2 / 累计 IV 3

**结论（双维度）**：

- 首次成本：2 轮，真花费 2 情报 + 2 轮行动 → IV=3
- **全局效率 = 3 / (2 轮 × 3 资源) = 0.5 分/资源**
- **轮次效率 = 3 / 2 轮 = 1.5 分/轮**
- 若目标隐藏 H=3（罪犯少调查）：补差 = 3−1 = 2 → 真花费 2+2=4 → 全局效率 = 3/6 = 0.5（真花费效率 = 3/4 = 0.75）
- **可持续性**：警长 12 轮最多 6 次抓捕（每 2 轮 1 次）；若全部命中等级 2 → 3×6 = 18 分（名义超 15，但情报约束与 3 罪犯分散证据使其不可达，见 §3.3）

### 3.2 无证据奖励（+2/黎明）

- 触发条件：版图上无任何罪犯"证据 Token"（警长手中持有不计）
- 0 技能现实：3 罪犯持续作案放证据，**全版图无证据只在"3 罪犯恰好都因被抓/证据被清空而无法放新证据"的窗口出现**
- 频率估计：12 轮中 1~2 次（+2~4 分），为政策性收益，非主收入
- **不计入警长稳态效率**（罕见事件），但计为"预防性收益"（警长清场行为的边际奖励）

### 3.3 警长与罪犯共享情报结构（对称性发现）

- 罪犯压低的点，警长侦查成本同步降低（侦查花费 = 当前情报值）
- 因此"罪犯压低版图"产生**双重效应**：
  - 罪犯侧：作案成本↓（利好）
  - 警长侧：侦查成本↓（利好，且无证据奖励的维持成本↓）
- **净效应不对称评估**：罪犯压低 1 点情报 = 自己作案省 1 情报 = **警长侦查该点也省 1 情报**。罪犯投入的压点行动，警长"免费搭车"。0 技能下警长是**压点行为的第二大受益者**

### 4.1 如实报告偏差（§1.5）

1. **双方稳态效率（0.5 / 1.5 分）均超过设计基准上沿**（0.42 / 1.25）约 19%——若按此值，12 轮理论得分 = 0.5 × 36 = 18 分，远超 14-15 目标
2. **但该稳态建立在苛刻前提**（独占最低点 / 目标隐藏低 / 无干扰），实际 4 人局中会因：
   - 复苏内卷（§2.4）→ 罪犯稳态效率实际下降
   - 3 罪犯分散证据 → 警长侦查目标被稀释，抓捕频率低于 6 次/12 轮
   - 情报供给约束 → 双方都无法无限维持高花费作案/侦查
3. **净评估**：0 单侧效率偏高于基准，但**跨方抑制未计入**（警长→罪犯：抓捕中断作案轮次；罪犯→警长：证据分散稀释抓捕目标）。抑制后净效率可能落回基准——需 r04 综合验证
4. **结构警告**：复苏机制（§0.1）制造"群体干涸版图"倾向，可能导致后期双方效率同步跃升（作案 0 成本 + 侦查 0 成本），此"后期加速"是否违背设计原则 12（操作成本平滑）需 r04 深度检查
