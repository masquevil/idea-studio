# 方案 1-B · 游戏流程框架

> 基于"城市暗战"方向：城市拓扑地图 + 隐藏行动 + 线索推理 + 动态演化
> 城市：凯恩市（Kane City）

---

## 一、游戏准备流程

### 步骤 1：选择角色配置

根据玩家人数，从以下配置中选择：

| 玩家数 | 警长 | 罪犯 | 超级英雄 | 受害者联盟 |
|--------|------|------|----------|----------|
| 2 | 1 | 1 | - | - |
| 3 | 1 | 2 | - | - |
| 4 | 1 | 2 | 1 | - |
| 5 | 1 | 2 | 1 | 1 |
| 6 | 1 | 3 | 1 | 1 |
| 7 | 1 | 3 | 1 | 2 |

### 步骤 2：构建城市拓扑地图

1. 从地点牌库中随机抽取 **6-9 张地点牌**，按以下示例布局在桌面中央：

```
       ┌─────────┐
       │  市政厅  │
       │ (政府 3) │
       └────┬────┘
            │
   ┌────────┼────────┐
   │        │        │
┌──▼───┐ ┌──▼───┐ ┌──▼───┐
│ 银行  │ │ 大学  │ │ 医院  │
│(金融2)│ │(教育1)│ │(服务2)│
└──┬───┘ └──┬───┘ └──┬───┘
   │        │        │
   ├────────┼────────┤
   │        │        │
┌──▼───┐ ┌──▼───┐ ┌──▼───┐
│商业街 │ │网络中心│ │美术馆 │
│(商业1)│ │(数字2)│ │(文化1)│
└──┬───┘ └──┬───┘ └──┬───┘
   │        │        │
   ├────────┼────────┤
   │        │        │
┌──▼───┐ ┌──▼───┐ ┌──▼───┐
│ 码头  │ │工业区 │ │贫民区 │
│(港口1)│ │(工业1)│ │(居住1)│
└──────┘ └──────┘ └──────┘
```

1. **地点牌属性**：每张地点牌标注以下信息：
   - 地点名称
   - 类型标签（政府/金融/教育/商业/港口/工业/居住/文化/数字等）
   - 初始警戒等级（1-3）
   - 连接地点（哪些地点相邻）
   - 容量（最多可容纳多少名警力/罪犯同时行动）
   - 特殊效果（如有）

2. 在相邻地点之间放置连接线 token（表示路径连通）
3. 在每个地点旁放置热度标记（初始 0）
4. 在每个地点旁放置警戒等级标记

### 步骤 3：分配角色

1. **警长**：公开身份，获得角色面板
2. **罪犯**：从身份牌中随机抽取 1 张（盗窃犯/抢劫犯/诈骗犯/杀人犯/毒贩/黑帮老大）
   - 罪犯之间互相确认身份（仅知道谁是同伴，不知道对方的具体职业）
   - 罪犯身份对警长保密
3. **超级英雄**（可选）：公开身份
4. **受害者联盟**（可选）：公开身份（可选规则中也可隐藏身份）

### 步骤 4：发牌

| 阵营 | 起始手牌 |
|------|---------|
| 警长 | 5 张警力牌（巡警×2、刑警×1、特警×1、卧底×1）+ 2 张特殊行动牌 |
| 每位罪犯 | 1 张身份牌 + 4 张手牌（行动牌 + 地点牌混合） |
| 超级英雄 | 4 张技能牌（快速移动、犯罪阻止、义警逮捕、城市守护各 1 张） |
| 受害者联盟 | 3 张行动牌（自警队、组织游行、悬赏通缉各 1 张）+ 3 个群众 token |

### 步骤 5：设置计数器

| 计数器 | 初始值 | 范围 | 说明 |
|--------|-------|------|------|
| **治安值** | 10 | 0-10 | 城市整体治安水平 |
| **民意值** | 10 | 0-10 | 公众对警长的支持度 |
| **恐慌值** | 0 | 0-10 | 城市恐慌程度 |
| **犯罪点数** | 0 | 0-阈值 | 罪犯累计点数 |
| **犯罪阈值** | 6-10 | — | 依人数设定（见平衡性表） |
| **回合数** | 第 1 回合 | 1-12 | 回合计数 |
| **线索池** | 空 | — | 收集线索碎片 |

**犯罪阈值设定**：

| 玩家数 | 罪犯数 | 犯罪阈值 |
|--------|--------|---------|
| 2 人（1v1） | 1 | 6 点 |
| 3 人（1v2） | 2 | 8 点 |
| 4-5 人（1v2+） | 2 | 8 点 |
| 6-7 人（1v3+） | 3 | 10 点 |

### 步骤 6：游戏开始

警长宣布游戏开始，进入第 1 回合。

## 二、每回合阶段划分

每个回合分为 **4 个阶段**，按顺序执行：

### 阶段 1：罪犯密谋（秘密阶段）

> 时长建议：2 分钟
> 此阶段罪犯秘密选择"要做什么"

**流程**：

1. **抽牌**：每位罪犯从行动牌库抽取 **2 张行动牌**，选择 1 张保留，另 1 张弃掉（抽 2 选 1）
2. **补地点牌**：如手牌中地点牌不足 1 张，从地点牌库补抽至 1 张
3. **选择行动牌**：每位罪犯从手牌中秘密选择 **1 张行动牌**，面朝下放在自己面前
   - 行动牌上标注了：目标地点类型、所需行动强度、暴露度增量、犯罪点数收益
   - 行动牌的类型需与后续选择的地点类型匹配才能获得加成
4. **罪犯可选附加操作**：
   - 打出手牌中的 **行动增强牌**（如武装强攻、顺手牵羊等职业专属牌）——面朝下附加在行动牌旁
   - 使用 **接头牌** 与同伴交换 1 张手牌（双方同意即可，不消耗行动）
   - 使用 **销声匿迹牌** 降低暴露度（如手牌中有，可选使用）
   - 选择 **pass**：弃掉 1 张行动牌，本回合不行动（保留信息优势）
5. 所有罪犯确认后，进入阶段 2

**密谋规则**：

- 罪犯之间可以低声交流（不限语言，但警长也可以听到）
- 交流内容可以撒谎（这是游戏的一部分）
- 所有密谋阶段的打牌必须面朝下，不可被警长看到
- 超级英雄和受害者联盟在此阶段不可行动

---

### 阶段 2：警长部署（公开阶段）

> 时长建议：3 分钟
> 此阶段警长根据情报进行布防

**流程**：

1. **查看城市治安报告**：
   - 查看所有地点的当前热度值（标记在地点旁）
   - 查看所有地点的当前警戒等级
   - 查看线索池中的线索碎片（类型和数量，但不含内容细节）
   - 获得 **情报提示**（模糊线索，如"今晚港口方向不安宁"——系统每回合随机给出 1 条提示）
   - 查看上回合成功犯罪留下的线索碎片分布

2. **执行行动**：
   警长本回合有 **3 行动点**，可分配执行以下操作：

   **派驻警力**（消耗 1 行动点/次）：
   - 从手牌中选择 1 张警力牌，派驻到某个地点
   - 警力牌面朝上放置在地点旁（公开部署，罪犯可见）
   - 例外：**卧底牌** 秘密部署（仅警长自己知道位置，不放在地点上）

   **巡逻调防**（消耗 1 行动点/次）：
   - 将已派驻的 1 名警力移动到相邻地点
   - 巡警每回合可免费调防 1 次（不消耗行动点）

   **调取监控**（消耗 1 行动点/次）：
   - 指定 1 个地点，查看该地点上一回合的犯罪线索内容（如该地点有线索）
   - 获取 1 条线索碎片放入警长的线索池

   **线索分析**（消耗 1 行动点/次）：
   - 从线索池中选择 1 条线索碎片，消耗后获得该线索指向的罪犯职业特征
   - 例如：消耗"目击·蒙面"碎片 → 了解到该地点犯罪的罪犯是"外貌特征：高大"

   **卧底部署**（消耗 2 行动点/次）：
   - 秘密选择 1 个地点安插卧底
   - 不为罪犯所见；下一回合揭晓时反制犯罪

   **新闻发布会**（消耗 1 行动点，每 2 回合限 1 次）：
   - 民意值 +1

   **签发逮捕令**（消耗 1 行动点）：
   - 条件：一名罪犯暴露度 ≥ 3，且警长已收集至少 3 条指向该罪犯的线索碎片
   - 签发后，警长可立即在任意地点对该罪犯执行逮捕

   **封锁入口**（消耗 2 行动点）：
   - 选择 1 条地点连接线，本回合该连接线不可通行
   - 该连接线的两个端点警戒等级各 +1

   **紧急动员**（消耗 2 行动点，限 1 次/局）：
   - 本回合获得额外 1 行动点

3. 警长部署完成后，宣布进入阶段 3

**警长部署规则**：

- 警力牌部署后面朝上（公开部署），罪犯可以看到每个地点的警力配置
- 卧底牌除外——卧底部署时不显示，仅警长自己记录位置
- 警长的行动点可能受民意值调整：民意 ≤3 时 -1，民意 ≥8 时 +1
- 警长行动点不影响"签发逮捕令"（有足够线索即可签发）

---

### 阶段 3：罪犯行动（秘密阶段）

> 时长建议：1-2 分钟
> 此阶段罪犯选择"要去哪里作案"

**流程**：

1. **选择地点**：每位罪犯从手牌中选择 **1 张地点牌**，或从城市地图上选择 1 个未被封锁的地点
   - 将选定的地点牌面朝下放在自己面前（与阶段 1 已选的行动牌组合）
   - 如果行动牌的目标类型与所选地点匹配，行动效果获得 **类型加成**（行动强度 +1）

2. **附加打牌**（可选）：
   - 打出 **闪避牌**：若本回合犯罪失败，暴露度额外 -1（保险措施）
   - 打出 **干扰牌**：使目标地点某个警力本回合不发挥作用
   - 打出 **职业专属牌**：触发职业特殊能力（如盗窃犯的"顺手牵羊"）

3. **多人冲突预检**：
   - 如果多名罪犯选择了同一地点，系统提示冲突（但仅提示"有冲突"，不暴露具体人数）
   - 冲突规则：同一地点有多个罪犯时，只有行动强度最高者成功，其余失败且不暴露

4. 所有罪犯确认后，进入阶段 4

**重要规则**：

- 此阶段罪犯**不可交流**（防止合谋调整策略）
- 地点牌可以是手牌中已有的，也可以是地图上现存的
- 罪犯不能选择已被 **宵禁封锁** 的地点
- 如果罪犯轮到自己时没有可用的地点牌，自动 pass

---

### 阶段 4：揭晓结算（公开阶段）

> 时长建议：4-6 分钟
> 此阶段同时揭晓所有犯罪行动并进行结算

**流程**：

#### 4.1 同时揭晓

1. 所有罪犯同时翻开面前的行动牌和地点牌
2. 警长同时检查各地点的警力部署状态
3. 确认完毕后，进入对抗结算

#### 4.2 对抗结算

对于每个被选为作案目标的地点：

1. **计算罪犯行动强度**：
   - 行动牌基础强度 + 地点类型匹配加成（是/否，+1）+ 职业专属加成 + 附加牌加成

2. **计算目标地点综合防御值**：
   - 所有驻防警力警力值总和 + 地点当前警戒等级 + 其他加成（如封锁入口）
   - 如果该地点有卧底部署，卧底的警力值（1 点）计入防御值，但不向罪犯显示

3. **对抗判定**：

| 结果 | 条件 | 效果 |
|------|------|------|
| **犯罪成功** | 行动强度 ≥ 综合防御值 | 罪犯获得犯罪点数、地点热度+1、留下线索碎片 |
| **犯罪失败** | 行动强度 < 综合防御值 | 犯罪被阻止、罪犯不获得点数、暴露度 +1 |
| **完美反制** | 卧底部署在该地 | 犯罪自动失败（无视强度对比）、罪犯暴露度 +2 |

1. **多名罪犯同一地点的冲突处理**：
   - 按行动强度从高到低排序
   - 仅最高者与防御值对抗
   - 行动强度相同者，暴露度低者优先
   - 其他罪犯的犯罪自动按失败处理（不暴露、不受惩罚）

#### 4.3 效果结算

**成功犯罪的罪犯**：

- 犯罪点数 +N（根据行动牌和职业）
- 暴露度 +M（根据行动牌和职业）
- 地点热度 +1
- 从线索池随机抽取 1 张线索碎片放入线索池（表示警方已收集到证据）

**失败犯罪的罪犯**：

- 犯罪点数 +0
- 暴露度 +1（基础值）
- 如果使用了闪避牌，暴露度不增加

**地点状态更新**：

- 该地点热度 +1
- 检查热度是否触发 **连锁效应**：
  - 热度 ≥ 3：该地点犯罪时暴露度额外 +1（警长更容易追查）
  - 热度 ≥ 4：自动触发警报，警长下回合必获该地点的提示
  - 热度 = 5：该地点被"封禁"（本回合无法犯罪，需等待衰减）

**城市三值更新**：

| 触发条件 | 治安值变化 | 民意值变化 | 恐慌值变化 |
|---------|-----------|-----------|-----------|
| 犯罪成功 1 次 | -1 | - | +1 |
| 犯罪成功 2 次以上（同回合） | -2 | -1 | +2 |
| 犯罪失败（警长阻止成功） | +1 | +1 | -1 |
| 地点升级 | -1 | -1 | +1 |
| 警长逮捕成功 | +1 | +1 | -1 |
| 民意值 ≤3 | - | - | +1（市民不安） |

#### 4.4 地点升级结算

检查每个地点是否触发升级：

- 同一地点某类型犯罪累积 **2 次** → 触发升级
- 升级由该地点最近一次犯罪类型决定
- 升级示例：
  - 银行（正常）→ **戒备银行**（警戒 +1，犯罪收益 +1）或 **沦陷银行**（犯罪收益 +2，警戒 -1）
  - 贫民区（正常）→ **骚乱贫民区**（恐慌 +2，罪犯可招兵买马）或 **军管区**（警长可驻军，但民意 -1）
  - 码头（正常）→ **走私码头**（罪犯行动加成 +2）或 **封锁码头**（警长封锁）
- 升级是永久性的，持续影响后续游戏

#### 4.5 暴露度与逮捕结算

**暴露度更新**：

- 每位罪犯根据本回合行动更新暴露度
- 暴露度自然衰减：未作案时每回合 -1
- 暴露度 ≥ 3：警长知道该罪犯的所在区域（大致位置）
- 暴露度 ≥ 5：自动暴露身份，下回合警长可无条件逮捕

**逮捕结算**：

- 警长检查是否满足逮捕条件：
  - 已有逮捕令（该罪犯暴露度 ≥ 3 + 3 条线索碎片指向）+ 警力在该罪犯所在地点
  - 或罪犯暴露度 ≥ 5（无条件逮捕）
- 满足条件 → 警长执行逮捕 → 该罪犯被捕出局
- 所有罪犯被捕 → 警长立即获胜

**特殊逮捕规则**：

- 超级英雄的可选逮捕（义警逮捕）：暴露度 ≥ 3 即可，每 3 回合 1 次
- 义警逮捕会使恐慌值 +1（法外执法引发不安）

#### 4.6 回合结束清理

1. **回收**：所有已使用的牌（行动牌、地点牌、附加牌）进入各自弃牌堆
2. **热度衰减**：所有地点热度 -1（最低为 0）
3. **暴露度衰减**：未作案的罪犯暴露度 -1
4. **补牌**：
   - 警长：从警力牌库补充至 5 张警力牌；每 2 回合补充 1 张特殊行动牌
   - 罪犯：从牌库（行动牌 + 地点牌混合）补充至手牌上限 5 张
   - 超级英雄：技能牌不消耗，无需补充
   - 受害者联盟：每 2 回合补充 1 个群众 token（上限 5）
5. **手牌上限**：每位玩家手牌上限 5 张，超出需弃掉至上限
6. **回合标记 +1**
7. **检查游戏结束条件**

## 三、各阵营行动选项总表

### 3.1 警长行动选项总表

| 行动类型 | 消耗 | 效果 | 限制 |
|---------|------|------|------|
| **派驻警力** | 1 行动点 | 部署 1 张警力牌到指定地点 | 每回合不限次数，但行动点有限 |
| **巡逻调防** | 1 行动点 | 移动已部署的 1 名警力到相邻地点 | 巡警可免费调防 1 次/回合 |
| **调取监控** | 1 行动点 | 获取指定地点的 1 条线索碎片 | 需该地点有线索 |
| **线索分析** | 1 行动点 | 消耗 1 条线索碎片，推理罪犯职业特征 | 需有线索池中的碎片 |
| **卧底部署** | 2 行动点 | 秘密部署卧底，揭晓时反制犯罪 | 不向罪犯展示 |
| **新闻发布会** | 1 行动点 | 民意值 +1 | 每 2 回合限 1 次 |
| **封锁入口** | 2 行动点 | 封锁 1 条连接线，两端警戒 +1 | — |
| **紧急动员** | 2 行动点 | 本回合额外 +1 行动点 | 限 1 次/局 |
| **签发逮捕令** | 1 行动点 | 逮捕暴露度 ≥3 且有 3 条线索指向的罪犯 | 需满足条件 |

### 3.2 罪犯行动选项总表

| 行动类型 | 消耗 | 效果 | 限制 |
|---------|------|------|------|
| **普通作案** | 1 行动牌 + 1 地点牌 | 基础犯罪行动 | 每回合 1 次 |
| **类型匹配作案** | 行动牌类型匹配地点类型 | 行动强度 +1 | 需手牌/地图上有匹配地点 |
| **使用增强牌** | 额外 1 张手牌 | 行动强度 / 闪避 / 干扰 等加成 | 可选附加 |
| **接头** | 消耗 1 张接头牌 | 与同伴交换手牌 | 仅密谋阶段可用 |
| **销声匿迹** | 消耗 1 张手牌 | 暴露度 -1 | 每回合 1 次 |
| **pass** | 弃 1 张手牌 | 不行动，暴露度自然衰减 | 每回合可选 |

**职业专属行动**（详见 04-角色设计.md）：

| 职业 | 专属行动 | 效果 |
|------|---------|------|
| 盗窃犯 🥷 | **顺手牵羊** | 犯罪成功时额外抽 1 张手牌，暴露度 +1 |
| 抢劫犯 🔫 | **武装强攻** | 本回合行动强度 +2，暴露度额外 +1，地点警戒 +1 |
| 诈骗犯 🧠 | **伪造线索** | 犯罪成功时向线索池投入假线索牌 |
| 杀人犯 ☠️ | **连环追击** | 连续 2 回合成功作案则恐慌值额外 +1 |
| 毒贩 💊 | **腐化** | 犯罪成功时使该地点 1 名警力下回合不提供防御值 |
| 黑帮老大 👑 | **调兵遣将** | 指定同伴本回合行动强度 +1 或暴露度 -1，每 2 回合 1 次 |

### 3.3 超级英雄行动选项总表

| 行动类型 | 消耗 | 效果 | 限制 |
|---------|------|------|------|
| **快速移动** | 1 次行动 | 移动到任意地点（无视拓扑连接） | 每回合 1 次 |
| **犯罪阻止** | 1 次行动 | 选择 1 个正在发生犯罪的地点，阻止该犯罪 | 每回合 1 次 |
| **义警逮捕** | 1 次行动 | 逮捕暴露度 ≥ 3 的 1 名罪犯（不消耗警长逮捕令） | 每 3 回合 1 次，恐慌值 +1 |
| **城市守护** | 全部行动 | 本回合 1 个地点所有犯罪自动失败 | 每 2 回合 1 次，牺牲移动和阻止权 |

### 3.4 受害者联盟行动选项总表

| 行动类型 | 消耗 | 效果 | 限制 |
|---------|------|------|------|
| **建立自警队** | 1 个群众 token | 在目标地点放置群众 token：50% 概率阻止犯罪（骰子 3+） | 每 2 回合 1 次 |
| **组织游行** | 1 次行动 | 警长下回合行动点 +1，恐慌值 +1 | 每 3 回合 1 次 |
| **悬赏通缉** | 1 次行动 | 指定 1 名罪犯，本回合所有玩家可见其暴露度 | 需有线索指向该罪犯，每 2 回合 1 次 |
| **媒体施压** | 1 次行动 | 选择：民意值 +1 或 恐慌值 +1 | 每 2 回合 1 次 |
| **私下谈判** | 无消耗 | 与 1 名玩家达成秘密协议 | 每回合 1 次，可对第三方撒谎 |

## 四、游戏结束触发条件

### 4.1 警长获胜

| 条件 | 说明 |
|------|------|
| **逮捕获胜** | 所有罪犯均被逮捕（被捕出局） |
| **安定获胜** | 游戏达到最大回合数（12 回合），犯罪点数未达到阈值，且恐慌值 ≤ 5 |

### 4.2 罪犯获胜

| 条件 | 说明 |
|------|------|
| **犯罪获胜** | 犯罪点数累计达到阈值，且至少 1 名罪犯未被逮捕 |
| **堕落获胜** | 恐慌值达到 10（城市陷入混乱），所有未被逮捕的罪犯获胜 |

### 4.3 超级英雄获胜

| 条件 | 说明 |
|------|------|
| **正义获胜** | 正义值达到 6 点（独自获胜，覆盖其他阵营） |
| **中立结局** | 游戏结束时正义值未达到 6 点，不参与最终胜负判定 |

### 4.4 受害者联盟获胜

| 条件 | 说明 |
|------|------|
| **变革获胜** | 民意值（个人）达到 10 点，独自获胜 |
| **共同获胜** | 民意值（个人）达到 6 点 + 至少 2 名罪犯被逮捕，与警长共同获胜 |
| **混乱获胜** | 恐慌值达到 10 且受害者联盟存活，独自获胜（极端情况） |

### 4.5 多阵营同时获胜优先级

如果多个阵营同时达到获胜条件：

1. **恐慌值 = 10** → 罪犯堕落获胜（城市崩溃）
2. **超级英雄正义值 ≥ 6** → 超级英雄独自获胜
3. **受害者联盟民意值 ≥ 10** → 受害者联盟独自获胜
4. **受害联盟混乱获胜**（恐慌 10 + 存活）→ 在堕落中建立新秩序
5. **罪犯犯罪点数达阈值且无人被捕** → 罪犯获胜
6. **警长逮捕所有罪犯** → 警长获胜
7. **混合胜利**：受害者联盟共同获胜 + 警长逮捕获胜 → 并列第一

### 4.6 游戏结束流程

1. 宣布获胜阵营及获胜方式
2. 如有个人成就统计（罪犯累计点数、警长逮捕数、英雄正义值等），宣布 MVP
3. 简短复盘（可选）

```
游戏准备：
  1. 选择角色配置（依人数）
  2. 构建城市拓扑地图（6-9 张地点牌）
  3. 分配角色（罪犯秘密抽身份）
  4. 发放起始手牌
  5. 设置计数器（三值 + 犯罪点数 + 线索池）
  6. 游戏开始

每回合：
  ┌─ 阶段 1：罪犯密谋（秘密，2 分钟）
  │   • 抽 2 选 1（行动牌）
  │   • 补地点牌（如不足）
  │   • 秘密选择 1 张行动牌
  │   • 可选：增强牌/接头/销声匿迹/pass
  │
  ├─ 阶段 2：警长部署（公开，3 分钟）
  │   • 查看城市治安报告
  │   • 派驻警力（1 行动点/次）
  │   • 调防/监控/分析/新闻发布会等
  │   • 可选：卧底部署/封锁入口/紧急动员
  │
  ├─ 阶段 3：罪犯行动（秘密，1-2 分钟）
  │   • 选择 1 张地点牌（匹配行动牌类型）
  │   • 可选：闪避牌/干扰牌/职业专属牌
  │   • 此阶段不可交流
  │
  └─ 阶段 4：揭晓结算（公开，4-6 分钟）
      1. 同时翻牌
      2. 对抗结算（行动强度 vs 综合防御）
      3. 效果结算（点数/热度/暴露度/线索）
      4. 地点升级结算
      5. 城市三值更新
      6. 逮捕结算
      7. 回合结束清理（回收/衰减/补牌）

游戏结束：
  • 检查所有阵营获胜条件
  • 按优先级宣布获胜者
  • 宣布 MVP
  • 复盘
```

|------|-------------|---------|----------|

- 揭晓结算阶段，建议按地点顺序逐一结算，避免混乱

## 七、规则核心要点总结

| 要点 | 说明 |
|------|------|
| 🎯 **核心机制** | 4 阶段循环：罪犯密谋 → 警长布防 → 罪犯选点 → 同时揭晓对抗 |
| 🗺️ **地图核心** | 城市拓扑地图决定移动路径和传播效应，封锁连接线可阻断犯罪传递 |
| 🔍 **线索推理** | 成功犯罪留下线索碎片，警长通过分析和拼凑锁定罪犯身份 |
| 🌡️ **热度管理** | 罪犯必须在高热度下转移地点，否则暴露风险递增 |
| 🏙️ **城市动态** | 地点升级永久改变城市面貌，每次游戏城市形态不同 |
| 📊 **三值平衡** | 警长不能只抓罪犯——治安、民意、恐慌三值同时管理 |
| 💡 **关键策略** | 罪犯：分散作案 vs 集中突破；警长：防守热点 vs 撒网布防 |
| ⚠️ **常见误区** | 罪犯连续同一地点作案（暴露+热度双升）；警长只派驻不调防（浪费警力灵活性） |
| 🎮 **新手建议** | 罪犯选盗窃犯（低风险稳定收益）；警长优先部署巡警+刑警（灵活+信息） |
| 🔄 **可选规则** | 超级英雄增加变数，受害者联盟增加深度——首次游玩建议 3 人纯警匪局 |

## 八、方案 B 流程与方案 A 的关键区别

| 维度 | 方案 A | 方案 B |
|------|--------|--------|
| **阶段数** | 3 阶段（密谋→部署→揭晓） | 4 阶段（密谋→部署→行动→揭晓） |
| **罪犯行动** | 密谋阶段同时选地点+行动 | 分两阶段：先选行动牌，再选地点牌 |
| **地图** | 固定 3×3 网格 | 拓扑地图，地点随机抽取，连接可变 |
| **警长部署** | 面朝下（秘密部署，罪犯不知） | 面朝上（公开部署，卧底除外） |
| **线索系统** | 简单线索 token | 线索碎片分类型（物证/目击/数字/关联），需要拼凑推理 |
| **城市状态** | 静态地点 | 动态升级，永久改变 |
| **三值系统** | 无 | 治安/民意/恐慌三值联动 |
| **热度系统** | 简单（≥3 触发连锁） | 完整（0-5 分段效果 + 封禁机制） |
| **获胜条件** | 逮捕/犯罪/正义/民意 四类 | 再加堕落获胜/混乱获胜等更多变体 |
