# 方案 1-B · 核心机制设计

> 基于"城市暗战"方向：城市拓扑地图 + 隐藏行动 + 线索推理 + 动态演化

---

## 核心游戏循环

游戏以"回合"为单位推进，每回合分为四个阶段：

### 阶段 1：罪犯密谋（秘密阶段）

1. 所有罪犯从手牌中秘密选择 **1 张行动牌**，面朝下放在面前（该阶段不直接选择地点）
2. 行动牌上标注了目标地点类型（如"商业区"）、所需行动强度、暴露度
3. 罪犯可选择 **pass**（弃掉手牌跳过本回合），保留信息优势
4. 所有罪犯确认后进入阶段 2

### 阶段 2：警长部署（公开阶段）

1. 警长查看 **城市治安报告**——显示各地点当前警戒等级、热度值，以及本回合"情报提示"（模糊线索：如"今晚港口方向不安宁"）
2. 警长执行以下操作（共 3 行动点）：
   - **派驻警力**：派遣 1 名警力到某地点（消耗 1 行动点）
   - **巡逻调防**：将已派驻的警力移动到相邻地点（消耗 1 行动点）
   - **部署卧底**：在目标地点安插卧底，该行动秘密进行（消耗 2 行动点）
   - **调取监控**：获取某个地点的上一回合犯罪线索（消耗 1 行动点）
   - **新闻发布会**：提升民意值（消耗 1 行动点，限每 2 回合 1 次）
3. 所有部署完成后进入阶段 3

### 阶段 3：罪犯行动（秘密阶段）

1. 每位罪犯从手牌中选择 **1 张地点牌**（或地图上某个未被封锁的地点），与阶段 1 的行动牌组合
2. 如果行动牌的目标类型与所选地点匹配，行动效果加成
3. 罪犯可额外打出 **闪避牌** 或 **干扰牌** 作为保险
4. 所有罪犯确认后进入阶段 4

### 阶段 4：揭晓结算（公开阶段）

1. **同时揭晓**：所有罪犯同时翻开幕布的行动和地点
2. **移动结算**：如果某地点有多个罪犯选择，先结算行动强度高的（冲突规则）
3. **对抗结算**：罪犯行动强度 vs 该地点当前 **综合防御值**（警力值 + 警戒等级 + 卧底反制）
   - 行动强度 ≥ 综合防御值 → **犯罪成功**
   - 行动强度 < 综合防御值 → **犯罪失败**，罪犯可能暴露
4. **效果结算**：成功犯罪的罪犯：
   - 获得对应犯罪点数
   - 该地点 **热度+1**
   - 可能触发 **地点升级**（如银行→戒备银行）
   - 留下 **线索碎片**（随机抽取 1 张线索牌放入线索池）
5. **城市状态更新**：根据本回合犯罪结果调整三值（治安↓/恐慌↑/民意↓）
6. 回收所有牌，弃牌阶段（手牌上限 5 张），补牌阶段，进入下一回合

## 胜利条件

### 警长获胜条件

- **逮捕获胜**：累计收集到足够线索拼出 N 名罪犯身份，发出逮捕令抓捕（所有罪犯落网则胜）
- **安定获胜**：游戏结束时恐慌值未超过阈值，且民意值保持在一定水平以上

### 罪犯获胜条件

- **犯罪获胜**：累计犯罪点数达到阈值（如 12 点），且至少有 1 名罪犯未被逮捕
- **堕落获胜**（特殊）：城市恐慌值达到上限（城市陷入混乱），所有存活罪犯获胜

### 超级英雄（0-1 人）获胜条件

- **正义值获胜**：阻止犯罪累计正义值，达到目标值则独自获胜
- 超级英雄不受警长指挥，可自行决定干预目标

### 受害者联盟（0-1 人）获胜条件

- **变革获胜**：累计民意值达到阈值，推动市长下台／新政权上台，独自获胜
- 受害者联盟可组织和煽动公众情绪

## 基本规则框架

### 游戏准备

1. **构建城市地图**：
   - 从地点牌库中随机选取 6-9 张地点牌，按拓扑结构排列在桌面中央
   - 每张地点牌标注：名称、类型标签（商业/港口/富人区/贫民区/政府/工业等）、初始警戒等级(1-3)、容量、连接地点
   - 地点间用连接线标记路径（可移动、传播效应等）

2. **资源配置**：
   - 警长：5 张警力牌（巡警×2、刑警×1、特警×1、卧底×1）+ 2 张特殊行动牌
   - 每位罪犯：1 张身份牌（职业随机分配）+ 4 张手牌（行动牌 + 地点牌混合）
   - 设置线索池（多种线索碎片牌）
   - 设置城市三值计数器（治安 10 / 民意 10 / 恐慌 0）

3. **标记初始状态**：每个地点放置初始警戒等级标记，设置热度计数器（初始 0）

### 基本名词定义

| 名词 | 说明 |
|------|------|
| **地点牌** | 城市中的地点，有类型标签和连接关系，构成拓扑地图 |
| **行动牌** | 罪犯的具体行动，标注目标类型、行动强度、暴露度、犯罪点数 |
| **行动强度** | 罪犯行动的成功力，与目标地点的防御值对抗 |
| **综合防御值** | 地点当前防御水平 = 警力值 + 警戒等级 + 其他加成 |
| **警力牌** | 警长资源，派驻到地点后提供防御值和特殊功能 |
| **警戒等级** | 地点固有安全级别（1-3），可通过警长行动提升，随回合恢复 |
| **热度** | 地点近期犯罪频率（0-5），越高越危险，降低罪犯暴露风险但也更容易被警长注意到 |
| **暴露度** | 罪犯行动时暴露身份的风险概率（由行动牌决定） |
| **线索碎片** | 成功犯罪留下的证据碎片，警长收集碎片拼凑完整线索链 |
| **逮捕令** | 线索链完成后警长获得，可指定逮捕一名罪犯 |
| **治安值** | 城市整体治安水平（初始 10），犯罪会降低，影响地点初始警戒 |
| **民意值** | 公众对警长的支持度（初始 10），犯罪过多或警长失误会降低，可通过新闻发布会等恢复 |
| **恐慌值** | 城市恐慌程度（初始 0），犯罪和连锁升级会提升，达到上限罪犯可直接获胜 |
| **地点升级** | 犯罪累积影响地点状态，每个地点有多个升级分支 |

### 核心规则

#### 城市拓扑地图

- 地点之间由连接线相连（形成网状拓扑）
- 警力移动受连接关系限制（只能移动到相邻地点）
- 某些犯罪效果可传播到相邻地点（如骚乱扩散）
- 警长可通过封锁入口切断地点连接（消耗资源）
- 地点距离（步数）影响某些行动牌的效果范围

#### 热度系统

- 每个地点有热度值（0-5），犯罪成功 +1，每回合自然衰减 -1
- 热度 ≥ 3：该地点犯罪时暴露度 +1（更易被警长追查）
- 热度 ≥ 4：该地点自动触发警报，警长下回合必获提示
- 热度 = 5：该地点被"封禁"（本回合无法犯罪，需等待衰减）
- 罪犯在高热度地点犯罪后必须换地点，否则风险递增

#### 线索推理解谜

- 每次成功犯罪产生 1 条线索碎片（随机从线索池抽取）
- 线索类型：
  - **物证**：DNA、指纹、弹道分析 → 确认罪犯身份
  - **目击**：证人描述、监控录像 → 锁定罪犯特征
  - **数字**：转账记录、通讯记录 → 追踪罪犯行踪
  - **关联**：犯罪手法、同伙线索 → 串联多起案件
- 警长需要收集 **3 条同一罪犯的线索碎片** 才能拼出完整线索链
- 完整线索链 → 发出逮捕令 → 指定逮捕该罪犯（需要警力部署到位）
- 线索可以共享（跨地点），但需要推理关联关系

#### 地点升级系统

- 每个地点有 2-3 个可能的升级方向（取决于犯罪类型）
- 升级阈值：某类型犯罪在该地点累积 2 次 → 触发升级
- 升级示例：
  - 银行（正常）→ **戒备银行**（警戒 +1，但犯罪收益 +1）或 **沦陷银行**（犯罪收益 +2，警戒 -1）
  - 贫民区（正常）→ **骚乱贫民区**（恐慌 +2，但罪犯可招兵买马）或 **军管区**（警长可以驻军，但民意 -1）
  - 码头（正常）→ **走私码头**（罪犯行动加成 +2）或 **封锁码头**（警长封锁，所有罪犯不可用）
- 升级是永久性的，每次升级改变地点状态，也影响后续策略选择

#### 警官派驻系统

| 警力类型 | 警力值 | 特殊功能 |
|---------|--------|---------|
| 巡警 | 2 | 每回合可调防一次（移动消耗 0 行动点） |
| 刑警 | 3 | 派驻时自动获取该地点线索碎片（如有） |
| 特警 | 4 | 可派驻到高热度地点（需热度 ≥3 才能派遣），对抗时优先结算 |
| 卧底 | 1 | 秘密部署，不为罪犯所见；揭晓时获得该地点所有犯罪记录；可用于反制（使一次犯罪自动失败） |
| 网警 | 0 | 不驻防，但每回合可追踪一条数字线索的来源地 |

#### 城市三值系统

- **治安值**（初始 10，范围 0-10）：
  - 犯罪降低治安值（每次 -1~-2）
  - 警长逮捕成功 +1
  - 治安值 ≤ 3：所有地点初始警戒 -1
  - 治安值 = 0：城市失控，进入危机模式

- **民意值**（初始 10，范围 0-10）：
  - 恐慌上升降低民意值（恐慌每 +2 则民意 -1）
  - 警长召开新闻发布会 +1
  - 警长逮捕成功 +1
  - 民意值 ≤ 3：警长每回合行动点 -1（市民不配合）
  - 民意值 = 0：警长被革职，所有罪犯获胜

- **恐慌值**（初始 0，范围 0-10）：
  - 犯罪成功 +1
  - 地点升级 +1
  - 恐慌值 ≥ 5：在某些地点触发随机事件
  - 恐慌值 = 10：城市崩溃，所有存活罪犯获胜

### 玩家操作复杂度

| 阵营 | 每回合操作 | 核心决策 | 信息量 |
|------|-----------|---------|--------|
| 警长 | 情报分析、派驻警力、调防、使用特殊行动 | 有限行动点分配：布防 vs 线索追查 vs 民意维稳 | 全地图信息 + 线索碎片提示 |
| 罪犯 | 选行动牌、选地点、可选打附加牌 | 选地点（看热度/警力分布）、管理暴露度、配合同伴 | 可见警力部署位置，但不知卧底 |
| 超级英雄 | 移动、阻止犯罪、特殊技能 | 帮哪边、何时出手效果最大 | 全地图 + 可查看线索池 |
| 受害者联盟 | 煽动情绪、组织活动、悬赏 | 推高恐慌还是积累民意、与罪犯合作还是对抗 | 有限信息，但了解城市三值 |

## 设计要点总结

1. **城市拓扑地图是核心**：地点连接关系决定了移动、传播、封锁等策略深度
2. **三值系统创造多维度胜利**：治安、民意、恐慌三者互相关联，警长不能只抓罪犯
3. **线索推理解谜**：与方案 A 的线索消耗不同，方案 B 的线索碎片需要拼凑推理，更强调"侦探感"
4. **地点升级实现动态城市**：地点状态因犯罪而永久变化，每次游戏城市形态不同
5. **热度系统驱动罪犯轮换**：迫使罪犯不停更换地点，避免"蹲一个点刷分"
6. **多种警力类型丰富布防策略**：不同警力适用不同场景，卧底和网警增加了隐藏博弈维度
7. **轻中策定位**：比方案 A 稍重（45-90 分钟），核心复杂度集中在城市拓扑管理和三值平衡上
