# 量化审查规则

> 评审工具文档 — 用于阶段 ③-B 中的量化审查
> 使用方式：在 ③-B 评审中，以本文档为工具对规则书、地点、技能进行量化审查

---

## 1. 基本单位体系

| 单位 | 含义 |
| - | - |
| AP | 1 个基础行动 |
| IP | 1 个"情报 Token" |
| VP | 1 分 |

**基准锚定**：

- **调查**：1AP → 1IP。同时地点IP-1
- **摸牌**：1AP → 1手牌。手牌本身无收益，是兑现策略潜力的媒介
- **出牌**：1AP+1手牌 → 牌面效果。手牌效果应显著>1才有意义

> 不引入 TP（完整回合）作为技能收益评估单位。技能评估仅使用 AP/IP/VP 三个单位。

## 2. 审查设计原则

以下 10 条原则在量化审查中作为判断依据：

| # | 原则 | 说明 |
| - | - | - |
| 1 | **得分效率一致** | 0技能下警长与所有犯罪等级的罪犯预期得分效率一致，极好发挥均可接近15VP（此为设计目标，非事实断言） |
| 2 | **规则一致** | 不因阵营不同而改变补给、胜利条件等全局规则。超级英雄/受害者的技能等同于基础行动 |
| 3 | **得分收益 ≠ 剥夺收益** | 得分是绝对领先（领先所有人），剥夺是相对优势（只压制1个对手），不能简单相加 |
| 4 | **技能效率 ≤ 基础效率** | 技能收益不应显著高于基础行动效率，否则玩家会优先用技能而非基础行动 |
| 5 | **摸牌=0即时收益** | 摸牌储存策略潜力，出牌兑现价值 |
| 6 | **读报是看守所保底** | 刻意低效，不与调查对比性价比 |
| 7 | **等级1不触发高效抓捕是叙事设计** | 小混混耗费警力，警长需在扫街与追大鱼之间抉择 |
| 8 | **等级1监禁1轮是惩罚** | 缺席1回合≈损失0.5-1VP作案机会 |
| 9 | **仅调查消耗版图IP** | 侦查/作案花费IP回流供应堆，不消耗版图资源 |
| 10 | **不出现已删除的内容** | 不对比前版本，不使用"修正/错误/撤回"等表述 |
| 11 | **作案频率预期** | 0技能下等级1罪犯每2回合作案1次(6次/12轮≈6证据)，等级2每2.5回合1次(5次/12轮≈5证据)，等级3每3回合1次(4次/12轮≈4证据)——此为设计目标，规则书数值应以此校准 |
| 12 | **隐藏值与等级正相关** | 犯罪等级越高则隐藏值越高。低等级罪犯容易被抓(低隐藏值)，高等级罪犯难被抓(高隐藏值)——与直觉相反但机制合理：高等级的单次得分高但频率低，低隐藏值保障警长有足够的抓捕机会 |
| 13 | **被捕次数预期** | 在上述作案频率与隐藏值下，警长不消耗额外资源(无IP补差)时每等级被捕约2/1.5/1次(等级1/2/3)；消耗额外资源(IP补差)时约4/3/2次。此为全局平衡的设计锚点 |

## 3. 基础行动审查清单

### 3.1 通用行动

| 行动 | 投入 | 直接产出 | 间接效果 | 审查要点 |
| - | - | - | - | - |
| **调查** | 1AP | 1IP + 地点IP-1 | 降低该地点后续侦查/作案成本 | 基线，锚定1AP=1IP |
| **摸牌** | 1AP | 1手牌 | 无直接游戏影响 | 0即时收益，存储策略潜力 |
| **出牌** | 1AP+1手牌 | 牌面效果 | — | 手牌效果应显著>1AP，否则不值得出 |
| **读报** | 1AP+弃1牌 | 1IP(从供应堆) | 不降低地点IP | 看守所保底行动，刻意低效 |

**审查方法**：对照上表，检查规则书中每个通用行动的投入产出是否匹配基准。

### 3.2 警长专属行动

#### 侦查

| 地点类型 | 投入 | 产出 | 审查标准 |
| - | - | - | - |
| 低IP地点 | 1AP+X IP(X=地点IP) | 1证据 | IP成本应与目标罪犯的潜在得分匹配 |
| 高IP地点 | 1AP+X IP | 1证据 | 高投入应对应高犯罪等级(高回报) |

**审查方法**：检查各级别地点的侦查IP成本是否合理，警长是否有"追大鱼"与"扫小虾"的抉择空间。

#### 抓捕

| 维度 | 审查标准 |
| - | - |
| 基础得分 | = 犯罪等级（1-4VP） |
| 高效抓捕 | 证据数<犯罪等级时+1（等级1不可触发） |
| 投入结构 | 2AP + 侦查前置 + 情报补差（视隐藏值） |
| 合理性 | 犯罪等级越高，投入越大但单次回报越高 |

**审查方法**：检查抓捕链的总投入（侦查+抓捕）与预期回报是否成正比。

#### 布控

| 维度 | 审查标准 |
| - | - |
| 投入 | 1AP |
| 效果 | 地点IP+2（本轮有效） |
| 资源限制 | 警员Token数量(5个) |
| 审查要点 | 布控是否提供了策略深度（提高侦查成本/保护特定区域） |

### 3.3 罪犯专属行动

#### 作案

| 维度 | 审查标准 |
| - | - |
| 基础得分 | = 地点影响值（1-4VP） |
| 超额作案 | 若影响值 ≥ 犯罪等级，额外+1 |
| 投入结构 | 2AP + 地点IP（情报） + 消耗1证据Token |
| 被捕风险 | 留下证据 → 警长可侦查获取 |

**审查方法**：检查作案和抓捕的投入产出是否基本对称。

#### 隐藏

| 维度 | 审查标准 |
| - | - |
| 投入 | 1AP |
| 效果 | 隐藏值+1（不超过上限） |
| 价值 | 提高警长抓捕的情报补差成本 |
| 审查要点 | 隐藏是否提供了有意义的防御深度，而非拖慢游戏节奏 |

## 4. 资源系统审查清单

### 4.1 IP 流向分析

IP 的两种去向：

| 去向 | 操作 | 版图IP影响 |
| - | - | - |
| ① 调查 | 版图→玩家 | 版图IP -1，玩家 IP +1 → **版图净减少** |
| ② 侦查/作案花费 | 玩家→供应堆 | 玩家 IP -X，版图 IP 不变 → **回流供应堆** |

**审查要点**：

- 只有调查才消耗版图IP
- 侦查和作案花费的IP回流供应堆，不消耗版图资源
- 这些IP可在后续被火车站等地点的特殊效果重新放到版图上

### 4.2 版图IP消耗估算方法

```
估算公式：
  初始版图IP = Σ(各区地点张数 × 各张初始情报值)
  每轮调查次数 ≈ (罪犯数 × 罪犯平均调查频率) + (警长调查频率)
  12轮总调查次数 = 每轮调查次数 × 12
  12轮后剩余 ≈ 初始IP - 总调查次数

注：此为简化模型，未计布控(+2IP)、特殊地点效果、玩家间IP交易等动态因素。
```

**审查标准**：

| 剩余IP | 结论 |
| - | - |
| > 10 | IP充足，无需补充 |
| -5 ~ 10 | 边界情况，需根据实际测试判断 |
| < -5 | IP可能不足，需要补充策略（如增加IP回收机制） |

### 4.3 IP不足时的游戏状态

当版图IP不足(IP=0)时，检查以下规则是否合理：

- **调查**：无法获取IP（IP=0不能调查）
- **作案**：免费（IP=0作案不需花费IP）
- **侦查**：免费（花费=地点IP=0），但需要该地点有证据

IP耗尽后的自然节奏变化：

| 影响 | 说明 |
| - | - |
| 调查不可做 | 玩家只能通过摸牌/出牌/读报来"过" |
| 作案免费 | 有IP储备的罪犯可以连续作案 → 得分加速 |
| 侦查免费 | 警长可以低成本获取证据 |
| 整体 | 自然的加速机制——后半局版图资源枯竭，游戏节奏加快 |

### 4.4 资源相关审查

| 项目 | 审查标准 |
| - | - |
| 情报Token持有上限 | 无上限正确，蓄力策略深度的一部分 |
| 证据Token供给 | 每个罪犯5个，12轮作案4-6次，够用。溢出时应自动移动 |
| 策略牌消耗 | 35张/4人局 ≈ 第9轮耗尽并洗混，后半程增加不确定性 |
| 手牌上限 | 3张，检查是否与其他资源系统合理配合 |

## 5. 得分效率审查

> 本节包含两部分：**方法论**（§5.1-5.2，固定不变）和**基于当前规则书的计算数据**（§5.3及之后，规则书修改后需重新计算）。
> 量化审查时：首先用方法论理解分析框架，然后用当前数据作为基准进行对比。

### 5.0 设计目标（不变锚点）

以下为设计阶段 ③-B 评审时的固定参照目标：

| 目标 | 说明 |
| - | - |
| **作案频率** | 等级1: 2回合/次(6次/12轮)；等级2: 2.5回合/次(5次/12轮)；等级3: 3回合/次(4次/12轮) |
| **证据供给量** | 等级1提供6证据/12轮；等级2提供5证据/12轮；等级3提供4证据/12轮 |
| **隐藏值与等级** | 犯罪等级↑则隐藏值↑。低等级(易被抓)/高等级(难被抓) |
| **被捕次数(无补差)** | 等级1约2次、等级2约1.5次、等级3约1次 |
| **被捕次数(有补差)** | 等级1约4次、等级2约3次、等级3约2次 |
| **普通得分接近** | 0被捕时各等级12轮得分应在10-15VP范围内 |
| **最佳可达15VP** | 无被捕的最佳发挥，所有阵营均可接近15VP |

### 5.1 审查方法论（固定不变）

> 以下方法论不随规则书版本变化。方法本身不变，仅需在 §5.3 起换入新数值即可。

#### 作案AP总投入

**核心机制**：调查降低地点IP，作案花费 = 地点当前IP值。

这意味着：如果你自己反复调查同一地点，你既获得了IP入账，又降低了作案的IP花费。当IP降至0时，作案免费。

```
示例：下城区(初始IP=2)
  第一步：调查(1AP) → 得1IP，地点IP 2→1
  第二步：调查(1AP) → 得1IP，地点IP 1→0
  第三步：作案(2AP) → 花费=0(IP=0)，得1-2VP
  净收入：+2IP(调查所得) - 0IP(作案花费) = +2IP
  总AP成本：调查2AP + 作案2AP = 4AP
```

**关键推论**：

- **作案后罪犯净赚IP**（等于初始IP值），并非消耗IP
- **其他玩家的调查也在帮所有人降成本**——版图IP是所有玩家共享的资源
- **真正成本是AP（行动次数）**，而不是IP。IP只是调查的副产品
- 版图IP越低，作案越便宜——后期IP耗尽时作案完全免费

**AP总投入表**（仅计自己调查的极端情况）：

| 目标(初始IP值) | 前置调查AP | 作案AP | 总AP | 净得IP | 得分 | VP/AP |
| - | - | - | - | - | - | - |
| 下城(IP=2) | 2AP | 2AP | 4AP | +2IP | 1-2VP | 0.25-0.50 |
| 核心(IP=3) | 3AP | 2AP | 5AP | +3IP | 2-3VP | 0.40-0.60 |
| 上城(IP=4) | 4AP | 2AP | 6AP | +4IP | 3-4VP | 0.50-0.67 |
| 博物馆(IP=5) | 5AP | 2AP | 7AP | +5IP | 4-5VP | 0.57-0.71 |

> 如果其他玩家已调查该地点降低IP，前置调查AP需求会减少，VP/AP提升。
> 审查时填入当前规则书中的IP/影响值计算具体数值。

#### 作案链周期模型

罪犯每回合 2AP。作案周期 = 调查积累 + 作案执行。

| 目标IP值 | 前置调查AP | 前置回合(独自) | +作案回合 | 周期(独自) | 12轮次数 |
| - | - | - | - | - | - |
| IP=2 | 2AP | 1 | 1 | 2回合 | 6 |
| IP=3 | 3AP | 1.5 | 1 | 2.5回合 | 4-5 |
| IP=4 | 4AP | 2 | 1 | 3回合 | 4 |
| IP=5 | 5AP | 2.5 | 1 | 3.5回合 | 3 |

> 注1：如果其他玩家也在该地点调查（帮降IP），实际周期缩短。
> 注2：隐藏值自动回复也消耗AP，实际周期可能略长。

#### 理性罪犯选址模型

| 等级 | 超额条件 | 可选区域 |
| - | - | - |
| 1 | 影响值≥1 | 全部区域 |
| 2 | 影响值≥2 | 影响值≥2的区域 |
| 3 | 影响值≥3 | 影响值≥3的区域 |
| 4 | 影响值≥4 | 影响值≥4的区域 |

#### 被捕频率估算模型

被捕频率 = f(作案次数, 证据量, 侦查成本, 警长激励, 隐藏值补差)

- 证据越多、侦查越便宜、抓捕激励越大 → 被捕概率越高
- 隐藏值越高、IP补差需求越大 → 被捕概率越低（无补差时）
- 分析时依次列出：作案次数→证据量→侦查成本→警长激励→最终被捕估算

| 目标等级 | 侦查IP成本 | 前置调查AP | 侦查AP | 抓捕AP | 总AP | 12轮可能性 |
| - | - | - | - | - | - | - |
| ？ | ？ | ？ | 1AP | 2AP | ？ | ？ |

### 5.3 当前作案链周期估算

> ⚠️ **以下所有数据均为当前规则书版本的数值**。规则书修改后需重新计算。

罪犯每回合 2AP。一个完整的作案周期 = 调查积累（多次调查） + 作案执行（1回合）。

**示例：等级2罪犯针对核心区（IP=3）**

- 前置调查：3次 = 3AP → 需要 2 回合（第1回合2调查+第2回合1调查）
- 作案执行：1回合（2AP全部用于作案）
- 周期 = 3回合（3次作案）→ 12轮 ≈ 4次
- 每次得分：影响值2 + 超额1 = 3VP
- 0被捕预估：4 × 3 = 12VP

**示例：等级2罪犯针对上城（IP=4）**

- 前置调查：4次 = 4AP → 需要 2 回合
- 作案执行：1回合
- 周期 = 3回合 → 12轮 ≈ 4次
- 每次得分：影响值3 + 超额1 = 4VP
- 0被捕预估：4 × 4 = 16VP

**各目标区域周期汇总**：

| 目标（IP值） | 前置AP | 前置回合 | +作案回合 | 周期(回合) | 12轮次数 |
| - | - | - | - | - | - |
| 下城(2) | 2AP | 1 | 1 | 2 | 6 |
| 核心(3) | 3AP | 1.5 | 1 | 2.5 | 4-5 |
| 上城(4) | 4AP | 2 | 1 | 3 | 4 |
| 博物馆(5) | 5AP | 2.5 | 1 | 3.5 | 3 |

> 注：隐藏值自动回复会让罪犯有额外AP用于隐藏而非调查，实际周期可能略长。此表为纯效率最优的计算。

### 5.4 理性罪犯的选址策略

每个等级的理性罪犯只会选择**能触发超额+1**的地点（否则效率过低）。这构成了各自的选择空间：

| 等级 | 超额条件 | 可选区域（单次得分） |
| - | - | - |
| **1** | 影响值≥1 | **全部区域**：下城2VP、核心3VP、上城4VP、博物馆5VP |
| **2** | 影响值≥2 | **核心**3VP、**上城**4VP、**博物馆**5VP（下城1VP❌） |
| **3** | 影响值≥3 | **上城**4VP、**博物馆**5VP（核心2VP❌，下城1VP❌） |
| **4** | 影响值≥4 | **博物馆**5VP（上城3VP❌，核心2VP❌，下城1VP❌） |

各等级的最优策略：

| 等级 | 最优目标 | 单次得分 | 作案周期 | 12轮次数 | 0被捕毛得分 |
| - | - | - | - | - | - |
| **1** | 核心(IP=3, 3VP) 或上城(IP=4, 4VP) | 3-4VP | 2.5-3回合 | 4-5次 | 12-16VP |
| **2** | 核心(IP=3, 3VP) 或上城(IP=4, 4VP) | 3-4VP | 2.5-3回合 | 4-5次 | 12-16VP |
| **3** | 上城(IP=4, 4VP) | 4VP | 3回合 | 4次 | 16VP |
| **4** | 博物馆(IP=5, 5VP) | 5VP | 3.5回合 | 3次 | 15VP |

> **关键特点**：等级1/2选择多（可去核心或上城）；等级3选择少（仅上城/博物馆）；等级4选择唯一（仅博物馆）。

### 5.5 证据Token与抓捕机制

#### 证据与逮捕的核心逻辑

1. **每次作案留1个证据** → 作几次案就有几个证据Token在版图上
2. **警长侦查** → 花费地点IP值的情报，获得1个证据Token
3. **警长抓捕** → 消耗手中全部该罪犯的证据Token + 2AP → 罪犯入狱
4. **入狱效果** → 所有证据Token进看守所 → 出狱后返回角色供应堆

#### 各等级的被捕难易度分析

| 等级 | 12轮作案次数 | 版图证据量 | 侦查成本 | 警长抓捕激励 | **综合被捕概率** |
| - | - | - | - | - | - |
| **1** | 4-5次 | **中等偏多（4-5个）** | 核心3IP=低 | 1VP = **极低激励** | ✅ **低**。警长花5-6AP只换1VP，不值得优先追 |
| **2** | 4-5次 | **中等偏多（4-5个）** | 核心3IP或上城4IP | 2-3VP = **中等激励** | ⚠️ **中**。值得抓但IP成本不低 |
| **3** | 3-4次 | **较少（3-4个）** | 上城4IP=高 | 3-4VP = **较高激励** | ⚠️ **偏低**。侦查贵、证据少，抓一次要投入6-7AP |
| **4** | 3次 | **最少（3个）** | 博物馆5IP=最高 | 4-5VP = **最高激励** | ⚠️ **最低**。侦查最贵、证据最少，抓一次投入7-8AP |

**关键推论**：

- 等级1作4-5次案留下4-5个证据，看似最容易抓，但**警长抓他只得1VP**——效率极低，警长不会优先追
- 等级2/3/4的侦查成本递增、证据量递减——**每次作案的单次风险在降低**
- 等级4（博物馆）侦查费5IP，全流程成本7-8AP——占警长24AP的三分之一，警长抓一次就得大出血
- **实际被捕概率并非"高等级更容易被捕"，而是相反——高等级更难被抓**

### 5.8 当前0技能得分效率总结

| 阵营 | 最佳发挥 | 普通发挥 | 被捕损失 |
| - | - | - | - |
| 罪犯等级1 | 15-16VP | **12VP**（0被捕） | 被捕1次→9VP |
| 罪犯等级2 | 15-16VP | **12VP**（0被捕） | 被捕1次→3-6VP |
| 罪犯等级3 | 15-16VP | **12VP**（0被捕） | 被捕1次→0-4VP |
| 罪犯等级4 | 15VP | **10-15VP**（0被捕） | 被捕1次→-5~0VP |
| **警长** | **17-20VP** | **10-13VP** | — |

**关键发现**：

1. **0被捕状态下所有等级罪犯的普通得分接近（10-15VP）**——等级1的核心3VP×4=12VP，等级3的上城4VP×3=12VP，等级4的博物馆5VP×2-3=10-15VP。差距没有之前想的那么大。
2. **等级4波动最大**（10-15VP→-5~0VP）——一旦被捕几乎出局。这是高风险高回报的设计特征。
3. **等级2被捕损失最大**（关2轮+性价比最高目标）——被捕后从12VP跌到3-6VP，跌幅最大。
4. **警长普通（10-13VP）与所有等级0被捕罪犯在同一范围**——警长需要主动出击才能得分，而罪犯只要安心作案就能自然得分。

> ⚠️ 以下技能收益预期基于当前规则书数值。规则书修改后需重新计算。

基于以上基线，各等级需要技能补足的差距：

| 等级 | 0技能普通(0被捕) | 含技能应达 | 技能需补 | 技能收益定位 |
| - | - | - | - | - |

**核心设计目标（含技能+策略牌后）**：

- **所有等级的最佳发挥应接近15-18VP**（可突破15VP提前结束）
- **等级1攻击防守平衡**（基础分稳，技能补充少但安全）
- **等级2防御价值高**（被捕损失最大，防御/反制类技能的战略弹性大）
- **等级3偏向安全得分**（减少暴露风险的技能，如双面人的金融犯罪）
- **等级4保护机制优先**（被捕一次就出局，需要有免死/保护类技能补偿）
- **警长维持控制力**（基础已够15VP，不需要大幅加强得分）

## 7. 技能收益基准

### 7.1 核心原则

**技能的效率不应显著高于基础行动的效率**，否则玩家会优先使用技能而非基础行动——但超级英雄和受害者例外，他们没有基础得分手段。

```
基础得分效率参考：
  作案（核心）：3AP+3IP+1证据 → 2VP ≈ 0.67 VP/AP
  作案的AP+IP投入 ≈ 5-6个资源单位 → 2VP

技能的成本收益应在同等量级，或略低（因为技能通常有更高灵活性）
```

### 7.2 技能成本收益建议表

| 成本类型 | 总资源成本 | 建议合理收益范围 | 说明 |
| - | - | - | - |
| ➡️ + 0IP | ≈1AP | 0.5-1VP 或 1-2IP | 相当于半次调查的收益 |
| ➡️ + 1IP | ≈2AP | 0.5-1.5VP 或 2-3IP | 略高于调查的纯资源收益 |
| ➡️➡️ 重大 | ≈2AP | 1.5-3VP | 重大消耗，应有高回报 |
| ⚡️ + 0IP | ≈0AP | 极低，纯触发福利 | 不能直接产生大局影响 |
| ⚡️ + 1IP | ≈1AP | 0-0.5VP | 不占行动的优势本身是价值 |
| ↩️ + 1-2IP | ≈1-2AP | 避免等量损失 | 成本≈避免的损失量级 |
| 被动 | ≈0AP | 0.3-0.5VP/轮 | 长期积累，每轮不应过高 |

### 7.3 ↩️ 技能评估方法

↩️ 技能的"避免等量损失"，评估时应区分三种情形：

| 情形 | 说明 | 例 |
| - | - | - |
| **避免自身损失** | 自己避免了资源/回合损失 | 金蝉脱壳：避免自己被捕 |
| **保护他人** | 让队友避免损失，非直接得分 | 见风使舵：保护任意角色 |
| **打断对方投入** | 让对方之前投入的资源作废 | 暗度陈仓：消除证据重置警长积累 |

↩️ 收益上限应由**使用次数限制**来平衡，而非直接超模判断。

### 7.4 超级英雄/受害者技能评估

超级英雄和受害者无基础得分手段，纯靠技能（与原则4"技能效率≤基础效率"冲突时例外）：

- 技能每次使用应有 **1-2VP 产出**
- 若技能以控制/信息为主而非直接得分，应有明确的得分补充途径

### 7.5 等级与技能收益对应关系

**指导原则**：犯罪等级越低，基础得分效率越高，技能收益应**略低于**基准表上限；犯罪等级越高，基础得分效率越低，技能收益可以**接近或达到**基准表上限。

| 犯罪等级 | 基础得分特征 | 技能收益定位 |
| - | - | - |
| **1** | 得分效率最高（全部区域均可触发超额+1），被捕风险最低（1轮） | 技能收益应**低于**基准中位线。防御/控制类技能需附加次数限制 |
| **2** | 得分效率中等，被捕风险标准（2轮） | 技能收益以**基准中位线**为准 |
| **3** | 得分效率偏低，被捕风险高（隐藏值2） | 技能收益可达到基准**上限** |
| **4** | 得分效率最低（隐藏值2+被捕4轮） | 技能收益可**高于**基准上限，高风险需高回报补偿 |

## 8. 审查输出格式

### 8.1 问题优先级

| 优先级 | 含义 | 处理建议 |
| - | - | - |
| 🔴 高 | 设计缺陷——严重影响游戏体验或平衡 | 必须在当前阶段修复 |
| 🟡 中 | 潜在问题——可能导致不平衡或体验不佳 | 建议在当前阶段修复，或标记为测试阶段重点观察 |
| 🟢 低 | 可优化项——不影响核心体验 | 可延后处理，或不处理 |

### 8.2 审查报告模板

每项审查结果应包含：

```
## [审查分类]

### 审查对象：[被审查的文档/机制/角色]

| # | 问题 | 优先级 | 说明 | 建议 |
| - | - | - | - | - |
| 1 | 简要描述问题 | 🔴/🟡/🟢 | 细节分析 | 修改方向 |

**技能强度分布总结**：

🟡 超模风险组：
  - ...

✅ 合理组：
  - ...

⚠️ 偏弱组：
  - ...
```

### 8.3 总体判断

审查最后应给出总体判断：

| 结果 | 含义 |
| - | - |
| ✅ **通过** | 未发现 🔴 问题，🟡 问题 ≤ 3个 |
| ⚠️ **有条件通过** | 发现 ≥ 1个 🔴 问题，或 🟡 问题 > 3个，需修复后重审 |
| ❌ **不通过** | 发现 ≥ 3个 🔴 问题，或存在根本性设计缺陷 |
