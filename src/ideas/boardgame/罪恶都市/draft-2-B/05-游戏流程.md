# 方案 2-B · 游戏流程框架

> 方案 B：参考 refs/initial-gpt.md + refs/user-ideas-2-B.md

## 一、游戏准备流程

### 步骤 1：选择角色与阵营

根据玩家人数按以下配置分配角色：

| 玩家人数 | 警长 | 罪犯 | 第三方 | 说明 |
|----------|------|------|--------|------|
| **2 人** | 1 人 | 1 人（+2 虚拟罪犯） | 无 | 最简配置，适合教学局 |
| **3 人** | 1 人 | 2 人（+1 虚拟罪犯） | 无 | 轻度推理局 |
| **4 人** | 1 人 | 3 人 | 无 | **基准配置**，推荐首次体验 |
| **5 人** | 1 人 | 3 人 | 1 人（超级英雄或受害者联盟） | 完全体，含第三方变数 |

角色分配流程：

1. 首先确认谁愿意担任**警长**（如无人自愿则随机指定）
2. 剩余玩家从罪犯职业池中公开选择职业（角色公开）
3. 5 人局时，最后一名玩家从超级英雄和受害者联盟中二选一

### 步骤 2：构建城市

1. 从地点牌池（22 张）中**随机抽取 12 张**
2. 按 **3×4** 排列在桌面中央，构成"城市版图"
3. 所有玩家确认地名牌的位置和效果

### 步骤 3：设置游戏组件

| 组件 | 设置方式 |
|------|----------|
| **治安值** | 设置为 10，使用轨道标记 |
| **民意值** | 设置为 5，使用轨道标记 |
| **恐慌值** | 设置为 0，使用轨道标记 |
| **分数轨道** | 所有玩家标记放在 0 位置 |
| **线索 token** | 放入公用池（警长专用） |
| **情报 token** | 放入公用池 |
| **赃物 token** | 放入公用池 |
| **踩点标记** | 待用，与罪犯数量匹配 |
| **通用牌库** | 洗牌后面朝下放置 |

### 步骤 4：分发起始手牌

- 所有玩家从通用牌库摸 **5 张**起始手牌
- 警长额外获得 2 张 **警官牌**（从警官牌池中抽 2 张）
- 如有虚拟罪犯，不拿手牌

### 步骤 5：设置虚拟罪犯（仅 2-3 人局）

- 在 3 张随机地名牌上各放置 1 个虚拟线索 token
- 记录本局使用的虚拟罪犯行为模式（见 04-角色设计.md 虚拟罪犯机制）

### 步骤 6：确定首个夜晚的起始玩家

- 第一回合起始玩家：**随机指定**
- 后续回合起始玩家：**当前分数最低的玩家**
- 同分时按逆时针顺序

## 二、回合阶段总览（每个夜晚）

每个夜晚严格按以下 5 阶段顺序执行：

```
① 准备阶段 → ② 宣告阶段 → ③ 揭露阶段 → ④ 调查阶段 → ⑤ 结算阶段
```

### 每回合时间预算（4 人局）

| 阶段 | 预估时间 | 说明 |
|------|---------|------|
| ① 准备阶段 | 1-2 分钟 | 翻开事件牌、补牌 |
| ② 宣告阶段 | 3-5 分钟 | 所有玩家同时秘密出牌 |
| ③ 揭露阶段 | 8-12 分钟 | 按顺序结算每位玩家行动（核心耗时环节） |
| ④ 调查阶段 | 3-5 分钟 | 警长专属阶段（推进嫌疑链、关押） |
| ⑤ 结算阶段 | 1-2 分钟 | 更新城市状态 |
| **合计** | **约 16-26 分钟/回合** | 10 回合总计约 160-260 分钟 |

## 三、阶段 ①：准备阶段

### 3.1 翻开事件牌

从事件牌堆顶部翻开 **1 张事件牌**，其效果影响本回合全局。

**事件牌示例**（10 张）：

| 事件 | 效果 | 叙事描述 |
|------|------|----------|
| **暴雨** | 所有犯罪成本 +1 情报 | "暴雨冲刷着街道，犯罪痕迹被掩盖，也增加了行动的难度" |
| **节日庆典** | 警长本回合 +1 行动力 | "全城狂欢，警力也趁机加强了部署" |
| **大停电** | 上城区地名牌效果暂停一回合 | "黑暗笼罩了城市的中心" |
| **市长讲话** | 民意值 +1 | "市长在电视上承诺加强治安" |
| **媒体曝光** | 所有罪犯暴露度 +1 | "某记者揭露了警方腐败内幕，市民对警方失去信心" |
| **暴动** | 恐慌值 +1，所有地名牌警戒值 -1 | "愤怒的市民走上街头" |
| **警队增援** | 警长额外获得 1 张警官牌 | "州警局派来了支援" |
| **黑市开放** | 所有罪犯本回合犯罪成本 -1 | "地下世界迎来了一场大交易" |
| **国际会议** | 超级英雄声望获取 +1（仅 5 人局） | "全球目光聚焦在这座城市" |
| **午夜钟声** | 本回合暴露度变化翻倍 | "午夜的钟声敲响，一切都被放大了" |

### 3.2 补牌

- 所有玩家从通用牌库摸牌至手牌上限（默认 5 张）
- 部分角色技能可在此时触发（如毒贩的"腐蚀"准备）

### 3.3 虚拟罪犯放置（2-3 人局）

- 按虚拟罪犯放置规则在指定地名牌放置虚拟线索 token

## 四、阶段 ②：宣告阶段（核心博弈）

### 4.1 秘密选择流程

所有玩家同时秘密选择以下三项，记录在各自的**行动板**上：

```
┌─────────────────────────────────────┐
│        玩家 [姓名] 的第 N 回合行动      │
│                                       │
│  目标地点：_________（从 12 张中选 1 张） │
│  行动牌：   _________（从手牌中打 1 张） │
│  发动技能： □ 是（消耗_______） □ 否  │
└─────────────────────────────────────┘
```

1. **选择目标地点**：从中央 12 张地名牌中选择一张作为本回合行动地点
2. **打出行动牌**：从手牌中选择一张行动牌，面朝下放置
3. **发动角色技能**（可选）：决定是否发动角色专属技能，消耗对应的资源

### 4.2 宣告规则

- 所有玩家选择完毕后，同时揭露
- **揭露顺序**：当前分数最低的玩家先揭露（同分按逆时针顺序）
- 揭露后不可更改

### 4.3 宣告阶段的策略维度

| 考量维度 | 说明 |
|----------|------|
| **地点选择** | 选择高收益但高风险的地点，还是低风险但低收益的地点 |
| **牌的选择** | 打出一张强牌但暴露战术意图，还是保留强牌打普通牌 |
| **技能发动** | 消耗有限资源发动技能，还是保留资源为后续回合做准备 |
| **心理博弈** | 预测警长会在哪个地点部署警官，反向选择"最安全"的地点 |

## 五、阶段 ③：揭露阶段

### 5.1 通用结算顺序

按揭露顺序依次结算每位玩家。一个玩家的行动完全结算完毕后才结算下一个玩家。

### 5.2 罪犯行动结算（基于成本机制）

**犯罪行动无概率判定**，基于资源消耗结算：

```
罪犯揭露行动
  │
  ├─ ① 检查目标地点的警官牌
  │    ├─ 有巡警   → 犯罪成本 +1 情报
  │    ├─ 有特警   → 犯罪成本 +2 情报
  │    ├─ 有刑警   → 犯罪后额外产生 1 线索 token
  │    └─ 有卧底   → 警长可查看该罪犯手牌 1 张
  │
  ├─ ② 计算犯罪总成本
  │    ├─ 基础成本（盗窃 1 / 抢劫 2 / 杀人 3 / 诈骗 1 / 贩毒 2）
  │    ├─ 警官牌加成（巡警 +1、特警 +2）
  │    ├─ 警戒值加成（Lv.2 +1、Lv.3 +2）
  │    ├─ 嫌疑链加成（Lv.3+ +1）
  │    └─ 事件影响（如暴雨 +1）
  │
  ├─ ③ 罪犯支付成本
  │    ├─ 优先消耗情报标记
  │    ├─ 资源不足 → 赊账（1 暴露度 = 1 情报，暴露度加倍上升）
  │    └─ 也可选择放弃行动（不支付、不犯罪）
  │
  ├─ ④ 支付完成 → 犯罪成功
  │    ├─ 获得赃物/分数（根据犯罪类型）
  │    ├─ 在地名牌上放置 1 线索 token
  │    ├─ 暴露度上升（盗窃+1、抢劫+2、杀人+3 等）
  │    └─ 触发被动技能（如有）
  │
  └─ ⑤ 超级英雄"出击"检查
       └─ 若超级英雄已在该地点出击 → 犯罪无效，已支付资源退还
```

**详细收益表**：

| 犯罪类型 | 基础情报成本 | 基础收益 | 暴露度增加 |
|----------|------------|---------|-----------|
| 盗窃 | 1 | 1 赃物 + 1 分 | +1 |
| 抢劫 | 2 | 2 赃物 + 2 分 | +2 |
| 行凶（杀人） | 3 | 3 分 + 恐慌值 +2 | +3 |
| 诈骗 | 1 | 1 分 + 1 假线索 | +0~+1 |
| 贩毒 | 2 | 2 赃物 + 1 分 | +1~+2 |

### 5.3 警长行动结算

警长在揭露阶段的行动选项（需消耗行动力）：

| 行动 | 行动力消耗 | 效果 |
|------|-----------|------|
| **巡逻布控** | 1 | 选择一张地名牌，本回合该地点警戒值 +1。若该地点有罪犯活动，该罪犯暴露度 +1 |
| **任命警官** | 1 | 从手牌打出一张警官牌，部署到目标地名牌（仅本回合有效） |
| **收集线索** | 1 | 从目标地名牌收集已存在的线索 token（每地点最多 1 个/回合） |
| **逮捕** | 2 | 指定一名罪犯发起逮捕（需嫌疑链 5 级或暴露度 ≥ 5） |

**警长行动限制**：

- 每回合总行动力受民意值影响（4/3/2/1）
- 逮捕失败（被抵抗）后本回合不可再次逮捕
- 同一地名牌本回合只能巡逻布控 1 次

### 5.4 超级英雄行动结算（5 人局）

| 行动 | 消耗 | 效果 |
|------|------|------|
| **出击** | 2 行动力 | 阻止目标地名牌本回合的犯罪（罪犯行动无效，资源退还），英雄得 +1 分 |
| **私刑** | 2 行动力 | 夺取暴露度 ≥ 3 的罪犯的 2 情报/赃物，恐慌值 +1，英雄得 +1 分。**不淘汰玩家** |
| **媒体宣传** | 1 行动力 | 声望 +1；如本回合阻止了犯罪则额外 +1 |
| **快速移动** | 1 行动力 | 检视任一罪犯的本回合宣告行动（查看其目标地点） |

### 5.5 受害者联盟行动结算（5 人局）

| 行动 | 消耗 | 效果 |
|------|------|------|
| **舆论** | 1 影响力 | 民意值 -1；民意值 ≤ 3 时所有罪犯暴露度 +1 |
| **游行** | 2 影响力 | 民意值 -2，警长下回合行动力 -1，得 +1 分 |
| **悬赏** | 2 影响力 | 指定一名罪犯持续 2 回合——警长推进该罪犯嫌疑链消耗减半，英雄出击免费 |
| **复仇** | 3 影响力 | 目标罪犯损失 3 情报/赃物，恐慌值 +1，得 +2 分。**不淘汰玩家** |

## 六、阶段 ④：调查阶段（警长专属）

### 6.1 调查阶段概览

本阶段仅警长行动，其他玩家不可干预。

### 6.2 警长调查行动

| 行动 | 消耗 | 效果 | 可执行次数 |
|------|------|------|-----------|
| **收集线索** | 1 行动力 | 从一张地名牌收集所有未收集的线索 token | 每回合最多 3 次 |
| **推进嫌疑链** | 1 行动力 + 消耗线索 | 推进某个指定罪犯的嫌疑链等级 | 每回合最多推进 1 个罪犯 |
| **发起逮捕** | 2 行动力 | 对嫌疑链 5 级或暴露度 ≥ 5 的罪犯发起逮捕 | 每回合最多 1 次 |

### 6.3 逮捕与关押详细规则

逮捕是警长最重要的行动。**逮捕不淘汰玩家，改为关押。**

```
发起逮捕
  │
  ├─ 检查条件
  │    ├─ 目标罪犯嫌疑链 ≥ 5 级 → ✅ 可逮捕
  │    ├─ 目标罪犯暴露度 ≥ 5 → ✅ 可逮捕
  │    └─ 两者都不满足 → ❌ 不能逮捕
  │
  ├─ 罪犯可消耗 2 情报标记抵抗逮捕
  │    ├─ 消耗抵抗 → 逮捕失败，警长本回合不能再逮捕
  │    └─ 不抵抗或资源不足 → 逮捕成功
  │
  ├─ 逮捕成功 → 进入关押状态
  │    ├─ 关押持续 1-2 回合（由警长选择）
  │    ├─ 关押期间罪犯不能行动（跳过回合）
  │    ├─ 警长得 +2 分（逮捕一次性）
  │    └─ 警长每回合从关押中获得 +1 分
  │
  └─ 触发审讯（被动）
       └─ 警长获得 1 情报标记
```

### 6.4 关押与越狱流程

**关押状态**：

- 被关押罪犯的回合被跳过
- 其他玩家正常行动
- 关押持续 1-2 回合后自动释放

**越狱（罪犯在自己的回合选择）**：

- 消耗：2 情报 + 1 赃物
- 效果：立即解除关押状态，暴露度 +2
- 越狱后本回合不能继续行动
- 暴力越狱（可选）：不消耗资源但暴露度 +4

**协助越狱**：

- 其他罪犯可协助支付部分越狱成本，协助者暴露度 +1
- 超级英雄可"劫狱"（消耗 2 行动力释放被关押罪犯，声望 +1，恐慌值 +1）

### 6.5 嫌疑链推进机制

警长通过消耗线索 token 推进某个罪犯的嫌疑链等级：

| 嫌疑等级 | 需要累计线索 | 对罪犯的影响 | 暴露度辅助 |
|----------|------------|-------------|-----------|
| 1 级 | 1 个 | — | — |
| 2 级 | 2 个 | — | — |
| 3 级 | 3 个 | 犯罪成本 +1 情报，收益 -1 | 暴露度 2-3 时消耗减半 |
| 4 级 | 4 个 | 犯罪成本 +2 情报，收益 -1 | 暴露度 4 时消耗减半 |
| 5 级 | 5 个 | 可直接发起逮捕 | 暴露度 5 时无需此条件 |

## 七、阶段 ⑤：结算阶段

### 7.1 城市状态更新

| 状态值 | 上升条件 | 下降条件 |
|--------|----------|----------|
| **治安值** | 关押罪犯 +1/回合；整回合无犯罪 +1 | 犯罪成功 -1~-3（视类型） |
| **民意值** | 逮捕 +1；治安值 ≥ 8 +1 | 游行 -2；恐慌事件 -1 |
| **恐慌值** | 凶杀 +2；抢劫 +1；私刑 +1；复仇 +1 | 关押罪犯 -1/次 |

### 7.2 地名牌状态更新

| 更新项目 | 规则 |
|----------|------|
| **警戒值** | 发生犯罪的地名牌 +1（上限 3）；警长逮捕成功 -1；连续两回合无事件 -1 |
| **踩点标记** | 该地点发生犯罪后，已有的踩点标记移除 |
| **警官牌** | 持续到本回合结束，自动移除（除非有"持续"关键词且警长支付了维持费） |

### 7.3 弃牌与手牌管理

- 所有玩家检查手牌数量，超过上限（5 张）的部分弃置
- 本回合打出的事件牌、行动牌、NPC 牌等进入弃牌堆
- 通用牌库耗尽时，洗混弃牌堆形成新牌库

### 7.4 分数组件检查

- 检查是否有玩家达到目标分数（15-20 分）
- 如有 → 游戏立即结束，该玩家所在阵营获胜
- 如无 → 进入下一回合
- 第 10 夜结束后，进入最终判定

## 八、游戏结束触发条件

### 8.1 跑分结束条件

**任何玩家达到目标分数（15-20 分）→ 游戏立即结束**：

```
有人达到目标分数
  │
  ├─ 警长分数最高 → 警长胜利（秩序维护）
  ├─ 罪犯中有人分数最高 → 该罪犯胜利（犯罪帝王）
  ├─ 超级英雄分数最高 → 城市英雄胜利
  └─ 受害者联盟分数最高 → 民粹胜利
```

### 8.2 第 10 夜最终判定

第 10 夜结束时若无人达到目标分数：

```
第 10 夜结算完毕
  │
  ├─ 治安值 ≥ 8 → 警长胜利（治安重建）
  │
  ├─ 治安值 4-7 → 按分数比较，最高者胜
  │
  └─ 治安值 ≤ 3 → 罪犯中分数最高者胜（城市崩溃）
```

### 8.3 完整胜利条件总表

| 阵营 | 胜利条件 | 判定时机 |
|------|----------|----------|
| 警长 | 警长分数最高且达到目标分数 | 即时跑分 |
| 罪犯 | 某罪犯分数最高且达到目标分数 | 即时跑分 |
| 超级英雄 | 超级英雄分数最高且达到目标分数 | 即时跑分 |
| 受害者联盟 | 受害者联盟分数最高且达到目标分数 | 即时跑分 |
| 警长 | 第 10 夜治安 ≥ 8 | 最终判定 |
| 罪犯 | 第 10 夜治安 ≤ 3 | 最终判定 |
| 任意 | 第 10 夜治安 4-7，分数最高者胜 | 最终判定 |

## 九、特殊情况处理

### 9.1 无玩家出局规则

- **任何行动都不能让玩家提前出局**
- 被逮捕的罪犯进入**关押状态**（1-2 回合不能行动），而非出局
- 关押结束后罪犯继续游戏
- 超级英雄的"私刑"改为夺取资源而非击败玩家
- **所有玩家全程参与，无人旁观**

### 9.2 关押状态交互

- 关押中的罪犯不能宣告行动，不能犯罪，不能使用技能
- 可以消耗资源进行越狱
- 关押自动解除后，罪犯下回合恢复正常行动

### 9.3 通用牌库耗尽

- 牌库耗尽时，将弃牌堆洗混作为新牌库
- 如弃牌堆也为空，玩家不再补牌

### 9.4 平局

- 最终分数平局时，按罪犯 > 超级英雄 > 受害者联盟 > 警长的优先级判定
- 同一阵营内平局时，共同获胜

## 十、速查表

### 10.1 每回合执行清单

```
□ ① 准备阶段
   □ 翻开 1 张事件牌，宣布效果
   □ 所有玩家补牌至手牌上限（5 张）
   □ 虚拟罪犯放置线索（2-3 人局）

□ ② 宣告阶段
   □ 所有玩家秘密选择：目标地点 + 行动牌 + 技能发动
   □ 所有玩家同时揭露（按分数从低到高顺序）

□ ③ 揭露阶段
   □ 按揭露顺序依次结算每位玩家
   □ 罪犯：检查警官 → 计算成本 → 支付情报 → 犯罪成功
   □ 警长：巡逻布控 / 任命警官 / 收集线索
   □ 超级英雄：出击（阻止犯罪） / 私刑（夺资源）/ 媒体宣传
   □ 受害者联盟：舆论 / 游行 / 悬赏 / 复仇

□ ④ 调查阶段（警长专属）
   □ 警长收集线索 → 推进嫌疑链
   □ 嫌疑链 5 级或暴露度 ≥ 5 → 发起逮捕 → 关押 1-2 回合
   □ 被关押罪犯可消耗资源越狱

□ ⑤ 结算阶段
   □ 更新治安值、民意值、恐慌值
   □ 更新地名牌警戒值、踩点标记、警官牌（自动移除）
   □ 弃牌至手牌上限
   □ 检查是否有玩家达到目标分数（15-20 分）
   □ 进入下一回合（或进行最终判定）
```

### 10.2 游戏结束判定流程图

```
是否有人达到目标分数（15-20 分）？
  │
  ├─ 是 → 该玩家阵营获胜
  │     ├─ 警长分数最高 → 秩序维护
  │     ├─ 罪犯分数最高 → 犯罪帝王
  │     ├─ 超级英雄最高 → 城市英雄
  │     └─ 受害者最高 → 民粹胜利
  │
  └─ 否 → 第 10 夜结束判定
         ├─ 治安 ≥ 8 → 警长胜利
         ├─ 治安 ≤ 3 → 罪犯中分数最高者胜
         └─ 治安 4-7 → 分数最高者胜
```
