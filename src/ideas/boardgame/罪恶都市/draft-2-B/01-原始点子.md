## 一句话概念（30 字以内）

> 通用牌库的卡牌警匪对决，罪犯踩点发育，警长推理追捕。

---

## 核心卖点（3-5 个关键词）

| 关键词 | 说明 |
|--------|------|
| **纯卡牌驱动** | 无棋盘无棋子，所有交互通过卡牌完成。城市由中央展示区的地名牌构成 |
| **通用牌库** | 同一张卡在不同角色手中效果完全不同，差异化体现在人物技能上 |
| **罪犯发育** | 踩点→积累资源→策划犯罪，形成完整的成长弧线 |
| **推理追捕** | 线索层层递进，警长逐步缩小嫌疑范围，堪比《开膛手杰克》的推理感 |
| **城市状态演变** | 每个地名牌带有特殊效果，连续犯罪或长期安全会使城市发生变化 |

---

## 目标体验

玩家经历一部完整的警匪剧：

- **罪犯玩家**体验"从街头混混到犯罪帝王"的成长——前期低调踩点积累情报，中期在最适合的地点策划犯罪，后期在警方围剿中争夺唯一胜出的机会。
- **警长玩家**体验"从迷雾重重到真相大白"的推理——通过线索 token 逐步缩小嫌疑范围，在城市治安崩盘前逮捕真凶。
- **超级英雄**体验"天降正义"的爽感——哪里出事飞去哪里，在警方和罪犯之间左右逢源。
- **受害者联盟**体验"民粹力量"——通过舆论和群众行动影响城市走向。

每个夜晚的出牌与博弈扣人心弦，结局往往出人意料。

## 与方案方向说明的关联

本方案完整遵循方案 B 的方向要求：

| 要求 | 实现方式 |
|------|----------|
| **纯卡牌驱动** | 完全移除版图和棋子，城市由中央展示区的随机地名牌构成，所有交互通过手牌执行 |
| **通用牌库** | 警长与罪犯共用同一牌库，差异化体现在人物技能上（如"线人"牌警长多抽牌、罪犯隐藏身份） |
| **罪犯发育链条** | 踩点→线索→犯罪：前期踩点在地名牌留下线索 token 获得情报资源，后期消耗资源提升犯罪成功率 |
| **推理与隐藏信息** | 罪犯行动后在地点留下线索 token，警长通过线索逐步缩小嫌疑人范围 |
| **异步回合节点** | 每回合一个"夜晚"，玩家依次出牌并指定目标地名牌，形成"谁在何时在哪里"的不完全信息博弈 |
| **虚拟罪犯机制** | 2-3 人局引入虚拟罪犯，自动按固定模式在地名牌放置线索 token，保持推理链条完整 |
| **NPC 卡牌化** | NPC 是手牌中的一次性卡牌，打出后弃置，文字描述决定效果 |
| **Token 体系简化** | 仅保留分数标记、线索标记、赃物标记、情报标记、踩点标记，均用于计数 |
