## 卡牌设计总则

### 命名规范

- 卡牌编号：`[阵营]-[序号]`（如 `S-01`）
- 阵营缩写：S = 警长（Sheriff）, C = 罪犯（Criminal）, P = 魅影（Phantom）, V = 受害者联盟（Victim）
- 特殊技编号以 `-09`、`-10` 结尾

### 效果文本格式

```
【卡牌名】（类型）
效果：正面效果描述
Flavor：「背景引文」
编号：#XX
```

### 关键术语

| 术语 | 说明 |
|------|------|
| **暗投** | 牌面朝下投入一个活跃地点的堆叠区顶部 |
| **结算** | 牌被揭示后执行效果 |
| **暗流分** | 统一胜利分数，达到 10 点即获胜 |
| **AP** | 行动点，每回合 2 点 |
| **LIFO** | 后进先出结算顺序 |
| **连锁** | 一张牌结算时触发的额外结算链 |
| **爆发** | 倒计时归零时强制触发的地点半结算 |
| **冷却** | 地点爆发后的不可用状态（1 轮） |
| **堆叠区** | 地点上堆放暗投卡牌的区域 |

> **设计理念**：所有卡牌效果追求"一句话说清楚"——不超过两行效果文本。详细连锁规则在规则书中说明，卡牌上只写触发条件和基础效果。

## 一、🛡️ 警长牌库（27 张）

### S-01 日常巡逻（巡逻 × 4）

```
【日常巡逻】（巡逻）
暗投 → 如果此牌所在地点在本回合被触发，你抽 1 张牌。
「每一条街我都走过一百遍。」
编号：S-01
```

### S-02 突击巡逻（巡逻 × 3）

```
【突击巡逻】（巡逻）
结算 → 你抽 1 张牌。如果连锁次数 ≥ 2，再抽 1 张。
「跑得快不如到得巧。」
编号：S-02
```

### S-03 深入调查（卧底 × 3）

```
【深入调查】（卧底）
结算 → 查看该地点堆叠区所有牌。你可以选择其中 1 张罪犯牌，将其放回所有者手牌。
「他们的计划都写在墙上了。」
编号：S-03
```

### S-04 线人情报（卧底 × 3）

```
【线人情报】（卧底）
结算 → 查看该地点堆叠区所有牌。获得 1 点声望。
「线人费可不能省。」
编号：S-04
```

### S-05 战术突袭（突袭 × 3）

```
【战术突袭】（突袭）
结算 → 移除该地点堆叠区最底部的 1 张牌（放回其所有者弃牌堆）。如果移除的是罪犯牌，获得 1 暗流分。
「破门而入，不留活口。」
编号：S-05
```

### S-06 区域封锁（封锁 × 3）

```
【区域封锁】（封锁）
暗投 → 此牌所在地点的倒计时在本回合结束阶段不减。
「封锁现场，一只苍蝇也别想飞出去。」
编号：S-06
```

### S-07 强力镇压（镇压 × 3）

```
【强力镇压】（镇压）
结算 → 此地点每有 1 张罪犯牌，该罪犯玩家失去 1 点黑市资源（最多 5 点）。
「这里我说了算。」
编号：S-07
```

### S-08 市民安抚（安抚 × 3）

```
【市民安抚】（安抚）
结算 → 此地点倒计时 +2（不超过 6）。获得 1 点镇静剂（不超过上限）。
「别慌，警察来了。」
编号：S-08
```

### S-09 铁腕手段（特殊技 × 1）

```
【铁腕手段】（特殊技·每局限 1 次）
<条件>任意地点即将爆发时（倒计时归零瞬间）
效果 → 终止该地点的爆发结算，将所有堆叠牌放回所有者手牌。获得 2 暗流分。
「够了。这座城市由我守护。」
编号：S-09
```

### S-10 紧急调度（专属·调度 × 1）

```
【紧急调度】（调度·每局限 1 次）
<条件>你的回合行动阶段
效果 → 本回合 AP +1（可以执行 3 次行动）。使用后弃掉此牌。
「各单位注意，目标地点有异动！」
编号：S-10
```

## 二、💀 罪犯牌库（27 张，各罪犯独立）

### C-01 捞一笔（捞金 × 4）

```
【捞一笔】（捞金）
结算 → 获得 = 此地点堆叠牌数量 的黑市资源（上限 5）。
「来得早不如来得巧。」
编号：C-01
```

### C-02 大买卖（捞金 × 3）

```
【大买卖】（捞金）
结算 → 获得 3 点黑市资源。如果此地点堆叠牌数 ≥ 4，再获得 2 点。
「这单干完，够吃三年。」
编号：C-02
```

### C-03 设伏陷阱（陷阱 × 3）

```
【设伏陷阱】（陷阱）
暗投 → 指定一个触发条件（如"当警长在此地设伏时""当此地点被触发时"）。条件满足时结算：
效果 → 对触发者产生 1 项：失去 2 点专属资源 / 弃 1 张手牌 / 此牌返回你的手牌。
「等鱼上钩。」
编号：C-03
```

### C-04 背刺计划（背刺 × 3）

```
【背刺计划】（背刺）
结算 → 选择此地点堆叠区中任意 1 张非自己的牌，将其移除（放回所有者弃牌堆）。你获得该牌所有者的 2 点资源（如无资源则获得 1 暗流分）。
「朋友？在这座城市，朋友就是还没动手的敌人。」
编号：C-04
```

### C-05 假情报单（假情报 × 4）

```
【假情报单】（假情报）
结算 → 无立即效果。此牌被揭示后移入弃牌堆时，你抽 1 张牌（如果是在对方回合被触发，改为抽 2 张）。
「让他们猜去吧。」
编号：C-05
```

### C-06 黑市采购（大采购 × 3）

```
【黑市采购】（大采购）
结算 → 获得 3 点黑市资源，然后弃 1 张手牌。如果此牌在连锁中结算，不需要弃牌。
「只要有钱，什么都有。」
编号：C-06
```

### C-07 替罪羊（替罪羊 × 3）

```
【替罪羊】（替罪羊）
结算 → 将此地点堆叠区中 1 张警长牌移到另一地点（你选择目标）。如果无法移动，获得 1 点掩护值。
「总得有人背锅。」
编号：C-07
```

### C-08 暗渡陈仓（专属·藏匿 × 2）

```
【暗渡陈仓】（藏匿）
结算 → 获得 2 点黑市资源。可以选择将此牌移入弃牌堆或放回手牌（如果是后者，跳过结算）。
「明修栈道，暗渡陈仓。」
编号：C-08
```

### C-09 孤注一掷（特殊技 × 1）

```
【孤注一掷】（特殊技·每局限 1 次）
<条件>你的黑市资源 ≥ 15
效果 → 免费触发一个地点（不消耗 AP），且该次结算的连锁上限 +2（变为 7 次）。完成结算后获得 3 暗流分。
「要么赢光，要么死透。」
编号：C-09
```

### C-10 交易筹码（专属·交易 × 1）

```
【交易筹码】（交易·每局限 1 次）
<条件>你的行动阶段
效果 → 弃 1 张手牌，获得 3 点黑市资源。然后你可以将另一张手牌暗投到任意地点（不消耗 AP）。
「情报也是商品。」
编号：C-10
```

## 三、🦸 魅影牌库（27 张）

### P-01 暗流感知（感知 × 4）

```
【暗流感知】（感知）
暗投 → 在结算前你可以随时查看此牌（仅自己可见）。结算时获得 1 点共鸣值。
「暗流在低语。」
编号：P-01
```

### P-02 深度感应（感知 × 3）

```
【深度感应】（感知）
结算 → 获得 1 点共鸣值。查看此地点堆叠区所有牌。
「我看得见暗流中的一切。」
编号：P-02
```

### P-03 紧急救援（救援 × 4）

```
【紧急救援】（救援）
结算 → 拯救此地点 1 名受害者 Token（从供应堆取出放在你的角色卡上）。
如果连锁次数 ≥ 3，额外拯救 1 名。
「让开，我来！」
编号：P-03
```

### P-04 全力救援（救援 × 2）

```
【全力救援】（救援）
结算 → 拯救此地点 2 名受害者 Token。如果你有 ≥ 3 点共鸣值，改为拯救 3 名。
「我必须救出所有人。」
编号：P-04
```

### P-05 暗流共鸣（共鸣 × 3）

```
【暗流共鸣】（共鸣）
结算 → 获得 1 点共鸣值。如果此地点堆叠区有你的其他牌，再获得 1 点共鸣值。
「暗流与我同在。」
编号：P-05
```

### P-06 灵魂引导（引导 × 3）

```
【灵魂引导】（引导）
暗投 → 选择此地点堆叠区中 1 张牌（任意玩家的），标记为"引导目标"。
结算 → 先结算此牌，然后立即结算"引导目标"（无视 LIFO）。
「跟我走。」
编号：P-06
```

### P-07 暗流庇护（庇护 × 3）

```
【暗流庇护】（庇护）
结算 → 选择此地点堆叠区中 1 张牌（可以是自己的），使其免疫"移除""转移""返回手牌"等效果，持续到本回合结束。
「暗流会保护你的。」
编号：P-07
```

### P-08 命运干涉（干涉 × 3）

```
【命运干涉】（干涉）
结算 → 反转此地点即将结算的 1 个负面效果为目标（使其效果目标变为对其所有者生效）。
「我替你挡了这一下。」
编号：P-08
```

### P-09 暗流降临（特殊技 × 1）

```
【暗流降临】（特殊技·每局限 1 次）
<条件>你的回合（任意时刻，包括其他玩家回合）
效果 → 立即选择一个地点，按 LIFO 顺序结算其中所有你的牌（不消耗 AP）。完成结算后获得 3 暗流分。
「暗流，听我号令。」
编号：P-09
```

### P-10 灾厄预兆（专属·预知 × 1）

```
【灾厄预兆】（预知·每局限 1 次）
<条件>任意地点爆发时
效果 → 查看该地点堆叠区所有牌，你可以选择其中 1 张牌拯救 1 名受害者 Token（如果该牌原本会产生受害者则不触发）。
「我看到了……」
编号：P-10
```

【邻里互助】（互助）

## 六、城市地名牌效果（完整版）

### 码头

```
【码头】（下城区）
被动：每被堆叠 1 张牌，产生 1 点黑市资源给该牌的玩家。
爆发：所有堆叠牌结算后，产生 3 点黑市资源平摊给所有有牌在此的玩家。
倒计时：3-6
```

### 警局

```
【警局】（过渡带）
被动：每结算 1 张牌，移除堆叠区最底部的 1 张牌（放回所有者弃牌堆）。
爆发：此地点所有罪犯牌被移除。警长获得 1 暗流分。
倒计时：2-5
```

### 银行

```
【银行】（中心区）
被动：当你主动触发此地时，可以额外翻看堆叠区最底部的 1 张牌。
爆发：所有牌结算后，每个玩家获得 1 暗流分。
倒计时：4-6
```

### 赌场

```
【赌场】（中心区）
被动：在此地点暗投时，你可以额外抽 1 张牌（每回合限 1 次）。
爆发：随机分配堆叠区所有牌的效果目标。
倒计时：2-4
```

### 医院

```
【医院】（过渡带）
被动：每回合 1 次，你可以从弃牌堆回收 1 张牌到手牌（跳过堆叠）。
爆发：拯救 2 名受害者 Token（给魅影，如无魅影则给拥有最多警长牌的玩家）。
倒计时：3-5
```

### 贫民窟

```
【贫民窟】（下城区）
被动：暗投此地的牌可以额外复制此地的 1 张同名的效果（如果有），复制效果在原效果结算后执行。
爆发：产生 3 名受害者 Token，所有玩家可争夺（按结算顺序，先到先得）。
倒计时：1-3
```

### 市政厅

```
【市政厅】（中心区）
被动：触发此地的 AP 费用减少 1（变为 1 AP）。
爆发：警长获得 1 暗流分。如果无警长，改为魅影获得 1 共鸣。
倒计时：5-6
```

### 地铁站

```
【地铁站】（过渡带）
被动：每回合 1 次，你可以将 1 张牌从任意地点转移到另一地点（不揭示）。
爆发：所有牌随机分配到其他地点继续堆叠（不结算）。
倒计时：3-5
```

## 八、设计决策说明

### 1. 统一暗流分框架

根据阶段 1.5 评审建议 **C-1（高优先级）**，将胜利条件重构为统一暗流分系统：

- 所有阵营的行为都产生暗流分
- 达到 10 暗流分即获胜
- 解决阶段 1 中"各玩各的胜利条件"导致的体验割裂

### 2. 倒计时公开可见

根据评审建议 **C-3（高优先级）** 和用户反馈，倒计时从隐蔽改为公开：

- 所有玩家都知道每个地点还有多少回合爆发
- 决策有据可依：不是"猜"，而是"计算"

### 3. 警长被动能力调整

根据评审建议 **C-4（中优先级）**，警长的"执法感知"改为：

- 每回合 1 次免费查看任意 1 张暗投牌（不再限于底部牌）
- 同时保留罪犯的"暗流嗅觉"（查看顶部 1 张）
- 信息更加对称

### 4. 魅影非爆发得分路径

根据评审建议 **C-5（中优先级）**：

- 救援卡牌（P-03/P-04）不依赖爆发也可以使用
- 增加 P-10 灾厄预兆作为爆发时的额外拯救机会
- 共鸣值累进机制（达到 3 点后效果增强）

### 5. 卡牌效果简洁化

根据用户反馈中"知识重比规则重更致命"的判断：

- 每张卡牌效果不超过两行
- 连锁规则统一在规则书中说明，卡牌上不写复杂连锁逻辑
- 使用"暗投→""结算→"前缀明确触发时机
