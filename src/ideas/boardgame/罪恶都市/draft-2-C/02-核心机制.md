## 1. 游戏概览

《暗流涌动》是一款 2-7 人的非对称卡牌对抗游戏。玩家分别扮演**警长**、**罪犯**、**超级英雄**或**受害者联盟**四个阵营，围绕城市地点进行暗投卡牌、堆叠结算、后手反制的心理博弈。

### 核心机制一句话

> **暗投堆叠**——卡牌秘密投入地点牌堆（牌面朝下），按**后进先出（LIFO）** 依次揭示结算。后手拥有信息优势与反制能力。

---

## 2. 核心游戏循环

### 每回合结构

每个玩家回合分为两个阶段：

#### 行动阶段（2 行动点）

| 行动 | 消耗 | 说明 |
|------|------|------|
| **暗投** | 1 AP | 从手牌选择一张牌，牌面朝下秘密投入一个地点的堆叠区顶部 |
| **触发** | 2 AP | 选择一个地点，按 LIFO 顺序依次揭示并结算该地点堆叠区内的所有牌 |
| **探查** | 1 AP | 偷看一个地点堆叠区中的一张指定牌（仅自己可见） |
| **抽牌** | 1 AP | 从个人牌库抽 1 张牌 |
| **转移** | 1 AP | 将自己在某地点的 1 张暗投牌移到另一地点（不揭示） |

#### 结束阶段（强制）

1. **倒计时更新**：所有地点的倒计时骰减少 1 点
2. **爆发检查**：检查是否有地点倒计时归零→执行爆发结算
3. **手牌上限调整**：弃牌至手牌上限（默认 5 张）
4. **下家回合开始**

### 关键概念

**后发制人**：因为后进先出结算，在同一地点后投牌的人必然先结算。这意味着：

- 先手玩家的牌会在底部被"压住"，可能被后手玩家的牌覆盖或连锁利用
- 后手玩家可以观察谁在往哪里投牌，然后做出针对性反制
- 心理博弈：你投牌时需要考虑对手后续可能会投入什么牌来反制你

## 3. 胜利条件

### 各阵营独立胜利方式

| 阵营 | 胜利条件 | 说明 |
|------|----------|------|
| **🛡️ 警长** | **控制 4 个地点** | 一个地点被你"控制"的条件：该地点堆叠区中至少有 1 张你的牌，且没有罪犯的牌。你需要在多个地点建立控制权 |
| **💀 罪犯（各人）** | **积累 20 点黑市资源** | 通过结算卡牌效果获取黑市资源。第一个达到 20 点的罪犯获胜——仅一人能胜出，其他罪犯失败 |
| **🦸 超级英雄** | **拯救 6 名受害者** | 通过特定卡牌效果从地点中"拯救"受害者 Token。受害者 Token 在地点爆发或特定卡牌结算时产生 |
| **👥 受害者联盟** | **终局生存积分最高** | 游戏结束时，按幸存者 Token 数量排名，最高者获胜。受害者联盟的玩家之间也互相竞争 |

### 游戏结束条件

满足以下任一条件时游戏结束：

1. **警长胜利**：警长控制 4 个地点→立即结束，警长获胜
2. **罪犯胜利**：任一罪犯达到 20 点黑市资源→立即结束，该罪犯获胜
3. **超级英雄胜利**：超级英雄拯救 6 名受害者→立即结束，超级英雄获胜
4. **牌库耗尽**：任意牌库第二次耗尽→游戏结束，进行终局计分
5. **终局计分**：牌库耗尽时，受害者联盟按幸存者 Token 数量排名（如平手则比较手牌价值总值）

> **注意**：游戏立即结束意味着只有触发胜利条件的阵营获胜，其他阵营（包括受害者联盟）失败。只有终局计分时受害者联盟才有机会获胜。

## 4. 基本规则框架

### 游戏准备

1. **设置城市**：从 8 个城市地点牌中随机选取 6 个（3 人以下选 4 个），在桌面中央一字排开
2. **分配阵营**：
   - 2 人：警长 vs 罪犯
   - 3 人：警长 + 罪犯 + 罪犯（或警长 + 罪犯 + 超级英雄）
   - 4 人：警长 + 2 罪犯 + 超级英雄（推荐配置）
   - 5-7 人：按比例添加受害者联盟和各罪犯
3. **分发卡牌**：每人拿取对应阵营的起始手牌和牌库
4. **设置倒计时**：每个地点秘密投掷 1 颗 D6，记录为倒计时数值（不公开）
5. **决定起始玩家**：警长最先行动，按顺时针方向进行

### 地点牌规则

每个城市地点拥有：

| 属性 | 说明 |
|------|------|
| **名称** | 如：码头、警局、银行、赌场、医院、贫民窟、市政厅、地铁站 |
| **被动能力** | 地点固有特效，持续生效 |
| **堆叠区** | 所有暗投卡牌在此堆叠（牌面朝下） |
| **倒计时骰** | 初始 1-6（隐藏），每回合 -1，归零时爆发 |
| **爆发效果** | 倒计时归零时触发的特殊效果 |

#### 地点示例

| 地点 | 被动能力 | 爆发效果 |
|------|----------|----------|
| **码头** | 每被堆叠 1 张牌，产生 1 点黑市资源（给该牌的玩家） | 所有堆叠牌结算后，产生额外 3 点黑市资源平均分配 |
| **警局** | 每结算 1 张牌，移除堆叠区最底层的 1 张牌（放回所有者弃牌堆） | 所有罪犯牌被移除，警长获得 2 点声望 |
| **银行** | 主动触发时，你可以额外翻看堆叠区最底部的 1 张牌 | 所有牌结算后，每个玩家获得 2 点金钱（可兑换资源） |
| **赌场** | 在此地点投牌时，你可以额外抽 1 张牌（每回合限 1 次） | 随机分配堆叠区所有牌的效果目标 |
| **医院** | 每回合 1 次，你可以从弃牌堆回收 1 张牌 | 拯救 2 名受害者 Token |
| **贫民窟** | 暗投此地的牌可以额外复制 1 张同名牌的效果（如果有） | 产生 3 名受害者 Token，所有人可争夺 |
| **市政厅** | 触发此地的费用减 1 AP（变为 1 AP） | 警长获得 1 个地点的控制权（如有警察牌在堆叠区） |
| **地铁站** | 每回合 1 次，你可以将 1 张牌从 A 地转移到 B 地 | 所有牌随机分配到其他地点继续堆叠 |

### 堆叠与结算规则

1. **暗投规则**：卡牌牌面朝下投入地点堆叠区顶部。其他玩家不知道你投了什么牌
2. **触发规则**：消耗 2 AP 选择地点，从顶部开始一张张揭示并结算
3. **LIFO 顺序**：后投入的牌先结算
4. **连锁机制**：一张牌结算时，如果效果引用了同地点其他牌（如"引爆目标牌"、"复制上一张牌的效果"），则暂停当前结算，先结算被引用的牌，再继续
5. **连锁上限**：同一结算链最多 5 次连锁（防止无限循环）
6. **爆发结算**：倒计时归零时，该地点立刻强制结算所有牌（不消耗 AP），同样按 LIFO 顺序

### 爆发规则详解

1. **时机**：每当一个地点的倒计时骰归零（通常在结束阶段检查）
2. **清算**：该地点堆叠区所有牌一次性按 LIFO 结算
3. **冷却**：爆发后，该地点进入冷却状态（跳过一轮倒计时，现有堆叠区清空）
4. **重生**：冷却结束后，重新投掷倒计时骰（1-6），地点恢复活跃
5. **连锁爆发**：如果一个地点的爆发结算导致另一个地点的倒计时归零，则连锁爆发（每回合最多 3 次连锁爆发）

### 冷却规则

1. 地点爆发后，翻面或旋转 90° 表示冷却状态
2. 冷却中的地点：不可投牌、不可触发、倒计时暂停
3. 冷却持续 1 轮（所有玩家经过 1 回合后解除）
4. 解除冷却后，重新设置倒计时骰

## 5. 游戏时长与人数

### 人数配置

| 人数 | 阵营配置 | 推荐？ | 预计时长 |
|------|----------|--------|----------|
| 2 人 | 警长 + 1 罪犯 | - | 20-30 min |
| 3 人 | 警长 + 1 罪犯 + 1 超级英雄 | - | 30-40 min |
| 4 人 | 警长 + 2 罪犯 + 1 超级英雄 | ⭐ 推荐 | 40-50 min |
| 5 人 | 警长 + 2 罪犯 + 1 超级英雄 + 1 受害者 | | 45-55 min |
| 6 人 | 警长 + 3 罪犯 + 1 超级英雄 + 1 受害者 | | 50-60 min |
| 7 人 | 警长 + 3 罪犯 + 1 超级英雄 + 2 受害者 | | 55-70 min |

### 规则讲解与上手

- 规则讲解时间：约 5 分钟
- 首局上手时间：约 10 分钟
- 推荐首局使用 4 人配置

## 6. 术语表

| 术语 | 说明 |
|------|------|
| **暗投** | 牌面朝下将卡牌投入地点堆叠区的行动 |
| **触发** | 按 LIFO 顺序结算地点堆叠区的所有卡牌 |
| **堆叠区** | 每个地点上的卡牌堆叠空间 |
| **LIFO** | 后进先出（Last In, First Out） |
| **连锁** | 卡牌结算时引用的额外结算链 |
| **爆发** | 倒计时归零时强制触发的结算 |
| **冷却** | 地点爆发后进入的不可用状态 |
| **黑市资源** | 罪犯积累的胜利资源 |
| **受害者 Token** | 超级英雄需要拯救的目标 |
| **控制权** | 警长在某地点建立的统治地位 |
