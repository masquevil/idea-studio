## 评价方法论

本文档从以下 **7 个维度** 进行全方位评价：

| 维度 | 考察重点 |
|------|---------|
| **① 概念与定位符合度** | 方案是否忠实于原定方向？核心承诺是否清晰？ |
| **② 核心机制自洽性** | 机制逻辑是否闭环？是否存在不可调和的矛盾？ |
| **③ 主题契合度** | 世界观是深嵌机制还是贴皮？代入感如何？ |
| **④ 非对称平衡性** | 四大阵营的公平性、差异化体验、策略深度？ |
| **⑤ 轻策匹配度** | 规则复杂度、学习成本、游戏时长是否匹配"轻策"定位？ |
| **⑥ 创新性亮点** | 相比已有桌游，方案的独特价值在哪里？ |
| **⑦ 潜在风险预判** | playtest 前最令人担忧的设计问题 |

建议优先级标记：

- 🔴 **高优先级**——不解决则游戏存在根本性缺陷
- 🟡 **中优先级**——影响体验但非致命
- 🟢 **低优先级**——锦上添花，可在后续迭代中优化

## 3.1 概念与定位符合度：⭐⭐⭐⭐⭐

方案 C 完全忠实于"自由发挥"的方向——它没有参考任何外部资料，创造了一个在桌游中极其少见的**暗投堆叠 + LIFO 结算**的核心机制。其核心承诺是 **"向城市地点暗投卡牌，堆叠结算，后手反制先手"**。

### 符合度分析

| 原定方向要素 | 实现情况 | 评价 |
|------------|---------|------|
| 自由发挥 | 完全从零构思，无参考 | ⭐⭐⭐⭐⭐ |
| 警匪非对称对抗 | 有，但警匪对抗性较弱 | ⭐⭐⭐（见下方分析） |
| 围绕城市地点行动 | 完全符合，地点是博弈核心 | ⭐⭐⭐⭐⭐ |
| 卡牌驱动 | 完全符合 | ⭐⭐⭐⭐⭐ |
| 轻策桌游 | 符合——规则简洁 | ⭐⭐⭐⭐⭐ |
| 多阵营各自为战 | 符合 | ⭐⭐⭐⭐⭐ |

## 3.2 核心机制自洽性：⭐⭐⭐⭐

### 做得好的

- **暗投堆叠 + LIFO 结算** 是真正有创新的核心机制。在桌游领域，"堆叠"（stack）概念常见于 TCG（如《万智牌》），但在非对称桌游中很少见
- **倒计时爆发** 机制制造了天然的时间压力和焦点争夺
- **连锁** 机制为游戏提供了"combo"的高潮体验
- **冷却** 机制控制了爆发频率，防止节奏失控

### 存在的问题

**🔴 问题 1：胜利条件之间缺乏对称性，导致"不同阵营玩的不是同一个游戏"**

方案 C 的四个胜利条件完全独立且互不兼容：

- 警长：控制 4 个地点（空间争夺）
- 罪犯：积累 20 点黑市资源（资源积累）
- 超级英雄：拯救 6 名受害者（拯救任务）
- 受害者联盟：终局计分排名（生存竞赛）

问题在于：

- 警长和罪犯的胜利条件可以在游戏中途突然触发（"哦，警长已经控制 4 个地点了，游戏结束"），其他玩家可能毫无准备
- 受害者联盟**只能通过终局计分获胜**，这意味着在游戏过程中，胜利者已经产生时，受害者联盟玩家可能还在"攒幸存者 token"，然后被告知"游戏结束了，你输了"
- **不兼容的胜利条件**是桌游设计中的高风险策略——虽然《Vast：水晶洞穴》做过，但那是非常特殊的案例

**🔴 问题 2：受害者的终局定位**

"终局生存积分最高"意味着受害者联盟：

- 不能主动触发游戏结束（对比罪犯、警长、魅影都能）
- 只能被动等待牌库耗尽
- 但在 4 人局中，罪犯可能在 10-15 分钟后就达到 20 点黑市资源，牌库还远未耗尽
- 结果是：**受害者联盟几乎从来等不到自己的胜利时刻**

这是方案 C 最严重的体验风险——受害者在大多数游戏中可能只是一个"陪玩"角色。

**🟡 问题 3：暗投信息的记忆负担**

- 暗投牌面朝下投入堆叠区 → 没人知道是什么
- 当堆叠区有 8-10 张牌时，玩家需要记忆自己投了什么、对手可能投了什么
- 但桌游不是电子游戏——没有系统帮玩家自动记录
- 实际体验：玩家频繁忘记"我投了什么"、"他投了什么"，需要不断扒牌看（但这是暗投！）
- **探查**（1 AP 看 1 张）提供了部分信息获取，但每回合 AP 有限

**🟡 问题 4：爆发冷却后重置倒计时的"无限循环"**

- 爆发→冷却→重生重新投 D6（1-6）→再次倒计时→再次爆发……
- 理论上游戏可以无限循环——只要没人触发胜利条件，地点可以无限次爆发
- 这可能是好事（游戏不会卡死），但也意味着没有"游戏结束的自然推力"
- 唯一触发终局的机制是"牌库第二次耗尽"——这在 20 张牌的小牌库下可能不会发生

## 3.3 主题契合度：⭐⭐⭐⭐⭐

**方案 C 的主题契合度与方案 B 并列最高。**

### 亮点

- "暗流"主题极度统一——暗投堆叠 = 向暗流投入意图，LIFO = 暗流记忆，倒计时 = 暗流蓄能周期
- **机制与主题完全同一**：玩家不是在"模拟暗流"，而是在操作暗流本身
- 城市地点身份化（码头的鲸鱼记忆、警局的囚犯低语）充满氛围感
- Decay-Noir 美术风格方向具体且有辨识度

方案 C 的主题设计证明了一点：**当机制本身就是主题的具象化时，主题契合度自然最高**。

## 3.4 非对称平衡性：⭐⭐⭐

### 存在的问题

**🔴 问题 1：警长的控制条件与 LIFO 存在矛盾**

- 警长控制地点的条件：该地点有警长牌 + 无罪犯牌
- 但在 LIFO 规则下，后投的牌先结算——罪犯可以在结算前的最后一刻投入一张罪犯牌，破坏警长的控制计划
- 控制权在"结束阶段检查"本来可以规避这个问题，但：
  - 如果地点爆发（LIFO 结算），结算前投入的罪犯牌会先结算，然后控制权自动消失
  - 警长需要确保在爆发前"清理"罪犯牌，但他唯一的清理手段是"卧底"（移除罪犯牌回手牌），这需要抽到对应牌
  - 控制权的建立和维持需要大量条件，但警长每回合只有 2 AP

**🟡 问题 2：罪犯的"暗流嗅觉"（免费看顶部牌）vs 警长的"执法感知"（免费看底部牌）**

- 在 LIFO 规则下，顶部牌先结算，底部牌后结算
- 罪犯能看顶部（最关键的牌），警长能看底部（最不关键的牌）
- 这是信息不对称，但方向对警长不利
- 警长看底部牌的信息价值很低——底部牌可能是 5 回合前投入的，早已被上面 10 张牌覆盖

**建议**：警长的被动改为"免费看任意 1 张暗投牌（自己选择位置）"，或者改为"免费看堆叠区顶部第 2 张牌"

**🟡 问题 3：魅影的胜利条件最苛刻**

- 需要拯救 6 名受害者
- 受害者 Token 的主要来源是地点爆发
- 但魅影不能控制地点何时爆发（倒计时是隐藏的！）
- 这意味着魅影的胜利节奏完全取决于运气
- 虽然魅影的"救援"行动（在 3+ 张牌的地点拯救 1 名受害者）提供了非爆发时的得分路径，但速度较慢

## 3.5 轻策匹配度：⭐⭐⭐⭐⭐

方案 C 与方案 A 同属轻策定位，但方向不同：

- **规则复杂度**：方案 C 的核心规则极其简洁（暗投/触发/探查/抽牌/转移 五个基础行动 + 倒计时/爆发/冷却）
- **学习成本**：约 5 分钟讲解，10 分钟上手
- **但策略深度来自复合系统交互**（连锁、倒计时博弈、信息心理战）

一个有趣的对比：方案 C 的规则如同《围棋》——规则书薄薄的十页，但策略深度来自简单规则的复合。这是典型的"易学难精"轻策特征。

## 3.6 创新性亮点

| 创新点 | 评价 |
|--------|------|
| **暗投堆叠 + LIFO** | 桌游中极其罕见的核心机制，将 TCG 的堆叠概念引入非对称桌游（实际上我的设计生涯中从未见过同类桌游） |
| **倒计时爆发** | 天然的节奏制造器，无需强制回合数 |
| **地点身份化** | 每个地点有独立"性格"，远超传统的"区控"设计 |
| **连锁引爆** | 提供了轻策中少见的高潮体验 |
| **零棋盘零棋子** | 地点就是卡牌堆叠区，极简物理组件 |

**方案 C 的创新性是三个方案中最高的。** 如果桌游设计有"专利"，暗投堆叠 + LIFO 是一个可以注册的机制。

## 3.7 潜在风险预判

| 风险 | 等级 | 说明 |
|------|------|------|
| **胜利条件不兼容** | 🔴 | 四个阵营各玩各的，其中一个玩家可能突然宣布胜利而其他人毫无参与感 |
| **受害者联盟终局缺陷** | 🔴 | 在大多数游戏中，受害者联盟可能无法等到终局 |
| **暗投记忆负担** | 🟡 | 堆叠区变大后，玩家需要记忆大量暗投信息，导致频繁"翻牌作弊" |
| **警长控制权脆弱** | 🟡 | 罪犯可以在最后一刻破坏警长的控制，导致警长整局目标无法达成 |
| **倒计时不可见** | 🟡 | 倒计时隐藏增加了悬念，但也剥夺了所有玩家（包括警长和魅影）规划所需的信息 |
| **2 AP 限制过紧** | 🟡 | 2 AP 限制了每回合操作数，但如果玩家总是只能做 1 件事（如暗投+探查但没有触发），节奏可能太慢 |

## 3.8 修改建议

### 🔴 高优先级

| # | 建议 | 原因 |
|---|------|------|
| C-1 | **统一胜利条件框架**：改为所有阵营共享"场景分"系统——不同的行为产生不同场景分，**第一个达到 X 场景分的玩家获胜**。警长控制地点产生场景分，罪犯积累资源产生场景分，魅影拯救受害者产生场景分，受害者生存产生场景分 | 解决胜利条件不兼容的根本问题 |
| C-2 | **或保留各自条件，但增加"终局检查"**：任何玩家触发胜利条件时，不是立即结束，而是进入"最后 1 轮"（所有玩家再行动一次），确保受害者联盟有最后机会 | 为受害者联盟提供公平的竞争窗口 |
| C-3 | **倒计时可见化**：将隐藏倒计时改为公开（面朝上），或改为"每回合末-1，且在牌面上标注剩余回合数"。所有玩家需要知道地点的剩余时间才能做出有意义的决策 | 当前隐藏倒计时剥夺了所有阵营的规划能力 |

### 🟡 中优先级

| # | 建议 | 原因 |
|---|------|------|
| C-4 | **警长被动改为查看任意 1 张暗投牌**：当前查看底部牌的信息价值太低 | 平衡信息不对称 |
| C-5 | **增加魅影的非爆发得分路径**：如"每拯救 1 名受害者后，下回合 AP+1" | 让魅影的节奏更可控 |
| C-6 | **引入"暗投记录纸"**：每人一张小纸，自己记录向哪个地点投了什么牌（可选，帮助记忆） | 解决暗投记忆负担 |
| C-7 | **冷却机制改为"固定 1 轮"而非"1 轮后"**：明确"本回合爆发→下回合同一位置不可用→再下回合恢复" | 冷却规则需要更清晰 |

### 🟢 低优先级

| # | 建议 |
|---|------|
| C-8 | 考虑将 AP 从 2 提升到 3，让玩家每回合可以做更多操作（尤其是"触发+其他"的 combo）|
| C-9 | 地名牌数量限制（如 6 个）在小局（2 人）中可能太多，建议 2 人使用 4 个地点 |
| C-10 | 在规则书中加入"回合行动示例表"，帮助新玩家理解常见的 2AP 组合（如"暗投+探查""探查+抽牌""抽牌+暗投"等） |
