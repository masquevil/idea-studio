## 1. 角色卡牌格式

所有角色卡牌统一使用以下布局：

```
┌──────────────────────┐
│ 阵营图标 │ 代号        │  ← 阵营色条（警长蓝/罪犯红/英雄紫/受害者绿）
│                       │
│   角色名              │
│   职位                │
│                       │
│  ┌─────────────────┐  │
│  │ 角色插画区域      │  │
│  └─────────────────┘  │
│                       │
│  犯罪等级：★☆☆☆（仅罪犯）│  ← 黑色加粗小字
│  隐藏值上限：3  （仅罪犯）│  ← 仅罪犯卡有
│                       │
│  ── 技能 ──          │
│  [技能1名称]（类型）    │
│  技能效果描述          │
│  [技能2名称]（类型）    │
│  技能效果描述          │
│                       │
│  ── 背景故事 ──       │
│  一句话背景描述        │
└──────────────────────┘
```

### 技能类型标注

| 类型 | 标识 | 说明 |
|------|------|------|
| 被动 | 【被动】 | 常驻生效，无需消耗行动 |
| 普通 | 【普通】 | 需消耗 1 基础行动使用 |
| 快速 | 【快速】 | 符合条件时可随时触发，不消耗行动 |

## 2. 警长角色（3 张）

### 2.1 警长设计思路

警长是 4 人局中唯一的执法者。三个角色分别侧重：

- **正面强攻型**：侦查效率高，适合主动出击
- **防守控制型**：布控能力强，适合区域压制
- **灵活战术型**：策略牌联动强，适合多变战术

## 3. 罪犯角色（8 张）

### 3.1 罪犯设计思路

8 个罪犯角色分布在犯罪等级 1-4 之间，每个犯罪等级 2 个角色：

- **犯罪等级 1**（2 个）：街头混混级，风险最低，但上限也低
- **犯罪等级 2**（4 个）：标准罪犯级，大部分角色的基准线
- **犯罪等级 3**（1 个）：重罪犯级，高回报高风险
- **犯罪等级 4**（1 个）：极端重罪犯级，最高回报最高风险

每个角色的技能与其犯罪等级和背景故事匹配。

## 6. 4 人局标准配置

### 6.1 角色分配流程

```
① 按人数配置确定警长数量（1人）和罪犯数量（3人）
② 警长玩家从 3 张警长角色中任选 1 张
③ 剩余玩家抽签决定罪犯角色（从 8 张中随机抽取 3 张）
④ 各玩家获得对应的角色卡、证据 Token（罪犯）、隐藏值 D6
```

### 6.2 推荐角色组合

以下组合在 4 人局中提供策略多样性：

| 组合风格 | 警长 | 罪犯 |
| --------- | ------ | ------ |
| 进攻型 | "铁腕"鲍默尔 | "毒蛇"+"铁拳"+"屠夫" |
| 控制型 | "猎犬"莫里斯 | "幽灵"+"鬼手"+"双面人" |
| 战术型 | "智囊"温斯洛 | "老鼠"+"阿列克谢"+"疯子" |
| 平衡型 | 任意 | 1 个等级 1 + 2 个等级 2 |

## 7. 不同人数配置的角色调整

| 人数 | 警长 | 罪犯 | 超级英雄 | 受害者 | 角色选择方式 |
| ------ | ------ | ------ | --------- | --------- | ------------- |
| 2 | 1（任选） | 1（随机） | 0 | 0 | 警长任选，罪犯随机 |
| 3 | 1（任选） | 2（随机） | 0 | 0 | 警长任选，罪犯随机 |
| **4** | **1（任选）** | **3（随机）** | **0** | **0** | **标准配置** |
| 5 | 1（任选） | 3（随机） | 0-1 | 0-1 | 受害者或超级英雄二选一 |
| 6 | 1（任选） | 3-4（随机） | 0-1 | 0-1 | 罪犯/超级英雄/受害者三选二 |
| 7 | 1（任选） | 4（随机） | 1（随机） | 1（随机） | 全阵营满配 |

> 随机抽取时，建议采用公开展示后按某种顺序（如抽签顺序/座位顺序）依次选择，避免完全随机导致某个玩家对角色不满意。
