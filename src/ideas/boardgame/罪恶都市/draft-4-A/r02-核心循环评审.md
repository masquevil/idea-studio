## 2. 隐藏值系统重构评估

### 2.1 新系统概览

```
隐藏值 0（极度暴露）←——调查-1 —— 隐藏值 2 —— 隐藏+1 ——→ 隐藏值 3（上限，最隐蔽）
                              ↑ 每回合自动回复 1（不超过上限）
                              ↑ 出狱/越狱后重置为上限
```

### 2.2 与 v4 原始想法的对齐

| v4 想法 | 新系统实现 | 一致性 |
| -------- | ---------- | ------- |
| 隐藏值影响侦查/抓捕成本 | ✅ 警长抓捕需要消耗 x 个证据 Token（x ≥ 当前隐藏值） | ✅ |
| 罪犯动作会降低隐藏值 | ✅ 调查 -1（合理：打听消息暴露行踪） | ✅ |
| 隐藏值可恢复 | ✅ 隐藏行动 +1、每回合自动回复 +1、出狱重置 | ✅ |
| 隐藏值分 6 格 | ⚠️ 改为通常上限 3（角色卡可差异化为 2/3/4） | ✅ 简化合理 |

### 2.3 关键设计验证

| 检查项 | 结论 | 说明 |
| -------- | ------ | ------ |
| 语义一致性 | ✅ | 数值高=隐蔽，隐藏行动提高数值，调查降低数值，直觉一致 |
| 涨跌节奏 | ✅ | 调查 -1 ↔ 隐藏 +1 + 自动回复 +1 → 保持动态平衡，无需额外行动就能回到上限 |
| 抓捕阈值清晰 | ✅ | 警长需收集罪犯当前隐藏值数量的证据 → 高隐藏值需要更多证据 → 罪犯更安全 |
| 策略深度 | ✅ | 罪犯需要在"获取情报（代价：隐藏值↓）"和"保持隐蔽（代价：行动机会）"之间权衡 |
| 犯罪不降低 | ✅ | 犯罪本身不额外暴露，符合"踩点充分"的叙事逻辑，且降低罪犯的挫败感 |

### 2.4 典型节奏模拟

以隐藏值上限 3 的罪犯为例：

```
第 1 回合：开始 → 自动回复到 3
            调查（隐藏值 3→2，得 1 情报）
            调查（隐藏值 2→1，得 1 情报）→ 共 2 情报，但隐藏值只剩 1，危险！
第 2 回合：开始 → 自动回复到 2
            隐藏（隐藏值 2→3，保命）
            调查（隐藏值 3→2，得 1 情报）→ 共 3 情报
第 3 回合：开始 → 自动回复到 3
            调查（3→2，得 1 情报）→ 共 4 情报，充足了
            犯罪（重大行动，隐藏值不变，得 2 分）
```

**评估**：节奏合理。罪犯无法持续高强度犯罪（需要轮换调查/隐藏的节奏），自动回复机制避免了"数值越滚越低"的恶性循环。✅

## 3. 警长策略重构评估

### 3.1 新旧对比

| 维度 | 旧版本（第一轮） | 新版本（修改后） |
| ------ | ----------------- | ----------------- |
| 核心问题 | 追谁不追谁 | 什么时候优先抓哪个角色，花多少成本 |
| 目标切换 | 未明确 | 每次出狱后证据清零+隐藏值回满 → 自然转向其他罪犯 |
| 决策模型 | 单维（谁暴露抓谁） | 三维（时机判断+成本考量+目标切换） |
| "死盯"问题 | 有风险 | 通过机制自然解决 |

### 3.2 三维决策模型验证

1. **时机判断**："现在抓 A 还是等 B 再犯一次案？" → 对 v4 想法中"即时 vs 延迟"的深化
2. **成本考量**："花情报布控压制 vs 集中资源收集证据快速抓捕" → 资源管理维度
3. **目标切换**："A 刚出狱 → 转向 B" → 保证每个罪犯都有游戏空间

> ✅ **评估**：新版本的重写将警长从一个"追踪者"提升为一个"策略调度者"，决策维度从 1 维扩展到 3 维，战术多样性显著提升。

### 3.3 剩余注意点

- ⚠️ **关注**：新策略框架依赖"出狱后证据清零+隐藏值回满"这一机制来驱动目标切换。如果某个罪犯从未被捕（一直犯罪但隐藏值保持高位），警长可能缺乏切换目标的动力。建议在阶段③ MVP 中设计「当某个罪犯连续多轮未被调查时的线索提示机制」（警长获得额外情报），确保警长不会完全忽视某个罪犯。

## 4. 越狱机制评估

### 4.1 新设计

| 参数 | 值 |
| ------ | ----- |
| 触发条件 | 看守所中的罪犯 |
| 消耗 | 2 情报 Token + 角色技能或策略牌 |
| 随机性 | **无骰子**（纯策略决策） |
| 成功条件 | 由角色技能或策略牌效果决定 |

### 4.2 评估

| 检查项 | 结论 | 说明 |
| -------- | ------ | ------ |
| 骰子依赖已消除 | ✅ | 完全去随机化，符合"策略优先于运气"的轻中策定位 |
| 消耗合理 | ✅ | 2 情报 ≈ 2 次调查动作，相当于花费一回合资源提前出狱 |
| 策略深度 | ✅ | 玩家需要判断：花 2 情报越狱 vs 等待自动减格出狱，哪个更划算 |
| 角色区分度 | ✅ | 不同角色的越狱技能可以差异化：有些角色越狱成本低，有些不需要策略牌 |

> **建议**：在阶段③角色设计时，确保每个罪犯角色在越狱方面有差异化。例如：混混可能不需要策略牌就能越狱（成本优势），而连环杀手需要特定策略牌（高风险高回报）。
