## 1. 游戏概述

### 1.1 背景故事

罪恶都市——一座被黑暗笼罩的城市。警长在体制内艰难执法，罪犯在街头暗中活动。所有人都在这座城市里追逐自己的利益，互相利用、互相压制。谁能第一个达到 15 分，谁就能在这场无休止的博弈中胜出。

### 1.2 游戏目标

- **跑分制**：最先达到 15 分的玩家获胜
- **回合上限**：第 12 轮结束时，分数最高者获胜
- **同时达标**：若多名玩家在同一轮结束时达到 15 分，按分数高低排名，同分则按距离 15 分差额小者胜

### 1.3 游戏人数与阵营

本游戏共有 4 个阵营：**警长**、**罪犯**、**超级英雄**、**受害者**。标准 4 人局仅使用警长和罪犯；5 人及以上时逐步加入超级英雄和受害者。

| 人数 | 警长 | 罪犯 | 超级英雄 | 受害者 | 说明 |
| :-: | :-: | :-: | :-: | :-: | - |
| 2 | 1 | 1 | | | 迷雾阶段 2 次/轮 |
| 3 | 1 | 2 | | | 迷雾阶段 1 次/轮 |

## 3. 游戏准备

### 3.1 版图设置

```
① 将 16 张地点牌按上城（4 张）、核心（8 张）、下城（4 张）分成 3 堆
② 从上城主堆中随机抽取 3 张，核心区抽 6 张，下城区抽 3 张
③ 将 12 张地点牌全部展出，排成 3×4 网格（4 人及以上局）；2-3 人局改为上 3+核心 3+下 3 = 9 张，排成 3×3
④ 在每个地点上放置等于其情报值数量的情报 Token
⑤ 剩余情报 Token 放入供应堆
```

### 3.2 角色分配

详见 [04-角色设计.md](./04-角色设计.md) 第 6 节。

```
① 所有玩家从自己所属阵营的角色池中随机抽取 2 张，选择其中 1 张作为本局角色
② 各玩家获得对应角色卡
③ 警长玩家获得：5 个警员 Token
④ 罪犯玩家额外获得：
   ├─ 5 个印有自己角色头像的证据 Token（放入自己面前）
   └─ 1 个异色小方块，放在角色卡隐藏值轨道的上限数字上作为初始值
⑤ 所有玩家获得初始资源：1 张策略牌（从公共牌堆摸取）
```

### 3.3 其他设置

```
① 将 35 张策略牌洗混，形成公共牌堆，放在版图旁边
② 将看守所面板放在警长旁边
③ 将警员 Token（5 个）、分数标记等放在供应堆
④ 设置回合标记为 1（第 1 轮）
⑤ 警长作为每轮的起始玩家（从警长开始按顺时针进行）
```

## 4. 核心概念

### 4.0 花费与效果

执行一切行动时，遵循以下规则：

- **花费与效果分离**：先支付行动的花费（行动力、情报 Token 等），再执行行动的效果
- **效果被取消时不退费**：若某个行动或卡牌的效果被取消（如被 ↩️ 牌「紧急躲避」阻止），已支付的花费**不予退回**
- **花费的类型**：情报 Token、行动额度（➡️/重大 ➡️➡️）、弃置手牌等都属于花费；"获得分数"、"将证据放入看守所"、"使效果失效"等属于效果

> **示例**：警长执行抓捕时，先消耗 2 点行动力（重大 ➡️➡️，花费），再执行将证据 Token 放入看守所并获得分数（效果）。若罪犯打出「紧急躲避」使效果失效，已消耗的行动力不会退回。

### 4.1 情报 Token

- **全阵营通用基础资源**，形状为蓝色小方块
- 玩家通过"调查"基础行动从地点获得情报 Token
- 几乎所有的行动（侦查、布控、犯罪、出牌等）都需要消耗情报 Token
- 情报 Token **无持有上限**（但手牌有上限 3 张）
- 情报 Token 主要通过"调查"基础行动从地点获取

### 4.2 证据 Token

- 每个罪犯角色有 5 个印有自己头像的圆形 Token
- **放置**：罪犯执行"犯罪"重大行动时，将 1 个自己的证据 Token 放置在地点上
- **获得**：警长执行"侦查"基础行动时，消耗情报获得地点上的 1 个证据 Token
- **消耗**：警长执行"抓捕"重大行动时，**消耗全部持有的该罪犯证据 Token**
- **证据 Token 溢出的处理**：若该罪犯的 5 个证据 Token 已全部在版图上，则在执行犯罪时改为将其中 1 个已在地点上的证据 Token 移动到新的目标地点（原地点上的证据 Token 消失）

### 4.3 隐藏值（仅罪犯）

- 每个罪犯角色有一个隐藏值，用角色卡底部的隐藏值轨道表示
- 隐藏值轨道印有 0～X 的数字小方格（X = 隐藏值上限 + 2），其中 0～上限 的方格带底色
- 玩家将一个小方块放在对应数字上，代表当前隐藏值
- **范围**：0 到角色卡上限（通常为 3）
- **提高方式**：
  - 执行"隐藏"基础行动：将隐藏值方块向前移动 1 格（不超过上限）
  - 每回合补给阶段自动回复 1：将隐藏值方块向前移动 1 格（不超过上限）
  - 越狱/出狱时重置为上限
- **降低方式**：
  - 执行"调查"基础行动：将隐藏值方块向后移动 1 格（可降至 0）
- **核心作用**：警长执行"抓捕"时，需要消耗该罪犯的**全部持有的证据 Token**；如果消耗的证据 Token 数量 < 当前隐藏值，每相差 1 点需额外花费 2 个情报 Token
- **被捕时不变**：罪犯被逮捕时，隐藏值保持不变（作为抓捕时的读数），不会因被捕而变动。越狱后才重置为角色卡上限

### 4.4 犯罪等级（仅罪犯）

- 角色卡上标注的犯罪等级（1-4）
- 决定抓捕得分、越狱起始格、超额犯罪条件
- **超额犯罪**：在**影响力高于自身犯罪等级**的地点犯罪时，额外 +1 分

| 犯罪等级 | 超额犯罪条件 | 符合条件的区域 |
| --------- | ------------ | -------------- |
| 1 | 影响值 > 1 | 核心区(2)✅ + 上城区(3/4)✅ |
| 2 | 影响值 > 2 | 上城区(3/4)✅ + 核心区部分(3)✅ |
| 3 | 影响值 > 3 | 博物馆(4)✅ |
| 4 | 影响值 > 4 | 无区域符合 |

### 4.5 看守所区域

- 印有 0/1/2/3 四个数字格的专用面板
- 警长抓捕时将消耗的证据 Token 放入对应犯罪等级的格
- 每个黎明阶段，所有证据 Token 向右移动 1 格（数字减少）
- Token 到达 0 格时 → 罪犯成功越狱 → 释放所有 Token → 罪犯恢复完全行动能力
- **看守所中的角色限制**：被捕罪犯的回合中，**每回合只能执行 1 次行动**（不能执行 2 基础行动或 1 重大行动的标准模式），只能从以下两种行动中选择其一：
  - **弃 1 张手牌**，从供应堆获得 1 情报 Token
  - **越狱**（重大行动，消耗 3 情报 + 弃 1 张手牌，执行后本回合不再有其他行动）
- 被捕罪犯不能使用快速牌、↩️ 牌和被动技能

### 4.6 警员 Token

- 警长专用的布控工具
- 放置在地点上 → 该地点情报值 +2（本轮有效）
- 黎明阶段收回所有警员 Token
- 同一地点不能放置 2 个以上的警员 Token

## 5. 回合流程详解

### 5.1 回合结构总览

```
一轮结构（约 10-20 分钟 / 4人局）
① 傍晚阶段（约 30 秒）
② 夜晚阶段（核心行动阶段，按顺序进行每个玩家的回合）
③ 黎明阶段（约 1 分钟）
```

> 2-3 人局额外有迷雾阶段：**傍晚 → 迷雾 → 夜晚 → 黎明**

### 5.2 傍晚阶段

```
① 翻开/结算延迟卡牌效果（部分策略牌的延迟效果在此时触发）
② 触发"新的一轮开始时"效果的技能
③ 宣布"傍晚结束，进入夜晚阶段"
```

### 5.3 迷雾阶段（仅 2-3 人局）

> 详细机制见 [02-核心循环.md](./02-核心循环.md) 第 5 节

```
① 由警长操作，执行（3 - 罪犯人数）次迷雾行动
② 每次：从情报值最高的地点中选 1 个 → 移除 1 情报 Token
   → 检查迷雾 Token 状态：无则放灰色，灰色则翻红（视为证据）
③ 宣布"迷雾阶段结束，进入夜晚"
```

### 5.4 夜晚阶段 — 玩家回合

**回合顺序**：从警长开始，按顺时针依次进行。

每个玩家的回合包含 5 个子阶段：

#### ① 开始阶段

```
触发"回合开始时"效果的技能或卡牌效果
```

#### ② 补给阶段

```
摸 1 张策略牌（从公共牌堆顶部摸取）
```

#### ③ 行动阶段

每回合拥有 **2 点行动力**。行动分为三种类型：

| 行动类型 | 说明 |
| ------ | ------ |
| `➡️` | 消耗 1 点行动力 |
| **快速** | 不消耗行动力，任何时段可执行 |
| `↩️` | 不消耗行动力，条件触发时立即执行 |

**标签**：部分行动带有标签，标签是一些共用的简短规则说明。常见标签：

| 标签 | 说明 |
| ------ | ------ |
| **重大** | 带此标签的行动每回合仅能执行 1 次 |
| ⏳ 延迟 | 带此标签的效果在打出时不立即生效，满足条件时翻开执行 |

> 每回合共有 2 点行动力，可用于执行 2 个带 `➡️` 的行动。部分技能或卡牌效果可增加行动力，但即使行动力增加，**每回合仍仅能执行 1 次带 "重大" 标签的行动**。

**行动清单**：

| 行动 | 效果 | 适用 |
| ------ | ------ | ------ |
| 调查 | `➡️` 从任意地点获得 1 个情报 Token（罪犯使用时，自身隐藏值 -1） | 全阵营 |
| 摸牌 | `➡️` 从公共策略牌堆摸 1 张牌 | 全阵营 |
| 出牌 | `➡️` 打出手中的 1 张策略牌（若策略牌带有 ⏳ 延迟 标签，则背面朝上放置；若无延迟标签则立即结算效果） | 全阵营 |
| 技能 | 使用角色的行动类技能（满足技能描述中的条件和费用） | 全阵营 |
| 侦查 🔵 | `➡️` 选择一个地点，花费等于该地点当前情报值的情报 Token，获得该地点上 1 个证据 Token | 警长专用 |
| 布控 🔵 | `➡️` 选择一个地点，放置 1 个警员 Token，该地点情报值 +2（本轮有效） | 警长专用 |
| 抓捕 🔵 | **重大** `➡️➡️` 选择一名罪犯角色，将持有的全部该罪犯的证据 Token 放入看守所的 X 位置；若持有数 < 其当前隐藏值，每差 1 额外花费 2 情报 Token；+X 分，X 为该罪犯的犯罪等级 | 警长专用 |
| 隐藏 🔴 | `➡️` 提高隐藏值 1 点（不超过角色卡上限） | 罪犯专用 |
| 犯罪 🔴 | **重大** `➡️➡️` 选择地点，花费情报（=地点当前情报值），放置 1 个证据 Token，获得影响值对应分数；若地点影响值 > 犯罪等级，额外 +1 分；若 5 个证据 Token 全在版图上则改为移动 1 个 | 罪犯专用 |
| 越狱 🔴 | **重大** `➡️➡️` 处于看守所的罪犯，花费 3 情报 Token + 弃置 1 张手牌尝试越狱，成功后移出看守所 | 罪犯专用 |

#### ④ 修整阶段

```
检查手牌中的策略牌数量：
- 若 > 3 张，弃置多出的牌，直到手牌 = 3 张
- 情报 Token 无上限，无需弃置
```

#### ⑤ 结束阶段

```
触发"回合结束时"效果的技能或卡牌效果
宣布"我的回合结束"，轮到下一位玩家
```

### 5.5 黎明阶段

```
① 看守所 Token 向右移动 1 格（数字减少）
   Token 到达 0 格 → 越狱成功 → 释放 Token
② 收回所有警员 Token（布控效果结束）
③ 触发"黎明阶段"效果的技能
④ 警长检查：版图上无任何证据 Token → 警长得 1 分
⑤ 检查终局条件：
   ├─ 是否有玩家分数 ≥ 15 分 → 进入游戏结算
   └─ 当前轮次是否为第 12 轮 → 进入游戏结算
⑥ 未结束 → 回合标记 +1 → 进入下一轮的傍晚阶段
```

## 6. 各阵营行动详解

### 6.1 警长专属行动

#### 侦查（基础行动）

```
条件：
├─ 选择 1 个地点（任意区域）
├─ 拥有 ≥ 该地点当前情报值 数量的情报 Token
└─ 该地点至少有 1 个证据 Token

执行：
├─ 花费 = 地点当前情报值 的情报 Token
├─ 从该地点获得 1 个证据 Token（选择要拿哪个罪犯的）
└─ 将获得的证据 Token 放在自己面前（暂时持有）
```

#### 布控（基础行动）

```
条件：
├─ 选择 1 个地点（"学校和图书馆"除外）
└─ 有可用的警员 Token（最多 5 个，部分已在场上）

执行：
├─ 该地点情报值 +2（仅在计算侦查成本时生效）
└─ 该地点上已有的证据 Token 不受影响

收回：黎明阶段自动收回所有警员 Token
```

#### 抓捕（重大行动）

```
条件：
├─ 选择 1 名罪犯作为目标
├─ 持有至少 1 个该罪犯的证据 Token
├─ 该罪犯不在看守所中

执行（花费 → 效果）：
├─ 【花费】消耗 2 点行动力（重大 ➡️➡️）
├─ 【花费】若消耗的证据 Token 数量 < 该罪犯的当前隐藏值：
│   └─ 每相差 1 点，额外消耗 2 个情报 Token（从手中支付）
├─ 【效果】将所有该罪犯的证据 Token 放入看守所面板
│   └─ 放入的格 = 该罪犯的犯罪等级（犯罪等级 1→格 1，犯罪等级 2→格 2，依此类推）
├─ 【效果】获得分数 = 该罪犯的犯罪等级
├─ 【效果】若消耗的证据 Token 数量 < 该罪犯的犯罪等级，额外 +1 分

注意：
- 被捕时罪犯的隐藏值保持不变（作为抓捕时的读数），不会因被捕而变动
- 越狱后才重置为角色卡上限

示例：
├─ 罪犯"毒蛇"（犯罪等级 2，当前隐藏值 2）
├─ 警长手中持有 2 个"毒蛇"的证据 Token
├─ 消耗全部 2 个证据 Token → 放入看守所的格 2
├─ 消耗数 2 = 隐藏值 2，无需额外情报 Token
├─ 获得 2 分（犯罪等级 2）

示例 2（证据不足，用情报补差）：
├─ 罪犯"屠夫"（犯罪等级 3，当前隐藏值 2）
├─ 警长手中持有 1 个"屠夫"的证据 Token
├─ 消耗全部 1 个证据 Token
├─ 消耗数 1 < 隐藏值 2 → 差 1 → 额外消耗 2 情报 Token
├─ 放入看守所的格 3
├─ 获得 3 分（犯罪等级 3）
└─ 消耗 1 < 犯罪等级 3 → 高效抓捕额外 +1 分 = 共 4 分
```

### 6.2 罪犯专属行动

#### 隐藏（基础行动）

```
条件：当前隐藏值 < 角色卡上限

执行：
├─ 隐藏值 +1
└─ （不超过角色卡上限）

作用：增加警长抓捕所需的情报代价（每多 1 隐藏值，警长需多消耗 2 情报或更多证据）
```

#### 犯罪（重大行动）

```
条件：
├─ 选择 1 个地点
├─ 拥有 ≥ 该地点当前情报值 数量的情报 Token
├─ 不在看守所中（被捕状态下不能犯罪）

执行（有可用证据 Token）：
├─ 消耗 = 地点当前情报值 的情报 Token
├─ 将 1 个自己的证据 Token 放置在该地点上
├─ 获得分数 = 该地点的影响值
├─ 若该地点的影响值 > 你的犯罪等级，额外 +1 分

执行（5 个证据 Token 已全部在版图上）：
├─ 消耗 = 地点当前情报值 的情报 Token
├─ 选择 1 个自己已在版图上的证据 Token，移动到新目标地点
├─ 获得分数 = 该地点的影响值
├─ 若该地点的影响值 > 你的犯罪等级，额外 +1 分

示例：
├─ 罪犯"老鼠"（犯罪等级 1）在贫民窟（影响值 1）犯罪
├─ 消耗 2 情报 Token（当前情报值），放置 1 证据 Token
├─ 获得 1 分（影响值）
└─ 影响值 1 = 犯罪等级 1，不满足"大于"条件，无额外分

示例 2：
├─ 罪犯"毒蛇"（犯罪等级 2）在博物馆（影响值 3）犯罪
├─ 消耗 5 情报 Token（当前情报值），放置 1 证据 Token
├─ 获得 3 分（影响值）
└─ 影响值 3 > 犯罪等级 2 → 额外 +1 分 = 共 4 分
```

#### 越狱（重大行动）

```
条件：
├─ 自己的证据 Token 在看守所中
├─ 拥有 ≥ 3 情报 Token
├─ 手牌 ≥ 1 张

执行：
├─ 消耗 3 情报 Token
├─ 弃置 1 张手牌
├─ 从看守所释放（所有自己的证据 Token 从看守所面板上移回供应堆或自己面前）
├─ 隐藏值重置为角色卡上限
└─ 恢复完全行动能力（下个回合起可正常行动）

注意：越狱是一个重大行动，意味着你本回合只能做越狱这一件事
某些角色技能（如"铁拳"马库斯）可以减少越狱的情报消耗
```

### 6.3 看守所中的行动

```
被捕罪犯的回合中，每回合只能从以下两种行动中选择其一执行（不可执行 2 基础行动或 1 重大行动）：

选项 A — 弃牌换情报（基础行动）：
  弃置 1 张手牌 → 从供应堆获得 1 情报 Token

选项 B — 越狱（重大行动）：
  消耗 3 情报 Token + 弃置 1 张手牌 → 越狱成功

注意：被捕期间不能使用快速牌、↩️ 牌和被动技能
```

### 6.4 通用行动

#### 调查（基础行动）

```
选择 1 个地点，从该地点获得 1 个情报 Token。
如果该地点当前情报值为 0，则无法获得。
如果执行者是罪犯，隐藏值 -1（降至 0 为止，不会为负数）。
```

#### 摸牌（基础行动）

```
从公共策略牌堆顶部摸 1 张牌。
如果牌堆为空，将弃牌堆洗混作为新的牌堆。
手牌上限为 3 张（修整阶段弃置超出部分）。
```

#### 出牌（基础行动）

```
打出手中的 1 张策略牌。常见的策略牌类型包括：

`➡️` 策略牌：打出即生效，消耗 1 点行动力
**快速** 策略牌：符合条件时随时打出，不消耗行动，每轮限 1 张
`↩️` 策略牌：条件触发时立即打出，不消耗行动（与快速牌合计每轮限 1 张）
⏳ 延迟 策略牌：打出时消耗 `➡️`，背面朝上放置在自己面前区域，在符合翻开条件时执行效果（翻开时不消耗行动）
```

#### 使用技能（基础行动）

```
使用角色卡上的 1 个技能。
消耗条件以技能效果描述为准。
标注为"被动"的技能常驻生效，无需消耗行动。
标注为"快速"的技能可在符合条件时随时触发，不消耗行动。
标注为"重大"的技能需消耗 1 个重大行动。
```

## 7. 胜利条件与计分方式

### 7.1 终局触发

| 条件 | 触发时机 |
| ------ | --------- |
| 任意玩家分数 ≥ 15 分 | 当前轮黎明阶段结束时 |
| 第 12 轮结束 | 第 12 轮黎明阶段结束时 |

### 7.2 得分途径

| 阵营 | 途径 | 分数 | 说明 |
| ------ | ------ | ------ | ------ |
| 罪犯 | 犯罪动作 | 地点影响值（1-3 分） | 每次犯罪获得 |
| 罪犯 | 超额犯罪 | 额外 +1 | 犯罪地点影响值 > 罪犯犯罪等级 |
| 罪犯 | 越狱动作 | 0 分（暂定） | 越狱本身不产生分数 |
| 警长 | 抓捕动作 | 犯罪等级（1-4 分） | 每次抓捕获得 |
| 警长 | 高效抓捕 | 额外 +1 | 消耗证据数 < 犯罪等级 |
| 警长 | 无证据奖励 | +1 | 每个黎明阶段，版图上无任何证据 Token 时 |
| 超级英雄 | 角色技能 | 视具体技能而定 | 详见角色卡技能描述 |
| 受害者 | 角色技能 | 视具体技能而定 | 详见角色卡技能描述 |

### 7.3 同时达标处理

若多名玩家在同一黎明阶段达到 ≥ 15 分：

```
① 按分数高低排名
② 分数相同时，按"距离 15 分的差额"排名，差额小者胜
③ 仍相同 → 共享胜利
```

## 9. 术语表

### 9.1 标签索引

以下标签可能出现在行动清单、角色卡、策略牌或地点牌上：

| 标签 | 说明 |
| ------ | ------ |
| `➡️` | 花费 1 点行动力 |
| **重大** | 标签，每回合仅能执行 1 次有此标签的行动。搭配 `➡️➡️` 使用时，表示共花费 2 点行动力 |
| **快速** | 不花费行动力，任何时段可执行 |
| `↩️` | 不花费行动力，条件触发时立即执行 |
| ⏳ 延迟 | 策略牌效果标签。打出时消耗 `➡️` 作为布局，满足条件时翻开执行效果 |
| 【被动】 | 角色技能，常驻生效，无需消耗行动 |

### 9.2 术语表

| 术语 | 说明 |
| ------ | ------ |
| 轮（Round） | 一轮包含傍晚→夜晚→黎明三个阶段 |
| 回合（Turn） | 一名玩家的完整行动流程（开始→补给→行动→修整→结束） |
| 行动力 | 每回合拥有的行动点数，默认 2 点。每个 `➡️` 代表 1 行动力 |
| 情报 Token | 蓝色方块，全阵营通用资源，通过调查行动从地点获取 |
| 证据 Token | 罪犯头像圆片，标记犯罪位置和抓捕门票 |
| 隐藏值 | 罪犯的隐蔽程度（0-3），决定抓捕的情报补差成本 |
| 犯罪等级 | 罪犯角色的危险等级（1-4），决定得分和看守所位置 |
| 看守所 | 被捕罪犯的证据 Token 放置区域，随时间递减越狱 |
| 警员 Token | 警长布控工具，提升地点情报值 |
| 迷雾 Token | 2-3 人局专用，灰色双面 Token，红色面视为证据 |
| 策略牌 | 公共卡牌，提供战术选择（`➡️`/快速/`↩️`） |
| 供应堆 | 游戏外的公共资源储备 |
| 超额犯罪 | 在影响力高于自身犯罪等级的地点犯罪时获得的额外 +1 分 |

## 10. 常见边界条件 FAQ

### Q1：地点上情报 Token 为 0 时还能调查吗？

**不能**。情报值 0 的地点无法执行"调查"行动。

### Q2：地点上情报 Token 为 0 时还能犯罪吗？

**能**。地点上情报 Token 为 0，代表该地点所有未知情况均已被探明，可以轻松完成犯罪。此时执行犯罪无需消耗情报 Token，但仍需放置证据 Token 并正常获得分数。

### Q3：多个罪犯在同一地点放置了证据 Token，警长侦查时选哪个？

警长选择其中一个罪犯的证据 Token 获得。

### Q4：警长手中持有证据 Token 时，罪犯越狱了，证据 Token 如何处理？

**警长手中持有的该罪犯的证据 Token 全部放入看守所**。抓捕时会将所有该角色持有的证据 Token 放置入看守所，与越狱机制联动。

### Q5：罪犯的隐藏值能降到负数吗？

**不能**。隐藏值最低为 0。调查仅将隐藏值降至 0，不会为负。

### Q6：警长布控的地点，情报值 +2 是永久性的吗？

**不是**。仅在当前轮有效，黎明阶段收回警员 Token 后恢复原值。

### Q7：策略牌打完后去哪里？

公共弃牌堆。牌堆为空时，将弃牌堆洗混形成新的牌堆。

### Q8：延迟策略牌翻开后去哪里？

执行效果后进入公共弃牌堆。

### Q9：罪犯被捕后还能使用快速牌和 ↩️ 牌吗？

**不能**。在看守所中只能执行规定的看守所行动（弃牌换情报或越狱），不能使用快速牌、↩️ 牌和被动技能。

### Q10：超级英雄和受害者如何得分？

详见 [04-角色设计.md](./04-角色设计.md) 第 4-5 节的技能描述。他们通过各自的专属技能获得分数。
