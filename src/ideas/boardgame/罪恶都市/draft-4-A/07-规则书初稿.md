## 1. 游戏概述

### 1.1 背景故事

罪恶都市——一座被黑暗笼罩的城市。警长在体制内艰难执法，罪犯在街头暗中活动。所有人都在这座城市里追逐自己的利益，互相利用、互相压制。谁能第一个达到 15 分，谁就能在这场无休止的博弈中胜出。

### 1.2 游戏目标

- **跑分制**：最先达到 15 分的玩家获胜
- **回合上限**：第 12 轮结束时，分数最高者获胜
- **同时达标**：若多名玩家在同一轮结束时达到 15 分，按分数高低排名，同分则按距离 15 分差额小者胜

### 1.3 游戏人数与阵营

本游戏共有 4 个阵营：**警长**、**罪犯**、**超级英雄**、**受害者**。标准 4 人局仅使用警长和罪犯；5 人及以上时逐步加入超级英雄和受害者。

| 人数 | 警长 | 罪犯 | 超级英雄 | 受害者 | 说明 |
| :-: | :-: | :-: | :-: | :-: | - |
| 2 | 1 | 1 | | | 迷雾阶段 2 次/轮 |
| 3 | 1 | 2 | | | 迷雾阶段 1 次/轮 |

## 2. 配件说明

详见 [03-组件清单.md](./03-组件清单.md)。以下为游戏设置和进行过程中必需的核心配件：

| 配件 | 用途 |
| ------ | ------ |
| 地点牌（12 张，4 人局） | 组成城市版图，含 1 张特殊地点牌「看守所」 |
| 角色卡（每名角色 1 张） | 确定身份和技能，罪犯角色卡底部印有隐藏值轨道 |
| 策略牌（35 张，公共牌堆） | 提供战术选择 |
| "情报 Token"（蓝色方块） | 全阵营通用资源 |
| "证据 Token"（罪犯头像圆片） | 标记犯罪 + 抓捕门票 |
| "警员 Token"（警徽圆片） | 警长布控专用 |
| 隐藏值指示物（小方块） | 放在角色卡隐藏值轨道上标记当前隐藏值 |
| 分数/回合共用面板 | 一条轨道标记各角色分数（0-15），另一条标记当前回合（1-12） |

**供应堆**分为两类：

- **公共供应堆**：牌堆、分数标记、"情报 Token" 储备等
- **角色供应堆**：每个角色自身拥有的配件，如警长的"警员 Token"、罪犯的"证据 Token"等

## 3. 游戏准备

### 3.1 版图设置

```
① 将 16 张地点牌按上城（4 张）、核心（8 张）、下城（4 张）分成 3 堆
② 从上城主堆中随机抽取 3 张，核心区抽 6 张，下城区抽 3 张
③ 将 12 张地点牌全部展出，排成 3×4 网格（4 人及以上局）；2-3 人局改为上 3+核心 3+下 3 = 9 张，排成 3×3
④ 将「看守所」地点牌放在版图旁边（单独放置，不参与版图网格）
⑤ 在每个地点上放置等于其情报值数量的"情报 Token"
⑥ 剩余"情报 Token"放入公共供应堆
```

### 3.2 角色分配

详见 [04-角色设计.md](./04-角色设计.md) 第 6 节。

```
① 所有玩家从自己所属阵营的角色池中随机抽取 2 张，选择其中 1 张作为本局角色
② 各玩家获得对应角色卡
③ 警长玩家获得：5 个"警员 Token"（放入自己的角色供应堆）
④ 罪犯玩家额外获得：
   ├─ 5 个印有自己角色头像的"证据 Token"（放入自己的角色供应堆）
   └─ 1 个异色小方块，放在角色卡隐藏值轨道的上限数字上作为初始值
⑤ 所有玩家获得初始资源：1 张策略牌（从公共牌堆摸取）
```

### 3.3 其他设置

```
① 将 35 张策略牌洗混，形成公共牌堆，放在版图旁边
② 将分数标记等放在公共供应堆
③ 设置回合标记为 1（第 1 轮）
④ 警长作为每轮的起始玩家（从警长开始按顺时针进行）
```

## 4. 核心规则

### 4.1 能力

能力是描述卡牌效果的文字。卡牌必须**在场上**（已打出并放置在你的角色区域、已展出的地点牌等）才能发动其能力。

#### 持续能力（被动）

没有额外图标，常驻生效。例如角色「铁拳」马库斯的"硬汉体质"——越狱的情报花费减少 1。

#### 触发能力

在效果文字前标有图标，玩家必须满足触发条件才能主动触发：

| 图标 | 类型 | 说明 |
| ------ | ------ | ------ |
| ⚡️ | 免费触发能力 | 任意时机触发，不消耗行动 |
| ↩️ | 反应触发能力 | 满足特定条件时触发。格式：`↩️ [触发条件]：[效果]` |
| ➡️ | 行动触发能力 | 在你的回合中花费 1 个行动来主动触发。格式：`➡️ [费用/条件]：[效果]` |

示例：

- 无额外费用：`➡️：获得 1 "情报 Token"`
- 有条件：`↩️ 在你打出策略牌后：摸 1 张牌`
- 地点牌上的能力：`➡️ 花费 2 情报：获得 1 分`

### 4.2 行动

每回合拥有 **2 点行动力**，可执行最多 2 个行动。游戏中共有以下 9 种行动：

| 行动 | 效果 | 适用 |
| ------ | ------ | ------ |
| 调查 | 从任意地点获得 1 个"情报 Token"（罪犯使用时，自身隐藏值 -1） | 全阵营 |
| 摸牌 | 从公共策略牌堆摸 1 张牌 | 全阵营 |
| 出牌 | 打出手中的 1 张策略牌 | 全阵营 |
| 侦查 🔵 | 选择一个地点，花费等于该地点当前情报值的"情报 Token"，获得该地点上 1 个"证据 Token" | 警长专用 |
| 布控 🔵 | 选择一个地点，放置 1 个"警员 Token"，该地点情报值 +2（本轮有效） | 警长专用 |
| 抓捕 🔵 | 额外花费 1 个行动。选择一名罪犯，将你持有的全部 X 枚该罪犯的"证据 Token"移入看守所的 A 位置；若 X < 其当前隐藏值，每差 1 额外花费 2"情报 Token"。+A 分，A 为该罪犯的犯罪等级；如果 X < 犯罪等级，额外 +1 分 | 警长专用 |
| 隐藏 🔴 | 提高隐藏值 1 点（不超过角色卡上限） | 罪犯专用 |
| 犯罪 🔴 | 额外花费 1 个行动。选择地点，花费情报（=地点当前情报值），放置 1 个"证据 Token"，获得影响值对应分数；若地点影响值 > 犯罪等级，额外 +1 分；若 5 个"证据 Token"全在版图上则改为移动 1 个 | 罪犯专用 |
| 越狱 🔴 | 额外花费 1 个行动。处于看守所的罪犯，花费 3"情报 Token"+ 弃置 1 张手牌，移出看守所 | 罪犯专用 |

> 抓捕、犯罪、越狱各固定消耗 2 点行动力（本身 1 个行动 + 额外 1 个行动）。

### 4.3 花费与效果

执行一切行动时，遵循以下规则：

- **花费与效果分离**：先支付行动的花费（行动力、"情报 Token"等），再执行行动的效果
- **效果被取消时不退费**：若某个行动或卡牌的效果被取消（如被 ↩️ 能力阻止），已支付的花费**不予退回**
- **花费的类型**：行动力、"情报 Token"、弃置手牌等都属于花费；"获得分数"、"将证据移入看守所"、"使效果失效"等属于效果

> **示例**：警长执行抓捕时，先花费 2 点行动力（抓捕固定额外消耗 1 个行动），再执行将"证据 Token"移入看守所并获得分数（效果）。若罪犯使用 ↩️ 能力使效果失效，已花费的行动力不会退回。

### 4.4 标签

标签是出现在卡牌上的简短规则标记：

| 标签 | 出现范围 | 说明 |
| ------ | -------- | ------ |
| **重大** | 任意卡牌或能力的效果 | 标注"重大"的效果每回合仅能执行 1 次 |
| ⏳ **延时** | 仅策略牌的效果 | 打出时正面向上放在你的角色区域，不立即生效，满足条件时结算其效果 |
| **快速** | 仅策略牌的效果 | 打出该策略牌时无需花费行动 |

### 4.5 资源

#### 情报 Token

蓝色方块，全阵营通用基础资源，存放在公共供应堆。

- 玩家通过"调查"行动从地点获得
- 几乎所有的行动都需要花费"情报 Token"
- **无持有上限**（手牌有上限 3 张）

#### 证据 Token

每个罪犯角色有 5 个印有自己头像的圆形 Token，存放在自己的**角色供应堆**。

- **放置**：罪犯执行"犯罪"行动时，将 1 个自己的"证据 Token"从角色供应堆放置到地点上
- **获得**：警长执行"侦查"行动时，花费情报获得地点上的 1 个"证据 Token"（暂时持有）
- **抓捕**：警长执行"抓捕"行动时，将持有的全部该罪犯"证据 Token"移入看守所
- **溢出**：若 5 个"证据 Token"已全部在版图上（角色供应堆为空），执行犯罪时改为将其中 1 个已在地点上的"证据 Token"移动到新的目标地点（原地点上的"证据 Token"消失）

> **"证据 Token" 循环**：角色供应堆 → 犯罪（放置到地点）→ 侦查（警长暂时持有）→ 抓捕（移入看守所）→ 越狱/黎明自动出狱（返回角色供应堆）

### 4.6 隐藏值（仅罪犯）

每个罪犯角色有一个隐藏值（0 到角色卡上限，通常为 3），用角色卡底部的隐藏值轨道表示。

- **提高方式**：执行"隐藏"行动（+1）/ 每回合补给阶段自动回复 1 / 越狱时重置为上限
- **降低方式**：执行"调查"行动（-1，可降至 0）
- **核心作用**：警长执行"抓捕"时，若消耗的"证据 Token"数量 < 当前隐藏值，每相差 1 点需额外花费 2 个"情报 Token"
- **被捕时不变**：罪犯被逮捕时隐藏值保持不变，越狱后才重置为角色卡上限

### 4.7 犯罪等级（仅罪犯）

角色卡上标注的犯罪等级（1-4），决定抓捕得分、越狱起始格、超额犯罪条件。

- **超额犯罪**：在影响力高于自身犯罪等级的地点犯罪时，额外 +1 分

| 犯罪等级 | 超额犯罪条件 | 符合条件的区域 |
| --------- | ------------ | -------------- |
| 1 | 影响值 > 1 | 核心区(2)✅ + 上城区(3/4)✅ |
| 2 | 影响值 > 2 | 上城区(3/4)✅ + 核心区部分(3)✅ |
| 3 | 影响值 > 3 | 博物馆(4)✅ |
| 4 | 影响值 > 4 | 无区域符合 |

## 5. 回合流程

### 5.1 回合结构总览

```
一轮结构（约 10-20 分钟 / 4人局）
① 傍晚阶段（约 30 秒）
② 夜晚阶段（核心行动阶段，按顺序进行每个玩家的回合）
③ 黎明阶段（约 1 分钟）
```

> 2-3 人局额外有迷雾阶段：**傍晚 → 迷雾 → 夜晚 → 黎明**

### 5.2 傍晚阶段

```
① 结算"傍晚阶段"效果的 ⏳ 延时能力
② 触发"新的一轮开始时"效果的能力
③ 宣布"傍晚结束，进入夜晚阶段"
```

### 5.3 迷雾阶段（仅 2-3 人局）

> 详细机制见 [02-核心循环.md](./02-核心循环.md) 第 5 节

```
① 由警长操作，执行（3 - 罪犯人数）次迷雾行动
② 每次：从情报值最高的地点中选 1 个 → 移除 1"情报 Token"
   → 检查"迷雾 Token"状态：无则放灰色，灰色则翻红（视为证据）
③ 宣布"迷雾阶段结束，进入夜晚"
```

### 5.4 夜晚阶段 — 玩家回合

**回合顺序**：从警长开始，按顺时针依次进行。

每个玩家的回合包含 5 个子阶段：

#### ① 开始阶段

```
触发"回合开始时"效果的能力
```

#### ② 补给阶段

```
摸 1 张策略牌（从公共牌堆顶部摸取）
```

#### ③ 行动阶段

每回合拥有 **2 点行动力**，可执行最多 2 个行动。行动清单见 §4.2。

> 抓捕、犯罪、越狱各消耗 2 点行动力。出牌时若策略牌带有"快速"标签则不消耗行动。

#### ④ 修整阶段

```
检查手牌中的策略牌数量：
- 若 > 3 张，弃置多出的牌，直到手牌 = 3 张
- "情报 Token"无上限，无需弃置
```

#### ⑤ 结束阶段

```
触发"回合结束时"效果的能力
宣布"我的回合结束"，轮到下一位玩家
```

### 5.5 黎明阶段

```
① 看守所中的"证据 Token"向右移动 1 格（数字减少）
   Token 到达 0 格 → 越狱成功 → 释放 Token
② 收回所有"警员 Token"（布控效果结束）
③ 触发"黎明阶段"效果的能力
④ 警长检查：版图上无任何"证据 Token" → 警长得 1 分
⑤ 检查终局条件：
   ├─ 是否有玩家分数 ≥ 15 分 → 进入游戏结算
   └─ 当前轮次是否为第 12 轮 → 进入游戏结算
⑥ 未结束 → 回合标记 +1 → 进入下一轮的傍晚阶段
```

## 6. 各阵营行动详解

### 6.1 警长专属行动

#### 侦查

```
条件：
├─ 选择 1 个地点（任意区域）
├─ 拥有 ≥ 该地点当前情报值 数量的"情报 Token"
└─ 该地点至少有 1 个"证据 Token"

执行：
├─ 花费 = 地点当前情报值 的"情报 Token"
├─ 从该地点获得 1 个"证据 Token"（选择要拿哪个罪犯的）
└─ 将获得的"证据 Token"放在自己面前（暂时持有）
```

#### 警员 Token 与布控

"警员 Token"是警长专用的布控工具，共 5 枚，放在警长的**角色供应堆**。

- 放置在地点上 → 该地点情报值 +2（本轮有效），但同一地点不能放置 2 个以上
- 黎明阶段自动收回所有"警员 Token"

```
条件：
├─ 选择 1 个地点（"学校和图书馆"除外）
└─ 有可用的"警员 Token"

执行：
├─ 该地点情报值 +2（仅在计算侦查成本时生效）
└─ 该地点上已有的"证据 Token"不受影响
```

#### 抓捕

```
额外花费：1 个行动

条件：
├─ 选择 1 名罪犯作为目标
├─ 持有至少 1 个该罪犯的"证据 Token"
├─ 该罪犯不在看守所中

执行（花费 → 效果）：
├─ 【花费】花费 2 点行动力
├─ 【花费】（额外的）"情报 Token"
│   └─ 若"证据 Token"数量 < 该罪犯的当前隐藏值：每相差 1 点，额外花费 2 个"情报 Token"
├─ 【效果】将所有该罪犯的"证据 Token"移入看守所面板
├─ 【效果】获得分数 = 该罪犯的犯罪等级
├─ 【效果】若移动的"证据 Token"数量 < 该罪犯的犯罪等级，额外 +1 分

注意：
- 被捕时罪犯的隐藏值保持不变（作为抓捕时的读数），不会因被捕而变动
- 越狱后才重置为角色卡上限

示例：
├─ 罪犯"毒蛇"（犯罪等级 2，当前隐藏值 2）
├─ 警长手中持有 2 个"毒蛇"的"证据 Token"
├─ 移入全部 2 个"证据 Token" → 放入看守所
├─ 移动数 2 = 隐藏值 2，无需额外"情报 Token"
├─ 获得 2 分（犯罪等级 2）

示例 2（证据不足，用情报补差）：
├─ 罪犯"屠夫"（犯罪等级 3，当前隐藏值 2）
├─ 警长手中持有 1 个"屠夫"的"证据 Token"
├─ 移入全部 1 个"证据 Token"
├─ 移动数 1 < 隐藏值 2 → 差 1 → 额外花费 2"情报 Token"
├─ 放入看守所
├─ 获得 3 分（犯罪等级 3）
└─ 移动 1 < 犯罪等级 3 → 高效抓捕额外 +1 分 = 共 4 分
```

### 6.2 罪犯专属行动

#### 隐藏

```
条件：当前隐藏值 < 角色卡上限

执行：隐藏值 +1（不超过角色卡上限）

作用：增加警长抓捕所需的情报代价（每多 1 隐藏值，警长需多花费 2 情报或更多证据）
```

#### 犯罪

```
额外花费：1 个行动

条件：
├─ 选择 1 个地点
├─ 拥有 ≥ 该地点当前情报值 数量的"情报 Token"
├─ 不在看守所中（被捕状态下不能犯罪）

执行（角色供应堆中有可用的"证据 Token"）：
├─ 花费 = 地点当前情报值 的"情报 Token"
├─ 将 1 个自己的"证据 Token"从角色供应堆放置到该地点上
├─ 获得分数 = 该地点的影响值
├─ 若该地点的影响值 > 你的犯罪等级，额外 +1 分

执行（角色供应堆中无可用"证据 Token"，全部在版图上）：
├─ 花费 = 地点当前情报值 的"情报 Token"
├─ 选择 1 个自己已在版图上的"证据 Token"，移动到新目标地点
├─ 获得分数 = 该地点的影响值
├─ 若该地点的影响值 > 你的犯罪等级，额外 +1 分

示例：
├─ 罪犯"老鼠"（犯罪等级 1）在贫民窟（影响值 1）犯罪
├─ 花费 2"情报 Token"，放置 1"证据 Token"
├─ 获得 1 分（影响值）
└─ 影响值 1 = 犯罪等级 1，不满足"大于"条件，无额外分

示例 2：
├─ 罪犯"毒蛇"（犯罪等级 2）在博物馆（影响值 3）犯罪
├─ 花费 5"情报 Token"，放置 1"证据 Token"
├─ 获得 3 分（影响值）
└─ 影响值 3 > 犯罪等级 2 → 额外 +1 分 = 共 4 分
```

#### 越狱

```
额外花费：1 个行动

条件：
├─ 自己的"证据 Token"在看守所中
├─ 拥有 ≥ 3"情报 Token"
├─ 手牌 ≥ 1 张

执行：
├─ 花费 3"情报 Token"
├─ 弃置 1 张手牌
├─ 所有自己的"证据 Token"从看守所移回自己的角色供应堆
├─ 隐藏值重置为角色卡上限
└─ 恢复完全行动能力（下个回合起可正常行动）

注意：越狱固定额外花费 1 个行动，意味着你本回合最多只剩 1 个行动
某些角色能力可以减少越狱的情报花费
```

### 6.3 通用行动

#### 调查

```
选择 1 个地点，从该地点获得 1 个"情报 Token"。
如果该地点当前情报值为 0，则无法获得。
如果执行者是罪犯，隐藏值 -1（降至 0 为止，不会为负数）。
```

#### 摸牌

```
从公共策略牌堆顶部摸 1 张牌。
如果牌堆为空，将弃牌堆洗混作为新的牌堆。
手牌上限为 3 张（修整阶段弃置超出部分）。
```

#### 出牌

```
打出手中的 1 张策略牌。

- 若策略牌带有"快速"标签：无需花费行动
- 若无"快速"标签：消耗 1 个行动
- 若策略牌带有"⏳ 延时"标签：打出时正面向上放在你的角色区域，不立即生效，在符合条件时结算其效果
- 策略牌上若有其他打出限制（如"仅在你的回合"等），须满足后才能打出
```

## 7. 看守所

看守所是一张特殊的**地点牌**，放置在版图旁边（不加入版图网格）。它拥有以下能力：

### 7.1 持续能力

**不可被选为目标**：看守所不可以被选为调查、侦查、犯罪等任何行动的目标。

**"证据 Token" 放置**："证据 Token"被放入看守所时，放置到其所属角色犯罪等级对应的数字区域。每个黎明阶段所有 Token 向右移动 1 格（数字减少 1）。

**行动限制**："证据 Token"位于看守所的角色，不能触发任何本地点以外的能力，不能进行其他任何行动。

### 7.2 触发能力

**弃牌换情报**（➡️➡️ 重大）：

```
弃置 1 张手牌 → 从公共供应堆获得 1"情报 Token"
```

**越狱**（➡️➡️ 重大）：

```
花费 3"情报 Token" + 弃置 1 张手牌 → 移动所有自己的"证据 Token"到角色供应堆
执行后隐藏值重置为角色卡上限，恢复完全行动能力
```

### 7.3 黎明阶段自动推进

每个黎明阶段，所有看守所中的"证据 Token"向右移动 1 格（数字减少 1）。Token 到达 0 格时 → 越狱成功 → 释放所有该罪犯的 Token 到其角色供应堆 → 罪犯恢复完全行动能力。

## 8. 胜利条件与计分方式

### 8.1 终局触发

| 条件 | 触发时机 |
| ------ | --------- |
| 任意玩家分数 ≥ 15 分 | 当前轮黎明阶段结束时 |
| 第 12 轮结束 | 第 12 轮黎明阶段结束时 |

### 8.2 得分途径

| 阵营 | 途径 | 分数 | 说明 |
| ------ | ------ | ------ | ------ |
| 罪犯 | 犯罪动作 | 地点影响值（1-3 分） | 每次犯罪获得 |
| 罪犯 | 超额犯罪 | 额外 +1 | 犯罪地点影响值 > 罪犯犯罪等级 |
| 罪犯 | 越狱动作 | 0 分（暂定） | 越狱本身不产生分数 |
| 警长 | 抓捕动作 | 犯罪等级（1-4 分） | 每次抓捕获得 |
| 警长 | 高效抓捕 | 额外 +1 | 移动证据数 < 犯罪等级 |
| 警长 | 无证据奖励 | +1 | 每个黎明阶段，版图上无任何"证据 Token"时 |
| 超级英雄 | 角色能力 | 视具体能力而定 | 详见角色卡能力描述 |
| 受害者 | 角色能力 | 视具体能力而定 | 详见角色卡能力描述 |

### 8.3 同时达标处理

若多名玩家在同一黎明阶段达到 ≥ 15 分：

```
① 按分数高低排名
② 分数相同时，按"距离 15 分的差额"排名，差额小者胜
③ 仍相同 → 共享胜利
```

## 10. 术语表

### 10.1 基础概念

| 术语 | 说明 |
| ------ | ------ |
| 轮（Round） | 一轮包含傍晚→夜晚→黎明三个阶段 |
| 回合（Turn） | 一名玩家的完整行动流程（开始→补给→行动→修整→结束） |
| 行动力 | 每回合拥有的行动点数，默认 2 点。执行 1 个行动消耗 1 点行动力 |
| "情报 Token" | 蓝色方块，全阵营通用资源，通过调查行动从地点获取 |
| "证据 Token" | 罪犯头像圆片，标记犯罪位置和抓捕门票 |
| 隐藏值 | 罪犯的隐蔽程度（0-3），决定抓捕的情报补差成本 |
| 犯罪等级 | 罪犯角色的危险等级（1-4），决定得分和看守所位置 |

### 10.2 效果标签

| 标签 | 出现范围 | 说明 |
| ------ | -------- | ------ |
| **重大** | 任意卡牌或能力的效果 | 标注"重大"的效果每回合仅能执行 1 次 |
| ⏳ **延时** | 仅策略牌的效果 | 打出时正面向上放在你的角色区域，不立即生效，满足条件时结算其效果 |
| **快速** | 仅策略牌的效果 | 打出该策略牌时无需花费行动 |

### 10.3 能力类型

| 图标/标记 | 类型 | 说明 |
| --------- | ------ | ------ |
| 无 | 持续能力（被动） | 常驻生效，无需触发 |
| ⚡️ | 免费触发能力 | 任意时机触发，不消耗行动 |
| ↩️ | 反应触发能力 | 满足特定条件时触发 |
| ➡️ | 行动触发能力 | 在你的回合中花费 1 个行动来主动触发 |

### 10.4 游戏元件

| 术语 | 说明 |
| ------ | ------ |
| 公共供应堆 | 牌堆、分数标记、"情报 Token"储备等公共资源的存放处 |
| 角色供应堆 | 每个角色自身拥有的配件存放处（如警员的"警员 Token"、罪犯的"证据 Token"） |
| 看守所 | 一张特殊的地点牌，被捕罪犯的"证据 Token"放置于此 |
| "警员 Token" | 警长布控工具，提升地点情报值 |
| "迷雾 Token" | 2-3 人局专用，灰色双面 Token，红色面视为证据 |
| 策略牌 | 公共卡牌，提供战术选择（可标注"快速"标签免行动打出） |
| 超额犯罪 | 在影响力高于自身犯罪等级的地点犯罪时获得的额外 +1 分 |

## 11. 常见边界条件 FAQ

### Q1：地点上"情报 Token"为 0 时还能调查吗？

**不能**。情报值 0 的地点无法执行"调查"行动。

### Q2：地点上"情报 Token"为 0 时还能犯罪吗？

**能**。地点上"情报 Token"为 0，代表该地点所有未知情况均已被探明，可以轻松完成犯罪。此时执行犯罪无需花费"情报 Token"，但仍需放置"证据 Token"并正常获得分数。

### Q3：多个罪犯在同一地点放置了"证据 Token"，警长侦查时选哪个？

警长选择其中一个罪犯的"证据 Token"获得。

### Q4：警长手中持有"证据 Token"时，罪犯越狱了，"证据 Token"如何处理？

警长手中持有的该罪犯的"证据 Token"全部移入看守所。看守所的持续能力会将其放置到对应犯罪等级的数字区域。

### Q5：罪犯的隐藏值能降到负数吗？

**不能**。隐藏值最低为 0。调查仅将隐藏值降至 0，不会为负。

### Q6：警长布控的地点，情报值 +2 是永久性的吗？

**不是**。仅在当前轮有效，黎明阶段收回"警员 Token"后恢复原值。

### Q7：策略牌打完后去哪里？

公共弃牌堆。牌堆为空时，将弃牌堆洗混形成新的牌堆。

### Q8：延时策略牌结算后去哪里？

结算效果后进入公共弃牌堆。

### Q9：罪犯被捕后还能使用 ⚡️ 和 ↩️ 能力吗？

**不能**。在看守所中只能执行看守所上的触发能力（弃牌换情报或越狱），不能触发任何本地点以外的能力。

### Q10：超级英雄和受害者如何得分？

详见 [04-角色设计.md](./04-角色设计.md) 第 4-5 节的能力描述。他们通过各自的专属能力获得分数。
