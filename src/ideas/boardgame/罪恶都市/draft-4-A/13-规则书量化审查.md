# 规则书量化审查报告

> 基于链式回合模型的规则书全面审查
> 审查范围：行动设计、资源系统、得分效率、子系统机制
> 审查日期：2026-07-30

---

## 一、审查方法

| 单位 | 含义 |
| - | - |
| AP | 1 个基础行动 |
| IP | 1 个"情报 Token" |
| VP | 1 分 |
| TP | 1 个完整回合 = 2AP + 补给1手牌 |

**基准锚定**：

- 调查：1AP → 1IP。同时地点IP-1
- 摸牌：1AP → 1手牌。手牌本身无收益，是兑现策略潜力的媒介
- 出牌：1AP+1手牌 → 牌面效果。因为手牌是摸牌储存的"策略潜力"，出牌的效果应显著>1才有意义的理由

### 1.1 设计原则

以下原则在本审查中作为判断依据：

| # | 原则 | 说明 |
| - | - | - |
| 1 | **得分效率一致** | 0技能下警长与所有犯罪等级的罪犯预期得分效率一致，极好发挥均可接近15VP |
| 2 | **规则一致** | 不因阵营不同而改变补给、胜利条件等全局规则。超级英雄/受害者的技能等同于基础行动 |
| 3 | **得分收益 ≠ 剥夺收益** | 得分是绝对领先（领先所有人），剥夺是相对优势（只压制1个对手），不能简单相加 |
| 4 | **技能效率 ≤ 基础效率** | 技能收益不应显著高于基础行动效率，否则玩家会优先用技能而非基础行动 |
| 5 | **摸牌=0即时收益** | 摸牌储存策略潜力，出牌兑现价值 |
| 6 | **读报是看守所保底** | 刻意低效，不与调查对比性价比 |
| 7 | **等级1不触发高效抓捕是叙事设计** | 小混混耗费警力，警长需在扫街与追大鱼之间抉择 |
| 8 | **等级1监禁1轮是惩罚** | 缺席1回合≈损失0.5-1VP作案机会 |
| 9 | **仅调查消耗版图IP** | 侦查/作案花费IP回流供应堆，不消耗版图资源 |
| 10 | **不出现已删除的内容** | 不对比前版本，不使用"修正/错误/撤回"等表述 |

## 二、基础行动审查

### 2.1 通用行动

| 行动 | 投入 | 直接产出 | 间接效果 | 评估 |
| - | - | - | - | - |
| **调查** | 1AP | 1IP + 地点IP-1 | 降低该地点后续侦查/作案成本 | ✅ 基准线 |

## 三、IP资源系统

### 3.1 IP 流向分析

```
IP 的两种去向：

① 调查：从版图→玩家手中
   版图IP -1，玩家 IP +1
   → 版图IP净减少

② 侦查/作案花费：从玩家手→供应堆
   玩家 IP -X（花费），版图 IP 不变
   → 这些IP回流供应堆，不消耗版图资源
   → 可在后续被火车站等地点的特殊效果重新放到版图上
```

**这意味着：只有调查才消耗版图IP。** 侦查和作案花费的IP回流供应堆，不会让版图上的IP变少。

### 3.2 版图IP消耗估算

```
初始版图IP（4人局标准抽取）：
  上城3张×4-5 = 12-15
  核心6张×3 = 18
  下城3张×2 = 6
  博物馆5×1 = 5（可能抽不到）
  ─────────────────
  约 36-44 IP

每轮调查次数估算（4人局）：
  3罪犯：每人需要IP来作案。调查同时降低隐藏值→罪犯不会纯调查。
          平均每罪犯每轮0.5-1.5次调查
  1警长：需要IP来侦查。警长也可以摸牌或布控替代调查。
          平均每轮0.5-1次调查
  ─────────────────
  每轮总调查次数 ≈ 2-4次

12轮总调查次数 ≈ 24-48次
每次调查移除1版图IP → 24-48 IP消耗

版图IP初始 ≈ 36-44
12轮后剩余 ≈ 36-44 - 24-48 = -12 ~ +20
```

**结论**：在低调查频率（2次/轮）下，版图IP够用。在高调查频率（4次/轮）下，版图IP在第8-10轮可能出现不足。

### 3.3 IP不足时的游戏状态

当版图IP不足时：

- **调查**：无法获取IP（Q1明确：IP=0不能调查）
- **作案**：免费（Q2明确：IP=0作案不需花费IP）
- **侦查**：免费（花费=地点IP=0），但需要该地点有证据

**后半局的节奏变化**：

- 版图IP耗尽 → 调查不能做 → 玩家只能通过摸牌/出牌/读报来"过"
- 但作案免费 → 有IP储备的罪犯可以连续作案 → 得分加速
- 侦查免费 → 警长可以低成本获取证据

这实际上是一个**自然的加速机制**——后半局版图资源枯竭，游戏节奏加快。这可能是设计意图的一部分。

**审查结论**：✅ **版图IP消耗机制整体合理，不存在必须修复的枯竭问题。** 如果测试中发现后半局节奏过快或过慢，可增加少量IP补充策略（如增加1-2张能以版图补充IP的策略牌），但不需要全局恢复机制。

### 3.4 情报Token持有

✅ 无持有上限正确。蓄力可能性是策略深度的一部分。

### 3.5 证据Token供给

每个罪犯5个证据Token。12轮作案4-6次，够用。溢出时自动移动。

✅ **合理。**

### 3.6 策略牌消耗

```
35张，每轮4人各摸1=4张/轮
第9轮耗尽，之后洗混弃牌堆
```

✅ **合理。** 后半程洗混增加不确定性。

## 四、得分效率与15VP目标审查

### 4.1 得分路径总览

| 阵营 | 得分路径 | 属性 |
| - | - | - |
| 警长 | 抓捕（得分=犯罪等级） | 基础 |
| 警长 | 高效抓捕（证据数<犯罪等级时+1） | 条件性基础 |
| 警长 | 无证据奖励（黎明无人有证据时+1） | 被动 |
| 罪犯 | 作案（得分=影响值） | 基础 |
| 罪犯 | 超额作案（影响值>犯罪等级时+1） | 条件性基础 |
| 罪犯 | 越狱得分 | 基础 |
| 罪犯 | 部分角色有得分技能 | 技能 |
| 超级英雄 | **只能通过技能得分** | 纯技能 |
| 受害者 | **只能通过技能得分** | 纯技能 |

### 4.2 作案得分详表（当前规则）

作案得分 = 地点影响值。若**影响值 > 犯罪等级**，额外+1VP。

| 等级 | 下城(影响值1) | 核心(影响值2) | 上城(影响值3) | 博物馆(影响值4) |
| - | :-: | :-: | :-: | :-: |
| **1** | 1 | 2+1=**3** | 3+1=**4** | 4+1=**5** |
| **2** | 1 | 2 | 3+1=**4** | 4+1=**5** |
| **3** | 1 | 2 | 3 | 4+1=**5** |
| **4** | 1 | 2 | 3 | 4 |

**理性罪犯的最优策略**：选择单次得分最高的区域。

| 等级 | 最优区域 | 得分 | 说明 |
| - | - | - | - |
| 1 | 上城/博物馆 | 4-5VP | 核心3VP也可接受，但上城4VP明显更高 |
| 2 | 上城/博物馆 | 4-5VP | 核心仅2VP，无吸引力 |
| 3 | 博物馆 | 5VP | 上城3VP，差距过大 |
| 4 | 博物馆 | 4VP | 仅此可选 |

**问题**：当前规则下，高分区域对上城/博物馆的激励过强，低等级罪犯没有理由去下城/核心。

### 4.3 作案链周期与12轮预估

**链式模型说明**（基于 12-收益量化分析.md v2）：

作案链 = 调查积累阶段（调查次数 = 目标地点IP值）+ 作案执行（1轮）

| 目标区域 | IP需求 | 调查次数 | 积累轮数 | +作案轮数 | 作案链周期 | 理论12轮次数 |
| - | - | - | - | - | - | - |
| 下城(IP2) | 2IP | 2次 | 1轮 | 1轮 | 2轮 | 5-6次 |
| 核心(IP3) | 3IP | 3次 | 1.5轮 | 1轮 | 2.5轮 | 4-5次 |
| 上城(IP4) | 4IP | 4次 | 2轮 | 1轮 | 3轮 | 3-4次 |
| 博物馆(IP5) | 5IP | 5次 | 2.5轮 | 1轮 | 3.5轮 | 3次 |

> 实际作案次数还需扣除被捕轮次。等级越高、隐藏值越低，被捕概率越大。

### 4.4 各等级罪犯得分预估（无技能）

**等级1**（隐藏值上限3）：

| 普通 | 核心 | 3VP | 4次 | 12VP | 被捕1次(-3VP) | **9VP** |
| 最差 | 核心 | 3VP | 3次 | 9VP | 被捕2次(-6VP) | **3VP** |

**等级2**（隐藏值上限3）：

| - | - | - | - | - | - | - |
| 最佳 | 上城 | 4VP | 4次 | 16VP | 被捕1次(-4VP) | **12VP** |
| 普通 | 上城 | 4VP | 3次 | 12VP | 被捕1-2次(-4~8VP) | **4-8VP** |
| 最差 | 核心 | 2VP | 3次 | 6VP | 被捕2次(-4VP) | **2VP** |

**等级3**（隐藏值上限2，风险更高）：

### 4.5 警长得分预估（无技能）

#### 抓捕得分详表

抓捕得分 = 犯罪等级。若移动的证据数 < 犯罪等级，额外+1VP（高效抓捕）。

| 犯罪等级 | 基础得分 | 高效+1条件 | 最得分 |
| - | - | - | - |
| 1 | 1VP | 证据数<1 → 需0证据→不可能 | 1VP |
| 2 | 2VP | 证据数<2 → 需1证据 | 2-3VP |
| 3 | 3VP | 证据数<3 → 需1-2证据 | 3-4VP |
| 4 | 4VP | 证据数<4 → 需1-3证据 | 4-5VP |

#### 抓捕链周期

抓捕链 = 等待作案 + 调查积累 + 侦查(1AP+地点IP) + 抓捕(2AP)

| 目标等级 | 侦查IP成本 | 总投入(含调查积累) | 周期 | 12轮次数 |
| - | - | - | - | - |
| 等级1 | 2-3IP | ≈2-3回合 | 2-3轮 | 4-6次 |
| 等级2 | 3-4IP | ≈3回合 | 3轮 | 3-4次 |
| 等级3 | 4-5IP | ≈3-4回合 | 3-4轮 | 3次 |
| 等级4 | 5IP | ≈4回合 | 4轮 | 2-3次 |

#### 12轮预估

| 场景 | 抓捕目标 | 抓捕次数 | 高效次数 | 无证据奖励 | **总得分** |
| - | - | - | - | - | - |
| **最佳** | 等级2×2 + 等级3×1 + 等级4×1 | 4次 | 3次(+3) | 3次 | **2+2+3+4 +3 +3 = 17VP** |
| **最佳(全大鱼)** | 等级2×1 + 等级3×1 + 等级4×2 | 4次 | 3次(+3) | 3次 | **2+3+4+4 +3 +3 = 19VP** |
| **普通** | 等级2×2 + 等级3×1 | 3次 | 1-2次(+1~2) | 2次 | **2+2+3 +1~2 +2 = 10-11VP** |
| **最差** | 等级1×2 | 2次 | 0次 | 1次 | **1+1 +0 +1 = 3VP** |

### 4.6 得分效率总结

| 阵营 | 12轮预估（无技能） | 含技能可达 | 能否到15VP |
| - | - | - | - |
| 罪犯等级1 | 3-12VP（普通9VP） | 9-15VP | ⚠️ 仅极好发挥+技能可及 |
| 罪犯等级2 | 2-12VP（普通4-8VP） | 6-15VP | ⚠️ 普通发挥远未达标 |
| 罪犯等级3 | 3-10VP（普通3VP） | 5-15VP | ❌ 普通发挥极低 |
| 罪犯等级4 | 0-8VP（普通0-2VP） | 2-15VP | ❌ 高风险低回报 |
| **警长** | **3-19VP（普通10-11VP）** | 10-19VP | ✅ 良好发挥可达 |

### 4.7 关键发现

1. **警长基线过高**：警长在普通发挥下已达10-11VP，良好发挥可达15VP+。这是因为抓捕等级2就有2VP，加上高效+1和无证据奖励。

2. **罪犯基线过低**：除等级1外，其他等级在普通发挥下远低于警长。等级3和等级4更是极度依赖不被抓——但他们的隐藏值上限只有2，极易被抓。

3. **罪犯罪名不副实**：犯罪等级高的角色应该得分更高，但当前规则下等级4反而得分最低（因为超额加分不可触发，且被捕风险最高）。

4. **15VP对警长合理，对罪犯过高**：以当前数值，仅技能极强的罪犯能接近15VP。

### 4.8 建议

方案A（推荐）：**修改超额规则为"≥"**（影响值≥犯罪等级时+1），详见 §8.1。

方案B：保持15VP但加强罪犯得分手段（需更大的技能增强）。

方案C：降低到12VP。

## 五、子系统审查

### 5.1 看守所

| 犯罪等级 | 入狱格 | 自然出狱 | 缺席行动 ≈ VP损失 |
| - | - | - | - |
| 1 | 1 | 下个黎明就出 | 缺席约1个回合 = 损失2AP ≈ 0.5-1VP作案机会 |
| 2 | 2 | 2个黎明后 | 缺席约2回合 = 损失4AP ≈ 1-2VP |
| 3 | 3 | 3个黎明后 | 缺席约3回合 = 损失6AP ≈ 1.5-3VP |
| 4 | 4 | 4个黎明后 | 缺席约4回合 = 损失8AP ≈ 2-4VP |

**等级1的1轮监禁构成惩罚**：缺席1回合=损失一次作案机会≈0.5-1VP。加上越狱也需要花费资源。

✅ **合理。** 不做调整。

### 5.2 越狱

越狱成本：每格2IP+弃1牌→+1分。效率相当于2IP+1牌换1VP。

对比作案（3-4IP+1证据→2-3VP），越狱的效率更低，但提供了"提前脱身"的战略弹性。

✅ **合理。**

### 5.3 迷雾阶段（2-3人局）

✅ 设计意图清晰。规则描述可略作补充。

### 5.4 无证据奖励

- 第1轮黎明：必触发（还没人作案）→ 1VP
- 第2-3轮：可能触发，概率下降
- 第4轮后：几乎不会触发
- 大批抓捕后：有机会触发

≈ 每局1-3VP。✅ **合理。**

### 5.5 初始资源

每人初始1策略牌+0情报Token。第1轮只能调查/摸牌/出牌。

✅ 第1轮紧缺有决策深度。**但可考虑+1情报Token提升开局体验**——非必须。

## 六、技能收益基准

### 6.1 基准校准

核心原则：**技能的效率不应显著高于基础行动的效率**，否则玩家会优先使用技能而非基础行动——但超级英雄和受害者例外，他们没有基础得分手段。

```
基础得分效率参考：
  作案（核心）：3AP+3TP+1证据 → 2VP ≈ 0.67 VP/TP
  作案的AP+IP投入 ≈ 5-6个资源单位 → 2VP

技能的成本收益应在同等量级，或略低（因为技能通常有更高灵活性）
```

### 6.2 技能成本收益建议表

| 成本类型 | 总资源成本 | 建议合理收益范围 | 说明 |
| - | - | - | - |
| ➡️ + 0IP | ≈1AP | 0.5-1VP 或 1-2IP | 相当于半次调查的收益 |
| ➡️ + 1IP | ≈2AP | 0.5-1.5VP 或 2-3IP | 略高于调查的纯资源收益 |
| ➡️➡️重大 | ≈2AP | 1.5-3VP | 重大消耗，应有高回报 |
| ⚡️ + 0IP | ≈0AP | 极低，纯触发福利 | 不能直接产生大局影响 |
| ⚡️ + 1IP | ≈1AP | 0-0.5VP | 不占行动的优势本身是价值 |
| ↩️ + 1-2IP | ≈1-2AP | 避免等量损失 | 成本≈避免的损失量级 |
| 被动 | ≈0AP | 0.3-0.5VP/轮 | 长期积累，每轮不应过高 |

### 6.3 技能应补足的得分

```
警长/罪犯的基础得分 ≈ 8-11VP/12轮
要达到15VP，需要额外 ≈ 4-7VP
技能每局触发3-5次 → 每次贡献0.8-2.3VP
→ 一些技能直接得分、一些间接辅助，综合合理

超级英雄/受害者没有基础得分
全靠技能 → 技能每次使用应有1-2VP产出
→ 目前这两个阵营的技能得分效率确实偏低
```

### 6.4 等级与技能收益的对应关系

**指导原则**：犯罪等级越低，基础得分效率越高，技能收益应**略低于**基准表上限；犯罪等级越高，基础得分效率越低，技能收益可以**接近或达到**基准表上限。

| 犯罪等级 | 基础得分特征 | 技能收益定位 |
| - | - | - |
| **1** | 得分效率最高（全部区域均可触发超额+1），被捕风险最低（1轮） | 技能收益应**低于**基准中位线。防御/控制类技能需附加次数限制 |
| **2** | 得分效率中等（核心区3VP，上城4VP），被捕风险标准（2轮） | 技能收益以**基准中位线**为准 |
| **3** | 得分效率偏低（仅博物馆5VP），被捕风险高（隐藏值2） | 技能收益可达到基准**上限** |
| **4** | 得分效率最低（隐藏值2+被捕4轮），仅博物馆5VP | 技能收益可**高于**基准上限，高风险需高回报补偿 |

> 例：等级1的防御技能（见风使舵），因等级1本身难被抓+得分效率高，该技能应附加使用次数限制，避免形成"零风险高收益"组合。

## 八、拟修改提案（待确认后执行）

### 8.1 作案得分调整

**目的**：在保持影响值（1/2/3/4）和犯罪等级（1/2/3/4）不变的前提下，引导罪犯自然前往与其等级匹配的区域，并使0技能下各阵营得分效率一致（极好发挥均可接近15VP）。

**改动**：超额加分条件从 `>` 改为 `≥`

- 当前：影响值 > 犯罪等级时额外+1分
- 改为：影响值 ≥ 犯罪等级时额外+1分

**改动后作案得分表**（加粗为触发超额加分的格子）：

| 等级 | 下城(影响值1) | 核心(影响值2) | 上城(影响值3) | 博物馆(影响值4) |
| - | :-: | :-: | :-: | :-: |
| **1** | 1+1=**2**(1≥1?是) | 2+1=**3** | 3+1=**4** | 4+1=**5** |
| **2** | 1(1≥2?否) | 2+1=**3**(2≥2?是) | 3+1=**4** | 4+1=**5** |
| **3** | 1 | 2(2≥3?否) | 3+1=**4**(3≥3?是) | 4+1=**5** |
| **4** | 1 | 2 | 3(3≥4?否) | 4+1=**5**(4≥4?是) |

**理性罪犯的最优策略**：

| 等级 | 最优区域 | 得分 | 说明 |
| - | - | - | - |
| 1 | 核心(3VP)或上城(4VP) | 3-4VP | 下城2VP可接受，上城4VP更优 |
| 2 | 核心(3VP)或上城(4VP) | 3-4VP | 核心从2VP→3VP，不再是禁区；上城4VP保持优秀 |
| 3 | 上城(4VP) | 4VP | 上城从3VP→4VP，与博物馆5VP差距缩小 |
| 4 | 博物馆(5VP) | 5VP | 博物馆4VP→5VP，与上城3VP差距扩大 |

**引导效果**：等级1/2有动力去核心（3VP）而非只冲上城；等级3上城4VP合理；等级4唯有博物馆5VP匹配高风险。

**12轮模拟（无技能，含被捕损失）**：

| 阵营 | 目标区域 | 单次得分 | 理论次数 | -被捕损失 | **12轮预估** |
| - | - | - | - | - | - |
| 罪犯等级1 | 核心/上城 | 3-4VP | 4-5次 | 1-2VP | **11-15VP** |
| 罪犯等级2 | 核心/上城 | 3-4VP | 3-4次 | 2-3VP | **9-13VP** |
| 罪犯等级3 | 上城 | 4VP | 3-4次 | 3-4VP | **8-12VP** |
| 罪犯等级4 | 博物馆 | 5VP | 3次 | 4-6VP | **9-11VP** |
| **警长** | — | 1-5VP | 3-4次 | — | **10-17VP** |

**0技能下15VP可达性**：

| 阵营 | 普通发挥 | 最佳发挥 | 含技能后 |
| - | - | - | - |
| 罪犯等级1 | 11VP | 15VP | 15VP+ ✅ |
| 罪犯等级2 | 9-11VP | 13VP | 13-15VP ✅ |
| 罪犯等级3 | 8-10VP | 12VP | 12-15VP ✅ |
| 罪犯等级4 | 9-11VP | 11VP | 11-15VP ⚠️（技能需补4VP） |
| 警长 | 10-13VP | 17VP | 17VP+ ✅ |

**结论**：仅改动一个符号（`>`→`≥`），即可实现：

1. 等级1的下城从1VP→**2VP**，核心保持3VP，自然引导向下城/核心 ✅
2. 等级2的核心从2VP→**3VP**，上城4VP，自然引导向核心/上城 ✅
3. 等级3的上城从3VP→**4VP**，自然引导向上城 ✅
4. 等级4的博物馆4VP→**5VP**，保持高风险高回报 ✅
5. 0技能下各阵营普通发挥均在8-13VP范围，含技能后可接近15VP ✅
6. 警长抓捕得分不变（犯罪等级不变），但罪犯得分提升→双方差距缩小 ✅

### 8.2 迷雾阶段调整（仅2-3人局）

**目的**：2人局中剥夺收益不稀释，警长抓捕效率过高。迷雾阶段改为消耗警长的侦查资源。

**设计**："迷雾 Token"所在的地点，警长侦查时必须先移除"迷雾 Token"（正常花费IP，但不获得"证据 Token"），移除后才能正常侦查该地点的"证据 Token"。

**效果**：2人局2个迷雾 → 警长每轮被迫多花至少2次侦查行动清除迷雾，大幅放慢抓捕节奏。
