## 1. 地点牌格式

所有地点牌统一使用以下布局：

```
┌──────────────────────┐
│    上城区 · 商业街     │  ← 区域标签（上城/核心/下城）+ 地点名
│                      │
│  ┌────────────────┐   │
│  │   地点插画区域    │   │
│  └────────────────┘   │
│                      │
│  情报值：4  影响值：3  │  ← 左上角情报值（蓝色数字），右下角影响值（红色数字）
│                      │
│  ── 特殊效果 ──      │
│  效果描述文字          │
│                      │
│  犯罪等级提示：        │
│  上城区 = 等级 3      │  ← 该区域对应的犯罪等级
└──────────────────────┘
```

### 地点牌参数说明

| 参数 | 说明 |
| ------ | ------ |
| **情报值** | 初始放置在该地点上的情报 Token 数量。决定"调查"可获得多少资源，"犯罪"需要消耗多少资源 |
| **影响值** | 在该地点执行"犯罪"行动时，罪犯获得的分数 |
| **犯罪等级** | 该地点的区域等级（上城=3/核心=2/下城=1），罪犯在此犯罪时比较自身犯罪等级与之决定是否获得"超额犯罪"额外分 |
| **特殊效果** | 部分地点拥有独特的机制效果 |

## 5. 地点牌配置规则

### 5.1 标准 4 人局设置

| 区域 | 可用牌数 | 每局抽取 | 组成版图 |
| ------ | --------- | --------- | --------- |
| 上城区 | 4 张 | 3 张 | 3 |
| 核心区 | 8 张 | 6 张 | 6 |
| 下城区 | 4 张 | 3 张 | 3 |
| **合计** | **16 张** | **12 张** | **9 张**（实际抽取时从 12 张中按上述数量抽取，组成 9 张版图） |

> 💡 设计说明：抽取时不使用布袋筛选，而是按上/核心/下三个袋子分别抽取对应数量的地点牌，确保版图各区有均衡的数量。

### 5.2 不同人数版图调整

| 人数 | 上城区 | 核心区 | 下城区 | 总计 |
| ------ | -------- | -------- | -------- | ------ |
| 2 人 | 2 张 | 3 张 | 2 张 | 7 张 |
| 3 人 | 2 张 | 4 张 | 2 张 | 8 张 |
| 4 人（基准） | **3 张** | **6 张** | **3 张** | **12 张 → 9 张版图** |
| 5 人 | 3 张 | 6 张 | 3 张 | 12 张 → 9 张版图 |
| 6 人 | 3 张 | 6 张 | 3 张 | 12 张 → 9 张版图 |
| 7 人 | 3 张 | 6 张 | 3 张 | 12 张 → 9 张版图 |

### 5.3 版图布局建议

抽取的地点牌建议按以下方式摆放（3 行 × 3 列）：

```
 ┌───────────┐
 │  上城  │  上城  │  上城  │  ← 上城区（犯罪等级 3）
 │─────────┤─────────┤─────────│
 │  核心  │  核心  │  核心  │  ← 核心区（犯罪等级 2）
 │─────────┤─────────┤─────────│
 │  核心  │  核心  │  核心  │  ← 核心区（犯罪等级 2）
 │─────────┤─────────┤─────────│
 │  下城  │  下城  │  下城  │  ← 下城区（犯罪等级 1）
 └───────────┘
```

> 💡 布局逻辑：上城区在最上方（远离罪犯的初始位置），下城区在最下方（靠近罪犯）。但实际游戏中玩家可以自由选择任意地点行动，无移动距离限制——布局仅用于视觉上区分区域等级。
