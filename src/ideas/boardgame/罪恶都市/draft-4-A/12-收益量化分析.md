## 一、审查方法

### 1.1 核心单位

| 单位 | 定义 |
| - | - |
| AP | 1 个基础行动 |
| IP | 1 个"情报 Token" |
| VP | 1 分 |

> 单位换算：1AP = 1IP（调查基准）。不引入TP作为技能收益评估单位。

### 1.2 技能收益基准（引自13-规则书量化审查.md §6.2）

| 成本类型 | 总资源成本 | 建议合理收益范围 | 说明 |
| - | - | - | - |
| ➡️ + 0IP | ≈1AP | 0.5-1VP 或 1-2IP | 相当于半次调查的收益 |
| ➡️ + 1IP | ≈2AP | 0.5-1.5VP 或 2-3IP | 略高于调查的纯资源收益 |
| ➡️➡️ 重大 | ≈2AP | 1.5-3VP | 重大消耗，应有高回报 |
| ⚡️ + 0IP | ≈0AP | 极低，纯触发福利 | 不能直接产生大局影响 |
| ⚡️ + 1IP | ≈1AP | 0-0.5VP | 不占行动的优势本身是价值 |
| ↩️ + 1-2IP | ≈1-2AP | 避免等量损失 | 成本≈避免的损失量级 |
| 被动 | ≈0AP | 0.3-0.5VP/轮 | 长期积累，每轮不应过高 |

### 1.3 等级与技能收益对应关系（引自13-规则书量化审查.md §6.4）

| 等级 | 基础得分特征 | 技能收益定位 |
| - | - | - |
| **1** | 得分效率最高，被捕风险最低 | 技能收益**低于**基准中位线。防御/控制类技能需次数限制 |
| **2** | 得分效率中等，被捕风险标准 | 技能收益以**基准中位线**为准 |
| **3** | 得分效率偏低，被捕风险高 | 技能收益可达到基准**上限** |
| **4** | 得分效率最低，被捕风险最高 | 技能收益可**高于**基准上限 |

### 1.4 ↩️ 技能评估方法

↩️ 技能的"避免等量损失"，评估时应区分两种情形：

| 情形 | 说明 | 例 |
| - | - | - |
| **避免自身损失** | 自己避免了资源/回合损失 | 金蝉脱壳：避免自己被捕 |
| **保护他人** | 让队友避免损失，非直接得分 | 见风使舵：保护任意角色 |
| **打断对方投入** | 让对方之前投入的资源作废 | 暗度陈仓：消除证据重置警长积累 |

↩️ 收益上限应由**使用次数限制**来平衡，而非直接超模判断。

| 维度 | 审查 |
