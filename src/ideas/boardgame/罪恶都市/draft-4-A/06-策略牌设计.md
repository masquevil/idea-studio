## 1. 策略牌格式与类型

### 1.1 卡牌格式

```
┌──────────────────────┐
│    情报报告            │  ← 策略牌名称
│                      │
│  ┌────────────────┐   │
│  │   卡牌插画区域    │   │
│  └────────────────┘   │
│                      │
│  类型：普通           │  ← 普通/快速/延迟
│                      │
│  ── 效果 ──          │
│  获得 2 个情报 Token  │  ← 效果文本
│                      │
│  "引用或背景文案"      │  ← 风味文本（可选）
└──────────────────────┘
```

### 1.2 三种类型

| 类型 | 卡背标识 | 打出时机 | 消耗行动 |
| ------ | --------- | --------- | --------- |
| 普通 | 无额外标识 | 行动阶段，作为"出牌"基础行动 | 是（算 1 基础行动） |
| 快速 ⚡ | 牌面标注"⚡ 快速" | 符合描述条件时随时打出 | **否**（不消耗行动，但有全局限制） |
| 延迟 ⏳ | 牌面标注"⏳ 延迟" | 行动阶段，作为"出牌"基础行动打出，**背面朝上**放在自己面前区域；在符合描述条件时翻开执行效果 | 是（打出时消耗 1 基础行动；翻开时不消耗行动） |

### 1.3 快速牌的全局限制

快速牌不消耗行动，但每轮每名玩家**最多只能打出 1 张快速牌**（防止快速牌滥用导致游戏节奏失控）。

## 2. 普通策略牌（20 张）

### 2.1 情报类（6 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 01 | **情报报告** | 3 张 | 获得 2 个情报 Token（从供应堆获得） |
| 02 | **情报截获** | 2 张 | 从任意地点获得 1 个情报 Token |
| 03 | **情报共享** | 1 张 | 选择 1 名玩家，双方各获得 1 个情报 Token |

### 2.2 干扰类（6 张）

| # | 名称 | 数量 | 效果 |
| --- | ------ | ------ | ------ |
| 04 | **情报干扰** | 2 张 | 在指定地点放置 2 个情报 Token |
| 05 | **尾随跟踪** | 2 张 | 选择 1 名罪犯，查看其当前隐藏值和手牌数量（不查看手牌内容） |
| 06 | **暗中观察** | 2 张 | 选择 1 个地点，查看该地点上所有证据 Token 的归属（不获得任何 Token） |

### 2.3 防御/反击类（4 张）

| # | 名称 | 数量 | 效果 |
|---|------|------|------|
| 07 | **暗中行动** | 2 张 | 提高或降低某角色的隐藏值 1 点（不超过角色上限，不低于 0） |
| 08 | **金库保险** | 2 张 | 选择 1 名玩家，该玩家本回合内不能被选为任何技能或卡牌效果的目标 |

### 2.4 资源转换类（4 张）

| # | 名称 | 数量 | 效果 |
|---|------|------|------|
| 09 | **证据交易** | 2 张 | 弃置 1 个证据 Token（从手中），获得 3 个情报 Token |
| 10 | **线人报酬** | 2 张 | 消耗 2 情报 Token，从牌堆顶部摸 2 张牌（保留 1 张，弃置 1 张） |

## 6. 各阵营的策略牌使用策略

### 6.1 警长优先关注的牌

| 牌名 | 理由 |
| ------ | ------ |
| 情报截获 #02 | 快速获得情报，支撑侦查/布控消耗 |
| 尾随跟踪 #05 | 掌握罪犯的隐藏值状态，决定抓捕时机 |
| 设伏 #16 | 双轮布控效果，可大大压制罪犯活动区域 |
| 大计划 #17 | 抓捕时额外 +1 分，提高得分效率 |

### 6.2 罪犯优先关注的牌

| 牌名 | 理由 |
| ------ | ------ |
| 情报报告 #01 | 快速积累情报，为犯罪准备资源 |
| 暗中行动 #07 | 提高自己的隐藏值，增加抓捕成本 |
| 紧急躲避 #12 | 防止被针对（包括警长抓捕和超级英雄私刑） |
| 不在场证明 #18 | 抵消抓捕，关键时刻保命 |
| 证据交易 #09 | 手上有证据 Token 但未放在版图时，可转化为情报 |

### 6.3 通用策略

| 牌名 | 适用场景 |
| ------ | --------- |
| 情报共享 #03 | 可与其他玩家建立临时合作关系 |
| 情报干扰 #04 | 警长用来提高犯罪难度，罪犯用来延缓警长侦查 |
| 证据误导 #11 | 罪犯用来混淆警长侦查目标（警长获得另一个罪犯的证据） |
| 恰到好处 #15 | 任何阵营都适用，积少成多 |

## 7. 平衡性说明

### 7.1 快速牌的全局限制

每轮每名玩家**最多只能打出 1 张快速牌**。原因：

- 防止快速牌累积过多导致"每轮额外打 3-4 张牌"的失控节奏
- 玩家需要选择最关键的时机使用快速牌
- 降低上手门槛（不用记大量时机触发项）

### 7.2 延迟牌的"延迟"设计

延迟牌在打出时消耗 1 基础行动，但翻开时不消耗行动。这种"前倾"设计：

- 让玩家在资源充裕时提前布局
- 翻开时机有不确定性（对手知道你有延迟牌，但不知道是什么）
- 增加心理博弈

### 7.3 与角色技能的兼容性

策略牌的设计原则是所有牌对所有阵营都有正面潜力。部分角色有"打出情报报告时额外+1"等技能联动，这些在设计角色时已考虑（如"鬼手"阿列克谢的精妙手法与调查联动）。

### 7.4 后续调整方向

| 调整方向 | 触发条件 | 建议调整 |
| --------- | --------- | --------- |
| 资源过剩 | 玩家普遍在修整阶段弃置大量情报 Token | 减少情报类卡牌数量，或提高情报消耗型行动的性价比 |
| 信息不足 | 玩家觉得"看不到对方的状态" | 增加信息类卡牌（如查看隐藏值、查看手牌） |
| 防御过强 | 防御类卡牌使用率过高 | 增加"无视防御"效果，或限制防御类卡牌的出牌时机 |
| 延迟牌节奏慢 | 玩家不愿意使用延迟牌 | 增强延迟牌效果，或减少延迟牌的消耗 |
