## 二、角色设计（04）评审

### ✅ 做得好的

| 项目 | 评价 |
| ------ | ------ |
| 警长三角色区分度 | 铁腕（正面进攻）、猎犬（侦查控制）、智囊（信息战术）三种风格清晰的区分 |
| 罪犯 8 角色多样性 | 4 个犯罪等级 × 各等级不同技能方向，提供了 56 种组合（C(8,3)） |
| 技能类型丰富 | 被动/普通/快速三种类型搭配合理，没有过度复杂的技能描述 |
| 背景故事贴切 | 代号+角色名+职位的命名体系一致，风味感强 |
| 扩展阵营预留 | 超级英雄和受害者的技能方向合理，与核心循环不冲突 |

### 🔴 核心问题

| # | 优先级 | 问题 | 建议 |
| --- | -------- | ------ | ------ |
| R1 | 🔴 高 | **"铁腕"鲍默尔的"雷霆行动"技能与"幽灵"琪琪的"华丽骗术"可能存在数值失衡**：<br>- 铁腕消耗 2 情报获得额外 1 基础行动（价值 1 次调查=1 情报，或 1 次摸牌）<br>- 琪琪消耗 1 情报获得 2 情报（净赚 1 情报）+ 对方损失 2 情报（总收益差为 3）<br>琪琪的"华丽骗术"每轮净收益 1 情报（支出 1 获得 2，对方损失 2 但情报无上限，对方损失的实际影响取决于情境），相比之下铁腕的"雷霆行动"在多数情况下收益较低 | 建议①：限制"华丽骗术"的目标不能是警长（减少对唯一执法者的压制）<br>建议②：改为"消耗 1 情报 Token，从任意玩家处获得 1 情报 Token"（净收益 0，但削弱对方 1 情报）<br>建议③：将"华丽骗术"的消耗改为 2 情报，获得 2 情报（净收益 0，但对方损失 2） |
| R2 | 🔴 高 | **"双面人"维克托的"金融犯罪"+ "金蝉脱壳"存在"低风险稳得分"的优化策略风险**：<br>- 金融犯罪（普通技能，消耗 2 情报，不放置证据得 1 分，每轮限 1 次）= 相当于每轮稳定 1 分，零暴露风险<br>- 金蝉脱壳（快速，消耗 3 情报抵消抓捕）= 保命底牌<br>- 维克托可以全程不犯罪、不暴露，仅靠金融犯罪+隐藏，长期安全稳定得分的可能性存在 | 建议①：金融犯罪改为"消耗 3 情报 Token，不放置证据获得 1 分"（提高成本降低性价比）<br>建议②：金融犯罪改为"使用后本轮不能再执行其他得分行动"（限制连续得分）<br>建议③：金融犯罪改为"消耗 2 情报 Token，不放置证据，获得 1 分，然后你的隐藏值 -1"（使其也有暴露风险） |
| R3 | 🔴 高 | **"疯子"莱利的"连环作案"递增机制存在极端情况**：<br>- 第 4 次犯罪 +3 分（第 1 次正常得分 + 第 2 次+1 + 第 3 次+2 + 第 4 次+3...）<br>- 在上城区犯罪时：影响值 3 + 超额犯罪 +1 + 连环 +3 = 7 分/次<br>- 配合"制造恐慌"（情报值 +3，自己仍按原值计算）可进一步降低犯罪成本<br>- 虽然黎明重置，但如果前几轮不犯罪、最后一轮连续多次犯罪，可能一次性获得极高分数 | 建议增加限定："连环作案"的递增上限为 +3 分（即第 4 次起不再增加），防止后期单次得分过高失控 |

### 🟡 中优先级问题

| # | 优先级 | 问题 | 建议 |
| --- | -------- | ------ | ------ |
| R4 | 🟡 中 | **"老鼠"汤米的"人群掩护"（核心区/上城区调查不降隐藏值）可能导致策略单调**：<br>- 老鼠可以无脑在上城/核心调查，隐藏值始终不变<br>- 与其他罪犯必须权衡"调查 vs 暴露"形成对比，但老鼠的权衡完全消失了 | 建议改为："你在核心区调查时隐藏值不降低，在上城区调查时隐藏值 -1（而非 -2 的标准？）。" 保持一定权衡 |
| R5 | 🟡 中 | **"屠夫"汉斯的隐藏值上限 2 + 每回合自动回复 2 的组合可能不够平衡**：<br>- 自动回复 2 意味着被捕出狱后只需 1 回合即可恢复到上限 2<br>- 隐藏值上限 2 意味着警长只需 2 证据即可抓捕<br>- "亡命之徒"原本是高风险高回报，但高回复速度降低了风险的持续时间 | 建议改为：自动回复 1（标准值），但上限仍为 2。被捕后只有 1 回合的低安全期，但需要更多回合恢复，增加风险持续时间 |
| R6 | 🟡 中 | **"智囊"温斯洛的"战术分析"（查看手牌）在 4 人局中的实际价值可能偏低**：<br>- 查看手牌的战术价值取决于对手的手牌策略<br>- 在轻中策游戏中，玩家手牌通常只有 2-3 张，策略深度有限<br>- 与其他警长角色的主动压制技能相比，"纯信息"技能的价值可能不足 | 建议增强："战术分析"消耗 1 情报 Token，查看一名玩家的手牌 **并获得其中 1 张策略牌**（改为窃取，而非仅查看），增加有形的收益 |
| R7 | 🟡 中 | **"裁决者"赫尔曼的"自有审判"（消耗 4 情报直接送入看守所，无需证据）** 在 5-7 人局中的强度可能过高：<br>- 4 情报兑换 1 次无条件抓捕，相比警长的正式抓捕（需侦查→收集证据→消耗证据）来说成本过低<br>- 虽然每局限 1 次，但这是"跨阵营"的超级英雄能力，可能让警长玩家感到不公平 | 建议改为：消耗 4 情报 Token + **消耗 1 个义警标记**（超级英雄专属资源），限制使用频率的同时维持成本合理性 |

### 🟢 低优先级建议

| # | 优先级 | 建议 |
| --- | -------- | ------ |
| R8 | 🟢 低 | "夜枭"索隆的"夜巡"（获得任意地点上的 1 个证据 Token）可明确指出"无论归属"是否包括迷雾 Token，需与迷雾阶段的红色证据一致 |
| R9 | 🟢 低 | 受害者的"黑料曝光"技能中"若分数不足 1 分则不扣分"——建议改为"若分数为 0 则不扣分"，因为分数不足 1 分=0 分，表述更精确 |
| R10 | 🟢 低 | 建议在角色卡牌的实际生产版本上，将基础行动速查表印刷在角色卡的背面，减少玩家参考卡的依赖 |

## 三、地点牌设计（05）评审

### ✅ 做得好的

| 项目 | 评价 |
| ------ | ------ |
| 16 张地点牌的多样性 | 各区域都有无效果的"基础"地点 + 有特殊效果的差异化地点 |
| 特殊效果与区域主题匹配 | 上城（金库/监控/珍宝）→ 高回报高难度；核心（走私/黑市/藏匿）→ 策略灵活；下城（捷径/黑市）→ 辅助性 |
| 无效果地点存在合理 | 商业街/老城区/贫民窟作为"干净"地点降低了学习负担 |
| 情报值/影响值分布合理 | 情报值 2-5 的梯度、影响值 1-3 的梯度都有逻辑 |
| 版图布局建议 | 3×3 网格 + 区域分区清晰，便于视觉定位 |

### ⚠️ 问题与建议

| # | 优先级 | 问题 | 建议 |
| --- | -------- | ------ | ------ |
| L1 | 🟡 中 | **"博物馆"的情报值为 5（比标准上城多 1）但影响值只有 3（与标准一样）**：<br>- 珍宝效果说"情报消耗比标准多 1 … 但额外获得 +1 分（共计影响值+1=4 分）"<br>- 文本产生矛盾：如果情报 5=标准+1，那么"多 1"是从 4 到 5 的多。但"额外+1 分"是从 3 到 4<br>- 玩家可能困惑：到底这卡是[情报 5 影响值 3 + 效果额外+1 分]还是[情报 4 影响值 3 + 效果情报值+1/影响值+1]？ | 建议重写特殊效果："珍宝：此地点初始情报值为 5（比标准上城多 1）。当你在此地点犯罪时，获得 4 分（影响值 3 + 珍宝额外 +1）而非 3 分。" 这样清楚说明"情报值=5，影响值=3，犯罪总得分=4" |
| L2 | 🟡 中 | **"地下酒吧"的情报黑市"全游戏共 3 次后该效果失效"——这是全局计数器**：<br>- 谁使用第 4 次时效果已经失效，但玩家可能不知道之前已被使用了 3 次？<br>- 需要一个全局计数器 Token 防止纠纷 | 建议：设计一个"黑市使用次数"标记（如 3 个 Token 放在卡牌上），每次有人使用效果时移除 1 个。3 个都用完后该效果永久失效 |
| L3 | 🟡 中 | **"学校和图书馆"不能布控——警长无法在该区域布置警员**：<br>- 这是一个"安全区"的设计，但与之对应的罪犯策略可能过于简单（直接去学校犯罪就不用担心布控）<br>- 并且学校图书馆的情报值只有 3（标准核心区），没有负面效果 | 建议增加一个小惩罚（或者保留为"安全区"也可以——轻量策略点）。当前可接受，但需在测试时关注是否成为"最优选择" |
| L4 | 🟢 低 | **2 人局的版图是上 2+核心 3+下 2=7 张，3 人局是上 2+核心 4+下 2=8 张**：<br>- 但 02-核心循环.md 的迷雾阶段机制中，迷雾行动的逻辑是"情报值最高的地点"，版图越小越容易集中压制<br>- 2 人局 2 次迷雾操作在 7 张版图上可能过快消耗情报 | 建议在测试阶段重点关注：2 人局中警长是否能通过 2 次迷雾操作在 7 张版图上制造足够的压力。如果不够，可考虑增加核心区到 4 张 |

## 四、策略牌设计（06）评审

### ✅ 做得好的

| 项目 | 评价 |
| ------ | ------ |
| 35 张牌的比例合理 | 普通 57% + 快速 26% + 延迟 17% 的比例符合预期战术节奏 |
| 快速牌的全局限制（每轮 1 张） | 防止快速牌滥用的关键控制，设计合理 |
| 延迟牌的"前倾"设计 | 提前布局→回报不确定，增加心理博弈 |
| 效果分类均衡 | 情报获取 29% + 信息获取 17% + 防御 23% + 进攻 17% + 得分 14%，覆盖全面 |
| 各阵营的使用优先级 | 给出警长/罪犯各自优先关注的牌，降低上手门槛 |

### ⚠️ 问题与建议

| # | 优先级 | 问题 | 建议 |
| --- | -------- | ------ | ------ |
| P1 | 🟡 中 | **"证据交易"（弃置 1 证据 Token → 获得 3 情报 Token）的触发场景有限**：<br>- 证据 Token 的天然持有者是警长（侦查后获得）和罪犯（犯罪后在版图上，或未放置的备用量）<br>- 罪犯的未放置证据 Token 数量：每个角色 5 个，最多同时放置 4 个（因为犯罪每次放 1 个，备用量可能不足）<br>- 但罪犯为何要弃置自己的证据 Token？除非他的证据 Token 全部在手上且不需要犯罪<br>- 对警长来说：获得证据后需要用来抓捕，弃置换情报的价值不高 | 建议①：改为"弃置 1 个 **版图上的** 证据 Token → 获得 3 情报 Token"（扩大适用范围）<br>建议②：增加"你可以在犯罪时额外消耗 1 个证据 Token 来替代情报消耗"的配合机制 |
| P2 | 🟡 中 | **"证据误导"（切换侦查目标）的效果描述可能存在执行歧义**：<br>- "当警长进行侦查时，改为获得该地点上另外 1 个证据 Token"<br>- 如果该地点上只有 1 个证据 Token 呢？没有"另外 1 个"可以切换 | 建议补充：如果该地点只有 1 个证据 Token，则此牌无效（不能使用）。或者改为"选择该地点的 1 个证据 Token 改为获得"（相当于让打牌者选择证据归属而非警长选择） |
| P3 | 🟡 中 | **"设伏"（延迟→黎明翻开→双轮布控）的效果与普通布控的关系不明确**：<br>- 普通布控使用警员 Token，黎明阶段收回<br>- "设伏"的警员 Token 在「本轮及下一轮都有效」<br>- 问题：这 1 个警员 Token 是额外多出来的？还是占用 5 个警员 Token 的配额？<br>- 如果是额外多出来的，警长可能同时有 7-8 个警员在场上（5 正常 + 2 设伏） | 建议明确："设伏"使用的警员 Token 来自供应堆（而非警长的 5 个配额），且黎明阶段不收回。但这样可能需要额外的 Token。改为"设伏的效果相当于在该地点放置 1 个不能被黎明阶段收回的警员 Token，沿用原有 5 个配额中的 1 个"——这又会影响正常布控的使用。建议改为"设伏：该地点的情报值在本轮及下一轮 +2（不消耗警员 Token，直接标记在卡牌上）" |
| P4 | 🟢 低 | **"线人报酬"（消耗 2 情报 → 摸 2 留 1）是一个"情报转换手牌"的战术牌**：<br>- 效果相当于用 2 情报换 1 张精选牌（弃牌堆中可能还有更好的选择？）<br>- 与"情报报告"（0 情报成本得 2 情报）相比性价比偏低 | 建议：改为"消耗 2 情报 Token，从牌堆顶部查看 3 张牌，选择 1 张加入手牌，其余 2 张弃置。"增加信息量和选择性 |
