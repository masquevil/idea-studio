## 1. 核心循环定义

### 1.1 罪犯的核心循环

```
┌────────────────────────────────────────────────────────────┐
│  罪犯的最小重复决策单元                                      │
│                                                             │
│  接收                                                       │
│  ├─ 查看：当前手牌、情报 Token 存量                          │
│  ├─ 扫描：哪些地点情报值高（可犯罪）、哪些证据已暴露            │
│  └─ 评估：警长的状态、其他罪犯的动向                         │
│       ↓                                                     │
│  选择 ← ← ← ← ← ← ← ← ← ← HDP（最难决策点）                │
│  ├─ 选项A：立即犯罪（在情报值最低的地点上犯罪，风险低收益低）    │
│  ├─ 选项B：积攒情报（消耗更多动作收集资源，为高收益犯罪铺路）    │
│  ├─ 选项C：转移视线（降低隐藏值，为后续高价值犯罪准备）        │
│  └─ 选项D：打出策略牌（干扰警长或其他罪犯，战术性操作）         │
│       ↓                                                     │
│  解决                                                       │
│  ├─ 消耗资源（情报 Token）                                   │
│  ├─ 放置证据 Token（标记犯罪地点）                            │
│  └─ 获得分数（影响值 + 可能的额外分）                         │
│       ↓                                                     │
│  回应                                                       │
│  ├─ 暴露：隐藏值降低（越高的犯罪收益 → 越大的暴露风险）         │
│  ├─ 等待警长反应：警长是否会来追查这个地点？                   │
│  └─ 调整策略：如果这次暴露太多，下次要更谨慎                    │
│       ↓                                                     │
│  传递 → 下一位玩家 / 下一轮                                     │
└────────────────────────────────────────────────────────────┘
```

#### 🎯 罪犯的 HDP（最难决策点）

> **"我要现在就犯罪拿低分，还是继续积攒资源/降低隐藏值去犯罪拿高分？"**

- **信息来源**：各地点当前情报值、自己的隐藏值、手牌
- **决策张力**：
  - 现在就犯罪 → 安全（情报值低 → 消耗少）→ 但收益低（影响值低的地点）
  - 积攒资源/降隐藏值 → 准备高收益犯罪（情报值高的上城区）→ 但可能被警长提前盯上
  - 等待的代价：多等一轮意味着警长多一轮侦查/布控→可能被捕
- **为什么是 HDP**：这是罪犯每回合最核心的"风险 vs 收益"权衡，直接影响胜负走向

### 1.2 警长的核心循环

```
┌────────────────────────────────────────────────────────────┐
│  警长的最小重复决策单元                                      │
│                                                             │
│  接收                                                       │
│  ├─ 查看：场上哪些地点有证据 Token                            │
│  ├─ 扫描：哪些地点被多次犯罪（高强度区域）                     │
│  └─ 评估：哪个罪犯最活跃、哪个最容易抓捕                       │
│       ↓                                                     │
│  选择 ← ← ← ← ← ← ← ← ← ← HDP（最难决策点）                │
│  ├─ 选项A：侦查立即抓捕（收集某罪犯的证据→尽快抓捕→得低分）    │
│  ├─ 选项B：广泛布控（消耗情报布控多个地点→限制罪犯活动范围）    │
│  ├─ 选项C：蹲守大鱼（等待某罪犯犯下更高罪→抓捕→得高分）        │
│  └─ 选项D：打出策略牌（干扰罪犯或增强自己的追查效率）           │
│       ↓                                                     │
│  解决                                                       │
│  ├─ 消耗情报 Token 进行侦查（获得证据 Token）                 │
│  ├─ 消耗证据 Token 进行抓捕（将证据送入看守所区域）            │
│  └─ 获得分数（犯罪等级对应分 + 可能的额外分）                  │
│       ↓                                                     │
│  回应                                                       │
│  ├─ 看守所递减：罪犯的证据每周期间减少/越狱→需重新抓捕          │
│  ├─ 调整布控：重新部署警员 Token                              │
│  └─ 评估局势：是否要转换追查目标                              │
│       ↓                                                     │
│  传递 → 下一位玩家 / 下一轮                                     │
└────────────────────────────────────────────────────────────┘
```

#### 🎯 警长的 HDP（最难决策点）

> **"我要立即抓一个低分罪犯确保稳定进账，还是放着大鱼养着等更高分？"**

- **信息来源**：各罪犯的证据分布、各罪犯的隐藏值信息、看守所状态、手牌
- **决策张力**：
  - 立即抓 → 稳定得分 + 减少场上罪犯数量 → 但分数低 + 对方很快越狱
  - 蹲守大鱼 → 等待罪犯积累更多犯罪记录 → 抓捕得分更高 → 但放任犯罪变相让罪犯得分
    - 还有一个风险：罪犯分数先到 15 分直接获胜
  - 布控压制 → 限制活动区域 → 但消耗行动不做抓捕 = 自己不直接得分
- **为什么是 HDP**：警长需要在"压制得分"和"自己得分"之间做平衡，同时要判断哪个罪犯是真正的威胁

### 1.3 非对称 HDP 关系

```
警长 HDP：立即抓低分 vs 蹲守高分
   ↕ 互相影响 ↕
罪犯 HDP：立即犯小案 vs 蓄谋大案

→ 警长选择蹲守 → 罪犯可以更自由地积攒资源 → 利于罪犯
→ 警长选择立即抓 → 罪犯必须更谨慎 → 但警长得分效率降低
→ 罪犯选择大案 → 分数高但暴露大 → 给警长高分抓捕机会
→ 罪犯选择小案 → 分数低但安全 → 警长得不到高抓捕分

结论：HDP 的对抗性天然构成猫鼠博弈的核心张力 ✓
```

## 2. 回合结构方案

### 2.1 整体回合结构

采用 v4 原始想法中的 **傍晚 → 夜晚 → 黎明** 三轮结构，保留并细化：

```
          一轮结构（约 10-20 分钟 / 4人局）
┌────────────────────────────────────────────────────────────┐
│  ① 傍晚阶段（约 30 秒）                                     │
│  ├─ 翻开/结算延迟卡牌效果（部分策略牌在此时触发）              │
│  ├─ 检查是否有"新的一轮开始时"触发的技能                      │
│  └─ 宣布"傍晚结束，进入夜晚"                                  │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐   │
│  │  ② 夜晚阶段（核心行动阶段）                           │   │
│  │  ├─ 警长回合 → 罪犯A回合 → 罪犯B回合 → 罪犯C回合      │   │
│  │  │  （固定顺序：从警长开始顺时针进行）                  │   │
│  │  │                                                      │   │
│  │  │  每个玩家回合内部：                                   │   │
│  │  │  ├─ ① 开始阶段（触发"回合开始时"效果）               │   │
│  │  │  ├─ ② 补给阶段：获得 1 情报 Token + 摸 1 张策略牌    │   │
│  │  │  ├─ ③ 行动阶段：2 基础行动 或 1 重大行动              │   │
│  │  │  │   └─ 基础行动清单（详见 2.2）                      │   │
│  │  │  │   └─ 重大行动清单（详见 2.3）                      │   │
│  │  │  ├─ ④ 修整阶段：手牌弃至上限 3 张                    │   │
│  │  │  └─ ⑤ 结束阶段（触发"回合结束时"效果）               │   │
│  │  └──────────────────────────────────────────────────────┘   │
│                                                             │
│  ③ 黎明阶段（约 1 分钟）                                     │
│  ├─ 看守所 Token 向右递减 1 格（数字减少 → 越狱进度推进）     │
│  │  （Token 到达 0 格 → 罪犯成功越狱，证据释放，恢复犯罪能力）  │
│  ├─ 收回所有警员 Token（布控仅在当轮有效）                     │
│  ├─ 触发"黎明阶段"效果（如有）                                │
│  ├─ 警长检查：版图上无任何证据 Token → 警长得 1 分            │
│  ├─ 检查是否有人达到 15 分（或第 12 轮结束）                  │
│  └─ 未结束 → 进入下一轮的傍晚阶段                              │
└────────────────────────────────────────────────────────────┘
```

### 2.2 基础行动清单

> 每人每回合可执行 **2 个基础行动**（可组合使用，可重复选择同一行动）

| # | 行动 | 效果 | 适用阵营 |
| --- | ------ | ------ | --------- |
| 1 | **调查** | 从任意地点获得 1 个情报 Token | 全阵营 |
| 2 | **摸牌** | 从公共策略牌堆摸 1 张牌 | 全阵营 |
| 3 | **出牌** | 打出手中的 1 张策略牌（普通/延迟） | 全阵营 |
| 4 | **侦查** 🔵 | 选择一个地点，消耗等于该地点当前情报值的情报 Token，获得该地点上的 1 个证据 Token | 警长专用 |
| 5 | **布控** 🔵 | 选择一个地点，放置 1 个警员 Token，该地点情报值在本轮+2 | 警长专用 |
| 6 | **隐藏** 🔴 | 降低自己的隐藏值 1 点（上限为 6） | 罪犯专用 |
| 7 | **使用技能** | 使用角色的"普通"技能（需消耗情报 Token 或满足其他条件） | 全阵营 |

> 🔵 = 警长专用 | 🔴 = 罪犯专用

### 2.3 重大行动清单

> 每人每回合可选择 **执行 1 个重大行动**（选择重大行动则不可执行基础行动）
> 重大行动 = 一次强力操作，相当于牺牲了本回合的灵活性换取一次高收益行动

| # | 行动 | 效果 | 适用阵营 |
| --- | ------ | ------ | --------- |
| 1 | **犯罪** 🔴 | 选择一个地点，消耗等于该地点当前情报值的情报 Token，将自己的 1 个证据 Token 放置在该地点上，获得该地点影响值对应分数；若该地点等级高于自己的犯罪等级，额外 +1 分 | 罪犯专用 |
| 2 | **抓捕** 🔵 | 选择一个罪犯，消耗 x 个该罪犯的证据 Token（x ≥ 该罪犯的当前隐藏值），将所有消耗的证据 Token 放入看守所区域（按该罪犯的犯罪等级放置在对应格），获得该罪犯犯罪等级的分数；若消耗证据数 < 犯罪等级，额外 +1 分 | 警长专用 |
| 3 | **越狱** 🔴 | 处于看守所区域的罪犯，消耗 1 个情报 Token 进行越狱尝试：投掷骰子或支付额外情报（待定），成功后移出看守所，恢复全部行动能力 | 罪犯专用 |
| 4 | **全力打击** 🦸 | 选择一个目标（罪犯或警长），执行一次强力的私刑行动（具体效果待超级英雄详细设计） | 超级英雄专用 |
| 5 | **舆论操控** 🎭 | 消耗情报 Token，制造媒体事件或信息垄断，获得对应分数（具体效果待受害者详细设计） | 受害者专用 |

> 🔵 = 警长专用 | 🔴 = 罪犯专用 | 🦸 = 超级英雄专用 | 🎭 = 受害者专用

### 2.4 回合顺序与先手优势补偿

**回合顺序**：固定顺序，从警长开始顺时针进行。

**先手优势分析**：

- 警长先手 → 拥有抓捕/布控的先机 → 但罪犯可以根据警长的动向后发制人
- 实际上警长的先手优势并不明显（罪犯可以看到警长动向再决定策略）
- 因此**无需额外的先手补偿机制**

**顺序优势补偿**：

- 如果未来测试中发现坐在警长下家的罪犯（最后一个行动）有明显劣势，可以考虑：
  - 最后行动的玩家在补给阶段额外获得 1 情报 Token
- 但当前设计阶段暂不增加，留待测试验证（参考模糊假设 H5）

### 2.5 "3-2-1" 简化检查

| 检查项 | 状态 | 说明 |
| -------- | ------ | ------ |
| **3 种核心行动** | ✅ | 调查（资源获取）、出牌/技能（战术）、犯罪/抓捕（得分） |
| **2 个选择层级** | ✅ | "做基础还是重大"的外层选择 + "做哪个具体行动"的内层选择 |
| **1 个核心张力** | ✅ | "罪犯想犯罪得分 vs 警长想抓捕得分"的猫鼠博弈 |

> ✅ "3-2-1" 检查通过：核心循环简洁但不简单，策略深度来自 HDP 的权衡而非规则复杂度

## 3. 胜利条件设计

### 3.1 终局触发条件

采用 **双触发机制**，以"先到 15 分"为主、"12 回合上限"为辅：

```
终局条件
├── 主要条件：有玩家在任一黎明阶段结束时达到或超过 15 分
│   └── 说明：由于是回合制，即使有人在夜晚阶段中途达到 15 分，
│             也要等到该轮黎明阶段结束时再结算
├── 备用条件：第 12 轮黎明阶段结束时，仍无人达到 15 分
│   └── 说明：防止游戏过长，12轮 ≈ 45-60 分钟（4人局）
└── 特殊条件：如果多个玩家在同一黎明阶段同时达到 15 分
    └── 处理：按分数高低排名；同分则按"距离 15 分的差额"排名，
              差额小者胜；仍相同则共享胜利
```

### 3.2 各阵营得分途径

| 途径 | 得分 | 归属 | 触发时机 | 限制条件 |
| ------ | ------ | ------ | --------- | --------- |
| **犯罪** | 地点影响值 + 可能额外 +1 | 罪犯 | 执行犯罪重大行动时 | 需消耗情报 Token → 放置证据 Token |
| **超额犯罪** | 额外 +1 | 罪犯 | 犯罪地点等级 > 犯罪等级 | 需要高犯罪等级或选上城区 |
| **抓捕** | 被捕罪犯的犯罪等级（1-4 分） | 警长 | 执行抓捕重大行动时 | 需收集足够证据 Token |
| **高效抓捕** | 额外 +1 | 警长 | 消耗证据数 < 犯罪等级 | 需要精准收集 |
| **无证据奖励** | +1 | 警长 | 每个黎明阶段 | 版图上无任何证据 Token |
| **越狱** | 可能 +1（待定） | 罪犯 | 越狱成功时 | 需讨论决定 |
| **私刑** 🔶 | 待定 | 超级英雄 | 待定 | 待阶段③细化 |
| **舆论/信息** 🔷 | 待定 | 受害者 | 待定 | 待阶段③细化 |

> 🔶 = 超级英雄 | 🔷 = 受害者

### 3.3 各阵营得分效率预估

基于 4 人局（1警长+3罪犯），12 轮预估：

```
┌─ 警长（1人）──────────────────────────────┐
│ 理想节奏：每 2-3 轮成功抓捕 1 次             │
│ → 12 轮约 4-6 次抓捕 × 2-3 分/次           │
│ → 预估总分：8-18 分                        │
│ 补充：无证据奖励 ≈ 12 轮 × 1 分 = 12 分    │
│ （条件苛刻，实际约 4-6 轮无人犯罪 ≈ 4-6 分） │
│ → 合理范围：12-20 分                       │
└────────────────────────────────────────────┘

┌─ 罪犯（3人）──────────────────────────────┐
│ 理想节奏：每 1-2 轮犯罪 1 次                │
│ → 12 轮约 6-12 次犯罪 × 1-3 分/次          │
│ → 预估总分：10-18 分                       │
│ （抢情报、降隐藏值都需要额外轮次准备）        │
│ → 合理范围：8-15 分                        │
└────────────────────────────────────────────┘

→ 警长与罪犯的得分曲线互相制衡：
  警长抓得越狠 → 罪犯被压制 → 警长得分↑ → 罪犯得分的↓
  罪犯犯罪越猖狂 → 警长无证据奖励↓ + 抓捕机会↑
→ 两者自然形成"此消彼长"的平衡 ✓
```

### 3.4 胜利条件与核心循环的关系

```
核心循环驱动得分，得分驱动胜利：
  罪犯犯罪 → 罪犯得分 + 留下证据 → 警长侦查/抓捕 → 警长得分
  
  证据作为"犯罪回报"和"抓捕线索"的二元角色：
  ┌─────────────────────────────┐
  │  罪犯视角：证据 = 犯罪的"收据"  │
  │  警长视角：证据 = 抓捕的"门票"  │
  └─────────────────────────────┘
  
  → 每个行动都同时服务于"得分"和"干扰对手"
  → 没有人能"各玩各的"，所有行动都互相影响 ✓
```

## 4. 各阵营核心机制

### 4.1 警长核心玩法

#### 角色定位

执法者，体制内的正义代表。有权力但也受限制——他需要证据才能行动。

#### 核心资源路线

```
情报 Token ──(消耗)──→ [侦查] ──→ 获得证据 Token
                               ──→ [布控] ──→ 地点情报值 +2 (限制犯罪)
                                     
证据 Token ──(消耗)──→ [抓捕] ──→ 罪犯入狱 + 获得分数
                               ──→ 证据送入看守所
```

#### 核心策略节奏

| 轮次 | 典型行动 | 目的 |
| ------ | --------- | ------ |
| 第 1 轮 | 调查 x2（或调查+侦查） | 积累初始情报，看准谁在犯罪 |
| 第 2-3 轮 | 侦查 + 布控 | 收集证据，同时压制一个区域 |
| 第 3-4 轮 | 抓捕（重大行动） | 首次抓捕，获得 2-3 分 |
| 后续 | 循环 | 维持压制节奏 |

#### 警长的关键策略选择

1. **集中火力**：盯住一个罪犯追查到底 → 快速多次抓捕+高分 → 但其他罪犯无人管
2. **广泛布控**：用警员 Token 压制多个地点 → 降低全局犯罪率 → 但自己不直接得分
3. **机会主义**：谁露头抓谁 → 灵活但缺乏深度 → 可能哪个都没抓牢

#### 警长的行动优势（来自 v4 想法：警长可执行更多行动）

**阶段②决定**：警长每回合仍使用"2基础或1重大"框架，但在以下方面拥有隐性优势：

1. **侦查成本低**：警长的"侦查"基础行动消耗情报 = 地点当前情报值
   - 地点情报值越低 → 侦查成本越低
   - 罪犯刚犯完罪的地点 → 情报被消耗 → 侦查成本低 → 天然激励警长追踪"刚犯罪的现场"
   - 这是一种**隐性的行动效率优势**，无需打破行动次数限制

2. **布控的压制效果**：一个布控可以影响多个罪犯（该地点的所有罪犯都受影响）

3. **无证据奖励**：如果警长压制得好，额外得 1 分

> 如果测试中警长得分偏低，再考虑给警长额外基础行动（每回合+1基础行动），暂不执行。

### 4.2 罪犯核心玩法

#### 角色定位

城市中的犯罪者，各自为战，通过犯罪获取分数。既要得分又要躲避警长。

#### 核心资源路线

```
情报 Token ──(消耗)──→ [犯罪] ──→ 放置证据 Token
  ↑                                  └──→ 获得分数
[调查 / 摸牌 / 技能]
  ↑
[隐藏] ──→ 降低隐藏值 → 降低被侦查成本
```

#### 隐藏值系统设计

> 对 v4 想法的细化和确定

| 参数 | 值 | 说明 |
| ------ | ----- | ------ |
| 隐藏值范围 | 1-6 | 6 = 最隐蔽（初始值），1 = 最暴露 |
| 初始隐藏值 | 6 | 所有人从最隐蔽状态开始 |
| 提高隐藏值 | 不主动提高 | 只能通过"降低隐藏值"被动消耗 |
| 降低隐藏值方式 | 获情报+1 隐藏（待定）/ 某些技能 | 部分行动会降低隐藏值 |

**隐藏值的核心作用**：

```
隐藏值 6（非常隐蔽）
  │ 警长侦查成本 ≈ 6 情报 → 很难被侦查
  │ （如果此时犯罪 → 获得证据→警长拿到的证据很便宜）
  ↓
隐藏值 3（中等暴露）
  │ 警长侦查成本 ≈ 3 情报 → 容易被侦查
  │ 但警长要抓捕需收集够证据
  ↓
隐藏值 1（极度暴露）
  │ 警长侦查成本 ≈ 1 情报 → 极易被侦查
  │ 抓捕成本 ≈ 1 证据 → 极可能被捕
```

**隐藏值调整方式（决定）**：

| 触发事件 | 隐藏值变化 | 说明 |
| --------- | ----------- | ------ |
| 执行犯罪（重大行动） | -1 | 犯罪暴露身份 |
| 执行隐藏（基础行动） | -1（向 1 方向降） | 主动藏匿（数值上是在降低隐藏值的数字） |
| 黎明阶段结束时 | -1 | 每轮自然暴露程度增加 |
| 被捕后越狱成功 | 重置为 6 | 越狱后全新身份，恢复犯罪能力 |

#### 犯罪等级系统

| 犯罪等级 | 代表角色 | 策略影响 | 抓捕分 | 越狱起始格 |
| --------- | --------- | --------- | ------- | ----------- |
| 1 | 混混、小偷 | 只能在下城区获得超额犯罪 +1 | 抓捕得 1 分 | 格 1 |
| 2 | 抢劫犯、诈骗犯（标准） | 可在核心区获得超额犯罪 +1 | 抓捕得 2 分 | 格 2 |
| 3 | 杀人犯 | 可在上城区获得超额犯罪 +1 | 抓捕得 3 分 | 格 3 |
| 4 | 连环杀手（高级角色） | 全地图超额犯罪 +1 | 抓捕得 4 分 | 格 4 |

#### 罪犯的关键策略选择

1. **快进快出**：低情报积累 → 在下城区犯小案 → 安全但分低
2. **蓄谋大案**：先调查积攒情报 → 选择上城区犯罪 → 高分但暴露大
3. **声东击西**：在 A 区布疑阵 → 在 B 区犯罪 → 增加警长的侦查成本
4. **转攻为守**：当警长逼近时，消耗行动降隐藏值 → 增加警长的抓捕成本

### 4.3 超级英雄核心玩法（方案框架）

> 标准 4 人局不包含超级英雄。以下为 5-7 人局时的设计框架，在阶段③中进一步细化。

#### 角色定位

以暴制暴的义警，不信赖警察，对罪犯和警长都构成威胁。

#### 核心机制方向

```
核心资源：
├─ 情报 Token（通用）
└─ "义警标记"（专属资源，通过特定行动获得）

核心行动：
├─ 侦查犯罪（基础）：调查地点的犯罪痕迹，获得线索
├─ 私刑打击（重大）：选择目标罪犯，消耗义警标记 + 情报 → 
│    直接对该罪犯造成惩罚（减少对方分数/破坏对方资源）
└─ 干预执法（基础/技能）：干扰警长的行动（抢夺证据、破坏布控）

得分途径：
├─ 抢先处置罪犯：在警长之前抓捕罪犯 → 获得对应分数
├─ 战利品收缴：从罪犯处抢夺资源 → 转化为分数
└─ 私刑正义：执行私刑时获得分数
```

#### 与其他阵营的互动

```
对罪犯：我是你的噩梦。你犯罪 → 我直接惩罚你
对警长：你是我的竞争对手。你抓人慢 → 我替你动手
对受害者：互相利用。你提供情报 → 我提供保护
```

### 4.4 受害者核心玩法（方案框架）

> 标准 4 人局不包含受害者。以下为 5-7 人局时的设计框架，在阶段③中进一步细化。

#### 角色定位

利用犯罪环境获利的机会主义者，通过信息差和舆论操控获得分数。

#### 核心机制方向

```
核心资源：
├─ 情报 Token（通用）
└─ "情报密码"（专属资源，标记自己掌握的秘密信息）

核心行动：
├─ 收集情报（基础）：从其他玩家处获得信息（查看对方手牌/证据分布）
├─ 舆论操控（重大）：消耗情报 + 情报密码 → 制造媒体事件 → 获得分数
├─ 信息交易（基础/技能）：将情报密码出售给其他玩家 → 获得情报 Token
└─ 独家报道（重大）：当有玩家被捕/犯罪时 + 消耗情报密码 → 获得高额分数

得分途径：
├─ 媒体影响力：制造舆论事件 → 获得影响力分数
├─ 灰色收入：情报交易 → 积累财富 → 转化为分数
└─ 独家新闻：报道重大事件 → 一次性高额分数
```

#### 与其他阵营的互动

```
对罪犯：表面受害，私下利用。掌握你的犯罪证据 → 关键时刻出售
对警长：表面配合，暗地质疑。提供有限情报 → 牵制警长行动
对超级英雄：信息互换。你给我情报 → 我给你掩护
```

## 5. 虚拟罪犯机制（2-3 人局）

### 5.1 机制概述

当玩家人数少于 4 人时（无受害者/超级英雄），罪犯数量减少导致两个问题：

1. 地点情报值消耗变慢 → 犯罪成本居高不下
2. 证据 Token 产出减少 → 警长无事可做

虚拟罪犯机制通过纯规则模拟额外罪犯的犯罪行为，解决以上问题。

### 5.2 虚拟罪犯规则

#### 2 人局（1 警长 + 1 罪犯）

| 参数 | 值 |
| ------ | ----- |
| 虚拟罪犯数量 | 2 个（模拟另外 2 名罪犯的犯罪行为） |
| 处理方式 | 纯规则模拟，无额外配件 |

**每轮黎明阶段，虚拟罪犯自动执行以下操作：**

```
① 选择一个情报值最高的地点（至少 2 以上）
② 消耗该地点 2 个情报 Token
③ 在该地点放置 1 个"虚拟证据 Token"（灰色/无角色标记）
④ 虚拟证据 Token 的标记：使用普通 Token + 背面朝上即可

虚拟证据 Token 的性质：
├─ 警长可以侦查并收集虚拟证据（消耗情报 = 地点情报值）
├─ 但虚拟证据不能用于抓捕（没有对应的罪犯角色）
├─ 收集虚拟证据的用途：
│  ├─ 弃置：警长可以丢弃虚拟证据（无任何效果）
│  └─ 作为"布控资源"：消耗 2 个虚拟证据 → 可在任意地点免费布控 1 次
└─ 黎明阶段结束时，场上所有虚拟证据 Token 自动消失
```

#### 3 人局（1 警长 + 2 罪犯）

| 参数 | 值 |
| ------ | ----- |
| 虚拟罪犯数量 | 1 个（模拟另外 1 名罪犯的犯罪行为） |
| 处理方式 | 纯规则模拟，无额外配件 |

**每轮黎明阶段，虚拟罪犯自动执行以下操作：**

```
① 选择一个情报值最高的地点（至少 2 以上）
② 消耗该地点 2 个情报 Token
③ 在该地点放置 1 个"虚拟证据 Token"（灰色/无角色标记）
④ 规则同 2 人局
```

### 5.3 虚拟罪犯的节奏预估

```
2 人局：
  虚拟罪犯每轮消耗 2 地点情报 + 放置 1 虚拟证据
  → 12 轮消耗 24 地点情报 + 产生 12 虚拟证据
  → 足够维持警长的行动节奏 ✓

3 人局：
  虚拟罪犯每轮消耗 2 地点情报 + 放置 1 虚拟证据
  → 12 轮消耗 12 地点情报 + 产生 6 虚拟证据
  → 加上 2 个真实罪犯的犯罪 → 警长依然有事可做 ✓
```

### 5.4 虚拟罪犯机制验证

| 验证项目 | 预期结果 |
| --------- | --------- |
| 2 人局警长不会无事可做 | ✅ 虚拟证据 + 真实证据足够支撑侦查/抓捕循环 |
| 2 人局罪犯不会太轻松 | ✅ 虚拟罪犯消耗情报 + 降低部分地点的情报值 → 真实罪犯犯罪成本自然降低，但警长也有更多事做 |
| 3 人局体验接近 4 人局 | ✅ 仅比标准局少 1 个罪犯的发散度 → 差距可接受 |
| 无需额外配件 | ✅ 纯规则实现，仅需额外几颗普通 Token |
| 规则复杂度增加 | ⚠️ 较低。仅在黎明阶段增加 2-3 行规则，不影响核心体验 |

## 6. 核心循环检查清单

### ✅ 6.1 循环是否完整

| 检查项 | 结果 | 说明 |

| 检查项 | 结果 | 说明 |
| -------- | ------ | ------ |
| "3-2-1" 是否通过 | ✅ | 3 核心行动 / 2 选择层级 / 1 核心张力 |
| 每个阶段是否无歧义 | ✅ | 傍晚→夜晚（含 5 个子阶段）→黎明 |
| 先手优势是否处理 | ✅ | 警长先手优势有限，无需额外补偿 |

| 检查项 | 结果 | 说明 |
| -------- | ------ | ------ |
| 胜利条件是否清晰 | ✅ | 先到 15 分 / 12 轮结束比高低 |
| 得分途径是否对齐阵营特色 | ✅ | 警长靠抓捕，罪犯靠犯罪 |
| 胜利条件是否驱动互动 | ✅ | 所有得分途径都直接或间接涉及其他玩家 |

### ⚠️ 6.4 复杂度检查（针对 H6：证据+隐藏值+犯罪等级+看守所 四子系统叠加）

| 子系统 | 核心作用 | 复杂度评级 | 是否必要 |

**复杂度综合评估**：

- 每个子系统只解决一个核心问题
