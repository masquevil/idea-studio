## 1. 一句话 Hook

**玩家扮演**城市中的不同角色（警长/罪犯/超级英雄/受害者），**通过在城市版图上争夺情报资源、执行阵营专属行动**，**率先获得 15 分达成胜利**，核心张力在于「罪犯藏匿与犯罪 vs 警长侦查与抓捕」的猫鼠博弈。

> 检验：30 秒内能否产生期待？—— "你是警长追捕罪犯，或者你是罪犯在警长眼皮底下犯罪跑分，双方在城市版图上争夺情报资源，互相干扰对手的得分节奏。"

## 2. 锁定参数

### 玩家人数与阵营配置

| 人数 | 警长 | 罪犯 | 超级英雄 | 受害者 | 说明 |
| :-: | :-: | :-: | :-: | :-: | - |
| 2 | 1 | 1 | 0 | 0 | 引入虚拟罪犯机制 |
| 3 | 1 | 2 | 0 | 0 | 引入虚拟罪犯机制 |
| **4** | **1** | **3** | **0** | **0** | **标准配置（设计基准）** |
| 5 | 1 | 3 | 0-1 | 0-1 | 超级英雄和受害者二选一 |
| 6 | 1 | 3-4 | 0-1 | 0-1 | 4人局基础上新增"罪犯/超级英雄/受害者"三选二 |
| 7 | 1 | 4 | 1 | 1 | 全阵营满配 |

### 其他参数

| 参数 | 值 | 说明 |
| ------ | ----- | ------ |
| 单局时长 | 30-120 分钟 | 取决于人数，4人局约 45-60 分钟 |
| 复杂度层级 | 轻中策 | 规则易懂但有策略深度，适合家庭/聚会到核心玩家的过渡 |
| 核心机制类型 | ① **非对称能力**（各阵营不同行动池）<br>② **区域控制/区控**（地点牌上的情报争夺）<br>③ **卡牌驱动**（策略牌提供战术变化） | 三个机制互相嵌套，构成核心体验 |
| 游戏类型定位 | 非对称 · 卡牌驱动 · 跑分制 | 各自为战，非对称能力通过得分途径差异化体现 |

## 3. 设计继承说明

### ✅ 直接保留

| v4 想法 | 保留理由 |
| --------- | --------- |
| 四大阵营（警长/罪犯/超级英雄/受害者） | 非对称的核心，创造丰富的互动关系 |
| 地点牌版图（上城/核心/下城） | 构建空间策略的物理基础 |
| 情报 Token 作为通用资源 | 全阵营通用的核心资源，驱动所有行动 |
| 证据 Token + 隐藏值系统 | 警长-罪犯博弈的核心机制 |
| 策略牌三类型（普通/快速/延迟） | 成熟的卡牌系统，提供战术深度 |
| 傍晚→夜晚→黎明三轮结构 | 清晰的回合节奏 |
| 跑分制（先到15分/12回合上限） | 简单明确的胜利条件 |
| 虚拟罪犯机制（2-3人局） | 解决低人数平衡问题的关键设计 |
| 看守所区域 | 罪犯被逮捕后的惩罚机制，增加博弈深度 |
| 犯罪等级 | 区分罪犯角色差异的核心参数 |

### 🔧 需要修改/细化

| v4 想法 | 修改方向 |
| --------- | --------- |
| 行动次数（2基础/1重大） | 需细化"基础行动"和"重大行动"的具体清单，明确哪些角色可以突破限制 |
| 警长可执行更多行动（待定） | 需在核心循环中明确警长的行动优势及其代价/限制 |
| 隐蔽值机制的具体实现 | v4 想法较模糊，需设计明确的数值和互动规则 |
| 布控（警员 Token） | 需简化，避免增加过多管理负担 |
| 超级英雄和受害者的核心玩法 | v4 中基本未设计，需从零构建 |
| 地点牌的特殊效果 | v4 中仅提及"不确定"，需设计具体效果列表 |
| 5-7 人局的具体角色配置 | v4 表格中部分为范围值（如 3-4），需锁定 |
| 越狱动作的触发条件 | v4 中仅提及"符合某些特殊条件"，需具体化 |
