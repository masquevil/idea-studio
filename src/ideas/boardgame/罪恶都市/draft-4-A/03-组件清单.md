## 2. Token 清单

### 2.1 情报 Token

| 属性 | 值 |
| ------ | ----- |
| 形态 | 小方块（建议 6mm 立方体） |
| 颜色 | 蓝色（透明/不透明均可） |
| 数量 | **60 个** |
| 用途 | 全阵营通用基础资源 |

### 2.2 证据 Token

| 属性 | 值 |
| ------ | ----- |
| 形态 | 圆形筹码（直径 16mm 圆片） |
| 颜色 | 正面印有对应罪犯角色头像（彩色），背面为统一黑白面 |
| 数量 | 每个罪犯角色 **5 个** |
| 总数量 | 8 个罪犯角色 × 5 = **40 个** |
| 用途 | 标记犯罪位置、抓捕门票 |

### 2.3 迷雾 Token

| 属性 | 值 |
| ------ | ----- |
| 形态 | 圆形筹码（直径 16mm 圆片，与证据 Token 同规格但不同色） |
| 颜色 | 双面：灰色面 / 红色面 |
| 数量 | **12 个** |
| 用途 | 仅用于 2-3 人局的迷雾阶段 |

### 2.4 警员 Token

| 属性 | 值 |
| ------ | ----- |
| 形态 | 圆形筹码（直径 16mm 圆片） |
| 颜色 | 蓝色（印有警徽图标） |
| 数量 | **5 个** |
| 用途 | 警长布控专用 |

### 2.5 隐藏值指示物

| 属性 | 值 |
| ------ | ----- |
| 形态 | 小方块（建议 6mm 立方体，使用情报 Token 中的异色方块） |
| 颜色 | 每罪犯一色（从 60 个情报 Token 中取用异色方块，如红色、绿色等） |
| 数量 | **8 个**（每个罪犯角色 1 个） |
| 用途 | 放在角色卡的隐藏值轨道上，标记当前隐藏值 |
| 说明 | 不使用独立骰子，直接利用情报 Token 中的异色方块。角色卡底部印有 0～X 的隐藏值轨道（X=上限+2），方块放在对应数字上 |

### 2.6 分数/回合共用面板

| 属性 | 值 |
| ------ | ----- |
| 形态 | 一张 A5 尺寸面板，印有两条并列的 0-15 数字轨道 |
| 数量 | **1 张**（共用面板）+ **7 个角色专属标记**（小型方块或圆片，每个角色 1 个，可用玩家角色卡颜色区分） |
| 用途 | 一条轨道标记各角色分数（0-15），另一条标记当前回合（1-12） |
| 说明 | 分数用共用面板代替每人独立的分数标记，减少 Token 种类。回合标记共用面板上的另一条轨道。看守所面板与分数面板分开（看守所面板每次抓捕都需要用，可与分数面板并列摆放） |

### 2.7 Token 用量汇总

| Token 类型 | 单局最大用量（4 人局） | 说明 |
| ------------ | --------------------- | ------ |
| 情报 Token | 约 30-40 个 | 初始放置 + 玩家持有，60 个足够 |
| 证据 Token | 15 个 | 3 个罪犯 × 5 个/人 |
| 迷雾 Token | 0 个（仅 2-3 人局使用） | 4 人局不需要 |
| 警员 Token | 5 个 | 全部供警长使用 |
| 隐藏值指示物（小方块） | 3 个 | 3 个罪犯各 1 个，使用异色方块 |
| 分数标记 | 4 人份 | 各玩家自管 |

### 3.1 看守所面板布局

```
┌────────────────────────────────────────────┐
│                看 守 所                      │
│                                            │
│  ┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐      │
│  │  3  │  │  2  │  │  1  │  │  0  │      │
│  │     │  │     │  │     │  │ ⭐  │      │
│  └─────┘  └─────┘  └─────┘  └─────┘      │
│                                            │
│  数字代表距离越狱的轮次数                    │
│  → 每次黎明阶段向右移动一格                  │
│  → 到达 ⭐（格 0）= 越狱成功                │
│  → 新被捕罪犯按犯罪等级放入对应格            │
└────────────────────────────────────────────┘
```
