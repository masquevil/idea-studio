# 方案 A · 原始点子

> 纯原创设计，基于用户基本想法自由发挥

---

## 一句话概念

> **「暗牌警匪」**—— 在一座罪恶都市中，警长布防城市，罪犯暗中作案，英雄与民众各自为战，一场关于情报与博弈的非对称对决。

## 核心卖点

- **地点驱动**：所有行动围绕城市地点展开，而非直接针对玩家
- **情报不对称**：罪犯秘密行动，警长通过线索推理，信息差是核心博弈
- **轻策快节奏**：30-60 分钟一局，规则简单但策略深度足够
- **角色鲜明**：每个阵营玩法完全不同，重开性高

## 目标体验

玩家玩完后的感受：

- 警长玩家体验到"城市守护者"的运筹帷幄感——猜罪犯会去哪、如何布防
- 罪犯玩家体验到"暗处猎手"的紧张刺激——选对地点、避开警察、完成目标
- 旁观者（或可选角色玩家）也能感受到城市逐渐失控的戏剧性

## 与基本想法的关联

| 基本想法要素 | 方案 A 的体现 |
|-------------|--------------|
| 警匪非对称 | 警长 1 人 vs 罪犯 N 人，玩法完全不同 |
| 轻策桌游 | 规则简洁，每回合行动选项有限 |
| 卡牌为主 | 罪犯通过手牌选择作案地点和行动 |
| 围绕地点展开 | 城市地图是核心，所有行动绑定地点 |
| 警长巡逻/任命/派驻 | 警长通过派驻警官到地点来布防 |
| 罪犯抽 2 选 1 | 保留此机制，增加策略性 |
| 超级英雄（0-1人） | 第三方干扰者，可平衡局势 |
| 受害者联盟（0-1人） | 第四方，代表民众力量 |

## 设计方向关键词

`非对称` `地点驱动` `情报博弈` `卡牌` `轻策` `30-60min` `2-6人`
