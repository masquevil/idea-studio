## 一、7 维度评价

### 1. 概念与定位符合度 — ⭐⭐⭐⭐⭐

方案 A 清晰锚定"警匪非对称轻中策卡牌游戏"的定位，核心概念结构完整：

| 要素 | 评价 |
|------|------|
| 一句话概念（30字内） | ✅ "纯卡牌驱动·通用牌库+角色能力差异化·资源管理替代概率·警匪非对称跑分"——精炼准确 |
| 非对称对抗 | ✅ 警长 1 人 vs 罪犯 1-4 人，资源体系和玩法截然不同 |
| 跑分制 | ✅ 统一 15 分目标，取消了以往方案中的"专属胜利"矛盾 |
| 轻中策门槛 | ✅ 通用牌库（84% 基础牌）+ 标准回合制，学习成本可控 |

**亮点**：定位清晰，与方案方向说明的关联表非常全面，每个机制选择都有明确的"为什么"。

**问题**：无。

---

### 2. 核心机制自洽性 — ⭐⭐⭐⭐

核心机制的三大支柱（通用牌库、标准回合制、跑分制）内部自洽，无逻辑矛盾：

| 机制 | 评价 |
|------|------|
| 通用牌库（95 张，84% 基础牌） | ✅ 结构合理，踩点/调查/转移/潜伏四种基础牌覆盖了所有基本操作 |
| 犯罪/布控由角色技能实现 | ✅ 解决了"阵营专属牌摸到无用"的问题，牌效固定+技能修改的设计干净 |
| 标准回合制（警长先→顺时针） | ✅ 信息透明、主题契合、学习成本低 |
| 治安/恐慌双轴 | ✅ 治安值自然恢复机制避免了恶性循环 |
| 资源体系（7 种） | ⚠️ 对轻策而言偏多。新手需同时管理：分数、情报、暴露度、线索、行动力、赃物/声望/影响力 |

**亮点**：嫌疑链系统（3 线索 = 1 级、4 级满可逮捕）提供了清晰的警长成长路径，且与暴露度系统形成双通道逮捕条件。

**问题**：

- **资源种类偏多**：7 种核心资源（分/情报/暴露度/线索/行动力/赃物/声望+影响力）对于定位为"轻中策"的游戏来说偏高，可能导致教学成本增加。建议后续阶段评估是否有资源可合并或隐藏（如赃物可合并到分数计算中，不对玩家单独追踪）。
- **事件牌数量矛盾**：表格列出 13 张（E-01~E-03 ×2 = 6 + E-04~E-10 ×1 = 7），但注脚写"共 12 张"，需统一。

### 3. 主题契合度 — ⭐⭐⭐⭐

| 主题元素 | 机制体现 | 评分 |
|---------|---------|------|
| 城市的夜晚 | 每回合 = 1 个夜晚，事件牌改变氛围 | ⭐⭐⭐⭐⭐ |
| 罪犯踩点→犯罪 | 踩点牌获取情报→消耗情报执行犯罪 | ⭐⭐⭐⭐⭐ |
| 警长巡逻布控 | 调查牌→布控增加警戒值 | ⭐⭐⭐⭐ |
| 侦探推理 | 嫌疑链系统：收集线索→推进等级→逮捕 | ⭐⭐⭐⭐⭐ |
| 越狱逃脱 | 关押 2 回合后可用金蝉脱壳越狱 | ⭐⭐⭐⭐ |
| 超级英雄介入 | 声望累积→出击阻止犯罪 | ⭐⭐⭐⭐ |
| 市民舆论影响 | 受害者联盟用影响力发动游行 | ⭐⭐⭐⭐ |
| 城市崩溃 | 恐慌值 ≥10 时城市崩溃 | ⭐⭐⭐⭐⭐ |

**亮点**：主题与机制的映射关系表非常清晰，每个主题元素都有明确对应的机制实现。警长先手的主题逻辑"先巡逻布控→罪犯后选择作案"叙事通顺。

**问题**：

- 受害者阵营技能叫"**调查**"，但通用牌库中已有同名的"**调查**"牌（获得 1 线索）。新玩家看到"调查"会自然联想到通用的调查牌效果，但受害者的"调查"技能效果完全不同（每回合获得 1 影响力）。建议改名，例如"**走访**"或"**采访**"。
- "警察局"地点（警戒值 3，犯罪成本 +3）的主题逻辑：警长在自己大本营的布控机制未说明，作为地点牌存在感不足。

### 4. 非对称平衡性 — ⭐⭐⭐⭐

各阵营的理论得分速率在合理范围内，但缺乏实战验证：

| 阵营 | 理论得分速率 | 达到 15 分所需回合 |
|------|-------------|------------------|
| 警长（方振华） | 1.5-2.5 分 | 7-10 回合 |
| 警长（李敏） | 1-2 分 | 8-12 回合 |
| 罪犯（公牛/幽灵） | 2-3 分 | 6-8 回合（爆发型） |
| 罪犯（老鼠/蛇） | 1.5-2 分 | 8-10 回合（稳定型） |
| 罪犯（狐狸） | 1-1.5 分 | 10+ 回合（干扰型） |
| 超级英雄 | 1.5-2.5 分 | 7-10 回合 |
| 受害者联盟 | 1.5-3 分 | 6-10 回合 |

**亮点**：文档主动列出了潜在不平衡风险并有缓解措施，体现了设计者的预判意识。

**问题**：

- **罪犯间零互动**：4 人局（1 警长 + 3 罪犯）中，3 个罪犯各自为战，互相之间不能帮助也不能损害。实际上是"1 场警长 vs 每个罪犯的零和游戏"的并行，而不是"4 人共同游戏"。这可能导致社交互动感不足。
- **2-3 人局体验差距大**：虚拟罪犯仅做线索来源，缺乏对真实罪犯的竞争压力模拟。2 人局中只有 1 个罪犯，警长可以集中所有资源追捕单一目标。
- **警长行动力消耗不完整**：布控/部署警官分别消耗多少行动力未写明，无法评估警长每回合能执行多少操作。

### 5. 轻策匹配度 — ⭐⭐⭐⭐

| 维度 | 评价 |
|------|------|
| 规则复杂度 | 基础规则清晰——3 阶段回合、出 1 张牌、摸 1 张牌、警长先手。新手容易上手 |
| 通用牌库设计 | 84% 基础牌 + 每张牌只有 1 行效果文字，学习成本极低 |
| 角色差异化 | 两层技能结构（阵营技能 1-2 + 专属技能 1-2），同一身份下技能可复用理解 |
| 资源数量 | 7 种资源对"轻中策"来说偏多，接近中策的量级 |
| 事件牌 | 12-13 张事件牌提供了每局变化但不过载 |
| 标准回合制 | 无"同时暗出"等复杂机制，信息透明 |

**整体评估**：**轻策偏上，接近中策下限**。核心操作规则简单（出牌→执行→摸牌），但资源管理维度和阵营差异化使策略深度超过了典型轻策。如果目标定位是"轻中策"，当前设计处于合理区间。

**问题**：7 种资源（分、情报、暴露度、线索、行动力、赃物、声望/影响力）中，赃物作为额外得分资源（3:1 换分）可能是最可削减的一环——它增加了追踪负担但策略价值有限。

---

### 6. 创新性亮点 — ⭐⭐⭐

| 亮点 | 评价 |
|------|------|
| 通用牌库 + 角色技能差异 | 核心创新点。"牌效固定、技能修改"的设计在已知桌游中较为少见，且解决了摸到无用牌的问题 |
| 治安/恐慌双轴 | 虽然不是全新设计，但治安值自然恢复机制（每次犯罪 -1 + 回合结束 +1）是好的思路 |
| 嫌疑链系统 | 警长的"收集线索→推进链条→逮捕"提供了清晰的成长弧线 |
| 统一跑分制 | 消除了多阵营专属胜利条件的逻辑矛盾 |
| 关押不淘汰 | 被捕 2 回合后可越狱，全员全程参与 |

**整体评估**：方案 A 的核心创新在于"**牌效固定、技能修改**"的设计范式，以及围绕这一范式构建的通用牌库 + 角色差异化体系。整体创新度属于"在成熟框架上的有意义的改良"层级，不属于"颠覆性创新"，但与定位一致。

---

### 7. 潜在风险预判 — ⭐⭐⭐⭐

| 风险 | 严重度 | 说明 |
|------|--------|------|
| 罪犯爆发过快（公牛/幽灵） | 🟡 | 理论 6-8 回合到 15 分，可能领先其他玩家 3-4 分 |
| 恐慌值失控（幽灵行凶） | 🟡 | 每次行凶恐慌值 +3，4 次行凶即城市崩溃 |
| 警长前期得分慢 | 🟡 | 前 5 回合需积累线索才能逮捕，期间主要靠治安值得分 |
| 低人数局体验 | 🟡 | 2-3 人局虚拟罪犯机制深度不足，体验与 4 人局差距大 |
| 资源种类偏多 | 🟢 | 7 种资源对新手教学有压力 |
| 罪犯间无互动 | 🟢 | 社交互动感不足，但不构成硬伤 |

## 二、按优先级建议汇总

### 🔴 高优先级（必须修改才能进入下一阶段）

无。当前方案 A 的概念设计在 🔴 层面没有必须修改的问题。

### 🟡 中优先级（建议修改，但可延至阶段 2d）

| 编号 | 问题 | 建议 |
|------|------|------|
| 🟡-1 | 受害者技能"调查"与通用牌"调查"同名 | 改名"**走访**"或"采访"：每回合获得 1 影响力 |
| 🟡-2 | 事件牌数量矛盾（13 张 vs "12 张"） | 统一为 12 张（例如移除 E-10 神秘访客） |
| 🟡-3 | 警长行动力消耗未完整定义 | 阶段 2d 中列出完整消耗表（布控/部署/逮捕/调查各消耗多少） |
| 🟡-4 | 蛇的技能"内应"时机歧义 | "出牌阶段开始时，可查看警长当前手牌"（警长先行动→蛇后行动，此时警长已出 1 牌但有剩余手牌） |
| 🟡-5 | 2-3 人局虚拟罪犯深度不足 | 阶段 2d 中探索：虚拟罪犯每回合自动"犯罪"（影响治安值和线索分布），模拟真实罪犯对全局的影响 |
| 🟡-6 | 罪犯间零互动 | 阶段 2d 中考虑：同地点犯罪的暴露度互相 +1（竞争效应） |

### 🟢 低优先级（可延至阶段 2d）

| 编号 | 问题 | 建议 |
|------|------|------|
| 🟢-1 | 赃物资源的必要性 | 阶段 2d 中评估：赃物是否可直接合并到分数计算中 |
| 🟢-2 | "警察局"地点主题说明 | 地点牌效果表中补充警长在警察局的布控机制 |
| 🟢-3 | 事件牌"节日庆典"效果验证 | "治安值不会被降低"在机制上是否意味着所有犯罪不减少治安值？语义需澄清 |
