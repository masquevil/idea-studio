## 核心游戏循环

### 回合框架：个人完整回合制

游戏整体流程：**警长回合 → 顺时针下一位玩家回合 → ... → 所有玩家执行完个人回合 → 黎明结算（全局更新）**

每个玩家的个人回合分为 **6 个阶段**，参考三国杀等经典桌游的回合结构：

```
轮到玩家 X 的个人回合：
  ↓
① 回合开始阶段
  ├─ 翻开 1 张事件牌（仅在本回合第一个行动的玩家回合执行）
  └─ 触发"每回合开始时"效果
  ↓
② 补充 Token 阶段
  └─ 补充行动 token 至上限（各阵营上限不同，见下表）
  ↓
③ 摸牌阶段
  └─ 从通用牌库摸 2 张手牌
  ↓
④ 出牌阶段
  ├─ 可出任意张手牌，每张牌需消耗对应数量的行动 token
  ├─ 核心行动每回合限 1 次（消耗 token 更多）
  └─ 出牌不补牌！可主动结束出牌阶段
  ↓
⑤ 弃牌阶段
  └─ 弃牌至手牌上限（5 张）
  ↓
⑥ 回合结束阶段
  ├─ 触发"每回合结束时"效果
  ├─ 本回合消耗的 token 留在目标地点（警长/罪犯专用交互）
  └─ 轮到顺时针下一位玩家执行个人回合
```

> **关于事件牌**：事件牌在本回合第一位玩家（通常是警长）的回合开始阶段翻开，持续生效至本轮黎明结算。所有玩家的个人回合共用同一张事件牌效果。

**警长先手的主题逻辑**：警长先行动 → 部署布控 → 罪犯看到警长动向后再选择作案地点。后手罪犯获得信息优势，同时符合"警察巡逻在先"的叙事。

## Token 行动力系统

### 核心设计思路

每个阵营有自己的行动 token，每回合补充至上限。**出牌需要消耗 token**——每张手牌有一个"token 成本"，打出时需消耗对应数量。消耗的 token 放置到目标地点上，**留在地点上的 token 可供其他角色交互使用**。

这替代了旧方案中"出牌限制靠手牌上限硬卡"的思路——Token 才是真正的行动力指示器，手牌只决定"你能用什么"，token 决定"你能做几次"。

### 各阵营 Token 配置

| 阵营 | Token 名 | 上限 | 每回合补充至 | 消耗去向 |
|------|---------|------|------------|---------|
| **罪犯** | **线索** | 3 | 补至 3 | 出牌消耗 → 放到目标地点 → 警长收集 |
| **警长** | **行动力** | 4 | 补至 4（恐慌≥5时-1，≥8时-2） | 执行警长行动消耗 → 部分可留在地点（布控标记） |
| **超英** | **精力** | 3 | 补至 3 | 使用超英技能消耗 |
| **受害者** | **舆论** | 3 | 补至 3（恐慌共鸣额外补充） | 使用受害者技能消耗 |

> 所有阵营的上限可在游戏中通过角色技能、事件牌等因素临时调整。

### Token 消耗规则

每张手牌打出时需消耗 **1 个对应阵营的行动 token**：

| 出牌名称 | 牌面效果 | 消耗 token | 特殊说明 |
|---------|---------|-----------|---------|
| **踩点** | 获得 1 情报 | 1 线索/行动力/精力/舆论 | 各阵营通用 |
| **调查** | 获得 1 线索标记 | 1 线索/行动力/精力/舆论 | 各阵营通用 |
| **转移** | 移动至目标地点 | 1 线索/行动力/精力/舆论 | 各阵营通用 |
| **潜伏** | 暴露度-1，免疫逮捕 | 1 线索/行动力/精力/舆论 | 各阵营通用 |
| **密谋** | 获得 2 情报并摸 1 张 | 2 线索/行动力/精力/舆论 | 消耗更高 |
| **追查** | 获得 2 线索并查看手牌 | 2 线索/行动力/精力/舆论 | 消耗更高 |
| **金蝉脱壳** | 逃脱关押 | 1 线索/行动力/精力/舆论 | - |
| **孤注一掷** | 弃所有手牌=得分 | 0（不消耗） | 不需要 token |

> 每种牌的成本对所有阵营都是 **1 个 token**（特殊牌如密谋/追查为 2 个）。这意味着罪犯最多每回合出 3 张牌（token 上限 3），警长最多 4 张。

### 双面 Token 设计

所有阵营的行动 Token 采用**双面设计**——A面为资源态（手中时），B面为消耗态（使用后）。

| Token | 阵营 | 数量 | A面（资源态） | B面（消耗态） | 消耗后去向 |
|-------|------|------|-------------|-------------|-----------|
| 🔍 **线索** | 罪犯 | 3 | 🟡 线索（黄色） | 🔴 **物证**（红色） | 放到目标地点→警长收集翻回A面 |
| 👮 **行动力** | 警长 | 4 | 🔵 行动力（蓝色） | ⚪ **布控**（白色/灰色） | 放到目标地点→该地警戒值+1 |
| ⚡ **精力** | 超英 | 3 | 🟢 精力（绿色） | 🟢 [消耗]（绿色灰字） | 留在面板自产自销 |
| 📢 **舆论** | 受害者 | 3 | 🟠 舆论（橙色） | 🟠 [消耗]（橙色灰字） | 留在面板自产自销 |

**双面流转流程**：

```
回合开始补充Token至上限 → 全部为A面（资源态）
  ↓
出牌消耗 1 个 Token → 将该 Token 翻到 B面（消耗态）
  ↓
罪犯/警长 → B面放到目标地点上      超英/受害者 → B面留在面板（自产自销）
  ↓                    ↓
警长在黎明结算收集    ⚪布控标记
🔴物证 翻回🟡线索   使该地点警戒值+1
→ 转为警长线索池     持续N回合后移除
```

### Token 互动的叙事逻辑

| 交互 | 叙事 |
|------|------|
| 罪犯出牌消耗🟡线索 Token → 翻到🔴物证 → 放到地点 | 罪犯在案发现场留下作案痕迹（指纹、监控等） |
| 警长黎明结算时收集🔴物证 → 翻回🟡线索 | 警长在现场勘察，收集到有效物证 |
| 警长消耗🔵行动力 → 翻到⚪布控 → 放到地点 | 警长在该地点派驻警力，警戒度上升 |
| ⚪布控标记在地点上 → 影响犯罪成本 | 警力巡逻使该地点犯罪难度增加 |
| 🟢精力 Token 翻面留在超英面板 | 超英自产自销，无人收集 |
| 🟠舆论 Token 翻面留在受害者面板 | 受害者自产自销，无人收集 |

> **重要区分**：警长的⚪布控标记增加的是**该特定地点的局部警戒值**，而全局治安值（城市状态轨道）是完全独立的系统——治安值由犯罪次数和自动恢复决定，不受布控标记直接影响。

## 通用牌库

### 核心原则

> **所有牌的效果对所有玩家完全一致。牌面上印的效果就是这张牌的效果，不会因为不同玩家而改变。角色技能可以修改某张/某类牌的效果，但这种修改是例外而非规则。**

### 禁止阵营专属牌

**牌库中没有任何一张牌是"只有某个阵营才能用"的。** 所有玩家摸到的每一张牌都有基本用途。策略性差异化全部由角色技能实现，而非通过阵营专属牌。

### 牌库结构（约 95 张）

| 类型 | 牌名 | 数量 | 牌面效果（一行字） | Token消耗 | 功能定位 |
|------|------|------|-------------------|----------|---------|
| 🟦 **基础牌** | **踩点** | ×30 | 获得 1 情报 | 1 | 最基本的经济牌，量最大 |
| | **调查** | ×25 | 获得 1 线索标记 | 1 | 信息牌，量第二 |
| | **转移** | ×15 | 移动目标地点 | 1 | 机动牌 |
| | **潜伏** | ×10 | 本回合暴露度-1，免疫 1 次逮捕尝试 | 1 | 防御牌 |
| 🟪 **特殊牌** | **密谋** | ×5 | 获得 2 情报并摸 1 张牌 | 2 | 高价值经济 |
| | **追查** | ×5 | 获得 2 线索并查看 1 名玩家的手牌 | 2 | 高价值信息 |
| | **金蝉脱壳** | ×3 | 逃脱一次关押或针对效果 | 1 | 保命牌 |
| | **孤注一掷** | ×2 | 弃所有手牌，每弃 1 张获得 1 分 | 0 | 逆转牌 |

### 基础牌占 84% 的设计意图

参考三国杀的牌库结构（杀/闪/桃等基础牌占 49%），本方案将基础牌占比提升至 **84%**，理由如下：

1. **降低学习成本**：玩家只需记住 4 种基础牌的效果，就能玩
2. **策略深度在技能上**：每张基础牌的使用方式由角色技能决定，同样的牌在不同角色手中产生不同结果
3. **减少"废牌"概率**：基础牌量大→抽牌容错率高→玩家不会摸到完全无用的牌

### 同地点竞争规则

如果本回合多名罪犯在同一地点执行犯罪行动，各自暴露度额外 +1（竞争效应带来的混乱和注意）。此规则增加了罪犯之间的策略互动——选择"安全且独享"的地点还是"高收益但共享"的地点，需要权衡。

---

### "犯罪"和"布控"的实现方式

这些功能不再需要专门的犯罪牌或布控牌，而是通过 **"基础牌 + 角色技能"** 实现：

| 场景 | 玩家出牌 | 消耗token | 牌面效果 | 角色技能覆盖后 |
|------|---------|----------|---------|-------------|
| 罪犯想犯罪 | 出**踩点牌** | 1（基础消耗）+ 情报（额外） | "获得 1 情报" | 阵营技能"犯罪"：改为执行一次犯罪行动，消耗 X 情报获得分数 |
| 警长想布控 | 出**调查牌** | 1 行动力 | "获得 1 线索" | 阵营技能"部署权"：改为布控行动，在目标地点放置布控标记 |
| 超英想出击 | 出**潜伏牌** | 2 精力 | "本回合暴露度-1" | 阵营技能"出击"：改为阻止目标地点的犯罪行动 |
| 受害者想爆料 | 出**密谋牌** | 1 舆论 | "获得 2 情报并摸 1 张" | 阵营技能"爆料"：改为使目标暴露度+1，自己+1分 |

### 牌库规模总结

| 类别 | 数量 | 占比 |
|------|------|------|
| 🟦 基础牌（踩点/调查/转移/潜伏） | 80 张 | 84% |
| 🟪 特殊牌（密谋/追查/金蝉脱壳/孤注一掷） | 15 张 | 16% |
| **总计** | **约 95 张** | **100%** |

## 胜利条件：跑分制

### 核心规则

- 游戏以 **目标分数到达即结束** 为统一规则
- **目标分数 = 15 分**（基准配置，可随人数调整）
- 一旦有人到达目标分数，**立即进行终局结算**（无人再行动）
- **不再有"专属胜利直接结束"** 的独立条件，避免逻辑矛盾

### 各阵营得分方式

| 阵营 | 得分方式 | 单次得分 | 说明 |
|------|---------|---------|------|
| **警长** | 逮捕关押罪犯 → 每回合 +1 分 | 持续 | 关押期间每回合结算 |
| | 逮捕时一次性得分 | +2 分 | 逮捕成功时 |
| | 维护城市秩序（治安值高 → 每回合得分） | +1 分/回合 | 治安值 ≥8 时 |
| | 终局治安值 ≥8 奖励 | +3 分 | 仅终局结算 |
| **罪犯** | 成功犯罪 | 1-3 分 | 取决于犯罪类型和投入资源 |
| | 越狱成功 | +1 分 | 从关押中逃脱 |
| **超级英雄** | 阻止犯罪 | +1 分 | 成功阻止一次犯罪行动 |
| | 协助逮捕 | +1 分 | 在同一地点与警长同时行动时 |
| | 声望累积 | +1 分/每 2 声望 | 声望是一种次级资源 |
| **受害者联盟** | 游行成功 | +2 分 | 需消耗影响力 |
| | 爆料揭露 | +1 分/次 | 需消耗影响力 |
| | 媒体风暴 | +2 分 | 终极技能，一次游戏限 1 次 |
| | 终局治安值 ≤3 奖励 | +5 分 | 仅终局结算 |

### 终局规则

1. 有人到达 **15 分** → 立即结束，**该玩家胜出**
2. 第 **10 回合** 结束时无人到达 15 分 → 分数最高者胜出
3. 平局时：贡献最多者胜（警长看逮捕人数，罪犯看犯罪次数，超英看阻止次数，受害者看游行次数）

## 基本规则框架

### 游戏准备

1. **地点牌池**：从 20+ 张地点牌中随机抽取 **10 张**，面朝上摆放在桌面中央（2×5 排列构成"城市版图"）
2. **牌库**：通用牌库约 95 张（踩点×30 + 调查×25 + 转移×15 + 潜伏×10 + 密谋×5 + 追查×5 + 金蝉脱壳×3 + 孤注一掷×2），洗混后放置一旁
3. **角色选择**：
   - 警长 1 名（从方振华/李敏中选择）
   - 罪犯 1-4 名（从幽灵/狐狸/老鼠/公牛/蛇中选择）
   - 超英/受害者联盟：在 4 人基准中即可选择加入（替换 1 名罪犯或作为第 5 人）
4. **初始手牌**：所有玩家摸 **3 张**
5. **初始 Token**：各玩家领取对应 Token 池并补充至上限
6. **资源标记**：各玩家领取情报标记、暴露度、分数标记等

### 回合执行顺序

1. **先手确定**：警长作为本回合第一位玩家，执行个人完整回合
2. **顺时针轮流**：警长右手边玩家为第二位，依次类推
3. **所有玩家执行完个人回合后** → 进入**黎明结算阶段**（全局更新）
4. 黎明结算完毕后 → 进入下一回合（第 N+1 夜），重新由警长开始

### Token 与手牌的协同

| 维度 | 手牌 | Token |
|------|------|-------|
| 决定 | 你"能做什么"（选项池） | 你"能做几次"（行动力） |
| 上限 | 弃牌阶段强制 5 张 | 各阵营不同（罪犯3/警长4/超英3/受害者3） |
| 补充 | 摸牌阶段摸 2 张 | 回合开始阶段补至上限 |
| 消耗 | 出牌后弃掉 | 出牌时消耗，部分留在地点交互 |

> 简单记忆：**Token = 行动的次数，手牌 = 行动的选项**。两者缺一不可——你有 5 张牌但 token 只有 2 个，也只能出 2 张；你有 3 个 token 但手牌只有 1 张，也只能出 1 张。

### 出牌规则

- 采用**标准回合制**：警长先执行个人完整回合 → 顺时针轮流
- 每位玩家在自己的出牌阶段，**可出任意张手牌**（不超过 token 数量和手牌数量）
- 每打出一张手牌，需消耗对应数量的行动 token（基础牌 1 token，特殊牌 2 token）
- **出牌不补牌**（已废除旧版"出牌后摸1张"规则）
- 出牌必须指定目标地点（若行动需指定地点）
- 玩家可随时**主动结束出牌阶段**

**标准回合制的核心优势**：

| 维度 | 说明 |
|------|------|
| **信息透明** | 后手玩家能看到先手玩家的行动，决策有信息支撑 |
| **主题契合** | 警长先巡逻布控 → 罪犯后选择作案，叙事逻辑一致 |
| **消除运气** | 不再有"猜拳"感，所有决定基于可见信息 |
| **学习成本低** | 标准回合制是桌游通用规则，新手无需额外学习 |

### 资源体系

| 资源 | 归属 | 用途 | 上限 |
|------|------|------|------|
| **分数（胜利点）** | 所有玩家 | 在计分轨道上记录 | 无上限 |
| **情报标记** | 所有玩家通用 | 执行犯罪行动的成本资源 | 5 |
| **行动 token（罪犯·线索）** | 罪犯 | 出牌消耗，消耗后放到地点→被警长收集 | 3 |
| **行动 token（警长·行动力）** | 警长 | 执行警察行动的消耗 | 4（受恐慌影响） |
| **行动 token（超英·精力）** | 超英 | 使用超英技能的消耗 | 3 |
| **行动 token（受害者·舆论）** | 受害者 | 使用受害者技能的消耗 | 3 |
| **暴露度** | 罪犯个人 | 0-5 刻度，越高警长越容易追查，≥5 可直接逮捕 | 5 |
| **线索标记** | 全局/警长专用 | 推进嫌疑链消耗 | 按需 |
| **赃物标记** | 罪犯专用 | 作为额外得分资源（3 赃物 = 1 分）；赃物可在交易事件中作为通用货币使用 | 按需 |
| **声望** | 超级英雄 | 累积到一定量可出击或兑换分数 | 10 |
| **影响力** | 受害者联盟 | 用于发动舆论/游行/复仇 | 10 |

### 全局状态值（精简为 2 个）

| 状态 | 初始值 | 说明 |
|------|-------|------|
| **治安值** | 10 | 每次犯罪 -1，黎明结算自动恢复 +1。≤3 时罪犯犯罪成本 -1，≥8 时警长额外 +1 分 |
| **恐慌值** | 0 | 严重犯罪（抢劫 +1 / 行凶 +2）会增加。≥8 时警长行动力上限 -1，≥10 时立即结束（城市崩溃） |

> 治安值新增自然恢复机制（黎明结算时 +1），3 名罪犯每轮犯罪 3 次 = 治安值 -3 + 恢复 +1，净影响 -2/轮，10 轮理论最低约 -10，但布控/关押/越狱等减速因素会减缓下降。

## 游戏时长与人数

| 配置 | 人数 | 目标分数 | 预计时长 | 说明 |
|------|------|---------|---------|------|
| 2 人局 | 1 警长 + 1 罪犯 | 12 分 | 30-45 分钟 | 引入"虚拟罪犯"补足线索产出 |

## 与 draft-2-B 的差异对比

| 维度 | draft-2-B | 本方案（draft-3-A） | 优化理由 |
|------|----------|-------------------|---------|
| 回合阶段 | 5 阶段 | **6 阶段（个人完整回合）** | 参考三国杀，每个玩家独立完成摸牌出牌弃牌 |
| 行动限制方式 | 未明确 | **Token 行动力系统** | 每个阵营有专属 token 消耗出牌，消耗后留在地点交互 |
| 出牌顺序 | 警长先行→逆序 | **标准回合制：警长先→顺时针轮流** | 用户硬约束；信息透明、主题契合 |
| 胜利条件 | 各阵营专属条件 | **统一跑分制（15 分）** | 避免逻辑矛盾，清晰公平 |
| 全局状态 | 治安/民意/恐慌 3 值 | **治安/恐慌 2 值** | 精简系统 |
| 嫌疑链 | 5 级/15 线索 | **4 级/10 线索** | 降低警长操作门槛 |
| 治安值曲线 | 只降不升 | **每次犯罪 -1 + 黎明结算恢复 +1** | 防止恶性循环 |
| 赊账 | 无限赊账 | **每回合最多赊 1 情报** | 防止策略坍塌 |
| 第三方加入 | 仅 5 人或以上 | **4 人局可选替换 1 罪犯** | 提供更多配置灵活性 |
| 资源体系 | 11 种 | **精简为 7 种+ 4 种 token** | token 即行动力的统一设计 |
| 牌与技能关系 | 未明确 | **牌的效果固定，技能选择性修改** | 用户纠正，降低学习成本 |
| 角色技能组织 | 2-4 条混在一起 | **阵营技能 1-2 条 + 专属技能 1-2 条** | 用户建议，分两层更清晰 |

| 牌库规模 | ~50-60 张 | **~95 张（基础牌占 84%）** | 参考三国杀，充足且基础牌占优 |
