## 核心游戏循环（玩家每回合做什么）

### 回合框架：3 阶段结构

```
夜晚开始（每回合 = 1 个夜晚）
  ↓
① 阶段 · 夜幕降临（准备）
  ├─ 翻开 1 张事件牌（全局生效）
  ├─ 所有玩家摸 2 张手牌
  └─ 警长恢复行动力（当前恐慌值决定）
  ↓
② 阶段 · 暗流涌动（出牌与行动）
  ├─ 警长回合开始：警长出 1 张手牌并公开执行（所有人可见）
  │   （警长先手 → 模拟"警长巡逻布控在先"的叙事逻辑）
  ├─ 警长右手边第一位罪犯回合开始：该罪犯出 1 张手牌并公开执行
  ├─ 顺时针继续下一位玩家（超英/受害者联盟按座位顺序）
  └─ 每个玩家的行动需指定目标地点（城市中央展示区的地名牌）
  ↓
③ 阶段 · 黎明结算（结算与结束）
  ├─ 结算所有持续性效果（警官持续、关押续期等）
  ├─ 警长执行调查阶段（消耗线索标记推进嫌疑链）
  ├─ 清除本回合临时标记
  ├─ 检查胜利条件（是否有人到达目标分数）
  └─ 进入下一回合 / 游戏结束
```

**警长先手的主题逻辑**：警长先部署布控 → 罪犯看到警长动向后再选择作案地点。后手罪犯获得信息优势，同时符合"警察巡逻在先"的叙事。

## 通用牌库

### 核心原则

> **所有牌的效果对所有玩家完全一致。牌面上印的效果就是这张牌的效果，不会因为不同玩家而改变。角色技能可以修改某张/某类牌的效果，但这种修改是例外而非规则。**

### 禁止阵营专属牌

**牌库中没有任何一张牌是"只有某个阵营才能用"的。** 所有玩家摸到的每一张牌都有基本用途。策略性差异化全部由角色技能实现，而非通过阵营专属牌。

### 牌库结构（约 95 张）

| 类型 | 牌名 | 数量 | 牌面效果（一行字） | 功能定位 |
|------|------|------|-------------------|---------|
| 🟦 **基础牌** | **踩点** | ×30 | 获得 1 情报 | 最基本的经济牌，量最大 |
| | **调查** | ×25 | 获得 1 线索 | 信息牌，量第二 |
| | **转移** | ×15 | 移动目标地点 | 机动牌 |
| | **潜伏** | ×10 | 本回合暴露度-1，免疫 1 次逮捕尝试 | 防御牌 |
| 🟪 **特殊牌** | **密谋** | ×5 | 获得 2 情报并摸 1 张牌 | 高价值经济 |
| | **追查** | ×5 | 获得 2 线索并查看 1 名玩家的手牌 | 高价值信息 |
| | **金蝉脱壳** | ×3 | 逃脱一次关押或针对效果 | 保命牌 |
| | **孤注一掷** | ×2 | 弃所有手牌，每弃 1 张获得 1 分 | 逆转牌 |

### 基础牌占 84% 的设计意图

参考三国杀的牌库结构（杀/闪/桃等基础牌占 49%），本方案将基础牌占比提升至 **84%**，理由如下：

1. **降低学习成本**：玩家只需记住 4 种基础牌的效果，就能玩
2. **策略深度在技能上**：每张基础牌的使用方式由角色技能决定，同样的牌在不同角色手中产生不同结果
3. **减少"废牌"概率**：基础牌量大→抽牌容错率高→玩家不会摸到完全无用的牌

### "犯罪"和"布控"的实现方式

这些功能不再需要专门的犯罪牌或布控牌，而是通过 **"基础牌 + 角色技能"** 实现：

| 场景 | 玩家出牌 | 牌面效果 | 角色技能覆盖后 |
|------|---------|---------|-------------|
| 罪犯想犯罪 | 出**踩点牌** | "获得 1 情报" | 阵营技能"犯罪"：改为执行一次犯罪行动，消耗 X 情报获得分数 |
| 警长想布控 | 出**调查牌** | "获得 1 线索" | 阵营技能"部署权"：改为布控行动，在目标地点警戒值+1 |
| 超英想出击 | 出**潜伏牌** | "本回合暴露度-1" | 阵营技能"出击"：改为阻止目标地点的犯罪行动 |
| 受害者想爆料 | 出**密谋牌** | "获得 2 情报并摸 1 张" | 阵营技能"爆料"：改为使目标暴露度+1，自己+1分 |

### 牌库规模总结

| 类别 | 数量 | 占比 |
|------|------|------|
| 🟦 基础牌（踩点/调查/转移/潜伏） | 80 张 | 84% |
| 🟪 特殊牌（密谋/追查/金蝉脱壳/孤注一掷） | 15 张 | 16% |
| **总计** | **约 95 张** | **100%** |

## 胜利条件：跑分制

### 核心规则

- 游戏以 **目标分数到达即结束** 为统一规则
- **目标分数 = 15 分**（基准配置，可随人数调整）
- 一旦有人到达目标分数，**立即进行终局结算**（无人再行动）
- **不再有"专属胜利直接结束"** 的独立条件，避免逻辑矛盾

### 各阵营得分方式

| 阵营 | 得分方式 | 单次得分 | 说明 |
|------|---------|---------|------|
| **警长** | 逮捕关押罪犯 → 每回合 +1 分 | 持续 | 关押期间每回合结算 |
| | 逮捕时一次性得分 | +2 分 | 逮捕成功时 |
| | 维护城市秩序（治安值高 → 每回合得分） | +1 分/回合 | 治安值 ≥8 时 |
| | 终局治安值 ≥8 奖励 | +3 分 | 仅终局结算 |
| **罪犯** | 成功犯罪 | 1-3 分 | 取决于犯罪类型和投入资源 |
| | 越狱成功 | +1 分 | 从关押中逃脱 |
| **超级英雄** | 阻止犯罪 | +1 分 | 成功阻止一次犯罪行动 |
| | 协助逮捕 | +1 分 | 在同一地点与警长同时行动时 |
| | 声望累积 | +1 分/每 2 声望 | 声望是一种次级资源 |
| **受害者联盟** | 游行成功 | +2 分 | 需消耗影响力 |
| | 爆料揭露 | +1 分/次 | 需消耗影响力 |
| | 媒体风暴 | +2 分 | 终极技能，一次游戏限 1 次 |
| | 终局治安值 ≤3 奖励 | +5 分 | 仅终局结算 |

### 终局规则

1. 有人到达 **15 分** → 立即结束，**该玩家胜出**
2. 第 **10 回合** 结束时无人到达 15 分 → 分数最高者胜出
3. 平局时：贡献最多者胜（警长看逮捕人数，罪犯看犯罪次数，超英看阻止次数，受害者看游行次数）

## 基本规则框架

### 游戏准备

1. **地点牌池**：从 20+ 张地点牌中随机抽取 **10 张**，面朝上摆放在桌面中央（2×5 排列构成"城市版图"）
2. **牌库**：通用牌库约 95 张（踩点×30 + 调查×25 + 转移×15 + 潜伏×10 + 密谋×5 + 追查×5 + 金蝉脱壳×3 + 孤注一掷×2），洗混后放置一旁
3. **角色选择**：
   - 警长 1 名（从方振华/李敏中选择）
   - 罪犯 1-4 名（从幽灵/狐狸/老鼠/公牛/蛇中选择）
   - 超英/受害者联盟：在 4 人基准中即可选择加入（替换 1 名罪犯或作为第 5 人）
4. **初始手牌**：所有玩家摸 **3 张**
5. **资源标记**：各玩家领取对应角色标记（分数标记、情报、暴露度等）

### 出牌规则

- 采用**标准回合制**：警长先行动 → 按座位顺时针轮流进行
- **警长回合**：出 1 张手牌并公开执行效果（所有人可见）
- **罪犯回合**：顺时针下一位玩家出 1 张手牌并公开执行效果
- **全部玩家行动完毕后** → 进入③黎明结算阶段
- 出牌必须指定目标地点（若行动需指定地点）
- 出牌后摸 **1 张牌**（保持手牌量，事件牌不进入手牌）

**标准回合制的核心优势**：

| 维度 | 说明 |
|------|------|
| **信息透明** | 后手玩家能看到先手玩家的行动，决策有信息支撑 |
| **主题契合** | 警长先巡逻布控 → 罪犯后选择作案，叙事逻辑一致 |
| **消除运气** | 不再有"猜拳"感，所有决定基于可见信息 |
| **学习成本低** | 标准回合制是桌游通用规则，新手无需额外学习 |

### 资源体系

| 资源 | 归属 | 用途 | 上限 |
|------|------|------|------|
| **分数（胜利点）** | 所有玩家 | 在计分轨道上记录 | 无上限 |
| **情报标记** | 所有玩家通用 | 执行行动的成本资源 | 5 |
| **暴露度** | 罪犯个人 | 0-5 刻度，越高警长越容易追查，≥5 可直接逮捕 | 5 |
| **线索标记** | 全局/警长专用 | 推进嫌疑链消耗 | 按需 |
| **行动力** | 警长专属 | 每回合执行巡逻/部署/逮捕等行动 | 受恐慌值影响 |
| **赃物标记** | 罪犯专用 | 作为额外得分资源（3 赃物 = 1 分） | 按需 |
| **声望** | 超级英雄 | 累积到一定量可出击或兑换分数 | 10 |
| **影响力** | 受害者联盟 | 用于发动舆论/游行/复仇 | 10 |

### 全局状态值（精简为 2 个）

| 状态 | 初始值 | 说明 |
|------|-------|------|
| **治安值** | 10 | 每次犯罪 -1，每回合结束自动恢复 +1。≤3 时罪犯犯罪成本 -1，≥8 时警长每回合额外 +1 分 |
| **恐慌值** | 0 | 严重犯罪（抢劫 +1 / 行凶 +2）会增加。≥8 时游戏进入临界状态，≥10 时立即结束（城市崩溃） |

> 合并了 draft-2-B 中的民意值功能。治安值新增自然恢复机制（每回合 +1），3 名罪犯每回合犯罪 3 次 = 治安值 -3 + 恢复 +1，净影响 -2/回合，10 回合理论最低约 -10，但布控/关押/越狱等减速因素会减缓下降，实际约在第 5-6 回合降至 0 附近，节奏合理。

## 游戏时长与人数

| 配置 | 人数 | 目标分数 | 预计时长 | 说明 |
|------|------|---------|---------|------|
| 2 人局 | 1 警长 + 1 罪犯 | 12 分 | 30-45 分钟 | 引入"虚拟罪犯"补足线索产出 |
| 3 人局 | 1 警长 + 2 罪犯 | 13 分 | 45-60 分钟 | 引入"虚拟罪犯"补足线索产出 |
| **4 人局（基准）** | **1 警长 + 3 罪犯** | **15 分** | **60-90 分钟** | 基准配置，无第三方 |
| 5 人或以上 | 1 警长 + 3 罪犯 + 1-2 第三方 | 15 分 | 75-120 分钟 | 可引入超英和/或受害者联盟 |

## 与 draft-2-B 的差异对比

| 维度 | draft-2-B | 本方案（draft-3-A） | 优化理由 |
|------|----------|-------------------|---------|
| 回合阶段 | 5 阶段 | **3 阶段** | 减少操作复杂度 |
| 出牌顺序 | 警长先行→逆序 | **标准回合制：警长先→顺时针轮流** | 用户硬约束；信息透明、主题契合 |
| 胜利条件 | 各阵营专属条件 | **统一跑分制（15 分）** | 避免逻辑矛盾，清晰公平 |
| 全局状态 | 治安/民意/恐慌 3 值 | **治安/恐慌 2 值** | 精简系统 |
| 嫌疑链 | 5 级/15 线索 | **4 级/10 线索** | 降低警长操作门槛 |
| 治安值曲线 | 只降不升 | **每次犯罪 -1 + 回合结束恢复 +1** | 防止恶性循环 |
| 赊账 | 无限赊账 | **每回合最多赊 1 情报** | 防止策略坍塌 |
| 第三方加入 | 仅 5 人或以上 | **4 人局可选替换 1 罪犯** | 提供更多配置灵活性 |
| 资源体系 | 11 种 | **精简为 7 种** | 控制子系统数量 |
| 出牌机制 | 同时暗出 | **标准回合制：警长先→顺时针轮流** | 用户硬约束 |
| 牌与技能关系 | 未明确 | **牌的效果固定，技能选择性修改** | 用户纠正，降低学习成本 |
| 角色技能组织 | 2-4 条混在一起 | **阵营技能 1-2 条 + 专属技能 1-2 条** | 用户建议，分两层更清晰 |
| 牌库结构 | 9 种牌含阵营专属 | **8 种牌全部通用，取消阵营专属牌** | 用户硬约束 |
| 身份专属牌 | G-02犯罪/G-06布控存在 | **全部取消，功能由角色技能实现** | 避免摸到无用牌 |
| 牌库规模 | ~50-60 张 | **~95 张（基础牌占 84%）** | 参考三国杀，充足且基础牌占优 |
