# 方案 3A · 配件清单（v2 · 无 Token 版）

> 基于 2r 阶段全面重构——删除 Token 行动力系统，引入卡牌标签系统。
> 所有配件按四类框架组织：卡牌 / 资源型 Token / 版图 / 分数。

## 1. 卡牌类

### 1.1 通用牌库（90 张 · 63×88mm 标准卡牌尺寸）

所有卡牌包含**标签**，标签定义行动限制：

| 标签 | 含义 | 效果 |
|------|------|------|
| **无标签（普通）** | 标准行动 | 每回合可出任意张 |
| **🏷️ 独特** | 大行动 | 本回合最多出 **1 张**带独特的牌 |
| **🏷️ 快速** | 反应行动 | 不受独特限制，可在独特前后自由使用 |

| 牌名 | 标签 | 数量 | 牌面效果 | 占比 |
|------|------|------|---------|------|
| **踩点** | 普通 | ×30 | 获得 1 情报 | 33.3% |
| **调查** | 普通 | ×20 | 获得 1 情报；若目标地点有证据则额外 +1 情报 | 22.2% |
| **转移** | 快速 | ×15 | 拖延一回合，免疫 1 次逮捕或针对效果 | 16.7% |
| **潜伏** | 快速 | ×10 | 本回合暴露度 -1 | 11.1% |
| **密谋** | 普通 | ×5 | 获得 2 情报并摸 1 张牌 | 5.6% |
| **金蝉脱壳** | 普通 | ×3 | 越狱时消耗减半（替代 2 情报） | 3.3% |
| **孤注一掷** | 普通 | ×2 | 弃所有手牌，每弃 1 张获得 1 分 | 2.2% |
| **合计** | | **90 张** | | **100%** |

**牌背设计**：统一使用城市夜景剪影 + "罪恶都市"字样。

**牌面模板**：

```
┌─────────────────────┐
│                     │
│   [牌名]    [标签]   │
│                     │
│   (背景插画区域)     │
│                     │
│   [牌面效果文字]     │
│                     │
│     [数量]          │
│   "罪恶都市"         │
└─────────────────────┘
```

- **尺寸**：63×88mm（标准卡牌尺寸）
- **标签位置**：牌名右侧，用标签图标标识（无标签/🏷️独特/🏷️快速）

## 2. 资源型 Token

### 2.1 情报（唯一经济资源）

| 属性 | 说明 |
|------|------|
| **形态** | 灰色 12mm 木质圆片 |
| **数量** | 20 个 |
| **获得方式** | 踩点 +1、调查 +1（有证据再+1）、密谋 +2 并摸 1 张、事件牌 E-07 |
| **消耗方式** | 犯罪成本、布控（1情报）、推进嫌疑链（3情报/级）、越狱成本 |
| **上限** | 每名玩家最多持有 5 情报（可在版图上标注边界） |

### 2.2 证据（公共资源，地点交互）

| 属性 | 说明 |
|------|------|
| **形态** | 黄色 12mm 木质圆片 |
| **数量** | 15 个 |
| **产生** | 罪犯执行"犯罪"时，放到目标地点 1 个 |
| **收集** | 警长黎明结算时从地点上收集 |
| **用途** | 警长收集后转化为"线索池"，用于推进嫌疑链 |
| **特殊** | 某些技能可消耗情报放置假证据（狐狸·假情报）、或避免产生证据（幽灵·消失） |

### 2.3 布控标记（警长专用）

| 属性 | 说明 |
|------|------|
| **形态** | 蓝色 12mm 木质圆片 |
| **数量** | 5 个 |
| **产生** | 警长执行"布控"（独特·消耗 1 情报），将标记放到目标地点 |
| **效果** | 目标地点的犯罪成本 +1 |
| **持续** | 直至下夜黎明结算时移除 |
| **上限** | 同一地点最多 1 个布控标记 |

### 2.4 暴露度标记（罪犯专用）

| 属性 | 说明 |
|------|------|
| **形态** | 红色 12mm 木质圆片，在轨道上滑动 |
| **数量** | 每名罪犯 1 个，共用轨道（0-5 刻度） |
| **增加** | 犯罪时根据类型增加（盗窃+1、抢劫+2、行凶+3、诈骗+1、渗透+1） |
| **减少** | 黎明结算时所有罪犯暴露度 -1（最低 0）；使用潜伏牌 -1 |
| **逮捕条件** | 暴露度 ≥5 时，警长可在黎明结算时执行逮捕 |

### 2.5 假证据（狐狸专属）

| 属性 | 说明 |
|------|------|
| **形态** | 灰色半透明 12mm 木质圆片（区别于黄色证据） |
| **数量** | 3 个（随游戏附带） |
| **产生** | 狐狸消耗 1 情报执行"假情报"技能 |
| **效果** | 警长在黎明结算收集时，假证据无效（不产生线索） |
| **考验** | 警长需分辨真假证据（假证据形状不同，但物理上需要翻面才能区分？或直接用不同颜色） |
