### 2.2 双面行动 Token（核心配件）

所有阵营的行动 Token 采用**双面设计**，每面颜色不同，表示不同状态。

| Token | 阵营 | 数量 | 材质 | A面（资源态） | B面（消耗态） | 消耗后去向 |
|-------|------|------|------|-------------|-------------|-----------|
| 🔍 **线索** | 罪犯 | 3 个 | 双面木质圆片（15mm） | 🟡 **线索**（黄色） | 🔴 **物证**（红色） | 放到目标地点→警长收集翻回A面 |
| 👮 **行动力** | 警长 | 4 个 | 双面木质圆片（15mm） | 🔵 **行动力**（蓝色） | ⚪ **布控**（白色/灰色） | 放到目标地点→该地警戒值+1 |
| ⚡ **精力** | 超英 | 3 个 | 双面木质圆片（15mm） | 🟢 **精力**（绿色） | 🟢 **[消耗]**（绿色·灰字） | 留在超英面板上，自产自销 |
| 📢 **舆论** | 受害者 | 3 个 | 双面木质圆片（15mm） | 🟠 **舆论**（橙色） | 🟠 **[消耗]**（橙色·灰字） | 留在受害者面板上，自产自销 |

**双面 Token 的使用逻辑**：

```
玩家回合开始补充到上限 → 所有 Token 展示 A面（资源态）
  ↓
出牌消耗 Token → 翻到 B面（消耗态）
  ↓
如果是罪犯/警长 → B面 Token 放到目标地点上
  ↓      ↓
警长在黎明结算时  警长派驻使该地点
收集B面(🔴物证)   警戒值+1（⚪布控）
翻回A面(🟡线索)   持续 N 回合后移除
→ 转为警长线索池
```
