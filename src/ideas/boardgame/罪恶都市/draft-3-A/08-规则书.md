# 方案 3A · 规则书初稿

> 游戏名称：《罪恶都市：夜晚属于我们》
> 设计类型：非对称卡牌轻中策桌游
> 支持人数：2-7 人
> 游戏时长：30-120 分钟（取决于人数）
> 目标年龄：14+

---

## 第一章：游戏概述

### 1.1 背景故事

新港城，一座典型的东海岸港口都市。经济下滑带来失业率飙升、贫富差距拉大，犯罪率逐年攀升。警局新任局长决心整顿治安，但资源极度有限。几股犯罪势力正在暗处蠢蠢欲动，他们各有各的野心和计划……

"白天的城市属于守法公民，夜晚的城市属于我们。"

### 1.2 游戏目标

- 游戏采用 **跑分制**，目标分数 15 分
- 最先到达 15 分的玩家获胜
- 第 10 回合结束时无人到达 15 分，则分数最高者获胜

### 1.3 核心概念

| 概念 | 说明 |
|------|------|
| **回合** | 每个玩家有个人完整回合（摸牌+出牌+弃牌），所有玩家执行完后进入黎明结算 |
| **通用牌库** | 所有玩家共享的牌库，牌的效果对所有玩家一致 |
| **角色技能** | 玩家的差异化来源——阵营技能（共享）+ 专属技能（个人） |
| **Token 行动力** | 每个阵营有专属 token，每回合补至上限。出牌消耗 token |
| **手牌上限** | 弃牌阶段强制弃至 5 张，防止手牌通胀 |
| **城市地点** | 每局随机抽取 10 张地点牌构成城市版图 |

## 第二章：配件

### 2.1 配件清单

详见 [06-配件清单.md](./06-配件清单.md)。

### 2.2 游戏准备

1. **构建城市**：从地点牌池随机抽取 10 张，在桌面中央按 2×5 排列
2. **选择角色**：1 名警长，其余玩家选罪犯（5 人以上可选超英/受害者）
3. **领取配件**：角色卡、分数标记、初始资源、Token 池
4. **设置全局状态**：治安值 10、恐慌值 0
5. **发牌**：洗混牌库（95 张），每位玩家摸 3 张手牌
6. **开始**：警长翻开第 1 张事件牌 → 警长的个人回合开始

### 2.3 初始资源与 Token

| 阵营 | 初始手牌 | Token 名 | Token 上限 |
|------|---------|---------|-----------|
| **警长** | 3 张 | 行动力 👮 | 4 |
| **罪犯** | 3 张 | 线索 🔍 | 3 |
| **超级英雄** | 3 张 | 精力 ⚡ | 3 |

## 第三章：每夜的流程

### 整体流程

每一夜由两部分构成：

```
① 依次执行个人完整回合（警长先手 → 顺时针轮流）
② 所有人执行完后 → 黎明结算

示例（4 人局）：
  警长个人回合 → 罪犯A个人回合 → 罪犯B个人回合 → 罪犯C个人回合
  → 黎明结算 → 进入下一夜
```

### 个人完整回合（6 阶段）

每位玩家在自己的回合中执行以下 6 个阶段：

| 阶段 | 名称 | 内容 |
|------|------|------|
| ① | **回合开始** | 第一位玩家翻开事件牌；触发"回合开始时"效果 |
| ② | **补充 Token** | 将自己的行动 token 补至上限 |
| ③ | **摸牌** | 从通用牌库摸 2 张手牌 |
| ④ | **出牌** | 可出任意张手牌，每张消耗对应 token；核心行动限 1 次 |
| ⑤ | **弃牌** | 弃牌至手牌上限（5 张） |
| ⑥ | **回合结束** | 触发"回合结束时"效果；轮到下一位玩家 |

## 第四章：Token 行动力系统

### 4.1 什么是 Token

Token 是每个阵营专属的"行动力指示器"。每打出一张手牌，必须消耗对应数量的 token。

| 阵营 | Token | 上限 | 每回合补充 | 消耗去向 |
|------|-------|------|-----------|---------|
| **罪犯** | 🔍 线索 | 3 | 补至 3 | 出牌消耗→放到目标地点→警长收集 |
| **警长** | 👮 行动力 | 4 | 补至 4（恐慌≥5时-1，≥8时-2） | 执行警长行动 |
| **超英** | ⚡ 精力 | 3 | 补至 3 | 使用超英技能 |
| **受害者** | 📢 舆论 | 3 | 补至 3（恐慌共鸣可额外） | 使用受害者技能 |

### 4.2 Token 消耗规则

| 出牌 | 消耗 | 牌面效果 |
|------|------|---------|
| **踩点** | 1 token | 获得 1 情报 |
| **调查** | 1 token | 获得 1 线索标记 |
| **转移** | 1 token | 移动至目标地点 |
| **潜伏** | 1 token | 暴露度-1，免疫逮捕 |
| **密谋** | 2 token | 获得 2 情报并摸 1 张 |
| **追查** | 2 token | 获得 2 线索并看 1 玩家手牌 |
| **金蝉脱壳** | 1 token | 逃脱关押 |
| **孤注一掷** | **0 token** | 弃所有手牌，每弃 1 张得 1 分 |

### 4.3 Token 交互逻辑

| 交互 | 叙事 |
|------|------|
| 罪犯出牌消耗线索 token → 放到目标地点 | 罪犯在案发现场留下痕迹 |
| 警长黎明结算时收集线索 token | 警长勘察现场收集物证 |
| 警长消耗行动力部署布控 | 警长在目标地点安排警力 |

> **Token 与手牌的记忆口诀**：手牌=你的选项，Token=你的行动次数。两者缺一不可。

## 第五章：出牌阶段规则

### 5.1 出牌规则

- 可出任意张手牌，但不超过 token 数量和手牌数
- 每张牌需消耗对应数量的 token（通常 1，特殊牌 2）
- **出牌不补牌**
- 出牌必须指定目标地点（如需）
- 可随时主动结束出牌阶段

### 5.2 核心行动限制

每个玩家每回合最多执行 **1 次核心行动**：

| 阵营 | 核心行动 |
|------|---------|
| **罪犯** | **犯罪**：出踩点牌（消耗 1 token + 情报），改为执行犯罪 |
| **警长** | **逮捕**（2 行动力）/ **推进嫌疑链**（1 行动力） |
| **超英** | **出击**：出潜伏牌（消耗 2 精力），阻止犯罪 |
| **受害者** | **爆料**/**游行**/**媒体风暴**：消耗舆论 token + 影响力 |

### 5.3 手牌上限

手牌上限 **5 张**。弃牌阶段必须弃至 ≤5 张。

## 第八章：黎明结算

### 8.1 警长调查

1. 收集地点上的线索 token（罪犯消耗后留下的）
2. 消耗 3 线索推进嫌疑链 1 级（每夜最多 2 级）
3. 暴露度≥5 或嫌疑链 4 级 → 逮捕（消耗剩余行动力 2）

**逮捕**：关押 2 回合，警长+2 分，罪犯暴露度清零

### 8.2 全局状态

| 检查 | 效果 |
|------|------|
| **治安值** | 每次犯罪-1，结算后恢复+1 |
| **恐慌值** | 抢劫+1，行凶+2 |
| **治安≥8** | 警长+1 分 |
| **治安≤3** | 罪犯犯罪成本-1 |
| **恐慌≥8** | 临界状态，警长行动力-1 |
| **恐慌≥10** | 城市崩溃 |

### 8.3 清理

清除临时标记、警官牌持续-1、关押倒计时-1、暴露度-1

### 8.4 胜利检查

≥15 分→获胜 / 恐慌≥10→崩溃 / 第10夜→终局 / 否则下一夜

## 第十二章：流程速查

### 个人完整回合

```
①开始(事件) → ②补Token(→上限) → ③摸2张 → ④出牌(消耗Token·核心限1) → ⑤弃牌至5 → ⑥结束
```

### Token 上限

```
罪犯线索 3 | 警长行动力 4 | 超英精力 3 | 受害者舆论 3
```

### 警长行动

```
布控(1) | 巡警(1) | 特警(2) | 推进嫌疑链(1) | 逮捕(2)
```

### 黎明结算

```
收集线索token → 推进嫌疑链 → 逮捕 → 治安+恐慌 → 清理 → 检查胜利
```

## 第十三章：FAQ

**Q：一回合能出几张牌？**
A：受 token 和手牌两个限制。例如罪犯 token 上限 3，最多出 3 张（除非有技能加成）。

**Q：出牌后补牌吗？**
A：不补。摸牌集中在阶段③统一进行。出牌阶段只出不进。

**Q：Token 消耗后去哪了？**
A：罪犯的线索 token 消耗后放到目标地点，警长黎明结算时收集。警长的行动力消耗即使用掉。

**Q：事件牌什么时候翻开？**
A：每夜第一位玩家（通常警长）的回合开始阶段翻开，持续至本夜黎明结算。

**Q：手牌和 Token 有什么区别？**
A：手牌是你的"选项库"——决定你能做什么；Token 是你的"行动力"——决定你能做几次。

**Q：Token 补充是补到上限还是补固定数量？**
A：补到上限。如果你本夜已经消耗了一些 token，则补至上限。如果你没消耗（被关押），则不补充。
