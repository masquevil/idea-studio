# 方案 3A · 规则书（v2 · 无 Token 版）

> 游戏名称：《罪恶都市：夜晚属于我们》
> 设计类型：非对称卡牌轻中策桌游
> 支持人数：2-7 人
> 游戏时长：30-120 分钟（取决于人数）
> 目标年龄：14+

> **版本说明**：v2 全面重构。删除了 Token 行动力系统，引入卡牌标签系统（普通/独特/快速）。所有行动限制通过卡牌标签实现，不再需要额外的 Token 管理。

---

## 第一章：游戏概述

### 1.1 背景故事

新港城，一座典型的东海岸港口都市。经济下滑带来失业率飙升、贫富差距拉大，犯罪率逐年攀升。警局新任局长决心整顿治安，但资源极度有限。几股犯罪势力正在暗处蠢蠢欲动，他们各有各的野心和计划……

"白天的城市属于守法公民，夜晚的城市属于我们。"

### 1.2 游戏目标

- 游戏采用 **跑分制**，目标分数 15 分
- 最先到达 15 分的玩家获胜
- 第 10 夜结束时无人到达 15 分，则分数最高者获胜

### 1.3 核心概念

| 概念 | 说明 |
|------|------|
| **通用牌库** | 所有玩家共享的牌库（约 95 张），每张牌印有固定效果 |
| **卡牌标签** | 每张牌带有标签：普通=可出任意张，独特=本回合最多 1 张，快速=不受独特限制 |
| **角色技能** | 差异化来源——阵营技能（共享）+ 专属技能（个人） |
| **手牌上限** | 5 张，弃牌阶段强制弃至上限 |
| **情报** | 唯一经济资源，踩点获得，犯罪/布控等消耗 |
| **证据** | 犯罪后放在地点上的公共资源，警长可收集 |
| **城市地点** | 每局随机抽取 10 张地点牌构成城市版图 |

## 第二章：配件

### 2.1 卡牌类型

| 类型 | 说明 | 数量 |
|------|------|------|
| **通用牌** | 所有玩家共用，牌面效果固定 | 约 95 张（踩点32/调查20/转移16/潜伏12/密谋6/金蝉脱壳3/孤注一掷2/紧急部署4） |
| **角色卡** | 每个玩家一张，正面技能+反面阵营速查 | 9 张 |
| **地点牌** | 构成城市版图 | 16+ 张，每局随机抽 10 张 |
| **事件牌** | 每夜翻开 1 张，影响全局 | 12 张，每局随机用 10 张 |

### 2.2 资源型 Token

| Token | 用途 | 数量 |
|-------|------|------|
| **情报**（灰） | 唯一经济资源，踩点获得，犯罪/布控/推进调查消耗 | 20 个 |
| **证据**（黄） | 犯罪后放到目标地点，警长黎明收集 | 15 个 |
| **假证据**（黄·背面X标记） | 狐狸专属，正面与真证据无法区分，收集时翻面验证 | 3 个 |
| **布控标记**（蓝） | 警长放置到地点上，犯罪成本 +1 | 5 个 |
| **暴露度标记**（红） | 每罪犯 1 个，在 0-5 轨道上滑动 | 5 个 |

### 2.3 版图

- 城市状态轨道（治安值+恐慌值）
- 计分轨道
- 嫌疑链面板（警长）
- 关押面板
- 超英/受害者面板

### 2.4 游戏准备

1. **构建城市**：从 16 张地点牌中按分组机制（详见 2.5）抽取 10 张，在桌面中央按 2×5 排列
2. **选择角色**：1 名警长，其余玩家选罪犯（5 人以上可选超英/受害者）
3. **领取配件**：角色卡、对应面板、情报 2（罪犯）/ 情报 0（警长）
4. **设置全局**：治安值 10、恐慌值 0
5. **发牌**：洗混通用牌库（约 95 张），每位玩家摸 3 张
6. **开始**：翻开第 1 张事件牌 → 警长的个人回合开始

### 2.5 地点牌分组机制

为确保每局城市地点的多样性，地点牌分为以下分组，按流程抽取：

| 分组 | 牌池 | 每局至少抽取 |
|------|------|-------------|
| **高警戒组**（警戒值≥2） | 银行、证券交易所、市政厅、警察局、郊区别墅 | **2 张** |
| **低警戒组**（警戒值=0） | 废弃工厂、贫民区、地下赌场、夜店、中央公园、大学城 | **2 张** |
| **高收益组**（★★★★） | 银行、赌场 | **1 张** |
| **其余随机** | 剩余地点牌 | 补齐至 10 张 |

**抽取流程**：

1. 从高警戒组随机抽 2 张
2. 从低警戒组随机抽 2 张
3. 从高收益组随机抽 1 张（如已包含在前两组则跳过）
4. 从剩余地点牌中随机抽取补齐至 10 张

## 第三章：卡牌标签系统

> **标签系统是本游戏的核心规则**。所有卡牌上的标签定义了该牌的行动限制，替代了传统桌游中"每回合只能出 X 张牌"的硬约束。

### 3.1 三种标签

| 标签 | 图标 | 含义 | 限制 |
|------|------|------|------|
| **普通** | — | 标准行动 | 每回合可出任意张 |
| **🏷️ 独特** | 🏷️ | 大行动 | 本回合最多出 **1 张**带独特的牌 |
| **🏷️ 快速** | ⚡ | 反应行动 | 不受独特限制，可在独特前后任意使用 |

### 3.2 标签交互规则

| 场景 | 是否允许 | 示例 |
|------|---------|------|
| 一回合出 3 张普通牌 | ✅ 允许 | 踩点×3（3 情报） |
| 一回合出 1 张独特牌 + 任意张普通牌 | ✅ 允许 | 犯罪（独特）+ 踩点（普通）×2 |
| 一回合出 2 张独特牌 | ❌ **禁止** | 不能同时犯罪+越狱 |
| 一回合出 1 张独特牌 + 任意张快速牌 | ✅ 允许 | 犯罪（独特）+ 潜伏（快速）+ 转移（快速） |
| 一回合只出快速牌，不出独特牌 | ✅ 允许 | 转移（快速）×2 + 潜伏（快速） |

### 3.3 牌库中卡牌的标签分布

| 牌名 | 标签 | 数量 |
|------|------|------|
| 踩点 | 普通 | 32 张 |
| 调查 | 普通 | 20 张 |
| 密谋 | 普通 | 6 张 |
| 金蝉脱壳 | 普通 | 3 张 |
| 孤注一掷 | 普通 | 2 张 |
| **普通小计** | | **63 张** |
| 转移 | 快速 ⚡ | 16 张 |
| 潜伏 | 快速 ⚡ | 12 张 |
| 紧急部署 | 快速 ⚡ | 4 张 |
| **快速小计** | | **32 张** |
| **总计** | | **95 张** |

> 独特标签不出现在通用牌上——独特行动全部通过**阵营技能**实现（如犯罪、布控、逮捕等）。

## 第四章：每夜的流程

### 4.1 整体流程

每一夜由两部分构成：

```
① 所有玩家依次执行个人完整回合（警长先手 → 顺时针轮流）
② 所有人执行完毕后 → 黎明结算（全局更新）
```

### 4.2 个人完整回合

每位玩家在自己的回合中执行以下阶段：

| 阶段 | 名称 | 内容 |
|------|------|------|
| ① | **回合开始** | 第一位玩家翻开 1 张事件牌（效力覆盖整夜）；触发"回合开始时"效果 |
| ② | **摸牌** | 从通用牌库摸 **2 张**手牌 |
| ③ | **出牌** | 可出任意张手牌（受标签限制）；**独特行动最多 1 次** |
| ④ | **弃牌** | 弃牌至手牌上限（5 张） |
| ⑤ | **回合结束** | 触发"回合结束时"效果；轮到下一位玩家 |

> **事件牌时机**：仅第一位玩家（警长）的回合开始阶段翻开 1 张，持续至黎明结算结束。之后的玩家不再重复翻开。

## 第五章：情报系统

### 5.1 什么是情报

情报是游戏中**唯一的经济资源**。所有阵营都需要情报来执行核心行动。

| 产生情报 | 消耗情报 |
|---------|---------|
| 踩点（普通）：+1 情报 | 犯罪：依类型消耗（见 7.1） |
| 调查（普通）：+1 情报（有证据再+1） | 布控（警长）：1 情报 |
| 密谋（普通）：+2 情报并摸 1 张 | 推进嫌疑链（警长）：3 情报/级 |
| 紧急部署（快速）：+1 情报 | 越狱（罪犯）：3 情报 + 弃 1 手牌 |
| 事件牌（E-07）：+2 情报 | 搜查（警长）：1 情报 |

### 5.2 情报上限

每名玩家最多持有 **5 情报**。超过上限时，多出的情报无法获得（先得先得，超出的无效）。

### 5.3 情报的竞争性

情报是有限资源——警长和罪犯都需要情报。踩点和调查是牌库中产生情报的主要手段，这也意味着：

- 摸到足够多的踩点/调查 = 行动力充足
- 如果没有情报，罪犯无法犯罪，警长无法布控

## 第六章：出牌阶段

### 6.1 出牌规则

| 规则 | 说明 |
|------|------|
| **出牌数量** | 可出任意张手牌，但受标签限制（独特最多1张） |
| **出牌不补牌** | 出牌后不摸牌，摸牌集中在阶段② |
| **指定目标** | 如果需要指定地点，必须声明目标地点 |
| **主动结束** | 可随时主动结束出牌阶段 |
| **空过** | 可以不出任何牌，直接进入弃牌阶段 |

### 6.2 手牌循环

```
起手 3 张 → 摸 2 张 = 5 张 → 出 0-5 张 → 弃牌至 5
→ 剩余 X 张 → 下回合摸 2 张 = X+2 张 → ...

正常波动范围：2-5 张
满额输出：起手 5 张 → 出 5 张 → 手牌 0 → 下回合摸 2 张
保守策略：起手 5 张 → 出 2 张 → 保留 3 张 → 下回合 5 张
```

### 6.3 出牌示例

```
罪犯老鼠的回合：手牌 5 张（踩点×3 + 转移×1 + 潜伏×1）

出牌顺序：
  ① 踩点（普通）→ 获得 1 情报（手牌-1，情报+1）
  ② 踩点（普通）→ 获得 1 情报（手牌-2，情报+2）
  ③ 老鼠专属"轻手轻脚"：踩点额外+1 → 第2张踩点变2情报（情报+3）
  ④ 阵营技能"犯罪"（独特）→ 声明银行，消耗 2 情报，盗窃 +1 分
     → 在银行放置 1 证据 Token
  ⑤ 潜伏（快速 ⚡）→ 暴露度-1（手牌-1，不受独特限制）
  共出 5 张牌，手牌用尽
⑥ 弃牌阶段：手牌 0 ≤ 5，无需弃牌
```

## 第七章：阵营行动详解

### 7.1 罪犯：犯罪

**犯罪**是罪犯的核心行动，带 🏷️ 独特 标签。

| 类型 | 情报消耗 | 得分 | 暴露+ | 恐慌+ | 描述 |
|------|---------|------|------|------|------|
| **盗窃** | 2 | 1 分 | +1 | 0 | 潜入目标地点盗窃财物 |
| **抢劫** | 2 | 2 分 | +2 | +1 | 暴力抢夺，风险与收益并存 |
| **行凶** | 3 | 1 分 | +3 | +2 | 极端暴力，大幅提升恐慌 |
| **诈骗** | 1 | 1 分 | +1 | 0 | 低风险低收益，适合持续发育 |
| **渗透** | 2 | 1 分 | +1 | 0 | 犯罪同时获取情报 |

**犯罪流程**：

1. 声明目标地点
2. 选择犯罪类型
3. 支付情报成本（基础消耗 + 地点警戒值 + 布控加成 - 事件优惠）
4. 获得分数（基础分 + 地点收益加成）
5. 暴露度增加
6. 在目标地点放置 1 个证据 Token（黄色圆片）
7. 治安值 -1

**成本计算公式**：

```
犯罪总成本 = 基础情报消耗 + 地点警戒值 + 布控标记加成 - 治安福利(≤3时) - 事件优惠
```

**执行示例**：

```
公牛在银行抢劫：
① 声明目标：银行
② 犯罪类型：抢劫
③ 成本计算：
   基础消耗：2（抢劫）
   银行警戒值 2：+2
   无布控标记：+0
   总成本：4 情报
④ 公牛专属"暴力突破"：成本减半 → 实际消耗 2 情报
⑤ 得分：基础 2 分 + 银行收益 +1 = 3 分
⑥ 暴露度 +2，治安值 -1
⑦ 在银行放置 1 证据 Token
```

### 7.2 罪犯：越狱

**越狱**是罪犯的核心行动，带 🏷️ 独特 标签。被关押的罪犯可以尝试逃脱。

| 方式 | 消耗 | 效果 |
|------|------|------|
| **基础越狱**（阵营技能） | 3 情报 + 弃 1 张手牌 | 逃脱关押，暴露度 +2 |
| **牌辅助越狱**（有金蝉脱壳） | 1 张「金蝉脱壳」+ 1 情报 | 逃脱关押，暴露度 +2 |

> 越狱是阵营技能，**永远可用**——只要有足够的资源就可以执行。金蝉脱壳让越狱更便宜（从 4 件消耗降到 2 件），体现了稀有牌的价值。

### 7.3 警长：搜查（新增 · 主动调查能力）

为了应对罪犯保守策略时警长无事可做的窘境，警长出牌阶段新增**搜查**行动。

| 技能 | 标签 | 消耗 | 效果 |
|------|------|------|------|
| **搜查** | 🏷️ 独特 | 1 情报 | 选择 1 个目标地点进行搜查。即使该地点当前没有证据 Token，警长也能获得 1 情报 |

> **设计意图**：搜查让警长在罪犯不犯罪或极少犯罪时仍有事可做——消耗情报主动获取信息，不完全依赖罪犯的犯罪活动来驱动警长游戏体验。此行动与布控共享独特标签限制，警长需要在"布控压制"和"搜查推进"之间做出选择。

### 7.4 警长：布控

**布控**是警长的独特行动，带 🏷️ 独特 标签。

| 消耗 | 效果 | 持续 |
|------|------|------|
| 1 情报 | 在目标地点放置 1 个布控标记 | 至下夜黎明结算时移除 |

**布控效果**：目标地点的犯罪成本 +1（所有罪犯在该地点犯罪时多消耗 1 情报）。

**策略提示**：

- 布控高收益地点（银行、赌场）迫使罪犯去低收益地点犯罪
- 同一地点最多 1 个布控标记
- 黎明结算时移除所有布控标记

### 7.5 警长：逮捕

**逮捕**是警长的独特行动，在**黎明结算阶段**执行。

| 条件 | 消耗 | 效果 |
|------|------|------|
| 目标罪犯暴露度 ≥5 或嫌疑链已达 4 级 | 🏷️ 独特 | 关押 2 回合 |

**逮捕效果**：

- 目标罪犯关押 2 回合（跳过出牌阶段）
- 警长 +2 分（方振华 +3 分）
- 罪犯暴露度清零
- 关押期间警长每回合 +1 分

### 7.6 警长：推进嫌疑链

在黎明结算阶段，警长可消耗情报推进嫌疑链：

| 消耗 | 效果 | 上限 |
|------|------|------|
| 3 情报 | 推进 1 级（从 0 级至 4 级可逮捕） | 每夜最多 2 级 |

**李敏专属"精准抓捕"**：推进 1 级仅需 2 情报（每夜最多 3 级）。

### 7.7 超级英雄

| 技能 | 标签 | 消耗 | 效果 |
|------|------|------|------|
| **夜巡** | 被动 | 无 | 每回合获得 2 声望 |
| **出击** | 🏷️ 独特 | 3 声望 | 阻止目标地点本夜犯罪行动，+1 分 |
| **私刑** | 🏷️ 独特 | 4 声望 | 夺目标罪犯 2 资源（情报或手牌），自己 +1 声望 |

**堕落路线**（恐慌值 ≥6 时可选择，不可逆）：

- 夜巡改为 +3 声望/回合
- 出击改为"惩戒"（目标暴露度 +3）
- 私刑改为"审判"（目标关押 1 回合）

### 7.8 受害者联盟

| 技能 | 标签 | 消耗 | 效果 |
|------|------|------|------|
| **走访** | 被动 | 无 | 每回合获得 1 影响力 |
| **爆料** | 🏷️ 独特 | 2 影响力 | 目标罪犯暴露度 +1，自己 +1 分 |
| **独家** | 主动 | 1 影响力 | 查看 1 名罪犯本夜行动（专属技能） |
| **媒体风暴** | 🏷️ 独特 | 5 影响力 | 恐慌值 +1，自己 +2 分（限 1 次/局·专属技能） |

**恐慌共鸣**（被动）：每夜结算时，恐慌值每有 2 点，受害者额外获得 +1 影响力。

## 第八章：黎明结算

### 8.1 黎明结算统一流程图

以下是完整的黎明结算流程，请严格按此顺序执行：

```
┌─────────────────────────────────────┐
│       黎明结算（顺序执行）            │
├─────────────────────────────────────┤
│                                     │
│  ① 警长调查阶段                     │
│  ├─ 收集各地点的证据 Token           │
│  │   └── 翻面验证 → 假证据无效       │
│  ├─ 推进嫌疑链（消耗情报，每夜≤2级）  │
│  └─ 可选：向各目标推进              │
│                                     │
│  ② 逮捕检查                         │
│  ├─ 每名罪犯检查暴露度 ≥5            │
│  ├─ 或嫌疑链已达 4 级                │
│  └─ 符合条件的 → 执行逮捕（关押2回）  │
│                                     │
│  ③ 全局状态更新                     │
│  ├─ 治安值恢复 +1                    │
│  ├─ 恐慌值不变（仅在犯罪时增加）      │
│  ├─ 治安值≥8 → 警长 +1 分           │
│  ├─ 治安值≤3 → 罪犯福利（犯罪成本-1）│
│  └─ 恐慌值≥10 → 城市崩溃，直接终局   │
│                                     │
│  ④ 清理                             │
│  ├─ 移除所有布控标记                  │
│  ├─ 关押倒计时 -1（满2回合释放）      │
│  └─ 所有未被关押的罪犯暴露度 -1（≥0） │
│                                     │
│  ⑤ 胜利检查                         │
│  ├─ 任何玩家 ≥15 分 → 立即获胜       │
│  ├─ 恐慌值 ≥10 → 按分数排名          │
│  └─ 第 10 夜结束 → 分数最高者胜      │
└─────────────────────────────────────┘
```

> **注意事项**：
>
> - 逮捕检查（②）在暴露度 -1（④）之前执行。这意味着当夜暴露度达标的罪犯会被当场逮捕，不会因黎明结算的暴露度降低逃脱。
> - 治安值恢复 +1 在逮捕后、胜利检查前。逮捕导致的治安值变化已在犯罪阶段处理完毕。
> - 全局状态更新（③）中恐慌值≥10 的城市崩溃检查优先于常规胜利检查。

### 8.2 警长调查详解

1. **收集证据**：从各地点上收集证据 Token（罪犯犯罪后留下的），转为警长的"线索池"。**假证据翻面验证**——背面有"X"标记的即为假证据，收集时无效。
2. **推进嫌疑链**：消耗情报推进（3/级，李敏 2/级），每夜最多推进 2 级。
3. **逮捕**：检查各罪犯是否符合逮捕条件。

### 8.3 全局状态

| 检查 | 效果 |
|------|------|
| **治安值** | 每次犯罪 -1，黎明结算后恢复 +1 |
| **恐慌值** | 抢劫 +1，行凶 +2 |
| **治安≥8** | 警长 +1 分 |
| **治安≤3** | 罪犯犯罪成本 -1（全局福利） |
| **恐慌≥8** | 临界状态（无额外效果，用于 NPC 行为和阵营技能触发） |
| **恐慌≥10** | 城市崩溃 |

> **治安值对第三方的影响**：恐慌共鸣（受害者）间接关联治安值——治安值低意味着犯罪率高→恐慌值上升→受害者获得更多影响力。治安值本身对超英和受害者的直接影响有限，但恐慌共鸣机制使它们通过恐慌值的连锁反应间接牵动治安格局。

### 8.4 清理

1. 清除所有布控标记
2. 关押倒计时 -1（满 2 回合释放）
3. 所有未被关押的罪犯暴露度 -1（最低 0）
4. 治安值恢复 +1

### 8.5 胜利检查

| 条件 | 结果 |
|------|------|
| 任何玩家 ≥15 分 | 该玩家立即获胜 |
| 恐慌值 ≥10 | 城市崩溃，按当前分数排名 |
| 第 10 夜结束 | 终局结算，分数最高者胜 |

## 第九章：特殊规则

### 9.1 虚拟罪犯（2-3 人局）

当游戏人数不足 4 人时，需补充虚拟罪犯以维持游戏平衡。

| 配置 | 虚拟罪犯数量 |
|------|-------------|
| 2 人局（1 警长 + 1 罪犯） | 2 个虚拟罪犯 |
| 3 人局（1 警长 + 2 罪犯） | 1 个虚拟罪犯 |

**行为规则**：

虚拟罪犯在每个个人回合（紧接在真实罪犯之后，按固定顺序执行）自动执行以下流程：

```
每个虚拟罪犯的回合：
① 踩点（默认行动）：虚拟罪犯不消耗手牌，自动获得 1 情报（但不持有，仅用于模拟行为）
② 犯罪判定：如果距上次犯罪已过 2 夜，则自动犯罪一次
   ├─ 目标地点：随机选择收益最高的可用地点
   ├─ 犯罪类型：随机选择（盗窃 50% / 抢劫 30% / 诈骗 20%）
   ├─ 效果：治安值 -1，目标地点放置 1 证据 Token
   └─ 暴露度修正（仅用于模拟）：+1
③ "踩点"效果：虚拟罪犯每夜自动为警长产生 1 情报——视为"线人情报"（警长获得 1 情报）
```

**虚拟罪犯与真实玩家的交互**：

| 交互项 | 规则 |
|-------|------|
| **逮捕** | 虚拟罪犯不能被逮捕或关押。警长无法从虚拟罪犯处获得分数 |
| **证据** | 虚拟罪犯犯罪产生真实证据。警长黎明结算时可正常收集，用于推进对真实罪犯的嫌疑链 |
| **布控** | 布控标记对虚拟罪犯无效（虚拟罪犯不受犯罪成本影响） |
| **暴露度** | 虚拟罪犯不持有暴露度标记。虚拟罪犯的暴露度仅为模拟数据，不影响逮捕 |
| **越狱** | 虚拟罪犯不会被关押，不需要越狱 |
| **超英/受害者** | 虚拟罪犯不能成为超英"出击"或受害者"爆料"的目标 |

**设计意图**：

- 虚拟罪犯的主要作用是**提供证据流**——确保即使在 2-3 人局中，警长也有足够的证据推进嫌疑链
- 虚拟罪犯不参与真实分数竞争，不会导致"机器人赢"的挫败感
- 虚拟罪犯的每夜线人情报为小配置局提供了额外的经济缓冲

**难度变体**（可选规则）：

| 变体 | 说明 |
|------|------|
| **随机模式**（简单） | 虚拟罪犯的犯罪目标完全随机 |
| **集中模式**（中等） | 虚拟罪犯优先选择当前证据最少的普通位置 |
| **战略模式**（困难） | 虚拟罪犯优先选择真实罪犯所在区域的地点犯罪，最大程度分散警长注意力 |

### 9.2 同地点竞争

多名罪犯在同一夜同一地点执行犯罪时，各自暴露度额外 +1。

| 规则 | 说明 |
|------|------|
| **判定时机** | 在每夜的**黎明结算前**，检查所有犯罪所在地点。同一地点有 ≥2 名罪犯犯罪的，每名参与者额外 +1 暴露度 |
| **超英阻止** | 如果超英在该地点"出击"阻止了某起犯罪，被阻止的罪犯不计入同地点竞争（阻止后的犯罪视同未发生） |
| **越狱期间** | 被关押的罪犯不参与同地点竞争 |

### 9.3 赊账

| 规则 | 内容 |
|------|------|
| **时机** | 执行犯罪时，若情报不足可触发赊账 |
| **效果** | 每夜最多赊 1 情报，用暴露度 +2 代替 |
| **偿还** | 赊账产生的暴露度是永久性增加，只能通过潜伏/黎明结算降低 |

### 9.4 手牌上限与牌库耗尽

| 情况 | 规则 |
|------|------|
| 专属技能导致手牌增加 | 蛇·内应、密谋摸牌等产生的临时手牌计入上限 |
| 手牌 ≥ 5 时摸牌 | 先正常摸牌，再弃牌至上限，不浪费摸牌机会 |
| **牌库耗尽** | 如果通用牌库被摸空，将弃牌堆洗混重新构成新牌库。游戏不因牌库耗尽而结束 |

## 第十一章：FAQ

**Q：一回合能出几张牌？**
A：受**手牌数量**和**独特标签**两个限制。手牌最多 5 张，独特最多 1 张，快速不受限制。

**Q：独特行动是什么？**
A：带"独特"标签的行动（犯罪、布控、逮捕、出击、爆料等），本回合最多执行 1 次。独特行动通常是大行动——做了一件就不能再做另一件。

**Q：快速牌和普通牌有什么区别？**
A：普通牌每回合可以出任意张。快速牌也每回合可以出任意张，但快速牌不占用独特名额——做了独特行动后仍然可以使用快速牌。

**Q：情报怎么获得？**
A：主要途径：踩点（+1 情报）、调查（+1 情报，有证据再+1）、密谋（+2 情报并摸 1 张）、紧急部署（+1 情报·快速）。

**Q：情报有什么用？**
A：情报是通用经济资源：

- 罪犯：犯罪成本、越狱成本
- 警长：布控成本（1 情报）、推进嫌疑链（3 情报/级）、搜查（1 情报）

**Q：证据是什么？**
A：罪犯犯罪后在地点放置的黄色 Token。警长黎明结算时收集，用于推进嫌疑链。证据是连接罪犯行动和警长调查的核心资源。

**Q：假证据怎么区分？**
A：假证据与真证据**完全相同颜色和尺寸**，正面无法区分。警长黎明结算收集时需翻面验证——背面有"X"标记的即为假证据，无效（不产生线索）。

**Q：没有 Token 系统了，怎么限制一回合的行动次数？**
A：通过**手牌上限（5 张）**和**独特标签（最多 1 张）**共同限制。手牌只有 5 张，一回合最多出 5 张；独特标签保证不能在一回合内做两件"大事"。

**Q：越狱必须要有金蝉脱壳吗？**
A：不需要。越狱是阵营技能，基础版本消耗 3 情报 + 弃 1 张手牌，永远可用。金蝉脱壳可以大幅降低消耗（1 金蝉脱壳 + 1 情报）。

**Q：警长怎么推进嫌疑链？**
A：在黎明结算阶段，消耗 3 情报推进 1 级（每夜最多 2 级）。4 级时该罪犯可逮捕。李敏技能：2 情报/级。

**Q：警长在罪犯不犯罪时能做什么？**
A：警长可以使用"搜查"行动（出牌阶段·独特·1 情报）主动调查地点，即使无证据也能获得 1 情报。这确保警长不依赖罪犯行动来推进自己的游戏。

**Q：牌库摸完了怎么办？**
A：将弃牌堆洗混重新构成新牌库，继续游戏。

**Q：恐慌值对游戏有什么影响？**
A：恐慌值 ≥10 时城市崩溃，直接终局按分数排名。恐慌值 ≥6 时触发超英"堕落路线"。恐慌值通过恐慌共鸣为受害者提供额外影响力。
