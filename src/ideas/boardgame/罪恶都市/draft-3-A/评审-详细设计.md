# 方案 3A · 详细设计评价（v1）

> 评审对象：06-配件清单、07-卡牌设计、08-规则书、09-平衡性分析
> 评审维度：完整性、一致性、可玩性、可打印性、平衡性

---

## 总体评价

方案 A 的详细设计整体非常完整，四个文档相互衔接、逻辑自洽。Token 行动力系统、嫌疑链系统、双面 Token 交互机制等核心设计有创意且落地扎实。平衡性分析展现了深度的量化思考。

以下评审基于 Token 闭环逻辑：罪犯线索 Token（A面🟡）→ 消耗出牌翻至 B面🔴物证 → 置入地点 → 警长黎明收集翻回 A面🟡。线索是统一资源在不同玩家/地点间流转。

---

## 一、规则书表述优化（非机制问题）

### 1.1 警长 Token 使用方式的描述需明确 🟢

**问题**：规则书第四章说"每打出一张手牌，必须消耗对应数量的 token"，但警长的操作存在两种方式：

| 操作 | Token 消耗 | 说明 |
|------|-----------|------|
| 出通用牌（调查/踩点等） | 消耗 1 行动力 token | 与其他阵营一致 |
| 执行警长专属行动（布控/部署/逮捕） | 消耗行动力 | 不消耗手牌 |

这不是机制问题——警长的行动力 token 本就可以同时驱动出牌和专属行动。但规则书仅在第四章写了"出牌消耗 token"的描述，对警长的两种操作方式没有明确说明。

**建议**：在规则书第七章（警长行动消耗表）前增加一段说明：

> 警长的行动力 token 与罪犯的线索 token 使用方式一致：消耗行动力出牌（调查/踩点等）消耗 1 行动力；执行警长专属行动（布控/部署/逮捕）同样消耗行动力。警长在出牌阶段可自由分配行动力于出牌和专属行动之间。

---

### 1.2 建议增加"线索资源流转总览" 🟢

**问题**：线索在"罪犯→地点→警长"间的流转逻辑是清晰的，但规则书中缺少一处集中说明。目前线索规则分散在：

- 第四章：Token 消耗规则（罪犯消耗线索出牌）
- 第四章 Token 交互逻辑（罪犯消耗→放地点→警长收集）
- 第八章 8.1（警长调查收集线索）
- 第七章（警长推进嫌疑链消耗线索）

**建议**：在规则书中增加一个"线索流转速查"框图：

```
           ┌──────────────────────────────────────────┐
           │           线索资源流转闭环                │
           │                                          │
           │  ①罪犯消耗 Token 出牌 → B面🔴放到地点    │
           │                          ↓               │
           │  ②警长黎明收集 B面🔴 → 翻回 A面🟡       │
           │                          ↓               │
           │  ③警长用 3 线索推进 1 级嫌疑链           │
           │    或用调查牌直接生产线索（1行动力）      │
           │                          ↓               │
           │  ④罪犯每回合补至 3 Token（A面🟡）       │
           └──────────────────────────────────────────┘

         ◉ 线索标记的持有者即使用者
         ◉ 罪犯手中的线索 Token（A面🟡）= 行动力
         ◉ 地点上的线索（B面🔴）= 物证，警长专属可收集
         ◉ 调查牌产出的线索 = 直接加入持有者的线索池
```

## 二、规则书逻辑完善（建议补充）

### 2.1 事件牌翻开的时机需澄清 🟢

**问题**：目前两处描述不一致：

- 第三章流程："第一位玩家翻开事件牌"——暗示在警长回合内
- FAQ："每夜第一位玩家的回合开始阶段翻开"——更精确

**建议**：统一为"每夜开始前翻开事件牌，效力覆盖整夜"。

---

### 2.2 "空过"规则缺失 🟢

规则书没有明确说明：如果玩家不想出牌或无法出牌，是否可以空过整个出牌阶段。

**建议**：增加：出牌阶段可以主动跳过（空过），直接进入弃牌阶段。

---

### 2.3 "不出牌使用角色能力"缺乏规则支持 🟢

平衡性分析中提到"不出牌使用角色能力"作为缓解"起手无踩点"的机制，但规则书中没有任何关于"不出牌使用技能"的规则说明。

**建议**：在规则书第五章增加说明：部分角色技能可以在不出牌的情况下消耗 token 直接触发（明确定义哪些技能适用）。

---

### 2.4 "赊账"规则的执行细节不完整 🟢

规则书 10.3 说"每夜最多赊 1 情报（暴露度+2 代替 1 情报）"，但缺乏：

- 赊账的时机：出牌阶段任意时刻？犯罪执行时？
- 赊账的偿还：需要后续回合偿还还是永久性暴露度增加？
- 被逮捕后赊账的暴露度如何处理？

## 三、平衡性问题（需关注）

### 3.1 地点牌随机组合的极端情况 🟡

16 张地点牌中随机抽取 10 张，可能存在极端组合：

| 极端情况 | 概率 | 影响 |
|---------|------|------|
| 抽到 6+ 高警戒值（≥2）的地点 | 中等 | 罪犯情报消耗大幅增加，发育节奏被打断 |
| 抽到 5+ 低警戒值（0）的地点 | 中等 | 罪犯行动成本极低，警长难以压制 |
| 未抽到高收益（★★★★）地点 | 较低 | 所有角色得分速度下降，游戏时间拉长 |

**建议**：增加地点牌分组机制，确保每局至少包含：2 张高警戒值 + 2 张低警戒值 + 2 张高收益地点，其余随机。

---

### 3.2 虚拟罪犯在 2 人局中过于简单 🟢

2 人局（1 警长 + 1 罪犯）时，虚拟罪犯的"每夜随机地点放 1 线索，每 2 夜犯罪 1 次"机制过于简单。

**建议**：为 2 人局增加虚拟罪犯行为规则丰富度（如优先级选择高收益地点、转移行为等）。

---

### 3.3 暗影侠堕落后可能过强 🟢

堕落后的暗影侠每回合用惩戒（暴露+3）+审判（关押 1 回合），压制力甚至超过警长。

**建议**：测试中重点关注堕落路线的强度。

## 四、可打印性建议

### 4.1 双面 Token 的 PnP 替代方案 🟢

提供替代方案：

- **打印版**：单面 Token + 小图标标记（用小贴纸标识 A/B 面）
- **卡牌版**：Token 的消耗过程改为使用小卡牌代替（类似"已消耗"指示牌）

### 4.2 角色卡双面打印对齐问题 🟢

提供两种规格：双面印刷版（需精确对齐）和分页版（正面卡+反面速查卡两张）

## 五、概念设计阶段的遗留问题

### 5.1 同地点竞争规则（10.2）的合理性 🟢

规则书说"多名罪犯同一地点犯罪 → 暴露度各+1"。但缺乏说明：

- 判断时机（同一夜同时犯罪？先后犯罪？）
- 犯罪后留下的线索是否对其他罪犯可见
- 如果其他罪犯在同一地点犯罪，是否共享线索 token

## 六、补充发现的规则书缺失点

### 6.1 线索 Token 的上限规则未明确 🟢

规则书说每回合补充"补至上限"，但：

- 罪犯使用「调查」牌额外获得 1 线索标记后，是否受 Token 上限（3个）约束？
- 获得的额外线索标记是保留在玩家面板上，还是自动进入公共池？

**建议**：明确"调查牌产出的线索标记不受 Token 上限限制，可作为额外资源储备"。

### 6.2 罪犯"犯罪"行动的 Token 消耗与情报消耗应区分说明 🟢

罪犯执行"犯罪"核心行动时需同时消耗两种资源：

- 出「踩点」牌消耗 1 Token（行动次数）
- 情报消耗（盗窃 2、抢劫 2 等经济成本）

规则书 9.3 的执行示例：

```
出踩点牌(1 token + 改为犯罪核心行动) → 基础消耗2情报
```

**建议**：规则书应补充说明"情报和 Token 是两种独立资源——Token 代表行动次数，情报代表经济成本"，以免新手混淆。

### 6.3 各阵营得分来源总表缺失 🟢

规则书有警长逮捕得分、罪犯犯罪得分、超英声望兑换、受害者爆料得分等，但缺少一张各阵营得分来源一览表。

**建议**：在规则书新增一节：

| 阵营 | 得分方式 | 单次得分 | 说明 |
|------|---------|---------|------|
| **警长** | 逮捕罪犯 | +2 分（方振华+3） | 暴露≥5或嫌疑链4级 |
| | 关押中得分 | 每关押 1 回合+1 分 | 最多 2 回合 |
| | 治安值≥8 | +1 分/夜 | 黎明结算时检查 |
| **罪犯** | 犯罪 | 1-3 分（类型不同） | 消耗情报+Token |
| | 赃物兑换 | 3 赃物=1 分 | 任何时候 |
| **超英** | 阻止犯罪 | +1 分/次 | 消耗声望出击 |
| | 声望兑换 | 2 声望=1 分 | 任何时候 |
| **受害者** | 爆料 | +1 分/次 | 消耗影响力 |
| | 媒体风暴 | +2 分/局 | 限 1 次 |
| | 终局奖励 | +5 分 | 治安值≤3 |
