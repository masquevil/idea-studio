# 方案 A · 原始点子

> 核心方向：以 user-ideas-2-B.md 为准，参考 ref-draft-2-B.md 设计思路

---

## 一句话概念（30 字以内）

> **纯卡牌驱动 · 通用牌库 + 角色能力差异化 · 资源管理替代概率 · 警匪非对称跑分**

---

## 核心卖点（5 个关键词）

| 关键词 | 说明 |
|--------|------|
| **全卡牌驱动** | 没有棋盘棋子移动，所有行动通过卡牌执行，城市由地点牌构成 |
| **通用牌库·角色差异** | 所有玩家共用同一牌库，牌的效果固定不变。差异化来自角色技能——阵营技能（1-2条通用）+ 专属技能（1-2条个人风格） |
| **0 概率策略** | 犯罪不再靠骰子判定，改用资源消耗（情报标记）作为确定性成本 |
| **关押不淘汰** | 被捕罪犯关押 1-2 回合而非出局，全员全程参与 |
| **跑分制** | 不再有专属胜利直接结束，改为向目标分数冲刺的公平竞争 |

## 目标体验（玩家玩完后的感受）

### 🕵️ 警长

- "作为先手，我先布控再等待罪犯行动——看他们一步步掉入陷阱的感觉很爽"
- "不是被动等罪犯犯罪，而是主动布控施压——嫌疑链推进到最后逮捕的感觉很有成就感"
- "但资源有限（行动力受恐慌值影响），每个决定都捉襟见肘"

### 🦹 罪犯

- "警长先布控，我后手选择在哪里犯罪——能看到他的部署再决定是否冒险"
- "每次犯罪前都要算情报够不够、暴露度会不会太高、警长的布控会不会让我暴露……"
- "被抓了也不怕，还能越狱东山再起"

### 🦸 超级英雄（5 人或以上）

- "第三方的平衡感——既要阻止犯罪抢功劳，又不能过分偏袒一方"
- "声望累积到顶点时出击的爽感"

### 👥 受害者联盟（5 人或以上）

- "政府靠不住、英雄在作秀——不如自己上街游行"
- "恐慌值越高，我的影响力越大——城市的混乱就是我的养分"

### 总体感受

- **紧张感**：每次出牌都能感受到对手的压力
- **策略深度**：资源规划 > 运气赌博，每一步都有明确的因果
- **参与度**：没有人会提前出局旁观，被捕只是暂时的挫折
- **重玩性**：随机地点牌 + 事件牌让每局城市布局和节奏都不同
- **轻中策门槛**：虽然有多层次策略，但通用牌库"一张牌只有一个效果"的设计让新手容易上手

## 与方案方向说明的关联

| 方案方向要点 | 本方案的体现 |
|-------------|-------------|
| 警匪非对称对抗 | ✓ 警长1人 vs 罪犯1-4人，资源体系和玩法完全不同 |
| 围绕城市地点展开行动 | ✓ 地点牌构成城市版图，行动需指定目标地点 |
| 卡牌驱动 | ✓ 纯卡牌驱动，无棋盘棋子移动 |
| 轻中策桌游 | ✓ 通用牌库降低学习成本，资源管理提供策略深度 |
| 多阵营各自为战 | ✓ 警长/罪犯/超英/受害者联盟各有独立的资源和胜利条件 |
| 通用牌库统一化 | ✓ 继承 draft-2-B 的核心原则——每张牌只有一个效果 |
| 资源管理替代概率 | ✓ 犯罪成本制（无骰子判定） |
| 关押不淘汰 | ✓ 保留玩家参与感，无人提前出局 |
| 跑分制 | ✓ 目标分数到达即结束，清晰公平 |
| 标准回合制 | ✓ 警长先手→顺时针轮流 |
| 牌的效果固定，技能选择性修改 | ✓ 通用牌牌面文字对所有玩家完全一致，角色技能选择性覆盖 |
| 无阵营专属牌 | ✓ 所有牌通用，G-02/G-06 等专属牌已全部取消，功能由角色技能实现 |
| 牌库规模充足 | ✓ 约 95 张，基础牌占 84%（踩点×30 / 调查×25 / 转移×15 / 潜伏×10） |
| 两层技能结构 | ✓ 每个角色 = 阵营技能（1-2条共享）+ 专属技能（1-2条区分风格） |
| 多角色选择 | ✓ 同一身份下多个可玩角色（警长方振华/李敏，罪犯幽灵/狐狸/老鼠/公牛/蛇） |
