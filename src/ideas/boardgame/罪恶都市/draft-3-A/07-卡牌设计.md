# 方案 3A · 卡牌详细设计

> 基于 02-核心机制.md 和 06-配件清单.md 的卡牌规格。

## 1. 通用牌设计

### 1.1 牌面模板

```
┌─────────────────────┐
│                     │
│   [牌名]    [类型]   │
│                     │
│   (背景插画区域)     │
│                     │
│   [牌面效果文字]     │
│                     │
│     [数量]          │
│   "罪恶都市"         │
└─────────────────────┘
```

- **尺寸**：63×88mm（标准卡牌尺寸）
- **牌背**：统一图案——城市夜景剪影 + 底部"罪恶都市"字样
- **边框颜色**：基础牌蓝色边框，特殊牌紫色边框（与 02-核心机制.md 一致）

### 1.2 基础牌（🟦 蓝色边框）

#### 🟦 踩点 · ×30

| 项目 | 内容 |
|------|------|
| **牌名** | 踩点 |
| **类型标识** | 🟦 行动 |
| **牌面效果** | 获得 1 情报 |
| **背景插画** | 一个戴着帽子的黑影在巷口观察建筑（俯视/侧影） |
| **边框** | 蓝色 |
| **可用性** | 所有角色通用；罪犯可通过技能"犯罪"修改为一次犯罪行动 |

**成本与收益**：

- 无消耗
- 收益：1 情报
- 游戏中最低级别的经济牌，通过量大（30张）确保玩家不会缺情报

#### 🟦 调查 · ×25

| 项目 | 内容 |
|------|------|
| **牌名** | 调查 |
| **类型标识** | 🟦 信息 |
| **牌面效果** | 获得 1 线索 |
| **背景插画** | 放大镜在报纸/地图上扫描 |
| **边框** | 蓝色 |
| **可用性** | 所有角色通用；警长可通过技能"部署权"修改为布控行动 |

**成本与收益**：

- 无消耗
- 收益：1 线索
- 线索是为全局服务（警长）还是为自己服务（罪犯看警长动向），取决于出牌者
- 李敏技能"数据链"可翻倍此牌效果

#### 🟦 转移 · ×15

|------|------|
| **牌名** | 转移 |
| **类型标识** | 🟦 移动 |

| **背景插画** | 车辆/人在地图路线上的移动轨迹 |
| **边框** | 蓝色 |
| **可用性** | 所有角色通用；老鼠技能"安全通道"可跨区域使用 |

**成本与收益**：

- 无消耗
- 收益：将你的行动目标从当前地点改为另一个地点
- 跨区域移动需消耗 2 张转移牌
- 剧院的地牌效果可使转移不消耗手牌（变相免费移动）

- 收益：暴露度-1 + 免疫 1 次逮捕

- 收益：逃脱关押或其他针对效果

#### 🟪 孤注一掷 · ×2

| 项目 | 内容 |
|------|------|
| **牌名** | 孤注一掷 |
| **类型标识** | 🟪 逆转 |
| **牌面效果** | 弃所有手牌，每弃 1 张获得 1 分 |
| **背景插画** | 一个人站在悬崖边，身后是烈火 |
| **边框** | 紫色 |
| **可用性** | 所有角色通用。仅 2 张，极度稀有。 |

**成本与收益**：

- 消耗：全部手牌
- 收益：弃牌数 = 得分
- 使用时机判断：此时手牌数越多收益越高，典型"孤注一掷"机制
- 设计意图：给落后玩家一个翻盘机会，但弃光手牌也意味着后续回合缺乏行动力

```
┌─────────────────────────────┐
│                             │
│  [角色名]     [阵营图标]    │
│  [称号/身份]               │
│                             │
│  (角色半身肖像插画)        │
│                             │
│  ┌─── 阵营技能 ─────────┐  │
│  │ · 技能名：效果         │  │
│  │ · 技能名：效果         │  │
│  └────────────────────────┘  │
│  ┌─── 专属技能 ─────────┐  │
│  │ · 技能名：效果         │  │
│  │ · 技能名：效果(可选)   │  │

│                             │
│       [阵营] [玩家名]       │
```

- **尺寸**：63×88mm（与通用牌相同尺寸）
- **正面**：全彩角色插画 + 技能列表
- **反面**：阵营速查（该阵营所有通用规则+得分方式）

## 3. 地点牌设计

### 3.1 地点牌模板

```
┌─────────────────────┐
│                     │
│  [区域图标] [名称]  │
│                     │
│  (建筑俯视轮廓)     │
│                     │
│  警戒值：[数字]     │
│  收益：[★★★★]     │
│                     │
│  [特殊效果文字]     │
│                     │
│  编号：[L-XX]       │
└─────────────────────┘
```

- **尺寸**：63×88mm（与通用牌相同）
- **边框**：地点牌边框颜色根据区域区分：
  - 🌆 上城区：金色边框
  - 🏙️ 市中心：银色边框
  - 🏚️ 下城区：灰色边框
  - 🌿 边缘区：绿色边框

警官牌不是牌库中的手牌，而是警长的专属配件：

|------|------|------|---------|

- 部署警官消耗行动力（巡警 1 点，特警 2 点），在行动阶段执行

## 8. 卡牌设计补充说明

### 8.1 文字排版规范

- **牌名**：加粗无衬线字体，字号 12pt
- **类型标识**：[🟦/🟪] + [行动/信息/移动/防御/经济/逃脱/逆转]
- **效果文字**：衬线字体，字号 10pt，单行不超过 20 字
- **编号**：字号 8pt，底部右侧
- **留白**：牌面至少 30% 留白区域，确保文字可读性

### 8.2 颜色编码系统

| 元素 | 颜色 | 用途 |
|------|------|------|
| 🔵 蓝色 | #2B6CB0 | 基础牌边框 |
| 🟣 紫色 | #805AD5 | 特殊牌边框 |
| 🟡 金色 | #D69E2E | 上城区地点牌边框 |
| ⚪ 银色 | #A0AEC0 | 市中心地点牌边框 |
| ⚫ 灰色 | #718096 | 下城区地点牌边框 |
| 🟢 绿色 | #38A169 | 边缘区地点牌边框 |
| 🌑 深紫 | #553C9A | 事件牌边框 |
| ⬛ 黑色 | #1A202C | 牌背底色 |

### 8.3 无障碍设计考量

- 所有颜色编码同时配有符号（🟦🟪🌆🏙️🏚️🌿等），色盲玩家可识别
- 文字与背景的对比度 ≥ 4.5:1
- 字体选择清晰易读，避免手写体或装饰性字体

### 8.4 PnP 说明

- 所有卡牌推荐使用 63×88mm 标准卡套
- 打印尺寸：A4 纸打印后裁剪，每张 A4 可容纳 8 张卡牌（3×3 排列减一行）
- 建议使用 200g 或以上卡纸
- 角色卡建议双面打印（正面角色+反面阵营速查）
