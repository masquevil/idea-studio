# 方案 3A · 卡牌详细设计（v2 · 无 Token 版）

> 基于 2r 阶段全面重构——引入卡牌标签系统（普通/独特/快速）。
> 所有卡牌采用统一模板：名称 + 标签 + 牌面效果（一行文字）+ 背景插画。

---

## 1. 标签系统

所有卡牌带有一个**标签**，定义该牌的行动限制：

| 标签 | 图标 | 含义 | 效果 |
|------|------|------|------|
| **普通** | — | 标准行动 | 每回合可出任意张 |
| **🏷️ 独特** | 🏷️ | 大行动 | 本回合最多出 **1 张** 带独特的牌 |
| **🏷️ 快速** | ⚡ | 反应行动 | 不受独特限制，可在任何时机使用 |

> 参考来源：炉石传说关键词系统 + 诡镇奇谈闪电行动。

## 3. 角色卡设计

### 3.1 角色卡模板

```
┌─────────────────────────────┐
│                             │
│  [角色名]     [阵营图标]    │
│  [称号/身份]               │
│                             │
│  (角色半身肖像插画)        │
│                             │
│  🏷 阵营技能（通用）        │
│  · [技能名]：效果（独特/被动）│
│  · [技能名]：效果（独特/被动）│
│                             │
│  🏷 专属技能（独有）        │
│  · [技能名]：效果           │
│  · [技能名]：效果（可选）   │
│                             │
│       [阵营] [玩家名]       │
└─────────────────────────────┘
```

- **尺寸**：63×88mm（与通用牌相同）
- **正面**：全彩角色插画 + 技能列表
- **反面**：阵营速查（该阵营所有通用规则 + 得分方式）
- **PnP 建议**：采用**分页版**——正面技能页与反面阵营速查页分开为两张卡纸，玩家裁切后套入透明牌套，避免双面对齐难度

## 4. 地点牌设计

（详见 [06-配件清单.md](./06-配件清单.md) 1.3 节——16 张地点牌数据同配件清单，此处不再重复）

**地点牌核心规则**：

| 要素 | 说明 |
|------|------|
| **警戒值** | 该地点的基础安保级别。犯罪成本 += 警戒值 |
| **收益星级** | 犯罪成功后的额外奖励。★/★★/★★★/★★★★ |
| **特殊效果** | 该地点的独特规则，如"抢劫收益+1""犯罪成本-1" |
| **无角色位置** | 罪犯/警长不在版图上移动。犯罪时直接**声明目标地点** |
| **证据交互** | 犯罪后在该地点放 1 个证据 Token；警长黎明结算收集 |
