# 罪恶都市 · 方案 B · 核心机制设计

> 方案 B：参考 refs/initial-gpt.md + refs/user-ideas-2-B.md

---

## 游戏概览

- **类型**：纯卡牌驱动的非对称对抗桌游
- **人数**：2-5 人（基准 4 人：1 警长 + 3 罪犯）
- **时长**：60-90 分钟（4 人局）
- **回合**：10 个回合（10 个夜晚）
- **目标**：跑分制——率先达到目标分数（15-20 分）的城市获胜方

---

## 核心游戏循环

每个夜晚分为 5 个阶段：

```
准备阶段 → 宣告阶段 → 揭露阶段 → 调查阶段 → 结算阶段
```

### ① 准备阶段

- 翻开 1 张**事件牌**，影响本回合全局效果
- 所有玩家摸牌至手牌上限（默认 5 张）

### ② 宣告阶段（核心博弈）

**这是方案 B 最核心的博弈环节。** 所有玩家秘密选择：

1. **目标地点**：从中央展示区的地名牌中选择一个作为行动地点
2. **行动牌**：从手牌中打出一张行动牌（面朝下）
3. **角色技能**：可选择是否发动角色技能（部分技能消耗特定资源）

宣告规则：

- 所有玩家同时秘密选择，完成后同时揭露
- 揭露顺序：**当前分数最低的玩家先揭露**（平衡机制，给落后玩家先手优势）
- 同分时按逆时针顺序

### ③ 揭露阶段

按揭露顺序依次结算每位玩家的行动：

**罪犯行动结算**（基于成本机制，无概率）：

1. 检查目标地点是否有警长部署的警官牌
2. 如有警官牌 → 犯罪成本增加（+1~+2 情报标记）
3. 计算犯罪所需总成本（基础成本 + 警官加成 - 技能减免）
4. 罪犯选择支付成本（情报标记）——资源不足可用暴露度抵冲（暴露度加倍上升）
5. 支付完成 → 犯罪成功，获得赃物/分数
6. 犯罪成功后在地名牌上放置对应线索 token
7. 暴露度上升（视犯罪类型）

**警长行动结算**：

1. 可执行"巡逻"（布控指定地点）/ "任命"（部署警官牌）/ "调查"（推进嫌疑链）
2. 部分行动即时生效影响罪犯结算

**超级英雄/受害者联盟行动结算**：

- 超级英雄：可"出击"（阻止犯罪，罪犯损失已投入资源）或"私刑"（夺取罪犯资源）
- 受害者联盟：可"舆论"（影响民意）或"游行"（降低警长权威）

### ④ 调查阶段（警长专属）

- 警长根据已收集的线索 token 推进**嫌疑链**
- 可消耗线索 token **推进某罪犯的嫌疑等级**——等级越高，该罪犯犯罪成本越高、收益越低
- 嫌疑链达到 5 级时，警长可直接发起"逮捕"（无需概率判定）
- 被逮捕的罪犯进入**关押状态**（1-2 回合不能行动），警长每回合获得分数

### ⑤ 结算阶段

更新城市状态：

| 状态值 | 初始 | 变化条件 | 影响 |
|--------|------|----------|------|
| **治安值** | 10 | 犯罪成功↓，关押罪犯↑ | 归零触发负面事件 |
| **民意值** | 5 | 逮捕成功↑，误抓↓，受害者游行↓ | 影响警长每回合行动次数 |
| **恐慌值** | 0 | 重罪↑，私刑↑，复仇↑ | 每 3 点触发负面事件 |

## 胜利条件（跑分制）

**核心原则**：整体为跑分游戏，率先达到目标分数（15-20 分）立即结束。得分行为门槛较高，对手可通过限制资源间接干预。

### 各阵营得分方式

| 阵营 | 得分行为 | 每次数值 | 说明 |
|------|----------|---------|------|
| **警长** | 关押罪犯 | +1 分/回合 | 罪犯被关押期间每回合自动+1 |
| **警长** | 逮捕 | +2 分（一次性） | 成功逮捕时获得 |
| **罪犯** | 成功犯罪 | +1~+2 分 | 需消耗情报标记，视犯罪类型 |
| **罪犯** | 高收益犯罪 | +3 分 | 需额外投入资源（如银行抢劫+3情报） |
| **超级英雄** | 阻止犯罪 | +1 分 | 消耗行动力 |
| **超级英雄** | 媒体宣传 | +1 分（累计声望） | 声望值≥10 时额外奖励 |
| **受害者联盟** | 成功游行 | +1 分 | 消耗影响力 |
| **受害者联盟** | 复仇 | +2 分 | 消耗 3 影响力 |

### 游戏结束条件

```
任何玩家达到目标分数（15-20 分）→ 游戏立即结束
  │
  ├─ 警长分数最高 → 警长胜利（秩序维护）
  ├─ 罪犯中有人分数最高 → 该罪犯胜利（犯罪帝王）
  ├─ 超级英雄分数最高 → 城市英雄胜利
  └─ 受害者联盟分数最高 → 民粹胜利
```

### 兜底规则

第 10 夜结束时若无人达到目标分数：

- 治安值 ≥ 8 → 警长胜利（治安重建）
- 治安值 4-7 → 按分数比较，最高者胜
- 治安值 ≤ 3 → 罪犯中分数最高者胜（城市崩溃）

### 罪犯内部关系：表面合作，暗中竞争

- 罪犯之间可以互相配合（如共同攻击同一地点），但最终只有分数最高的罪犯能获胜
- 被捕（关押）的罪犯分数不会清零，但关押期间无法得分

## 基本规则框架

### 犯罪成本机制（取代概率）

犯罪行动**没有概率判定**，改为消耗**情报标记**作为"策划成本"：

| 犯罪类型 | 基础成本 | 基础收益 | 暴露度增加 |
|----------|---------|---------|-----------|
| 盗窃 | 1 情报 | 1 赃物 + 1 分 | +1 |
| 抢劫 | 2 情报 | 2 赃物 + 2 分 | +2 |
| 行凶（杀人） | 3 情报 | 3 分 | +3 |
| 诈骗 | 1 情报 | 1 分 + 1 假线索 | +0~+1 |
| 贩毒 | 2 情报 | 2 赃物 + 1 分 | +1~+2 |

**成本调整因素**：

| 因素 | 成本变化 | 说明 |
|------|---------|------|
| 巡警在场 | +1 情报 | 该地点有巡警部署 |
| 特警在场 | +2 情报 | 该地点有特警部署 |
| 地点警戒值 Lv.2 | +1 情报 | 警戒值影响 |
| 地点警戒值 Lv.3 | +2 情报 | 高度戒严 |
| 罪犯嫌疑链 Lv.3+ | +1 情报 | 警长调查压力 |
| 投入额外情报 | 每 +1 情报 = 额外 +1 收益 | 自愿加码，上限视犯罪类型 |

**资源不足时的"赊账"机制**：

- 罪犯情报标记不足时，可用暴露度抵冲（1 暴露度 = 1 情报）
- 但暴露度上升加倍（赊账 1 情报 → 暴露度 +2）
- 暴露度 ≥ 5 时，警长可直接发起逮捕（无需嫌疑链 5 级）

### 通用牌库构成

方案 B 所有玩家共用同一牌库，共约 60-80 张牌：

| 卡牌类别 | 占比 | 示例 | 说明 |
|----------|------|------|------|
| **行动牌** | 30% | 潜入、策应、干扰、追查、封锁 | 驱动核心行动 |
| **资源牌** | 20% | 情报、赃物、工具、路线图 | 提供资源或增益 |
| **干扰牌** | 15% | 假线索、诬告、贿赂、威胁 | 干扰对手 |
| **警官牌** | 15% | 巡警、特警、刑警、卧底、网警 | 警长部署，罪犯也可用于伪装 |
| **NPC 牌** | 10% | 线人、黑市商人、记者、律师 | 一次性效果，打出弃置 |
| **事件牌** | 10% | 暴雨、节日、停电、暴动 | 准备阶段翻开，影响全局 |

### 卡牌公共效果 + 人物技能附加

**核心原则**：所有卡牌对所有人效果相同或接近。差异来自**人物技能**附加的额外效果。

例如，"**策应**"这张牌，所有人打出时都是"本回合在目标地点获得 +1 资源/效果"。但：

- 警长的技能可让"策应"额外提升警戒值
- 罪犯的技能可让"策应"额外降低暴露度
- 超级英雄的技能可让"策应"额外获得声望

| 卡牌示例 | 公共效果 | 技能附加示例（非固定，由角色板定义） |
|----------|----------|------------------------------------|
| **策应** | 目标地点效果 +1 | 警长：+1 警戒值；罪犯：-1 暴露 |
| **潜入** | 获得 1 情报标记 | 罪犯：犯罪成本 -1；英雄：可检视目标 |
| **干扰** | 目标地点警戒值 +1 | 罪犯：目标地点警官效果减半 |
| **追查** | 获得 1 线索 token | 警长：该线索可推进嫌疑链 |
| **封锁** | 目标地点本回合无人可行动 | 警长：持续 2 回合；英雄：仅限英雄自己 |

### 地点系统

- **牌池**：共 20+ 张地点牌，每局随机抽取 12 张
- **布局**：抽出的 12 张地点牌按 3×4 排列在桌面中央
- **每张地点牌包含**：
  - 地点名称与图标
  - 警戒值（0-3，犯罪后可升级）
  - 收益值（犯罪成功可获得的赃物/分数）
  - 特殊效果（如"银行：抢劫收益+1"、"贫民区：暴露度-1"）
  - 线索类型（如"监控录像"、"目击证人"、"IP 地址"）

### 嫌疑链系统（取代"概率线索"）

警长通过消耗线索 token 推进对某个罪犯的嫌疑等级。嫌疑链不提供信息（信息公开），而是**通过施加压力间接限制罪犯**：

| 嫌疑等级 | 需要累积线索 | 对罪犯的影响 |
|----------|------------|-------------|
| 1 级 | 1 个 | —（开始关注，无实质影响） |
| 2 级 | 2 个 | 该罪犯犯罪成本 +1 情报 |
| 3 级 | 3 个 | 该罪犯犯罪成本 +1 情报，收益 -1 |
| 4 级 | 4 个 | 该罪犯犯罪成本 +2 情报，收益 -1 |
| 5 级 | 5 个 | 可直接发起逮捕（关押 1-2 回合） |

**线索 type 与地点的对应关系**：

| 地点 | 可能留下的线索类型 |
|------|-------------------|
| 银行 | 监控录像、指纹 |
| 商业街 | 目击证人、消费记录 |
| 贫民区 | 目击证人、残留物证 |
| 港口 | 走私痕迹、交易记录 |
| 网络中心 | IP 地址、网络痕迹 |
| 大学 | 出入记录、物证 |
| 住宅区 | 指纹、邻居证词 |

### 罪犯发育链条

```
踩点（消耗行动力）
  ↓ 获得 1 情报标记 + 在地名牌放置踩点标记
积累（收集情报标记 / 赃物）
  ↓ 情报标记可用于支付犯罪成本
犯罪（在目标地点执行）
  ↓ 消耗情报标记，无需概率判定
收尾（销赃 / 洗钱 / 隐藏）
  ↓ 降低暴露度
继续下一轮发育
```

### 暴露度系统

每个罪犯有暴露度 0-5：

| 暴露度 | 效果 |
|--------|------|
| 0-1 | 低关注——警长需要更多线索才能推进嫌疑链 |
| 2-3 | 可追踪——警长推进嫌疑链成本减半（2 线索=1 级） |
| 4 | 高度暴露——警长推进嫌疑链成本再减半 |
| 5 | 完全暴露——警长可直接发起逮捕（无需嫌疑链 5 级） |

**暴露度变化**：

- 犯罪成功：+1~+3（视犯罪类型）
- 使用"隐藏"行动：-1~-2
- 越狱：+2
- 在特定地点活动：可降低（如贫民区 -1）

## 关押与越狱机制

### 逮捕（警长行动）

- **条件**：嫌疑链达到 5 级，或罪犯暴露度 ≥ 5
- **消耗**：2 行动力
- **效果**：目标罪犯进入**关押状态**
  - 关押持续 **1-2 回合**（由警长选择）
  - 关押期间罪犯**不能行动**（跳过回合）
  - 警长每回合从关押中获得 **+1 分**
- 逮捕失败的情况：警长线索不足或罪犯资源保护——逮捕被抵抗时，警长本回合不能再逮捕

### 越狱（罪犯行动）

- 被关押罪犯可以在自己的回合选择**越狱**
- **消耗**：2 情报标记 + 1 赃物标记（给守卫、破坏设施等）
- **效果**：立即解除关押状态，但暴露度 +2
- 越狱后本回合不能继续行动（已消耗整回合）
- 如果资源不足，可选择"**暴力越狱**"——不消耗资源但暴露度 +4

### 关押状态下的交互

- 其他罪犯可以**协助越狱**（支付部分资源），但会留下与该罪犯勾结的证据（暴露度+1）
- 超级英雄可**劫狱**（消耗 2 行动力，直接释放被关押罪犯，英雄声望 +1，警长不悦——恐慌值 +1）
- 受害者联盟可通过舆论**施压释放**（消耗 2 影响力，释放一名罪犯，民意值 -1）

## 游戏准备流程

1. **选择角色**：玩家公开选择角色（警长 1 人固定，罪犯从角色池中选择，角色公开）
2. **抽取地名牌**：从地点牌池随机抽取 12 张，3×4 排列在桌面中央
3. **设置虚拟罪犯**（2-3 人局）：按固定模式设置虚拟罪犯的初始线索
4. **分发起始手牌**：每位玩家摸 5 张
5. **设置状态值**：治安值 10，民意值 5，恐慌值 0；所有玩家分数从 0 开始
6. **确定起始玩家**：分数最低的玩家为起始玩家（首轮随机）

## 关键规则补充

### 行动顺序

- 揭露阶段按分数从低到高结算
- 同分按逆时针顺序
- 警长在调查阶段之前有优先行动权

### 手牌上限

- 默认手牌上限 5 张
- 超过上限时弃至 5 张（弃牌由玩家选择）
- 某些效果可暂时提升手牌上限

### 分数体系

- 所有玩家从 0 分开始
- 目标分数：15-20 分（具体值由设计师测试后确定）
- 得分行为详见胜利条件章节

### 10 回合结束处理

```
无人达到目标分数 → 结束判定：
  治安值 ≥ 8 → 警长胜利（治安重建）
  治安值 4-7 → 分数最高者胜
  治安值 ≤ 3 → 罪犯中分数最高者胜
```

### 禁止提前出局规则

- **任何行动都不能让玩家提前出局**
- 被逮捕的罪犯进入关押状态（1-2 回合不能行动）而非出局
- 关押结束后的罪犯继续游戏
- 超级英雄的"私刑"改为夺取资源而非击败玩家
- **所有玩家全程参与，无人旁观**

## 扩展方向预留

- **更多罪犯类型**：可增加黑客、走私犯、间谍等
- **城市扩展**：增加更多地点牌，形成不同城市主题
- **剧本模式**：预置特定地点组合和事件顺序，提供剧本体验
- **成就系统**：各角色有隐藏成就，达成可获得额外分数
