# 方案 2-A · 世界观与主题设定

> 纯卡牌驱动 · 德式轻策

## 背景故事

**「罪城夜话」**

罪恶之城「新港市」——一座光鲜与肮脏并存的海港城市。表面上是繁华的贸易中心，暗地里黑帮横行、政商勾结。市民们早已习惯了在罪恶的夹缝中求生。

警长办公室的灯彻夜未熄。新任警长决心整顿治安，他需要在每一个夜晚做出正确的判断——今晚去哪里？盯住谁？信任哪个线人？

而城市的暗处，各路罪犯正在策划自己的"大买卖"。他们知道，10 个夜晚足以改变一切——谁能在这 10 个夜晚中积累最多的资源、躲避最紧的追捕，谁就能成为这座城市的暗夜之王。

在这座城市中，每一个夜晚都可能发生新的故事。今晚的码头可能有交易，明晚的市政厅可能有阴谋。你手中的每一张卡牌，都是你在这个夜晚的选择。

## 城市设定

### 城市名称：新港市（New Port City）

一座虚构的现代都市，融合了旧金山、香港和哥谭市的视觉元素。

### 地点牌池（示例）

每局随机抽取 10-15 张构成版图。每张地点牌有持续生效的文字效果：

| 地点牌 | 效果 |
|-------|------|
| **警察局** | 警长以此为目标时，额外获得 1 线索 |
| **码头区** | 以此为目标的玩家获得赃物时 +1 |
| **市政厅** | 以此为目标的玩家可获得 1 情报 |
| **唐人街** | 以此为目标时，可多抽 1 张牌 |
| **商业街** | 以此为目标的玩家可额外打出 1 张 NPC 牌 |
| **工业区** | 以此为目标的罪犯可多获得 1 赃物 |
| **夜总会** | 以此为目标的玩家可查看牌库顶 2 张牌 |
| **废弃仓库** | 场景牌在此持续 +1 回合 |
| **医院** | 玩家以此为目标后，下回合可多抽 1 张牌 |
| **学校** | 以此为目标的玩家情报收益 +1 |
| **银行** | 以此为目标时，转化资源效率翻倍 |
| **港口** | 以此为目标的玩家可额外弃 1 牌重抽 |
| **贫民窟** | 罪犯以此为目标时隐藏效果更好 |
| **法院** | 警长以此为目标时线索收益 +2 |
| **地下酒吧** | 所有玩家以此为目标时可额外出 1 张牌 |

> 地点牌池建议 20-25 张，每局随机抽取 10-15 张，确保重开性。

## 美术风格方向

### 整体风格

**黑色电影（Film Noir）+ 现代都市漫画**风格。

### 参考关键词

| 元素 | 方向 |
|------|------|
| **色调** | 暗色调为主，霓虹灯点缀（紫、蓝、红），夜晚/黄昏场景 |
| **构图** | 高对比度光影、硬朗线条、倾斜构图 |
| **角色设计** | 剪影风格为主，突出阵营特征色——警长用蓝色系，罪犯用红色/紫色系 |
| **地点牌** | 正面为地点插画 + 文字描述区，简洁突出功能性 |
| **行动牌** | 上方为图标（行动类型），下方为效果文本 |
| **NPC 牌** | 人物肖像插画 + NPC 名称 + 双栏效果（警长/罪犯不同效果） |
| **事件牌** | 全幅插画 + 标题 + 全局效果文字 |
| **卡背** | 统一的"城市剪影"图案，阵营色边框区分 |

### 卡牌设计参考

- 卡牌尺寸：标准扑克牌尺寸（63×88mm）
- 卡背统一设计，正面布局清晰文本易读

## 主题与机制的契合度说明

| 主题元素 | 机制体现 | 契合度分析 |
|---------|---------|-----------|
| **每个夜晚都是新的行动** | 每回合出牌指定目标 | 契合：玩家每晚决定"今晚去哪、做什么" |
| **警长追查罪犯** | 警长卡牌以获取线索、追踪罪犯为主 | 契合：需要在有限回合内收集足够证据 |
| **罪犯暗中活动** | 罪犯卡牌以获取赃物、隐蔽为主 | 契合：需要在警长眼皮底下积累资源 |
| **城市版图每局不同** | 地点牌随机抽取构成 | 契合：每次游戏城市面貌不同，策略变化 |
| **NPC 是关键** | NPC 卡牌一次性打出提供关键效果 | 契合：线人、目击者等是破案/犯罪的关键 |
| **创造临时场景** | 场景牌创造临时地点 | 契合：伪造现场、街头事件等符合主题 |
| **暗出手牌** | 游戏核心机制 | 契合：夜晚的行动本就是隐密的 |
| **10 夜完结** | 游戏 10 回合上限 | 契合：10 天破案/犯罪的故事弧线 |

## 主题一致性摘要

**「罪城夜话」** 的世界观围绕一个核心理念构建：**每个夜晚，都是一手牌。**

- 你手中的每一张卡牌代表这个夜晚的一个选择
- 你的目标是你今晚要去的地方
- 你打出的 NPC 是今晚与你会面的人
- 10 个夜晚过后，城市将迎来黎明——谁能在暗夜中胜出，全看这 10 手牌

主题与机制的深度契合，让玩家在出牌的每一个决策都有叙事层面的支撑，增强了代入感。
