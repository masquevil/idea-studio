# 方案 1-C · 核心机制设计

> 基于"罪城回响"方向：事件链系统 + 舆论战场 + 时间压力 + 公共任务板

---

## 核心游戏循环

游戏以"夜"为单位推进，每夜分为四个阶段：

### 阶段 0：夜幕降临（准备阶段）

1. **刷新公共任务板**：从案件库中抽取 3 张案件牌面朝上放置在公共任务板上（每位罪犯从任务板选择案件作案）
2. **媒体头条**：抛出一张"媒体头条牌"——决定本夜舆论倾向（如："政客丑闻转移视线"→警长民意获取减半；"连环案引发恐慌"→恐慌值自动+1）
3. **警长情报**：警长查看"城市脉搏报告"——热点区域提示、已发案件进展状态
4. 所有玩家补牌至手牌上限

### 阶段 1：罪犯密谋（秘密阶段）

1. 每位罪犯从公共任务板 **竞标/选择 1 个案件**（先到先得或竞价机制）
2. 选定案件后，从手牌中打出 **策划牌** 来规划作案方式（决定行动强度、连锁触发条件、舆论影响方向）
3. 罪犯可选 **提前策划**（消耗额外手牌为案件增加链式触发条件）→ 若成功，自动触发下一次级事件
4. 罪犯确认后进入阶段 2

### 阶段 2：警长响应（公开阶段）

1. 警长查看案件信息（罪犯选了什么案件，但不知罪犯身份）
2. 警长分配 **响应行动点**（共 4 点），可执行以下操作：
   - **派遣干预**：向某个已启动案件所在地点派遣警力（消耗 2 点，阻止该案件或降低其连锁风险）
   - **舆情控制**：召开新闻发布会或管控媒体（消耗 1 点，稳定民意/降低恐慌）
   - **提前预警**：封锁某个地点使其本夜不可犯罪（消耗 2 点，但该地点警戒等级永久+1）
   - **追查线索**：调查一个已发生的案件，获取罪犯身份信息（消耗 1 点）
   - **紧急动员**：额外消耗 1 点行动点获取第 2 次派遣机会（限 1 次/夜）
3. 警长部署完成后进入阶段 3

### 阶段 3：案件结算（公开阶段）

1. **案件执行**：依次结算每个被选中的案件
   - 罪犯行动强度 vs 地点综合防御值（基本防御 + 警长干预 + 警戒等级）
   - 成功：罪犯获得犯罪点数，案件标记为"已犯"
   - 失败：罪犯不获得点数，但也不暴露（除非打出暴露牌）
2. **连锁结算**：检查已成功的案件是否满足连锁触发条件
   - 满足 → 自动生成新的次级事件（如银行劫案成功 → 触发"警力分散"→ 导致贫民区骚乱）
   - 次级事件立即进入结算队列（本夜内继续结算）
   - 每个案件最多连锁 2 级（防止无限链）
3. **舆论结算**：根据本夜犯罪结果 + 媒体头条，调整舆论倾向值
4. **时间推进**：夜数+1，检查游戏结束条件

### 阶段 4：黎明报道（过渡阶段）

1. **媒体总结**：根据本夜事件生成"城市早报"摘要（叙事性描述事件结果）
2. **罪犯身份互动**：罪犯可在本阶段使用"接头牌"——尝试确认同伴身份或交换信息（但不强制）
3. **资源恢复**：回收所有已使用的牌，补充公共任务板（移除已犯案件，补充新案件）
4. 进入下一夜

## 胜利条件

### 警长获胜条件

- **秩序恢复**：规定夜数（如 8 夜）内，恐慌值未达到阈值，且至少逮捕 1 名罪犯
- **精确打击**：成功逮捕所有罪犯（需收集足够线索+警力部署到位）

### 罪犯获胜条件

- **罪恶狂欢**：累计犯罪点数达到阈值（如 15 点），且至少有 1 名罪犯未被逮捕
- **城市沦陷**：恐慌值达到上限（城市全面失控），所有存活罪犯获胜
- **完美犯罪**（可选）：某罪犯完成"完美犯罪"系列案件（任务板特定组合），该罪犯独自获胜

### 超级英雄（0-1 人）获胜条件

- **正义制裁**：成功阻止 N 次犯罪（含连锁事件），累计正义值达到目标则独自获胜
- 超级英雄在连锁结算阶段拥有"中断权"——可牺牲行动打断一次连锁

### 受害者联盟（0-1 人）获胜条件

- **民粹浪潮**：民意值达到上限且恐慌值高于阈值，推动民粹领袖上台，独自获胜
- 受害者联盟可在舆论结算阶段影响媒体头条方向

## 基本规则框架

### 游戏准备

1. **设置城市版图**：将 8-10 张地点牌围成一圈或按区域摆放，每个地点标注名称、警戒等级、连锁标签（案件类型匹配）
2. **构建公共任务板**：从案件牌库中随机抽取 5 张放置到任务板区域（面朝上）
3. **资源配置**：
   - 警长：5 张行动牌 + 3 张舆情牌
   - 每位罪犯：1 张身份牌（罪犯职业）+ 4 张手牌（策划牌 + 接头牌混合）+ 初始案件竞标代币 3 个
   - 媒体牌库：独立牌库，每夜翻 1 张
4. **设置计数器**：
   - 夜数计数器：第 1 夜
   - 犯罪点数计数器：0→目标值
   - 恐慌值计数器：初始 0
   - 民意值计数器：初始 5
   - 舆论倾向指示器：中立

### 基本名词定义

| 名词 | 说明 |
|------|------|
| **案件牌** | 公共任务板上的犯罪任务，标注名称、目标地点类型、犯罪点数、连锁条件、所需行动强度 |
| **策划牌** | 罪犯手牌，决定作案方式（快速作案/精密策划/暴力突入等），提供行动强度加成 |
| **连锁条件** | 案件成功后自动触发的次级事件条件（如"银行劫案 → 警力分散 → 贫民区骚乱"） |
| **次级事件** | 连锁触发产生的事件，立即进入结算队列，一般犯罪点数减半 |
| **行动强度** | 罪犯执行案件的成功力，与目标地点的防御值对抗 |
| **综合防御值** | 地点当前防御水平 = 地点基础防御 + 警长干预 + 警戒等级加成 |
| **竞标代币** | 罪犯用于竞争公共任务板案件的资源（每人起始 3 个，可补充） |
| **媒体头条牌** | 每夜随机一张，决定舆论风向，影响民意/恐慌变化 |
| **舆论倾向** | 偏警长/偏罪犯/中立，影响民意值和恐慌值的增减幅度 |
| **恐慌值** | 城市恐慌程度（0-10），达到上限罪犯胜 |
| **民意值** | 公众对警长的支持度（0-10），决定警长可用资源 |
| **接头牌** | 罪犯之间用于秘密确认或交换信息的手牌 |
| **暴露度** | 罪犯行动可能导致身份暴露的风险 |
| **封锁** | 警长使某个地点暂停使用 1 夜，但代价是该地点警戒永久+1 |

### 核心规则

#### 公共任务板竞标机制

- 任务板上始终有 5 个面朝上的案件
- 每位罪犯每夜可以：
  - **免费选择 1 个案件**（如无人竞争）
  - **竞标**：多名罪犯想要同一案件时，出价竞标代币（暗拍），出价高者得，所有竞标者扣除所出代币
- 未选中任何案件的罪犯可以：
  - **自行策划**：从手牌中打出 1 张策划牌 + 1 张地点牌，创造一个"自制案件"
  - 自制案件的犯罪点数 = 策划牌基础值 + 与地点的匹配加成
- 案件被完成后从任务板移除，下夜补充新案（补充至 5 张）

#### 事件链系统

- 每个案件牌上标注 **连锁标签**（如"金融线"、"暴力线"、"政治线"等）
- 连锁条件：同一条连锁线上累计成功犯罪 2 次 → 触发链式反应
- 链式反应效果：
  - **自动生成次级事件**（无需罪犯额外操作）
  - 次级事件立即进入本夜结算队列
  - 次级事件的犯罪点数 = 原案的 50%
  - 次级事件同样可能触发下一级连锁（最多 2 级）
- 连锁示例：

  ```
  银行劫案（金融线 1/3）→ 成功
  ↓
  警力被调往银行 → 港口守卫空虚
  ↓
  码头走私案（金融线 2/3）→ 成功 → 连锁触发条件达成（金融线 2/2）
  ↓
  黑色星期五（次级事件）→ 股市崩盘 → 恐慌+2、民意-2
  ↓
  链接触发（第 2 级）：大量失业 → 贫民区骚乱
  ```

- 警长可以 **打断连锁**：在某次级事件生成前，通过派遣警力到目标地点来阻止
- 超级英雄可以 **中断连锁**：牺牲自己的回合行动，直接取消一个即将生成的次级事件

#### 舆论战场系统

- **舆论倾向指示器**：中立 → 偏警长 → 偏罪犯（双向滑动）
- 影响因素：

  | 事件 | 舆论倾向变化 |
  |------|-------------|
  | 罪犯成功犯罪 | 向偏罪犯方向移动 1 格 |
  | 警长成功阻止 | 向偏警长方向移动 1 格 |
  | 媒体头条事件 | 按头条描述移动 |
  | 恐慌值上升 ≥3 | 自动向偏罪犯方向移动 1 格 |
  | 受害者联盟行动 | 可调整 1 格 |

- 舆论倾向影响：

  | 舆论倾向 | 对警长效果 | 对罪犯效果 |
  |---------|-----------|-----------|
  | 偏警长 | 民意值下降速度减半；警长行动点+1 | 竞标代币恢复-1 |
  | 中立 | 正常 | 正常 |
  | 偏罪犯 | 恐慌值上升速度加倍；警长行动点-1 | 竞标代币恢复+1；暴露度-1 |

- 警长可通过 **舆情控制行动** 扭转舆论倾向（消耗 1 行动点，向偏警长方向移动 1 格）
- 罪犯可通过 **舆论操纵牌** 扭转舆论（打出手牌，向偏罪犯方向移动 1 格）

#### 时间压力系统

- 游戏固定进行 **8 夜**（8 回合）
- 每夜结束后，未阻止的案件会积累"衍生威胁"：
  - 第 1 次未阻止：该地点热度+1
  - 第 2 次连续未阻止：该地点自动生成 1 个"自制案件"供罪犯下夜选择
  - 第 3 次连续未阻止：该地点爆发骚乱（恐慌+2，连锁自动触发）
- 警长行动点每夜固定 4 点，但随民意值变化：
  - 民意 ≥ 8：行动点+1（民众配合）
  - 民意 ≤ 3：行动点-1（民众不配合）
- 限时感制造紧迫：案件过期未选则移除并替换，但犯罪机会减少，罪犯犯罪压力增大

#### 罪犯身份系统

- 每位罪犯有隐藏身份（职业：黑客、走私者、杀手、教父、骗子等）
- 罪犯之间 **不知对方具体身份**，仅知道谁是同伴
- 可以通过以下方式确认同伴身份：
  - **接头牌**：消耗 1 张接头牌，指定一名同伴，对方可选择展示身份或拒绝（拒绝则关系紧张）
  - **协同犯罪**：两名罪犯选择同一案件链时，结算后可互认身份
  - **身份暴露**：犯罪失败可能暴露身份特征（如黑客留下数字痕迹）
- 确认身份后的好处：
  - 可以交换手牌
  - 可以策划联合犯罪（2 人合作提升行动强度）
  - 可以共享竞标代币
- 不确定身份的代价：
  - 可能互相抢夺同一案件（浪费资源）
  - 无法有效策划连锁配合

#### 时间推进与游戏节奏

| 夜数 | 阶段名称 | 特征 |
|------|---------|------|
| 1-2 | 试探期 | 案件简单，连锁容易打断，罪犯在积累资源 |
| 3-4 | 升级期 | 案件变难，连锁开始出现，警长压力增大 |
| 5-6 | 高危期 | 案件难度高，连锁频发，恐慌值接近阈值 |
| 7-8 | 终局期 | 最难的案件出现，所有决策都是最后机会 |

### 玩家操作复杂度

| 阵营 | 每夜操作 | 核心决策 | 信息量 |
|------|---------|---------|--------|
| 警长 | 情报分析、派遣干预、舆情控制、锁定追查 | 4 行动点分配：阻止犯罪 vs 控制舆论 vs 追查线索 | 全案件信息 + 罪犯匿名 + 舆论趋势 |
| 罪犯 | 选案竞标、打策划牌、打接头牌 | 选哪个案件、是否连锁策划、是否与同伴配合 | 可见任务板 + 警长部署（有限） |
| 超级英雄 | 移动、中断连锁、特殊技能 | 何时使用中断权、帮警长还是制衡警长 | 全地图 + 可提前查看连锁路径 |
| 受害者联盟 | 影响媒体、煽动情绪、组织行动 | 推恐慌还是推民意、何时转向 | 了解舆论倾向 + 城市三值 |

## 设计要点总结

1. **事件链是核心特色**：案件互相连接形成多米诺效应，单次犯罪可能引发城市级危机
2. **舆论战场增加非对称维度**：警匪博弈不仅在地点层面，还在公众认知层面——掌握舆论就是掌握主动权
3. **固定夜数制造倒计时感**：8 夜固定时长，每夜都不可浪费，时间本身就是压力源
4. **公共任务板公开博弈**：案件对所有人可见，但竞争和竞标创造新的互动维度
5. **罪犯身份有限透明**：同伴间不确定身份细节 → 可合作可背叛 → 增加社交推理元素
6. **与 A/B 差异化**：C 更强调"连锁反应"和"系统性失控"的戏剧感，而不只是警匪直接对抗
