# 方案 1-C · 世界观与主题设定

> 基于"罪城回响"方向：事件链系统 + 舆论战场 + 时间压力 + 公共任务板
> 核心关键词：连锁反应、舆论之战、倒计时、城市燃烧

---

## 背景故事

### 世界观概要

**罪恶都市回声城（Echo City）**——一座被媒体聚光灯照亮的罪恶温床。

回声城是全球媒体帝国的总部所在地。三大传媒集团的总部摩天大楼在城市天际线上彼此对峙，它们的信号覆盖全球每一寸土地。这座城市的一切——犯罪、执法、娱乐、丑闻——都是内容。罪犯在这里作案不仅为了钱，更为了头版头条的"荣耀"；警长不仅要抓罪犯，还要在镜头前表演"正义"；市民既是观众也是参与者，每一次点赞、转发、抗议都可能改变城市的天平。

回声城是一座**注意力经济**的城市。在这里，罪恶本身不是目的——吸引目光才是。每一起犯罪都是一场秀，每一次抓捕都是一场演出。问题在于：当聚光灯熄灭的时候，城市的真正面目才会浮现。

### 时间线

| 时间 | 事件 |
|------|------|
| 40 年前 | 回声城从港口小城崛起为广播电视中心 |
| 25 年前 | 三大传媒集团完成对城市的信息垄断 |
| 10 年前 | "犯罪真人秀"节目《罪城24小时》开播，犯罪率与收视率同步飙升 |
| 5 年前 | 城市地下犯罪网络"回响帮"形成，专攻"高关注度犯罪" |
| 1 年前 | 警局成立"媒体响应指挥部"（MRC），警长成为城市"主演" |
| 现在 | 每一夜都是直播。全城都在看——谁会赢 |

### 核心冲突

> **曝光 vs 控制**
>
> 罪犯想要的不是钱——是头版头条，是全网热搜，是让自己的"作品"被全城讨论。
> 警长想要的不是简单的抓捕——是在媒体报道下"正确"地抓捕，是不能让舆论失控。
>
> 他们在一座被摄像头和闪光灯包围的城市中对决。
> 每一次交锋都在直播。
> 全城都在看。全世界都在看。

## 城市设定（区域与地点）

回声城分为五大城区，共 12 个关键地点。每个城区对应不同的"收视受众"和犯罪风格。

**连锁传播规则**：

- 同一连锁标签的地点之间，犯罪成功会产生链式反应（如同属"金融线"的银行与交易所）
- 跨线连锁：某些案件成功后，可通过连接线触发其他标签的次级事件
- ☆ 暗影公园为中心枢纽——多线交叉节点，犯罪在此处容易引发多线连锁

## 美术风格方向

### 整体风格

**媒体 noir + 霓虹过曝（Media-Noir / Neon-Overexposed）**——城市的罪恶被媒体的强光照亮，但过度曝光反而让真相更加模糊：

- **高对比度的视觉风格**：强烈的光晕、过曝的霓虹、监控摄像头的鱼眼畸变
- **屏幕感**：所有 UI 元素模拟电视屏幕和手机界面——像素化、HUD 风格
- **媒体元素无处不在**：直播框、滚动字幕、评论弹幕、收视率图表
- **暗处更暗**：在媒体的强光之外，阴影比任何城市都更深——暗示聚光灯照不到的地方才是真正的罪恶

### 色彩方案

| 阵营/场景 | 主色调 | 辅助色 | 氛围 |
|-----------|--------|--------|------|
| **警方** | 冷蓝色 | 白色、银色 | 冷静、秩序、直播中的"正义面孔" |
| **罪犯** | 热粉色/品红 | 黑色、金色 | 高调、挑衅、摇滚明星式的犯罪 |
| **超级英雄** | 荧光绿 | 深蓝 | 异类、不合时宜、像素故障效果 |
| **受害者联盟** | 橙色/警告色 | 灰色 | 愤怒、民粹、街头运动的视觉语言 |

### 区域色彩区分

| 区域 | 色调 | 视觉氛围 |
|------|------|---------|
| 媒体区 | 屏幕蓝白、信号扭曲 | 无处不在的屏幕、刺眼的聚光灯 |
| 金融区 | 冷金、玻璃绿 | 钱的颜色——冷静、冰冷、昂贵 |
| 港口区 | 锈红、雾灰 | 被遗忘的角落，媒体不会拍的地方 |
| 娱乐区 | 霓虹紫、粉、蓝 | 过曝的霓虹，狂欢到腐烂 |
| 居民区 | 暖黄、灰褐 | 仅存的"人情味"，但也在被侵蚀 |

### 视觉参考

- **地点牌设计**：像是"犯罪直播"的取景地——每个地点上方有一个"直播中"的红点标志，牌面采用监控摄像头视角的鱼眼畸变构图
- **角色立绘**：像是"通缉令"海报或"真人秀选手"的定妆照——警长穿着笔挺的制服面对镜头微笑，罪犯则故意遮挡面部或用数字故障效果
- **卡牌边框**：
  - 警方：蓝色透明边框，像新闻台的 UI 元素
  - 罪犯：像素风格的故障艺术边框，像被篡改过的数字文件
  - 媒体牌：滚动字幕底栏 + 收视率柱状图
- **UI 元素**：舆论倾向用"社交媒体趋势"图表显示，恐慌值用"新闻紧迫度"滚动条

### 卡牌设计方向简述

| 卡牌类型 | 背景色 | 边框 | 特殊视觉元素 |
|---------|--------|------|-------------|
| 地点牌 | 根据区域色调 | 监控镜头畸变边框 | "直播中"红点 + 地点名称用新闻标题字体 |
| 案件牌（公共任务板） | 深色渐变+霓虹强调 | 案件卷宗夹样式 | 左上角连锁标签彩色图标 + 右下角犯罪点数 |
| 策划牌（罪犯） | 品红/热粉 | 像素故障边框 | 行动强度用"热度评分"显示，带有社交媒体图标 |
| 行动牌（警长） | 冷蓝渐变 | 透明玻璃边框 | 警徽水印 + 行动类型用"操作菜单"风格 |
| 媒体头条牌 | 纯色+对比色块 | 无边框（全幅） | 新闻大标题 + 滚动字幕副标题 + 舆论影响图标 |

## 主题与机制的契合度说明

| 主题要素 | 体现机制 | 说明 |
|---------|---------|------|
| **注意力经济** | 公共任务板 + 竞标 | 罪犯需要的不是钱，是"关注度"——公共任务板上的案件就是"流量"，罪犯争抢最高关注度的案件 |
| **连锁反应** | 事件链系统（3级连锁） | 在这个被媒体紧密连接的城市，任何事件都会产生涟漪效应——银行劫案不会只影响银行 |
| **舆论操控现实** | 舆论倾向指示器 + 媒体头条 | 在回声城，公众认知比事实更重要。谁掌握了舆论，谁就掌握了城市的走向 |
| **直播压力** | 固定 8 夜倒计时 + 时间压力 | 每一夜都在直播，必须在公众耐心耗尽之前分出胜负——没有人记得第 9 夜发生了什么 |
| **犯罪作为表演** | 自制案件机制 | 罪犯不仅是罪犯，还是"内容创作者"——精心策划的犯罪就像拍电影 |
| **警方被媒体绑架** | 警长需要分心舆情控制 | 警长不能只埋头破案，还必须维护"公众形象"——真实反映了媒体时代执法者的困境 |
| **观众就是力量** | 民意值影响警长行动点 | 民众的支持或反对直接影响警方运作——点赞就是资源，抗议就是威胁 |
| **英雄的表演欲** | 超级英雄的"中断权" | 超级英雄在关键时刻打断连锁，就像电影中的救场——但这也是一场表演 |
| **民众的双刃剑** | 受害者联盟可操控舆论 | 民众愤怒可以推动变革，也可以制造混乱——民粹崛起是民主的阴影面 |

## 游戏氛围设计

### 游戏过程中的氛围营造

1. **游戏准备**：
   - 12 张地点牌以环形展开，中央是"城市直播"主画面
   - 公共任务板上 5 张案件牌面朝上排列——像"犯罪菜单"
   - 媒体头条牌库放在聚光灯下——它将是每一夜的不确定因素
   - 舆论倾向指示器像社交媒体趋势图表一样摆在显眼位置

2. **游戏中**：
   - 📺 阶段 0（夜幕降临）：翻开媒体头条牌——像晚间新闻的开场白
   - 🎭 阶段 1（密谋）：罪犯当面竞标案件——像真人秀选手争夺挑战权
   - 🚨 阶段 2（警长响应）：警长的行动像在开新闻发布会——每个决定都要考虑"观众怎么想"
   - 💥 阶段 3（结算）：连锁触发时的效果，像新闻中的"突发新闻"弹窗
   - 📰 阶段 4（黎明报道）：城市早报摘要叙事性总结本夜事件——每个案件都是一集剧集

3. **游戏结束**：
   - 如果罪犯胜利：社交媒体上的"罪犯支持率"飙升，警长在发布会上低头认错
   - 如果警长胜利：新闻标题是"正义不眠！警长坚守城市"，但底下的评论却不乏讽刺
   - 如果城市沦陷：新闻滚动条变成故障雪花屏——没有人知道接下来会发生什么

### 叙事风格

游戏中的所有描述采用"新闻报道"的语气：

- 案件描述像是**节目预告**：
  > "《水晶银行·午夜奇袭》——保险库大门后的十亿秘密。金融线，难度★★★，收视潜力 8/10。"

- 媒体头条像是**新闻标题**：
  > "🔴 突发：市长办公室惊现窃听器！恐慌指数+1，民意倾向向罪犯偏移。"

- 城市早报像是**剧评**：
  > "第 4 夜回顾：金融线持续升温，银行劫案触发连锁港口的走私狂欢。警长成功阻止了第二级连锁，但暗流仍在涌。明晚是否迎来暴力线的大爆发？"
