## 项目目标

基于 v4 原始想法（`refs/user-initial-4.md`），设计一款名为《罪恶都市》的非对称卡牌轻中策桌游。

- **支持人数**：2-7 人
- **游戏时长**：30-120 分钟（取决于人数）
- **目标年龄**：14+
- **核心设计方向**：以 `refs/user-initial-4.md` 中的原始想法为基础进行细化和完善

## 与 progress-4 的关键区别

| 维度 | progress-4 的问题 | progress-5 的改进 |
| - | - | - |
| **MVP 构建** | 6 个文档并行产出，评审焦点分散，08-数值表与源文档11处不一致 | 仅 4 个设计文档，按规则书→角色→地点→策略编号连续。评审按顺序：非量化→量化基准→设计审查→综合计算→修改指令 |
| **数值表** | 独立维护数据，源文档修改后同步遗漏 | 废除"数据仓库"，删除 08-数值表。审查时直接从源文档计算。量化方法论内置在 04-量化审查规则.md 中 |
| **评审方式** | 1 个综合评审文档，每次重写 | 5 个专项评审文档（r01~r05），层次清晰：非量化问题、0技能基准、设计对比、综合计算、修改指令 |
| **深层漏洞** | 未系统审查 IP 枯竭、犯罪成本坍塌等问题 | r04 专门检查：资源耗竭曲线、技能×地点交叉风险、策略收敛、证据循环等 |
| **阶段④ 测试** | 文档分析（规则审查+数值验证） | 改为 AI 引擎 + 并发 AI agent 模拟测试。但流程中只记录方法框架，执行时细化 |
| **阶段切换** | 工作流程写"用户确认→进入" | 流程中不写"确认后进入"。只有你说"推进进入阶段④"才切换，由你主动控制 |

## 工作流程概览

基于"桌游设计流程（sox-boardgame-design）"skill 的 6 阶段体系，但针对本项目的实际情况调整：

| 阶段 | 名称 | 核心产出 |
| - | - | - |
| ① | **概念定义** | 概念卡片（已通过，直接从 progress-4 的 draft-4-A 继承成果） |
| ② | **核心循环设计** | 核心循环方案（已通过，直接从 progress-4 的 draft-4-A 继承成果） |
| **③** | **MVP 构建与审查** | 规则书、角色、地点、策略牌设计 + 五轮评审（r01~r05） |
| **④** | **模拟测试** | （方法在 01-工作流程.md 中记录，执行时再细化产出） |
| ⑤ | **物理原型 + 人类测试** | 用户自行处理，不写流程 |

> 阶段①概念定义和阶段②核心循环设计已在 progress-4 中完成并确认通过。draft-5-A 直接从规则书开始，继承 draft-4-A 最终状态的规则书、角色设计、地点牌设计、策略牌设计——但所有数值和机制均可调整。

## 一句话参考

> 玩家扮演城市中的不同角色（警长/罪犯/超级英雄/受害者），通过在城市版图上争夺情报资源、执行阵营专属行动，率先达到 15 分获胜。核心张力在于「罪犯藏匿与犯罪 vs 警长侦查与抓捕」的猫鼠博弈，所有阵营各怀鬼胎、互相利用。
