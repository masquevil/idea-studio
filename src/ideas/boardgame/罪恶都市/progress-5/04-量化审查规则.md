# 量化审查规则

> 评审工具文档 — 用于阶段 ③-A 中的量化审查
> 使用方式：在 ③-A 评审中，以本文档 §2 的审查设计原则为指导思想，对规则书、地点、角色、策略牌进行审查。
> 注意：本文档仅包含**审查原则框架**。具体计算、方法论和详细检查清单应在 r02~r04 中基于当前规则书版本实时建立和计算。

---

## 1. 基本单位

在量化审查中，需要先定义你的游戏中"投入"和"产出"的基本单位。例如：

- **投入单位**：玩家执行操作的成本（如行动次数、资源消耗、回合时间等）
- **产出单位**：玩家获得的收益（如分数、资源、位置优势等）

每个游戏的定义不同，在 r02 中根据规则书实际情况确定。

---

## 2. 审查设计原则

以下原则在量化审查中作为判断依据：

| # | 原则 | 说明 |
| - | - | - |
| 1 | **得分效率一致** | 0 特殊能力下各阵营/路线的预期得分效率应基本一致 |
| 2 | **规则一致** | 不因阵营/角色不同而改变全局规则 |
| 3 | **得分收益 ≠ 剥夺收益** | 得分是绝对领先，剥夺是相对优势（只压制 1 个对手），不能简单相加 |
| 4 | **特殊能力效率 ≤ 基础效率** | 特殊能力的收益不应显著高于基础操作效率。但"没有基础得分手段"的阵营例外——特殊能力是他们的核心竞争力 |
| 5 | **蓄力行为 = 0 即时收益** | 摸牌/蓄力等行为储存策略潜力，出牌兑现价值 |
| 6 | **读报是看守所保底** | 刻意低效，不与调查对比性价比 |
| 7 | **低等级不触发高效奖励是叙事设计** | 小角色不值得追，玩家需在高回报与低成本之间抉择 |
| 8 | **低等级监禁时间短是惩罚** | 缺席 1 回合 ≈ 损失一定收益机会 |
| 9 | **仅基础资源获取消耗版图资源** | 其他操作消耗的资源回流供应堆，不消耗版图存量 |
| 10 | **不出现已删除的内容** | 不对比前版本，不使用"修正/错误/撤回"等表述 |
| 11 | **操作频率预期** | 0 特殊能力下各等级/路线的核心操作频率应有合理差异，规则书数值应以此校准 |
| 12 | **隐藏/防御值与等级正相关** | 等级越高则防御越强。低等级易被抓，高等级难被抓 |
| 13 | **被捕次数预期** | 不同等级在被捕概率和被捕损失上应有合理梯度 |
| 14 | **资源耗竭可预测** | 有限资源应在可预测的节奏下消耗。资源耗尽后的游戏状态变化应是设计有意为之 |
| 15 | **操作成本不应跳跃式变化** | 从资源充裕到耗尽的过程中，操作成本应平滑过渡 |
| 16 | **资源/Token 链完整** | 从产生→消耗→回收的全链路必须闭环，不能在任意环节漏失 |
| 17 | **交叉组合不超预期** | 特殊能力+环境+特殊手段的任意组合不应产生大幅超出各自单独效果的收益 |
| 18 | **策略多样性** | 不应存在对所有玩家都最优的同一个"必胜策略"。各等级的理性选择应有差异性 |
| 19 | **非对称阵营补偿合理** | 不具有基础得分手段的阵营，其特殊能力应能弥补基础得分缺口 |

## 3. 使用说明

- **使用阶段**：本工具用于阶段 ③-A（评审 MVP）中的量化审查环节
- **审查范围**：规则书基础操作（§3）、资源系统（§4）、角色特殊能力（§7）、子系统（§6）
- **产出形式**：审查结果写入对应的 `r01~r04` 评审文档；修改指令写入 `r05-修改指令.md`
- **方法论来源**：具体审查方法论的更多参考见 `kamininaru/agents/skills/sox-boardgame-design/docs/balance.md`
- **深层审查维度参考**：见 `kamininaru/agents/skills/sox-boardgame-design/docs/design-review.md`
