# 量化审查规则

> 评审工具文档 — 用于阶段 ③-A 中的量化审查
> 本文档是评审（r01~r05）的完整准则：评审行为准则 + 量化分析方法论 + 评审标准。
> 具体计算在 r02~r04 中基于规则书版本实时建立。

**核心原则概览**：

- **主平衡轴 = KSA 终局节奏**：各阵营达到 15 分终局线所需的 KSA 次数（4-6 次）与全周期轮次（8-12 轮）是首要判定基准（§4.1）
- **行动永远在成本分母**：KSA 完整成本 = 行动占用 + 动态资源花费，行动是情报的上游资源，不得省略（§1.6/§2.4）
- **得分含金量加权**：得分+剥夺型（抓捕/追偿）的 1 分价值高于纯得分型，跨阵营对比一律用加权分（§3.6）
- **KSA 逐行动标定**：独占型（作案/抓捕/制裁/登场，2 行动=1 执行轮）与轻量型（追偿/爆料，1 行动，频率更高）分别标定，不预设统一值（§2.4）
- **触发率独立推演**：和平奖励、追偿、爆料命中率等中间量由推演得出，禁止预设（§3.9）

## 1. 评审行为准则

> 评审质量决定评审价值。评审中的常见失误会扭曲结论，本节定义评审的正确行为方式，适用于 r01~r05 的整个评审过程。

### 1.1 先理解核心规则

- 评审开始前，先通读规则书全文，确保对游戏的核心机制有正确理解
- 用自己的话复述以下维度，检查理解一致性：
  - 能力类型（被动/↩️反应/⚡️免费/➡️行动）的含义
  - 各标签（重大/快速/延时）的含义，特别是「重大 = 每回合≤1 次」对得分频率的硬约束
  - 各阵营的基础操作与得分途径；**每个得分行动（KSA）的实际行动占用**（§2.4）
  - 游戏终局条件（15 分触发线 / 12 轮上限）——**15 分是终局线，不是"12 轮末应有分"**
  - 看守所的运作流程
- 对任何概念有疑惑或不确定时，先用 `ask_followup_question` 向用户提问澄清，得到确认后再开始正式评审

### 1.2 基于实际数值分析

- 每个结论都建立在规则书中明确写出的数值与机制之上
- 引用规则书中的实际参数（如情报值、影响值、花费规则）进行计算
- 对状态时机的判断通过实际推演得出，例如根据调查次数与玩家数量推演地点情报耗尽的轮次

### 1.3 基于具体决策场景分析

- 在具体地点参数（初始情报值、影响值）与具体资源条件下，模拟玩家实际采用的决策链
- 分析时给出完整的行动序列与逐回合的资源/版图状态变化

### 1.4 覆盖多种合理策略

- 考虑不同角色、不同等级、不同局势下的多种合理策略，分别分析各自的最优打法
- 玩家可能集中资源攻一处，也可能多线分散，取决于角色、手牌和局势

### 1.5 如实报告计算与基准的对照

- 独立完成计算，得出什么结果就报告什么结果
- 如实报告结果与设计基准（§4.1）的差值，由设计师判断是否需要调整规则书数值
- 计算过程中的中间参数取值都必须有规则书依据
- **禁止**：把设计师的定性估算（§3.9 参考锚）当作预设结论来"凑数"。参考锚只用于解释量化结果与直觉的偏差，不用于生成量化结果

### 1.6 成本拆分

- KSA 完整成本拆分为**行动占用**与**动态花费**两部分，分开核算：
  - **行动占用**：执行该 KSA 实际消耗的行动点数（§2.4 逐行动标定）。**行动是情报的上游资源**（调查 = 1 行动 → 1 情报，反向不可），因此行动永远计入成本分母，不得省略
  - **动态花费**：行动之外的可积累资源投入（情报 Token 等），受版图状态与对手干扰影响（压 0 降低、布控/设伏/爆料提高）
- 动态成本按实际游戏节奏核算：
  - 推演版图状态在真实交互中的变化速度（例如核心区地点初始情报值 3，4 人局中可被快速打空）
  - 对关键动态成本（如作案情报花费），给出随版图状态变化的区间
- **执行标准**：
  - 每项 KSA 必须按「行动占用 + 动态花费」分列，两者都进"分/资源"分母
  - 关键动态花费必须给出**区间或曲线**（如"作案情报花费 0~4 → 对应完整成本 2 行动+0~4 情报"），**禁止只给单点值**
  - 必须区分**首次成本**与**稳态成本**：首次成本 = 完整前置准备（含把地点情报压低的调查链）；稳态成本 = 前置完成后"每次操作"的投入。两者差异显著时必须分别列出

### 1.7 边界情况归口，不写入卡面

- 评审发现技能/效果描述的边界情况未定义时，只报告"是否需要定义"
- 修改归口指向 **FAQ（规则书 §11）或规则书正文对应章节**，**不得要求将边界情况写进技能/效果描述**（卡面文字只印核心机制，见 `refs/ai-writing-standards.md` §2.2.7）
- 若某技能的核心机制本身需要大量边界说明，评审应指出"简化机制本身"而非"把说明写进卡面"

## 2. 基本单位

- **IC（Investment Cost/单位成本）**：统一以**资源点数**为单位。资源包括行动次数、手牌、"情报 Token"三类，各按自然单位计为 1 资源：
  - 1 次行动 = 1 资源
  - 1"情报 Token" = 1 资源
  - 1 张手牌（策略牌）= 1 资源（初始按 1 处理；因手牌存在"延迟兑现 + 上限 3"特性，理论上应略强，但与限制结合后回到 1 附近，可据测试微调 0.8~1.2）
- **IV（Investment Value/单位收益）**：统一以**分数**为单位。中间产出（情报、手牌）不做独立折算，而是通过"资源→IV 的投入路径"体现其价值。
- **IR（Investment Round/单位时间）**：统一以**轮次**为单位。1 轮 = 一名玩家完整的一轮游戏流程（2 行动 + 1 手牌，见规则书 §5.4）。

**效率的双维度**：

- **资源效率 = IV / IC（分/资源）**：资源利用率，衡量"投入多少资源换多少分"。**IC 分母 = 行动占用 + 动态花费，行动永远在分母**（§1.6）
- **轮次效率 = IV / IR（分/轮）**：时间利用率，衡量"每轮能得多少分"。分母含准备轮、执行轮与干扰轮的完整周期

**双重约束与强制报告**：游戏同时受**资源供给速率**（每轮 3 资源：2 行动 + 1 手牌）与**时间约束**（12 轮上限）制约。任何策略评价**必须同时报告两个指标**，并标注**可持续性**（该策略可连续执行几轮、依赖的外部条件）。

- 两个维度通过"供给速率"换算相互校验：每轮供给 3 资源 → 每轮可积累的动态资源（情报）上限 = 2（调查 2 次）。**不存在"每轮 3 资源全部可自由投入得分"的假设**
- 具体基准与判定方式见 §4.1——**不设"分/资源"的硬性预测数字**，推演后横向对比 + 与 KSA 终局节奏交叉验证（§3.7/§3.8）

### 2.1 资源收入与总资源池

- **每回合资源收入：2 行动 + 1 手牌 = 3 资源**（规则书 §5.4：行动阶段 2 点行动力 + 补给阶段摸 1 张牌）
- **罪犯额外收入：补给阶段隐藏值 +1**（规则书 §5.4②，不超过角色卡上限）——此回复是压点推演的隐性约束：罪犯调查压点会降低隐藏值，但每轮补给会回补 1 点，推演时**必须计入隐藏值的逐轮变化**，不得忽略
- 标准 12 轮、4 人局：单玩家总资源供给 = 3 × 12 = **36 资源**——这是**供给速率口径**，仅表示"最多可用量"，不代表得分资源池
- **重要**：36 资源中，调查/摸牌属于**资源转换**（不产分）、布控/隐藏属于**状态性**（不直接产分）、作案/抓捕轮的行动是**每次 KSA 的固定占用**。因此**不得**用 `15 分 / 36 资源` 推导全局效率基准

### 2.2 资源的三类使用

| 类型 | 定义 | 示例 | 是否产生 IV |
| - | - | - | - |
| **资源转换** | 1 种资源 → 另 1 种资源，总量不变 | 调查（1 行动 → 1"情报 Token"）、摸牌（1 行动 → 1 手牌） | 否 |
| **资源 → IV** | 投入资源直接换取分数 | 作案（2 行动 + X 情报 → 分数）、抓捕、牌面得分效果 | 是 |
| **状态性行动** | 不转换资源、不直接得分，改变版图/防御状态 | 布控、隐藏 | 否（单独作机会成本分析） |

- **资源转换不产生 IV**：调查的本质是"1 行动资源 → 1 情报资源"的转换，不产生分数。但**行动资源的价值并未消失**——它体现为情报的获取成本（每次作案的情报花费需要事前调查行动来积累），此成本计入"准备轮"（§3.3）
- **状态性行动按机会成本分析**：做了布控/隐藏 = 放弃了当回合其他 1 资源的使用，其价值通过"对后续资源→IV 路径效率的影响"衡量，不直接计入分/资源

### 2.3 资源的延迟与可达性

- 行动与情报是即时的；手牌是延迟的（需"摸牌→出牌"两步兑现，普通牌打出还要 1 行动）
- 手牌受上限 3 约束，修整阶段需弃置超出部分
- 涉及手牌的长链（摸牌→出牌→效果）**按实际行动序列逐步推演**，不折算成单步

### 2.4 KSA（关键得分行动）分类与轮次占用

> 关键得分行动（Key Scoring Action, KSA）= 各阵营直接产生 IV 的**重大**专属行动。平衡的第一判定以 KSA 为最小单位（§3.7/§3.8）。

**非对称阵营的 KSA 行动占用不同，"1 次 KSA = 1 轮"不是普遍等式**。逐行动标定如下（依据规则书 §4.2）：

| KSA | 阵营 | 行动占用 | 轮次性质 | 0 能力单次得分基准 |
| - | - | - | - | - |
| 作案 | 罪犯 | **2 行动**（本身 1 + 额外 1） | **独占型**：占满回合 → 1 次 = 1 个执行轮 | 影响值（1-4）+ 匹配 +1 |
| 抓捕 | 警长 | **2 行动**（本身 1 + 额外 1） | 独占型 | 犯罪等级（1-4）+ 高效 +1 |
| 制裁 | 超级英雄 | **2 行动**（本身 1 + 额外 1） | 独占型 | 持有证据数（等差数列 1+2+3…） |
| 登场 | 超级英雄 | **2 行动**（本身 1 + 额外 1） | 独占型 | 该地点证据数 X |
| 追偿 | 受害者 | **1 行动** + 2 情报 | **轻量型**：不占满回合，剩余 1 行动可同时攒情报 → 1 次 ≈ 0.5 个执行轮 | 剥夺型 +1（加权，见 §3.6） |
| 爆料 | 受害者 | **1 行动** + 2 情报 | 轻量型 | 条件 +1（独立推演触发率） |

- **独占型**：2 行动正好占满一回合，且「重大」每回合限 1 次 → 执行该 KSA 的回合无法同时做其他行动，**1 次 KSA = 1 个执行轮**
- **轻量型**：1 行动不占满回合 → 执行该 KSA 的回合剩余 1 行动可同时调查攒情报/摸牌，**执行轮与准备轮部分重叠**，实际频率高于独占型。其节奏约束来自「重大 ≤1 次/回合」+ 情报攒费（每次 2 情报）
- **看守所内补充动作（不作为常规 KSA，但在罪犯被捕后的节奏推演中必须计入）**：
  - **越狱**：➡️➡️ 重大，执行消耗 **2 行动/次**；每移动 1 格花费 **2 情报 + 弃 1 手牌**；若移动到 0 格获得 **+1 分**（依据规则书 §7.2）
  - **放风**：➡️ 额外花费 1 行动，弃置 1 手牌，获得 1"情报 Token"（依据规则书 §7.1）。放风是看守所内的**低效资源转化**（2 行动 + 弃 1 牌 → 1 情报），用于为越狱/出狱后积攒资源
- 推演时必须引用本表的行动占用；**禁止擅自把某 KSA 标定为与规则书不同的占用**，也禁止把轻量型按独占型口径简化（会系统性低估受害者频率）

## 3. 量化分析方法论

> 以下为"怎么做分析"的方法原则。不包含具体游戏数值。

### 3.1 基于真实决策逻辑

量化分析模拟理性玩家在实际游戏中的决策过程：

- **目标导向**：玩家围绕得分目标做决策，行动服务于得分目标
- **投入连续性**：前一个行动的效果会影响后一个行动的条件（资源增减、版图状态变化）
- **循环反馈**：玩家行为改变版图状态，版图状态变化又影响后续决策
- **调查双效（强制计入）**：调查行动同时产生两个效果——①获得 1"情报 Token"；②该地点情报值 -1（降低后续"作案/侦查"的动态成本）。**两个效应必须同时计入计算**，不得只算其一
- **后续操作基于行动后的版图状态**：某行动后的操作成本，必须基于该行动完成后的版图状态（如调查后的地点情报值），**不得回退到初始值**

### 3.2 版图权衡分析

一个地点的情报值变化会同时影响各方决策，形成双向权衡。

**从行动者视角看一个地点：**

- 情报值高 → 得分潜力大 → 有动力在此活动
  - 但调查成本高、准备时间长，需要先投入资源降情报
- 调查降低情报后 → 作案成本降低 → 得分效率提升
- 情报值低 → **首次作案成本极低、得分快**
  - 但**作案会在该地点回填 1"情报 Token"（地点情报值 +1）**，连续作案会使成本递增，需周期性重压调查
  - 且其他阵营在此行动的成本也低（如警长抓捕），行动者的风险上升
  - 风险事件（如被捕）会损失回合 → 降低整体得分效率

**从对手视角看同一个地点：**

- 情报值高 → 对手的干预成本高 → 行动者相对安全
- 情报值低 → 对手的干预成本低 → 行动者风险上升

**量化分析时应考虑：**

- 在同一地点的多回合模拟中，追踪情报值变化对各方决策条件的对称影响
- 评估是否存在情报值区间导致某一方获得不对称优势
- 检查版图上不同地点的情报值分布是否提供了足够的策略多样性
- 注意一个阵营的行为会改变版图状态，间接影响其他阵营的决策条件（对称性）

### 3.3 多回合累计

- **强制使用完整行动力**：每回合按 2 行动 + 1 手牌（3 资源）计，**逐行动列出行动序列**，不得用"每回合 1 行动"的简化推演（每回合 2 点行动力是规则书 §5.4 的基本规则）
- **行动去向清单（强制）**：每回合的 2 个行动必须逐项注明去向（KSA / 调查 / 摸牌 / 状态性 / 空过），确保行动价值不被忽略。每个 KSA 的行动占用按 §2.4 标定值记入"分/资源"分母；调查/摸牌等转换行动的价值体现在"准备轮"与"情报积累"中，不直接进分母但必须列出去向
- 追踪资源、属性的逐回合变化趋势，覆盖完整的游戏流程
- 对"每回合/每轮自动补给"类的机制（火车站回填、情报干扰放置、作案回填等），**逐轮纳入累计计算，禁止一次性折算**（如火车站·流动人口每黎明回填 1 情报 → 只能每次 +1，不得一次性折算）
- **机制前提（与规则书一致）**：
  - "调查动作"降低地点情报值（-1）并获得 1"情报 Token"（转换）
  - "作案动作"花费 = 地点当前情报值 的"情报 Token"，**并在该地点放置 1 个"情报 Token"（地点情报值 +1）**——这是规则书 §6.3/FAQ Q2 的明文规则，推演必须计入回填造成的成本递增
  - 地点情报值**只被"调查动作"降低**，被**作案回填、火车站回填（黎明）、情报干扰（放置）**等机制提高

**记账口径（强制）**：

- **KSA 完整成本 = 行动占用（§2.4 标定值）+ 动态花费（情报等）**，两部分全部进入"分/资源"分母。行动是情报的上游资源，不得省略
- **准备轮独立列前置周期**：警长的侦查/抓捕链（调查攒情报 → 侦查取证 → 抓捕）与罪犯的压点链（调查压情报 → 作案）**必须按同一口径拆分准备轮与执行轮**，禁止一方把准备轮摊进执行轮、另一方平均稀释
- **作案回填必须计入连续作案的成本曲线**：首次作案（压 0 后）动态花费 0，但因回填 +1，第二次作案花费 1、第三次花费 2……需结合"重压调查轮"建模，**禁止按"压 0 后每次作案 0 成本"的静态假设推演**
- 每回合资源供给 = 2 行动 + 1 手牌 = 3 IC（常量，作为供给速率上限）

**逐回合流水账模板（强制格式）**：

> 所有多回合推演必须使用以下列结构，逐回合逐行动记账，供审计核对。行动代号由推演场景自行定义（示例：D = "调查动作"（转换）、C = "作案动作"（KSA）、S = "侦查动作"（前置）、A = "抓捕动作"（KSA））。

| 回合 | 行动序列（含去向） | 地点情报值(初→行后→傍晚) | 供给 IC | 行动占用 | 动态花费 IC | 情报余额 | 手牌余额 | 本回合 IV |
| - | - | - | - | - | - | - | - | - |
| R_i | 逐行动列出 | a→b→c | 3 | 本回合 KSA 消耗的行动 | 本回合 KSA 消耗的情报等 | 转换与花费后的存量 | 按摸牌/弃牌更新 | 本回合得分 |

> 注：表中"地点情报值(初→行后→傍晚)"必须体现作案后的回填（如 `0→1`），不得照抄"作案不改变情报值"的旧假设。

**计算规则（强制）**：

- **资源效率 = 累计 IV / 累计 KSA 完整成本**：分母 = 累计行动占用 + 累计动态花费。调查/摸牌等转换不进入分母，但**必须能通过"行动去向清单"核算其价值落点**（如"为第 N 次作案攒了 X 情报，占用 Y 个准备轮"）
- **轮次效率 = 累计 IV / 完整周期轮数**：分母必须包含准备轮、执行轮与恢复轮（即完整起止区间），并标注起算轮次与周期长度；禁止只取得分轮
- **KSA 节奏审计（新增，强制）**：每张流水账末尾附：① 共执行几次 KSA；② 每次 KSA 的执行轮数合计（独占 1/次、轻量按重叠折算）；③ 准备轮数合计；④ 干扰轮数合计（被捕/转移/布控规避）；⑤ 总周期轮数 = ②+③+④
- **可持续性标注**：每个策略必须标注可连续执行轮数、中断点或外部依赖条件
- **循环闭合判定**：标注"从 X 到 Y 构成完整闭合循环"或"该片段为非闭合、需额外恢复"；循环末状态须与循环初可比
- **审计行**：每张流水账末尾附累计明细（累计供给 / 累计行动占用 / 累计动态花费 / 累计结余 / 累计 IV），用于核对资源"用多、用少、刚好"
- **起点状态声明**：每张流水账注明起点状态（初始情报、初始手牌、目标地点初始情报值、隐藏值、作案回填等机制是否生效），确保推演可复现

### 3.4 动态周期

游戏通常存在前中后期的节奏差异。量化分析应分阶段进行：

- **前期**：资源积累期，效率通常偏低
- **中期**：策略执行期，效率提升
- **后期**：冲刺期，效率最高

各阶段的转换节点由资源耗竭、得分阈值等触发。分析时确认转换节点是否合理。

### 3.5 非对称阵营的跨方抑制分析

> 本游戏为非对称阵营（警长 vs 罪犯等），一方的行为会改变另一方的操作成本与得分条件。量化平衡时**不能只看单侧效率**，必须将"抑制与被抑制"纳入评估。本节定义跨方抑制的分析方法，具体数值判定在 r02~r04 中产出。

**分析对象**：如警长对罪犯（布控/侦查/抓捕），反之罪犯对警长（压情报/藏匿）。本文档以警长→罪犯为例作为通用模板；其他阵营对同理套用。

**警长侧量化必须包含两部分**：

| 部分 | 内容 | 计算方法 |
| - | - | - |
| ① 自身双效率 | 侦查→抓捕链的得分（抓捕犯罪等级分、高效抓捕 +1、和平奖励） | 同一套逐回合流水账 + 资源效率/轮次效率（§3.3） |
| ② 对罪犯的负面影响（抑制量） | 布控、侦查、抓捕对罪犯操作成本与得分节奏的压制 | 见下方"抑制量拆分" |

**抑制量拆分（警长→罪犯）**：

| 手段 | 机制 | 对罪犯的影响（量化口径） |
| - | - | - |
| 布控（情报 +2，持续 1 轮） | 提高目标地点当前情报值 | 提高罪犯在该地点作案/调查的动态花费（作案情报花费 +2） |
| 侦查（取走证据） | 减少罪犯"证据 Token"存量 | 限制连续作案能力（证据 5 枚封顶），迫使其中断或转移 |
| 抓捕 | 证据入看守所 + 罪犯入狱 | 罪犯 ≥1 轮无法正常得分（看守所内仅可"放风/越狱"），损失执行轮（§3.8 干扰轮） |

**净平衡判定规则（方法指导）**：

1. 分别估算：**罪犯无干预节奏**（罪犯单侧流水账 + KSA 节奏审计）、**警长自身双效率**、**警长对罪犯的抑制量**（把布控/侦查/抓捕折算进罪犯的效率削减或成本提升）
2. 计算**净平衡**：被抑制后的罪犯加权分 / KSA 节奏，与警长自身加权分 / KSA 节奏对照（**必须用加权分，见 §3.6**——跨阵营对比不得把不同阵营的表面分直接对减，必须体现"剥夺型得分含金量更高"）
3. 判定口径（以 KSA 终局节奏为主）：
   - 罪犯无干预是否在 8-12 轮自然触发 15 分终局（§4.1 主基准）
   - 施加警长抑制后，罪犯是否被打出合理区间（<8 轮 = 抑制过度；仍 >12 轮 = 未被有效反制）
   - 警长自身在"同时执行抑制"的前提下，是否仍能在 12 轮内接近 15 分（防止"警长只顾压制对手、自己到不了分"）
4. 交叉组合同理：对高威胁罪犯组合（如压区低情报作案），必须评估警长布控（回拉情报）/抓捕（打断循环）能否有效反制；当反制成本低于其收益时才算抑制有效
5. 所有跨方推断与折算也须给出审计行，注明折算依据（如"布控 +2 情报 → 罪犯作案花费 +2 IC"）

### 3.6 得分含金量加权（操作化 §4.2 原则 3）

> 得分的"含金量"不同。跨阵营对比时**必须使用加权分**，不得把两个阵营的表面分直接对减。

**三类得分及其加权系数**：

| 类型 | 定义 | 加权系数 | 持有阵营 |
| - | - | - | - |
| **纯得分** | 只增加自己的分数，不影响他人 | 1.0 | 罪犯（作案）、英雄（制裁/登场） |
| **得分 + 剥夺** | 自己得分的同时，直接削减/剥夺对手的得分能力 | **≈1.3-1.5** | 警长（抓捕）、受害者（追偿） |
| **纯剥夺** | 只压制对手，不直接为自己加分 | 按当量折算，不计入自身得分效率 | — |

**抓捕的含金量（设计基准推导，来自设计师）**：

- 抓捕等级 2 罪犯：自身得分 3（犯罪等级）+ 高效 1 = 3~4 分
- **剥夺当量**：一次抓捕让目标罪犯进看守所 ≥1 轮 → 损失约 1 次作案（≈1 个执行轮）；3 罪犯局中同等次数抓捕摊到每个罪犯约 1 分当量
- 因此 `1 次抓捕 ≈ 自己的 3 分 + 剥夺对手 1 分 = 4 分当量` → **警长 1 分的价值 ≈ 罪犯 1 分的 1.33 倍**（在等级 2 场景下）

**追偿的含金量**：

- 追偿黎明触发：目标 -1、自己 +1 → 表面差 2 分当量，加权区间 1.5~2.0（视双方得分节奏）
- 追偿是**条件杀伤**（目标本轮得分 ≥2 才触发），实际含金量由触发率独立推演后加权

**使用规则（强制）**：

1. 跨阵营对比（净平衡、超模判定、r04 综合对比）一律使用加权分
2. 加权系数按实际目标等级/场景微调，并在审计行注明（如"等级 2 目标加权 1.33；等级 4 目标罪犯损失更大，加权上调"）
3. 纯剥夺手段（如暴力催收缴手牌）不直接加分，按其折算当量备注，不混入得分效率

### 3.7 跨阵营 KSA 对等检查（主平衡轴之一）

> 非对称阵营平衡的第一判定：**各阵营 0 能力下，达到 15 分所需的 KSA 次数与轮次预算是否对等**。此检查在 r02 产出，作为一切后续评审的锚。判定目标（4-6 次 KSA、8-12 轮）是设计基准（§4.1），推演过程独立。

**检查步骤**：

1. **单次 KSA 得分**：按规则书基础操作计算（不含技能，技能层在 r03/r04 再加入）
2. **KSA 次数**：`次数 = ⌈15 ÷ 单次 KSA 得分⌉`（纯得分型）；剥夺型按加权分等效（§3.6）
3. **轮次预算**：`总轮次 = (KSA 次数 × 每次轮次占用) + 准备轮 + 干扰轮`，与 12 轮上限对照
   - 独占型每次占用 1 轮；轻量型按重叠折算（§2.4）
   - 准备轮独立推演（压点调查、侦查取证），**双方同一口径**
4. **判定**：各阵营总轮次是否都落在 **8-12 轮**（即自然触发 15 分终局、且在 12 轮上限内留有余量）。小于 8 轮 = 该阵营节奏过快（超模候选）；大于 12 轮 = 该阵营到不了 15 分（偏弱候选）；差异显著的阵营间对比是首要平衡风险

**参考锚（对照解释用，非预设，§3.9）**：

> 设计师定性估算：等级 2 罪犯 15 分 ≈ 5 次作案（3 分/次）= 5 执行轮 + 调查准备 + 布控抓捕干扰 ≈ 8-12 轮；警长 ≈ 4-5 次抓捕（3 分/次）+ 前期和平 2-3 分 ≈ 8-11 轮。量化结果应与这些锚可比；**偏差由量化独立得出，不由参考锚生成**。其中"8-12 轮"同时也是设计基准（§4.1）的取值来源；中间量（和平触发轮次等）必须独立推演。

### 3.8 KSA 终局节奏推演模板

> r02 为每个阵营的主得分路线输出一张"终点节奏卡"：单次 KSA 得分、KSA 次数目标、轮次占用、准备轮、干扰轮、总轮次、敏感性。模板如下。

**推演步骤**：

1. **场景声明**：目标地点/目标角色、犯罪等级、初始情报值、隐藏值、作案回填等机制是否生效
2. **单次 KSA 得分**：影响值/犯罪等级 + 匹配/高效加成
3. **KSA 次数目标**：⌈15 ÷ 单次得分⌉（纯得分）；剥夺型用加权分当量
4. **每次轮次占用**：独占 1 轮 / 轻量折算（§2.4）
5. **准备轮**：压点调查（`⌈初始情报 ÷ 2⌉` 轮，受每回合 2 行动上限约束）+ 攒情报轮；**因作案回填，需按"压 0 → 作案 → 回填 +1 → 重压"的成本递增曲线补计压缩/重压轮**
6. **干扰轮**：按推演场景计入（如"每 3 次作案被捕获 1 次 → 损失 1 执行轮 + 重积累"；或先标 0 再在敏感性中展开）
7. **总轮次**：`(次数 × 占用) + 准备轮 + 干扰轮`，判定落在 8-12 区间与否

**敏感性模板（强制对每个 KSA 做）**：

| 变量 | 基准 | 变化 | 对单次 KSA 完整成本的影响 |
| - | - | - | - |
| 布控 +2 情报 | 压 0 首次作案 0 情报 | 0 → 2 情报 | 动态花费 +2 → 需要额外 1 轮调查（2 行动/轮上限） |
| 作案回填 +1 | 压 0 后作案 | 0→1→2 递增 | 连续作案成本递增 → 每次作案后需周期性重压调查；另附码头仓库/黑市的交互注记 |
| 情报通胀（供应堆富集） | — | 情报充裕 | 降警长/英雄动态成本，利好抓人侧；罪犯作案成本不随通胀降低 → 压 0 动机增强 |
| 高效抓捕补差 | 1 证据抓隐藏 3 | 差 2 补 2 情报 | 警长动态花费 +2 → 该次抓捕准备轮 +1 |
| 设伏 +2 情报 | 目标地点行动花费 | 花费 +2 | 与布控/爆料同向叠加（见规则书 FAQ Q11），抑制罪犯/警长在该地点的行动 |
| 迷雾（2-3 人局） | 4 人局无迷雾 | 版图存在迷雾 | 2-3 人局迷雾视为"证据 Token"计入和平奖励判定 → 迷雾局和平奖励几乎不可达（量化范围以 4 人局为主，仅作注记） |

> 敏感性目的在于暴露"成本结构异常"（例如布控后每次作案的轮次成本翻倍，是否使罪犯理性转移/延迟），不用于生成主判定，主判定仍以 KSA 终局节奏为准。

### 3.9 设计基准 vs 参考锚 vs 量化判定

> 明确三类概念，防止把量化评估与非量化评估混为一谈。

- **设计基准（判定用）**：§4.1 主基准——各阵营达到 15 分所需的 KSA 次数（4-6 次）与全周期轮次（8-12 轮）。这是设计师对游戏节奏的**硬性设计目标**，量化结论必须与之对照判定。**主基准可以是目标数字，但推演它的中间量（触发率、准备轮、和平触发次数等）不得预设**——生成过程保持独立，只对照最终结果。
- **参考锚（解释用，非预设）**：设计师对具体情节的定性估算（如"约 5 次作案、警长 4-5 次抓捕、前期和平 2-3 分"）。**仅用于解释量化结果与直觉的偏差**，标注「参考锚 · 非预设」，不进入判定。
- **量化判定**：由规则书实际数值独立推演出的结论（触发率、轮次、成本、含金量）。**触发率（和平奖励、追偿、爆料命中）必须独立推演，严禁预设**——例如"和平奖励前期 2-3 次"是待推演的假设对象，不是输入。
- 三者关系：量化先独立推演 → 结果对照设计基准（§4.1）判定 → 偏差再用参考锚解释 → 结论由设计师裁决。量化不得为了匹配设计基准或参考锚而调整模型参数（§1.5 如实报告原则）。

## 4. 评审标准

> 以下为评审时判断数值是否合理的依据。包括设计师的预期得分目标和各维度的判断原则。

### 4.1 得分目标

> **主基准（平衡轴）：KSA 终局节奏**
>
> - 各阵营（0 特殊能力、4 人局）达到 **15 分终局线**所需的 KSA 次数应落在 **4-6 次**（纯得分型）或加权等效（剥夺型，§3.6）
> - 全周期轮次 = KSA 执行轮 + 准备轮 + 干扰轮，应落在 **8-12 轮**内自然触发终局（在 12 轮上限内留有余量）
> - 不同角色（不同阵营、不同等级）在发挥一般的情况下，达到终局的轮次应相差不大
>
> **主基准是判定目标，不是推演输入**：达标与否用最终总轮次对照；但准备轮数、干扰轮数、和平/追偿等触发率必须由 r02 独立推演得出，不得预设后反推（§3.9）。

> **次基准（结构检查）：KSA 资源效率**
>
> - 资源效率 = 得分 /（行动占用 + 动态花费），行动永远在分母
> - **不设硬性预测数字**。r02 推演后**后验**得出各阵营 0 能力的分/资源，用于：
>   ① 跨阵营横向对比（差异显著的阵营间需要解释）；
>   ② 与主基准（KSA 节奏）交叉验证（如"资源效率虚高但 KSA 频率受限" → 以主基准为准）；
>   ③ 敏感性分析（布控/情报通胀对成本结构的影响，§3.8）
> - 判定原则：**不使用 `15 分 / 36 资源` 之类的全局算术推导基准数字**——36 资源中大量是转换/状态性行动，且 15 分是终局线而非"12 轮末应有分"。分/资源只作为后验结构检查，不作为主判定

**参考锚（非预设，§3.9）**：

| 阵营 | 参考锚（设计师定性） | 加权口径 |
| - | - | - |
| 罪犯（等级 2） | 核心区作案 3 分/次，约 5 次 = 15 分；加准备与干扰 8-12 轮 | 纯得分 1.0 |
| 警长 | 1 证据抓等级 2 = 3 分，约 4-5 次抓捕 + 和平 2-3 分 = 15 分 | 得分+剥夺 ≈1.33 |
| 超级英雄（夜枭） | 制裁等差数列 1+2+3+4+5 = 15 分，约 5 次 = 5 执行轮 + 攒情报准备轮 | 纯得分 1.0（另有对局影响：清证据利于和平奖励） |
| 受害者（艾登） | 追偿为轻量型，频率高但单次 1 分；8-10 次追偿叠加"剥夺含金量"后收敛 | 得分+剥夺 1.5~2.0 |

> 上述锚用于解释量化偏差，不预设结论。例如"和平奖励 2-3 分"的实际触发轮次与次数由 r02 独立推演（含"3 罪犯集中压同一地点 → 第一轮和平就拿不到"等边界场景）。

### 4.2 审查设计原则

以下原则在量化审查中作为判断标准：

| # | 原则 | 说明 |
| - | - | - |
| 1 | **得分节奏一致** | 0 特殊能力下各阵营/路线达到 15 分的 KSA 次数与轮次预算应基本一致（§4.1 主基准） |
| 2 | **规则一致** | 不因阵营/角色不同而改变全局规则 |
| 3 | **得分收益 ≠ 剥夺收益（操作化）** | 得分是绝对领先，剥夺是相对优势。跨阵营对比用加权分（纯得分 1.0 / 得分+剥夺 1.3-1.5 / 纯剥夺按当量），见 §3.6。**禁止把警长表面分与罪犯表面分直接对减** |
| 4 | **特殊能力效率 ≤ 基础效率** | 特殊能力的收益不应显著高于基础操作效率。但"没有基础得分手段"的阵营例外——特殊能力是他们的核心竞争力 |
| 5 | **放风是看守所保底** | 刻意低效，不与调查对比性价比 |
| 6 | **仅基础资源获取消耗版图资源** | 其他操作消耗的资源回流供应堆，不消耗版图存量 |
| 7 | **不出现已删除的内容** | 不对比前版本，不使用"修正/错误/撤回"等表述 |
| 8 | **KSA 频率预期** | 0 特殊能力下各等级/路线的 KSA 次数应有合理差异（低等级保护下频率稳定，高等级爆发时频率低但单次高） |
| 9 | **隐藏/防御值与等级正相关** | 等级越高则防御越强。低等级易被抓，高等级难被抓 |
| 10 | **被捕次数预期** | 不同等级在被捕概率和被捕损失上应有合理梯度 |
| 11 | **资源耗竭可预测** | 有限资源应在可预测的节奏下消耗 |
| 12 | **操作成本不应跳跃式变化** | 从资源充裕到耗尽的过程中，操作成本应平滑过渡 |
| 13 | **资源/Token 链完整** | 从产生→消耗→回收的全链路必须闭环 |
| 14 | **交叉组合不超预期** | 特殊能力+环境+特殊手段的任意组合不应大幅超出各自单独效果的收益 |
| 15 | **策略多样性** | 不应存在对所有玩家都最优的同一个"必胜策略" |
| 16 | **非对称阵营补偿合理** | 不具有基础得分手段的阵营，其特殊能力应能弥补基础得分缺口 |
| 17 | **技能描述简短** | 技能/效果是卡面印刷文字，以"一张卡片能否容纳"为评价标准。边界定义归口 FAQ 或规则书正文，不写入技能描述（见 §1.7） |

## 6. 量化计算自查清单

> 每次出具 r02~r04 的计算结果前，逐项自查。任何一项不满足，必须修正计算后再产出。

### 资源与行动力

- [ ] 每回合资源是否用满（2 行动 + 1 手牌 = 3 资源），未用满时是否说明原因
- [ ] 行动序列是否逐行动列出，未使用"每回合 1 行动"的简化推演
- [ ] **每回合是否附「行动去向清单」**（KSA / 调查 / 摸牌 / 状态性逐项注明），确保行动价值不被忽略
- [ ] 手牌按 1 资源计（如需偏离 1，是否说明理由）

### 成本拆分与记账口径

- [ ] 每项 KSA 是否按「行动占用 + 动态花费」分列，**行动是否在分母里**（禁止只算动态花费）
- [ ] 关键动态花费是否给了区间/曲线（非单点值）
- [ ] 是否区分首次成本与稳态成本
- [ ] 后续操作成本是否基于上一行动后的版图状态（未回退初始值）
- [ ] **准备轮是否对双方统一口径**（警长侦查/抓捕链与罪犯压点链同一拆分标准，禁止一方摊进执行轮、另一方稀释）

### 资源分类

- [ ] 资源转换（调查/摸牌）与资源→IV 投入（KSA）是否分开统计
- [ ] 调查/摸牌是否未直接记入"分/资源"分母（但必须能在准备轮/行动去向中核算）
- [ ] 状态性行动（布控/隐藏）是否作为机会成本单独分析
- [ ] 涉及手牌的长链（摸牌→出牌→效果）是否按实际步骤推演

### 作案回填与版图状态

- [ ] **作案是否确认了"回填 1'情报 Token'（地点情报值 +1）"**——每次作案后地点情报值递增，连续作案成本曲线已计入，未按"压 0 后 0 成本"的静态假设推演
- [ ] 流水账中地点情报值列是否体现作案后的回填（如 `0→1`），未照抄"作案不改变情报值"的旧口径
- [ ] 地点回填机制（火车站·流动人口、情报干扰、作案回填）是否逐轮纳入累计，未一次性折算

### KSA 与平衡轴

- [ ] **每个得分行动是否按 §2.4 标定行动占用**（独占型 2 行动 / 轻量型 1 行动），未擅自改占用、未把轻量型按独占型简化
- [ ] 是否输出「KSA 节奏审计」：KSA 次数、执行轮合计、准备轮合计、干扰轮合计、总周期轮数
- [ ] 各阵营达到 15 分的总轮次是否与 8-12 主基准对照（§3.7/§4.1）
- [ ] **轻量型 KSA（追偿/爆料）是否按频率加权**（执行轮与准备轮部分重叠），未按 1 次 = 1 轮错误简化

### 循环与口径

- [ ] 是否使用逐回合流水账模板（回合/行动/地点情报值/供给IC/行动占用/动态花费IC/情报余额/手牌余额/IV）
- [ ] 轮次效率分母是否含准备轮与不得分轮（完整周期轮数），并标注起算与周期长度
- [ ] 是否标注循环闭合性（完整循环区间 + 循环末状态与循环初可比；非闭合片段标注中断点）
- [ ] 是否附审计行（累计供给 / 累计行动占用 / 累计动态花费 / 累计 IV），核对"用多、用少、刚好"

### 调查双效

- [ ] 调查的"获得 1 情报 + 地点情报值 -1"双效应是否同时计入
- [ ] 罪犯的"调查降隐藏"与"补给阶段隐藏值 +1"回复是否同时计入（隐藏值逐轮变化已推演）

### 双维度效率与基准

- [ ] 是否同时报告分/资源（IV/IC，IC 含行动+动态）与分/轮（IV/IR，IR 含准备轮）两个指标
- [ ] 是否标注策略可持续性（可连续执行几轮 / 依赖的外部条件）
- [ ] **是否以 15 分终局线为准判定节奏**（未把"12 轮末满分"当目标）
- [ ] **是否使用了全局算术推导的"分/资源"硬基准数字**（禁止：分/资源仅作后验横向对比 + 与 KSA 节奏交叉验证）

### 含金量与跨方抑制

- [ ] **得分+剥夺型（抓捕/追偿）是否使用加权分**（§3.6）参与跨阵营对比，未与纯得分直接对减
- [ ] 加权系数是否注明适用场景（如等级 2 目标加权 1.33）
- [ ] 警长等压制方量化是否包含两部分（自身双效率 + 对被压制方的负面影响）
- [ ] 抑制量折算是否给出依据并附审计行（如布控 +2 情报 → 作案花费 +2 IC）
- [ ] **触发率（和平奖励/追偿/爆料命中）是否独立推演**，未作为预设输入

### 参考锚定位

- [ ] **设计师定性估算是否仅作对照、未当预设结论**（§3.9）
- [ ] 量化与参考锚的偏差是否如实报告，由设计师判断（未为凑锚而调模型）

### 技能描述简短

- [ ] 发现的边界情况是否归口 FAQ 或规则书正文，未要求写入技能/效果描述（§1.7）
- [ ] 对需要大量边界说明的技能，是否优先指向"简化机制本身"而非"把说明写进卡面"
