# 罪恶都市 · AI Agent 工作流程

> 本文档为 AI agent 提供完整的、逐步执行的工作流程。
> 每次"推进"只执行一个原子任务，按 A → B → C → A → B → C ... 轮转。

---

## 核心规则

1. **一次只做一个任务**：每次"推进"只执行当前轮到方案的下一个未完成任务
2. **轮转顺序**：A → B → C → A → B → C ...（循环）
3. **不越界**：只处理当前任务，不提前处理后续任务
4. **进度记录**：每个任务完成后更新 `02-进度监控.md` 和 `03-任务执行记录.md`
5. **结果可验证**：每个任务产出明确的文档或文件
6. **🚨 硬性停机规则（AI agent 必须遵守）**：每次完成任务后，必须使用 `attempt_completion` 工具报告结果并**完全停止**，绝不可自行继续下一个任务、不可提前读取下一任务内容、不可翻阅下一轮方案资料。必须等待用户再次输入"推进"指令后再启动新一轮工作。

## 阶段 1：概念设计（每个方案独立进行）

> 每个方案独立完成本阶段所有任务。
> 轮转顺序：A1 → B1 → C1 → A2 → B2 → C2 ...

### 任务 1.1：原始点子

**目标**：给出方案的一句话概念、核心卖点、目标体验。

**输入**：

- 方案 A/C：基于用户的基本想法自由发挥
- 方案 B：参考 refs/initial-gpt.md

**产出**：`draft-1-X/01-原始点子.md`

**检查清单**：

- [ ] 一句话概念（30字以内）
- [ ] 核心卖点（3-5个关键词）
- [ ] 目标体验（玩家玩完后的感受）
- [ ] 与基本想法的关联说明

### 任务 1.2：核心机制设计

**目标**：定义游戏的核心循环、胜利条件、基本规则框架。

**产出**：`draft-1-X/02-核心机制.md`

**检查清单**：

- [ ] 核心游戏循环（玩家每回合做什么）
- [ ] 胜利条件（各阵营如何获胜）
- [ ] 基本规则框架
- [ ] 游戏时长与人数

### 任务 1.3：世界观与主题设定

**目标**：定义游戏的背景故事、城市设定、美术风格方向。

**产出**：`draft-1-X/03-世界观.md`

**检查清单**：

- [ ] 城市设定（地点、区域）
- [ ] 美术风格方向

**目标**：详细设计所有玩家角色和阵营的能力、目标。

**产出**：`draft-1-X/04-角色设计.md`

## 任务执行流程（AI agent 每次"推进"时遵循）

```
1. 读取 progress-1/03-任务执行记录.md
   → 确定当前轮到哪个方案（A/B/C）
   → 确定该方案下一个未完成的任务编号

2. 读取 progress-1/02-进度监控.md
   → 确认该任务的状态为"待执行"

3. 执行任务
   → 读取该方案已有文档（如有）
   → 生成任务产出文档
   → 写入对应目录

4. 更新进度
   → 更新 progress-1/02-进度监控.md（标记完成）
   → 更新 progress-1/03-任务执行记录.md（记录执行详情）

5. 报告完成并停机
   → 使用 attempt_completion 工具向用户报告任务完成
   → 🚨 必须完全停止，不可执行任何下一步工作
   → 不可读取下一任务内容，不可翻阅其他方案的资料
   → 等待用户下一次"推进"指令
```
