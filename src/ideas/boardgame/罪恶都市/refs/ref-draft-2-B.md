## 一句话概括设计哲学

> **纯卡牌驱动的警匪非对称对抗**——城市由卡牌构成，行动由卡牌驱动，差异由角色卡定义，胜负由资源管理决定。

---

## 核心机制脉络

### 1. 通用牌库原则（最重要的设计决策）

draft-2-B 在阶段 2 重构后确立了这一核心原则：**所有通用牌只有 1 个效果印在牌面上，对所有玩家相同**。角色和阵营的差异化通过角色卡上的 2-4 条能力规则实现。

- 9 种行动牌 + 3 种特殊牌 = 12 种牌型，每种 1 行效果文字
- 9 个角色共计约 25 条差异化规则
- 新手只需看牌面文字 + 自己的角色卡即可上手
- **解决了** "同一张牌在不同人手中效果不同"的记忆负担问题

### 2. 发展链条：罪犯发育 + 警长推理

**罪犯**：踩点（获取情报）→ 积累资源 → 犯罪（消耗情报）→ 收尾/隐藏

**警长**：巡逻布控 → 收集线索 → 推进嫌疑链 → 逮捕关押

两者形成对称博弈：罪犯的暴露度 ↔ 警长的嫌疑链。

### 3. 资源体系

| 资源 | 归属 | 用途 |
|------|------|------|
| 情报标记 | 罪犯 | 支付犯罪成本 |
| 赃物标记 | 罪犯 | 胜利条件计数 |
| 线索标记 | 警长 | 推进嫌疑链 |
| 暴露度 | 罪犯（0-5） | 越高越易被捕 |
| 行动力 | 警长 | 执行警长行动 |
| 声望 | 超级英雄 | 得分+行动消耗 |
| 影响力 | 受害者联盟 | 执行联盟行动 |
| 治安/民意/恐慌 | 公共 | 全局状态值 |

### 4. 胜负逻辑

**个人胜利条件制**——每个角色有独立的获胜条件（警长逮捕 2 罪犯/治安≥5，罪犯收集 N 赃物等），谁先达到谁赢。第 10 回合无人达成时走兜底判定。

### 5. 博弈结构

draft-2-B 的游戏流程经历了从"同时宣告→揭露"（阶段 1）到"警长先行→逆序出牌"（阶段 2）的转变：

- **准备阶段**：翻开事件牌，补牌
- **出牌阶段**：警长先行布控/埋伏，其他玩家逆序依次出牌选地点
- **揭露阶段**：按分数从低到高结算行动
- **调查阶段**：警长推进嫌疑链
- **结束阶段**：更新状态，检查胜利条件

### 6. 关键替代方案：犯罪成本制

犯罪**没有概率判定**，改为消耗情报标记作为"策划成本"。不同犯罪类型基础成本不同（盗窃 1、抢劫 2、杀人 3 情报），警长部署的警官牌增加成本。资源不足可用暴露度"赊账"。

## 关键设计亮点

| 亮点 | 说明 |
|------|------|
| **嫌疑链系统** | 5 级递进推理，第 5 级触发逮捕。不是获取信息，而是施加压力——增加罪犯成本、降低收益 |
| **犯罪成本替代概率** | 用资源消耗代替骰子判定，确定性策略深度 |
| **通用牌库统一化** | 一张牌只有 1 行效果，差异化在角色卡上集中定义，大幅降低学习成本 |
| **埋伏牌（Bluff）** | 警长面朝下放埋伏标记，其他玩家知其存在但不知区域，增加了 bluff 博弈 |
| **职业差异化设计** | 盗窃犯（低成本稳定）、抢劫犯（高收益高暴露）、杀人犯（越狱二阶段）、诈骗犯（远程+假线索）——各有鲜明的打法 |
| **关押不淘汰** | 逮捕后关押 1-2 回合而非出局，保留玩家参与感 |
| **禁止提前出局** | 所有行动都不让玩家出局，全程参与 |

## 设计教训和已知问题

以下来自两份评审文档（概念设计评审 + 详细设计评审），是方案 2-B 实际遇到的核心问题：

### 🔴 严重问题

1. **流程文档不一致**：05-游戏流程.md 与 08-规则书.md 描述不同的核心范式（同时宣告 vs 警长先行），导致"到底按哪套规则"的混乱
2. **出牌顺序造成后手信息优势**：逆序出牌使先手罪犯相当于盲猜，后手获得全信息——与期望的"先手必胜"相反
3. **胜利条件逻辑漏洞**：个人条件触发的终局结算流程存在矛盾——触发条件和兜底判定之间的逻辑不清晰
4. **系统过重**：5 阶段、3 个城市状态值、暴露度+嫌疑链+关押/越狱+虚拟罪犯——系统丰富，复杂度接近中策

### 🟡 中度问题

1. **嫌疑链 15 线索门槛偏高**：警长逮捕路径可能比治安值路径慢，导致警长实际只有一种可行策略
2. **赊账机制的风险**：暴露度抵冲资源可能导致"零情报积累、全赊账"策略，使踩点失去意义
3. **超英/受害者体验过弱**：仅在 5 人局可用，且胜率估算偏低（受害者联盟可能低于 5%）
4. **诈骗犯假线索可能无效**：警长试一次就能识破，持续干扰效果弱
5. **警长行动力追踪**：规则书中行动力消耗与获取之间的物理操作方式不明确

### 🟢 轻微问题

1. **同名地点牌规则矛盾**：×2 的牌与"同种地点不会同时出现 2 张"的规则冲突
2. **事件牌出现频率不均**：部分事件（E-09/E-10）几乎永远不会出现
3. **地点牌尺寸**：63×88mm 上叠加多个 token 会拥挤

## 可以借鉴但不应照搬的思路

以下是从 draft-2-B 中提取的、"好的方向但不应原样复制"的设计思路：

### ✅ 值得继承的设计方向

| 方向 | 建议的优化方式 |
|------|--------------|
| **通用牌库原则** | 继续保持"1 张牌 = 1 个效果"，差异化在角色卡上。但可精简牌型种类（draft-2-B 有 12 种，或许可以减到 8-10 种） |
| **犯罪成本制（无概率）** | 保留。用资源管理替代运气是优秀方向 |
| **嫌疑链系统** | 保留推理追捕的核心体验。但门槛可降低（如 5 级 10 线索而非 15） |
| **关押不淘汰** | 保留。确保所有玩家全程参与 |
| **罪犯发育链条** | 保留。踩点→犯罪→收尾的闭环体验优秀 |
| **埋伏/Bluff 元素** | 保留面朝下部署的 bluff 博弈，但要确保警长的信息优势有合理的边界 |

### ❌ 需要避免的问题

| 问题 | 避免方式 |
|------|---------|
| **流程范式冲突** | 一开始就确定统一的流程范式，在阶段 1 就写入 05-游戏流程.md |
| **子系统过多** | 精简到 3-4 个子系统（如犯罪成本、嫌疑链、暴露度），合并或裁减城市三值系统 |
| **后手信息优势** | 设计出牌顺序时考虑公平性（如分数顺序出牌替代固定逆序，或同时出牌） |
| **数值门槛不合理** | 胜利条件门槛不可过高，确保所有阵营有合理的达成路径 |
| **文档不一致** | 所有文档描述同一个游戏，阶段切换时更新旧文档 |

### 💡 可以探索的新方向

| 方向 | 说明 |
|------|------|
| **更简洁的流程** | 3 阶段而非 5 阶段（如出牌→揭露→结算），降低每回合操作量 |
| **更少的全局状态值** | 合并治安/民意/恐慌为 1-2 个值，或完全取消仅保留分数 |
| **更强的阵营冲突** | 增加罪犯之间的直接对抗（draft-2-B 罪犯之间几乎没有交互） |
| **更直观的地名牌操作** | 改善地点牌上 token 叠放的物理操作体验 |
| **超英/受害者在 4 人局可用** | 让第三方阵营在基准配置中就能被体验 |

---

## 总结

draft-2-B 是一个**系统完整性极高**的设计方案，复杂度介于轻策与中策之间。它的核心创新——通用牌库统一效果、犯罪成本替代概率、嫌疑链推理——都是优秀的。但它的执行层面存在流程不一致、子系统过多、出牌顺序公平性等关键缺陷。

方案 A 应**继承其设计方向（通用牌库、资源驱动的犯罪、推理追捕），但规避其执行陷阱（流程不一致、子系统过多、出牌顺序公平性）**，在轻中策的框架内实现清晰的警匪博弈体验。
