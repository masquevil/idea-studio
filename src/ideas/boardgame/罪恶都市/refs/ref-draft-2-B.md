## 一句话概括设计哲学

> **通用牌库统一效果 + 角色卡承载差异化 + 无概率的资源管理犯罪 = 纯卡牌驱动的警匪非对称对抗**。城市由地点牌构成，行动由卡牌驱动，差异由角色卡定义，胜负由资源规划决定。

---

## 核心机制脉络

### 1. 通用牌库统一化

所有通用牌只有 1 个效果印在牌面上，对所有玩家完全相同。角色和阵营的差异化通过角色卡上的 2-4 条能力规则实现。

- 9 种行动牌（G-01~G-09）+ 3 种特殊牌（S-01~S-03）= 12 种牌型，每种牌面上只印 1 行效果文字
- 所有玩家（警长、任何罪犯、超级英雄、受害者联盟）打出同一张牌时，效果文字完全相同
- 差异化来源：每张角色卡上有 2-4 条"角色能力"规则
- 新手只需看牌面文字 + 自己的角色卡即可上手
- 本局摘要卡（SUM-01）双面印刷，提供所有角色的能力速查

### 2. 游戏流程

5 阶段回合结构：

```
① 准备阶段：翻开 1 张事件牌，所有玩家摸 2 张牌
② 出牌阶段：警长先行（巡逻/部署/埋伏），其他玩家逆序出牌选地点
③ 结算阶段：按分数从低到高依次结算每位玩家的行动
④ 调查阶段（警长专属）：收集线索，推进嫌疑链，逮捕关押
⑤ 结束阶段：清除临时效果，更新状态值，检查胜利条件
```

### 3. 资源体系

| 资源 | 归属 | 用途 |
|------|------|------|
| 情报标记（紫色） | 罪犯通用 | 支付犯罪成本、越狱消耗 |
| 赃物标记（金色） | 罪犯通用 | 得分计数，达数量目标获胜 |
| 暴露度（红色，0-5） | 罪犯各人 | 越高警长推进嫌疑链越容易，≥5 时可直接被捕 |
| 线索标记（蓝色） | 全局/警长专用 | 犯罪后在地点留下，警长收集用于推进嫌疑链 |
| 行动力 | 警长 | 执行巡逻/部署/调查/逮捕 |
| 警官牌 | 警长专属牌池 | 部署到地点增加犯罪成本 |
| 声望值 | 超级英雄 | 用于出击/私刑，达到目标值获胜 |
| 影响力 | 受害者联盟 | 用于舆论/游行/复仇 |
| 治安值（全局，初始 10） | 全局 | 影响警长行动力和终局判定 |
| 民意值（全局，初始 5） | 全局 | 影响警长行动力和逮捕效率 |
| 恐慌值（全局，初始 0） | 全局 | 达到 10 时游戏立即结束 |

### 4. 犯罪成本机制（替代概率判定）

犯罪行动**没有概率判定**，改为消耗情报标记作为"策划成本"：

| 犯罪类型 | 基础成本 | 基础收益 | 暴露度增加 |
|----------|---------|---------|-----------|
| 盗窃 | 1 情报 | 1 赃物 + 1 分 | +1 |
| 抢劫 | 2 情报 | 2 赃物 + 2 分 | +2 |
| 行凶（杀人） | 3 情报 | 3 分 + 恐慌值 +2 | +3 |
| 诈骗 | 1 情报 | 1 分 + 1 假线索 | +0~+1 |
| 贩毒 | 2 情报 | 2 赃物 + 1 分 | +1~+2 |

成本调整因素：巡警在场（+1）、特警在场（+2）、地点警戒值（每级+1）、罪犯嫌疑链 Lv.3+（+1）、事件牌影响（如暴雨+1）。

资源不足时可"赊账"：1 暴露度抵 1 情报，但暴露度加倍上升（赊 1 情报 → 暴露度 +2）。

### 5. 嫌疑链系统

警长通过消耗线索标记推进对某个罪犯的嫌疑等级：

| 嫌疑等级 | 需要累计线索 | 对罪犯的影响 |
|----------|------------|-------------|
| 1 级 | 3 个 | —（开始关注） |
| 2 级 | 3 个（累计 6） | — |
| 3 级 | 3 个（累计 9） | 犯罪成本 +1 情报，收益 -1 |
| 4 级 | 3 个（累计 12） | 犯罪成本 +2 情报，收益 -1 |
| 5 级 | 3 个（累计 15） | 可直接逮捕（关押 1-2 回合） |

### 6. 关押与越狱

- 逮捕不淘汰玩家：改为**关押 1-2 回合**
- 关押期间：罪犯不能行动，跳过回合
- 警长的收益：逮捕时一次性 +2 分，关押期间每回合 +1 分
- 越狱（杀人犯专属技能）：消耗 3 情报 + 1 张"金蝉脱壳"牌，越狱后暴露度 +2
- 暴力越狱（可选）：不消耗资源，但暴露度 +4

### 7. 胜负逻辑

每个角色有独立的胜利条件，满足条件即触发终局结算：

| 阵营 | 胜利条件 |
|------|----------|
| **警长** | 逮捕 2 名不同罪犯，或治安值 ≥5 至第 10 回合结束 |
| **盗窃犯** | 获得 8 赃物 |
| **抢劫犯** | 获得 8 赃物 |
| **杀人犯** | 获得 6 赃物 + 至少 1 次被捕后越狱 |
| **诈骗犯** | 获得 5 赃物 + 5 情报 |
| **暗影侠（超英）** | 声望 ≥15 |
| **夜鹰（超英）** | 声望 ≥12 + 协助警长逮捕至少 1 名罪犯 |
| **民权领袖（受害者）** | 影响力 ≥10 + 治安值 ≤3 |
| **调查记者（受害者）** | 影响力 ≥8 + 成功揭露至少 2 名罪犯 |

第 10 回合结束时若无人达成，则按治安值兜底判定（治安值 ≥8 警长胜，≤3 罪犯中分数最高者胜，4-7 分数最高者胜）。

### 8. 角色与阵营体系

**警长（1 人，固定）**：

- 资源：行动力（受民意值影响：4/3/2/1 每回合）
- 核心行动：巡逻布控（消耗 1 行动力指定地点警戒值+1）、部署警官（消耗 1 行动力 + 警官牌）、推进嫌疑链（消耗线索标记）、逮捕（消耗 2 行动力）
- 胜利条件（双路径）：逮捕 2 名不同罪犯，或治安值 ≥5 至第 10 回合结束

**罪犯（1-4 人，4 种职业）**：

| 职业 | 定位 | 核心能力 | 暴露风险 | 最佳地点 |
|------|------|---------|---------|---------|
| 盗窃犯 | 稳定型，每回合持续收入 | 上城区犯罪成本 -1 情报，踩点额外 +1 情报 | 低 | 商业街、银行 |
| 抢劫犯 | 爆发型，单次高收益高暴露 | 市中心犯罪收益 +1 赃物，通缉额外 +1 暴露 | 高 | 银行、赌场 |
| 杀人犯 | 极端型，高得分+越狱二阶段 | 下城区犯罪不增暴露，可越狱 | 极高 | 贫民区、公园 |
| 诈骗犯 | 干扰型，远程安全犯罪 | 犯罪不留线索，制造假线索，收尾可清线索 | 极低 | 网络中心、大学 |

**超级英雄（0-1 人，5 人或以上）**：

- 暗影侠：每回合 3 声望，出击阻止犯罪，私刑夺取资源
- 夜鹰：每回合 2 声望+协助逮捕，鹰眼获取信息，追踪精确到人
- 堕落路线：恐慌值 ≥6 且使用私刑后变为"义警"

**受害者联盟（0-1 人，5 人或以上）**：

- 民权领袖：每回合 2 影响力，舆论降低民意值，游行降低治安值
- 调查记者：每回合 1 影响力，独家新闻揭晓行动，爆料加暴露度

### 9. 地点与城市系统

- 地点牌池：22 张（每局随机抽 12 张，3×4 排列）
- 四大区域：上城区、市中心、下城区、边缘区
- 每张地名牌有：警戒值（0-3）、收益星级（☆~★★★★）、特殊效果、线索类型
- 城市三值状态轨道：治安值（初始 10）、民意值（初始 5）、恐慌值（初始 0）
- 每个地点上的 Token 操作是唯一的信息载体

## 关键设计亮点与可取之处

| 亮点 | 说明 | 可借鉴程度 |
|------|------|-----------|
| **通用牌库统一化原则** | 每张牌只有 1 个效果印在牌面，差异化集中在角色卡上。极大降低学习成本 | 强烈推荐继承 |
| **犯罪成本替代概率** | 用资源消耗代替骰子判定，确定性策略深度 | 强烈推荐继承 |
| **嫌疑链系统** | 5 级递进推理，不是获取信息而是"施加压力"——增加犯罪成本、降低收益 | 推荐继承，数值门槛需调整 |
| **关押不淘汰** | 逮捕后关押 1-2 回合而非出局，保留玩家参与感 | 强烈推荐继承 |
| **禁止提前出局原则** | 任何行动都不让玩家出局，全程参与 | 应作为基本设计原则 |
| **埋伏牌 Bluff 元素** | 警长面朝下放埋伏标记，其他玩家知其存在但不知区域 | 推荐继承 |
| **罪犯发育链条** | 踩点→积累→犯罪→收尾，完整的成长弧线 | 推荐继承 |
| **罪犯职业差异化** | 4 种职业各有鲜明的打法（盗窃稳定、抢劫爆发、杀人极端、诈骗干扰） | 差异化方向好，可选方案可精简或增删 |
| **警长双胜利路径** | 逮捕路径（进攻性）和治安路径（防守性）提供策略选择 | 推荐 |
| **本局摘要卡设计** | 双面印刷速查卡，降低所有玩家的记忆负担 | 值得复制 |
| **事件牌对全局的节奏控制** | 每回合 1 张事件牌改变全局环境，防止流程僵化 | 推荐 |
| **黑帮老大被移除** | 移除了"命令其他罪犯"的职业，避免强制队友的负面体验 | 正确的设计决策 |

## 已知设计问题

### 🔴 严重问题

1. **出牌顺序造成后手信息优势**："警长先行→逆序出牌"模式使后手罪犯获得全信息优势，先手罪犯几乎是在盲猜。
2. **胜利条件逻辑漏洞**："达到个人条件→立即结束"与"触发终局后先检查警长"的顺序矛盾。若盗窃犯达到 8 赃物，按前者应立即获胜，按后者还要等警长先检查条件。
3. **系统较重**：11 种资源/状态值、5 阶段回合结构、4-6 个子系统，实际复杂度接近中策。预估游戏时长 80-150 分钟。

### 🟡 中度问题

1. **嫌疑链 15 线索门槛偏高**：每级 3 线索 × 5 级 = 15 线索，警长每回合最多收集 2-3 线索。理论最快第 5-6 回合完成嫌疑链，但此时罪犯可能已接近胜利条件。
2. **赊账机制可能导致资源管理策略坍塌**："1 暴露度 = 1 情报（暴露度加倍上升）"可能导致罪犯完全放弃踩点，全凭赊账犯罪。
3. **超级英雄和受害者联盟在 5 人或以上可用**：丰富的第三方设计在 4 人基准配置中也可替换使用。
4. **诈骗犯的假线索可能低效**：警长消耗 3 假线索推进嫌疑链时才发现是假的——如果警长已通过其他方式怀疑某人是诈骗犯，假线索的干扰作用就很有限。
5. **警长行动力追踪不明确**：行动力消耗与获取之间的物理操作方式不明确。

### 🟢 轻微问题

1. **同名地点牌规则矛盾**：22 张地点牌中有银行×2、商业街×2 等重复，但规则说"同种地点不会同时出现 2 张"。
2. **事件牌出现频率不均**：E-09（街头火拼）×1 和 E-10（神秘访客）×1 几乎永远不会出现，而 E-01（月黑风高）×3 和 E-02（全城警戒）×3 几乎每局必出。

## 可以借鉴但不应照搬的思路

### ✅ 值得继承的设计方向

| 方向 | 建议的优化方式 |
|------|--------------|
| **通用牌库统一化** | 继承"每张牌 1 个效果 + 角色卡差异化"原则。牌型种类可精简 |
| **犯罪成本制（无概率）** | 完全继承。以资源管理替代运气的方向正确 |
| **嫌疑链系统** | 保留"推理→施压→逮捕"体验。可降低门槛（如 5 级 10 线索而非 15） |
| **关押不淘汰** | 完全继承 |
| **罪犯发育链条** | 保留踩点→犯罪→收尾闭环。可简化资源体系 |
| **埋伏/Bluff 元素** | 保留面朝下部署的 bluff 博弈 |
| **限制子系统数量** | 控制在 3-4 个子系统以内，避免膨胀 |

### ❌ 需要避免的问题

| 问题 | 避免方式 |
|------|---------|
| **子系统过多** | 控制在 3-4 个以内 |
| **后手信息优势** | 分数顺序出牌（低分先出，高分后出信息多）或同时出牌 |
| **数值门槛不合理** | 确保所有阵营有合理的达成路径 |
| **胜利条件逻辑矛盾** | "触发即赢"模式，不可混用 |
| **超英/受害者仅在 5 人或以上可用** | 让第三方阵营在 4 人基准配置中也可体验 |
| **赊账无限制** | 必须设置上限（如每回合最多赊 1 情报） |

### 💡 可以探索的新方向

| 方向 | 说明 |
|------|------|
| **更简洁的回合流程** | 3 阶段（出牌→结算→结束），降低每回合操作量 |
| **合并全局状态值** | 将治安/民意/恐慌 3 值合并为 1-2 个值 |
| **加强罪犯之间的直接对抗** | 探索"抢地点"、"破坏对手犯罪"等直接冲突 |
| **更清晰的地名牌物理操作** | 解决多个 token 叠放拥挤的问题 |
| **事件牌平衡出现率** | 所有事件牌至少 2 张，确保特殊事件常见 |
| **更简单的胜利条件** | 跑分制或简洁的个人条件制 |
