# 桌游设计经验总结

> 记录于罪恶都市方案 B（draft-2-B）推进过程中的设计决策。
> 供未来桌游项目参考。

---

## 1. 通用牌库的正确实现方式

**核心原则**：每张牌只有 1 个效果印在牌面上，对所有玩家相同。

- 牌的效果文字简洁，直接印在牌上，任何人抽到都一样用
- 阵营和角色之间的差异化**不写在牌上**，而是写在角色卡上
- 每个角色卡上有 2-4 条能力规则，与通用牌交互产生不同效果

**物理实现**：玩家只需看牌上的字 + 自己角色卡上的规则，即可上手。

---

## 2. 卡牌操作方式

**打牌→弃牌堆，在地点标记上体现行动。**

- 玩家打出一张牌，直接进入弃牌堆，不在桌面上停留
- 行动结果通过在地点旁放置/修改标记来体现
  - 踩点 → 在地点放 1 个情报标记
  - 布控 → 在地点放 1 个防御标记
  - 犯罪 → 不放标记（线索在结算阶段才放）
  - 调查/潜伏等无地点影响的牌 → 不放标记
- 所有人巡场看一眼各地点上的标记，即可知道当前局势
- 口头说明仅辅助，实际信息全在标记上

---

## 3. 警长先行 + 埋伏设计

警长先于所有玩家行动，为游戏创造核心信息不对称。

**公开行动**（所有玩家可见）：

- 巡逻布控：消耗行动力，在指定地点放置防御标记
- 部署警官：消耗行动力，将警官牌打出→弃牌堆，在指定地点放对应标记

**隐藏行动**（仅警长可见）：

- 埋伏：打出埋伏牌→弃牌堆，面朝下放埋伏标记在自己面前
- 其他玩家知道警长埋伏了，但不知埋伏在哪个区域
- 埋伏分区域版本（上城区/市中心/下城区/边缘区）
- 结算阶段触发：该区域有犯罪则自动失败，没犯罪则浪费

**效果**：警长需要预判罪犯动向，罪犯需要在"赌警长没埋伏这个区域"和"避开热门区域"之间权衡。

---

## 4. 角色能力的物理可实现性

每个角色能力必须能用以下物理操作完成，不能出现需要"记住"或"追踪"的隐式状态：

**可用的物理操作**：

- 拿/放/移动标记（Token）
- 看牌（自己的手牌、别人的手牌、牌库顶部）
- 数数量（标记总数）
- 在轨道上移动指示物
- 宣告目标（口头说出地点和牌名）

**不可行的设计**（避免）：

- ❌ "知晓标记所属玩家"——标记上没有标签，无法物理实现
- ❌ "不暴露目标地点"——不选地点就无法博弈，选了地点又说"没暴露"自相矛盾
- ❌ 需要额外记录的状态（如"某玩家上次去过哪"）

**示例**：诈骗犯"不留痕迹"= 犯罪后不在地点放置线索标记。警长可通过该地点无线索推断这里有过诈骗犯活动，但无法通过线索追踪具体是谁。

---

## 5. 摸牌规则

**每回合固定摸 2 张，而不是补满。**

- 手牌通过"消耗 2 张 → 补 2 张"的自然节奏流转
- 手牌上限（默认 5 张）只做弃牌限制，不做补牌依据
- "潜伏"和"线人"牌可额外摸牌，让摸牌成为有意义的行动选择而非白送

---

## 6. 术语惯例

| 使用 | 避免 |
|------|------|
| 出牌阶段 | 宣告阶段 |
| 打出一张牌 | 宣告行动 |
| 选择目标地点 | 宣告目标 |
| 结算阶段 | 揭露阶段 |
| 结束阶段 | 结算阶段（歧义） |
| 后出牌的玩家 | 后宣告的玩家 |

---

## 7. Token 体系设计

Token 种类控制在 10 种以内，每种配一种颜色，用途明确：

| 颜色 | Token | 用途 |
|------|-------|------|
| 蓝色 | 线索标记 | 犯罪后在地点留下，警长收集 |
| 紫色 | 情报标记 | 罪犯资源，支付犯罪成本 |
| 金色 | 赃物标记 | 罪犯得分 |
| 灰色 | 踩点标记 | 标记罪犯已踩点的地点 |
| 红色 | 暴露度标记 | 每名罪犯 1 个，记录暴露等级 |
| 橙色 | 防御标记 | 布控/巡逻放置，回合结束移除 |
| （多色） | 埋伏标记 | 警长面朝下放在自己面前 |
