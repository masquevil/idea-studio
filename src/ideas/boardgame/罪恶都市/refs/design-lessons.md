# 桌游设计经验总结

> 记录于罪恶都市方案 B（draft-2-B）推进过程中的设计决策。
> 供未来桌游项目参考。

---

## 1. 通用牌库的正确实现方式

**核心原则**：每张牌只有 1 个效果印在牌面上，对所有玩家相同。

- 牌的效果文字简洁，直接印在牌上，任何人抽到都一样用
- 阵营和角色之间的差异化**不写在牌上**，而是写在角色卡上
- 每个角色卡上有 2-4 条能力规则，与通用牌交互产生不同效果

**物理实现**：玩家只需看牌上的字 + 自己角色卡上的规则，即可上手。

---

## 2. 卡牌操作方式

**打牌→弃牌堆，在地点标记上体现行动。**

- 玩家打出一张牌，直接进入弃牌堆，不在桌面上停留
- 行动结果通过在地点旁放置/修改标记来体现
  - 踩点 → 在地点放 1 个情报标记
  - 布控 → 在地点放 1 个防御标记
  - 犯罪 → 不放标记（线索在结算阶段才放）
  - 调查/潜伏等无地点影响的牌 → 不放标记
- 所有人巡场看一眼各地点上的标记，即可知道当前局势
- 口头说明仅辅助，实际信息全在标记上

---

## 3. 警长先行 + 埋伏设计

警长先于所有玩家行动，为游戏创造核心信息不对称。

**公开行动**（所有玩家可见）：

- 巡逻布控：消耗行动力，在指定地点放置防御标记
- 部署警官：消耗行动力，将警官牌打出→弃牌堆，在指定地点放对应标记

**隐藏行动**（仅警长可见）：

- 埋伏：打出埋伏牌→弃牌堆，面朝下放埋伏标记在自己面前
- 其他玩家知道警长埋伏了，但不知埋伏在哪个区域
- 埋伏分区域版本（上城区/市中心/下城区/边缘区）
- 结算阶段触发：该区域有犯罪则自动失败，没犯罪则浪费

**效果**：警长需要预判罪犯动向，罪犯需要在"赌警长没埋伏这个区域"和"避开热门区域"之间权衡。

---

## 4. 角色能力的物理可实现性

每个角色能力必须能用以下物理操作完成，不能出现需要"记住"或"追踪"的隐式状态：

**可用的物理操作**：

- 拿/放/移动标记（Token）
- 看牌（自己的手牌、别人的手牌、牌库顶部）
- 数数量（标记总数）
- 在轨道上移动指示物
- 宣告目标（口头说出地点和牌名）

**不可行的设计**（避免）：

- ❌ "知晓标记所属玩家"——标记上没有标签，无法物理实现
- ❌ "不暴露目标地点"——不选地点就无法博弈，选了地点又说"没暴露"自相矛盾
- ❌ 需要额外记录的状态（如"某玩家上次去过哪"）

**示例**：诈骗犯"不留痕迹"= 犯罪后不在地点放置线索标记。警长可通过该地点无线索推断这里有过诈骗犯活动，但无法通过线索追踪具体是谁。

---

## 5. 摸牌规则

**每回合固定摸 2 张，而不是补满。**

- 手牌通过"消耗 2 张 → 补 2 张"的自然节奏流转
- 手牌上限（默认 5 张）只做弃牌限制，不做补牌依据
- "潜伏"和"线人"牌可额外摸牌，让摸牌成为有意义的行动选择而非白送

---

## 6. 术语惯例

| 使用 | 避免 |
|------|------|
| 出牌阶段 | 宣告阶段 |
| 打出一张牌 | 宣告行动 |
| 选择目标地点 | 宣告目标 |
| 结算阶段 | 揭露阶段 |
| 结束阶段 | 结算阶段（歧义） |
| 后出牌的玩家 | 后宣告的玩家 |

## 7. Token 体系设计

Token 种类控制在 10 种以内，每种配一种颜色，用途明确：

| 颜色 | Token | 用途 |
|------|-------|------|
| 蓝色 | 线索标记 | 犯罪后在地点留下，警长收集 |
| 紫色 | 情报标记 | 罪犯资源，支付犯罪成本 |
| 金色 | 赃物标记 | 罪犯得分 |
| 灰色 | 踩点标记 | 标记罪犯已踩点的地点 |
| 红色 | 暴露度标记 | 每名罪犯 1 个，记录暴露等级 |
| 橙色 | 防御标记 | 布控/巡逻放置，回合结束移除 |
| （多色） | 埋伏标记 | 警长面朝下放在自己面前 |

## 8. Token 是通用资源系统

**核心观点**：Token 是资源而非单纯的"行动力"。出牌消耗 Token = 消耗资源。每回合通过某种方式补充，控制玩家每回合能做的事。

**关键设计要点**：

- Token 是真正的行动限制资源，手牌只是"选项池"——手牌决定你能做什么，Token 决定你能做几次
- Token 的补充方式**不一定非要是"补至上限"**。当前设计用补至上限，但如果发现不合理可改为其他方式（如固定补充 X 个、通过特定行动补充等）
- 出牌消耗 Token = 消耗资源，Token 上限决定了玩家每回合理论最大行动次数
- 这种设计让"限制行动次数"有了物理直观性：Token 池空了就是真空了，玩家能直接看到

**为什么手牌不能兼任行动限制**：

| 机制 | 问题 |
|------|------|
| "每回合只许出1张牌" | 太生硬，限制策略空间，叙事上不合理（一晚只能干一件事？） |
| "手牌多就能多出牌" | 导致囤牌玩法，手牌只增不减→通胀问题 |
| "出牌后摸牌保持手牌" | 每回合净增手牌→10回合23张→失去手牌管理意义 |

**Token 系统的优势**：

- 行动次数 = Token 数量（直观）
- Token 补充节奏可控，不和手牌数量挂钩
- 消耗掉的 Token 可作为其他交互的"产出"（见第9条双面Token）

## 9. 双面 Token 提高配件利用率并联动阵营

**核心观点**：同一 Token 两面不同用途——A面是消耗者自己的资源，B面消耗后成为其他阵营的资源或触发互动。减少了配件种类数，同时让"消耗"自动等于"产出"。

**设计模式**：

| Token | A面（资源态·己用） | B面（消耗态） | 交互方式 |
|-------|-----------------|-------------|---------|
| 罪犯线索 | 🟡 线索 | 🔴 **物证** | 放地点→警长收集翻回A面转为己用 |
| 警长行动力 | 🔵 行动力 | ⚪ **布控** | 放地点→该地点警戒值+1 |
| 超英精力 | 🟢 精力 | 🟢 [消耗] | 自产自销（仅提高利用率） |
| 受害者舆论 | 🟠 舆论 | 🟠 [消耗] | 自产自销（仅提高利用率） |

**核心价值**：

1. **提高配件利用率**：同一 Token 两面都有用，不是消耗了就变垃圾，而是翻面成为另一个状态继续参与游戏
2. **联动阵营**：罪犯的消耗变成警长的资源，警长的派驻影响地点的警戒值——"消耗"这个动作本身就自动产生了对其他阵营的影响力
3. **物理直观**：桌面上能看到"哪些地点被罪犯踩过""哪些地点被警长布控"——标记即是信息
4. **减少配件种类**：不需要额外生产"物证标记""布控标记"等——只需要对同一批 Token 翻面即可

**可选的延伸设计**：

- 罪犯 Token 的 B 面（物证）是否也可以被第三方（如超英、受害者）收集使用？
- 警长布控 Token 的 B 面是否可以被罪犯通过某些手段移除？
- 这些延伸可以进一步增加阵营间交互深度

## 10. 回合应个人独立完整闭环

**核心观点**：每个人的回合应独立完成摸牌→出牌→弃牌的完整闭环。禁止任何"所有玩家同时"的操作。

**正确结构**：

```
轮到玩家 X 的个人回合：
  ① 回合开始阶段（触发效果、翻事件牌）
  ② 补充 Token 阶段（个人资源）
  ③ 摸牌阶段（个人摸牌）
  ④ 出牌阶段（个人出牌）
  ⑤ 弃牌阶段（个人弃至上限）
  ⑥ 回合结束阶段（触发效果，轮到下一位）
```

**所有玩家依次执行完个人回合后**，才进入全局结算（如黎明结算）。

**为什么"所有玩家同时"是垃圾设计**：

| 问题 | 说明 |
|------|------|
| **失去回合归属感** | "轮到我的回合"是桌游的基本心理节奏，同时操作破坏这种感觉 |
| **执行混乱** | 谁先摸牌、谁先弃牌？真实桌游中"同时"几乎不可能真正同时执行 |
| **策略交互降低** | 后手玩家无法根据先手玩家的操作调整策略（因为同时进行） |
| **出牌顺序模糊** | 标准回合制的核心价值就是明确的先后顺序带来的信息不对称 |
