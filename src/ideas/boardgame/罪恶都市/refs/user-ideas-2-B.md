# 用户补充设计方向 · 方案 B（progress-2）

> 这些是用户提供的设计方向，subagent 在设计方案 B 时需要参考。
> 具体实现方式由设计师自行决定，不必照搬。

---

## 核心理念转变

方案 B 为**纯卡牌驱动的警匪游戏**——没有棋子移动，没有物理版图网格，所有功能通过卡牌实现。牌库**不分阵营**（通用牌库），但各角色通过不同的人物技能以不同方式使用卡牌。

---

## 1. 回合概念：每个回合 = 一个夜晚

- 游戏共 **10 个回合（10 个夜晚）**，4 人局时长 60-90 分钟
- 每个夜晚玩家通过出牌宣告自己的行动
- 出牌时必须指定目标地点（中央展示区的地名牌），行动期间视为玩家"在该地点活动"
- 行动完即离开（每个玩家行动顺序有先后）

## 2. 地点随机性（卡牌化）

- 每局游戏开始时，从地点牌池中随机抽取 **10-15 张（或更多）地点牌**
- 面朝上摆放在桌面中央，构成"城市版图"
- 地点之间的位置关系具有**区控逻辑**——某些卡牌效果可影响相邻或某个区域
- 确保每局城市布局不同，地点牌本身带有文字描述的特殊效果
- 地点牌持续存在，直到被特定卡牌效果移除/替换

## 3. NPC 系统（卡牌化）

- NPC 不再是物理 token，而是**手牌中的 NPC 卡牌**
- 玩家打出 NPC 卡牌时，卡牌上的文字描述决定效果
- NPC 卡牌效果与方案 A 类似，但方案 B 不设"创造场景"机制
- NPC 牌是一次性使用（打出后弃置）

## 4. 通用牌库 + 人物技能差异化

- **所有玩家共用同一牌库**，没有阵营专属牌
- 但不同角色（警长、罪犯、超级英雄、受害者联盟）拥有**不同的人物技能**
- 人物技能使同一张卡牌在不同角色手中产生不同效果
- 例如："线人"卡牌——警长打出可额外多抽一张牌，罪犯打出可隐藏身份

## 5. 罪犯发育思路（保留）

- 罪犯前期的核心行动是"踩点"——选择目标地点/目标人物进行侦查
- 踩点获得某种资源（如情报、工具、路线图等）
- 踩点会在该地点留下线索 token，供警长使用
- 后续在同一地点（或关联地点）犯罪时，可消耗前期积累的资源来提升成功率或收益
- 资源、线索、地点、卡牌之间的具体关系由设计师自行设计

## 6. 人数平衡规则

- 以 **1警长 vs 3罪犯** 为基准进行设计
- **2人局**（1警长 vs 1罪犯）：引入"虚拟罪犯"机制，自动按某种逻辑在地点放置线索 token，警长也可使用这些线索进行推理
- **3人局**（1警长 vs 2罪犯）：同样引入虚拟罪犯机制，补足至相当于 3 罪犯的线索产出
- 虚拟罪犯的行为逻辑由设计师自行定义（如固定模式/随机模式/简化规则）

## 7. Token 体系（尽可能简单）

所有 token 仅用于计数，无复杂逻辑：

| Token | 用途 | 形式建议 |
|-------|------|---------|
| **分数标记** | 每人一个，在计分轨道上移动 | 玩家棋子/立方体 |
| **线索标记** | 警长专用，计数用 | 小立方体/骰子 |
| **赃物标记** | 罪犯专用，计数用 | 小立方体/骰子 |
| **情报标记** | 通用资源，计数用 | 小立方体/骰子 |
| **踩点标记** | 罪犯放置在地名牌上的标记，代表已踩点 | 小圆片 token |

## 8. 与方案方向的融合

以上设计方向应融入方案 B 的"参考 refs/initial-gpt.md"方向中。特别是罪犯发育思路与 GPT 讨论中的"隐藏行动→线索→推理"链条结合，形成完整的前期踩点→中期犯罪→后期追捕的体验曲线。通用牌库+人物技能的设计让游戏更易上手，同时角色差异化体现在技能而非牌库上。

## 9. 设计调整记录（2026-07-24 用户反馈后追加）

> 以下为用户对 draft-2-2 初始版本提出的设计调整意见。

### 9.1 犯罪成功率改为资源成本机制

- **原设计**：犯罪有百分比成功率（40%-100%），成功/失败二元结果
- **调整后**：犯罪行动**无概率**，改为消耗**情报标记**作为"策划成本"
- 不同犯罪类型成本不同（盗窃=1情报，抢劫=2情报，杀人=3情报）
- 警长部署的警官牌**增加犯罪成本**（巡警→成本+1，特警→成本+2）
- 投入更多资源可获得额外收益（多花1情报→赃物+1）
- 资源不够时可"赊账"——用**暴露度**抵冲，但暴露度加倍上升
- **效果**：从"赌概率"变为"资源规划"，策略性更强

### 9.2 警长巡逻重设计

- **原设计**：巡逻获取该地点上一回合的玩家行动信息
- **调整后**：巡逻改为**主动布控**——选择一张地名牌，本回合该地点警戒值+1（犯罪成本+1），且若该地点有罪犯活动，罪犯暴露度额外+1
- **原因**：角色信息、行动信息本就是公开的，无需技能获取
- **效果**：巡逻变成"增加犯罪成本+逼迫暴露"的战术压制

### 9.3 警官牌派驻改为回合制

- **原设计**：警官牌部署后永久存在
- **调整后**：警官牌默认只持续**当前回合**（到下一回合警长行动阶段结束为止）
- 特殊警官卡可带"**持续**"关键词（需消耗额外行动力维持）
- **效果**：警长每回合需要做布防决策，动态博弈

### 9.4 调查重设计

- **原设计**：调查获取罪犯类型/暴露度/位置等公开信息
- **调整后**：调查改为推进**"嫌疑链"**——消耗线索标记推进对某罪犯的嫌疑等级
- 嫌疑链等级**增加该罪犯的犯罪成本**或**降低其收益**
- 嫌疑链5级时可直接发起逮捕
- **效果**：调查从"获取信息"变为"施加压力"

### 9.5 抓捕改为关押+越狱

- **原设计**：逮捕成功→罪犯**出局淘汰**
- **调整后**：逮捕成功→罪犯被**关押**（**1-2回合不能行动**）
- 警长从关押中获得持续得分（每回合+1分）
- 被关押罪犯可在自己的回合消耗资源（情报/赃物）"**越狱**"
- 越狱后暴露度+2（更容易被再次锁定）
- **效果**：控制但不淘汰，保留玩家参与感

### 9.6 跑分制——取消专属胜利直接结束

- **原设计**：各角色有专属胜利条件（如累计偷窃8赃物→直接获胜）
- **调整后**：**整体改为跑分游戏**，目标分数到达即结束（15-20分）
- 得分行为门槛较高：
  - 罪犯：成功犯罪得1-2分，需消耗情报+承担暴露风险
  - 警长：关押罪犯每回合+1分，逮捕时一次性+2分
  - 超级英雄：阻止犯罪+1分，媒体宣传累计声望
  - 受害者联盟：成功游行/复仇得分
- **对手可通过限制资源间接干预**：警长部署→罪犯成本↑收益↓；罪犯破坏→警长行动力↓

### 9.7 禁止玩家提前出局

- **原设计**：超级英雄"私刑"可直接击败罪犯，抓捕成功的罪犯直接出局
- **调整后**：**绝不让玩家提前出局旁观**
  - 超级英雄"出击"：阻止犯罪（罪犯本回合行动无效，损失已投入资源）
  - 超级英雄"私刑"：改为**夺取资源**（目标损失2情报/赃物，英雄得1声望）
  - 唯一无法行动的情况：被警长逮捕关押，但也是暂时的（1-2回合后可通过越狱恢复）
  - 被捕的罪犯**不会出局**，只是暂时被关押

### 9.8 卡牌不应有专属化

- 所有卡牌是公共可用的，对所有人效果相同或接近
- 如果有差异，那是人物技能的差异
- 不应有"盗窃"这种只有一个人能用的牌，也不应有任何角色"核心行动"的专属卡牌概念
