## 二、用户的核心判断标准（本轮新增/强化）

### 1. 出牌机制必须是正常回合制（🔴 硬约束）

| 要求 | 说明 |
|------|------|
| 每轮起始 | 警长先开始他的回合 |
| 回合结束后 | 顺时针下一位玩家开始自己的回合 |
| 核心原则 | 不要同时暗出，不要搞复杂，**回归标准回合制** |

**设计原则**：

- 所有玩家的行动是**轮流公开执行**的，不存在"暗出→揭示"的环节
- 警长先手有其主题意义（警长先部署，罪犯后行动），同时符合"警长=决策核心"的定位
- 此机制消除了用户之前在 progress-2 中批评的"猜拳感"和"运气成分"
- 消息顺序天然提供了信息：后手玩家能看到先手玩家做了什么

### 2. 角色技能数量控制在 1-3 条（两方案均适用）

| 原则 | 依据 |
|------|------|
| 过载阈值 | 超过 3 条角色技能会增加教学成本和认知负担 |
| 推荐范围 | 每个角色 1-3 条核心技能，其中 0-1 条为被动技能，1-2 条为主动技能 |
| 与卡牌的关系 | 角色技能"可以修改某些牌的效果"，但这种修改是**例外而非规则**。大部分情况下牌的效果就是写的那样 |

### 3. 牌的效果是固定的，技能是修饰器（两方案均适用）

用户纠正了"同牌不同效"的说法，正确的表述是：

> **牌的效果就是写在上面的那样，不会变。每个角色有技能，有些技能可以改变某张/某类牌的效果。**

这意味着：

- 通用牌的牌面文字对所有玩家**完全一致**
- 角色技能**选择性覆盖**部分牌的效果或增加额外效果
- 玩家不需要看别人手的角色技能来理解自己手里的牌

## 四、用户未明确说出的偏好判断（基于对话推断）

1. **所有机制必须有明确的"为什么"**——用户不接受"听上去很酷但说不清楚为什么好玩"的机制
2. **"正常的回合制"是底线**——不要为了创新而创新。如果"同时暗出"不能解决比标准回合制更明确的问题，那就用标准回合制
3. **技能和牌的关系要清晰**——牌是规则，技能是例外。技能只在特定条件下触发，80% 的情况下牌就是牌本身
4. **角色差异化要可观、可感**——两个角色的区别应该是玩家在看角色卡时就能直观看到的，而不是需要背下来的

## 六、对后续设计的核心指导

### 必须修改项（进入阶段 1r.3 前明确）

| 编号 | 修改项 | 影响范围 |
|------|--------|---------|
| 🔴-1 | **所有"同时暗出"机制改为标准回合制** | 方案 A 02-核心机制、05-游戏流程；方案 B 02-核心机制、05-游戏流程 |
| 🔴-2 | **每个角色技能数量约束为 1-3 条** | 方案 A 04-角色设计；方案 B 04-角色设计 |
| 🟡-3 | **方案表述修正：牌的效果固定，技能修改效果（两方案均适用）** | 方案 A 04-角色设计、02-核心机制；方案 B 02-核心机制中的表格和文案描述 |

### 修改方向建议

#### 回合制（替代同时暗出）

```
每回合流程（标准回合制）：

① 警长回合开始
   ├─ 警长出 1 张牌/执行 1 个行动（公开打出，所有人可见）
   ├─ 执行效果（布控/调查/逮捕等）
   └─ 警长回合结束

② 警长右手边第一位罪犯回合开始
   ├─ 该罪犯出 1 张牌/执行 1 个行动（公开打出）
   ├─ 执行效果（踩点/犯罪/转移等）
   └─ 回合结束，顺时针下一位

③ 所有人完成行动后 → 进入"结算阶段"
   ├─ 警长调查阶段（收集线索、推进嫌疑链）
   ├─ 全局状态更新（治安/恐慌变化）
   ├─ 持续性效果结算（关押、越狱等）
   └─ 检查胜利条件

④ 进入下一回合
```

#### 警长先手的主题意义

- 警长先手 → 模拟"警长巡逻布控在先"的叙事逻辑
- 罪犯后手 → 模拟"罪犯观察警长动向，选择作案时机"的叙事逻辑
- 信息优势：后手的罪犯能提前看到警长的部署，从而做出更明智的决定
- 这直接解决了 progress-2 中"没有信息支撑的决策"的批评

#### 角色技能 < 牌的效果

- 每个角色 **1 条主动技能 + 1 条被动技能**（部分角色可 2+1 或 1+2）
- 技能对牌效果的修改**必须有一个触发的条件或成本**，不能是无代价白嫖
- 例如：盗窃犯的"踩点高手"技能——不是"踩点牌变成另一个效果"，而是"踩点牌效果不变，额外+1 情报"

## 八、第二轮对话新增反馈（2026-07-25 · 推进 #8 反馈）

> 本轮对话在完成方案A第一轮修改后，用户看到了 G-02（犯罪）、G-06（布控）等阵营专属牌的设计，提出了批评意见。同时补充了角色设计的组织方式。

### 1. 🔴 硬约束：通用牌不能有身份专属牌

**用户原话**："G-02 和 G-06 不应该存在任何身份专用的牌，不然这个人摸到这张牌干啥，拿着扇风吗？"

**解读**：之前设计的行动类型表中存在阵营专属牌：

| 原牌 | 问题 | 解决方案 |
|------|------|---------|
| **G-02 犯罪** | 罪犯专属，警长/超英/受害者摸到无用 | **取消！** 罪犯通过"踩点牌+阵营技能"实现犯罪 |
| **G-06 布控** | 警长专属，罪犯/超英/受害者摸到无用 | **取消！** 警长通过"调查牌+阵营技能"实现布控 |

**核心原则**：牌库中**所有牌对所有玩家都有基本用途**，没有任何一张牌是"只有某个阵营才能用"的。策略性差异化统一由角色技能处理。

### 2. 🔴 硬约束：牌库结构要求

**用户原话**："通用牌库有点太少了，参考三国杀，应该有很多牌，牌有不同的类型，并且基础牌应该是明显多余其它牌的"

**要求**：

| 维度 | 要求 |
|------|------|
| **牌量** | 充足，约 95 张 |
| **基础牌占比** | 明显多于其他牌（≥80%） |
| **牌的类型** | 有不同的类型 |

**最终采用方案**（两层牌库）：

| 类型 | 牌名 | 数量 | 牌面效果（一行字） |
|------|------|------|-------------------|
| 🟦 **基础牌**（80张 / 84%） | 踩点 | ×30 | 获得1情报 |
| | 调查 | ×25 | 获得1线索 |
| | 转移 | ×15 | 移动目标地点 |
| | 潜伏 | ×10 | 本回合暴露度-1，免疫1次逮捕尝试 |
| 🟪 **特殊牌**（15张 / 16%） | 密谋 | ×5 | 获得2情报并摸1张牌 |
| | 追查 | ×5 | 获得2线索并查看1名玩家的手牌 |
| | 金蝉脱壳 | ×3 | 逃脱一次关押或针对效果 |
| | 孤注一掷 | ×2 | 弃所有手牌，每弃1张获得1分 |

**犯罪/布控等功能的实现方式**：不再需要专门的犯罪牌或布控牌，由角色技能处理：

- 罪犯出「踩点」牌 → 牌面效果"获得1情报" → 阵营技能"犯罪"：可改为执行一次犯罪行动
- 警长出「调查」牌 → 牌面效果"获得1线索" → 警长技能"部署权"：可改为执行布控行动

### 3. 🟡 角色技能组织方式：两层结构

**用户原话**："每个角色都是有名字的，比如警长，有警长A，警长B，罪犯也有罪犯A，罪犯B"

**设计**：

```
角色卡结构：
┌─────────────────────────────┐
│  [角色名]  [身份图标]       │
│                             │
│  🏷 阵营技能（该身份通用）   │
│  1. ××××××                 │
│  2. ××××××                 │
│                             │
│  🏷 专属技能（该角色独有）   │
│  1. ××××××                 │
│  2. ××××××                 │
└─────────────────────────────┘
```

**两层技能说明**：

| 层级 | 数量 | 说明 |
|------|------|------|
| **阵营技能** | 1-2 条 | 该身份所有角色共享，描述该阵营的核心操作能力（如：警长的"部署权"、罪犯的"犯罪"） |
| **专属技能** | 1-2 条 | 该角色独有的能力，区分同一身份下不同角色的风格（如：方振华"严打" vs 李敏"数据链"） |

**身份示例**：

| 身份 | 阵营技能 | 可选角色 | 各自专属技能 |
|------|---------|---------|-------------|
| 🕵️ **警长** | 部署权（行动力3/回合） | 方振华（铁腕型）、李敏（技术型） | 各有 1-2 条专属 |
| 🦹 **罪犯** | 犯罪（踩点→犯罪）、越狱 | 幽灵（杀人）、狐狸（诈骗）、老鼠（盗窃）、公牛（抢劫）、蛇（渗透） | 各有 1-2 条专属 |
| 🦸 **超英** | 夜巡（每回合+2声望）、出击 | 暗影侠 | 1-2 条专属 |
| 👥 **受害者** | 调查（每回合+1影响力）、爆料 | 林悦（记者） | 1-2 条专属 |

**总技能数量**：每个角色 = 阵营技能（1-2条）+ 专属技能（1-2条）= 总计 2-4 条。
⚠️ 用户之前要求的"角色技能 1-3 条"指的是**专属技能**部分。阵营技能是同一身份共享的，玩家看一次就知道，不增加个体记忆成本。

### 4. 角色设计替代职业分类

| 旧方案 | 新方案 |
|--------|--------|
| 罪犯按职业分类（盗窃犯/抢劫犯/杀人犯/诈骗犯各1个） | 罪犯按角色名区分（幽灵/狐狸/老鼠/公牛/蛇各1个），每个角色有专属技能对应其犯罪类型 |
| 每个罪犯角色2-3条技能混在一起 | 阵营技能（1-2条通用）+ 角色专属技能（1-2条区分风格） |

**新罪犯角色一览**：

| 名字 | 定位 | 专属技能1 | 专属技能2 |
|------|------|----------|----------|
| **"幽灵"** | 杀人·极端 | 致命一击：行凶犯罪+2分，但恐慌值额外+1 | 消失：在下城区犯罪不留线索 |
| **"狐狸"** | 诈骗·干扰 | 假情报：消耗1情报在某地点放置假线索 | 洗钱：诈骗所得+1赃物 |
| **"老鼠"** | 盗窃·稳定 | 轻手轻脚：踩点牌额外+1情报 | 安全通道：转移牌可跨1区域 |
| **"公牛"** | 抢劫·爆发 | 暴力突破：抢劫犯罪仅需1情报即可执行 | 皮糙肉厚：受警官部署影响-1犯罪成本 |
| **"蛇"** | 渗透·搜集 | 易容：每回合可用1情报改变目标地点 | 内应：可查看警长本回合行动 |

**新警长角色一览**：

| 名字 | 定位 | 专属技能1 | 专属技能2 |
|------|------|----------|----------|
| **方振华** | 铁腕压制 | 严打：逮捕时额外+1分 | 威慑：所在区域犯罪成本+1 |
| **李敏** | 技术追查 | 数据链：调查牌效果翻倍 | 精准抓捕：嫌疑链仅需2线索推进1级 |
