## 二、用户的核心判断标准（本轮新增/强化）

### 1. 出牌机制必须是正常回合制（🔴 硬约束）

| 要求 | 说明 |
|------|------|
| 每轮起始 | 警长先开始他的回合 |
| 回合结束后 | 顺时针下一位玩家开始自己的回合 |
| 核心原则 | 不要同时暗出，不要搞复杂，**回归标准回合制** |

**设计原则**：

- 所有玩家的行动是**轮流公开执行**的，不存在"暗出→揭示"的环节
- 警长先手有其主题意义（警长先部署，罪犯后行动），同时符合"警长=决策核心"的定位
- 此机制消除了用户之前在 progress-2 中批评的"猜拳感"和"运气成分"
- 消息顺序天然提供了信息：后手玩家能看到先手玩家做了什么

### 2. 角色技能数量控制在 1-3 条（两方案均适用）

| 原则 | 依据 |
|------|------|
| 过载阈值 | 超过 3 条角色技能会增加教学成本和认知负担 |
| 推荐范围 | 每个角色 1-3 条核心技能，其中 0-1 条为被动技能，1-2 条为主动技能 |
| 与卡牌的关系 | 角色技能"可以修改某些牌的效果"，但这种修改是**例外而非规则**。大部分情况下牌的效果就是写的那样 |

### 3. 牌的效果是固定的，技能是修饰器（两方案均适用）

用户纠正了"同牌不同效"的说法，正确的表述是：

> **牌的效果就是写在上面的那样，不会变。每个角色有技能，有些技能可以改变某张/某类牌的效果。**

这意味着：

- 通用牌的牌面文字对所有玩家**完全一致**
- 角色技能**选择性覆盖**部分牌的效果或增加额外效果
- 玩家不需要看别人手的角色技能来理解自己手里的牌

## 四、用户未明确说出的偏好判断（基于对话推断）

1. **所有机制必须有明确的"为什么"**——用户不接受"听上去很酷但说不清楚为什么好玩"的机制
2. **"正常的回合制"是底线**——不要为了创新而创新。如果"同时暗出"不能解决比标准回合制更明确的问题，那就用标准回合制
3. **技能和牌的关系要清晰**——牌是规则，技能是例外。技能只在特定条件下触发，80% 的情况下牌就是牌本身
4. **角色差异化要可观、可感**——两个角色的区别应该是玩家在看角色卡时就能直观看到的，而不是需要背下来的

## 六、对后续设计的核心指导

### 必须修改项（进入阶段 1r.3 前明确）

| 编号 | 修改项 | 影响范围 |
|------|--------|---------|
| 🔴-1 | **所有"同时暗出"机制改为标准回合制** | 方案 A 02-核心机制、05-游戏流程；方案 B 02-核心机制、05-游戏流程 |
| 🔴-2 | **每个角色技能数量约束为 1-3 条** | 方案 A 04-角色设计；方案 B 04-角色设计 |
| 🟡-3 | **方案表述修正：牌的效果固定，技能修改效果（两方案均适用）** | 方案 A 04-角色设计、02-核心机制；方案 B 02-核心机制中的表格和文案描述 |

### 修改方向建议

#### 回合制（替代同时暗出）

```
每回合流程（标准回合制）：

① 警长回合开始
   ├─ 警长出 1 张牌/执行 1 个行动（公开打出，所有人可见）
   ├─ 执行效果（布控/调查/逮捕等）
   └─ 警长回合结束

② 警长右手边第一位罪犯回合开始
   ├─ 该罪犯出 1 张牌/执行 1 个行动（公开打出）
   ├─ 执行效果（踩点/犯罪/转移等）
   └─ 回合结束，顺时针下一位

③ 所有人完成行动后 → 进入"结算阶段"
   ├─ 警长调查阶段（收集线索、推进嫌疑链）
   ├─ 全局状态更新（治安/恐慌变化）
   ├─ 持续性效果结算（关押、越狱等）
   └─ 检查胜利条件

④ 进入下一回合
```

#### 警长先手的主题意义

- 警长先手 → 模拟"警长巡逻布控在先"的叙事逻辑
- 罪犯后手 → 模拟"罪犯观察警长动向，选择作案时机"的叙事逻辑
- 信息优势：后手的罪犯能提前看到警长的部署，从而做出更明智的决定
- 这直接解决了 progress-2 中"没有信息支撑的决策"的批评

#### 角色技能 < 牌的效果

- 每个角色 **1 条主动技能 + 1 条被动技能**（部分角色可 2+1 或 1+2）
- 技能对牌效果的修改**必须有一个触发的条件或成本**，不能是无代价白嫖
- 例如：盗窃犯的"踩点高手"技能——不是"踩点牌变成另一个效果"，而是"踩点牌效果不变，额外+1 情报"

## 八、1d 阶段补充反馈（第二轮对话 · 推进 #8 反馈）

> 本轮对话在完成方案A第一轮修改后，用户看到了 G-02（犯罪）、G-06（布控）等阵营专属牌的设计，提出了批评意见。同时补充了角色设计的组织方式。

### 1. 🔴 硬约束：通用牌不能有身份专属牌

**用户原话**："G-02 和 G-06 不应该存在任何身份专用的牌，不然这个人摸到这张牌干啥，拿着扇风吗？"

**解读**：之前设计的行动类型表中存在阵营专属牌：

| 原牌 | 问题 | 解决方案 |
|------|------|---------|
| **G-02 犯罪** | 罪犯专属，警长/超英/受害者摸到无用 | **取消！** 罪犯通过"踩点牌+阵营技能"实现犯罪 |
| **G-06 布控** | 警长专属，罪犯/超英/受害者摸到无用 | **取消！** 警长通过"调查牌+阵营技能"实现布控 |

**核心原则**：牌库中**所有牌对所有玩家都有基本用途**，没有任何一张牌是"只有某个阵营才能用"的。策略性差异化统一由角色技能处理。

### 2. 🔴 硬约束：牌库结构要求

**用户原话**："通用牌库有点太少了，参考三国杀，应该有很多牌，牌有不同的类型，并且基础牌应该是明显多余其它牌的"

**要求**：

| 维度 | 要求 |
|------|------|
| **牌量** | 充足，约 95 张 |
| **基础牌占比** | 明显多于其他牌（≥80%） |
| **牌的类型** | 有不同的类型 |

### 3. 🟡 角色技能组织方式：两层结构

**用户原话**："每个角色都是有名字的，比如警长，有警长A，警长B，罪犯也有罪犯A，罪犯B"

**设计**：

```
角色卡结构：
┌─────────────────────────────┐
│  [角色名]  [身份图标]       │
│                             │
│  🏷 阵营技能（该身份通用）   │
│  1. ××××××                 │
│  2. ××××××                 │
│                             │
│  🏷 专属技能（该角色独有）   │
│  1. ××××××                 │
│  2. ××××××                 │
└─────────────────────────────┘
```

**两层技能说明**：

| 层级 | 数量 | 说明 |
|------|------|------|
| **阵营技能** | 1-2 条 | 该身份所有角色共享，描述该阵营的核心操作能力（如：警长的"部署权"、罪犯的"犯罪"） |
| **专属技能** | 1-2 条 | 该角色独有的能力，区分同一身份下不同角色的风格（如：方振华"严打" vs 李敏"数据链"） |

## 十、2r 阶段·第1轮：全面重构决策（推进 #23）

> 在方案 A 的详细设计评审（2r.1A）完成后，用户提出了对 Token 系统和整个资源体系的根本性质疑，导致了以下的全面重构。

### 核心决策：删除 Token 行动力系统

| 旧设计 | 新设计 |
|-------|-------|
| 4 种行动 Token（线索/行动力/精力/舆论） | ❌ **全部删除** |
| Token 上限 3-4 + 手牌上限 5 = 双重限制 | ✅ **仅剩手牌上限（5张）** |
| 出牌消耗 Token + 双面 Token 交互 | ✅ **出牌只受手牌数量限制** |

**理由**：手牌本身就限制了"一回合能做多少事"。Token 作为额外的行动次数限制是冗余的。既然有手牌上限（5张）+ 摸牌固定（2张/回合），手牌的流转本身就自然约束了行动频率。

### 新增：卡牌标签系统

所有卡牌增加**关键词标签**，类似炉石传说（嘲讽/冲锋/圣盾）和诡镇奇谈（闪电行动）：

| 标签 | 含义 | 效果 |
|------|------|------|
| **无标签（普通）** | 标准行动 | 每回合可出任意张 |
| **🏷️ 独特** | 大行动 | 本回合最多出 **1 张**带独特的牌 |
| **🏷️ 快速** | 反应行动 | 不受独特限制，可在独特前后自由使用 |

**代表叙事**：

| 标签 | 叙事含义 | 例子 |
|------|---------|------|
| **普通** | 日常操作（踩点、调查、密谋） | 一晚上可以反复踩点积累情报 |
| **独特** | 今晚只能干这一件"大事" | 犯罪、布控、逮捕、出击——做了就不能再做别的独特行动 |
| **快速** | 本能反应/小动作 | 潜伏（躲起来）、转移（拖延抓捕）、金蝉脱壳（紧急逃脱） |

### 简化：资源体系（你的四类配件框架）

| 类别 | 内容 | 说明 |
|------|------|------|
| **① 卡牌（随机性资源）** | 通用牌库约 95 张 | 每回合摸 2 张，手牌上限 5 |
| **② 资源型 Token** | 情报（唯一经济资源）+ 证据（地点上）+ 布控标记 + 暴露度 | 大幅简化，取消所有阵营专属 Token |
| **③ 版图（状态）** | 治安/恐慌轨道 + 计分轨道 + 嫌疑链面板 + 10 张地点牌 | 不变 |
| **④ 分数 Token** | 计分轨道直接标记 | 不变 |

### 关键决策：踩点和调查合并

**用户原话**："踩点就是调查，地点没有什么隐藏信息，都是公开的。"

合并为一种行动，同时引入差异化设计：

| 牌名 | 标签 | 效果 |
|------|------|------|
| **踩点**（普通） | 普通 | +1 情报 |
| **调查**（普通） | 普通 | +1 情报；若目标地点有物证则额外 +1 情报 |

踩点是稳定的经济来源，调查在有物证的地点能获得额外收益——鼓励罪犯去"有人踩过点"的地方活动。

### 关键决策：犯罪是阵营技能，不是牌

**用户原话**："犯罪是角色或者阵营技能吧，肯定不是牌啊。"

- 罪犯不需要摸到"犯罪牌"才能犯罪
- 犯罪是阵营技能，在出牌阶段声明即可——**带"独特"标签**
- 消耗情报获得分数，在地点留下证据 Token
- 证据 Token 是**公共资源**，警长可收集用于推进调查

### 关键决策：转移是"快速"行动（防御性）

**用户原话**："转移更像是一个反应动作，有点像三国杀的无懈可击。本身是不存在角色在地点上这一说的，因为就没有角色 Token。转移只是在你要被抓的时候，拖延一回合这种感觉。"

- 转移 = **快速** 标签
- 没有角色面板/角色在地点的概念
- 功能：防御性反制，在被逮捕/被针对时拖延一回合
- 类似无懈可击的定位——不占"独特"名额

### 关键决策：越狱双轨设计

**用户原话**："越狱是罪犯阵营都有的能力。如果摸到了少量的越狱牌（金蝉脱壳），可以消耗较少的资源提前越狱。"

| 方式 | 消耗 | 效果 |
|------|------|------|
| **基础越狱**（阵营技能·独特） | 3 情报 + 弃 1 张手牌 | 逃脱关押，暴露度 +2 |
| **牌辅助越狱**（有金蝉脱壳） | 1 张金蝉脱壳 + 1 情报 | 逃脱关押，暴露度 +2（便宜很多） |

- 越狱总是**可用的**（只要有资源），不会被"摸不到牌"卡死
- 金蝉脱壳让越狱大幅降价，体现了"摸到好牌"的价值

### 关键决策：情报是通用经济资源

所有阵营（包括警长）都需要情报：

| 阵营 | 情报用途 |
|------|---------|
| **罪犯** | 犯罪成本（不同犯罪消耗不同）、越狱成本 |
| **警长** | 布控（1情报）、推进嫌疑链（3情报/级） |
| **超英** | 出击所需的声望可通过情报加速积累（待定） |
| **受害者** | 爆料/游行可能消耗情报（待定） |

**情报的产生**：踩点 +1、调查 +1（有物证再 +1）、密谋 +2 并摸 1 张

**设计的竞争性**：警长和罪犯都需要情报，大家都要抢"踩点"和"调查"牌。

### 关键决策：地点交互逻辑

| 要素 | 规则 |
|------|------|
| **角色位置** | 不存在——没有角色 Token 在版图上移动 |
| **犯罪地点** | 罪犯执行犯罪时**声明目标地点**，将证据 Token 放到该地点 |
| **地点效果** | 警戒值影响犯罪成本，收益星级影响得分 |
| **布控** | 警长消耗情报将布控标记放到某地点，增加该地点犯罪成本 |
| **证据收集** | 警长黎明结算时从各地点上收集证据 Token |

### 用户确认的标签系统适用范围

**用户原话**："其他阵营一样，标签都是一致的，参考诡镇奇谈（有闪电行动这种东西）和炉石传说（嘲讽、浮空等）"

所有阵营的独特行动：

| 阵营 | 独特行动 | 说明 |
|------|---------|------|
| **罪犯** | 犯罪、越狱 | 犯罪得分+留证据，越狱逃脱关押 |
| **警长** | 布控、逮捕 | 布控增加地点成本，逮捕关押罪犯 |
| **超英** | 出击、私刑 | 阻止犯罪，惩戒罪犯 |
| **受害者** | 爆料、游行、媒体风暴 | 舆论攻击得分 |

## 附录：设计原则总结

### 核心设计哲学

1. **不要冗余机制**——Token 系统和手牌限制重复时，删 Token
2. **物理可实现性**——每个操作必须能用实体配件完成（拿/放/翻标记、看牌、数数量）
3. **一个资源一个作用**——情报是"钱"，证据是"线索"，不交叉
4. **标签代替繁杂规则**——普通/独特/快速 三标签覆盖所有行动限制
5. **继承经典**——参考炉石的关键词系统、诡镇奇谈的闪电行动、三国杀的手牌结构
