## 二、用户的核心判断标准（本轮新增/强化）

### 1. 出牌机制必须是正常回合制（🔴 硬约束）

| 要求 | 说明 |
|------|------|
| 每轮起始 | 警长先开始他的回合 |
| 回合结束后 | 顺时针下一位玩家开始自己的回合 |
| 核心原则 | 不要同时暗出，不要搞复杂，**回归标准回合制** |

**设计原则**：

- 所有玩家的行动是**轮流公开执行**的，不存在"暗出→揭示"的环节
- 警长先手有其主题意义（警长先部署，罪犯后行动），同时符合"警长=决策核心"的定位
- 此机制消除了用户之前在 progress-2 中批评的"猜拳感"和"运气成分"
- 消息顺序天然提供了信息：后手玩家能看到先手玩家做了什么

### 2. 角色技能数量控制在 1-3 条（两方案均适用）

| 原则 | 依据 |
|------|------|
| 过载阈值 | 超过 3 条角色技能会增加教学成本和认知负担 |
| 推荐范围 | 每个角色 1-3 条核心技能，其中 0-1 条为被动技能，1-2 条为主动技能 |
| 与卡牌的关系 | 角色技能"可以修改某些牌的效果"，但这种修改是**例外而非规则**。大部分情况下牌的效果就是写的那样 |

### 3. 牌的效果是固定的，技能是修饰器（两方案均适用）

用户纠正了"同牌不同效"的说法，正确的表述是：

> **牌的效果就是写在上面的那样，不会变。每个角色有技能，有些技能可以改变某张/某类牌的效果。**

这意味着：

- 通用牌的牌面文字对所有玩家**完全一致**
- 角色技能**选择性覆盖**部分牌的效果或增加额外效果
- 玩家不需要看别人手的角色技能来理解自己手里的牌

## 四、用户未明确说出的偏好判断（基于对话推断）

1. **所有机制必须有明确的"为什么"**——用户不接受"听上去很酷但说不清楚为什么好玩"的机制
2. **"正常的回合制"是底线**——不要为了创新而创新。如果"同时暗出"不能解决比标准回合制更明确的问题，那就用标准回合制
3. **技能和牌的关系要清晰**——牌是规则，技能是例外。技能只在特定条件下触发，80% 的情况下牌就是牌本身
4. **角色差异化要可观、可感**——两个角色的区别应该是玩家在看角色卡时就能直观看到的，而不是需要背下来的

## 六、对后续设计的核心指导

### 必须修改项（进入阶段 1r.3 前明确）

| 编号 | 修改项 | 影响范围 |
|------|--------|---------|
| 🔴-1 | **所有"同时暗出"机制改为标准回合制** | 方案 A 02-核心机制、05-游戏流程；方案 B 02-核心机制、05-游戏流程 |
| 🔴-2 | **每个角色技能数量约束为 1-3 条** | 方案 A 04-角色设计；方案 B 04-角色设计 |
| 🟡-3 | **方案表述修正：牌的效果固定，技能修改效果（两方案均适用）** | 方案 A 04-角色设计、02-核心机制；方案 B 02-核心机制中的表格和文案描述 |

### 修改方向建议

#### 回合制（替代同时暗出）

```
每回合流程（标准回合制）：

① 警长回合开始
   ├─ 警长出 1 张牌/执行 1 个行动（公开打出，所有人可见）
   ├─ 执行效果（布控/调查/逮捕等）
   └─ 警长回合结束

② 警长右手边第一位罪犯回合开始
   ├─ 该罪犯出 1 张牌/执行 1 个行动（公开打出）
   ├─ 执行效果（踩点/犯罪/转移等）
   └─ 回合结束，顺时针下一位

③ 所有人完成行动后 → 进入"结算阶段"
   ├─ 警长调查阶段（收集线索、推进嫌疑链）
   ├─ 全局状态更新（治安/恐慌变化）
   ├─ 持续性效果结算（关押、越狱等）
   └─ 检查胜利条件

④ 进入下一回合
```

#### 警长先手的主题意义

- 警长先手 → 模拟"警长巡逻布控在先"的叙事逻辑
- 罪犯后手 → 模拟"罪犯观察警长动向，选择作案时机"的叙事逻辑
- 信息优势：后手的罪犯能提前看到警长的部署，从而做出更明智的决定
- 这直接解决了 progress-2 中"没有信息支撑的决策"的批评

#### 角色技能 < 牌的效果

- 每个角色 **1 条主动技能 + 1 条被动技能**（部分角色可 2+1 或 1+2）
- 技能对牌效果的修改**必须有一个触发的条件或成本**，不能是无代价白嫖
- 例如：盗窃犯的"踩点高手"技能——不是"踩点牌变成另一个效果"，而是"踩点牌效果不变，额外+1 情报"

## 七、本次对话的关键纠正点

| 纠正点 | 旧理解（错误） | 新理解（正确） |
|--------|---------------|---------------|
| 出牌机制 | 同时暗出→低分先动揭示 | **标准回合制：警长先→顺时针轮流** |
| 角色技能数量 | 2-4 条 | **1-3 条** |
| 同牌不同效 | "同一张牌不同角色效果不同" | **"牌的效果固定，角色技能选择性改变牌的效果"（两方案均适用）** |
| 方案差异 | "两个方案看起来一样"需修正 | 没差异没关系，两方案独立设计，保持各自方向即可 |
