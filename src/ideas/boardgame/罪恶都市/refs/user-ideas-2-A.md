# 用户想法参考 · 方案 2-A

> 这些是用户提供的设计想法，可供各方案参考使用。
> 具体实现方式由设计师自行决定，不必照搬。

---

## 核心理念转变

方案 A 应为**纯卡牌驱动的德式轻策游戏**——没有棋子移动，没有物理版图网格，所有功能通过卡牌实现。

---

## 1. 回合概念：每个回合 = 一个夜晚

- 游戏共 **10 个回合（10 个夜晚）**，4 人局时长 60-90 分钟
- 每个夜晚玩家通过出牌宣告自己的行动
- 出牌时必须指定目标地点（中央展示区的地名牌），行动期间视为玩家"在该地点活动"
- 行动完即离开（每个玩家行动顺序有先后）

## 2. 地点随机性（卡牌化）

- 每局游戏开始时，从地点牌池中随机抽取 **10-15 张（或更多）地点牌**
- 面朝上摆放在桌面中央，构成"城市版图"
- 地点之间的位置关系具有**区控逻辑**——某些卡牌效果可影响相邻或某个区域
- 确保每局城市布局不同，地点牌本身带有文字描述的特殊效果
- 地点牌持续存在，直到被特定卡牌效果移除/替换

## 3. NPC 系统（卡牌化）

- NPC 不再是物理 token，而是**手牌中的 NPC 卡牌**
- 玩家打出 NPC 卡牌时，卡牌上的文字描述决定效果
- NPC 卡牌可能的效果方向：
  - 警长打出"目击者"→ 获得线索，指认某地点有犯罪活动
  - 罪犯打出"混混"→ 干扰警长，或获得额外赃物
  - 通用 NPC（线人、店主、政客等）→ 双方打出效果不同
- NPC 牌是一次性使用（打出后弃置）

## 4. 创造场景

- 玩家可以通过出牌**创造临时地点**
- 创造的地点牌作为"临时场景"放置到版图区，持续 1-2 回合后消失
- 这些临时地点可提供特殊效果，或成为策略上的"假目标"
- 警长可能借此引诱罪犯现身，罪犯可能借此制造混乱

## 5. Token 体系（尽可能简单）

所有 token 仅用于计数，无复杂逻辑：

| Token | 用途 | 形式建议 |
|-------|------|---------|
| **分数标记** | 每人一个，在计分轨道上移动 | 玩家棋子/立方体 |
| **线索标记** | 警长专用，计数用 | 小立方体/骰子 |
| **赃物标记** | 罪犯专用，计数用 | 小立方体/骰子 |
| **情报标记** | 通用资源，计数用 | 小立方体/骰子 |

## 6. 应用方向参考

以上设计方向可根据方案定位选择融入方式——例如德式轻策方案可以突出资源控制与规划；其他风格方案也可灵活选取适用的部分。卡牌化后的 NPC 和地点仍然是可以规划利用的资源，地点随机性增加重开性，而"创造场景"提供了独特的策略维度。

## 卡牌类型速览

| 卡牌类型 | 说明 | 是否在版图上 |
|---------|------|------------|
| **行动牌** | 玩家手牌主力，描述行动内容，指定目标后结算效果 | ❌ |
| **地点牌** | 构成中央版图，每局随机抽取，有文字描述的持续效果 | ✅ 永久存在 |
| **NPC牌** | 一次性，打出后按文字描述结算效果 | ❌ |
| **事件牌** | 每回合翻开一张，全局效果影响该夜晚 | ✅ 临时 |
| **场景牌** | 玩家创造临时地点 | ✅ 1-2回合后消失 |
