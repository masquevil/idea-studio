# 方案 3B · 世界观与主题设定

> 设计日期：2026-07-25
> 方案方向：纯卡牌驱动的 noir 警匪博弈

---

## 背景故事

**"这座城市没有白天。"**

大都会——一座永不入眠的罪恶之都。表面上是光鲜亮丽的现代都市，夜幕降临时却变成弱肉强食的丛林。腐败的政客与黑帮勾结，警局资源捉襟见肘，普通市民在恐惧中苟延残喘。

有人说这座城市病了，病入膏肓。

但每个夜晚，总有人试图改变些什么——

**警长**坚守着最后一道防线，用有限的人手在这个无法无天的城市里维护秩序。他知道自己赢不了这场战争，但只要能多阻止一桩罪行，就值了。

**罪犯**们在这座城市如鱼得水。银行、珠宝店、港口、夜总会——到处都是机会。他们彼此既是竞争者也是合作者，但最终，只有一个人能站到最后。

**超级英雄**——有人叫他疯子，有人叫他救世主。他不属于任何阵营，不受任何规则约束。今晚他想当英雄就阻止犯罪，想当义警就以暴制暴。没人能命令他，也没人能预测他。

**受害者联盟**——这群人曾经相信正义，曾经报警、等警察、失望。现在他们不再等待任何人。他们要自己掌握这座城市的话语权。游行、抗议、曝光——让所有人看看，这座城市的真面目。

十天的黑夜，十次命运的转折。

天亮之前，谁会成为这座城市的真正主宰？

## 城市设定

### 大都会 · 概览

大都会是一个典型的 noir 风格现代都市，融合了 80 年代美式犯罪电影元素与当代城市问题。城市的灵魂不在于建筑物，而在于**地点牌池**——每局游戏随机抽取的 12 张地点牌构成了该局的城市面貌。

### 地点类别与风格

| 类别 | 风格 | 代表地点 | 在游戏中的作用 |
|------|------|----------|----------------|
| 🏦 **金融区** | 高楼林立、冷峻现代 | 市中心银行、证券交易所、保险公司 | 高收益犯罪目标，但警长布控优先级高 |
| 🚢 **工业区** | 昏暗潮湿、废弃仓库 | 港口码头、工厂、冷藏仓库 | 便于藏匿，暴露度低，适合前期踩点发育 |
| 🌃 **娱乐区** | 霓虹闪烁、鱼龙混杂 | 夜总会、赌场、地下拳场 | 情报交易活跃，踩点收益高 |
| 🏘️ **居民区** | 老旧破败、人情冷暖 | 公寓楼、贫民窟、社区中心 | 暴露度低，但犯罪收益也低，适合躲避追捕 |
| 🏛️ **市政区** | 庄严压抑、戒备森严 | 市政厅、警局、法院 | 警长优势区域，部分地点不能被选为犯罪目标 |
| 📺 **媒体区** | 灯光刺眼、舆论中心 | 电视台、报社、网络中心 | 舆论战的核心区域，影响城市整体状态 |

### 城市动态状态

除了静态的地点牌，城市还有两个全局状态，受玩家行动影响：

| 全局状态 | 初始值 | 影响 | 改变方式 |
|----------|--------|------|----------|
| **城市治安** 🔵 | 5（满值 10） | 治安高→犯罪成本增加（情报消耗+1）；治安低→犯罪收益增加（分数+1） | 警长行动提升，罪犯/受害者行动降低 |
| **市民恐慌** 🔴 | 3（满值 10） | 恐慌高→受害者联盟得分效率提升；恐慌低→超级英雄声望获取减少 | 重大犯罪/暴力事件增加，警长维持秩序减少 |

> 这两个状态是**全局性的**，影响所有玩家。城市治安和市民恐慌是**独立的**——一个高不代表另一个低。治安是秩序度量，恐慌是情绪度量。

## 主题与机制的契合度说明

### "卡牌即命运"——纯卡牌驱动的主题意义

方案 B 选择纯卡牌驱动（无版图、无棋子移动），**核心隐喻是"城市是流动的，每个夜晚都是一次机会"**。

| 主题元素 | 机制体现 | 契合度 |
|----------|----------|--------|
| **夜色笼罩** | 警长先手布控——罪犯在后观察，黑暗中博弈 | 🎯 极高 |
| **城市百态** | 随机地点牌池——每局城市面貌不同 | 🎯 极高 |
| **犯罪策划** | 情报消耗机制→踩点→策划→执行 | 🎯 极高 |
| **警匪博弈** | 标准回合制·警长先手→后手罪犯获得信息优势 | 🎯 极高 |
| **舆论战** | 城市恐慌/治安状态→公众情绪影响游戏 | 🎯 高 |
| **灰色正义** | 超级英雄的自由行动→第三方搅局 | 🎯 高 |
| **底层反抗** | 受害者联盟的破坏性得分→秩序崩塌 | 🎯 高 |

### 关键主题-机制对照

1. **"每个夜晚都是一次发牌"** → 每回合摸 1 张牌，你永远不知道今晚你能做什么。这反映了 noir 故事中角色的宿命感——你只能用手上有限的牌去应对这个危险的世界。

2. **"城市是活的"** → 地点牌的特殊效果会改变游戏规则，城市治安和恐慌状态随行动变化。玩家不是在静态的棋盘上对弈，而是在一个动态的、有生命的城市中博弈。

3. **"没有人是纯粹的好人或坏人"** → 通用牌库设计：所有人共用同一套工具（卡牌），但使用方式因角色而异。这暗示了在罪恶都市中，手段是中性的，如何使用决定了你是谁。

4. **"灰色正义"** → 超级英雄不受约束的行动模式、受害者联盟的破坏性抗议——这些机制都在挑战传统的"好人vs坏人"二元叙事。

5. **"信息就是武器"** → 标准回合制的核心隐喻：警长先手部署，罪犯后手观察——在罪恶都市中，谁掌握了更多信息，谁就能在博弈中占据上风。

## 美术风格方向

### 视觉基调

**Noir 冷色调 + 霓虹躁动**

整体以暗色调为主，用霓虹色彩(粉、紫、绿)点缀，营造"表面的黑暗 + 暗处的躁动"之感。

### 卡牌设计方向

| 元素 | 方向 |
|------|------|
| **卡牌底色** | 深色背景（深蓝/墨绿/暗红），对应卡牌类型 |
| **插画风格** | 粗线条+块状色彩，类似漫画 pop art 风格但偏暗 |
| **字体** | 粗体无衬线，部分标题使用手写风格 |
| **信息层级** | 顶部：卡牌名称（醒目）→ 中部：插画 + 一句风味文字 → 底部：效果文本 |
| **边框** | 磨损/做旧效果，体现城市的老旧感 |

### 地点牌设计方向

- 每张地点牌以俯瞰视角展示该地点的"天际线"轮廓
- 夜间色调为主，霓虹灯点缀
- 地点名称以霓虹招牌风格呈现
- 特殊效果图标化显示在牌面

### 计分轨道

- 设计为"城市天际线"风格，分数从"黑暗"到"黎明"过渡
- 0 分：黑暗的夜空
- 15 分：黎明破晓
- 象征每个玩家都在推进这座城市走向自己的结局

### 角色立绘方向

| 阵营 | 视觉关键词 |
|------|------------|
| 👮 **警长** | 制服、风衣、警徽、疲惫但坚定的眼神 |
| 🦹 **罪犯** | 阴影中的轮廓、作案工具、钞票/珠宝 |
| 🦸 **超级英雄** | 紧身衣+面具（破旧质感，非光鲜的超级英雄风） |
| 👥 **受害者联盟** | 普通人面孔、标语牌、燃烧瓶 |

### 回合制与 noir 风格的视觉呼应

| 回合顺序 | 视觉主题 | 说明 |
|----------|----------|------|
| 警长回合 | 探照灯、警徽、蓝色冷光 | 秩序的象征，先手决策 |
| 罪犯回合 | 阴影、面具、红色暗光 | 罪犯在黑暗中伺机而动 |
| 结算阶段 | 霓虹闪烁、新闻头条 | 行动的后果显现，城市状态更新 |
