## 回合流程详解（×10 回合）

### 每回合步骤

#### 步骤 1：回合开始阶段

```
① 翻开回合牌 → 揭示本回合的特殊事件/效果
② 警长获得 1 线索（自动补给）
③ 所有玩家摸 1 张通用牌（手牌超 5 张需弃至 5 张）
④ 所有玩家检视自己的手牌
```

#### 步骤 2：玩家行动阶段（标准回合制 · 警长先手 · 顺时针轮流）

> ⚠️ 用户硬约束：**严禁同时暗出！采用标准回合制。**

```
① 警长回合开始（行动力分配阶段）
   ├─ 警长拥有 3 点行动力（阵营技能"部署权"）
   ├─ 出 1 张牌消耗 1 点行动力，执行牌面效果 + 阵营/专属技能修饰
   ├─ 剩余 2 点行动力留存至结算阶段，用于额外布控（地点警戒值+1）或额外调查（消耗1线索）
   └─ 警长回合结束

② 警长右手边第一位罪犯（或超英/受害者）回合开始
   ├─ 该玩家：从手牌中选择 1 张牌公开打出
   ├─ 出牌时需指定目标地点（如涉及地点选择）
   ├─ 执行牌面效果 + 阵营技能/专属技能修饰
   └─ 该玩家回合结束

③ 顺时针下一位玩家回合开始
   ├─ 重复以上流程
   └─ 直到所有玩家完成本回合行动

④ 所有玩家完成行动 → 进入结算阶段
```

**回合制核心规则**：

| 规则 | 说明 |
|------|------|
| **先手** | 警长先行动 |
| **顺序** | 顺时针轮流（警长→右手边第一位→依次类推） |
| **出牌** | 牌公开打出，所有人可见效果 |
| **信息优势** | 后手玩家可看到先手玩家的行动后决策 |
| **同一地点冲突** | 同一回合同一地点，后执行者覆盖先执行者 |
| **不行动选项** | 玩家可选择不出牌，改为「弃 1 张牌过」 |
| **模拟叙事** | 警长先部署→罪犯后观察→模拟执法博弈中的信息不对称 |

#### 步骤 3：结算阶段

所有玩家完成行动后，进入全局结算阶段：

```
① 警长调查阶段
   ├─ 警长使用剩余的部署权行动力进行额外布控/调查
   └─ 推进嫌疑链、收集线索

② 超级英雄/受害者联盟响应
   ├─ 超级英雄"义警出击"：检查是否有可阻止的犯罪
   └─ 受害者联盟"以暴制暴"：消耗声势破坏行动

③ 全局状态更新
   ├─ 检查城市治安和恐慌变化
   ├─ 治安或恐慌超出 0-10 范围时，钳制在边界值
   └─ 恐慌 ≥ 7：受害者联盟自动获得 1 分

④ 持续性效果结算
   ├─ 被关押的罪犯：如果已关押满 2 回合，自动释放
   ├─ 警长：从关押罪犯每回合获得 1 分
   ├─ 暴露度自然消退：所有罪犯暴露度 -1（不会低于 0）
   └─ 嫌疑链自然衰退：连续 3 回合未被关注则 -1

⑤ 清理本回合临时效果
   ├─ 警官牌回收（除非有"持续"关键词）
   ├─ 移除本回合放置的临时标记
   └─ 回合计数器 +1
```

### 行动执行顺序争议处理

| 情况 | 处理方式 |
|------|----------|
| 多人有响应效果 | 按回合顺序（警长→罪犯→超英→受害者）执行 |
| 目标在同一行动中消失 | 行动改为无效（但已消耗的资源不退还） |
| 效果冲突 | 后执行的覆盖先执行的（基于回合顺序） |

## 🟡 新手学习路径（评审 M4 建议）

为降低新玩家认知负担，建议前 3 回合采用简化规则：

| 回合 | 简化规则 | 学习目标 |
|------|----------|----------|
| 第 1 回合 🟢 | **不使用地点牌特殊效果**（地点牌仅作为位置标记） | 让玩家先熟悉核心出牌循环：出牌→结算→摸牌 |
| 第 2 回合 🟢 | **仅启用基础牌效果**（踩点、调查、转移、潜伏 4 种）| 学习 4 种基础牌的作用和配合 |
| 第 3 回合 🟡 | **启用地点牌特殊效果** | 学习地点系统对策略的影响 |
| 第 4 回合起 🔴 | **全部规则启用**（包括特殊牌、事件牌、NPC 牌）| 完整游戏体验 |

## 游戏结束触发条件

### 条件 1：分数达标

```
任一玩家分数达到 15 分 → 当前回合结束后游戏结束
```

### 条件 2：回合用尽

```
第 10 回合结束 → 强制结束
```

### 最终计分

```
① 统计所有玩家的最终分数
② 分数最高者获胜
③ 平局时按以下顺序判定：
   ├─ 剩余情报+赃物+线索（总和）最多者
   ├─ 城市治安状态更接近自己阵营偏好者
   └─ 仍平局 → 共享胜利
```

## 特殊规则

### 虚拟罪犯机制（2-3 人局适配）

| 实况 | 虚拟罪犯数量 | 虚拟罪犯行为 |
|------|--------------|--------------|
| 1 罪犯（2 人局） | 2 个 | 按"最近犯罪地点相邻区域"逻辑选择踩点 |
| 2 罪犯（3 人局） | 1 个 | 优先选择尚未被布控且距离最近犯罪地点最近的地点 |

**虚拟罪犯规则**（优化版）：

- 不再随机选择地点，按逻辑规则：优先选择距离最近一次犯罪地点相邻的区域
- 如果没有合适的相邻区域，选择警长最近未布控的区域
- 模拟犯罪的"扩散效应"——犯罪会向周边蔓延
- 虚拟罪犯不犯罪、不得分、不受逮捕
- 虚拟罪犯产生的线索归警长所有

### 关押与越狱规则

| 状态 | 效果 | 释放条件 |
|------|------|----------|
| 被关押（第 1 回合） | 不能行动，不能出牌 | ① 本回合结束时若已满 2 回合，自动释放 |
| 被关押（第 2 回合） | 不能行动，不能出牌 | ② 消耗 2 情报或 1 赃物主动越狱（在自己回合） |
| 越狱后 | 暴露度 +2 | 越狱后立即恢复行动能力 |

- 被关押的罪犯**不摸牌**（不补充手牌）
- 越狱成功后本回合剩余行动力可用（如已过行动阶段则等到下回合）

### 城市治安/恐慌状态波动规则

| 状态 | 最低值 | 最高值 | 超限处理 |
|------|--------|--------|----------|
| 城市治安 🔵 | 1（无政府状态） | 10（秩序井然） | 钳制在边界值 |
| 市民恐慌 🔴 | 0（平静） | 10（暴乱边缘） | 钳制在边界值 |

**关键阈值**：

```
城市治安 ≤ 3：罪犯犯罪收益+1（得分为+1）
城市治安 ≥ 8：罪犯犯罪成本+1（情报消耗+1）
城市恐慌 ≥ 7：受害者联盟每回合自动得 1 分（回合结束阶段）
```

### 手牌管理规则

| 规则 | 说明 |
|------|------|
| 手牌上限 | 5 张（回合结束时若超限，弃至 5 张） |
| 摸牌时机 | 每回合开始阶段摸 1 张通用牌 |
| 弃牌 | 回合中可通过人物技能或卡牌效果弃牌 |
| 牌库耗尽 | 通用牌库耗尽时，重洗弃牌堆作为新牌库 |
