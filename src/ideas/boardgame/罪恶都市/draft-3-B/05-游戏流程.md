## 回合流程详解（×10 回合）

### 每回合步骤

#### 步骤 1：回合开始阶段

```
① 翻开回合牌 → 揭示本回合的特殊事件/效果
② 警长获得 1 线索（自动补给）
③ 所有玩家摸 1 张通用牌（手牌超 5 张需弃至 5 张）
④ 所有玩家检视自己的手牌
```

#### 步骤 2：行动出牌阶段

```
① 所有玩家同时从手牌中选择 1 张牌，面朝下打出
   └─ 出牌时需指定目标地点（如涉及地点选择）
   └─ 部分卡牌可"不行动"（弃 1 张牌过）

② 按【分数从低到高】的顺序，依次揭示并执行行动
   └─ 分数相同者：按固定顺序（警长优先→罪犯→超级英雄→受害者联盟）
   └─ 低分先动的逻辑：给落后玩家翻盘机会
```

#### 步骤 3：行动结算阶段

按行动顺序，每位玩家的行动完整结算完毕后，才轮到下一位玩家。

##### 行动结算流程（通用）

```
玩家揭示卡牌 → 确认卡牌类型 → 应用人物技能修饰 → 结算效果

结算过程中可能触发的中断事件：
├─ 超级英雄"义警出击"（在行动执行前）
├─ 受害者联盟"以暴制暴"（在行动执行前）
└─ 其他卡牌的"响应"效果
```

##### 各阵营典型行动结算

| 阵营 | 行动 | 结算步骤 |
|------|------|----------|
| 👮 警长 | **巡逻布控** | 选地点→该地点警戒+1→若该地点有罪犯活动，其暴露度+1 |
| 👮 警长 | **调查追查** | 消耗 1 线索→指定罪犯→嫌疑链+1 |
| 👮 警长 | **逮捕** | 指定罪犯（嫌疑链满级）→罪犯被关押→警长得 2 分 |
| 👮 警长 | **部署警力** | 打警官牌到某地点→该地点犯罪成本+1（持续至回合结束） |
| 👮 警长 | **安抚城市** | 城市恐慌-1 或城市治安+1 |
| 🦹 罪犯 | **踩点** | 选地点→放置踩点标记→获 1 情报→该地点加 1 线索 |
| 🦹 罪犯 | **犯罪** | 选已踩点地点→消耗情报（基础 2 情报）→获得赃物+分数 |
| 🦹 罪犯 | **越狱** | 消耗 2 情报或 1 赃物→暴露度+2→恢复行动 |
| 🦸 超级英雄 | **阻止犯罪** | 指定目标罪犯行动→若为犯罪则无效→英雄得 1 声望 |
| 🦸 超级英雄 | **夺取资源** | 指定目标玩家→损失 2 情报/赃物→英雄得 1 声望 |
| 🦸 超级英雄 | **追踪罪犯** | 指定罪犯→获知其暴露度+嫌疑等级 |
| 🦸 超级英雄 | **维护正义** | 城市恐慌-1 或城市治安+1 |
| 👥 受害者联盟 | **组织游行** | 选地点→封锁该地点本回合→获 1 声势 |
| 👥 受害者联盟 | **抗议示威** | 城市治安-1→获 1 声势→若治安≤3 额外+1 分 |
| 👥 受害者联盟 | **媒体曝光** | 指定玩家→暴露度+2 |
| 👥 受害者联盟 | **煽动暴动** | 城市恐慌+2→所有其他玩家失去 1 情报/赃物 |
| 👥 受害者联盟 | **破坏行动** | 消耗 2 声势→指定玩家行动无效 |

#### 步骤 4：回合结束阶段

```
① 结算所有"回合结束时"效果
   ├─ 被关押的罪犯：如果已关押满 2 回合，自动释放
   └─ 警长：从关押罪犯每回合获得 1 分

② 检查城市治安和恐慌状态的边界值
   ├─ 治安或恐慌超出 0-10 范围时，钳制在边界值
   └─ 恐慌 ≥ 7：受害者联盟自动获得 1 分

③ 清理本回合临时效果
   ├─ 警官牌回收（除非有"持续"关键词）
   ├─ 移除本回合放置的临时标记
   └─ 重置警戒值

④ 回合计数器 +1
```

### 行动执行顺序争议处理

| 情况 | 处理方式 |
|------|----------|
| 多人有响应效果 | 按分数从低到高执行，分数同按固定顺序 |
| 目标在同一行动中消失 | 行动改为无效（但已消耗的资源不退还） |
| 效果冲突 | 后执行的覆盖先执行的（非同时生效） |

## 游戏结束触发条件

### 条件 1：分数达标

```
任一玩家分数达到 15 分 → 当前回合结束后游戏结束
```

### 条件 2：回合用尽

```
第 10 回合结束 → 强制结束
```

### 最终计分

```
① 统计所有玩家的最终分数
② 分数最高者获胜
③ 平局时按以下顺序判定：
   ├─ 剩余情报+赃物+线索（总和）最多者
   ├─ 城市治安状态更接近自己阵营偏好者
   └─ 仍平局 → 共享胜利
```

## 特殊规则

### 虚拟罪犯机制（2-3 人局适配）

当游戏人数为 2 或 3 人（罪犯数量不足 3 人）时，启动虚拟罪犯机制：

| 实况 | 虚拟罪犯数量 | 虚拟罪犯行为 |
|------|--------------|--------------|
| 1 罪犯（2 人局） | 2 个 | ① 每回合自动在"警长未布控的地点"放置踩点标记+线索 |
| 2 罪犯（3 人局） | 1 个 | ② 虚拟罪犯不犯罪、不得分、不受逮捕 |
| | | ③ 虚拟罪犯产生的线索归警长所有 |

**虚拟罪犯规则**：

- 每回合开始阶段，在"尚未有踩点标记且未被布控"的地点中随机选取 1 个，放置踩点标记和 1 线索
- 若无可用地点则不执行
- 虚拟罪犯的线索直接加入警长的线索池

### 关押与越狱规则

| 状态 | 效果 | 释放条件 |
|------|------|----------|
| 被关押（第 1 回合） | 不能行动，不能出牌 | ① 本回合结束时若已满 2 回合，自动释放 |
| 被关押（第 2 回合） | 不能行动，不能出牌 | ② 消耗 2 情报或 1 赃物主动越狱（在自己回合） |
| 越狱后 | 暴露度 +2 | 越狱后立即恢复行动能力 |

- 被关押的罪犯**不摸牌**（不补充手牌）
- 越狱成功后本回合剩余行动力可用（如已过行动阶段则等到下回合）

### 城市治安/恐慌状态波动规则

| 状态 | 最低值 | 最高值 | 超限处理 |
|------|--------|--------|----------|
| 城市治安 🔵 | 1（无政府状态） | 10（秩序井然） | 钳制在边界值 |
| 市民恐慌 🔴 | 0（平静） | 10（暴乱边缘） | 钳制在边界值 |

**关键阈值**：

```
城市治安 ≤ 3：罪犯犯罪收益+1（得分为+1）
城市治安 ≥ 8：罪犯犯罪成本+1（情报消耗+1）
城市恐慌 ≥ 7：受害者联盟每回合自动得 1 分（回合结束阶段）
```

### 手牌管理规则

| 规则 | 说明 |
|------|------|
| 手牌上限 | 5 张（回合结束时若超限，弃至 5 张） |
| 摸牌时机 | 每回合开始阶段摸 1 张通用牌 |
| 弃牌 | 回合中可通过人物技能或卡牌效果弃牌 |
| 牌库耗尽 | 通用牌库耗尽时，重洗弃牌堆作为新牌库 |
