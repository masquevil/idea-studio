## 核心游戏循环

### 每回合（每个夜晚）的宏观流程

```
┌─────────────────────────────────────────────────────┐
│                   夜晚开始                           │
├─────────────────────────────────────────────────────┤
│  ① 翻回合牌（揭示本回合的特殊事件/效果）            │
│  ② 警长回合：警长出 1 张牌（消耗 1 点行动力），      │
│     剩余 2 点行动力可在结算阶段用于额外布控/调查      │
│  ③ 顺时针轮流：每位罪犯依次出 1 张牌/执行 1 个行动  │
│  ④ 超英/受害者在自己的回合出牌/行动                  │
│  ⑤ 结算阶段：警长调查、状态更新、持续性效果结算      │
│  ⑥ 回合结束：补充手牌、更新状态                     │
└─────────────────────────────────────────────────────┘
```

### 玩家每回合的基本选择

每个玩家在自己的回合从手牌中选择 **1 张牌公开打出**，作为本回合的主要行动。警长先手，然后顺时针轮流。后手玩家可以看到先手玩家的行动，从而获得信息优势。

### 回合制规则

| 要点 | 说明 |
|------|------|
| **先手顺序** | 警长先 → 顺时针轮流 |
| **出牌方式** | 公开打出，所有人可见 |
| **信息优势** | 后手玩家可看到先手玩家的行动后做决策 |
| **叙事逻辑** | 警长先部署 → 罪犯后行动 → 模拟现实的执法博弈 |
| **同一地点冲突** | 同一地点同一回合内，后执行者覆盖先执行者（如警长在罪犯行动前布控→罪犯看到布控后可选其他地点） |

## 资源体系

| 资源 | 全称 | 用途 | 获取方式 |
|------|------|------|----------|
| 💰 **情报** | 情报标记 | 罪犯犯罪成本、越狱成本、部分卡牌消耗 | 踩点、特定卡牌效果 |
| 💎 **赃物** | 赃物标记 | 罪犯得分转化物、部分卡牌消耗 | 成功犯罪后获得 |
| 🔍 **线索** | 线索标记 | 警长推进嫌疑链、逮捕消耗 | 罪犯踩点时留下、回合自动补给 |
| 🏆 **分数** | 胜利分数 | 达到 15 分触发游戏结束 | 各阵营各有得分方式 |
| ⚠️ **暴露度** | 暴露等级 | 越高越容易被警长锁定和逮捕 | 犯罪/越狱时增加 |

### 资源交互关系

```
罪犯踩点 ──→ 该地点留下【线索标记】（警长得）
         ──→ 罪犯获得【情报标记】（用于犯罪）

罪犯犯罪 ──→ 消耗【情报标记】
         ──→ 获得【赃物标记】
         ──→ 增加【暴露度】

警长调查 ──→ 消耗【线索标记】
         ──→ 推进嫌疑人【嫌疑链】

警长逮捕 ──→ 嫌疑人【嫌疑链】满级 + 暴露度 ≥ 3
         ──→ 罪犯被【关押】（1-2 回合）
         ──→ 警长获得分数

罪犯越狱 ──→ 消耗【情报标记】/【赃物标记】
         ──→ 【暴露度】+2
         ──→ 恢复行动能力
```

## 暴露度完整机制（🔴 评审修复）

### 暴露度等级与效果

| 暴露度等级 | 效果 | 说明 |
|-----------|------|------|
| 0-2 | 安全 | 无影响 |
| 3-4 | 可疑 | 警长调查该罪犯时消耗线索 -1（更容易被跟踪） |
| 5-7 | 被盯上 | 警长调查该罪犯只需 1 线索即可推进 1 级嫌疑链（效率翻倍） |
| 8-9 | 高度通缉 | 暴露度 ≥ 8 时，满足逮捕条件之一（无需暴露度≥3的额外条件） |
| 10 | 完全暴露 🔴 | 所有玩家获知该罪犯的身份和当前位置（自动触发全局通知） |

### 暴露度变化

| 行为 | 暴露度变化 |
|------|-----------|
| 踩点（基础） | 0（不增加） |
| 在警长布控地点踩点 | +1 |
| 犯罪（基础） | +2 |
| 越狱 | +2 |
| 被媒体曝光（受害者联盟技能） | +2 |
| 每回合结束时 | -1（自然消退，不会低于 0） |

### 暴露度与逮捕条件

- 逮捕条件变更为：**嫌疑链满 5 级 且 暴露度 ≥ 3**
- 暴露度 ≥ 8 时，暴露度条件自动满足（无需达到 3）
- 暴露度直接影响警长调查效率（见上表），形成"犯罪越多→暴露越高→越容易被捕"的因果链

## 卡牌系统

### 牌库构成（🔴 用户反馈修复）

- **基础牌**：80 张（84%），所有玩家基础操作
- **特殊牌**：15 张（16%），提供爆发/特殊策略
- 所有牌对所有阵营玩家都有基本用途，**无任何阵营专属牌**
- 牌的效果固定不变，角色技能选择性修改部分效果

### 卡牌类型

| 类型 | 牌名 | 数量 | 牌面效果（一行字） | 用途说明 |
|------|------|------|-------------------|----------|
| 🟦 **基础牌** | 踩点 | ×30 | 获得 1 情报 | 核心资源积累，罪犯发育起点 |
| | 调查 | ×25 | 获得 1 线索 | 警长核心行动，罪犯也可用于获取信息 |
| | 转移 | ×15 | 移动目标地点（更换当前关注地点） | 改变位置的通用行动 |
| | 潜伏 | ×10 | 本回合暴露度 -1，免疫 1 次逮捕尝试 | 防守牌，适合高风险时使用 |
| 🟪 **特殊牌** | 密谋 | ×5 | 获得 2 情报并摸 1 张牌 | 资源爆发 |
| | 追查 | ×5 | 获得 2 线索并查看 1 名玩家的手牌 | 信息战 |
| | 金蝉脱壳 | ×3 | 逃脱一次关押或针对效果 | 保命牌 |
| | 孤注一掷 | ×2 | 弃所有手牌，每弃 1 张获得 1 分 | 最后一搏 |

### 牌的效果固定，技能是修饰器（🔴 用户反馈修正）

> **核心原则：牌的效果就是写在上面的那样，不会变。每个角色有技能，有些技能可以改变某张/某类牌的效果。**

| 原则 | 说明 |
|------|------|
| 通用性 | 通用牌的牌面文字对所有玩家完全一致 |
| 例外性 | 角色技能选择性覆盖部分牌的效果或增加额外效果，80% 情况下牌就是牌本身 |
| 透明性 | 玩家不需要看别人角色的技能来理解自己手里的牌 |
| 成本约束 | 技能对牌效果的修改必须有触发条件或成本 |

### 角色技能如何影响卡牌效果（示例）

| 卡牌 | 警长打出 | 罪犯打出 | 超级英雄打出 | 受害者联盟打出 |
|------|----------|----------|--------------|----------------|
| 「踩点」×30 | 牌面"获得 1 情报"→ 警长技能修改为："获得 1 线索" | 牌面"获得 1 情报"+ 阵营技能"犯罪"可改为执行犯罪 | 牌面"获得 1 情报"→ 英雄技能修改为："获得 1 声望" | 牌面"获得 1 情报"→ 无修改，获得 1 情报 |
| 「调查」×25 | 牌面"获得 1 线索"+ 警长技能"部署权"可改为执行布控 | 牌面"获得 1 线索"→ 正常使用 | 牌面"获得 1 线索"→ 正常使用 | 牌面"获得 1 线索"→ 正常使用 |
| 「潜伏」×10 | 牌面效果不变（本回合暴露度-1，免疫 1 次逮捕） | 牌面效果不变 | 牌面效果不变 | 牌面效果不变 |
| 「追查」×5 | 牌面"获得 2 线索并查看 1 名玩家的手牌" | 牌面效果不变 | 牌面效果不变 | 牌面效果不变 |

> 卡牌的效果是固定的。角色技能可以**在某些条件下修改牌的效果**，这种修改是例外而非规则。大部分情况下，牌的效果就是写的那样。

## 地点系统（卡牌化城市）

### 地点牌机制

- 每局游戏开始从地点牌池随机抽取 **12 张地点牌**
- 面朝上摆放在桌面中央，形成 3×4 或 4×3 的城市布局
- **相邻关系**：上下左右相邻的地点视为"邻近区域"
- 地点牌本身带有**特殊效果**（持续存在）

### 地点牌示例

| 地点名 | 特殊效果 | 犯罪偏好 |
|--------|----------|----------|
| 市中心银行 | 在此犯罪得分为 +1 | 抢劫 |
| 港口仓库 | 相邻地点踩点可共享情报 | 走私 |
| 夜总会 | 在此踩点获得情报 +1 | 情报交易 |
| 警局总部 | 此地点不能被选为犯罪目标 | - |
| 贫民窟 | 在此犯罪的暴露度 -1 | 藏匿 |
| 电视台 | 在此行动被曝光概率 +1 | 舆论战 |

### 地点互动

- 罪犯选择地点**踩点**：在地名牌上放置踩点标记，获得情报，同时在该地点留下线索
- 罪犯选择地点**犯罪**：需要目标地点已被踩点，消耗情报执行犯罪
- 🔴 **同一地点同一回合只能被一个罪犯踩点**（先到先得），增强罪犯间的竞争
- 警长选择地点**布控**：该地点警戒值+1（增加犯罪成本）
- 部分卡牌效果依赖**地点间相邻关系**（如"引爆整个区域"）

## 罪犯竞争机制（🔴 评审修复）

### 同一地点竞争

| 规则 | 说明 |
|------|------|
| 唯一踩点 | 同一地点同一回合只能被一个罪犯踩点（先到先得） |
| 冲突解决 | 按回合顺序，先执行者先占（标准回合制中，先轮到谁谁先占） |
| 踩点覆盖 | 若罪犯 A 已在一地点踩点，罪犯 B 可出「转移」牌后在同一地点踩点，覆盖 A 的踩点标记 |

### 抢夺与干扰

- 引入"抢夺赃物"卡牌效果（由角色技能触发）：罪犯可抢夺另一罪犯的 1 赃物
- 部分角色专属技能支持直接干扰其他罪犯（如狐狸的"假情报"可在其他罪犯的踩点地点放置假线索，混淆警长）

### 囚徒困境设计

```
        罪犯不告密                   罪犯告密
罪犯A   各得 1 分（和平发育）        A 损失 1 情报，B 得 2 分
罪犯B   各得 1 分（和平发育）        B 得 2 分，A 损失 1 情报
```

- 部分特殊牌支持"告密"行为：举报另一罪犯的犯罪计划→警长获得额外线索，举报者获得分数
- 最终胜利者只有一个，罪犯间是"临时合作但本质竞争"的关系

## 胜利条件（跑分制）

**目标分数：15 分**

| 阵营 | 得分方式 | 得分节奏 |
|------|----------|----------|
| 👮 **警长** | 关押罪犯每回合 +1；逮捕 +2；阻止重大犯罪 +1 | 中后期稳定得分 |
| 🦹 **罪犯** | 成功犯罪得 1-2 分（视犯罪类型） | 中后期爆发得分 |
| 🦸 **超级英雄** | 阻止犯罪 +1；成功预测 +1；英雄热度累积爆发；最终声望最高的英雄获得额外分数 | 全期均可得分 |
| 👥 **受害者联盟** | 成功游行/抗议 +1；破坏警长行动 +1；城市恐慌升级时得分 | 需要积累声势 |

### 游戏结束时机

1. **任一玩家达到 15 分** → 当前回合结束后游戏结束
2. **第 10 回合结束** → 强制结束
3. 分数最高者获胜（如平局，剩余情报/赃物/线索最多者胜）

## 核心博弈结构

### 信息博弈

| 维度 | 公开信息 | 隐藏信息 |
|------|----------|----------|
| 卡牌 | 玩家手牌数量公开 | 手牌内容未知 |
| 行动 | 标准回合制，行动公开打出 | 下一位玩家行动未知（但可基于已见信息推测） |
| 身份 | 警长身份公开 | 罪犯身份部分隐藏（有无身份卡） |
| 资源 | 分数、线索、情报可见 | 手牌内容不可见 |

### 风险收益三角

```
         【收益】
            ▲
           /|\
          / | \
         /  |  \
        /   |   \
       /    |    \
      / 【策划】  \
     /   （情报）    \
    /_________________\
  【暴露】          【成本】
```

罪犯的每个决策都是这三个维度的权衡：

- **投入情报越多** → 犯罪成功率越高、收益越大 → 但暴露度也越高
- **选择高风险目标** → 收益大 → 但警长布控可能性高
- **保持低调** → 安全 → 但得分效率低

## 虚拟罪犯机制（优化版 🟡）

当游戏人数为 2 或 3 人（罪犯数量不足 3 人）时，启动虚拟罪犯机制：

| 实况 | 虚拟罪犯数量 | 虚拟罪犯行为 |
|------|--------------|--------------|
| 1 罪犯（2 人局） | 2 个 | 按"最近犯罪地点相邻区域"逻辑选择踩点 |
| 2 罪犯（3 人局） | 1 个 | 优先选择**尚未被布控**且**距离最近一次犯罪地点最近**的地点 |

**虚拟罪犯优化规则**（🟡 评审建议改进）：

1. 不再随机选择地点，而是按**逻辑规则**选择：
   - 优先选择「距离最近一次犯罪地点相邻」的区域
   - 如果没有合适的相邻区域，选择「警长最近未布控」的区域
   - 模拟犯罪的"扩散效应"——犯罪会向周边蔓延
2. 虚拟罪犯不犯罪、不得分、不受逮捕
3. 虚拟罪犯产生的线索归警长所有

### 虚拟罪犯驱散机制（🟡 修复：低人数局警长得分）

为弥补低人数局（2-3 人）中警长逮捕机会不足的问题，引入虚拟罪犯驱散机制：

| 规则 | 说明 |
|------|------|
| **布控驱散** | 警长在虚拟罪犯踩点的地点执行布控时，可驱散该虚拟罪犯（移除其踩点标记），并获得 1 分 |
| **驱散时机** | 结算阶段，警长使用剩余行动力执行布控时触发 |
| **驱散限制** | 每回合最多驱散 1 个虚拟罪犯 |
| **虚拟罪犯重生** | 被驱散的虚拟罪犯在下回合开始时，在距离最近一次犯罪地点相邻的区域重新出现并踩点 |
| **设计目的** | 让警长在低人数局中也有"阻止犯罪"的得分机会，避免线索过剩但无事可做的管理型体验 |

## 人数适配

| 人数 | 配置 | 调整 | 推荐度 |
|------|------|------|--------|
| **2 人** | 1 警长 vs 1 罪犯 | 虚拟罪犯机制 | ⭐⭐ 快速决斗 |
| **3 人** | 1 警长 vs 2 罪犯 | 虚拟罪犯机制 | ⭐⭐⭐ 标准短局 |
| **4 人** | 1 警长 vs 3 罪犯 | 标准配置 | ⭐⭐⭐⭐⭐ 推荐 |
| **5 人** | 1 警长 vs 3 罪犯 + 1 超级英雄 | 加入第三方 | ⭐⭐⭐⭐ 丰富体验 |
| **6 人** | 1 警长 vs 3 罪犯 + 1 超级英雄 + 1 受害者联盟 | 全部阵营显现 | ⭐⭐⭐⭐ 满配体验 |
| **7 人** | 1 警长 vs 4 罪犯 + 1 超级英雄 + 1 受害者联盟 | 极限配置 | ⭐⭐ 节奏偏慢 |

> ⚠️ 推荐上限为 **6 人**。7 人局作为极限配置标注，行动结算链较长，可能导致节奏拖沓。

### 城市治安/恐慌阈值联动（🟢 可选规则）

城市治安和市民恐慌虽为独立状态，但在极端情况下可产生交互：

| 触发条件 | 效果 |
|----------|------|
| 治安 ≤ 3 且 恐慌 ≥ 6 | 恐慌上涨速度翻倍（每次恐慌变化量 ×2）——混乱蔓延让恐慌加剧 |
| 恐慌 ≥ 8 | 警长行动对治安的提升效果减半（向下取整，最低 0）——恐慌麻痹了秩序维护 |
| 治安 ≥ 8 且 恐慌 ≤ 2 | 恐慌每回合自动 -1（不会低于 0）——秩序井然安抚了市民情绪 |

> 该联动为**可选规则**，不影响核心规则的复杂度。初次游玩建议不使用，熟悉游戏后再加入以增加策略深度。

| 项目 | 内容 |
|------|------|
| 🎯 **游戏目标** | 率先获得 15 分 |
