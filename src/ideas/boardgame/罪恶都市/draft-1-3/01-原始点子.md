# 方案 C · 原始点子

> 纯原创设计，基于基本想法自由发挥（另一个方向）

---

## 一句话概念

> **「罪城回响」**—— 罪犯在城中策划连环案件，警长争分夺秒阻止犯罪升级，媒体与公众舆论左右局势走向，一场关于时间、声望与连锁反应的城市博弈。

## 核心卖点

- **事件链系统**：每个犯罪事件会触发连锁反应（银行劫案→警力紧张→贫民区失控），案件之间相互影响，形成多米诺效应
- **舆论战场**：媒体是第三方力量——报道倾向影响公众情绪，罪犯可以利用舆论施压警长，警长需要争取民心
- **时间压力**：游戏以"夜"为单位推进，每夜罪犯必须策划行动，未阻止的犯罪自动升级（敲门效应），警长面临越来越大的压力
- **身份有限透明**：罪犯之间互相不知道对方的具体身份（只知道是同伴），但可以通过行动暴露线索互相识别，增加内鬼博弈的潜台词
- **公共任务板**：城市中存在公开的"犯罪市场"——罪犯从公共任务池中选择案件，警长则能从中预判可能的犯罪方向

## 目标体验

玩家玩完后的感受：

- 警长玩家体验到"救火队长"的焦虑感——事件链四处蔓延，每次只能扑灭一处，其他犯罪会不断升级
- 罪犯玩家体验到"幕后黑手"的掌控感——精心策划案件链、操纵舆论、让城市在你的节奏中运转
- 罪犯之间体验到"同盟但非坦诚"的微妙关系——你知道同伴的存在但不确定他们的具体计划，可能需要协调也可能各自为战
- 所有玩家感受到"城市在燃烧"的紧迫感——游戏越到后期，事件压力越大，决策越来越艰难

## 与基本想法的关联

| 基本想法要素 | 方案 C 的体现 |
|-------------|--------------|
| 警匪非对称 | 警长 1 人 vs 罪犯 N 人，玩法完全不同 |
| 轻策桌游 | 规则简洁，每回合行动选项有限 |
| 卡牌为主 | 罪犯通过手牌策划案件，警长通过手牌派遣警力 |
| 围绕地点展开 | 城市地点是事件链的节点，案件绑定特定地点 |
| 警长巡逻/任命/派驻 | 警长派遣警力到地点阻止/延缓犯罪升级 |
| 罪犯抽 2 选 1 | 保留此机制，增加策略性 |
| 超级英雄（0-1人） | 第三方，可以阻断事件链、揭露隐藏线索 |
| 受害者联盟（0-1人） | 第四方，代表媒体/公众舆论，影响游戏走向 |
