# 设计评审 Checklist

本文档将原「桌游设计经验原则」1-11 条按阶段重新归类，形成可按阶段引用的评审清单。在阶段 ③（MVP 审查）和阶段 ⑤（人类测试）中做全维度审查时使用。

> 阶段 ③ 中补充的深层审查维度（量化审查部分）见 `docs/balance.md` 中的「深层问题检查」章节。

## 如何使用

每个阶段完成后，引用对应的检查项。不需要每个阶段做全部检查——只检查当前阶段相关的内容。

---

## 概念阶段检查（对应阶段 ①）

### 30 秒 Hook 检验

- [ ] 核心玩法能用一句话说清楚吗？
- [ ] 听者能在 30 秒内想象出"玩的时候是什么感觉"吗？
- [ ] ✅ "我扮演罪犯，在警长眼皮底下抢银行还得安全撤退"
- [ ] ❌ 需要先解释回合流程、出牌机制、堆叠规则才能让人理解

**检验方法**：向朋友口头介绍 30 秒，看对方的反应是"这听起来很酷！"还是"呃……所以怎么玩？"

### 新奇机制的讲解检验

- [ ] 如果核心机制是前所未有的，它的"爽点"能在规则讲解 30 秒内被感知吗？
- [ ] ✅ "所有人往同一个地点塞牌，等它塞到一定数量就会引爆结算"——有画面感
- [ ] ❌ "这是一个暗投堆叠再翻开的机制"——抽象晦涩

---

## 核心循环检查（对应阶段 ②）

### 策略深度验证

- [ ] 每个重要决策都基于可见、可推理的信息，而非猜测
- [ ] ✅ 版图上的标记、公开牌堆、轨道位置提供决策依据
- [ ] ❌ 玩家只能盲猜"对手会去 A 还是 B"，没有任何推理依据
- [ ] ❌ "所有人同时出牌后翻牌结算"——没有可见信息支撑选择

**检验方法**：让一名新玩家玩完第一局后，问他"你告诉我下次你会怎么做？"——如果他说不出任何改进方向，说明信息不足以支撑策略深度。

### 首次胜利来源于理解而非运气

- [ ] 新玩家玩完第一局后，能明确说出"下次我应该先做 X 而不是 Y"吗？
- [ ] ✅ 新手能复盘："我这次失误是因为没有注意到对手的防御部署"
- [ ] ❌ 新手说："全凭运气"、"不知道，随便选的"

---

## 复杂度检查（对应阶段 ③/⑤）

### 复杂度与策略回报成正比

- [ ] 每增加一条规则，是否对应增加了一层策略深度？
- [ ] 是否有某个子系统只在"记录"或"终局计分"时用到，对游戏过程中的决策没有影响？
- [ ] ✅ "我增加了一个子系统，玩家在这个子系统上有更多有意思的决策可以做"
- [ ] ❌ "这个状态值只在终局算分时用到，对游戏过程中的决策没有任何影响"

### 规则重 vs 知识重

- [ ] 优先选择了"规则多但信息透明"（规则重），而非"需要记忆大量隐藏信息"（知识重）？
- [ ] ✅ **规则重**——"摆在桌面上的重"：子系统多，但全部信息公开透明，学会后一目了然
- [ ] ❌ **知识重**——"在脑子里的重"：需要记住所有卡牌效果才能做最佳决策，牌表每扩展包都要重新背

> 对于非竞技桌游，知识重比规则重更危险——规则学一次就记住了，牌表每次扩展都要重新熟悉。

---

## 交互检查（对应阶段 ②/④）

### 交互是直接的、对抗性的

- [ ] 玩家之间的核心交互是"你堵我→我绕开/硬闯"的直接对抗，而非"各追各的分"？
- [ ] ✅ 一方部署防御，另一方选择正面突破或绕行，结果立竿见影
- [ ] ❌ 双方各自追进度条，互不干涉，只靠终局计分比较谁更强

---

## 物理实现检查（对应阶段 ③）

### 信息在桌面上，不在脑子里

- [ ] 所有影响玩家决策的核心信息，是否用物理组件呈现在桌面上？
- [ ] 玩家巡场一眼就能看懂局势，不需要追问"刚才发生了什么"？
- [ ] ✅ 各地点状态通过标记和 Token 一目了然
- [ ] ❌ "你需要记住某人上次去了哪"
- [ ] ❌ "玩家 A 放的这个标记只有他知道是谁放的"——标记上没有标签，无法物理实现

**操作指引**：所有游戏信息使用以下物理操作呈现——拿/放/移动标记、看牌、在轨道上移动指示物、数数量、口头宣告目标。

---

## 测试反馈检查（对应阶段 ④）

### 原型测试信号识别

测试中是否出现以下信号词？

- [ ] **"然后呢？"** → 规则不连续，有逻辑空档
- [ ] **"这怎么算？"** → 规则模糊，边界条件未定义
- [ ] **"我为什么要这么做？"** → 目标指引不清晰，玩家行动缺乏动机
- [ ] **"这不就是猜吗？"** → 缺乏信息支撑，沦为运气

> 设计者口头解释填补的漏洞 ≈ 游戏实际运行时一定会被玩家质疑的地方。不要为规则辩护，记下问题并修改。

---

## 综合检查（对应阶段 ⑤ — 全维度评审）

以下检查项覆盖设计的整体质量：

- [ ] **核心玩法明确**：30 秒内能让人产生期待
- [ ] **策略有深度**：玩家决策基于可见信息，而非猜测
- [ ] **复杂度有回报**：每条规则都有对应的策略价值
- [ ] **规则重而非知识重**：信息公开透明，不依赖记忆
- [ ] **交互直接**：玩家之间的互动是对抗性的，而非各玩各的
- [ ] **信息可视化**：所有关键信息在桌面上呈现
- [ ] **新手友好**：首次胜利来源于理解而非运气
- [ ] **测试通过**：没有触发信号词，或已修复所有触发的信号词
- [ ] **术语一致**：全篇使用统一术语
- [ ] **平衡合理**：没有最优解，多路径可行，节奏健康
