# 概率与平衡计算

## 概率基础速查

### 骰子概率

| 骰子类型 | 单次掷出特定值的概率 | ≥ X 的概率速查 | 说明 |
| - | - | - | - |
| d6（六面骰） | 1/6 ≈ 16.7% | ≥ 4：50%；≥ 5：1/3 ≈ 33%；≥ 6：1/6 ≈ 17% | 最常用 |
| 2d6 | 结果为 7 的概率最高（6/36 ≈ 16.7%） | ≥ 7：21/36 ≈ 58%；≥ 8：15/36 ≈ 42%；≥ 9：10/36 ≈ 28%；≥ 10：6/36 ≈ 17% | 钟形分布，结果集中在中间值 |
| d10 | 1/10 = 10% | — | 常用于百分比判定 |
| d20 | 1/20 = 5% | — | 常用于临界值判定（命中率等） |

### 卡牌概率

- **从 N 张牌的牌库中，想要抽到特定 1 张牌的概率**：1/N（首抽）→ 逐步提高
- **从 N 张牌的牌库中，起手 M 张牌抽到特定 1 张的概率**：1 - ((N-1)/N × (N-2)/(N-1) × ... × (N-M)/(N-M+1))
- 简化为：M/N（近似值，N 较大时准确）
- **从 30 张牌中摸到特定 1 张**：首抽 3.3%，起手 5 张 16.7%，起手 7 张 23.3%

### 资源曲线基本公式

- **成本曲线**：假设每回合收入为 R，费用为 C，则 X 回合后可用资源为：R × X - C
- **增长速度**：如果每回合资源产出递增（引擎构筑），则累计资源 = 初始 + Σ(每回合产出)
- **临界点**：当收入 > 消耗时，玩家从"生存模式"切换为"发展模式"

## 平衡验证检查列表

### 1. 资源获取速率 vs 消耗速率

- [ ] 玩家每回合平均获得多少资源？
- [ ] 玩家每回合平均需要消耗多少资源？
- [ ] 如果获得 < 消耗 → 玩家始终处于资源短缺状态，体验焦虑
- [ ] 如果获得 >> 消耗 → 资源冗余，决策无关紧要

理想状态：初期获得 < 消耗（制造紧张感），中期获得 ≈ 消耗（策略决策最密集），后期获得 > 消耗（成就感/爆发感）。

### 2. 检测"最优解"

- [ ] 在所有可能的策略中，是否有一个策略始终优于其他？
- [ ] 如果有，核心原因是数值问题还是机制问题？
- [ ] 修改方向：降低最优策略的收益，或提升其他策略的收益

**检验方法**：列出 X 种不同策略，分别计算在 N 回合后的理论得分/资源量。如果某种策略显著高于其他，说明存在最优解。

### 3. 不同玩法路径的可行性

- [ ] 每种玩法路径是否有独特的优势场景？
- [ ] 是否有某种玩法在任何场景下都不可行？
- [ ] 玩家是否有足够的可见信息来判断"当前局面适合哪种玩法"？

### 4. 节奏与 pacing 检查

- [ ] 游戏前中后期的节奏是否有明显变化？
- [ ] 玩家是否能感知到"游戏快要结束了"？
- [ ] 是否有"突然就结束了"或"怎么还没结束"的问题？

常见健康节奏模式：

```
[前期] 探索/积累 → [中期] 竞争/冲突 → [后期] 冲刺/终局
                                ↑
                        决策密度最高点
```

### 5. 回合时间检查

- [ ] 一个玩家平均每回合花多少时间在决策上？
- [ ] 等待其他玩家回合的时间（downtime）是否过长？
- [ ] Downtime 时间 > 决策时间 × 1.5 → 建议引入同时行动或简化回合

计算方式：

```
downtime = 每回合决策时间 × (玩家数 - 1)
```

### 6. 玩家数缩放检查

| 人数 | 典型问题 | 常见解决方案 |
| ------ | --------- | ------------ |
| 2 人 | 交互过于直接，容错率低 | 加入中立第三方（AI 对手/中立标记） |
| 3 人 | 可能出现"2 打 1"的合纵局面 | 规则中限制合作或公开约定 |
| 4 人 | 等待时间过长 | 引入并行行动或简化回合 |
| 5+ 人 | 单个玩家影响力稀释 | 缩短回合时间或使用竞速规则 |

#### 缩放策略速查

**等比例缩放**（最简单）：

- 每个玩家用相同资源开局
- 游戏时长 ≈ 每玩家时间 × 玩家数
- 问题：玩家数多时过长

**模块化缩放**：

- 根据人数增减版图大小、目标数量等
- 示例：4 人用完整版图，3 人用精简版图

**非线性缩放**（最复杂）：

- 不同人数下规则有差异
- 示例：2 人用特殊规则（如控制两个角色）

## 量化审查方法论

> 以下方法论用于阶段 ③-B 的系统化评审中的量化审查。
> 目标是：**用统一的逻辑框架衡量不同策略/选项的效率，找出失衡点**。

### 核心思路

量化审查的核心只有三个问题：

1. **什么是"投入"？** — 玩家执行某个操作需要付出什么？（行动次数、资源消耗、回合时间、前置条件）
2. **什么是"产出"？** — 玩家得到什么？（分数、资源、位置优势、对手劣势）
3. **不同选项的投入产出比是否合理？** — 是否有某个选项的性价比远超其他？

不同的游戏有完全不同的计量单位，所以不需要预设"1AP=1资源"这类硬锚定。而是：

- 找到你的游戏中最基础的"单位投入"（可能是 1 个行动、1 回合、1 张牌）
- 找到你的游戏中最通用的"单位产出"（可能是分数、资源、进度）
- 用这些基础单位去衡量所有其他操作的效率

### 审查步骤

#### 第一步：建立一致的基础操作

1. 列出游戏中所有基础操作（不依赖特殊能力也能做的事）
2. 检查每个操作的投入产出关系是否矛盾
3. 如果存在矛盾（如"行动 A 比行动 B 做起来更简单但收益更高"），先修复这些矛盾

#### 第二步：建立"0 特殊能力"基准

在不考虑角色技能、卡牌效果等特殊能力的情况下：

1. 分析各种策略的投入产出比
2. 分析各种策略的执行周期（多少回合一次）
3. 分析理性选择下玩家的最优选择
4. 估算各情景下的预期得分/进度

这个基准告诉你在"最朴素"的情况下游戏是否平衡。如果基础都不平衡，加入特殊能力只会放大问题。

#### 第三步：特殊能力的成本收益分析

对每个特殊能力/技能，逐一分析：

1. **使用成本**：消耗多少资源？消耗几个行动？是否有限制条件？
2. **直接收益**：直接得到什么？（分数、资源、信息、位置优势等）
3. **间接收益**：改变了哪些基础操作的成本收益比？
4. **使用频率**：每局能用几次？是否有使用上限？

**分析原则**：

- 特殊能力的效率不应显著高于基础操作的效率（否则玩家会只依赖特殊能力）
- 但对"没有基础得分手段"的阵营/角色，特殊能力可以效率更高（这是他们的核心竞争力）
- 成本越高的能力，收益应该越大，但增幅应是递减的
- 反应/反击类能力（被动触发）的收益上限应通过使用次数限制来平衡

#### 第四步：综合计算

将特殊能力、环境效果、卡牌效果全都加进去：

1. **综合效率对比**：加入所有因素后，是否还有某个策略显著优于其他？
2. **组合效应检查**：是否存在能力A+场景B+卡牌C的组合产生超出预期的大幅收益？
3. **策略多样性检查**：是否所有玩家都被迫选择同一个最优策略？

如果某种策略在绝大多数情况下都优于其他，说明存在平衡问题。修正方向：要么削弱它，要么给其他策略增加独特的优势场景。

### 深层问题检查

> 以下 6 个维度用于发现那些"表面看不出来，跑起来才会暴露"的深层问题。

#### 1. 资源耗竭曲线

如果游戏中存在**有限资源**（版图上的资源/Tokens 被消耗后就不再产生），模拟它的消耗趋势：

- 初始总量是多少？大概在第几轮会耗尽？
- 耗尽后还剩多少回合？这些回合的游戏体验是否有意义？
- 是否有资源回流机制？回流速度是否匹配消耗速度？

#### 2. 成本突变检查

当某种资源从充裕→耗尽时，核心操作的成本是否发生跳跃性变化？

- 从"有成本"突然跳到"免费"，是否有机制平滑这一过渡？
- 成本突变的受益方是谁？是否突然让某一方获得不公平的优势？

#### 3. 循环完整性检查

如果游戏中有 Token/标记/资源需要在玩家之间流转：

```
产生 → 使用/消耗 → 回收/回归 → 可再次使用
```

检查每个环节：

- 会在某个环节漏失（不返回可用池）吗？
- 回收速度（每轮返回）匹配消耗速度（每轮使用）吗？
- 初始供给量够支撑完整游戏流程的循环吗？

#### 4. 交叉组合风险

能力×环境×特殊手段的组合可能产生超出预期的效果：

- 有没有某个能力+某个场景的组合变成"必胜策略"？
- 特殊手段是否能"激活"某个被设计为弱点的属性？
- 是否存在"无限循环"或"自洽增益"链？
- 组合收益是否超出同路线/阵营的基准范围？

#### 5. 策略收敛检查

- 是否所有可行的路线最终都指向同一个最优策略？
- 资源耗尽后是否所有玩家涌向同一个目标？
- 次优策略与最优策略的效率差距是否在可接受范围？

#### 6. 非对称补偿检查

如果游戏中有"天生不具有某种能力"的阵营/角色，检查他们的特殊手段是否足够补偿：

- 他们的预期得分是否达到其他阵营的 80% 以上？
- 他们的特殊手段使用次数是否满足得分需求？
- 他们的玩法是否独特，而非"弱化版"?
